# 5.6 止损与回头：从失望到离开、从离开到重逢的节奏

> 素材来源：novel-material-skill ·《女主人设手册》5.6 止损与回头：从失望到离开、从离开到重逢的节奏

止损是清醒果断型女主的核心动作，也是女频读者最想看的桥段之一。女主止损不是作，是她在关系里发现不对之后，做出的理性决定。回头不是她心软，是他用行动重新证明了自己。本节拆成三段：止损的信号、离开的写法、回头的条件。

### 5.6.1 止损的信号

女主决定离开之前，一定有信号。这些信号不能一天出现，要在五到十章里慢慢累积，让读者看着她一点一点心冷。
- 信号一：她不再主动找他。以前她会主动问他在干嘛，现在他不找她，她就不找他。
- 信号二：她不再对他的事上心。他生病她不再紧张，他出事她不再第一时间到。
- 信号三：她开始整理自己的东西。她把他送的东西收起来，把自己的东西搬走，把账算清。
- 信号四：她对他说话变客气了。以前她会骂他、怼他，现在她用"好的""谢谢""没关系"这种客气话。
- 信号五：她不再为他哭。以前她会为他掉眼泪，现在她连难过都没有了。
- 信号六：她开始规划没有他的未来。她看新的城市、新的工作、新的圈子，把他从未来里删掉。

### 5.6.2 离开的写法

离开要写得干净、体面、不拖泥带水。女主的离开不是哭闹，是收拾完东西，留一封信，走。
- 离开的方式一：不告而别。她趁他不在，收拾好东西，走了。留一封信，信上写"我走了，别找"。
- 离开的方式二：当面说清。她约他见面，把账算清，把东西还他，说"我们到此为止"。
- 离开的方式三：写信。她写一封长信，把为什么走、为什么不等他、为什么不再信他，一件一件说清楚。
- 离开的方式四：他发现的时候，她已经在千里之外了。她走得彻底，联系方式全换，他找不到她。

离开的写法纪律：女主离开之后，不能立刻后悔。她要在离开之后的五到十章里，过得比跟他在一起时还好。读者要看到她离开之后是松了一口气，不是难过到死。如果她离开之后过得很惨，读者会觉得她离不开他，依附感就出来了。

### 5.6.3 回头的条件

回头不是她心软，是他用行动重新证明了自己。回头的条件要满足三个：
- 条件一：他真的变了。不是嘴上说变了，是行动上变了。他以前不解释，现在他会主动说；他以前不顾她，现在他会替她想。
- 条件二：他付出了代价。他为了找她，放下了自己的骄傲、自己的身份、自己的规矩。代价越大，回头越值钱。
- 条件三：她有底气拒绝。她可以选择回头，也可以选择不回头。她不是被他追回来的，是她自己选择回来的。

### 5.6.4 回头的节奏样本

下面给一个"清醒果断型女主止损 + 并肩型男主回头"的节奏样本。

【离开后的前十章】她在另一个城市，换了工作，交了新朋友。她每天很忙，很忙到没时间想他。读者要看到她过得很好。

【他找过来的第一面】他找到她，她没惊讶，像早就知道他会来。她请他喝了一杯茶，问他"喝什么"，客气得像对一个陌生人。

【他解释】他把以前的误会一件一件说清楚。她听完，点点头，说"我知道了"。没有哭，没有闹，只是平静。

【他问"我们还能回去吗"】她看着他，很久，说："我回去，不是因为你改了，是因为我愿意再给你一次机会。但你记住，这是最后一次。"

这个样本的关键：女主全程是主动的。他来，她接待；他解释，她听；他问，她决定。她不是被他追回来的，是她选择回来的。这才是"被偏爱但不依附"的回头。
