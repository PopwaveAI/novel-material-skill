# 11.2 原版二十个案例深拆

> 素材来源：novel-material-skill ·《女主人设手册》11.2 原版二十个案例深拆

行为与习惯清单：
- 回消息永远隔半个时辰，不管对方是谁。
- 别人示好，她不拒绝也不答应，只说"再说吧"。
- 和人吃饭坐主位但话最少，听完所有人说才开口一句。
- 被人问"你到底怎么想"，她答"没怎么想"。
- 生气的时候更安静，安静到对方发现自己错了。
- 每天傍晚雷打不动喂鱼，喂鱼的时候谁都不见。
- 收到情书不拆，压在书堆最下面，过三个月才看。
- 有人离她太近，她会下意识退半步，退得很自然。

台词样本：

"你不用对我这么好。我这个人，记不住好。"（对方靠近时）

"我没说我等你。我只是刚好也没走。"（对方以为她在等时）

"你要走就走。走了就别再回来，我不会问第二遍。"（对方犹豫时）

"我今天没有不高兴。我只是话少。你别多想。"（对方以为她冷脸时）

名场面一：

他追了她三个月，每天送花、每天接她下班，她永远那副淡淡的样子。这天他冒雨在她楼下站了两个时辰，浑身湿透，敲开她的门，说："苏枕雪，我到底要怎么做你才肯正眼看我一次？"她开门看他，看了很久，没让他进来，也没把门关上。她转身去倒了一杯热水，递到他手里，手指碰到他的手背，凉的。她说："你进来吧。我给你找条毛巾。"他愣在门口。她已经走进去了，走了两步又回头，补了一句："毛巾是我自己用的。你今天用了，下次你别再来了。"他那天在她屋里坐了一个时辰，她一句话没说，就坐在鱼缸前喂鱼。他临走时她送到门口，第一次主动说了一句："明天下雨，你别来了。"

名场面二：

他和别的女同事被人拍到一起吃饭，照片传到她手上。他慌了，跑来解释，说了一刻钟。她听完，把照片放在桌上，抬眼看他："你解释完了？"他点头。她起身走到鱼缸前，撒了一把鱼食，说："我没生气。我只是在想，我要是生气，是不是就有理由让你以后别来了。"她说完转过身，看着他，"我没有生气。但我告诉你一件事：我这个人这辈子第一次等一个人回家，等了三个月。你要是让我等第二次，我不等了。"他那天站在她屋里，第一次看见她眼里有一点湿。

拆解仿写要点：
- 清冷钓系的苏点在于"她偶尔泄露的那一下在意"。平时她越淡，那一下泄露就越值钱。
- 她的在意要靠动作，不靠台词。一杯热水、一条毛巾、一句"明天别来了"，比十句"我喜欢你"重。
- 她和男主的节奏要慢。前三十章男主追，三十章后她才第一次主动，主动的方式也只是"等你回家"。
- 她的冷要写成"累"，不是"傲"。她只是从小习惯了不说，不是看不起谁。

崩人设预警：
- 她突然话多。救法：话多只能是一次喝醉，醉完第二天她比平时更安静，且装作什么都不记得。
- 她主动倒贴。救法：主动只能是"她默默替他做了一件事"，不是"她表白"。做完她自己先装作没做。
- 她的冷淡被读者写成无情。救法：加一段她独自在鱼缸前对着鱼说话的戏，把她平时不说的话对着鱼说出来。
- 男主误会她不在乎。救法：误会只能持续三章以内，且第三章末尾必须让男主撞见她为他做的那件事。

仿写练习：写她母亲重病住院，她一个人在医院守了七天，没告诉任何人。自检标准：男主得知消息赶到医院时，她不能扑上去哭；她要坐在病房外的长椅上，抬头看他一眼，说"你怎么来了"，然后把头靠在他肩膀上，靠了十秒，立刻直起身说"你去帮我买份粥"。

### 案例七：钓系心机女主｜步步为营（闻人疏）

一句话定位：她接近你的每一步都算过分寸，可算到最后一步，她自己先陷进去了。

人设卡（五要素）：

「核心欲望」：借男主这步棋，把自己从被家族摆布的棋子，下成自己执棋的人。

「核心恐惧」：算得太精，把真心也算了进去，最后分不清哪一步是套路、哪一步是真。

「致命缺陷」：不信真心。她收到男主的真心第一反应不是感动，是"他图什么"。

「行事逻辑」：接近一个人之前先列一张对方的需求表；每走一步都留三个后手；动情的时候反而离得更远。

「反差点」：在外步步为营算无遗策，回家却把今天说过的每一句话在脑子里复盘三遍，怕哪一句说错。

底层创伤：她是庶女，从小被嫡母当礼物养，十三岁就被安排去接近一个十六岁的世家公子。她接近到一半，那个公子被家族送去边关，死在战场上。她站在城门口等了三个月，等到的是一只染血的玉佩。从那天起她信一件事：感情是可以拿来用的，用的时候别走心。

行为与习惯清单：
- 见任何人之前先打听对方喜欢什么、讨厌什么、最近在愁什么。
- 说话永远留三分，答应的事只做到七成，剩下三成看情况。
- 对人笑的时候眼睛先不动，笑到眼睛里需要三息。
- 有人对她好，她第一反应是记录对方图什么。
- 深夜写日记，但日记里写的全是计划，不写情绪。
- 和人保持固定的距离，对方靠近一寸，她就退后一寸。
- 动情的时候反而更冷，冷到对方以为她变了心。
- 关键局前会一个人待一夜，把明天每一句台词在心里过一遍。

台词样本：

"我对你好是真的。但我为什么对你好，你别问。"（被试探时）

"你以为我是真心？真心这东西，我十岁那年就用完了。"（男主掏心时）

"我可以帮你，但你记住，我帮你的每一步，都是要还的。"（结盟时）

"你今天问我的这句话，我二十年前就被人问过。我当时没答，现在也不打算答。"（被戳中心事时）

名场面一：

她按计划接近男主，三个月后男主向她表白，说"闻人疏，我知道你心里有事，你不说我也等"。她站在廊下，看着男主的背影，第一次不知道下一步该怎么走。她回到自己屋里，把这三个月和男主说过的每一句话在脑子里过了一遍，过到第三遍，她发现自己有两句话是不在计划里的。她坐在灯下，手里捏着那枚当年那个公子留下的染血玉佩，捏了很久。第二天她照常去见男主，笑还是那个笑，话还是那些话，但临走时她鬼使神差地多说了一句："你天冷了，自己加衣。"说完她自己愣了一下，男主也愣了一下。她立刻转身走了，走得比平时都快。

名场面二：

男主终于发现她接近他是为了家族那桩婚事，拿着她的日记来质问她。她被堵在屋里，知道瞒不住了。她抬起头，很平静地说："是。我一开始接近你，是因为你这步棋对我有用。"男主手在抖。她顿了一下，继续说："但你听我说完。我从十四岁开始被人当棋子用，用了十年。我本来以为我这辈子只会用别人、不会被别人用。直到三个月前，我对你说了一句不在计划里的话。那天晚上我失眠到天亮，我才知道，我完了。"她说到这里，声音第一次有点抖，"你要恨我，我认。但我告诉你，从那天起，我对你的每一步，都不是算计。"

拆解仿写要点：
- 心机钓系的关键不是"她有多会算"，而是"她算到最后把自己算进去了"。这个转折要写得让人心疼。
- 她的算计要有边界：她算计别人，但绝不伤无辜。一旦伤了无辜，人物就黑了。
- 她的过去那只染血玉佩是关键道具，全书至少用三次：初见、动摇、摊牌。
- 男主识破她之后不要立刻分手。男主该做的是把日记放下，说"你这本子从今天起别写了，写我"。

崩人设预警：
- 她突然全心全意。救法：全心全意只能发生在"男主替她挡了一次真正的死劫"之后，且她要为此放弃一个筹谋了很久的计划。
- 她的算计伤到了男主。救法：一旦误伤到男主，她必须独自消失一段时间，回来之后把那枚玉佩交给男主，相当于把过去交出去。
- 她对男主动机不纯被读者骂。救法：让她在算计男主的同时，私下里替男主挡过一件男主自己都不知道的麻烦。
- 她日记被发现的戏写成了狗血。救法：发现日记的不是男主，是她自己喝醉了主动把日记交给男主。
