# 1.7 避免"预制人"：标签堆叠与真人感的区别

> 素材来源：novel-material-skill ·《女主人设手册》1.7 避免"预制人"：标签堆叠与真人感的区别

预制人是指那种把标签贴满全身、却没有行为支撑的纸片人：大女主、清醒、飒、敢爱敢恨，样样都有，样样都假。区别预制人和真人的关键，看三层结构是否完整。

### 1.7.1 预制人的三个典型症状
- 症状一：标签靠旁白。别人说"她就是那种很清醒的女人"，但她的行为处处恋爱脑。
- 症状二：行为万能化。她对所有人都一个态度，没有亲疏远近之分。
- 症状三：缺陷是贴上去的。她号称"固执"，但从不因此付出代价。

三个症状的本质都是同一件事：只有表层标签，没有中层行为和底层创伤。

### 1.7.2 真人感从哪里来

真人感来自三层结构的完整，加两个细节：不一致性和私密性。
- 不一致性：她对上司一个态度、对闺蜜另一个态度、对陌生路人第三个态度。态度差异本身就是人物。
- 私密性：她有别人不知道的小习惯、小物件、小执念。独处时的她，才见真章。
- 缺陷露馅：她装得很稳，但某个瞬间漏出真实的情绪，这个瞬间比一百句描写都值钱。

「真人感三件套」：一个只有她自己知道的小习惯，一个她绝不承认的软肋，一个她单独面对时才露出的表情。三样凑齐，人物就有温度。

「习惯动作库」：给女主配一组独属于她的习惯动作：紧张时转无名指上的旧戒、说谎时先看自己的手、独处时把字写得很小、思考时用指节敲桌面。习惯动作要和她的人物史对得上（戒指出自谁、小字是因为怕被看到），用三次以上才成记忆点。

「真人感密度」：真人感是密度问题，不是玄学：每三千字至少出现一个"只有她知道"的细节。细节不必解释，读者自己会拼出她的历史。

### 1.7.3 快速检查法

| 检查问题 | 通过标准 |
|---|---|
| 把她的标签全部遮住，光看行为，读者能认出她是哪型吗 | 能，行为自己会说话 |
| 她对不同的人态度一样吗 | 不一样，亲疏远近分明 |
| 她有没有只有自己知道的秘密 | 有，且这个秘密影响她的选择 |
| 她最近一次吃亏是因为什么 | 因为她的致命缺陷，而不是因为剧情需要 |

四条全过，人设基本是真人。有任一不过，回到 1.1 到 1.2 把那一层补上。

### 1.7.4 预制人与真人的改写对照

同一个情节，预制人写法和真人写法差在哪，对照最直观。

预制人写法：她是个清醒又飒的女人，从不恋爱脑。面对男主的追求，她淡淡一笑：男人只会影响我拔剑的速度。读者感受：这句话像从段子里抄的，人物是标签的集合体。

真人写法：男主约她吃饭，她先查了他的排班表，确认他今天没有别的饭局，才答应。席间他给她夹菜，她没动那筷子，先问了句：你上次说要查的那个案子，查得怎么样了。她不是不爱他，是她的爱有前置条件：她要知道这个男人值不值得她放下手里的剑。

真人写法里没有一句"清醒"，但读者读完全段都信她清醒。标签靠行为证明，不靠形容词宣告，这是全书写女主的底层法则。

### 1.7.5 真人感的三条检查线

写完一个女主，用三条线自查：行为线、关系线、独处线。
- 行为线：抽三场关键戏，她的行为是否都符合一定会/绝不会清单。
- 关系线：她对男主、闺蜜、敌人、陌生人的态度是否有梯度差异。
- 独处线：有没有一场戏只有她一个人，读者能看见她的真实状态。

三条线都通，人物就立住了。任何一条不通，回到对应小节补课：行为线回 1.1.4，关系线回 1.2.2，独处线回 1.2.3。

「真人感的最后一道检验」：把她写进一个完全陌生的场景（迷路、停电、突发变故），看她会怎么反应。真人会在陌生场景里露出习惯性动作和条件反射，预制人只会换一套形容词。
