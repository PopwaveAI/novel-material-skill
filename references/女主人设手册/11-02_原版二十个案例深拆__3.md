# 11.2 原版二十个案例深拆

> 素材来源：novel-material-skill ·《女主人设手册》11.2 原版二十个案例深拆

她搬走那天，他冒雨追到楼下，撑着伞站在出租车外，说"南枝你下来，我们谈谈"。她隔着车窗看他，看了很久。司机问她走不走，她轻轻说"走"。车开出去半条街，她从后视镜里看他还站在雨里，一只手捂住了脸。她低下头，从包里拿出那张三年前的信纸，慢慢撕了，撕成一小片一小片，按下车窗，让风把碎片吹走。她没哭。司机从后视镜里看她，她对司机笑了一下："师傅，麻烦快一点，我下午还有个会。"

名场面二：

半年后她在一个酒局上遇见他。他瘦了很多，端着酒杯走过来，说"南枝，这半年我想清楚了，我们重新开始好不好"。她正端着茶，听见这话没抬头，只是把茶杯放下，从包里取出一张纸，推到他面前。那是她半年前列的那张开销表，每一笔都记得清清楚楚。她说："你要重新开始，可以。这张表你先看。欠我的那部分，你要是真有心，就先还清。还清那天，我们再谈重新开始。"他看着那张纸，手开始抖。她站起身，拎包走了，走到门口才停下，背对着他说："其实我今天看见你，还是有点难受。但难受归难受，账归账。"

拆解仿写要点：
- 清醒止损的爽感来自"她比所有人想象的都果断"。分手戏要让读者在三章前就开始替她憋屈，这一章一次性释放。
- 她的痛要写，但不能写成自怨自艾。她允许自己难受一次，第二天照常上班。
- 前任回头不能立刻和好。和好用至少十章来铺，且和好的前提是前任真的还了账。
- 她和新男主的关系要慢。新男主越追，她越要先把"三条线"列清楚，这是她的自我保护。

崩人设预警：
- 她突然回头。救法：回头只能是一次试探，试探完她发现他没变，立刻再走，且这一次比上一次更狠。
- 她在分手戏里歇斯底里。救法：把歇斯底里改成"她把杯子摔了，摔完蹲下去一片一片捡"，动作比台词有力。
- 她开始否定过去三年。救法：加一段她独自去以前常去的小店、点以前常点的菜、吃完结账离开的戏，她承认那三年里有真的好。
- 她为了证明自己不难过而立刻谈新恋爱。救法：让她在新恋爱里突然发现自己又在算账，被新男主点破，她才承认自己还没走出来。

仿写练习：写她搬出去三个月后，前任生病住院，托人带话想见她最后一面。自检标准：她不能不见，也不能去了就哭着和好；她要去医院，站在病房门口看他一眼，把一个保温桶放在门口，转身走。保温桶里是他以前爱喝的粥，粥底下压着一张字条："这是最后一次。"

### 案例五：钓系明艳女主｜撩而不陷（霍青梧）

一句话定位：她笑起来满屋子的男人都失了半分神，可她心里那本账，谁都没算到过最后一页。

人设卡（五要素）：

「核心欲望」：被人真正读懂，而不是被人真正拿下。她要的是一个能接住她所有套路还不拆穿的人。

「核心恐惧」：自己先动了真心，被人看穿之后成为对方手里的牌。

「致命缺陷」：先走一步。真到该交真心的时候，她的第一反应是撤，结果把人撤没了。

「行事逻辑」：撩三寸留七分；对方认真她就退半步；绝不主动说"喜欢"两个字。

「反差点」：在外是眼波横处自有春水的明艳美人，回家卸了妆却蹲在地板上给猫梳毛，梳着梳着自己先打个哈欠。

底层创伤：她小时候是勾栏里养出来的瘦马，师傅教她的第一课是"男人的眼睛可以让你活下去，但不能让你信"。她十三岁被一位富商赎身，离开时师傅笑着说"记住，谁先动心谁先死"。这句话她记了十年。

行为与习惯清单：
- 和人对视时眼尾先挑一下，再慢慢把眼神移开。
- 笑的时候用指尖轻轻挡一下嘴角，挡得很做作，但好看。
- 收到贵重礼物当场笑纳，转头就让人按市价折成银子送到对方府上，分文不少。
- 和谁都不把话说满，答应什么事永远带三分余地。
- 喝了酒脸颊先红，红到耳根，但眼神始终清明。
- 有人表白，她不接话，只笑着给对方斟一杯酒，把话题岔开。
- 回家第一件事是把耳饰摘下来，揉一揉耳垂，整个人立刻松下来。
- 半夜睡不着会起来给猫添粮，添完坐在窗台上看月亮，看很久。

台词样本：

"你喜欢我哪一点？我改。"（对方认真表白时）

"我今天给你这一寸，你别以为就有一丈。线还在我手里。"（对方得寸进尺时）

"你别急。我要是真想走，你现在已经见不到我了。"（对方怕她跑时）

"我对你有意思是真的。但有意思和把心交出去，是两回事。"（被追问时）

名场面一：

宴上他喝多了，抓着她的手腕，红着眼说"青梧，我是真的喜欢你，你别再逗我了"。她被他抓着手腕没挣开，只是歪着头看他，看了很久，忽然笑了一下，那笑和平时应酬的笑不一样，笑得有点软。她空着的那只手抬起来，替他理了理衣领，动作很轻。她说："我今天不逗你。你听清楚，我霍青梧长到二十四岁，对谁都没认真过。今天对你，认真了三分。这三分你拿着，别糟蹋。"说完她抽出手腕，转身就走，走得比平时还快。他在原地愣了半天，才发现自己手心全是汗。

名场面二：

他查到她其实早年在勾栏待过，拿着这件事来质问她，以为她会慌。她听完，端起茶盏慢慢吹了吹，抬眼看他："你既然都查清楚了，还来问我做什么？"他说"我是怕你瞒我"。她放下茶盏，站起身，走到他面前，很近地看着他："我在勾栏待过六年。这六年里我学会的第一件事，就是不把自己交给任何人。今天我既然坐在你面前，把这件事亲口告诉你，你知道这意味着什么吗？"她顿了一下，"意味着我今天，把线松开了一寸。你要是敢拿这件事伤我，我下一秒就收回去，从此你连一寸都没有。"

拆解仿写要点：
- 钓系明艳的高级写法是"她根本没在撩，是你自己被晃了眼"。写她的撩，不要写她主动凑上去，要写她什么都没做，对方先失了神。
- 她的真心只能一点点露。第一次露三分，第二次露五分，全书露到八分就停，留两分是她的自我保护。
- 她的过去不要写成羞耻。她自己不觉得羞耻，男主也不能觉得羞耻，这是钓系女主和"风尘从良"文的分界线。
- 她的退要写得让人心疼。每次她先撤，都要配一个她独自松下来的瞬间，让读者看见她撤的时候也在疼。

崩人设预警：
- 她突然倒贴。救法：倒贴只能是一次喝醉后的失控，第二天她必须装作不记得，且比平时更冷。
- 她的撩变成了渣。救法：给她加一条"绝不动朋友的男人、绝不动有婚约的人"的底线，底线踩了她自己比谁都难受。
- 她对谁都钓。救法：让男主之外的男人追求她时，她的反应明显和对男主不一样：对别人是应酬的笑，对男主是失神的那一下。
- 她的身世被男主揭短时崩了。救法：她不是哭，是当场笑出声，笑完说"你查我，说明你认真了。认真就好办了"。

仿写练习：写她遇到一个"男主为了救她，被仇家打断了一条腿"的局。自检标准：她不能立刻扑上去哭；她要先把仇家处理完，处理完之后回到男主床前，站着看他很久，然后做一件她从来没做过的事：把头靠在他没受伤的那只手上，靠了三秒，立刻起身出去吩咐人熬药。

### 案例六：钓系清冷女主｜若即若离（苏枕雪）

一句话定位：她不主动，不拒绝，不负责。你以为你在追她，其实是她在看你配不配。

人设卡（五要素）：

「核心欲望」：找一个不用她开口就知道她要什么的人，从此她可以省掉所有"解释"的力气。

「核心恐惧」：一旦交底，对方发现她其实没那么好，掉头就走。

「致命缺陷」：什么都不说。她把在意压在心底，对方猜不到，猜不到就以为她不在乎。

「行事逻辑」：不主动联系；对方来找她，她不拒绝也不热情；对方冷淡，她比对方还淡三分。

「反差点」：对外人是一座冰山，唯独养了一缸热带鱼，每天雷打不动坐在缸前喂十分钟。

底层创伤：她从小被家里当棋子养，七岁就被教"不要把想要的东西说出来，说出来就会被人拿去当把柄"。她想要一块糖，等到别人主动给；想要一个人陪，等到别人主动来。等到最后，糖和人都没等到几个。
