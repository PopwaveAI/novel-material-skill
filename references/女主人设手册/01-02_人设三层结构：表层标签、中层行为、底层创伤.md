# 1.2 人设三层结构：表层标签、中层行为、底层创伤

> 素材来源：novel-material-skill ·《女主人设手册》1.2 人设三层结构：表层标签、中层行为、底层创伤

三层结构是五要素的落地版。表层标签是读者第一眼看到的，中层行为是标签的证明，底层创伤是行为的出处。三层缺一层，人物就飘。

### 1.2.1 表层标签：一句话让读者认出她

标签负责第一印象，它必须能被一句话说清楚：大女主、清醒果断、钓系、软刺、倔强隐忍、清冷疏离、明艳张扬。标签是入口，不是终点。
- 标签要可感知：不是"她很有个性"，而是"她是那种能把一屋子人安排明白的人"。
- 标签要能起冲突：清冷疏离放在宫斗里，本身就是冲突源。
- 标签要留升级空间：大女主不是开局即满级，标签要经得起后面被打碎再重组。

写标签时顺手写一句"标签的第一印象"，再用一段"标签的反面"做平衡。比如明艳张扬的反面是怕被看穿，钓系的反面是怕被当真。标签带着反面，才有厚度。

### 1.2.2 中层行为：标签落到具体动作和选择上

标签没有行为支撑，就是贴纸。中层行为是把标签翻译成读者看得见的动作、语言、选择。这一层写得越细，人物越活。
- 清醒型的行为：别人画饼时她只问"什么时候兑现、写不写进合同"。
- 大女主型的行为：被针对时不辩解，直接把对方的牌一张张亮出来。
- 软刺型的行为：嘴上说着"你爱怎么想怎么想"，手里已经替对方把事情办妥了。
- 钓系型的行为：从不主动说喜欢，但每句话都让对方多想一步。

中层行为是全书写作密度最高的一层。行为清单要写到"可抄用"的程度：具体动作、具体台词、具体场景。这部分内容在第二、三、七部分的词库里大量展开，这里先给方法论。

「行为三件套」：每个标签配三个典型行为，每个行为配一个触发场景。比如"果断"配"限时两刻钟，她当场撕了契约重拟"。行为有场景才有生命。

「行为密度检查」：一段三百字的戏里，女主至少要有两个具体行为（动作、选择或反应），不能全靠旁白和他人转述。行为密度不够，人物就是纸上的名字。

### 1.2.3 底层创伤：过往如何塑造她，决定她如何爱人、如何防备

底层创伤是三层的根。它不必惨烈，但要具体、要早、要真实地改变过她的认知。创伤决定两件事：她怎么爱人，她怎么防备。
- 她第一次信任换来背叛，从此她的爱都要带条件。
- 她在家里永远是"要让着弟弟"的那个，从此她学会什么都靠自己。
- 她曾被当众否定得体无完肤，从此她把"被认可"当成执念。

写创伤三条纪律：第一，创伤要能解释她的行为，不能行为是行为、创伤是创伤；第二，创伤要回扣，不能开头提一句后面再也不管；第三，创伤要留愈合的口子，否则结局没有光。

「创伤回扣动作」：创伤要物化成一个具体的意象或动作反复出现。比如被锁过的女主，对关着的门有本能的紧张；被抛弃过的女主，听到"你先走"会顿一下。意象越具体，回扣越有力。

### 1.2.4 三层之间的关系：一致与落差

三层关系有两种正确形态：一致型，标签、行为、创伤在同一条线上，人物厚而稳；落差型，表层标签和中层行为与底层创伤形成反差，人物有戏剧张力。最怕的是断层型：行为解释不了标签，创伤解释不了行为。
- 一致型示例：标签"清醒"，行为"从不被画饼打动"，创伤"画过她饼的人骗走了她妈留给她的钱"。三层同源，稳。
- 落差型示例：标签"钓系"，行为"撩完就跑"，创伤"她怕被当真，因为上次被当真之后她输得很惨"。落差有成因，戏剧性强。

写落差型时，成因要早给，不能拖到中段才揭。读者需要在前面就能隐约感到"她不对劲"，后面揭开成因时才觉得合理。

拿第二个虚构角色走一遍三层结构。沈鸢，钓系清冷女主。表层标签：清冷钓系，话少、分寸感强、撩完就跑。中层行为：她从不说喜欢，但记得对方随口提过的喜好；对方靠近一步她就退一步；被人拆穿在意时，她用一句玩笑带过。底层创伤：她十二岁那年真心交付过一次，换来的是对方拿她的秘密当谈资，从此她把"被看穿"当成危险信号。三层串起来：因为创伤（怕被看穿），所以行为上若即若离（保持距离），于是标签就成了"钓系"（别人看到的壳）。读者在前面看到的是她的壳，中段揭开创伤，壳和核才一起成立。

「三层串讲练习」：给每个女主写一段三层串讲：因为发生过什么，所以她习惯怎样，于是别人看到的她是怎样。串讲能讲通，人物就立住了。

「偏好重置练习」：写完一个女主，把她的类型标签换掉（钓系换成软刺、大女主换成清冷），看同一场戏她的反应会不会变。不会变，说明你写的是通用型女主，行为没有跟着人设走。

「断层自查」：行为解释不了标签、创伤解释不了行为，就是断层。断层时优先改创伤，因为创伤是根，改根比改枝更省力。

「标签与行为对齐」：标签只是索引，行为才是内容。读者记住的不是你说她清醒，是她听到画饼时当场算了一笔账。每写一个标签词，问自己：这场戏里它落在哪个动作上。

### 1.2.5 标签的升级线

标签不是一层不变的。女主的成长，本质上就是标签被修正的过程：开局她是"清醒"，中段她学会"糊涂一次"，结局她是"清醒但敢相信"。标签升级线写清楚了，读者就看得见她的弧光。

| 阶段 | 标签形态 | 行为表现 |
|---|---|---|
| 开局 | 防御型标签：清醒、疏离、算得清 | 对所有人保留三分，独善其身 |
| 中段 | 松动型标签：开始有例外 | 她为一个人破例，但事后会慌、会补救 |
| 结局 | 整合型标签：清醒且敢信 | 她依然看得清，但愿意把后背交出去 |

写升级线时注意：每一级标签的变化都要有事件推动，不能她睡一觉就变了。谁让她松动、哪件事让她敢信，都要写实。

### 1.2.6 六类高频创伤与写法

| 创伤类型 | 留给女主的行为痕迹 | 愈合线写法 |
|---|---|---|
| 被背叛 | 对信任极度谨慎，先查再信 | 让她把后背交给一个人，且对方接住了 |
| 被抛弃 | 永远先走一步，不肯做被留下的那个 | 让她学会等一次，且对方真的来了 |
| 被轻视 | 拼命证明自己，害怕被看低 | 让她接受一次"不被证明也能被爱" |
| 被控制 | 对"替她做决定"高度敏感 | 让她自己掌一次舵，且后果可承受 |
| 被误解 | 话只说三分，怕再被扭曲 | 让她完整说出一次心里话，且被听懂了 |
| 被牺牲 | 不敢接受别人的好，怕欠债 | 让她坦然收下一次好意，不急着还 |

这六类几乎覆盖女频主流创伤。选创伤时注意两点：第一，创伤要与她的类型同源（钓系的伤通常是"被看穿"，大女主的伤通常是"信错人"）；第二，创伤的强度要与题材匹配（宫斗文里灭门之仇成立，甜宠文里可以轻很多）。
