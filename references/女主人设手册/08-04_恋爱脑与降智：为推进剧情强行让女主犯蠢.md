# 8.4 恋爱脑与降智：为推进剧情强行让女主犯蠢

> 素材来源：novel-material-skill ·《女主人设手册》8.4 恋爱脑与降智：为推进剧情强行让女主犯蠢

这是女频被骂得最多的一类崩。读者点开一个“清醒大女主”的简介，看了二十章发现她一谈恋爱就智商归零，评论区立刻炸。恋爱脑和降智的本质是：作者为了推进感情线或制造误会，强行让女主做出一件她按人设绝不会做的事。下面先给边界判定法，再给症状、案例、修法。

### 8.4.1 “女主主动但不恋爱脑”的边界判定法

这是本节最重要的一张表。写每一场女主和男主的感情戏之前，拿这张表对一遍。过了边界，就是恋爱脑；没过边界，就是女主主动。

| 维度 | 女主主动（可写） | 恋爱脑（不可写） |
|---|---|---|
| 选择顺序 | 先有她自己的目标，他是她目标路上的人，她选择靠近他是因为他对她有用或她真的喜欢，但她的目标不因为他放弃。 | 她的人生目标从遇见他那一刻起就变成了“得到他”，事业、家人、仇全都可以为他让路。 |
| 信息判断 | 她知道他有问题、有秘密、有危险，她选择“我留下来，是因为我自己想看看，不是因为我傻”。 | 所有人都告诉她这个人有问题，她选择性失明，理由是“我相信他”。 |
| 止损能力 | 他真的伤害她一次，她会疼、会哭、会舍不得，但她会走。走了之后可以回来，但回来的条件是他真的变了，且她没丢自己。 | 他伤害她一次又一次，她每次都原谅，理由是“他对我其实是真心的”，她身边所有朋友都被她得罪光。 |
| 付出与回报 | 她为他付出，可以很多，但她要看见他也在付出。她付出的底线是“我不把命交给你，除非你先把命给我”。 | 她为他付出一切，他什么都没做，她还自我感动“我只要他开心就好”。 |
| 情绪上头时的决定 | 她在他面前可以哭、可以闹、可以失态，但真到要做大事的时候，她把情绪压下去，先把事办完。 | 她一和他吵架就放下手里所有正事，工作不管了、朋友不见了、仇不报了，满脑子都是“他为什么不理我”。 |
| 自我认知 | 她知道自己喜欢他，她也知道自己喜欢他多少。她不回避这份喜欢，但她不让这份喜欢定义她是谁。 | 她嘴上说“我才不是那种围着男人转的女人”，身体却很诚实，一章不写到他就慌。 |

### 8.4.2 典型症状
- 她和男主一吵架就放下正在办的正事，正事连续三章没推进，全在写她怎么伤心。
- 男主说一句“你信我”，她就把所有理智下线，明明有三个疑点摆在眼前，她一个都不查。
- 她为了男主和身边所有真心对她的人翻脸，闺蜜劝她一句她骂闺蜜，父亲劝她一句她离家出走。
- 她的“主动”全部围着他转：她努力是为了配得上他，她变强是为了他不被人欺负，她的成长线和他的成长线完全绑死。
- 分手之后她彻底垮掉，工作丢了、人病了、整个世界塌了，直到他回来找她她才活过来。她没有自己的支撑系统。
- 她对他的一切缺点视而不见，他冷暴力她，她自我解释“他是工作忙”；他和别的女人暧昧，她自我解释“他们只是朋友”。

### 8.4.3 翻车案例

【案例 1】女主是个刑警，追一个连环案追了五十章，线索已经指向男主身边那个助理。她同事提醒她“你查一下那个人”，她想了想说“他不会骗我的”，然后把线索压了下去。结果那个助理就是真凶，她的搭档因此牺牲。这就是典型的为感情线降智：她作为刑警的专业判断被“他不会骗我”五个字杀掉了。读者看到这里会出戏，因为前面五十章她建立起来的专业形象，被这一句话毁掉了。

【案例 2】女主是个集团总裁，正在和对手打一场决定公司生死的商战。男主那天和她吵了一架，她一怒之下飞去他的城市找他，留着公司那几千万的合同没人签，对手趁虚而入。等她回来，公司已经快垮了。这就是“情绪上头时做决定”越过了边界。女主可以有情绪，但她不能在几千万的合同面前为了一架就飞走。

### 8.4.4 修正方案
- 给女主建一条“事业/主线进度线”，和感情线并行。每写两章感情戏，必须写一章她自己的事。她的事（复仇、事业、救人）不能因为谈恋爱停摆。
- 她可以为他心软，但心软之后要付出代价。她因为相信男主压下了线索，结果搭档牺牲，她要为此自责、为此和男主大吵一架、为此在后面的戏里再也不犯第二次。心软不是错，不成长才是错。
- 写她吃醋、她伤心、她想他的时候，让她手上同时在做一件事：一边想他一边改方案、一边哭一边给下属打电话安排明天的会。情绪和做事并行，她就不是恋爱脑，是一个有七情六欲的活人。
- 她身边要有一个“理性声音”。可以是闺蜜、是副手、是她自己日记本里的一段话。这个声音在她快要恋爱脑的时候出来提醒她，她可以不听，但那个声音必须存在。
- 她的“主动追他”要写得有章法。她可以主动、可以撩、可以先告白，但她的主动是她自己选的，不是她失控了。她告白完转身走，不等他回答，那叫主动；她告白完跪在他脚下求他选自己，那叫恋爱脑。
- 分手后让她先活过来，再考虑复合。她分手之后的五到十章，要写她自己怎么把日子过下去、怎么把没办完的事办完、怎么一个人扛过最疼的那段。她活过来了，男主再回来追，这时候复合才有重量；她没活过来就复合，她就是男主的附属品。
