# 10.1 女主人设卡模板：一张表填完一个女主

> 素材来源：novel-material-skill ·《女主人设手册》10.1 女主人设卡模板：一张表填完一个女主

本部分是全书的工具箱。前面九部分讲的是"怎么想"，本部分讲的是"怎么做"：把一个抽象的人设想法，变成一张能拿在手里、随时对照、随时修改的人设卡，再按五步流程把它搭出来，用二十条一致性检查表把它卡住，最后学会怎么在写到一半的时候安全地改人设、怎么处理多女主和女配。本部分承接第一部分（五要素与三层结构）、第二部分（类型库）、第三部分（性格写法）、第七部分（台词与名场面），把前面所有零散的知识点收束成可执行的表格与流程。后面第十二部分（自检清单）会在本部分检查表的基础上扩展成全书定稿前的总自检，第十一部分（单项人设参考库）的每个案例都会按本部分的人设卡格式来填。本部分只负责给工具、给流程、给检查表。

人设卡不是写完就锁死的文物，它是活的文档，每写二十章回来更新一次。更新的时候改什么：她对男主的关系有没有变，她的反差点有没有新增，她的口头禅有没有变，她的核心欲望有没有偏移。这些变了，卡就要跟着改。卡是她的地图，人走到哪，地图更新到哪。

填卡的时候有三个常见毛病要避开。一是字段全是形容词。"她很美""她很聪明""她很善良"，这种填法等于没填。每个字段都要落到具体行为。不要写"她很聪明"，要写"她看一遍账本就能发现哪里对不上"。二是字段之间互相矛盾。核心欲望写"我要复仇"，行事逻辑写"与人为善"，这种自相矛盾要回头理顺。三是缺陷字段写得太轻。"她有点固执""她偶尔任性"，这不是致命缺陷，这是可爱小脾气。致命缺陷要真的能让她栽跟头。

再展开说几个关键字段怎么填。核心欲望不要写"她要幸福"这种大词。要写得具体到她能为之付出一切的那件事。是复国？是报仇？是离开那个家？是证明给某个看不起她的人看？越具体，后面越好写。核心恐惧和核心欲望是一对镜像：她越想要什么，就越怕失去什么。致命缺陷不要写"她太善良"，善良不是缺陷。缺陷要写那种她自己都知道不好、但改不掉的东西。比如她不会求助，比如她过度独立，比如她习惯性推开人。行事逻辑要写成一句可以判断任何事的公式：遇到任何选择，她怎么算。反差点要落到一个具体物件或具体行为上，不要只写"外冷内热"。

### 10.1.1 完整字段模板

一张标准女主人设卡分七大块。每一块都不能空着，空着的字段就是后面崩人设的伏笔。

| 板块 | 字段 | 填写要求 |
|---|---|---|
| 基础信息 | 姓名/年龄/身份/题材/时代 | 身份要写到具体职位或处境，不要只写"侯府千金"，要写"侯府嫡女，母早亡，父不疼，继母掌权" |
| 基础信息 | 一句话定位 | 用一句话说清这个女主的核心卖点，例：被全家当棋子嫁出去的嫡女，反手把棋盘掀了 |
| 外貌 | 眉眼/身形/服饰/标志特征 | 参考第四部分词库，每项至少一条具体描写，不要只写"很美" |
| 性格 | 核心欲望/核心恐惧/致命缺陷/行事逻辑/反差点 | 这五要素必须逐条写清，详见第一部分 1.1 |
| 性格 | 表层标签/中层行为/底层创伤 | 三层结构逐层填，详见第一部分 1.2 |
| 过往 | 童年/关键事件/当前处境 | 过往要回答"她为什么变成今天这样"，至少三个关键事件 |
| 缺陷 | 致命缺陷的具体表现/代价 | 缺陷必须有代价，详见 10.4.1 |
| 台词 | 口头禅5句/禁忌用语5句/标志台词1句 | 参考第七部分 7.1 |
| 关系 | 男主定位/闺蜜/对手/反派 | 每个关系对象写清"她对他什么态度、他对她什么态度" |
| 名场面 | 已排名场面3-5个 | 登场/翻盘/摊牌/告白/诀别五类里选，参考第七部分 7.3 |

### 10.1.2 样例卡一：权谋大女主（萧明瑟）

| 字段 | 内容 |
|---|---|
| 一句话定位 | 嫁入敌国的亡国公主，用十年时间把仇人的江山变成自己的 |
| 基础信息 | 萧明瑟，二十三岁，南梁亡国公主，现北狄左王妃，表面温婉，实为北狄朝堂背后的执棋人 |
| 外貌 | 凤眼，眼尾上挑，笑时弯成月牙，不笑时冷得像刀；身段偏瘦，穿素色旗袍，腕上常年一串佛珠；标志特征是说话前会先转一下腕上佛珠 |
| 核心欲望 | 让南梁复国，让当年灭她国的人血债血偿 |
| 核心恐惧 | 再次被人当成棋子抛弃 |
| 致命缺陷 | 不信任何人，所有亲近她的人都被她当成棋子，最后把真心待她的人也推开了 |
| 行事逻辑 | 先算三步再动，动则不留后手；情感是奢侈品，能不用就不用 |
| 反差点 | 对外是心狠手辣的左王妃，私下里会偷偷养一院子南梁带来的栀子花，每年母妃忌日独自在花房待一夜 |
| 表层标签 | 温婉、不争、贤淑 |
| 中层行为 | 对丈夫恭敬，对小妾和善，对朝堂事务从不过问，私下里却通过佛堂往来联络旧部 |
| 底层创伤 | 十三岁那年国破，亲眼看着母妃被敌军从城楼扔下去，她被藏在水缸里，一声不敢出，从那以后她就不信任何承诺 |
| 口头禅 | 佛珠转一圈说一句：王爷说的是。臣妾以为。不急。再等等。 |
| 禁忌用语 | 绝不说"我信你"；绝不当众哭；绝不说"我一个女人家"；绝不求任何人；绝不在仇人面前露出软肋 |
| 标志台词 | 这盘棋我下了十年，今日该收官了 |
| 与男主关系 | 男主是北狄大王，她名义上的丈夫，两人从互相提防到互相试探到最后棋逢对手 |
| 名场面 | 登场：新婚夜掀盖头时她先笑了；翻盘：朝堂上用一份伪造的账本扳倒右相；摊牌：在佛堂向大王坦白身份；诀别：城破时她选择留下守那院子栀子花 |
