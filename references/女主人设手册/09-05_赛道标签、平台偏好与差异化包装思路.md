# 9.5 赛道标签、平台偏好与差异化包装思路

> 素材来源：novel-material-skill ·《女主人设手册》9.5 赛道标签、平台偏好与差异化包装思路

同一个女主，在不同平台、不同赛道，包装方式完全不同。本节拆三件事：各平台的女主差异、男女频对照表、七条差异化包装思路，最后给一张标签词表。

### 9.5.1 各平台女主差异
- 番茄女频：爽感优先，节奏快，女主开局就要有爽点。标签偏好：清醒、打脸、逆袭、团宠。
- 晋江女频：细腻优先，人物深，女主要有复杂的内心世界。标签偏好：权谋、虐恋、追妻、氛围感。
- 起点女频：事业优先，女主搞事业为主，感情为辅。标签偏好：大女主、经商、种田、基建。
- 小红书图文：情绪优先，女主要有让人截图的金句和名场面。标签偏好：钓系、明艳、清醒、人设感。
- 抖音短剧：节奏极致快，三秒一个钩子，女主一出场就要有冲突。标签偏好：重生、复仇、打脸、闪婚。

平台差异的本质是读者群的差异。番茄的读者是碎片时间多的打工人，要的是快速爽；晋江的读者是有耐心的深度读者，要的是人物深度；起点的读者是事业型读者，要的是搞事业的过程；小红书的读者是年轻女性，要的是情绪共鸣和人设感；抖音的读者是刷视频的人，三秒不留就划走。同一本书，在不同平台要改的不是内容，是节奏和包装。

跨平台发行时，记住一个原则：核心人设不变，节奏和文案变。女主的五要素、三层结构、核心行为逻辑，在哪个平台都一样；变的是开篇的节奏（番茄要更快，晋江可以慢一点）、文案的语气（小红书要更网感，起点要更务实）、标签的选择（抖音要最炸的标签，晋江要最有质感的标签）。

### 9.5.2 男女频对照表

| 维度 | 女频女主 | 男频男主 |
|---|---|---|
| 核心诉求 | 被偏爱但不依附 | 征服与升级 |
| 爽感来源 | 打脸 + 翻盘 | 打怪 + 升级 |
| 感情线 | 她被偏爱，她有自己的世界 | 他征服女人，女人是战利品 |
| 底线 | 她不能失去自我 | 他不能失去主动权 |
| 读者投射 | 我想成为她 | 我想成为他 |
| 常见标签 | 清醒、钓系、大女主、软刺 | 杀伐果断、腹黑、妖孽、高冷 |

### 9.5.3 七条差异化包装思路
- 思路一：把标签翻译成读者能懂的话。"钓系"翻译成"她撩他的方式，读者都想学"，"大女主"翻译成"她不靠男人，她靠自己"。
- 思路二：把人设放进一个具体的场景里。不要说"她是大女主"，要说"她在朝堂上一个人怼了三十个大臣"。
- 思路三：给她一句让人截图的金句。金句是传播的核心，一句好的金句比十段描写都管用。
- 思路四：给她一个让人记住的动作。她在谈判时会转笔、她在紧张时会揉无名指、她在撒谎时会笑。动作是人设的记忆点。
- 思路五：给她一个反差。她对外杀伐果断，回家喂猫；她在外面八面玲珑，回家怕黑。反差让人上头。
- 思路六：给她一个"她和别的女主不一样"的点。别的女主都被男主救，她救男主；别的女主都哭，她不哭。
- 思路七：给她一个让人想追的悬念。她到底是谁？她为什么会这样？她最后会选谁？悬念是追读的动力。

七条思路的使用纪律：不要七条全用。选三条做到极深，比七条都浅尝辄止管用。多数爆款女主的包装公式是：一个具体场景 + 一句金句 + 一个反差。这三样有了，读者就记住她了。剩下的四条，是锦上添花，不是必需。

### 9.5.4 标签词表

| 人设类型 | 核心标签词 | 传播金句方向 |
|---|---|---|
| 大女主 | 杀伐果断、搞事业、不靠男人、女帝、权谋 | 我自己的路，我自己走 |
| 清醒果断 | 清醒、止损、算账、不恋爱脑、人间清醒 | 爱情算什么，我的账才算 |
| 钓系 | 撩、钓、明艳、风情、欲擒故纵 | 我钓的不是你，是我的心 |
| 软刺 | 外柔内刚、嘴硬心软、温柔有底线 | 我可以对你好，但你不能碰我的底线 |
| 倔强隐忍 | 咬牙、硬撑、不低头、爆发式反击 | 我不哭，不是我不疼，是我不能输 |
| 清冷疏离 | 不食人间烟火、边界感、偶尔泄露在意 | 我不是冷，我只是没遇到值得我热的人 |
| 明艳张扬 | 肆意、锋芒、敢爱敢恨、全场焦点 | 我活着，就是要让所有人都看见我 |

标签词表的使用方法：写文案的时候，从表里挑三个核心标签，再配一句金句。比如写权谋大女主的文案："杀伐果断的罪臣之女，带着全家的冤屈回京，这一次，她要把当年踩过她的人，一个一个拉下来。我自己的路，我自己走。"三个标签（杀伐果断、罪臣之女、拉人下马）加一句金句，读者一眼就知道这本书在讲什么。

标签的进阶用法是"标签组合"。单一标签读者看腻了，标签组合才有新鲜感。比如"清醒 + 钓系"：她撩他，但她每一步都在算；"大女主 + 软刺"：她杀伐果断，但她回家会喂猫；"清冷 + 腹黑"：她看起来冷，其实她什么都知道。标签组合的写法，详见第二部分 2.9。

最后补一句：本部分讲的所有读者心理、追读设计、标签包装，最终都要回到第一部分 1.4 的四条底层诉求上。读者要的不是标签，是情绪；不是人设，是"如果我是她"。写女主的终极目标，是让读者合上这本书的时候，觉得"我也想成为这样的女人"。

### 9.5.5 差异化包装的常见错误
- 错误一：标签堆砌。一本书打了二十个标签，读者不知道她到底是谁。标签要少而精，三个核心标签就够。
- 错误二：包装和内容不符。文案写"钓系明艳"，正文写的是个清冷姑娘，读者被骗进来，三章就弃。
- 错误三：照搬别人的标签。别人的"大女主"已经被写烂了，你再写一个一样的，读者记不住。要在标签基础上加一个你自己的东西。
- 错误四：只包装开篇，不包装中段。开篇三章很精彩，中段写崩了，读者照样弃。包装要贯穿全书。
- 错误五：为了标签牺牲人设。为了蹭"钓系"的热度，把本来清冷的姑娘硬写成钓系，人设就崩了。包装要为人设服务，不是人设为包装服务。

### 9.5.6 一张图看懂追读设计

把本部分所有内容浓缩成一张追读设计图：地基是代入感（她像活人），主菜是爽感和被偏爱（她赢、她被偏爱着却谁也不靠），回甘是清醒翻盘（她靠自己站起来），调味是虐和心疼（让她苦一下，再甜一下），节奏是小循环三到五章、大循环十五到二十章，包装是三个核心标签加一句金句加一个反差。这张图记住了，写女主的时候就不会跑偏。

这张图和第一部分 1.4 的四条底层诉求、第五部分的关系写法、第七部分的名场面、第十部分的人设卡，是一套完整的工具链。第一部分给她的骨架，第二部分给她的类型，第五部分给她的关系动作，第七部分给她的台词，第九部分给她的读者情绪，第十部分给她的落地模板。写完一个女主，把这几部分翻出来对一遍，基本不会出大错。

如果你是第一次用这套工具，建议你先写一张人设卡（第十部分 10.1），再按本部分的节奏表排前三十章的情绪，再按第五部分的桥段库排关系进展。三步走完，你的书就有了骨架、有了节奏、有了情绪，剩下的就是把文字写好。不要急着开写，先把架子搭好，写起来才不卡，写嗨了也不会跑偏。

最后一句话：读者追女频，追的不是女主有多强，是她在强的过程里，让读者看到了自己想成为的那个样子。写女主的终极目的，是给读者一个"我也可以这样"的念想。这个念想给足了，读者会跟你走完全书。这个念想给不足，读者三章就划走。技巧可以学，结构可以练，但这个念想，要你真心相信你写的这个女主值得被喜欢，读者才会跟着你信。
