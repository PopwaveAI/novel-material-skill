# 14.3 句式调整模板

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》14.3 句式调整模板

### 14.3.1 停顿与节奏类模板

句子写顺了，读着才不磕。这一节给你三十二条现成句式模板。每条三列：句型、适用场景、示例句。你写对话、写心理、写转场的时候，从表里挑一条套进去就行。

句式模板不是让你抄句子，是让你学一种收尾的思路。你看多了「人物不说话就做小事」这种套路，自己写的时候自然就会用。模板是拐杖，走稳了就扔。

这一组模板管的是节奏。你写一段紧张戏，用短句子；写一段抒情，用长句子。模板给你的是节奏的骨架。

|---|---|---|

### 14.3.2 揭示与留白类模板

这一组模板管的是留白。你不把话说完，读者自己会补。补出来的东西比你写出来的更有力。

表 14-9 揭示与留白句式模板

| 句型 | 适用场景 | 示例 |
|---|---|---|
| 雨下了一整夜。第二天早上，院子里的槐树落了一地花。 | 时间流逝加意象 | 古言 |
| 他没回头。再回头，怕自己就走不动了。 | 心理克制 | 现言 |
| 那只猫蹲在墙头上，看了他一会儿，跳走了。 | 旁观者视角 | 现言 |
| 信封上没有署名，只写了一个字。 | 悬念 | 悬疑 |
| 她数着他的脚步声，一步，两步，三步，直到听不见。 | 离别 | 古言 |
| 锅里的水开了，咕嘟咕嘟响。她忘了关火。 | 出神 | 现言 |
| 这句话她在心里说了一百遍，真说出口，连自己都不信。 | 内心外化 | 通用 |
| 账本上那一页，她用红笔圈了三次。 | 标记重点 | 古言 |
| 他把帽子压低了一点，走进人堆里。 | 隐藏身份 | 现言 |
| 月亮从云后面出来，照见地上那摊水。 | 环境揭示 | 悬疑 |
| 她没哭。哭是要给人看的。 | 心理旁白 | 古言 |
| 门被推开的时候，他正在系最后一颗扣子。 | 时间点 | 现言 |
| 这件事，他连她都没说。 | 留白 | 通用 |
| 药很苦。她一口喝干，没皱眉。 | 隐忍 | 古言 |
| 远处传来鸡叫。天快亮了。 | 时间标记 | 古言 |
| 他把那个名字写在纸上，看了很久，烧了。 | 决绝 | 现言 |
| 她的手在袖口里抖，脸上还在笑。 | 表里不一 | 古言 |
| 那碗药她喝了三天，第四天没再喝。 | 时间写放弃 | 古言 |
| 他把伞递给她，自己站在雨里。 | 动作写深情 | 现言 |
| 信写到一半，笔没墨了。 | 物件写中断 | 古言 |
| 她数了数抽屉里的钱，又数了一遍。 | 动作写窘迫 | 现言 |

这两组模板有个共同的内核：不写情绪，写情绪的壳。你写一个人难受，模板不让你写「难受」，让你写他数钱数了两遍、写他把伞递给别人自己淋雨。情绪是读者从这些动作里自己长出来的。

模板用熟了之后，你会发现自己不需要再背新模板。你会根据眼前的人物和场景，现场造一个。这时候工具就变成了直觉。

### 14.3.3 模板怎么用

这三十二条不要全背。你只需要做一件事：把它们打印出来，写稿时遇到「这里该怎么收尾」的卡点，翻一张，挑一条接近的套进去。

模板用熟了，你会发现自己不需要再背新模板。你会根据眼前的人物和场景，现场造一个。这时候工具就变成了直觉。

套模板最容易犯的错是原封不动抄。你把模板里的物件换成自己场景里的物件，模板才活。原封不动抄，读者一眼就看出你在套。

套的时候要改字。模板是骨架，不是咒语。你把模板里的「茶盖」换成「杯盖」，把「灯焰」换成「手机屏幕」，它就活了。原封不动抄，读者一眼就看出你在套模板。

同一个模板不要在三万字内用两次。你写了「她没说话，只把茶盖刮了两圈」，下次再用「他没说话，只把烟头摁灭了」，读者就会觉得你江郎才尽。

模板最大的用处不是套句子，是教你一种收尾的思路。你看多了「茶盖刮两圈」这种写法，就会明白：人物不说话的时候，让他手里做点小事，情绪就出来了。这个思路你内化之后，自己就能写出「她把桌布角折了又折」这种新句子，不用再翻表。

原句：他没有回答。她很着急。

模板套用：他没回答，只把袖口的扣子解开，又扣上。她盯着那只手，半天没催。

对比一下：原句十个字，全是标签。套模板之后，动作把「不回答」的张力写出来了，「她很着急」也不用写，读者从「盯着那只手」就看出来了。

「使用节奏」：写稿卡壳时翻一次，一次只用一条。用完就在旁边画个勾，下次换一条。
