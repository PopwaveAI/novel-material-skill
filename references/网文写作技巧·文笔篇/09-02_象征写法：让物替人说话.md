# 9.2 象征写法：让物替人说话

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》9.2 象征写法：让物替人说话

### 9.2.1 象征对照表（18 组）

象征是让一个物件承载比它本身更多的意思。伞不是伞，是「我替你挡」。窗台上的花不是花，是「我还在等」。象征不用解释，读者看到物件出现，就会想起人物。

看一组「物件 → 象征」的对照，同一个物件在不同语境里怎么变成象征。

伞第一次出现：下雨了，他把伞倾向她，自己肩膀湿了。这时候伞只是伞。
伞第二次出现：她一个人撑着伞走在当年那条路上。这时候伞是「他不在了」。
伞第三次出现：他在旧物箱里翻出那把伞，伞骨歪了一根。这时候伞是「回不去了」。

同一把伞，三次出现，意义一层比一层深。作者一个字都没解释「伞象征什么」。读者自己会算。

「象征的三次法」：第一次物件本身，第二次带情绪，第三次带命运。三次就够。

下面给 18 组「物到人」的象征对照。写的时候直接用。

表 9-2 物人象征对照（18 组）

| 物件 | 象征的人或情绪 | 使用场景示例 |
|---|---|---|
| 伞 | 庇护、替对方挡 | 他把伞倾向她，自己肩膀湿了 |
| 窗台上的花 | 等待、守着 | 她每天浇花，花还活着，他还没回 |

| 桂花糕 | 母亲、旧家 | 他在异乡吃到桂花糕，停了筷 |
| 碎了的杯子 | 破镜、回不去 | 杯子碎了，他没有扫 |

| 铜镜 | 自我审视 | 她对着铜镜，没认出来自己 |
| 落叶 | 凋零、告别 | 叶子落了一地，他没有扫 |

另外还有三组象征对照，凑成二十一组。
- 旧手表：时间停了、回不去。他把表摘了，表针还在走。
- 门：距离、隔阂。她站在门里，他站在门外。门没有关。
- 一碗热汤：牵挂、被等。她把汤热了三遍，他没有回来。

这些物件都来自日常。日常物件读者有共鸣。

象征的关键是不解释。不要写「这盏灯象征着他对家的渴望」。这种句子一出来，象征就死了。让物件出现两次，读者自己会懂。解释是作者不自信。

一章里象征物件不要超过两个。两个以上，读者会觉得你在显摆。一个主象征，一个次象征，够了。主象征贯穿全书，次象征用在关键场景。

### 9.2.2 象征的本土化

象征要本土化。不要用西方那套玫瑰、十字架。中国读者的象征是桂花、油纸伞、旧邮筒、胡同口的槐树。用本土物件，读者一眼就懂。

举几个本土化的象征。胡同口的槐树代表「家」，旧邮筒代表「远方的信」，灶上的砂锅代表「母亲在等」。这些物件中国读者有共鸣。

沈聿站在胡同口。那棵老槐树还在。他小时候在树下吃过一碗冰棍。他抬头，树影晃在他脸上。

同一个象征不要用太多次。伞用三次就够。第一次是庇护，第二次是告别，第三次是回忆。用多了读者会腻。象征是味精，一点就鲜，多了就苦。

不同章节要用不同象征。这一章用伞，下一章用灯，再下一章用桂花糕。交替着来，读者不会觉得你在重复。

象征要贴人物。江湖人用剑、用酒。闺秀用玉梳、用帕子。上班族用咖啡杯、用旧钢笔。不要给闺秀配一把剑，也不要给江湖人配一把玉梳。

沈聿是现言人物，他的象征是旧咖啡杯、地铁卡、手机里没拨出去的号码。这些物件贴他的身份。卫照是古言人物，他的象征是玉梳、旧伞、一盏灯。

### 9.2.3 象征的高级用法

最高级的象征，是物件本身没有意义，但因为反复出现，读者给了它意义。伞第一次出现只是遮雨。第二次出现是他给她撑。第三次出现是她一个人撑着。伞还是伞，但读者知道它代表两个人。

这种「无意义物件被读者赋予意义」的写法，比直接象征高级。直接象征是作者说「这伞代表爱」。高级象征是作者不说，读者自己说。

「象征的最高境界」：作者不解释。物件出现三次。读者自己把意义填上。填上的那个意义，比作者说的重十倍。

象征要和全书主题扣合。书写「等待」，所有象征都要往等待上靠。窗台上的花在等，灶上的砂锅在等，胡同口的槐树在等。象征要成系统，不要东一个西一个。

如果你的象征东一个西一个，读者会觉得乱。要围绕一个主题词，挑三到五个物件。这三五个物件一起替主题说话。

「象征系统」：围绕一个主题词，挑三到五个物件。每个物件出现两到三次。物件之间要互相呼应。
