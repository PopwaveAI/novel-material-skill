# 7.7 防止大段内心 OS 注水

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》7.7 防止大段内心 OS 注水

### 7.7.1 注水 OS 的三个判定

内心 OS 注水，是网文中最常见的毛病。一个段落写三百字心理，动作和对话一个都没有。三个判定标准。第一，这段心理能不能删，删了剧情有没有损失。如果删了剧情照走，这段就是水。第二，这段心理有没有给出新信息。如果只是把读者已经知道的情绪再描述一遍，就是水。第三，这段心理有没有具体物件或动作。如果全是抽象词，就是水。

表 7-5 注水 OS 判定表

| 判定问题 | 水的样子 | 该删的程度 |
|---|---|---|
| 删了会怎样 | 删了剧情照走 | 整段删 |
| 有没有新信息 | 只是把已知情绪再说一遍 | 删到剩一句 |
| 有没有具体物 | 全是形容词和抽象名词 | 改成动作或对话 |

判断的时候，把这段 OS 用一张纸盖住。如果故事还能往下走，人物还在动，那就说明这段 OS 是多余的。很多时候盖住之后，你会发现自己都松一口气。

### 7.7.2 三种删法

第一种是整段删。整段心理删了，剧情照走，那就删。很多时候删完读者反而更爽。第二种是浓缩成一句。三百字心理压缩成一句行动指令，比如「她决定明天就去找他」。第三种是改写成动作。把心理变成她做了一件事，比如她把那封信撕了。

注水版：温梨坐在床上想了很多。她想起三年前他在雨里给她递伞，想起去年他生日她忘了买礼物，想起他最近三个月总是加班。她觉得这段感情大概是真的完了，又觉得不甘心。她想了很久。

改写版：温梨把手机里他的聊天记录往上翻，翻到三年前那一句「到家说一声」。她按了截图，又删掉。她把手机扣在床头。

原版一百二十字心理，改写版八十字动作。信息量一样，但后者读者能看见画面。心理一旦能改成动作，就改。

看三种常见的删法案例。

注水版：温梨想起三年前那个雨夜，他把伞倾向她，自己半边肩膀湿了。她想起去年冬天他给她买的那条围巾。她想起他最近总是加班。她觉得这段感情大概完了。
改写版：温梨拉开抽屉，那条围巾还叠在角落。她拿起来，闻了闻。没味道了。

注水版：萧令仪心里又想起母亲，想起族里的议论，想起初三要来吃酒的那三家。她觉得这些事像石头一样压在她心上。
改写版：萧令仪把帖子拿出来，一张张看过。她把初三那一张抽出来，放在最上面。

注水版：应无咎想起阿箬，想起她递茶的样子，想起她喊他师兄。他心里一阵绞痛。
改写版：应无咎端起茶。他停了一下。他把茶放到另一边，那是阿箬以前常坐的位置。

三个改写版都把回忆变成了当下的动作。抽屉里的围巾、抽出来的帖子、放错位置的茶。读者看见动作，就明白了他在想什么。

### 7.7.3 替代方案：把 OS 拆成动作与对话

真要写心理，也不要在一段里写完。拆成三块。一块给动作，一块给对话，一块给一句最短的内心。三块交替，读者读起来就不闷。比如她不是坐着想三百字，她是先撕了一张纸，然后给朋友发了一句「我可能要分手」，最后才在心里说一句「这次是真的」。

「OS 拆三法」：动作一句，对话一句，内心一句。三句一组，比一段三百字 OS 更有劲。写内心 OS 之前，先问自己能不能拆。

拆的时候注意，对话要给真实的人说。不要给朋友发一段长文，发一句短的就够。朋友回什么也别写，留白。这样比两个人微信聊五百字要省字，也更像真实生活。

她给闺蜜发：「我可能要分。」闺蜜回了一个问号。她把手机放下。她想，这次是真的。

不是所有 OS 都要删。有一种 OS 是有信息的。比如人物在心里推算了一步棋，或者他在心里给下一个决定列了三个理由。这种 OS 要留，但要短，三行以内。

判断方法：把这段 OS 念给一个没看过书的人听。他听完能不能说出人物接下来要做什么。能，就有信息。不能，就是情绪废话。
- OS 字数红线：单章 OS 总字数不超过本章总字数的一成。超过就开始删。

拿到一段 OS，先把所有「她想起」「他记得」「她想到」划掉。划完之后，看剩下还有没有内容。如果剩下的只是情绪形容词，这段 OS 就该整段删。

如果剩下还有具体的事，比如她想起三年前那把伞，就把这件事改成动作：她打开抽屉，那把伞还在。这样 OS 就变成了场景。
