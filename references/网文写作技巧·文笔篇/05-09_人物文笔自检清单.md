# 5.9 人物文笔自检清单

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》5.9 人物文笔自检清单

### 5.9.1 群像与出场自检
- 这个人物出场，有没有一句是模板套话？有就删。
- 他身上有没有一个只属于他的记号？没有就加一个。
- 外貌信息是不是分三次投放的？一次倒完了就拆。
- 这段情绪，有没有直接写“他很紧张”？有就换成微表情。
- 他的动作有没有目的和阻力？没目的就加。
- 他身上有没有两三个招牌小动作反复出现？没有就定两个。
- 一场戏超过三个人，有没有一次只给一个人一个特征？
- 新人物出场，是不是先给了声音、物件或者议论，再给脸？
- 人物动作符不符合他的身份和性格？

这二十条，写完一章对一遍。对不上的地方，就是你人物塌下去的地方。人物这件事，说到底是耐心活：你愿意给他多少个只属于他的小细节，他就愿意在读者心里站多久。

### 5.9.2 拿自己的稿子练一遍

光看不练没用。挑你最近写的一章，把里面出现的人物挨个过一遍。
- 第一个人：他身上有一个只属于他的记号吗？没有就加。
- 第二个人：他说“我没事”的时候，手上在干什么？没动作就加一个。
- 第三个人：他的动作符合他的身份吗？一个婆子做了小姐的动作，就改。
- 第四个人：他身上有没有两三个小动作反复出现？没有就定两个。
- 第五个人：他的外貌信息是一次倒完的吗？是就拆成三次。

这么过一遍，比你写五千字新的都管用。人物是磨出来的，不是想出来的。你给他加的每一个小细节，最后都会变成他站在读者心里的那条腿。

最后提醒一句：人物写多了，容易写成自己。十个主角有八个是你自己的影子。写完一个人物，把他的名字盖住，问自己一句：他做的这件事，换我我会这么做吗？如果答案是“会”，你就得给他改一个不一样的反应。人物要跟你像，但不能全是你。全是你，就假了。
