# 10.8 风格统一训练：定调、抽样、回校

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》10.8 风格统一训练：定调、抽样、回校

### 10.8.1 定调：开书前先钉死六参数

很多作者开书前三章是一个调子，写到二十章就变了。读者不是非要你写得多好，是怕你忽冷忽热。本册给你一套能跑起来的流程：定调、抽样、回校。

开书之前，先花半小时，把你这本书的六参数写在一张纸上。
- 第一步，写下你这本书的主文风，比如古言权谋，主调就是厚重权谋。
- 第二步，写下六个参数的目标值，比如平均句长 30 字，感叹号一章不超过 5 个，核心意象是「奏折、镇纸、帘、烛台」。
- 第三步，写一段 200 字的定调示范，用你这本书的主角写。这段示范就是你这本书的「基准音」。

定调示范写完之后，存下来，后面每次回校都拿它当对照。没有这个基准音，你后面所有的判断都是凭感觉。

定调示范不要抄别人的句子。用你自己的主角，写一个你这本书里一定会出现的场景。比如你的书是古言权谋，你就写一段主角在书房批奏折的场景；你的书是甜宠，你就写一段主角在厨房里偷吃的场景。

写得越久，手越容易飘。你得定期回头抽。
- 前 10 章：每写完一章，抽这一章的第 3 段、第 7 段、最后一段，共 3 段，对照定调示范。
- 11 到 50 章：每 5 章抽一次，每次抽 5 段，分别取自一章的开头、中段、章末。
- 51 章以后：每 10 章抽一次，每次抽 3 段。

抽样不要挑你觉得写得好的段，要随机抽。挑好段回校，等于没回校。

抽出来的段落不要当场改。先攒着，等攒够三章的量，回头集中改一次。日常写的时候，笔感比修改更重要。

抽样的位置要固定。不要每次都抽你觉得写得好的那段，要按章节顺序抽。比如第 3 章抽第 3 段、第 7 段、最后一段，第 8 章也抽同样位置。这样你才能看出自己是真的在进步，还是在挑好看的段自欺欺人。

### 10.8.2 回校：比对项与纠偏动作

抽出来的段落，跟定调示范比这四样。
- 比句长：抽 3 句算平均字数。偏差超过目标值 30%，这一段要重写。
- 比用词：把抽段里的动词和名词圈出来。跟定调示范里的动词名词重合率低于一半，说明你换了词汇池。
- 比意象：抽段里的核心物件，是不是你目标参数里那一类。不是，就换成同类。
- 比情绪烈度：写完之后主观打个分。跟目标档位差超过 2 分，这一段要压或抬。

纠偏动作不要一章一章地改。攒够三章都跑飞了，回头集中改一次。日常写的时候，笔感比修改更重要。

比对的时候，不要凭感觉。拿你定调示范里的句子跟你抽出来的句子，逐字对。对不上的地方，一个字一个字改。改完之后，再读一遍，听语感对不对。

「回校口诀」：定调示范贴在边，抽段比对四样，跑飞就重写，别一章一改。

下面这张表是一周七天的抽样回校流程，你照着跑就行。

表 10-5 周抽样回校流程表

| 星期 | 动作 | 抽几段 | 比对项 | 纠偏动作 |
|---|---|---|---|---|
| 周一 | 写完新章，不回校 | 0 | 写之前朗读定调示范一遍 | 无 |
| 周二 | 写完新章，不回校 | 0 | 写之前朗读定调示范一遍 | 无 |
| 周三 | 回校日：抽本周三段 | 3 | 句长、用词、意象、情绪烈度 | 跑飞段标红，攒着 |
| 周四 | 写完新章，不回校 | 0 | 写之前朗读定调示范一遍 | 无 |
| 周五 | 写完新章，不回校 | 0 | 写之前朗读定调示范一遍 | 无 |
| 周六 | 集中改周三标红段 | 3 | 逐句对照定调示范重写 | 改完再读一遍 |
| 周日 | 通读本周全部章节 | 全读 | 看调子是否统一 | 不统一处微调，不大改 |

### 10.8.3 一份定调示范长什么样

拿古言权谋举个例子。定调示范不是空泛的「我要写厚重」，是一段具体的、200 字的、用主角写的场景。

孟勰把那份奏折搁在镇纸旁边，墨迹未干。他抬眼，帘外站着的人已经等了半柱香。他没说话，先端起茶盏，茶水刚换过，温度正好。他吹了吹，没喝，又搁回去。帘外那人终于开口，说王爷问，那笔账何时了。孟勰笑了一下，说快了。他说完，伸手把那份奏折翻过来，扣在案上。帘外的人看见了，退了半步。

这段就是定调示范。以后每写一章，都拿它跟这段比对：句长是不是 28 到 35 字，用词是不是沉准，意象是不是镇纸茶盏奏折，情绪烈度是不是 2 到 3 分。对得上，调子就没跑。

定调示范写完之后，不要改它。它是你的基准音。哪怕你写了一百万字，它还是那 200 字。每次回校都拿它量。

如果你写了两本小说，第二本的定调示范不要抄第一本。每本书都有自己的调子。第一本是古言权谋，第二本可能是现言甜宠，调子完全不同。

定调示范写完之后，存成一个单独的文件，每次开写之前先读一遍。

这是本册给你的最重要的一个动作。

没有这个动作，前面所有参数都是空的。

记住这一条。

它会救你十万字。
