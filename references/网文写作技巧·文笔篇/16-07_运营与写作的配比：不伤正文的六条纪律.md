# 16.7 运营与写作的配比：不伤正文的六条纪律

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》16.7 运营与写作的配比：不伤正文的六条纪律

### 16.7.1 每周投入配比

运营做太多，正文就废了。运营做太少，书没人看。中间那条线，要靠纪律来守。本册这一节给六条纪律，每条都具体到每周投入多少小时。

一周按七小时算。写正文占五小时，运营占两小时。两小时拆到六天里，每天二十分钟。这是上限。超过这个配比，正文就会被挤。

表 16-8 每周时间分配表

| 动作 | 每周时长 | 固定时段 |
|---|---|---|
| 正文写作 | 五小时 | 每天早上九点到十点，雷打不动 |
| 评论回复 | 一小时 | 周二、周五晚上八点到九点 |
| 短视频文案 | 一小时 | 周三下午，写一条存一条 |
| 周复盘 | 半小时 | 周日晚上 |
| 休息 | 不计入 | 每周一天不碰键盘 |

这个配比不是死的。新书上架第一个月，可以把运营加到三小时，正文压到四小时。上架三个月后，必须回到五比二。过了半年，再慢慢把运营压回一小时。

### 16.7.2 六条纪律
- 纪律一：正文没写完之前，不开任何对外动作。当天的三千字没落地，不发短视频，不回评论，不做简介。
- 纪律二：运营动作固定时段。评论回复只在周二、周五晚上，其他时间看到也不回。不把全天切碎。
- 纪律三：每周只发一条短视频。写一条好的，不充数。充数的短视频不如不发。
- 纪律四：存稿箱保持两章以上。存稿少于两章，停止一切运营动作，先补存稿。
- 纪律五：每周日做一次复盘。看数据只看一件事：本周有没有读完自己这一周写的章节。没读完，下周砍运营。
- 纪律六：每月停笔一天。这一天不写、不发、不看评论。脑子空一天，下一个月的句子才接得上。

六条纪律看起来简单，难在长期执行。运营的诱惑是无穷的，今天想发一条，明天想多回一句。守住配比，正文才守得住。

最后再提醒一句。运营是放大器，不是发动机。正文是发动机，运营只是把正文里的东西递到读者眼前。发动机不行，放大器再大也没用。本册这一节讲的所有动作，前提都是：你的正文已经立住了。

「本册收尾」：写到这里，运营这一节就收了。记住一句话：运营是把正文里已经有的东西递到读者眼前，不是在正文之外再造一个故事。正文立住了，运营只是顺手。

六条纪律光靠脑子记不住，得贴在桌前。本册给一张执行表，每周打勾。

| 纪律 | 本周是否完成 | 备注 |
|---|---|---|
| 正文日更三千字 | □ |  |
| 存稿箱两章以上 | □ |  |
| 短视频只发一条 | □ |  |

连续四周都能打勾，纪律就立住了。连续两周打不齐，说明配比被运营挤了，下周砍运营动作。

最后一句话。作者的本分是写好正文。运营是给正文搭一座桥，让读者走过来。桥修得再漂亮，对岸没有东西，读者走一趟就不再来了。本册讲的所有动作，都是为了让对岸的那本书，值得读者走这一趟。

### 16.7.3 运营数据的看法

作者都会看数据。订阅数、追读数、评论数。看数据是为了判断正文哪里出了问题，不是为了焦虑。

数据掉了，先看最近三章的正文。不要先怪运营没做好。九成情况，是正文出了问题。

数据涨了，也不要加更。加更会打乱节奏，反而掉。稳住日更，让数据自己跑。

表 16-13 数据与正文的对应关系

| 数据信号 | 正文可能的问题 |
|---|---|
| 追读掉了 | 最近三章节奏拖了，或者钩子没了 |
| 评论少了 | 最近没有值得讨论的点 |
| 收藏涨了但追读没涨 | 简介写得好，第一章没接住 |
| 评论里抱怨文笔 | 最近几章形容词多了，句子长了 |

数据是镜子，不是鞭子。照一照，改改正文，不要盯着它焦虑。焦虑写不出好句子。

本册这一部分讲了卖点、埋点、文案、讨论点、简介、互动、纪律七件事。七件事串起来，其实就是一句话：把正文里已经有的好东西，稳稳地递到读者眼前。不要多，不要少，不要急。

很多作者把运营想复杂了，觉得要学很多新东西。其实不用。运营的全部功夫，都在正文里。你正文里写得越好，运营越轻松。你正文里没有的东西，运营再怎么包装也包不出来。

所以本册这一部分的最后一句话是：先把正文写好。写好之后，运营只是顺手。写不好，运营就是给自己挖坑。

把这七件事记在心里，每天写正文的时候顺手做一点。不要专门抽一天来做运营，那样太累。顺手做，做半年，你会发现书自己就长出来了。

运营这件事，说到底是关于耐心。读者不会一天就爱上你的书。他要读十章，读五十章，读一百章，才会成为你的老读者。你能做的，就是每天把正文写好，每天让他多留一章。

急不得。一急，就会想发短视频，想回评论，想做简介。这些事都做了，正文就没了。

本册这一部分的纪律，本质上就是在帮你把“急”按下去。按下去之后，你才有时间写正文。正文写好了，读者自然来。

本册这一部分到这里就结束了。回头看看，卖点、埋点、文案、讨论点、简介、互动、纪律，七件事其实都指向同一个动作：回到正文里去。正文是根，运营是枝叶。根扎深了，枝叶自然长。根没扎深，枝叶再茂盛也是假的。

愿你写完这本书的时候，回头看，发现自己写出了一本书，也留住了一群愿意陪你读完的人。

这本书的运营，说到底是一件小事：把正文里的好东西，一个一个递到读者眼前。不急，不贪，不急。

本册这一部分到这里就结束了。下一本书，见。

最后一句话。运营的全部秘密，就是正文好。正文好了，运营是顺手。正文不好，运营是白忙。

去写正文吧。

正文好了，一切都好。正文不好，一切都白搭。

这本书的运营，没有捷径可走。每天写三千字，每周发一条文案，每周回两次评论。就这些。做满一年，你会看到变化。

做不满一年，一切免谈。运营是复利，前面三个月看不到效果。第四个月开始，读者会自己找上门。

那时候你会发现，你做的那些事，每天写三千字，每周发一条文案，每周回两次评论，都没有白费。它们都长成了读者追更的理由。
