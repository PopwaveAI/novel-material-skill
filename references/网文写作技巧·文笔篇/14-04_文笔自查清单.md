# 14.4 文笔自查清单

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》14.4 文笔自查清单

### 14.4.1 字词与句子组

改稿最愁的是不知道查什么。这一节给你六十项检查，分成五组：字词、句子、段落、人物、环境。每章写完对着过一遍，每项三秒，五分钟过完一章。

每项三列：检查项、判定标准、不合格动作。判定标准写得很硬，是或否，没有中间态。你答否，就按不合格动作那一列改。

这六十项是本册前面十三部分所有技法的浓缩版。你前面学过的每一条原则，在这里都变成了一个可勾选的检查项。改稿的时候不用回忆技法，对着表勾就行。

这一组三十项是基本功。你写每一句话都要过这三十项。练熟了，写出来的句子自然顺。

表 14-10 字词与句子自查清单

| 检查项 | 判定标准 | 不合格动作 |
|---|---|---|
| 一段内同一个动词出现超过3次 | 数一遍该动词 | 换同义动词或改写句子 |
| 连续三个形容词修饰同一个名词 | 数形容词数量 | 留一个最准的，其余删掉 |
| 副词非常、很、十分连用 | 搜索这三个字 | 删一个，或换成具体动作 |
| 成语一段内连用两个以上 | 数成语数量 | 拆成白描，留一个 |
| 现代词出现在古言稿 | 逐句过一遍 | 换成时代对应的词 |
| 量词用错 | 逐个量词核对 | 改成符合习惯的搭配 |
| 同义词在同段重复 | 搜索该词 | 换一个语义刻度不同的词 |
| 生僻词堆砌 | 查自己认不认识 | 换成常用词 |
| 拟声词一段超过一个 | 数拟声词 | 删到最多一个 |
| 颜色词堆砌 | 数颜色词 | 留一个焦点色 |
| 口语词和书面语混杂不分场景 | 大声读一遍 | 按场景统一语体 |
| 代词指代不清 | 找他和她 | 补回人名 |
| 数字写法不统一 | 数写法 | 统一用半角阿拉伯数字 |
| 称谓前后不一致 | 核对人物关系 | 按身份统一称呼 |
| 一段全用句号没有起伏 | 数句末标点 | 按情绪加问号或省略号 |
| 连续三句超过30字 | 数每句字数 | 拆一句成两句 |
| 连续三句少于8字 | 数短句 | 合并或补一句长句 |
| 一句话里两个以上主语 | 找主语 | 拆成两句 |
| 从句套从句读不下来 | 找最长句 | 拆成短句 |
| 段首连续三段用同一个词 | 看段首词 | 换一个开头 |
| 句子之间硬接没有衔接 | 读接缝 | 补一个时间或动作衔接 |
| 被动句连续超过两句 | 数被字句 | 改成主动句 |
| 长句中间套插入语 | 找插入语 | 挪到句末或删掉 |
| 对话后面没有动作或神态 | 找纯对话行 | 加半句动作或神态 |
| 叙述视角一段内跳两次 | 核对谁在看 | 固定一个视角 |
| 时间线在段内倒叙又插叙 | 理时间 | 按顺序重排 |
| 因果关系写反 | 找因为所以 | 理顺逻辑 |
| 句末都是同一个语气 | 数句末字 | 换节奏 |
| 排比句超过三句 | 数排比 | 留两句 |
| 反问句连用 | 数反问 | 留一句 |

字词句子这三十项，是改稿第一遍要过的。这三十项全是硬指标，数得出来，没有模糊地带。你拿一支笔，对着一章过一遍，不合格就画圈。画完圈再改。

这三十项里，最容易出问题的是「连续三句超过三十字」和「主语乱换」。前者让读者读着累，后者让读者要回头重看。这两项你每周都练，写稿时自然就避开了。

### 14.4.2 段落人物环境组

这一组三十项是中级检查。你过了字词句子那三十项，再过这三十项。这三十项管的是段落、人物、环境三个维度。

表 14-11 段落人物环境自查清单

| 检查项 | 判定标准 | 不合格动作 |
|---|---|---|
| 一段超过400字没分段 | 数字数 | 在节奏点断开 |
| 一段只有一句话 | 数段长 | 并入相邻段或补一句 |
| 对话段连续五行无叙述 | 数对话行 | 插一句动作或神态 |
| 环境描写连续超过100字 | 数字数 | 切进人物动作 |
| 心理独白连续超过150字 | 数字数 | 切成动作或对话 |
| 段末没有钩子 | 读最后一句 | 加一个反常细节 |
| 段首和上段末重复用词 | 找重复 | 换词 |
| 段内情绪一直平没有变化 | 读一遍 | 加一个转折 |
| 段内信息密度太低全是废话 | 找形容词堆 | 删掉废话 |
| 段内信息密度太高塞三件事 | 数事件 | 拆成两段 |
| 人物出场没有一个具体特征 | 找出场段 | 补一个物件或动作 |
| 所有人物对话一个口吻 | 抽三段对白 | 按身份改语气 |
| 人物情绪全靠标签词 | 找很开心很难过 | 换成动作 |
| 人物小动作不固定 | 找标志动作 | 贯穿出现三次以上 |
| 人物外貌一次性写完 | 找出场段 | 分散到三章 |
| 人物内心戏和动作不一致 | 找内心独白 | 改成一致，或故意错位 |
| 人物称呼随作者心情变 | 找称呼 | 按身份统一 |
| 人物没有口头禅 | 找对话 | 给一句专属口头禅 |
| 人物生气时反应都一样 | 找生气场景 | 给差异化反应 |
| 人物弱点没在细节里体现 | 找人物弧 | 补一处弱点细节 |
| 每个场景都写天气 | 找天气段 | 删到每章最多一次 |
| 环境描写和情绪不搭 | 找景物 | 换成贴合情绪的景物 |
| 环境描写没有焦点物件 | 找环境段 | 选一个核心意象 |
| 环境描写只写视觉 | 找环境段 | 加一个其他感官 |
| 环境描写和剧情脱节 | 找环境段 | 删掉，或改成影响剧情 |
| 时间用大段交代 | 找时间段 | 用一个物件带过 |
| 地点只写名字 | 找地点 | 给一个感官细节 |
| 四季描写都用成语 | 找四季段 | 换成白描 |
| 夜景都写月亮星星 | 找夜景 | 换一个光源 |
| 雨天都写下雨了 | 找雨天 | 写雨打在什么东西上 |

段落人物环境这三十项，是改稿第二遍要过的。这一遍你要站在读者视角，把这一章当成第一次读。读到哪里磕了，就在那一项后面画圈。

环境那一组最容易被忽略。很多人写环境就是写天气，写完就过。其实环境是故事的一部分。你写一个人在吵架，窗外突然打雷，这场架的气氛就变了。环境不参与剧情，就是废话。

人物那一组最容易串味。你写了十万字之后，男主和男二的口头禅可能不知不觉就混了。第二遍过的时候，把所有对话抽出来，只看对话，不看人名，看能不能分清谁在说话。分不清楚就改。

这六十项不要每章全查。分三遍走。第一遍查字词句子（三十项），第二遍查段落（十项），第三遍查人物环境（二十项）。每遍十分钟。

这六十项查完，一章的文笔问题基本就扫清了。剩下的就是你自己的故事好不好看，那不是文笔能解决的。

查的时候拿一支笔，在不合格的那一项后面画个圈。一章下来，圈最多的那一类就是你当前最大的毛病。连续三章圈在同一类，下周就专门练那一类。

「使用节奏」：每章改稿时过一遍，全书定稿前整体过一遍。圈最多的那项就是你的下一个训练重点。
