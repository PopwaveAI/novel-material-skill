# 2.4 精简冗余：删掉一半字，意思更清楚

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》2.4 精简冗余：删掉一半字，意思更清楚

### 2.4.1 删什么

新手最大的毛病，不是写得少，是写得多。一句话能说清的，非要三句；一个词能说清的，非要三个词。精简不是偷工减料，是把废话挤掉，让意思更突出。

删字的时候，别从开头删，从结尾删。结尾最容易写废话。很多人结尾爱总结，“他心里想着，这一天真是漫长”。这种总结句，全删。

删字的顺序：先删形容词，再删副词，再删重复情绪词。形容词堆最多，先动它。副词紧随其后，程度副词十个有九个能删。重复情绪词最后清。三刀下去，段落瘦一圈。

「删字练习」：写完一段，先删三分之一。删完读一遍，意思没丢就过。十次有八次，删完更好。新手舍不得删，是把字当宝贝；其实读者要的是意思。

删字还有个对象：重复的情绪词。“他很生气，非常愤怒，十分恼火”，三个词说一件事。留一个动作，其余全删。读者看一个动作，比看三个形容词管用。

先删“的”。一句话里三个“的”，读着就黏。“他慢慢地端起了那杯热腾腾的茶”，删成“他端起茶，抿了一口”，意思没变，干净多了。

再删副词。“非常、十分、很、极其”，这些十个有九个能删。“他非常愤怒”改成“他沉了脸”，愤怒自己就出来了。

她非常非常伤心，眼泪止不住地掉，心里难过极了，觉得整个世界都抛弃了她。

改：她坐在床边，眼泪一滴一滴砸在被面上。十二个字，伤心够了。原句四十个字，读者还在等画面。

还要删重复的情绪词。“他很生气，非常愤怒，十分恼火，怒不可遏”，四个词说一个意思，留一个动作就够了。情绪词堆多了，读者反而麻木。

### 2.4.2 删的标准

删完读一遍，有个标准：读着喘气，就是删对了；读着憋气，就是删多了。喘气说明句子短了，节奏快了。憋气说明你把该留的删了。

删的时候有个心法：把自己当读者，不当作者。作者心疼自己写的字，读者只关心意思。你站在读者那边，该删就删。读者要的是好看，不是你的辛苦。

删的时候，优先删哪些？先删“的”，再删副词，再删重复的情绪词。这三类是冗余重灾区。删完你会发现句子立刻清爽。

删的时候别心疼。你写了两百字，删到一百五，意思还在，那五十就是废话。新手总觉得删了就少了，其实读者要的是意思，不是字数。一百五十字的好段落，比两百字的水段落值钱。

删的标准很简单：这句话删掉，意思有没有变。没变，就删。变了，就留。别舍不得字，字是最不值钱的，意思才值钱。
- 删完读一遍，看顺不顺。不顺，说明删多了，加回来；顺，说明删对了。

我自己改稿，有个习惯：写完一段，先删三分之一，再读。读着不缺东西，就过；缺了，再加回来。十次有八次，删完更好。新手舍不得删，总觉得删了就少了，其实读者要的是意思，不是字数。

删冗余还有个原则：删完读一遍，意思不丢就过。你删了三分之一，意思还在，那三分之一就是废话。读者要的是意思，不是字数。

删冗余的顺序：先删形容词，再删副词，再删重复情绪词。形容词堆最多，先动它。副词其次。重复情绪词最后清。三刀下去，段落瘦一圈。

### 2.4.3 保留什么

精简不是偷工减料，是让意思更突出。你删掉废话，留下的动作和物件才显眼。读者的眼睛是有限的，你塞太多东西，他什么都看不见。

什么不能删？动作不能删，对话不能删，关键物件不能删。你删的是肉，不是骨。骨是骨架，肉是修饰。骨架留着，肉才好长。

删完还有个检查：读着顺不顺。删完读着别扭，说明删多了，加回来一两个。读着顺，说明删对了。耳朵比眼睛准。

什么不能删？动作不能删，对话不能删，关键物件不能删。你删的是修饰词，不是骨架。骨架留着，肉才好长。

不是所有字都能删。动作不能删，细节不能删，对话不能删。你删的是形容词、副词、重复的情绪词，留下的是动作、物件、声音。

他慢慢地、轻轻地、小心翼翼地推开门，门轴发出一声长长的、刺耳的、令人不安的响声。

改：他推开门，门轴吱呀一声。动作和声音留着，修饰词全删。读者听见吱呀一声，自然知道门轴旧，不用你说。

「精简口诀」：删形容词，删副词，删重复的情绪词；留动作，留物件，留声音。删完读一遍，意思不丢就行。
