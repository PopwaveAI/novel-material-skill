# 5.1 外貌描写的反模板策略

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》5.1 外貌描写的反模板策略

### 5.1.1 外貌模板雷区表

翻开十本网文，八本的女主出场都是“柳叶眉杏核眼樱桃小口一点点”，八本的男主都是“剑眉星目鼻梁高挺薄唇紧抿”。读者看完十个男主，一个都记不住。因为这些词是五官清单，不是人。

模板的问题在于：它写的是所有美人的公约数。公约数越通用，就越没个性。你写一个人，要写的是他跟别人不一样的地方，不是他跟所有人都一样的地方。

【模板版】她生得柳叶眉，杏核眼，樱桃小口，皮肤白皙，身材窈窕，穿一身水绿衣裙，宛如画中走出的仙子。

这段放在任何一本古言里都成立，也放在任何一本里都没人记得住。因为它没有一处是“只属于她”的。

下面这张表，列了十五条最常见的外貌套话，每条给一个替换方向。写之前对着查一遍，中一条改一条。

表 5-1 外貌模板雷区与替换方向

| 雷区套话 | 为什么是雷 | 替换方向 |
|---|---|---|
| 柳叶眉杏核眼 | 所有美人通用，无辨识度 | 写眉峰那道疤、眼角那颗痣 |
| 樱桃小口一点点 | 读者看不见 | 写她说话时下唇怎么咬 |
| 皮肤白皙胜雪 | 等于没写 | 写她手背上那层薄青筋 |
| 剑眉星目 | 男主标配，谁都是 | 写他皱眉时眉心那道竖纹 |
| 鼻梁高挺 | 读者记不住 | 写他笑起来鼻头上那点细纹 |
| 薄唇紧抿 | 冷酷男主标配 | 写他说话前舌尖顶一下腮帮 |
| 宛如仙子/谪仙 | 空泛赞美 | 删掉，用动作让她自己仙 |
| 身材窈窕/修长 | 没有信息量 | 写她走路时肩膀端不端 |
| 一双会说话的眼睛 | 陈词滥调 | 写她看人的时候先看哪 |
| 眸若星辰 | 比喻烂大街 | 写她瞳孔缩了一下 |
| 面若桃花 | 跟情绪无关 | 写她生气时耳根先红 |
| 气宇轩昂 | 套话 | 写他站着时重心压在哪条腿 |
| 眉目如画 | 空 | 写他低头时睫毛投下的影 |
| 冰山美人 | 标签 | 写她三个月没笑过一次 |
| 邪魅一笑 | 网文烂梗 | 写他嘴角只往一边扯了半寸 |

这十五条，你中了几条？中三条以上，说明你的人物还在流水线上。改的时候别想着一步到位，先把最扎眼的那几条划掉，换成具体的、只属于这个人的细节。

### 5.1.2 写一个“不对劲”的地方

让人记住一个人，不靠写他多美，靠写他身上那点不对劲。美人脸上一颗痣，比她整脸的美都让人记得住。这颗痣长在嘴角，就是俏皮；长在眼角，就是苦相；长在眉心，就是英气。位置不同，人就不同。

姜漪长得不算顶美。她左边眉尾缺了一小截，据说是小时候摔的。那截眉缺得恰到好处，让她笑起来的时候，左边比右边先弯。

眉尾缺一截。就这一个细节，姜漪从“又一个美人”变成了“那个眉尾缺一块的姑娘”。写外貌的诀窍，是找那点残缺、那点记号、那点跟标准不一样的地方。

这个“不对劲”要趁早给。人物刚出场，读者对他还陌生，这时候给一个记号，他就记住了。等写了十章再给，读者已经忘了他长什么样，记号也白搭。

「外貌写法」：别写他长什么样，写他身上哪一处跟别人不一样。一处就够。这一处要能在他出场三次以后，读者还能凭这一处认出他。

### 5.1.3 穿衣和身材怎么写

穿衣比脸好写，因为衣服能说话。一个人穿什么、怎么穿，比他长什么样更能暴露他。裴照川那种武人，再讲究也会在袖口磨出毛边；姜漪那种贵女，再素的衣裳也会在领口压出一道极细的暗花。

写身材别用“窈窕”“修长”这种词。写他穿衣服时的样子：肩线撑不撑得起袍子，腰那里收不收得住，袖子挽上去小臂什么形状。读者自己会脑补身材。

顾行简穿一件半旧的青衫。衫子洗得发白，肩膀那里却撑得很平，一看就是天天干活的人。袖子挽到手肘，小臂上一层薄汗，晒得有点黑。

洗得发白的衫子、撑得平的肩、挽袖子露小臂。三笔，一个在太阳底下跑外勤的年轻书生就出来了。衣服是人的第二层皮，比脸诚实。

穿衣还有个讲究：写他身上那点“不对劲”。一个天天穿官服的人，忽然穿了件旧棉袄；一个天天素衣的人，忽然戴了支新簪子。这个“不对劲”就是戏眼，读者立刻知道他今天有心事。

### 5.1.4 写老人和孩子的外貌

老人别写“白发苍苍步履蹒跚”。写他身上那点旧习惯。老大夫的手，指甲剪得极短，指节变形，是一辈子号脉号出来的；老管家的背，是微微驼的，因为跟了主子一辈子，低着头回话。

崔嬷嬷进来的时候，先把手里的掸子往门后一靠。她头发全白了，梳得一丝不乱，在脑后挽成一个髻。走路没声，鞋底是纳过的。她走到姜漪身后，伸手替她把鬓边那根松了的簪子重新插好，手背上的皮皱得像老树皮。

掸子靠门后、白发梳髻、纳过的鞋底、替人插簪子、皱得像老树皮的手。没一个“慈祥”，但这个婆子立刻立住了。老人写手，孩子写眼睛。

孩子别写“粉雕玉琢聪明伶俐”。写他的手在干什么。三岁的孩子手永远闲不住，抠桌缝、揪猫尾巴、把饭粒摆成一排。写他手闲不住，孩子就活了。

### 5.1.5 现言人物外貌怎么写

现言不用写“剑眉星目”，现言写的是现代人的样子。现代读者对身边人敏感，你写得越具体，他越觉得这人他认识。

现言男主：别写帅，写他那件洗得发白的卫衣、鞋边蹭掉的皮、抬手腕时露出的表。
- 现言女主：别写美，写她扎头发时碎发落下来的样子、指甲剪得短短的、帆布鞋后跟踩扁。

顾行简这种现言男主，出场别给脸。给他一个动作：

顾行简推门进来，腋下夹着电脑包，另一只手端着半杯凉了的美式。他把杯子往桌上一放，杯底在木头桌面上留下一圈水渍。他没擦，直接拉开椅子坐下。

电脑包、半杯美式、水渍、不擦、直接坐。五个细节，一个加班加到没脾气的年轻男人就出来了。现言写外貌，写的是他生活里那些懒得收拾的痕迹。

仙侠人物最容易写飘。一袭白衣、飘飘欲仙、不食人间烟火。写多了就是个纸片。仙侠人物要写仙，但也要写他是人。给他加一点人间的痕迹：袖子上沾的灰、剑穗磨毛了、袖口那里被火烤过一点。

玄鹤站在云头。白衣很白，但袖口那里磨出了一道灰边，是常年握剑磨的。他剑上挂的那枚玉坠，绳子换过两回，玉倒是老玉，沁了一道红。

白衣、袖口灰边、握剑磨的、玉坠绳子换过、老玉沁红。仙是仙，但他握了很多年剑。仙侠写外貌，要仙里面挑一点旧。一点旧就够，他就不是个塑料人。
