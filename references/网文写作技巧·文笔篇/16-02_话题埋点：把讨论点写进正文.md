# 16.2 话题埋点：把讨论点写进正文

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》16.2 话题埋点：把讨论点写进正文

### 16.2.1 埋点的底层逻辑

读者讨论一本书，往往不是因为整本书精彩，而是因为某一句话、某一个动作、某一个没说透的地方。作者在写正文的时候，可以主动留这种口子。这就是埋点。埋点不是挖坑不填，是填的时候故意留半寸，让读者自己伸手指进去摸。

人为什么会讨论。因为他心里有一个没被回答的问题。作者把这个问题藏在正文里，又不急着回答，读者就会带着它往下读，读完还要在评论区问一句。埋点的本质，是给读者一个说话的位置。

埋点的分寸很要紧。埋太浅，读者一眼看穿，懒得讨论；埋太深，读者根本没注意到，白埋。好的埋点，是读者读到第三遍才反应过来“这里不对劲”，然后他回去翻第一章。

埋点还要分轻重。轻的埋点放在章节里，读者读完就忘，第二天再翻起来又想起；重的埋点放在卷末，读者带着这个问题等下一卷。轻重搭配，讨论区才不会一边倒。

### 16.2.2 八种埋点方法与正文示例

下面八种方法，每一种都给一句正文示例。示例都用《长夜衔霜》做底。

表 16-2 八种话题埋点方法

| 方法 | 正文示例句 | 讨论为什么会被引出来 |
|---|---|---|
| 反常动作 | 她把那封信读完，没有烧，也没有收，而是把它压在了茶杯底下。 | 压在茶杯底下是什么意思，读者会自己脑补三种结局。 |
| 半句留白 | 他张了张嘴，最后只说了一句：“你要是……”就没再说下去。 | 省略号后面那半句才是钩子，读者替他补。 |
| 道具错位 | 她戴上了他三年前送的那支旧簪，簪头已经歪了。 | 歪了的簪子配今天这场重逢，读者会问“她是不是故意的”。 |
| 时间差 | 那是腊月二十八，离他说要回来的日子，还有整整一个月。 | 一个月后的事，读者会一直记着。 |
| 旁观者一句 | 卖炭的老妇看了一眼那个背影，跟旁边的人说：“这姑娘，怕是见不着了。” | 外人下判断，读者会想反驳，也会想印证。 |
| 视角错位 | 他以为她是来送行的。她其实是来告别的。 | 同一时刻两个人想的不一样，读者最爱吵。 |
| 重复意象 | 这是今年第三次落雪，她又一次把那盏灯留到了天亮。 | 第三次、又一次，读者会数，数完就要讨论。 |
| 谶语 | 她小时候被算命先生说过，活不过那个冬天。 | 这句话一出现，整本书都有了倒计时感。 |

八种方法不用全用。一本书里挑两到三种反复用，比八种各用一次强。反复用的那一种，会变成这本书的讨论暗号。读者看到第三次出现，会主动在评论区报到。

埋点的位置也有讲究。不要埋在章节开头，开头读者还没进入状态。埋在章节中间偏后，或者章节末尾。读者读到那里，情绪已经被带起来了，埋点才咬得动。

「埋点的红线」：埋点不能毁掉主线。主线该交的信息必须交，埋点只是在主线边上多开一道小缝。读者讨论归讨论，故事不能因为要被讨论就停下来不走。

### 16.2.3 埋点的回收

埋点埋下去，最后必须收。收的方式有两种。一种是正面收：到某一章，把埋点的答案明明白白写出来。另一种是侧面收：不直接回答，让读者通过人物的变化自己感受到答案。

正面收适合悬疑类埋点，侧面收适合情感类埋点。混用也可以，但一本书里要有明确的主收法。读者追了三百章，最后连埋点都没被回应，会觉得被耍。

表 16-9 八种埋点的回收方式对照

| 埋点方法 | 回收方式 | 回收时机 |
|---|---|---|
| 反常动作 | 正面收：点明她为什么压在茶杯底下 | 第三卷中段 |
| 半句留白 | 侧面收：男主后来自己把那句话说完 | 第四卷开头 |
| 道具错位 | 正面收：簪子的来历讲清楚 | 第二卷末 |
| 时间差 | 正面收：腊月二十八那天发生了什么 | 当卷末尾 |
| 旁观者一句 | 侧面收：老妇的话被另一人物印证 | 下一卷开头 |
| 视角错位 | 正面收：两人当面对质，误会解开 | 第三卷高潮 |
| 重复意象 | 侧面收：第七次落雪时意象合上 | 全书结尾 |
| 谶语 | 正面收：那个冬天她到底有没有活下来 | 全书结尾 |

回收的节奏要跟得上埋点的节奏。埋了八个点，每卷至少收一个。埋而不收，读者会觉得你在挖坑。收得太快，讨论还没起来就结束了，也可惜。

判断什么时候收，看评论区。同一个问题被问了三次，就到了该收的时候。读者已经把这个问题想透了，你再不回答，他们就要自己编答案了。
