# 16.5 简介、章节名与试读页的文笔

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》16.5 简介、章节名与试读页的文笔

### 16.5.1 简介四套模板

简介、章节名、试读页，是读者接触这本书的前三秒。这三个地方的文笔，决定了他会不会点进去第一章。本册这一节给简介模板、章节名命名法和试读页的落点。

四套模板对应四种气质。用的时候把自己的人物、物件、题眼填进去。

表 16-5 简介四套模板

| 模板 | 结构 | 样例（《长夜衔霜》） |
|---|---|---|
| 题眼式 | 一句题目拆开，再加一个人物 | 她熬过了第七次入冬，却没熬过他推门的那一声。 |
| 反差式 | 前半句冷，后半句烫 | 这世上最冷的地方是北境，最热的人是从北境回来的那个。 |
| 独白式 | 以主角第一人称说一句 | 我以为我藏得很好，直到他在雪地里叫出我的名字。 |
| 留白式 | 只给场景，不给答案 | 雪夜里，窗纸上有两个人影。一个在等，一个不敢敲门。 |

简介控制在两行以内。超过两行，读者就不看了。模板只是骨架，最后那一句一定要有自己正文里长出来的东西。

写简介的时候，最容易犯的错是把整个故事讲完。讲完了，读者就不用点进去了。简介只给一个钩子，不给答案。

表 16-6 章节名五种命名法

| 命名法 | 做法 | 示例 |
|---|---|---|
| 物件式 | 用本章出现的核心物件命名 | 旧簪，炭火，半封信 |
| 动作式 | 用本章最重的一个动作命名 | 她没回头，门没开，灯留到天亮 |
| 时间式 | 用本章发生的时辰命名 | 腊月廿八，三更，第七次落雪 |
| 对白式 | 摘本章最狠的一句台词命名 | “你要是……”，“不碍事。”，“这姑娘怕是见不着了。” |
| 意象式 | 用本章反复出现的那个意象命名 | 霜，灰烬，空灯 |

一本书里只用一种命名法。混着用，读者会觉得章节名是随手起的。选定一种，沿用到底。

章节名不要起得太长。四个字以内最好，最多六个字。超过六个字，章节名就变成了小标题，读者不读。

### 16.5.2 试读页的文笔落点

试读页是前三章。前三章的文笔要做三件事：立人物、给场景、留钩子。立人物靠一两个动作，给场景靠一个核心意象，留钩子靠段末那一句没说完的话。

她推开门的时候，屋里没有人。桌上的茶还冒着热气，椅子是温的，像有人刚刚才走。她在门口站了很久，没有进去，也没有把门带上。

这一段里没有人说话，没有心理描写，可读者立刻知道她是谁、在等谁、等到了没有。试读页就要写到这种密度。

试读页还有一个隐性要求：前三章里必须出现一次主角的小动作。这个小动作以后会反复出现，成为人物的指纹。读者记住这个动作，就记住了这个人。

作者在写试读页的时候，最容易犯三个错。本册列出来，对着改。
- 错误一：第一章就把世界观讲完。读者还没进入故事，先被一堆设定砸晕。设定要拆，跟着情节慢慢给。
- 错误二：第一章主角不出场。第一章末尾主角必须露面，最好带着一个动作露面。
- 错误三：前三章没有冲突。哪怕是小冲突也要有，比如一个被退的信、一次没等到的人。没有冲突，读者就滑走了。

试读页写完，自己读一遍。读完问自己：如果我是读者，我会不会点开第二章。不会，回去改。

### 16.5.3 简介的迭代

简介写完，不要直接用。放一天，第二天再看。第一天写的简介，往往带着自我感动。第二天再看，你会发现有三句话可以删。

简介迭代三轮。第一轮写完，第二轮删一半，第三轮换成自己正文里最狠的那句台词。三轮之后，简介才立得住。

表 16-12 简介三轮迭代对照

| 轮次 | 写法 | 字数 |
|---|---|---|
| 第一轮 | 把故事讲完 | 一百五十字 |
| 第二轮 | 删到只剩钩子 | 八十字 |
| 第三轮 | 换成正文里的一句台词 | 四十字 |

三轮迭代的核心是：第一轮写给自己，第二轮写给路人，第三轮写给正文。第一轮你在自我感动，第二轮你在想说清楚，第三轮你终于意识到，正文里那句话已经说清楚了，你只需要把它摘出来。

很多作者写不好简介，是因为他们把简介当成了一个独立的东西。其实不是。简介是正文的影子。正文立住了，影子自然出来。
