# 16.1 文笔卖点提炼

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》16.1 文笔卖点提炼

### 16.1.1 卖点句从正文里长出来

书写完三十万字，最常被问的一句话是：你这本书好在哪。这个问题在作者嘴里答不清楚，往往是因为卖点还埋在正文里没被自己拎出来。卖点不是吹牛，是把正文里已经成立的东西，用一句读者能复述的话重新说一遍。本册这一节谈的卖点，全部来自自己的稿子，不来自对标，不来自想象。

很多作者一说到卖点，就去翻同类爆款，看别人怎么写，自己照抄一句。这条路走不远。别人的卖点是别人正文里长出来的，你搬过来，自己正文里没有那三段话撑着，读者一翻就穿帮。真正稳的做法，是回头翻自己的稿子，把读者主动夸过的句子挑出来。

提炼卖点的第一步，是回头翻自己写过的章节。翻的时候只做一件事：把读者在评论区主动夸过的句子划线。哪一句被人截图、被人说“这段我来回读了三遍”，那一句就是种子。把种子抽出来，缩成一句话，就是卖点句。

从自己稿子里长出来的卖点，站得住。因为它在正文里已经被验证过，读者愿意为它停下来。反过来，坐在桌前硬想出来的卖点，往往是形容词堆出来的，读者读三章就发现货不对板。

翻稿子的时候，建议按三类划线。第一类是被人单独摘出来夸的句子，第二类是被人说“看哭了”的段落，第三类是被人分析过的细节。三类各挑五条，凑成十五句素材库。卖点句就从这十五句里缩。

「卖点句的验收」：把这句话念给一个没读过你书的人听。他听完问“然后呢”，说明钩子在；他听完说“也就那样”，说明这句话是空的，得换。

### 16.1.2 四类角度的卖点句库

卖点句按四个角度拆。文风质感、情绪浓度、人物口吻、场景辨识度。一个角度给三条样例，用《长夜衔霜》《山河故纸》《第七次入冬》三本虚构书做底。

表 16-1 四类卖点句库（共 12 条，可直接改写套用）

| 角度 | 卖点句样例 | 出自哪类段落 |
|---|---|---|
| 文风质感 | 句子是冷的，故事是热的，最冷的地方写最烫的人。 | 《长夜衔霜》开篇调 |
| 文风质感 | 叙事慢半拍，像雪落在窗纸上，你听见它才知道它已经落了一夜。 | 《山河故纸》雪景段 |
| 文风质感 | 白描到底，不喊痛，痛自己从字缝里渗出来。 | 《第七次入冬》克制段 |
| 情绪浓度 | 她哭的时候没有人哭，她不哭的时候，读者替她哭了。 | 《长夜衔霜》重逢段 |
| 情绪浓度 | 整本书只在最后一章让主角掉过一次眼泪，前面攒的全在那一次里。 | 《山河故纸》终章 |
| 情绪浓度 | 虐不写虐，写一碗热了又凉、凉了又热的粥。 | 《第七次入冬》日常段 |
| 人物口吻 | 女主说话从不带感叹号，你能从她的停顿里听出她在忍。 | 《长夜衔霜》人物声口 |
| 人物口吻 | 男主是那种把“没事”挂在嘴边的人，可他的“没事”每次都有事。 | 《山河故纸》男主立住段 |
| 人物口吻 | 老仆说话绕三圈，绕到第三圈你才听懂他在劝谁。 | 《山河故纸》配角声口 |
| 场景辨识度 | 雪夜、炭火、旧信纸，三个意象反复出现，看到第三个你就知道这是哪本书。 | 《山河故纸》意象系统 |
| 场景辨识度 | 入冬的第七次，他终于等到那个不会回来的人推门。 | 《第七次入冬》题目段 |
| 场景辨识度 | 女主的兵器是一卷旧账册，翻账页的时候比拔剑还好看。 | 《长夜衔霜》道具段 |

这十二条不是让你照抄，是让你照这个密度去抠自己的稿子。一条卖点句背后，至少要有正文里三段话撑着。没有三段话撑着的卖点，是空头支票。

抠自己稿子的时候，会遇到一个常见问题：翻遍了也找不到三条被夸的句子。这说明书还没写到能提炼卖点的程度，先回去写，不要急着做宣传。硬提炼出来的卖点，读者不认。

卖点句用在简介、章末话、对外介绍里。用在三个地方就够：书名下面那一段、每卷开头那一句、自己对外介绍时那一句。用多了，读者会腻。

还要记住一条：卖点不能跨赛道搬。清冷文风的卖点搬到甜宠文里，读者觉得装；日常向的卖点搬到悬疑里，读者觉得轻。卖点是贴着自己那本书长出来的，不是通用广告词。

卖点句也不能变成长篇大论。一句话超过二十个字，就没人记得住。能缩到十个字以内最好。比如“冷句子，烫人心”，六个字就把文风质感说清楚了。

### 16.1.3 卖点句的日常打磨

卖点句不是写完就不动了。每写完十章，回头看一次，把新冒出来的好句子加进素材库。旧的卖点句如果发现正文里撑不住了，就换掉。卖点句是活的，跟着书一起长。

打磨的时候，把同一条卖点句写出三个版本。一个短的，八个字；一个中的，十五个字；一个长的，三十个字。短的放简介，中的放章末话，长的放对外介绍。同一句话，三种长度，三个场合。

「卖点句的反面」：不要把“文笔好”“情感细腻”“人物立体”这种话当卖点。这些话是评语，不是卖点。卖点必须能落到一个具体的物件、一句具体的台词、一个具体的动作上。

再给一组对照。左边是空的，右边是实的。

表 16-11 空卖点与实卖点对照

| 空卖点 | 实卖点 |
|---|---|
| 文笔优美 | 一段雪景只用一百二十字，不写一个冷字 |
| 情感细腻 | 女主整本书只哭过一次，读者替她哭了十次 |
| 人物立体 | 男主断了手指只说“不碍事” |
| 情节紧凑 | 每章末尾都有一句没说完的话 |
| 设定新颖 | 女主的兵器是一卷旧账册 |

左边那种话，读者在一百本书的简介里都看过。右边那种话，只属于你这本书。

实卖点的写法有一个公式。具体数字加具体物件加具体动作。比如“一百二十字雪景”，有数字；“旧账册”，有物件；“翻账页”，有动作。三样凑齐，卖点就立住了。

写不出来的时候，回到正文里找。不要坐在桌前想。想出来的都是空的，从正文里挖出来的才是实的。
