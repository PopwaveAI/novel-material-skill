# 3.2 听觉描写：声音是另一种节奏

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》3.2 听觉描写：声音是另一种节奏

### 3.2.1 声音分远近

声音是最容易被忽略的感官，但它最勾人。你写一个场景，加一两个声音，读者立刻就进去了。

声音分远近，还有个用法：用声音制造紧张。你写人物在等，写钟摆、写水滴、写心跳，声音越清楚，人越紧张。因为安静里的声音，比嘈杂里的明显。

声音还能写空间。你写一个大屋子，不用写“屋子很大”，写远处有回声、近处有水滴。声音一出来，空间就大了。

好的听觉描写，有远近层次。远处的声音垫着，近处的声音顶着。比如你写程野在废墟里，远处有风声，近处有水滴，更远有“它们”的嘶吼。三层声音，空间就出来了。

程野贴着墙，先听见远处的风，呜呜地刮过楼板。再听见近处，头顶有水滴下来，嗒，嗒。再远，很远的地方，传来一声嘶吼，被风撕碎了。

三层声音，空间感就有了。读者不用你说“这楼很大很空”，声音自己告诉他。

### 3.2.2 听觉词句库

听觉词句库，用的时候注意：声音要带情绪。“他牙关咬得咯咯响”是紧张，“他吐了口气很轻”是放松。声音不是白写的，它带情绪。

你写夜里，用“雨打窗纸沙沙沙”和“钟敲十二下”；写紧张，用“他手指在桌上敲，嗒嗒嗒”。一条一个声音，挑着用。

### 3.2.3 声音的反例

安静不是说“很安静”，是写安静里的声音。你写“屋里很静，静得能听见水壶冒泡”，安静就出来了。

反例是“安静得可怕、安静得窒息”。这是形容词，不是声音。你写安静里的声音，读者才觉得安静。

安静不是说“很安静”，是写安静里的声音。你写“屋里很静”，再加一句“静得能听见水壶冒泡”，安静就出来了。

反例是“安静得可怕、安静得窒息”。这是形容词，不是声音。你写安静里的声音，读者才觉得安静。

反例是只有一种声音。“屋里很安静，他坐在椅子上，安静极了。”安静是概念，不是声音。你写安静，要写安静里的声音：水滴、钟摆、自己的呼吸。

屋里很安静，安静得可怕，安静得让人窒息。

改：屋里很静，静得能听见炉上水壶冒泡，咕嘟，咕嘟。安静不是说出来的，是靠一声水泡出来的。

「听觉口诀」：声音分远近。远处垫，近处顶。安静要写安静里的声音。
