# 15.4 展示而非告知

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》15.4 展示而非告知

### 15.4.1 告知是作者偷懒

这是高级文笔最核心的一条。展示，就是让读者看见。告知，就是你直接告诉读者。这一节给你十二组对照，看完你就懂了。

这一条是所有高级技巧的基础。你学会了展示，其他技巧都是锦上添花。学不会展示，其他技巧都是空中楼阁。

展示是高级文笔的门槛。你跨过这道门槛，才算从新手跨到了老手。跨不过去，你写的永远是新手文。

告知的本质是作者偷懒。你不想想怎么写画面，就直接告诉读者结论。「他很紧张」就是告知。你写「他把纸杯捏扁了，又展开」就是展示。

告知读起来快，但读者记不住。展示读起来慢，但读者忘不了。网文是慢读，读者有时间品味。所以展示比告知高级。

不是说告知不能用。节奏快的时候可以用告知，一笔带过。节奏慢的时候，重要的情绪和场面，必须用展示。

举个例子。你写主角从北京到上海，路上坐了五个小时高铁。这五个小时不用展示，一笔带过就行：「他坐了五个小时高铁，到了上海。」这是告知，没问题。

但你写主角在上海见了一个五年没见的人，这个场面就要展示。不能写「他们五年没见，很激动」。要写「他进门的时候，她手里的杯子停在半空」。这是展示。

判断标准很简单：这个场面读者会不会记住？会记住的，展示。不会记住的，告知。

很多新人学了展示，就走极端，什么都展示，结果节奏特别慢。一章写不完一件事。这就是矫枉过正。

展示是给重要的东西用的。不重要的东西，一笔带过就行。你写主角早上起来刷牙，不用展示他怎么刷的。写主角早上起来发现枕边没人，这时候要展示。

### 15.4.2 十二组告知展示对照

下面这十二组对照，覆盖了最常见的情绪和场面。你写的时候对照着看，自己写的是哪一种。

这十二组不是让你背下来。是让你看完之后，建立一种意识：写东西的时候，先想能不能展示，能展示就不要告知。

这十二组覆盖了最常见的情绪：紧张、伤心、愤怒、期待、害怕、想念。你写这些情绪的时候，对照着看自己写的是哪一种。

如果你写的是左边那列，赶紧改成右边那列。改完之后你会发现，同样的情绪，右边写出来比左边有力十倍。

这个对照练习做二十次，你就会形成肌肉记忆。以后写东西，你的手会自动去找展示，而不是自动去写告知。

有个小技巧：写完一段，把里面所有情绪形容词圈出来。每个形容词后面，问自己一句：这个情绪有没有对应的动作？有，就把形容词删了，写动作。没有，就想一个。

这个技巧做上十段，你就会发现自己写东西时自动就不写情绪词了。你的手会自动去找动作。

还有一个小技巧：写完一段，把里面所有「很」字圈出来。每个「很」字后面，问自己一句：这个「很」能不能换成一个具体动作？能换就换。

表 15-3 告知展示对照十二组

| 告知（原句） | 展示（改句） |
|---|---|
| 他非常紧张 | 他把纸杯捏扁了，又展开，又捏扁 |
| 她很伤心 | 她对着镜子把头发梳了三遍，梳子断了一根齿 |
| 房间很破 | 墙上的石灰掉了一块，露出里面的青砖 |
| 他很生气 | 他把烟掐灭在茶杯里 |
| 她很期待 | 她把那条裙子挂在门后，看了三回 |
| 他们很久没见了 | 他进门的时候，她手里的杯子停在半空 |
| 这件事很严重 | 他看完信，把信纸折成原来的样子，才发现手在抖 |
| 她很善良 | 她把自己的馒头掰了一半，递给那个乞丐 |

### 15.4.3 什么时候可以告知

展示不是万能的。有些时候必须用告知。

很多新人学了展示，就走极端，什么都展示，结果节奏特别慢。一章写不完一件事。这就是矫枉过正。

展示是给重要的东西用的。不重要的东西，一笔带过就行。你写主角早上起来刷牙，不用展示他怎么刷的。写主角早上起来发现枕边没人，这时候要展示。

判断标准很简单：这个场面读者会不会记住？会记住的，展示。不会记住的，告知。
- 节奏快的时候：打斗戏、追逐戏，没时间展示，一笔带过就行。
- 过渡的时候：从一个场景切到另一个场景，中间的过程用告知。
- 不重要的情绪：配角的小情绪，不值得展示，告知就行。

重要的主角情绪、重要的场面、重要的转折点，必须展示。这三个地方用告知，读者就出戏。

「核心一句话」：重要的情绪和场面用展示，过渡和节奏快的地方用告知。
