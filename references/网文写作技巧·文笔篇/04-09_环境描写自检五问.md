# 4.9 环境描写自检五问

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》4.9 环境描写自检五问

### 4.9.1 这一段是谁在看

改稿的时候，把每一段环境描写单独拎出来，问自己：删掉它，剧情懂不懂？情绪丢不丢？如果答案是“都不耽误”，那就删。网文里没有一段环境是非留不可的，除非它在干活。

干活的环境只有三种：交代处境、衬托情绪、推动动作。三样都不沾的，再美也是赘肉。

把段落里的名词圈出来，问一句：这是视角人物此刻会注意到的东西吗？一个饿了三天的人，不会注意窗台上的花纹；一个逃命的人，不会注意天很蓝。如果你的环境描写换个主角也成立，说明它没扎根，重写。

【自检表】
这一段的焦点物件，跟人物此刻的心事有关吗？
这段里至少有一个动词是人物对环境做出的反应吗？
如果把这段搬到另一个人身上，是不是也成立？成立就重写。

### 4.9.2 这一段的情绪落点在哪

每一段环境描写，最后都要落在一个情绪上。落在人物的一个动作上更好。写完检查：这段最后一句，是又加了一个景物，还是落回了人物身上？永远要落回人物身上。景物是为人物服务的，不是让景物自己表演。

【没收住的】窗外下着雨，雨打在芭蕉叶上，噼里啪啦，夜色浓得像化不开的墨，远处几点灯火明灭不定。
【收住的】窗外下着雨，雨打在芭蕉叶上，噼里啪啦。姜漪把信凑到灯上，看着它卷起来，黑下去。

改前最后一句还在写景（灯火明灭），改后最后一句落到了人物动作上（烧信）。同一个雨景，改前是风景明信片，改后是她下决心的那一刻。段落的最后一个字，必须长在人物身上。

表 4-5 环境描写五问速查

| 问题 | 不合格时的动作 |
|---|---|
| 这段能不能删 | 不能推动剧情或情绪的，删 |
| 谁在看 | 换成上帝视角的，重写成视角人物所见 |
| 核心意象是什么 | 一段超过五个名词的，砍到一个 |
| 淡写还是浓写 | 情绪克制处用浓写，情绪爆发处用淡写 |
| 最后落回人物了吗 | 结尾又写景的，加一个人物动作收住 |

这五问，每写完一章环境戏就过一遍。过上半年，你会发现自己写景越来越省，也越来越准。写景这件事，说到底不是手艺，是克制。舍得删，才写得好。手别痒，笔别重，写的时候想着读者的拇指什么时候会往上滑。

### 4.9.3 拿自己的稿子练一遍

光看不练没用。拿你最近写的一章，挑一段你自己最得意的环境描写，按下面的顺序改一遍。
- 第一步：把里面所有形容词圈出来，删掉一半。剩下的形容词，问自己能不能换成一个具体物件。
- 第二步：把视角人物的名字写在段落开头。检查这段里的每一个细节，是不是他此刻会注意到的。不是的，删。
- 第三步：数名词。超过五个的，留下最贴人物处境的那个，剩下的挪走。
- 第四步：看结尾。结尾如果还在写景，加一个人物的小动作收住。
- 第五步：把改完的段落读出来。耳朵不磕巴，就过关；读着喘不过气，继续删。

这么改一章，比你写十段新的都管用。文笔是改出来的，不是写出来的。先会删，再会加，这个顺序别搞反。改完拿不准，就把段落大声读一遍，耳朵不骗你。

「本册态度」：环境描写这件事，本册的立场很明确：少即是多。一个场景里真正立得住的，往往就一两笔。剩下的都是陪衬。你敢删，读者才敢信。写的时候宁可少写十句，也别让一句没由来的景物混进去充数。
