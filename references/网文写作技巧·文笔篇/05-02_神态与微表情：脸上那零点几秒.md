# 5.2 神态与微表情：脸上那零点几秒

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》5.2 神态与微表情：脸上那零点几秒

### 5.2.1 微表情清单（二十条）

人脸上的大表情是可以装的。笑可以装，怒可以装。但微表情装不住：眼皮跳一下、嘴角抽一下、瞳孔缩一下、喉结滚一下。这些动作发生在零点几秒里，连当事人自己都没察觉。写微表情，就是写人物没说出口的那部分。

新手写情绪，爱写“他脸色一变”“她眼神一冷”。这是大标签。老作者写情绪，写的是那零点几秒的裂缝：他端茶的手停了半寸，她掀帘子的指尖顿了一下。

下面这二十条，每条给情绪和可见征兆。写的时候挑一条用，别一次堆五条。

表 5-2 微表情与情绪对照

| 情绪 | 脸上/身上的可见征兆 |
|---|---|
| 心虚 | 视线先飘开，再偷偷瞟对方一眼 |
| 紧张 | 咽口水，喉结上下滚一下 |
| 被说中 | 嘴角绷住，鼻翼张了张 |
| 压着火 | 太阳穴跳了一下，咬后槽牙 |
| 惊讶 | 眼皮抬一半，嘴没张开 |
| 不信 | 单侧眉毛挑起来 |
| 强笑 | 嘴角上去了，眼睛没动 |
| 尴尬 | 摸后脖子，或者摸鼻子 |
| 心虚被抓 | 眼神往下落，落在自己手上 |
| 下决心 | 抿一下嘴，下巴收紧 |
| 忍痛 | 眨眼频率变快，眨得很重 |
| 动心 | 睫毛颤了一下，呼吸慢半拍 |
| 厌恶 | 上唇往上提一点，鼻子皱 |
| 盘算 | 眼珠往斜上方转，停住 |
| 撒谎 | 说话前先舔一下嘴唇 |
| 委屈 | 眼眶先红，但嘴角还压着 |
| 得意 | 嘴角压不住地往上翘 |
| 慌 | 手不知道往哪放，去整袖口 |
| 失望 | 肩膀塌下来半寸 |
| 动心被戳穿 | 耳尖先红，脸还绷着 |

这二十条不是让你背。是让你写的时候，从里面挑一条最贴此刻情绪的，安到人物脸上。一条微表情，顶三句“他很紧张”。

微表情不能孤立用。它要接在一句台词前面或者后面，像标点。台词说“我没事”，前面加一个“她咽了口口水”，读者就知道她有事。

“我没事。”姜漪把帘子放下来，手指在帘角绞了一下。

“我没事”是台词，绞帘角是微表情。台词和动作反着来，潜台词就出来了。嘴上说没事，手上在绞东西，读者立刻懂。这是写对话最省钱的招，下一部分还会细讲。

### 5.2.2 大表情什么时候可以用

微表情是日常用的，但不是说大表情不能用。人物真到了大悲大喜、大怒大惊的时候，该写大表情就写大表情。天天微表情，读者也会累。

大表情用在三个地方：一是情绪压不住了，二是剧情的爆点，三是人物第一次露真容。除此之外，都用微表情。

贺青听完那句话，愣在原地。他张了张嘴，没发出声。过了好一会儿，他才笑出来。那笑得比哭还难看。

愣、张嘴没声、比哭还难看的笑。这是大表情，因为他此刻情绪真的压不住了。微表情写日常，大表情写破防。破防的瞬间，读者需要看到他整张脸垮下来。

眼睛是最难写的地方。新手写眼睛，爱写“眸子一寒”“眼神一冷”。这是标签，不是画面。眼睛要写它落在哪、怎么动、动多快。
- 他看她的时候，先看她的鞋，再慢慢把目光抬上来。
- 她不敢看他，眼睛盯着桌上那只茶盏。
- 他听完那句话，眼睛眯了一下，眯得很轻。

看鞋、盯茶盏、眯一下。三个动作，三种心思。眼睛怎么落，比眼睛长什么样重要一百倍。你写“他眼神锐利”，读者看不见；你写“他眼睛从她脸上扫到手上，又扫回来”，读者自己就觉得被他打量了。

### 5.2.3 笑怎么写

笑是最容易写俗的。“莞尔一笑”“嫣然一笑”“冷冷一笑”。这些词放在一起，十个角色九个一个笑法。笑要分怎么笑、笑几声、笑到哪、笑完之后脸什么样。

写笑的时候，把“笑”这个字先删掉。看看能不能用动作代替。能代替，就别写“他笑了”。

笑分很多种，每种都有写法：
- 扯嘴角：只动一边，不出声。这是嘲讽。
- 低头笑：笑的时候手挡一下嘴。这是害羞。
- 仰头笑：笑出了声，脖子伸开。这是真开心。
- 冷笑：从鼻子里哼出来的，半声就停。这是压着火。
- 苦笑：笑完嘴角还挂着，眼睛里没光。这是认了。

姜漪听完，低下头笑了。她拿袖子挡了一下嘴，肩膀轻轻抖。笑完，她抬起头，眼睛有点红。

低头、挡嘴、肩膀抖、笑完眼红。这一串动作，比“她凄然一笑”有劲多了。笑到哪一步，就是哪一种情绪。

沉默比说话难写。两个人不说话的时候，戏怎么继续？靠动作和眼神。沉默不是没东西写，沉默是戏最密的时候。

两个人对着坐着。茶凉了，谁也没去续。窗外有只鸟叫了两声，飞走了。姜漪低头看自己的手，裴照川看她。看了很久，他站起来，走到窗边。

茶凉、鸟叫飞走、看手、看她、站起来、走到窗边。六个动作，一段沉默。沉默里的每一秒都要有事发生：一个眼神、一个动作、一个声音。什么都没有的沉默，读者就划走了。

哭是最容易写滥的。“泪如雨下”“泣不成声”。这些词一出来，读者就出戏。真哭是有过程的：先眼眶热、再鼻子酸、然后眼泪掉下来、最后才出声。你写这个过程，比写“大哭”有劲。

姜漪听完那句话，没动。过了一会儿，她眨了一下眼。又眨了一下。她抬手用手背蹭了一下眼角，蹭完才发觉自己哭了。

没动、眨眼、眨眼、蹭眼角、发觉哭了。五个动作，一段哭。真哭的人是不知道自己在哭的。你写她“哇的一声哭出来”，那是演；你写她蹭眼角才发觉，那是真的。

哭还有个写法：写完哭，写哭完之后。哭完的人是什么样？眼睛肿了、鼻子红了、嗓子哑了、或者反而笑了一下。这个“哭完之后”比哭本身还打人。
