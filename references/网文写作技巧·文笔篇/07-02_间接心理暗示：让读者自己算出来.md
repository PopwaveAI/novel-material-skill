# 7.2 间接心理暗示：让读者自己算出来

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》7.2 间接心理暗示：让读者自己算出来

### 7.2.1 暗示的四个支点

暗示比独白高级的地方，是读者自己推出来的情绪比作者塞给他的更重。四个支点够用。第一是动作停顿：她话说到一半停了，筷子悬在碗上。第二是感官错位：明明是白天，他却觉得屋子里像下过雨。第三是用词偏差：他形容一件事用了一个不该用的词，比如「他早就等着这一天」里的「早」。第四是重复：同一个物件、同一句话出现两次，第二次的语气就变了。

萧令仪把那杯茶端起来，又放下。茶是新沏的，她却嫌烫。她又端起来，吹了吹，没有喝。嬷嬷在门外站着，没敢出声。

这段没有一个「气」字。但读者知道她在气。端起放下、嫌烫、吹而不喝，三个动作叠在一起，情绪就立起来了。

四个支点不要一次全用。一段用两个就够。三个以上，读者会觉得你在显摆；一个都不用，又变成平铺直叙。两个是最稳的数。

### 7.2.2 把「他很难过」拆成可观察信号

新手写情绪，最常用的句式是「他很难过」「她心里一紧」。这种句子等于没写。要拆成可观察的信号。难过在普通人身上是什么？是吃饭的时候筷子伸出去又收回来，是看电视的时候眼睛盯着同一个广告看了三遍，是朋友说话他应了一声却不知道对方问了什么。情绪是内在的，但情绪的痕迹一定是外在的。你只要写痕迹，读者自己会把情绪填上。

表 7-2 情绪标签到可观察信号的拆法

| 情绪标签 | 错误写法 | 可观察信号（任选两个） |
|---|---|---|
| 难过 | 他很难过 | 筷子停在半空 / 同一则广告看三遍 / 应了一声却没抬头 |
| 心虚 | 她心里有鬼 | 说话比平时快 / 不看对方眼睛 / 手指反复摩挲杯沿 |
| 愤怒 | 他怒不可遏 | 把杯子放回桌上时多用力一寸 / 声音反而压低 / 说完一句话停两秒 |
| 失望 | 她失望透顶 | 笑了一下才开口 / 把要说的话咽回去 / 低头去整理桌上的纸 |

拆的时候要注意，信号不能是那个人物的常态。温梨本来就话少，话少就不能当她难过的信号。要选她反常的那个动作。判断方法：这个动作如果放在她平时的章节里，读者会不会觉得奇怪。会，才是信号。

下面再给四组「情绪标签 → 暗示版」的对照，直接抄用。

原句（情绪标签）：他很心虚，不敢看她的眼睛。
暗示版：他把茶杯端起来，又放下。他说这茶不错，声音比平时高了半度。

原句（情绪标签）：她非常失望。
暗示版：她笑了一下。她把要说的话咽回去，低头去整理桌上那叠纸。

原句（情绪标签）：他很紧张。
暗示版：他把打火机按了八次。火着了，他没点烟，又掐灭。

原句（情绪标签）：她很高兴。
暗示版：她走路的时候蹦了一下。她自己没察觉。

四组对照的规律是：把抽象情绪换成一个过量的小动作。按八次打火机、声音高半度、蹦一下自己没察觉，这些动作读者一看就懂。

### 7.2.3 暗示的密度与读者推理空间

暗示不能铺太满。铺太满，读者不用想，等于作者替他把答案说出来了，高级感就没了。密度怎么定？一段三到五个信号就够，不要十个。十个信号等于在脸上写字「我很难过」。留一个空给读者。比如写她吃饭不香，写她话少，写她站在窗前站了很久，但不写她为什么。读者自己会去猜，猜的过程就是参与。

「暗示的留白率」：一段暗示里，明确写出原因的句子不超过三分之一。剩下三分之二只写症状，不写病因。读者会替你把病因补上。

还有一个分寸。暗示不能用得太偏，偏到读者真的读不懂。判断方法很简单：写完放一天，第二天读一遍，如果要回头猜两次才能明白，就删一个信号，让它更清楚一点。

举一个反面示范。她的手指在桌面上划了一道又一道，像在写一个没有写完的字。窗外的蝉鸣一声比一声长。茶凉了。这个暗示写得偏，读者不知道她在想什么。改成：她的手指在桌面上划了一道又一道，划到第三道停住。她抬头看了一眼窗外，又低下头。这样读者能猜到她在犹豫一件事，画面也具体了。

表 7-7 情绪强度到句式选择对照

| 情绪强度 | 推荐句式 | 示例 |
|---|---|---|
| 平静 | 中长句，带一个细节 | 她把茶杯放在桌上，茶还冒着热气。 |
| 微澜 | 中句 + 一个反常动作 | 她把茶杯放回去，又拿起来。 |
| 激动 | 短句，断行 | 她站起来。椅子响了一声。她没有回头。 |
| 崩溃 | 极短句，三字以内 | 她跪了。地上凉。 |
| 事后 | 长句，慢 | 过了很久，她才想起那杯茶已经凉透了。 |

这张表可以直接当速查用。写情绪段落之前，先定这一段的情绪强度，再选句式。强度定错了，句式就全错。

### 7.2.4 暗示失效的三种情况

第一种失效是暗示之后又跟一句解释。比如写她端起茶又放下，下一句立刻写「她心里很不是滋味」。这句解释一出来，前面的暗示全废了。要忍住。

第二种失效是暗示的信号用错了人。温梨话少是常态，你再用「她话少」当暗示，读者无感。要选她反常的动作。

第三种失效是暗示之间没有逻辑。今天写她端茶又放下，明天写她咬指甲，两个动作没有关联，读者串不起来。暗示要围绕同一个情绪主线布置，比如这一周她都在反复做某个动作。

同一个暗示信号出现两次，第二次的语气要变。第一次她端起茶又放下，是犹豫。第三次她端起茶一口喝干，是下定了决心。动作一样，状态不一样，读者一眼就懂。

间隔的章节不要太短。第一次和第二次之间至少隔两到三章。隔一章读者会觉得你在重复，隔五章以上读者会忘。两到三章是最稳的。
