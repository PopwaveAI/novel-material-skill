# 1.7 落地：给自己的文笔做一次体检

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》1.7 落地：给自己的文笔做一次体检

### 1.7.1 三个量化指标

标准都立完了，这一节教你怎么给自己现在的文笔做一次体检。不用玄学，靠三个数加一张表。体检的目的不是打分，是找到你最弱的那一项，后面针对性练。

挑你最近写完的一章，三个数算一遍。第一个是平均句长：把这一章所有句子字数加起来除以句子数。网文舒服的区间是十五到二十五字，超过三十说明太黏。
- 第二个是段长：数一下有多少段超过四行。手机上超过四行的段，读者会跳。一章超过三个，就拆。
- 第三个是对话占比：对话行数除以总行数。现言甜宠可以到四成，悬疑末世两成。太低说明你一直在自说自话地叙述，太高说明场景空。

算完别慌。大部分人第一遍算出来，平均句长二十六七，段长五六行，对话占比一成。这很正常，知道在哪，就往哪改。

举个具体算法。随便找一章，把句子按句号问号感叹号切开，数每句的字数，加起来除以句数。比如你一章三十句，总字数六百，平均就是二十字。这个数最舒服。超过三十，说明你爱写长句；低于十，说明你太碎，读者喘不过气。

段长也一样。手机上一行大概十五个字，四行就是六十字。一段超过六十字，手机上就要滑两屏，读者容易跳。你写完一段，瞟一眼屏幕，超过四行就拆。

三个量化指标，每周算一次。算完记下来，连记四周，你就知道自己文笔在往哪走。平均句长往二十字靠，段长往四行靠，对话占比往赛道该有的比例靠。

### 1.7.2 体检表与打分

拿一张表，把前面六条标准逐项打分。每章结束打一次，记下来。打了三五次，你就知道自己最弱的是哪一项。这个记录要连着做，单次说明不了问题，趋势才说明问题。

表 1-3 单章文笔体检表

| 检查项 | 怎么算 | 及格线 |
|---|---|---|
| 信息密度 | 每三百字名词动词数 | 名词不少于十个 |
| 主语稳定 | 一段换几次主语 | 一段不超过一次 |
| 感官在场 | 一段有几个声音气味温度 | 至少一个 |
| 对话活气 | 对话里有没有打断跑题 | 至少一处 |
| 节奏变化 | 最长句与最短句差 | 差十五字以上 |
| 情绪落点 | 段末有没有落到动作物件 | 每段都要有 |

打分开篇别追求全五分，三分及格就行。你的目标是每次都比上一章多一分，而不是一口吃成胖子。文笔这东西，急不得，但停不得。

怎么记？拿个表格，每章结束花两分钟填一行。填一周你就看出趋势了：哪一项在涨，哪一项一直在原地踏步。原地踏步那项，就是你下一个月要练的靶子。

别贪多，一次只盯一项。比如这个月只盯信息密度，那你每段写完就数名词，不够就补。别这个月改密度、下个月改节奏、再下个月又想练对话，结果哪项都没练透。一个月练一项，半年下来六项全通。

练的时候，手边放一个本子，记下你每天改了哪一句。比如今天删了三个“非常”，明天把五个长句拆成了短句。这些记录攒起来，就是你的进步轨迹。一个月后翻回去看，你会发现自己改掉的毛病，比你以为的多得多。

别想着一次把文笔全改好。最弱那一项，连续练十章。信息密度弱，就每段逼自己塞三个具体物件；对话弱，就每段对话加一次打断。十章之后，你会看见变化。

最后一句实话：文笔不是天赋，是手艺。手艺靠练，不靠悟。你今天把体检表用起来，三个月后回头看，自己都会吓一跳。怕的不是写得差，是写完不看。这一点，比什么技法都要紧。

### 1.7.3 三个月后的二次体检

第一次体检只是起点。三个月后，把你当时那章翻出来，和现在新写的一章并排读。不用别人评，你自己就感觉得到差别。那种差别，就是文笔在长。

二次体检多做一件事：把你三个月前最得意的句子挑出来，现在再看，还得意吗？如果觉得脸红，恭喜，你进步了。如果还觉得好，说明你原地踏步。文笔这东西，进步的标志就是看旧稿觉得丢人。不丢人，就是没长。

「本册的用法」：这一部分是地基。后面讲的字词、五感、人物、对话，都是往这六条标准上填砖。你现在不用记所有技法，先把体检表用起来。知道自己哪儿软，后面学到对应的招，才知道往哪儿使。

表 1-4 十条文笔误区速查

| 误区 | 一句话改法 |
|---|---|
| 辞藻堆砌 | 删三个比喻，留一个动作 |
| 告知情绪 | 把情绪词换成动作 |
| 外貌大段堆砌 | 拆成三次，一次一个特征 |
| 全员一个腔调 | 按身份改语气 |
| 段落太长 | 手机屏一段不超过四行 |
| 修饰词失控 | 十句删八个形容词 |
| 比喻陈词 | 陈喻全删，换动作 |
| 写完不读 | 出声读一遍 |
| 比喻太密 | 一句一个比喻 |
| 写完不校 | 查错别字和人称 |

这十条，写完一章过一遍。中了哪条改哪条，别一次全改。一次改一条，改十次就全了。

五赛道的差别，说到底就是词库和节奏的差别。选了赛道，你的词就得跟着换。
