# 16.6 追更互动与读者运营

> 素材来源：novel-material-skill ·《网文写作技巧·文笔篇》16.6 追更互动与读者运营

### 16.6.1 评论回复的分寸

追更互动不是陪聊，是给愿意追的读者一个稳定的预期。本册这一节谈评论回复、断章处理、加更规则。三件事都要有章法，不能凭心情。

评论区每天扫一遍。挑三类回复：一类是提出真问题的，一类是认真分析的，一类是情绪最浓的。其余点赞就够。
- 提真问题的：用正文里的细节回，不剧透下一章。比如读者问“那支簪子是谁送的”，你回“看到第三十章就知道了”。
- 认真分析的：哪怕他分析错了，也要谢他。错的分析是讨论点被激活的证明。
- 情绪最浓的：回一句就够，不要长。长了就变成陪聊，第二天还会有人等着。

不要在评论区吵架。遇到骂文笔的，把他的话记下来，回去翻他说的那一章。如果他指得对，改；指得不对，不回。

评论区还有一种特殊情况：读者之间吵起来了。这时候作者不要下场拉架。让他们吵。吵完他们会自己和解，你一拉，两边都不舒服。

### 16.6.2 断章与加更

断章要有规矩。每卷末留一个大钩，每章末留一个小钩。小钩是段末那一句没说完的话，大钩是卷末那一个没解决的问题。

加更也要有规矩。写死一个数字：日更三千字是底线，状态好的时候多写的存进存稿箱，不用当天就放出来。存稿箱是作者的底气。

|---|---|---|
| 日更正文 | 每日一章，约三千字 | 每天三小时 |

| 存稿箱维护 | 每周补两章 | 每周两小时 |
| 短视频文案 | 每周一条 | 每周一小时 |
| 周复盘 | 每周日一次 | 半小时 |

断章位置的选择也有讲究。不要在动作进行到一半的时候切，那叫吊胃口，读者会反感。要在一个动作做完、情绪刚落地的时候切。读者合上书，心里还留着那一下。

「互动的红线」：不要把评论区当成情绪出口。作者在评论区吐槽，第二天追更的读者会慌。情绪自己消化，回读者的话只说正事。

总有一天会断更。生病、有事、写不动，都可能。断更不可怕，可怕的是断更没有说法。

断更的时候，发一条简短的说明。两句话就够。第一句说停多久，第二句说什么时候恢复。不要长篇大论解释原因，读者不关心。

今天停更一天。明天这个时候见。

就这两句。干净，利落，读者知道你还在。断更超过三天，恢复那天要补一章，不补，读者的信任会掉。

追更的读者分三层。第一层是潜水的，每天看但不说话。第二层是评论的，偶尔说一句。第三层是写长评的，隔三差五写一段分析。

三层读者都要照顾到。潜水的读者靠正文留住，评论的读者靠回复留住，长评的读者靠不打扰留住。

不要把精力全放在第三层。第三层读者最活跃，但他们只占百分之一。百分之九十九的读者是潜水的，他们才是你的基本盘。正文写好，比回一百条长评重要。

还有一种读者，是从别的书过来的。他们会拿你和别人比。不要接这个话。比来比去，你就成了别人的注脚。

你的读者只跟你自己比。今天的章比昨天的章好，明天的章比今天的章好，就够了。
