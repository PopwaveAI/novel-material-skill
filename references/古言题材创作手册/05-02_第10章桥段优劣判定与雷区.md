# 第10章　桥段优劣判定与雷区

> 素材来源：novel-material-skill ·《古言题材创作手册》第10章　桥段优劣判定与雷区

### 10.1　判定四问

一个桥段写完，能不能用，用四问过一遍。四问任何一问答不上来，这个桥段就要回炉。下面把四问摆开，每问给一个反例。

10.1.1　动机是否成立

问的是：推动这个桥段的人，他的动机在当前阶段的关系刻度上立不立得住。反例：初见阶段女主主动给男主送暖炉。她的动机是什么？她还不认识他，送暖炉等于她已经动心了，但初见阶段她不该动心。动机不成立，桥段就删。

10.1.2　阻力是否真实

问的是：桥段里的阻力是外部的，还是作者硬造的。反例：雨中借伞，阻力写成“她心里犹豫要不要接。”这个阻力是虚的，外部阻力应该是雨、是宫门落锁、是伞只有一把。心里犹豫留给旁白带过，场面里只写外部阻力。

10.1.3　代价是否付出

问的是：桥段结束时，其中一方有没有付出一个看得见的代价。反例：宫宴递酒，沈砚递完酒，干干净净回席，什么代价都没有。代价应该是指节发白、是半边肩膀湿了、是把自己半押的账册当众亮出来。没有代价的桥段是甜水，不是糖。

代价的分寸：代价不能太大，太大就是悲剧；不能太小，太小就是甜水。指节发白是刚好的代价，半押账册被当众亮是更大的代价，这两种代价要在不同阶段用。初见用指节发白，身份试探用半押被亮，危机共渡用官袍淋雨。代价随阶段升级。

10.1.4　余味是否留下

问的是：桥段结束时，有没有一个细节能让读者合上书之后还能想起来。反例：并肩定局，两人说完“明日见”就散了，没有留下任何细节。余味应该是那缕按回帽檐下的头发、是伞是干的、是绢上的墨指印。没有余味的桥段，读者三天就忘。

四问的使用顺序：写完一个桥段，先问动机，再问阻力，再问代价，最后问余味。动机不成立，整个桥段删；阻力不真实，换外部阻力；代价没付出，加一个身体细节；余味没留下，加一个可复用的小物件。四问过一遍，这个桥段就能用。

四问还有一个隐藏用法：挑桥段的时候先用四问筛。开书之前，把你想写的所有桥段列出来，每个桥段过一遍四问，四问答不上来的桥段直接从大纲里删掉。不要舍不得，用四问答不上来的桥段，写出来也是雷区。

四问筛法：开书之前用动机、阻力、代价、余味四问筛桥段，筛掉的桥段不要舍不得，写出来也是雷区。

四问筛法的实操：把你想写的所有桥段列在一张纸上，每个桥段后面画四个格子，分别写动机、阻力、代价、余味。哪个格子写不满，那个桥段就回炉。动机格子写不满，说明推动方没立住；阻力格子写不满，说明冲突是虚的；代价格子写不满，说明这个桥段是甜水；余味格子写不满，说明这个桥段读者三天就忘。

四个格子里，代价格子最容易空。新手写桥段，光顾着甜，忘了代价。古言的糖是靠代价撑起来的，没有代价的糖是糖水，读者喝完就忘。代价格子写满，这个桥段才立得住。

要点速记：四问：动机立不立得住、阻力是不是外部的、代价有没有看得见、余味有没有留下；四问答不上来就回炉；反例是送暖炉、心里犹豫、干净回席、说完就散。

### 10.2　雷区桥段清单与原因

下面这张表把古言里最高频的十二个雷区桥段摆开，每条写清雷在哪、怎么改。写完一本书对着这张表搜一遍，搜中一条回改一处。

表 10-1　十二类雷区桥段与改法

| 桥段 | 雷在哪 | 改法 |
|---|---|---|
| 女配下药栽赃 | 人物失真、节奏突兀 | 删掉下药，改成裴据那本账目被沈砚当众亮出来 |
| 女主被推下水男主跳湖救 | 性别观陈旧、人物失真 | 改成御前亮账册，护在公堂 |
| 宫宴当众喊心仪已久 | 节奏突兀、违反礼制 | 改成递一盏温酒，指节发白 |
| 书房夜奔动手 | 违反礼制、人物失真 | 改成磨墨到四更，墨指印留在绢上 |
| 雨中拦马车道歉 | 人物失真、违反礼制 | 改成墙敲三下两下，半炷香拆完误会 |
| 当众撕帖子宣示主权 | 性别观陈旧、节奏突兀 | 改成女主自己退帖子附名帖 |
| 金殿拦婚抢人 | 人物失真、违反礼制 | 改成圣旨顺水，圣旨写官职 |
| 拥抱超过三息 | 言情剧味重 | 改成门槛上一抱，三息内分开各说公事 |
| 赠物反复同款 | 糖太腻 | 赠物全书五次以内，每次物件不同 |
| 女配反复出现栽赃 | 剧本敷衍 | 女配只出现一次，栽赃一次，被拆穿一次 |
| 女主每章哭 | 女主矫情 | 哭全书不超过三次，每次都有外部理由 |
| 男主事业线与感情线脱节 | 两本书感 | 用一个事件把两条线拧到一起，比如半押账册 |
| 桥段里男主内心独白超过两句 | 读者觉得男主话多 | 删独白，张力放动作上 |
| 桥段里配角抢戏超过三句 | 读者跳戏 | 配角只说一句，其余删 |
| 桥段里朝会零推进 | 读者觉得古言没古意 | 朝会桥段必须推进一个不可逆变化 |
| 桥段结尾没有钩子 | 读者划走 | 每个桥段留一个未完成的动作 |
| 桥段环境描写超过半页 | 读者快进 | 环境压缩到三句以内，剩下给动作 |
| 桥段里赠物超过三件同款 | 读者糖腻 | 赠物每次物件不同，全书五次以内 |
| 桥段里拥抱超过三息 | 读者觉得言情剧味重 | 拥抱压缩到三息以内，立刻各说公事 |

这张表的使用方法：每条雷区桥段在自己书里搜一遍，搜中一条就回改。不要想着“下本书注意”，这一本就要改。雷区桥段是会传染的，一处雷处处雷。

雷区桥段为什么会出现：多半是作者写顺了手，抄了言情剧的桥段壳子，没换古言的骨头。言情剧的桥段壳子是拥抱、吻、拦马车、撕帖子，古言的骨头是礼数、立场、代价、余味。壳子抄过来不换骨头，就是雷区。换骨头不换壳子，就是优质变体。

雷区桥段还有一个来源：为了制造冲突而制造冲突。女配下药、推下水、撕帖子，都是为了制造戏剧冲突而硬造的冲突。古言的冲突不需要硬造，朝党之争、账目亏空、礼制规矩本身就是冲突。把冲突交给背景，不要交给女配。

改雷区桥段的笨办法：把雷区桥段的最后一句单独拎出来读。如果那一句读起来像言情剧台词，这个桥段就是雷区；如果那一句读起来像古言奏折，这个桥段就是优质变体。比如“我错了，你回来”是言情剧台词，“账归账，礼归礼”是古言奏折。一句之差，写法天壤。

还有一条判断：把雷区桥段的男主换成一个现代剧男主，成不成立。如果成立，那就是言情剧壳子，是雷区；如果不成立，必须有古言语境才能成立，那就是古言骨头，是优质变体。

判断一个桥段是雷区还是优质变体，有一条简单的标准：把这个桥段放到现代都市剧里，成不成立。如果放到现代都市剧里也成立，那就是言情剧壳子，是雷区；如果放到现代都市剧里不成立，必须有古言语境才能成立，那就是古言骨头，是优质变体。比如“敲墙三下两下”，现代剧里没法敲，必须有诏狱的隔墙才能成立，这就是古言骨头。

要点速记：十二类雷区：下药、跳湖、当众喊心仪、书房夜奔、拦马车、撕帖子、金殿抢婚、拥抱超时、赠物同款、女配反复、女主常哭、双线脱节；搜中一条回改一处。

### 10.3　桥段复用与防重复

同一个桥段在八阶段里可以写多次，但每次写法必须换。下面这张表拿“雨中借伞”做例子，把它在初见、误会后、定局前三个阶段的写法差异摆开。这张表的用法是：你自己书里的任何一个桥段，都可以照这个方法拆。

表 10-2　雨中借伞在三个阶段的写法差异

| 阶段 | 伞的归属 | 淋湿的半边 | 关键动作 | 收尾钩子 |
|---|---|---|---|---|
| 初见试探（身份初立） | 她的伞他撑 | 他右肩湿了 | 他把伞递到她头顶，自己半边淋 | 伞是干的，明天让书吏取回 |
| 误会疏离后（危机共渡） | 他的伞她收 | 他左肩湿了 | 他没用伞，跑着回去的，伞是干的 | 她展开外袍闻到墨香，收进柜没洗 |
| 并肩定局前（心意相通） | 他的官袍 | 他右袖淋了 | 他把官袍脱下来披在她肩上，没扶 | 她站在宫门口看他背影，官袍颜色深了一块 |
| 赐婚高光（三个阶段） | 圣旨/折子/墨指印 | 圣旨写官职 | 折子只写“未娶”二字 | 墨指印压在圣旨底下 |
| 护驾解难（三个阶段） | 御前/诏狱/午门 | 御前亮账册 | 诏狱隔墙敲三下 | 午门披官袍不扶 |

从这张表可以看出，同一个“雨中”，三次写法的差异在四个变量上：伞的归属、淋湿的左右、关键动作、收尾钩子。四个变量换两个，读者就觉得是新桥段；四个变量全换，读者觉得是另一个桥段。
