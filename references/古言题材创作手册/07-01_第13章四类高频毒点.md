# 第13章　四类高频毒点

> 素材来源：novel-material-skill ·《古言题材创作手册》第13章　四类高频毒点

这一部分是古言写作的排雷手册：哪些词一出现读者就骂，哪些观念一写就穿帮，哪些常识错了被考据党追着打，哪些情节踩了平台红线。读完你会有一张按表排雷的清单，投稿前对着过一遍，能躲过九成差评和大半下架风险。

### 13.1　现代语言穿帮

现代语言穿帮是古言差评的第一大来源。不是你文笔不好，是某个词漏了，读者瞬间出戏。下面十二组错例，写成了真实句子的样子，每组给穿帮原因和改法，写完对白逐组对。

表 13-1　十二组现代语言穿帮错例

| 错例 | 为什么穿帮 | 改法 |
|---|---|---|
| 她觉得自己在这段关系里不被尊重 | “关系”“尊重”是今词 | “她只觉得，这日子过得没了脸面” |
| 他很有责任感，答应的事一定办妥 | “责任感”是心理学术语 | “他这人应下的事，从不食言” |
| 她们俩之间有一道看不见的隔阂 | “隔阂”太书面现代 | “两人中间像隔了一层纸” |
| 这件事对她打击很大 | “打击”是现代词 | “这一下，她像被人抽走了筋骨” |
| 她一直在强撑着，不崩溃 | “崩溃”“强撑”是心理词 | “她咬着牙，一日没敢塌下来” |
| 男主第一时间赶到了现场 | “现场”“第一时间”是新闻词 | “得到信儿，他连夜就赶来了” |
| 这家人的教育方式有问题 | “教育方式”是今词 | “这户人家教女儿的法子，太严” |
| 她不想再委屈自己了 | “委屈自己”是今人口头禅 | “她这一回，不想再由着他们了” |
| 他当场就对她刮目相看 | “刮目相看”虽有出处，但太成现代成语 | “他头一回正眼看她” |
| 两个人的价值观不合 | “价值观”是心理词 | “两人的心气，到底是两路人” |
| 她觉得自己被PUA了 | “PUA”是网络词 | “她被他哄得，连自己姓什么都忘了” |
| 这家店的服务态度太差 | “服务态度”是现代 | “这店家待人，太怠慢” |

穿帮句识别：一句台词里只要出现一个你今天上班也会原样说的词，就穿帮。穿帮不靠语感靠对照，写的时候这张表放手边，扫到相似的就换。

这张表会持续更新，你写的过程中每发现一个新穿帮词，就补一行进去。写久了，这张表就是你个人的古言词库，比任何教程都管用。

这十二组的共同点是它们太顺了。顺到作者自己读十遍都不觉得怪。所以不能靠读完判断，要靠逐词挑出来看。把一句台词里的名词、形容词全部圈出来，挨个问：这个词，唐朝、宋朝、明朝的人会说吗？不会，就换。

穿帮词有个规律：越是抽象的词越危险。“关系”“尊重”“责任感”“价值观”这类抽象名词，古人有古人的说法，但意思相近。危险的不是名词本身，是它背后那套现代思维。你换了词，思维还在，读者照样觉得别扭。

所以排雷不能只换词，要换说法。“她不被尊重”换成“这日子过得没脸面”，不只是字换了，连观察角度都从自我评价换成了旁人眼光。古人评价一个人，先看旁人怎么说，不看自我感觉。这个角度换对了，穿帮自然少。

还有一类穿帮是网络流行语。“绝绝子”“破防”“社死”这类词，作者写的时候根本没意识到是今天的话。投稿前把这些词全部搜一遍，哪怕只用了一次，也要删。读者看到一句网络梗，对整本书的信任就崩了。

除了词，还有句式穿帮。现代的“不是……而是……”“与其说……不如说……”这种长句式，古人不这么说话。把一句台词拆成短句，句式自然就古了。句式比词汇更难自查，因为你天天这么说话，已经麻木了。

排雷的节奏建议放到改稿环节。第一稿只管写，第二稿专门扫今词和今句式。两遍分开，比一边写一边改效率高。写的时候被一个词卡住，节奏就断了；写完集中扫，一遍能扫出几十个。

最后提醒一句：旁白可以今，对白必须古。叙述语言你怎么顺怎么来，读者不挑；但人物一开口，必须立刻切回旧腔。这道线划在引号上。引号外白话，引号内旧话，两不耽误。

穿帮还有个隐形来源是成语。很多成语今天还在用，但古人不这么用。“刮目相看”“一见钟情”“无可奈何”这类，写进对白就成了现代翻译腔。对白里少用四字成语，宁可拆成大白话。

最后给一个排雷的小工具：把你的对白单独抽出来，连成一篇读。读着读着出戏的地方，就是穿帮点。这个方法比逐词查更快，因为穿帮的句子连在一起读，违和感会被放大。

要点速记：现代语言穿帮排第一；十二组错例逐组对；穿帮不靠语感靠逐词对照；名词形容词圈出来挨个问是不是古人会说的话。

### 13.2　现代观念穿帮

比语言穿帮更致命的是观念穿帮。语言错了读者皱眉，观念错了读者直接弃书还骂你不尊重历史。古言的壳子下，装的若是一整套现代个人主义，读者一眼就看穿。

这一节给五类最常见的观念穿帮，每类配错例和古装化的替代写法。照着装，就能把现代腔换成旧瓶装新酒。

13.2.1　个人主义宣言

错例：“我命由我不由天，凭什么你们安排我的婚事。”这句话放在仙侠里尚可，放在宅斗古言里就出戏。古人不这么说话，古人说“父母之命媒妁之言”是天经地义，她要反抗，也得用这个时代能懂的话反抗。

古装化替代：“我知道爹娘是为我好，可这门亲事，我死也不从。”反抗的意志没变，但话术换成了时代的语言。她用“死也不从”表决心，而不是用“我命由我”这种现代宣言。

13.2.2　平等口号

错例：“丫鬟也是人，凭什么低人一等。”平等观念是现代的，古言里主仆有别是制度。你可以写女主善待丫鬟，但不能让她当众宣讲人人平等。读者要看的是她的善，不是她的政治觉悟。

古装化替代：“她跟了我八年，不是奴才，是我的姐妹。”善待的意思到了，用的是“跟了八年”“姐妹”这种旧说法，没有喊平等口号。

13.2.3　成功学话术

错例：“女人一定要独立，要经济独立，不然迟早被抛弃。”这套话是今天的女性自媒体。古言女主可以自强，但她的动力是在这个时代活下去，不是喊独立口号。

古装化替代：“我手里得有自己的铺子，不然哪天被休了，连口饭都吃不上。”动机是真实的处境，话术是时代的，读者会信。

13.2.4　心理咨询话术

错例：“你这是原生家庭带来的创伤，需要和过去和解。”心理咨询是现代舶来品。古言里人处理心结，靠的是时间、是陪伴、是一桩具体的事，不是名词解释。

古装化替代：“你心里那道坎，旁人替不了你。但我可以陪你，慢慢跨过去。”意思到了，词换了。

13.2.5　职场术语

错例：“这个项目的KPI完不成，这个团队要背锅。”职场术语进古言，穿帮最快。古言里办差、当差、交差，没有项目、KPI、团队。

古装化替代：“这趟差事办砸了，咱们几个都得担责。”意思一样，词全换。

观念穿帮的根源，是作者拿今天的价值观去套古人的处境。你要写一个有现代意识的女主，可以，但她的意识得在这个时代里发芽，不能是空降的。她可以不满包办婚姻，但她反抗的方式是绝食、是逃婚、是找个相熟的长辈求情，不是站在堂屋宣讲恋爱自由。

判断一段观念是否穿帮，用一个标准：这句话放到今天也成立吗？如果成立，那它多半是现代观念溜进来了。古言的好句子，必须带着那个时代的具体困境，离开那个时代就不成立。

但也别矫枉过正。古言的女主可以有超越时代的见识，这正是读者爱看的地方。区别在于：她的见识是她自己悟出来的，不是作者空降的。她读过书、见过世面、吃过亏，所以想得比旁人远。这个成长过程写出来，读者就不觉得穿帮。

最怕的是女主一出场就站在现代价值观制高点，对着古人的生活指指点点。她要融入这个时代，在时代里挣扎，再慢慢长出自己的想法。让现代意识从土里长出来，不要从天上掉下来。

还有一类观念穿帮是经济账。古人不会天天把“赚钱”“投资”挂在嘴边，但女主可以会算账。区别在于：她算的是这月的胭脂钱够不够，不是“这笔投资的回报率。”同样是精明，说法要落在她的日子上，不要落在商业术语上。
