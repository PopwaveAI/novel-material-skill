# 第27章　四组定稿自检清单

> 素材来源：novel-material-skill ·《古言题材创作手册》第27章　四组定稿自检清单

| 检查项 | 判定标准 | 不合格怎么办 |
|---|---|---|
| 时间线闭合 | 从开篇到结局的时间跨度对得上角色的年龄 | 把年龄不对的角色生日或者事件年份改对 |
| 信息来源清楚 | 主角知道的每件事都有合理的获取渠道 | 补一场她怎么打听到这条消息的戏 |
| 身份不飘 | 她当前的官位或者诰命跟她做的事匹配 | 把超出她身份的事改成旁人替她做 |
| 银钱对得上 | 主角的花销跟她家的家底量级一致 | 把超出量级的大额花销改成小额，或者补一段她怎么挣的 |
| 因果链不断 | 每个大事件都有前因，不是凭空冒出来 | 在事件前三章补一段它的起因 |
| 反应合乎身份 | 配角听到消息的反应跟他的身份和性格一致 | 把反应过度的配角改成他该有的冷静或者冷漠 |
| 误会能解开 | 所有误会在合理解释下一章内能解 | 把解不开的误会改小，让它一章内散掉 |
| 死的人真死 | 前面写死的角色后面没有莫名其妙复活 | 把复活的人改成长得像他的远亲 |
| 伤好得合理 | 重伤之后至少养了合理的天数再出场 | 把养伤期太短的角色在中间补一段卧床戏 |
| 规矩不穿帮 | 女主做出格的事之后有合理的代价显出来 | 在出格戏之后补一段旁人议论或者官府追究 |

因果链：故事里每一个大事件都能往前追到一个起因，不是作者想让它发生它就发生。断链是读者弃书的高频原因。

这一组里最隐蔽的是信息来源清楚。主角怎么知道这条消息的？作者自己知道，所以写主角说出来的时候顺理成章。但读者不知道她怎么知道的，会觉得作者开了天眼。每一条关键消息，都要在前面留一个她打听到的渠道。可以是丫鬟跑腿听来的，可以是门客在外查回来的，可以是对手内部有人反水。渠道一补，主角的聪明就立得住。

另一个隐蔽的坑是银钱对得上。女主一个五品官家的小姐，一出手就是一万两银子请人办事，读者会立刻出戏。古言的读者对银钱量级很敏感。你得先在前面交代她家一年进项是多少，再写她花多少钱。超出量级的大钱，要么改成小额，要么补一段她怎么临时弄到这笔钱。

再补一个：死的人真死。作者写死人的时候常常写得含含糊糊，怕后面舍不得删这个角色。含含糊糊的死，读者会觉得这个人后面还要出来。结果真的不出来了，读者会觉得作者烂尾。要么写死就写透，要么干脆别写死。写透的标志是：有旁人替他收尸，有主角在他坟前说过一句话，后面再没有人提起他的时候还带着那种人已经走了的语气。

要点速记：逻辑自检十条顺着时间线推；最容易漏的是信息来源、银钱量级、规矩代价；写死的人不能复活，误会必须一章内解开。

### 27.4　合规自检

这一组检查的是这本书发出去会不会被平台或者读者挑出毛病。不是法律意见，是平台常见的几条红线。交稿前过一遍，避免上架之后被下架重改。

合规自检这一组，作者最容易犯的错是觉得自己写的是架空朝代不会有事。架空只是朝代架空，不是现代审核架空。平台的红线跟朝代没关系，跟写出来的东西本身有关系。哪怕你写的是一个完全虚构的王朝，里面写了床戏写实、未成年恋爱、影射真实事件，该卡还是会卡。架空只是帮你躲开了具体历史人物的雷，没有帮你躲开内容本身的雷。

表 27-4　合规自检八条

| 检查项 | 判定标准 | 不合格怎么办 |
|---|---|---|
| 无真实朝代影射 | 不影射、不影射真实历史人物的具体事迹 | 把影射的具体人名改成架空名，事迹打散 |
| 无真实地名敏感 | 不写真实当代地名里的真实敏感事件 | 把地名换成架空地名，事件虚化 |
| 暴力不过度 | 虐打、刑讯的描写不渲染细节，点到即止 | 把细节段改成结果段，不写过程 |
| 床戏不写实 | 亲密戏停在关灯或者天亮之前 | 把中间段删掉，用一个转场跳过去 |
| 不美化封建糟粕 | 裹小脚、殉葬、典妻这类事不写成浪漫 | 给这类事加一段主角的反抗或者旁观的不适 |
| 未成年不恋爱 | 主角双方明确年龄在成年之后 | 把成婚前的年龄改成十八岁以后 |
| 无真实品牌 | 不出现真实商号、真实药品、真实食物品牌 | 把真实品牌名改成架空的字号 |
| 不涉宗教敏感 | 不影射真实宗教的具体仪轨 | 把宗教仪轨改成架空的礼法 |

平台红线：免费小说平台审核时常见的几条硬线。踩中会被要求改稿，严重的会整本书下架。作者交稿前自己先过一遍。

这一组里最容易踩的是床戏不写实。作者写到两人定情那一夜，常常忍不住想把过程写细。平台的规则是停在关灯之前。写得再美，过了那条线就会被要求删。删掉的戏会影响前后文衔接，不如一开始就写在关灯那里，用一个转场跳到第二天早上。

另一个高频是未成年不恋爱。古言里古代女子十五六岁出嫁是常事，但放到当代平台审核里，这个年龄会被卡。保险的做法是把婚前的年龄模糊掉，或者直接设定成双方都已成年。女主可以写她“及笄两年”，男主写他“弱冠之后”，既符合古言气质，又过得了审。

再补一条：不美化封建糟粕。古言的背景本身就是一个讲规矩的时代，作者写着写着容易把那些糟粕写成浪漫。比如写女主裹着小脚走得娇弱，写男主把女主当物件赏玩，写婆婆打儿媳是天经地义。这些事在当代读者眼里是雷。处理方法不是删掉，而是让主角对这些事有反应。女主被要求裹脚的时候皱一下眉，男主看到婆婆打儿媳的时候站出来说一句。反应一有，作者的立场就清楚了。

要点速记：合规自检八条半小时过完；最容易踩的是床戏写实、未成年恋爱、真实朝代影射；拿不准的就改虚，不要存侥幸。
