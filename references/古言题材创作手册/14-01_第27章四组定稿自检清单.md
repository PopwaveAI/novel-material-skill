# 第27章　四组定稿自检清单

> 素材来源：novel-material-skill ·《古言题材创作手册》第27章　四组定稿自检清单

这一部分是交稿前最后一道关。四组共四十四条可以一条条勾的检查项，加上三轮通读法和一张能填的终检记录表。读完你能在交稿前的最后一个晚上，对着清单把整本书过一遍，把还能发现的硬伤全部堵在发出去之前。

### 27.1　排版与形式自检

这一组检查的是看得见但不涉及内容的硬伤。这些错误读者不会明说，但会在评论区用“读着累”“跳戏”“看不懂”这种模糊的话吐出来。交稿前对着表勾一遍，半小时能过完。

排版自检这一组，作者最容易犯的错是觉得这些事不重要。觉得只要故事好，段落长一点、称呼飘一点没关系。其实不是。读者在手机上读，屏幕就那么大。段落一长，他的眼睛就累。称呼一飘，他就要停下来想这个人是谁。这些小动作加起来，就是他决定要不要切出去的那一秒。

表 27-1　排版与形式自检十二条

| 检查项 | 判定标准 | 不合格怎么办 |
|---|---|---|
| 章节编号连续 | 从第1章到最后一章没有跳号、没有重号 | 把断号那一章补上，或者把重号那章重新编号 |
| 每章字数均匀 | 最长一章不超过最短一章的两倍 | 把过长的章拆成两章，过短的章并到下一章 |
| 章末有钩子 | 每一章最后一段不是平铺直叙的收尾 | 在最后一段加一句留给下一章的悬念 |
| 对话不连排 | 同一场对话没有超过连续十行无旁白 | 在对话之间插入动作、表情或者环境描写 |
| 段落不堆墙 | 没有连续三段以上超过一百五十字的长段 | 把超长段拆成两段，中间加一句短的 |
| 人名统一 | 同一个角色全书只用一个名字，没有中途改名 | 把后面出现的别名全部替换成主名 |
| 称呼统一 | 丫鬟对女主的称呼前后一致，没有一会小姐一会夫人 | 按身份阶段统一改，婚前婚后分两段 |
| 时间线词无矛盾 | 今天、明日、三日后这类词前后接得上 | 把整章的时间词列在草稿纸上顺一遍 |
| 标点全角 | 全书用中文标点，没有半角逗号半角句号混排 | 用编辑器的全半角转换一次过一遍 |
| 无错字漏字 | 通读时没有读到读不通顺的句子 | 把可疑句单独抄出来逐字对 |
| 分段空行正确 | 每段之间有空行，段内不再多空 | 把多余的空行一次删掉 |
| 章题统一格式 | 所有章题都是“第N章 标题”，没有漏字没有多字 | 把所有章题列出来统一改一遍 |

排版硬伤：读者读得出来但说不清楚的那种不舒服。它不是剧情问题，是形式问题，包括章号断、段落长、称呼飘、时间词打架这一类。

这一组里最容易被作者自己忽略的是章末钩子。作者写完一章，常常觉得事情讲完了就可以收尾。但对读者来说，一章结束的地方就是他考虑要不要切出去的那一秒。收尾太满，他就走了。收尾留半句，他才会点下一章。

另一个容易漏的是称呼统一。丫鬟在女主婚前叫小姐，婚后叫夫人。这中间的切换点是拜堂那一天。拜堂之前的最后一章她还是小姐，拜堂之后的第一章她就是夫人。作者写嗨了常常在拜堂前两章就提前叫夫人，读者会觉得穿帮。

还有一条要单独拎出来说，就是段落不堆墙。作者写到情绪上头的时候，常常一段连着一段，每段都超过两百字。读者手机屏幕上一屏只能看几百字，一堵墙压过来，他就想往下滑。拆段的技巧很简单：一段里只要换了一次视角或者换了一个动作，就另起一段。不要舍不得空行。

要点速记：排版自检十二条半小时过完；最容易漏的是章号连续、章末钩子、人名统一；错字要靠通读抓，不要靠搜索。

### 27.2　内容自检

这一组检查的是故事本身有没有塌。它不是看文笔，是看故事的骨架有没有立住。这一组要慢，两小时能过完。

内容自检这一组，作者最容易犯的错是舍不得删。写到两百章的时候，前面有些支线其实已经收不回来了，但作者觉得删了可惜，硬留着。留着的结果是读者一直惦记那条没收的线，看到结局都觉得欠着。交稿前这一组检查，就是要狠下心把收不回来的支线砍掉。砍的时候心疼，发出去之后读者会感谢你。

表 27-2　内容自检十四条

| 检查项 | 判定标准 | 不合格怎么办 |
|---|---|---|
| 开篇有钩子 | 第一章前三百字内出现主角的具体处境 | 把开头铺陈的段落砍掉，从出事那一段起笔 |
| 女主立得住 | 前三章内女主有一次自己做主的选择 | 补一场她顶住压力自己拿主意的戏 |
| 男主动机清楚 | 读者能一句话说清男主为什么留在女主身边 | 在男主视角段里补一句他心里的算盘 |
| 感情线有台阶 | 两人关系有可见的刻度变化，没有原地踏步 | 在中段补一场让关系不可逆往前一步的戏 |
| 反派有后手 | 反派至少做过两次让主角真正吃瘪的事 | 补一场反派先手得手的戏，不要让主角一路赢 |
| 配角不工具 | 至少两个配角有自己跟主角无关的小目标 | 给每个主要配角加一段他自己的私事 |
| 爽点均匀 | 每一万字至少有一次让读者解气的小爽点 | 把连续超过一万字的憋屈段落拆开，中间塞一个小爽 |
| 虐不悬空 | 虐之前有铺垫，不是为虐而虐 | 在虐戏前三章埋一条主角在意的东西 |
| 甜有铺垫 | 甜戏不是突然撒糖，是前面攒出来的 | 在甜戏前补两章两人之间的小动作 |
| 支线不喧宾 | 副CP和配角线加起来不超过主线三成篇幅 | 把过肥的支线砍掉一半，关键场面保留 |
| 名场面落实 | 书里自己承诺过的关键场面都写到了 | 翻回大纲把漏掉的名场面补上 |
| 女主不圣母 | 她的善良都付出了代价，不是无脑救人 | 给她救过人之后的代价写一段 |
| 男主不OOC | 他做的事跟他前面立起来的人设对得上 | 把崩人设那场戏改成更符合他的做法 |
| 结局回收开篇 | 最后一章正面回答了开篇提出的那个问题 | 在结局最后一场戏加一句点题 |

OOC：人物做了跟他前面立起来的人设完全不符的事。读者一眼能看出来，是古言最伤的内容硬伤之一。

这一组里最要命的是女主不圣母这一条。古言读者对圣母女主的忍耐度比想象中低得多。她救一次人，后面必须有相应的代价。代价可以是被救的人反咬，可以是她自己因此错过了重要的时机，可以是她为此被旁人误解。没有代价的善良，读者会直接在评论区骂掉智。

还有一条容易踩的是爽点均匀。作者写爽文常常憋着一大段，想在结尾一次性爆出来。但免费平台的读者等不到结尾。每一万字至少要给一次小爽点，哪怕是一次小反击、一次小打脸、一次小翻身。把大爽点拆成小爽点散在中间，读者才不会在中途弃书。

再补一条经验：女配不能全坏。古言写到女配，作者常常忍不住把她写成一个脸谱化的恶人。但全程坏到底的女配是没有生命力的，读者看完不会记得她。给女配留一个她自己的执念，哪怕这个执念很蠢，她也会从纸片人变成真人。读者记住一个复杂的女配，比记住一个坏透的女配，更愿意写长评。

还有男主动机清楚这一条。男主为什么留在女主身边，作者自己心里要有一句话的答案。这个答案不必告诉读者，但作者自己必须知道。知道了，写男主每一次出手的时候才有底气。不知道，男主就会写着写着变成作者手里的提线木偶，读者一眼看得出来他是为了剧情需要才出现的。

要点速记：内容自检十四条要两小时；开篇钩子、女主立得住、感情线台阶是最容易塌的三处；女主善良必须付代价，男主不能崩人设；结局必须回收开篇。

### 27.3　逻辑自检

这一组检查的是事情讲不讲得通。读者逻辑一乱就弃书，而且弃得无声无息。这一组要顺着时间线从头推一遍。

逻辑自检这一组，作者最容易犯的错是默认读者跟自己一样知道全本书的设定。作者自己知道主角小时候经历过什么，知道反派为什么恨女主，知道那笔银子是从哪来的。但读者是跟着正文一点点看的，他不知道。每写一个主角做了决定的段落，停下来问自己一句：读者现在手里有做出这个决定需要的信息吗？没有，就在前面补一段。
