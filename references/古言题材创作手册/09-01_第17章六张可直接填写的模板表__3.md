# 第17章　六张可直接填写的模板表

> 素材来源：novel-material-skill ·《古言题材创作手册》第17章　六张可直接填写的模板表

| 检查项 | 判定标准 | 不合格的修法 |
|---|---|---|
| 男女主是否每三章见过一面 | 十章里至少三章两人同场 | 连续三章不见面就安排一次远远的照面 |
| 关系刻度有没有动 | 十章结束时两人关系比十章前多一笔账 | 没动就加一次越界或一次退让 |
| 外部事件线有没有推进 | 十章里朝廷或宅斗那条线至少露一次脸 | 没露就加一封书信或一句传闻 |
| 新人物有没有真实诉求 | 本章新出场人物说得清他要什么 | 说不清就合并到老人物身上 |
| 伏笔有没有回收 | 十章里至少收一条之前埋的伏笔 | 没收就把最近的一条提前收了 |
| 礼教有没有剥一层 | 十章里至少破一次之前列的束缚 | 没破就让主角碰一次红线 |
| 评论区话题有没有埋 | 十章里至少留一个可站队的细节 | 没留就在关键动作后加一个反常细节 |
| 章末有没有钩子 | 每章末两句不是总结式收尾 | 是总结就改成切在动作或台词后 |
| 有没有连续三章同场景 | 十章里场景至少换过两次 | 没换就安排一次出门赴宴 |
| 有没有连续三章贴同一视角 | 十章里至少切一次另一人物视角 | 没切就写一章男主视角 |
| 对白有没有今词 | 把本章对白单独抽出来对一遍词表 | 有今词就换旧说法 |
| 有没有旁白替人物说话 | 本章里删掉所有“她心里又甜又苦”式句子 | 有就改成动作 |
| 人物称呼有没有升降 | 本章里至少有一次称呼的变化 | 没有就安排一次称呼的回退或拉近 |
| 反派是不是纸片人 | 反派本章有没有一处显出他的难处 | 没有就加一个他独处的小动作 |
| 章号区间和节点表对不对得上 | 这十章落在节点表的哪个格子里 | 对不上就调整节点表 |

这张表的用法是每十章跑一次，不要日跑。日跑会变成负担，而且看不出问题。每十章找一个下午，把这十五项逐条勾一遍，勾到不合格的当场记下来，下周写新章的时候先补。

十五项不要平均用力。其中有三项是一票否决：章末有没有钩子、关系刻度有没有动、外部事件线有没有推进。这三项里有一项不合格，这十章就算白写，其他项勾得再漂亮也没用。先查这三项，再查其他十二项。

自检表跑出来的结果，不要只看不合格项，要看连续不合格项。如果连续三个十章，“章末钩子”这一项都不合格，说明你不是某几章没写好，是你的断章手法已经形成了坏习惯。这时候要停下来，把最近三十章的章末全部拉出来，对着 15.3 节的六种模板重写一遍。

十五项里最容易被忽略的是最后一项：章号区间和节点表对不对得上。写着写着经常写飞，节点表排在第 30 章的事，写到第 25 章就发生了。对不上不要硬改正文，回头调整节点表，把它挪到第 25 章。

自检表跑出来的不合格项，不要试图在当天补。当天该写的章已经写完，回头改稿会把节奏打乱。把不合格项记到下周的节点表里，下周写新章的时候顺手补进去。补得自然，不像是事后补丁。

要点速记：自检表十五项固定，每十章跑一次。最容易漏的是“和节点表对不对得上。”勾到不合格当场记下来，下周写新章先补这一项。
