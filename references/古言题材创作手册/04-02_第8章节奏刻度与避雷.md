# 第8章　节奏刻度与避雷

> 素材来源：novel-material-skill ·《古言题材创作手册》第8章　节奏刻度与避雷

### 8.1　全书节奏刻度表

八阶段排进一本书，要按篇幅折算。同样的八级台阶，三十万字的长篇和六万字的短篇，节奏密度完全不同。长篇可以在误会疏离停十章，短篇停三章读者就嫌拖。下面这张表是折算后的章节数和字数，直接抄进自己的大纲里就能用。

表 8-1　三档篇幅下八阶段的章节数与字数折算

| 阶段 | 30万字长篇（章数/字数） | 15万字中篇（章数/字数） | 6万字短篇（章数/字数） |
|---|---|---|---|
| 初见试探 | 3章/约3万 | 2章/约1.5万 | 1章/约6千 |
| 身份试探 | 4章/约3.5万 | 2章/约2万 | 1章/约8千 |
| 心动克己 | 4章/约3.5万 | 2章/约2万 | 1章/约8千 |
| 情愫暗生 | 5章/约4.5万 | 3章/约2.5万 | 1章/约1万 |
| 误会疏离 | 4章/约3.5万 | 2章/约2万 | 1章/约8千 |
| 危机共渡 | 5章/约4.5万 | 3章/约2.5万 | 1章/约1万 |
| 心意相通 | 3章/约2.5万 | 2章/约1.5万 | 1章/约6千 |
| 并肩定局 | 4章/约4万 | 2章/约2万 | 1章/约4千（收束） |

表格读法：长篇每章约一万字，中篇每章约七千五百字，短篇每章约六千字。短篇的合并要诀是把初见和身份试探压进同一章，把心动克己和情愫暗生压进同一章，把心意相通和并肩定局压进同一章。压的时候不要砍事件，要砍环境描写和旁人议论。

节拍密度：单位字数内事件发生的频次。长篇节拍密度低，短篇节拍密度高。判断一本书节拍对不对，看每一万字有没有至少一个不可逆变化。

要点速记：长篇八阶段可拉三十章；中篇压成十六章；短篇压成八章；压阶段不压事件，砍环境描写不砍动作；每一万字必须有一个不可逆变化。

### 8.2　情礼拉扯密度控制：五级越界

情礼拉扯不是凭感觉写的，要拆成五级。每一级越界都有升级条件和冷却期，跳级读者会觉得突兀，不升级读者会觉得原地踏步。下面这张表是五级的完整刻度，从目光到独处，逐级放行。

表 8-2　五级越界的升级条件与冷却期

| 级别 | 越界内容 | 升级到下一级的条件 | 冷却期（千字） |
|---|---|---|---|
| 一级目光 | 对视超过三息 | 被第三方撞见过一次 | 5千 |
| 二级言语 | 用小字称呼、说一句超出公事的话 | 目光越界累计出现三次 | 8千 |
| 三级接触 | 功能性肢体接触，指尖、臂弯、伞柄 | 言语越界累计出现五次 | 1万 |
| 四级赠物 | 送一件不能退回的小物件，茶、笔、纸条 | 接触越界累计出现三次 | 1.5万 |
| 五级独处 | 无第三人共处超过一炷香，且有公事外壳 | 赠物被收下一次 | 2万 |

冷却期的意思是：上一次发生该级越界之后，多少千字之内不能再发生同级别越界。冷却期内可以写下一级，不能重复上一级。比如一级目光冷却五千字，意思是这五千字之内不要重复写“她抬眼他也抬眼”，但可以写二级言语。

五级的上限是：全书目光越界不超过五十次，言语越界不超过三十次，功能性接触不超过十次，赠物不超过五次，独处不超过四次。超出任何一项，读者都会觉得“这两个人怎么这么多戏。”

每一级升级失败会怎样，摆开说清楚。

升级失败：越界级别该升不升、或者升过了头。该升不升读者觉得原地踏步，升过了头读者觉得跳级。两种失败都要修。

一级目光升级失败：目光越界冷却期内重复写对视，读者觉得糖腻。补救是删掉重复对视，把同一章目光次数压到三次以内，留最关键的那一次。

二级言语升级失败：还没用小字就用了“你我”，人物关系跳级。补救是把“你我”改回“大人”和“崔姑娘”，等目光越界累计三次之后再放小字。

三级接触升级失败：接触越界没有功能性理由，比如无缘无故拉手。补救是把接触改成递东西时指尖相碰，接触之后立刻收回，不超过一息。

四级赠物升级失败：赠物被退回，或者赠物太贵重。补救是赠物改成小物件，茶、笔、纸条，被退回也不写，留到第二天书吏取回去那一笔。

五级独处升级失败：独处没有公事外壳，两个人在书房你侬我侬。补救是独处必须有核账、避雨、对案卷的外壳，外壳不成立就删这场独处。

数越界的笨办法：写完一章之后，回翻一遍，把所有“他抬眼”、“她抬眼”、“对视”、“指尖相碰”、“伞柄递过来”、“她递茶他没退”这些动作画出来，数一遍次数。同一章里目光越界超过三次，就删一次，留最关键的那次。赠物超过两次，就把其中一次改成“打算送但没送成”，留那个遗憾。

五级越界还有一个隐形规则：降级比升级重要。危机共渡那一段五级全开，但心意相通之后要主动降回三级，把接触级压下来，把言语级压下来。一直升级到并肩定局，读者会糖瘾上头，反而记不住最后那个按头发的动作。降级的过程就是收束的过程。

冷却期：同级别越界之间的最小字数间隔。冷却期内重复同级别越界叫“刷屏”，读者会觉得糖太腻。

要点速记：越界分五级：目光、言语、接触、赠物、独处；每级有升级条件和冷却期；全书上限：目光50、言语30、接触10、赠物5、独处4；冷却期内写下一级不写同级别。

### 8.3　阶段跃进的加速与代价

有时候必须加速，比如平台要求十五万字内完结，比如编辑要求把八阶段压到十二章。加速不是删事件，是跳过冷却期。跳过冷却期有三种写法，每种写法都有代价，也都有补救。下面这张表把三种加速写法摆开，作者自己选。

表 8-3　三种阶段跃进的加速写法、代价与补救

| 加速写法 | 适用场景 | 代价 | 补救动作 |
|---|---|---|---|
| 合并阶段 | 把两个相邻阶段压进同一章 | 不可逆变化稀释，读者感觉“没踩实” | 合并时在章末加一个“第三方背书”，比如老吏一句“这两人近来不对劲” |
| 提前越界 | 让上一级越界在冷却期内重复出现 | 糖太腻，读者弃书 | 提前越界必须用外部事件包裹，比如雨中、病中、诏狱中，不是日常场合 |
| 跳过克己 | 心动克己阶段直接进入情愫暗生 | 人物定力崩塌，男主恋爱脑 | 跳过克己要补一场“装作没发生”的戏，第二天照常坐衙，眼神多停半拍 |

三种写法不要同时用。一本书最多用一种加速写法，用两种读者就觉得节奏乱。用了加速写法，就要在后面的阶段补回一次冷却期，比如情愫暗生阶段多停五千字，让读者喘口气。

加速的判断标准：如果加速之后读者在评论区说“好甜”，说明加速成功；如果说“怎么这么快”，说明加速太猛，退回去两千字。

要点速记：加速三招：合并阶段、提前越界、跳过克己；一招只用一次；用了加速就在后一阶段补冷却期；评论区说“好甜”是成功，说“怎么这么快”是太猛。

### 8.4　古言节奏避雷清单

节奏写崩有十种典型症状，每种症状读者的反应和修法都摆在下面这张表里。写完一本书对着这张表查一遍，能救回大半弃书读者。

表 8-4　古言节奏十大避雷清单

| 症状 | 读者反应 | 修法 |
|---|---|---|
| 前三章就告白 | 读者觉得后面无事可写 | 把告白挪到并肩定局，前三章只留记忆点 |
| 误会超过十章 | 读者骂“怎么这么能憋” | 把误会压缩到八章以内，中间用一次危机共渡碾碎 |
| 男主在心动阶段就当众护短 | 读者觉得男主恋爱脑 | 护短改为暗中站台，等危机共渡再公开 |
| 女主每章都在哭 | 读者觉得女主矫情 | 哭的次数全书不超过三次，每次都要有外部理由 |
| 女配反复栽赃 | 读者觉得剧本敷衍 | 女配只出现一次，栽赃一次，被拆穿一次 |
| 男女主私下频繁见面 | 读者觉得节奏太快 | 每次私下见面都要公事外壳，否则删 |
| 朝会场景写得像背景板 | 读者觉得古言没有古意 | 朝会每次出现至少推进一个不可逆变化 |
| 赠物反复出现同款 | 读者觉得糖太腻 | 赠物全书五次以内，每次物件不同 |
| 拥抱超过三息 | 读者觉得言情剧味重 | 拥抱压缩到三息以内，立刻各说公事 |
| 定局靠皇帝赐婚 | 读者觉得外部强加 | 赐婚放在站队之后，作为顺水推舟 |
| 每章朝会零推进 | 读者觉得古言是背景板 | 朝会每次出现至少推进一个不可逆变化 |
| 配角戏份超过男女主同场 | 读者跳戏 | 配角单章戏份不超过男女主同场的一半 |
| 事业线与感情线各走各的 | 读者觉得两本书 | 用一个事件把双线拧到一起 |
| 男主内心独白超过两段 | 读者觉得男主话多 | 删独白，只写动作 |
| 每章结尾没有钩子 | 读者划走 | 每章结尾留一个未完成的越界 |
| 环境描写超过半页 | 读者快进 | 环境压缩到三句以内，剩下给动作 |
