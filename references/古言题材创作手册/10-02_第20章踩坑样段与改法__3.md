# 第20章　踩坑样段与改法

> 素材来源：novel-material-skill ·《古言题材创作手册》第20章　踩坑样段与改法

### 20.11　仿写与踩坑的常见疑问

这一节把作者在仿写过程中最常问的几个问题集中答一遍。

问：仿写是不是抄袭？答：不是。抄袭是把别人的句子搬过来，把人名换了。仿写是把别人的骨架拆出来，自己换一件事、换一个人、换一个场面。判断标准很简单：你写完之后，把人名遮住，还能不能认出这是别人的书？能认出，就是抄袭；认不出，就是仿写。

问：八个样段我都仿完了，下一步怎么办？答：不要再仿了。八个样段够你练三个月。三个月之后，你应该开始写自己的场面，写完再回头对照八个样段，看自己少了哪件。仿写的目的是脱离仿写，不是永远仿写。

问：我写的段落改完之后，为什么还是不如样段有味道？答：多半是判断层没到。你四件套凑齐了，节奏也对了，但你写的事不够具体。样段里的事是“漕司新换的印”“袖口磨出一道浅痕”“灯芯剪得很短”，全是能拿在手里的东西。你写的事如果是“他很温柔”“她很感动”，那不是事，是情绪。把情绪换成物件，味道就出来了。

问：反面样段我都看了，为什么自己写的时候还是会犯？答：因为看是看，写是写。你写的时候手里没有自查清单。下面这张表是一张随身清单，写完一段就对照一遍。

表 20-3　仿写随身自查清单

| 检查项 | 问自己 | 不合格时怎么改 |
|---|---|---|
| 事 | 这段里有没有一件能拿在手里的具体的事 | 没有就加一件，删掉所有情绪词 |
| 话 | 有没有一句能被读者原样复述的短话 | 没有就把长台词拆短，留最狠的一句 |
| 动作 | 有没有一个不动声色的动作 | 没有就把情绪词换成动作 |
| 留白 | 结尾有没有一处同时闭嘴 | 没有就把最后一句台词删掉，换一个沉默 |
| 现代词 | 有没有“机会”“好感”“幸运”“风景” | 有就换成具体的事或物 |
| 光环 | 有没有所有人都给他面子 | 有就加一个对手，加一个质疑 |
| 独白 | 有没有“她知道这一辈子……” | 有就删掉，换成一个动作 |

最后说一句。案例库不是拿来读的，是拿来用的。你读十遍，不如自己写一段然后对照一遍。古言这门手艺，是手上的功夫，不是眼睛的功夫。

要点速记：仿写不是抄袭，是换骨架不换句子；八个样段够练三个月；改完还是没味道多半是事不够具体；随身对照清单：事、话、动作、留白、现代词、光环、独白。

问：我仿完之后，怎么判断自己的段落够不够格？答：把你写的段落和这一章的八个样段并排放在一起，读三遍。第一遍读感觉，看你写的段落和样段放一起显不显怯。第二遍拆四件套，看你凑齐了没有。第三遍找关键句，看你能不能指出删掉哪一句整段塌掉。三遍都过，及格；有一遍不过，回去改。

问：反面样段里的毛病，我怎么知道自己写没犯？答：写完一章，把这一章里所有“她如何如何”“他如何如何”的句子圈出来，数一下。超过五句，这一章就有旁白抒情的病。再把所有对话里的“我”“你”圈出来，数一下连续对话超过三句没有动作，就是台词堆砌。这两个动作花不了十分钟，能挡掉一半的毒点。

要点速记：判断自己够不够格：并排读三遍，感觉、四件套、关键句；自查旁白抒情和台词堆砌，十分钟挡掉一半毒点。

问：八个样段里的人物，我能不能直接拿来用？答：不能。这八个人物是自造的示范，你拿来用就是抄袭。你要学的是他们之间的关系结构：一个外放的御史、一个掌着家业的嫡女、一个有分寸的老夫人、一个不动声色的表少爷。把这个结构搬到你自己的人物身上，名字换了，籍贯换了，事由换了，才是你的书。

要点速记：人物结构可以学，人名不能搬；学的是关系骨架，不是姓名家世。

最后一句。这一册的案例库，是给你写不下去的时候翻的。翻完合上，回去写你自己的书。

手艺是手上长出来的，不是眼睛看出来的。

回去写。

写下去。

动笔。
