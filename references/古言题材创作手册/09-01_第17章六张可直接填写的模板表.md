# 第17章　六张可直接填写的模板表

> 素材来源：novel-material-skill ·《古言题材创作手册》第17章　六张可直接填写的模板表

这一部分给的是六张可以直接填的空表，加上一份填好的示范和一套每周能跑的工作流。读完你手里会有一套从立项到日更都能用的台账，写每一章之前对着表过一遍，写完之后再对着表查一遍。

### 17.1　使用说明：六张表的先后顺序、写多少、什么时候更新

六张表不是一次写完就锁死的。它们是一套滚动台账，跟着你这本书从立项一直跑到结局。顺序错了会返工，节奏乱了会变成填表的负担。下面把顺序、篇幅、更新时点说清楚。

六张表的先后顺序是：CP 设定卡、身份关系图谱、事件节点排布表、礼教束缚与突破计划表、伏笔追踪表、剧情自检表。前三张是骨架，立项阶段就要搭好；后三张是台账，写作过程中持续更新。

为什么是这个顺序？CP 卡不定，人物图谱就不知道往谁身上写；图谱不定，节点表就不知道排谁和谁的事；节点不定，束缚和伏笔都没地方挂。顺序反了，先写节点再补 CP，回头一定会推翻重来。

每张表写多少？CP 设定卡填十四到十八行，不要多，多了就是啰嗦；身份关系图谱十二到十六行，把主要人物都列上；事件节点排布表十四行起步，写到中期会扩到二十行；礼教束缚表十到十二行；伏笔追踪表十二行起步，越写越多；剧情自检表固定十五行。

什么时候更新？CP 设定卡和身份关系图谱每卷结束复盘一次，不要日改；事件节点排布表每周日晚排下周，不要日排；礼教束缚表每揭一层新束缚加一行；伏笔追踪表每天写完章顺手记一笔；剧情自检表每十章跑一次。

六张表放在一起管理。建议在电脑里建一个文件夹，六张表存成六个纯文本文件，文件名就叫 CP 卡、图谱、节点、束缚、伏笔、自检。不要存成 Word，不要加花哨的格式，纯文本最好查，搜两个字三秒就能翻出来。

还有一个常见误区。有人觉得表填得越细越好，CP 卡写到三十行，节点表排到两百章。表是给自己看的工具，不是给编辑看的稿件。写得太细，日更的时候反而被表绑死。骨架表留弹性，台账表才记死数。

六张表之间会互相打架。CP 卡上说不能碰的话题，节点表上排了一场戏正好要碰；图谱上写某个人已经病死，伏笔追踪表上还记着他要出场。这种冲突每周日扫表的时候一定会遇到。遇到冲突不要慌，以 CP 卡为准。CP 卡是最底层的设定，其他表都要围着它改。

滚动台账：不是一次写完锁死的文档，而是跟着写作进度持续更新的工作表。台账的价值不在写完那一刻，在写每一章之前都能翻开看一眼。

要点速记：六张表按顺序搭：先 CP、再人物、再节点，然后是束缚、伏笔、自检。前三张立项时搭好，后三张边写边更。日更不要日改骨架表，只动伏笔追踪表，每周日复盘。

### 17.2　CP 设定卡：把两个人的账写在一张纸上

CP 设定卡是六张表里最重要的一张。它回答一个问题：这两个人为什么非彼此不可。填的时候不要写外貌，不要写家世，只写“锚”“底线”“不能碰的话题”“第一次越界”“雷区”这五样东西。

表 17-1　CP 设定卡（空表模板）

| 项目 | 要点 | 填写提示 |
|---|---|---|
| 男主姓名与表字 |  | 先定名字再填表，名字没定下来后面全是空的 |
| 男主的身份位次 |  | 写他在朝堂、家族、社交圈里的真实位置，不要写官职全称 |
| 男主的锚 |  | 他这辈子最放不下的一件事，可以是人可以是差事，写一句话 |
| 男主的软肋 |  | 他在什么人面前会破功，写一个具体场景 |
| 男主不能被冒犯的点 |  | 别人做了什么他一定会翻脸，写一条就够 |
| 女主姓名与排行 |  | 崔九娘这种排行称呼直接用，不要另起一串字 |
| 女主的身份位次 |  | 写她在婆家、娘家、社交圈里的真实位置 |
| 女主的底线 |  | 哪件事她死都不能让，写一句话 |
| 女主的软肋 |  | 她在什么人面前会软下来，写一个具体场景 |
| 女主不能被冒犯的点 |  | 别人碰了什么她一定会翻脸，写一条 |
| 两人第一次见面的场合 |  | 不要写偶遇，写一个有第三方在场的场合 |
| 两人不能碰的三个话题 |  | 列三行，每一行一个话题，写作时绕开 |
| 两人第一次越界 |  | 写一个具体动作，不要写告白 |
| 两人定情的不可逆瞬间 |  | 写一个事件，不是一句话 |
| 必须避开的雷 |  | 列三行，写作时这三件事绝不能发生 |
| 两人关系刻度的终点 |  | 写结局时两人关系落到哪一档，一句话 |

填这张卡的时候有三个硬规矩。第一，锚和底线必须各只有一条。男主有三个锚，等于没有锚；女主有五条底线，等于没有底线。写多了人物就散。

再补一条。男主的锚和女主的底线最好不要撞车。如果男主放不下的那个人正好是女主最不能碰的话题，两个人一上来就站在对立面，后面写什么都别扭。让锚和底线分开放，一个压男主心里，一个压女主身上，两人中间才有拉扯的空间。

第二，不能碰的三个话题必须是真的不能碰。不是“他不太愿意提母亲”这种温吞话，是“他被人当面提亡母会当场翻脸”这种硬边界。写作时每次对话要绕开这三句，绕开的过程就是张力。

绕开这三个话题怎么写才好看？让旁人替你踩雷。一个不懂事的新姨娘在饭桌上提了一句，男主手里的筷子停了半秒，女主在旁边接话岔开。这半秒和这句岔开，读者全看在眼里。雷不一定要主角自己踩，旁人踩一次，两个人之间的默契就多一笔。

第三，第一次越界必须是动作，不是台词。“他替她拢了一下斗篷”是合格的第一次越界；“他忽然发现自己喜欢她”不是。越界要落在一个能被旁人看见的小动作上。

CP 卡填完之后，有一个自查动作。把这十四行念给一个没看过你这本书的人听。他听完能不能说出“这两个人大概是个什么处境？”能，这张卡就成了；他听完还是一脸茫然，说明你填的全是形容词，得重填。

CP 卡不是写完就不动了。每卷结束复盘一次，复盘的时候问自己：“这一卷写完，两个人之间多了哪笔账？”把这笔记到卡片最下面的空行里。书写完那一刻，这张卡就是两人关系的全史。

要点速记：CP 卡只写六类东西：锚、底线、不能碰的话题、第一次越界、不可逆瞬间、雷区。每类只写一条到三条，写多了人物就散。动作大于心理，场景大于旁白，反复用大于一次性。

### 17.3　身份关系图谱：把所有人物摆到一张图上

身份关系图谱是一张人物对号表。这本书里出现的有名字的人，一个一个列上去，写清他和主角的关系、表面立场、真实诉求、可用冲突、结局去向。写作时翻这张表，就不会把人物写丢。

这张表的关键列是真实诉求。表面立场谁都会写，真实诉求才决定这个人物能不能用。写不出真实诉求的人物，就是工具人，删掉或者合并。

举例。表面立场写“婆母严苛”，真实诉求就要写成“她怕长房绝嗣，所以把压力全压在儿媳身上。”有了真实诉求，婆母每次出场你都知道她为什么发难，写出来的反派就不是纸片。

真实诉求还要分明面诉求和暗面诉求。明面诉求是他自己说出口的，暗面诉求是他自己都未必承认的。婆母明面说“我是为了家规”，暗面是“我怕这屋里的话柄传出去。”写群戏的时候，让人物按明面诉求说话，按暗面诉求做事，人物立刻就有了层次。

结局去向这一列不要写“变好”“变坏”这种词。写具体动作：“被休归家”“升了嫔”“告老还乡”“病死。”一句话一个动作，这本书写到收尾，你才不会忘了这个人。

图谱的行数不是越多越好。超过二十行，你自己都记不住谁是谁。古言一本书里有名有姓的人物控制在十五个上下最合适：两个主角、三五个长辈、三五个平辈、三两个下人和清客、一两个宫里的远人。多了就合并。

合并人物是个重要功夫。两个功能相似的人物，比如两个都喜欢嚼舌根的婆子，合成一个，给她更多戏份。人物少而精，读者记得住；人物多而散，读者读到第五十章还在记名字。
