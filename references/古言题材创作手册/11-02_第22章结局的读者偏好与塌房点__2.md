# 第22章　结局的读者偏好与塌房点

第三塌实例：前文写两人中间隔着国仇家恨，男主的爹杀了女主的爹。最后结局两人和好了，说什么国仇家恨都不重要，我们只要彼此就好。读者看到这里会觉得前面二百章的国仇家恨都是假的。立场这道坎跨不过去就是跨不过去，不能因为相爱就跨过去了。跨过去了，这个故事就不是遗憾开放了，是强行HE。

22.2.5　BE 美学的塌房点

第一塌：为了虐而虐。男主最后一集得病死了，前面毫无铺垫。读者会觉得作者就是想虐。改法：男主的身体或者立场，必须在前一百章就埋好伏笔。他咳过血，他受过内伤，他站在城墙上说过一句我这身子撑不了几年。伏笔埋好了，结局的死才叫命运。

为什么这是个塌房点？因为BE的读者要的是意难平，不是莫名其妙。男主前面活蹦乱跳，最后一集突然死了，读者不会意难平，只会觉得莫名其妙。意难平是你早就知道他要死，但你还是舍不得。

第二塌：女主最后殉情了。这是 BE 里最偷懒的一招。两个人一起死，看似深情，其实是把活着的难一笔勾销。改法：让女主活着。活着带着回忆过下去，比一起死难得多，也高级得多。

为什么这是个塌房点？因为BE美学的核心是活着的人怎么带着回忆过下去。你让两个人一起死了，这个问题就没了。活着才是最难的，也是最有力量的。

第三塌实例：前文写男主是个杀伐果断的权臣，杀人不眨眼。最后他为了救女主，自己挡了一刀，死了。读者看到这里会觉得违和。不是说权臣不能死，是说他前面杀了那么多人，最后突然为了一个女人死了，这个转变太大了。改法：要么前面就写他对女主不一样，他杀别人的时候眼睛都不眨，但对着女主就下不去手。要么就别让他为女主死，让他死在战场上，死在他该死的地方。

要点速记：HE三塌：诰命白给、仇人翻篇、男主变舔狗；归隐两塌：账没了清、日子太苦；两全两塌：登顶太易、开始纳妃；开放两塌：拖泥带水、模糊不清；BE两塌：无铺垫死、女主殉情；每类再补一个实例对照前文细节。

### 22.3　结局与开篇的呼应校验

写完结局之后，把开篇前两章翻出来，对着下面这张表一条一条勾。勾不上的地方，就是你结局没接住的地方。

这张表不是写完才用的。开书的时候就把它打印出来，贴在你书桌前面。每写一章，就把这一章里埋的新钩子加进去。写到结局的时候，这张表已经是一张完整的钩子清单了。对着清单写结局，就不会漏。

表 22-2　开篇提问与结局回应的校验表

| 开篇埋的问题 | 结局该给的回答 | 是否闭环 |
|---|---|---|
| 女主被退婚那口气出了没有 | 仇人下场如何、女主诰命如何 | 必须答 |
| 男女主第一次那个误会解了没有 | 最后一场戏里两人说没说开 | 必须答 |
| 开篇那个立flag的配角后来怎样 | 他的下场是否交代 | 最好答 |
| 开篇提到的那个信物最后在谁手里 | 结局那一幕有没有拿出来 | 最好答 |
| 女主开篇说的那句话最后兑现了没 | 她说我要让他后悔他后没后悔 | 必须答 |
| 开篇埋下的那个身体暗伤最后发作没 | 发不发作都要有个交代 | 建议答 |
| 男女主初见时那个眼神最后落在哪 | 结局有没有再写一次同样的眼神 | 加分项 |
| 开篇那个场景最后有没有再回去一次 | 结尾是否回到同一个地点 | 加分项 |

这张表的用法：把你开篇前两章里所有埋的钩子列出来，一条一条对着结局打勾。打不上勾的，回去补一场戏。补不动的，就在结局加一段旁白把它收掉。读者记着的，比你以为的多。

呼应校验这一步，很多作者写完结局就跳过了。觉得前面都写完了，结局也写完了，还校验什么？但读者不会跳过。读者追了二百章，开篇每一个钩子她都记着。你漏了一个，她就在书评区给你列出来。

校验的时候有个技巧：把开篇前两章单独打印出来，拿笔一条一条勾。不要在脑子里过，脑子里过会自动忽略那些你觉得不重要的。打印出来用笔勾，才不会漏。

还有一个要点：呼应不一定是一模一样的场面。开篇她被退婚站在风里，结局她穿着诰命站在风里。同一个场景，不同的状态，这就是呼应。不一定要写同样的台词，写同样的天气、同样的位置、同样的动作，读者就能想起开篇。

呼应校验：结局写完之后，把开篇钩子一条一条对着结局勾。勾不上的就是没接住的地方。读者记着的伏笔比作者以为的多，漏掉一个就是差评。

呼应技巧：呼应不一定要写一模一样的场面，写同样的天气、同样的位置、同样的动作，读者就能想起开篇。开篇她站在风里被退婚，结局她站在风里穿诰命，这就是呼应。

呼应校验这一步，最好在写结局之前做，不是写完之后才做。写结局之前就把开篇钩子列出来，然后对着钩子设计结局的场面。这样写出来的结局天然就呼应，不用事后补。写完了才校验，发现漏了再补，补出来的东西总是生硬的。

先校验再写结局：呼应校验最好在写结局之前做，不是写完之后才做。写结局之前就把开篇钩子列出来，对着钩子设计结局场面。这样写出来的结局天然就呼应，不用事后补。

要点速记：八类钩子要呼应：被退婚那口气、初见的误会、立flag的配角、信物、女主那句话、身体暗伤、初见眼神、开篇场景；漏一个就是差评；把开篇打印出来用笔勾，不要在脑子里过；先校验再写结局。
