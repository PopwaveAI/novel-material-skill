# 第3章　男主模板库

> 素材来源：novel-material-skill ·《古言题材创作手册》第3章　男主模板库

这一部分把古言里被反复验证过的男主、女主和配角模板拆成可照抄的零件。读完你能拿到七类男主、六类女主、五类配角的五段式写法，以及一张身份阶层与性格冲突的搭配矩阵，直接套进自己那本书。

### 3.1　五段式写法总纲

古言男主写崩，九成不是因为不够帅，而是因为五个零件之间没有咬合。身份底色是他站在哪儿，行为逻辑是他遇事怎么动，台词腔调是他开口什么味儿，适配桥段是他适合在什么场面里被读者记住，崩坏信号是写着写着他就走样的几个征兆。五个零件缺一个，人物就立不住。

先定身份底色，再推行为逻辑。一个人站在什么位置上，被什么规矩捆着，决定了他遇到事的第一反应。权臣遇到有人弹劾他，第一反应不是怒，是算这笔账能不能被对方拿到台面上；江湖客遇到有人拔刀，第一反应不是退，是先看周围有没有同伙埋伏。把位置写死，动作自然就出来了。

行为逻辑往下接台词腔调。同一个意思，权臣说“此事容后再议”，武将说“末将这就去办”，翰林说“学生以为不妥。”台词不是装饰，是身份的出口。写台词之前先问自己，这个人这辈子说过几句超过十个字的长句，他跟谁说话会压低声音，他发怒的时候是摔东西还是只把茶盖搁下。

五段式：写男主的固定拆解框架，含身份底色、行为逻辑、台词腔调、适配桥段、崩坏信号五段。任何一类男主都先按这五段填，填不出来说明人物还没想清楚，别急着写正文。

身份底色：人物在故事世界里的坐标，含官职、出身、爵位、被谁看着、被什么规矩捆着。底色不清，后面所有动作都飘。

适配桥段是把人物放进具体场面里烤。权臣适合在御前奏对、深夜密谈、政敌登门这三类场面里发光；江湖客适合在酒楼斗殴、深夜追逃、客栈避雨里显形。桥段不是随便挑的，是从身份底色里长出来的。一个常年在书房批公文的人，你让他在马背上耍帅，读者立刻出戏。

崩坏信号是写作者给自己的警报器。一个权臣开始在女主面前说“我不管这朝堂了我跟你走”，那就是崩了，因为他半辈子都在朝堂里，朝堂就是他的命。一个江湖客开始替女主分析户部秋粮怎么调，那也是崩了。信号出现的时候，要么改桥段，要么改人物，不能硬写。

用一句话定住一个人物，是五段式的最后一步。写完五段之后，逼自己用一句话把这个男主说清楚，句式是“一个被X规矩捆着的Y，遇到Z事第一反应是W。”比如“一个被言官盯着的内阁次辅，遇到有人撞破他私库账目，第一反应是把账册烧了再写自辩折子。”这句话定不住，说明五段还没咬合，回头重写。

表 3-1　五段式咬合关系速查

| 零件 | 它回答什么问题 | 下一个零件从哪里接 |
|---|---|---|
| 身份底色 | 他站在哪，被什么捆着 | 捆他的规矩决定他遇事怎么选 |
| 行为逻辑 | 他遇事第一反应是什么 | 反应路径决定他开口说什么 |
| 台词腔调 | 他开口什么味儿 | 腔调决定他适合在什么场面说话 |
| 适配桥段 | 他在什么场面发光 | 场面里暴露他最怕什么 |
| 崩坏信号 | 写崩的征兆是什么 | 征兆一旦出现回头改底色 |

要点速记：五段按顺序写，底色不清别动逻辑；一句话定住人物才能动笔；桥段从身份长出来，别硬塞帅戏；崩坏信号就是警报，响了就回头。

### 3.2　权臣

3.2.1　身份底色

权臣的底色是“被看着的强者。”他手里握着吏部或者兵部的实权，年纪不大但已经在朝里站了十年，言官的折子三天两头点他的名，皇帝用他也防他。他不是靠家世吃饭的，是靠一笔一笔批公文、一场一场熬廷议熬上来的。这种人身上最浓的味道是克制，因为他知道多说一句话就多一份把柄。

他被三层规矩捆着。第一层是台谏，折子递上去他就得停手自辩；第二层是同僚，跟他同列的那几个尚书都在等他出错；第三层是家眷，他府上的门客、幕僚、丫鬟，任何一个被对面买通，他三年的布局就塌了。所以权臣的宅子里永远安静，连说话都压着声。

权臣：在朝里握着六部实权、被皇帝倚重也被言官盯上的重臣。古言里常见年纪二十五到三十五，寒门或破落世家出身，靠政绩和心机上来。

3.2.2　行为逻辑

权臣遇事的第一反应是算账。有人递折子弹劾他，他不先生气，先把折子上每一个字对应的物证在脑子里过一遍，哪一条对方拿得出实证，哪一条是空炮。算完账他才决定是自辩、是切割、是反手参一本，还是装病三天。决策顺序永远是：先看证据，再看人，最后看自己能不能承受代价。

他做感情决策也是这套。女主被人扣了，他第一反应不是冲过去救人，是先问清楚是谁扣的、为什么扣、扣在哪里、周围有多少人。问完了他才动手，而且动手的方式是调一支不靠他名分的人，把自己摘干净。读者觉得他冷血，他自己知道，他要是冲动一次，前十年的位子就没了。

他的决策有一个铁律：绝不在明面上护女主。真要护，也是借别人的手，走别的由头。女主被嫡母罚跪，他不会亲自上门去要人的，他会让御史台参一本侯府苛待孤女，把事情闹到御前，让皇帝下旨放人。这一步看着绕，实则是把女主从侯府的内宅拉到公域，侯府再也不能动她。

3.2.3　台词腔调

权臣的台词短、准、留余地。他不说“我对你好”，他说“你的事我记下了。”他不说“我会救你”，他说“三日后宫门开，你自然能出去。”他发怒的时候音量不升，只是把手里的笔搁下，笔尖对着桌面。

示范台词一，女主问他为什么要帮自己，他抬眼看了一下房梁，说“沈小姐今日在廊下站了半个时辰，本官若是不管，明日都察院的折子就要参到内阁来了。”他把功劳推给都察院，其实是他自己动的手。

示范台词二，政敌登门试探，他给对方斟茶，茶汤满到杯沿才停手，说“王大人这杯茶喝了，咱们再说正事。茶要是洒了，今儿的话就当我没听过。”用一杯茶把对方的退路堵死。

示范台词三，深夜女主问他怕不怕，他看着案上的折子，说“怕。怕的不是他们参我，怕的是哪一天我批公文批到半夜，发现自己已经忘了当初为什么要站在这里。”这一句是他全书中唯一一次露软，留给读者记。

3.2.4　适配桥段

第一类适配场面是御前奏对。权臣站在丹陛下，皇帝在上面摔折子，他跪在下面，一字一句把对方的指控拆成七段，每段都给出反证。这一场戏用来亮他的专业，读者看完会明白这个人为什么能坐到这个位置。女主在屏风后偷听，这是她对他改观的第一个节点。

第二类是深夜密谈。他刚从宫里出来，斗篷上还带着雪，进门先把袖子里的密折烧了，再跟女主说今晚发生了什么。密谈里他话比平时多三成，因为这是他一天里唯一不用防人的时候。感情线的推进靠这种场面，不靠花前月下。

第三类是政敌登门。对方带着家眷名义上门，实则是来探口风。权臣在花厅里陪对方品茶，女主在屏风后看着，发现他笑得越客气，茶盏搁得越重。这一场用来写他的双面，让读者知道他对外人是什么样，对女主又是什么样。

3.2.5　崩坏信号

信号一，他开始在女方面前说“这官我不做了。”权臣的官就是他的盔甲，脱了盔甲他什么都不是，他不会说这种话。真要辞，也是写一道折子递上去，三天后告老还乡，不会先跟女主表态。

信号二，他为了女主跟皇帝当面顶起来。权臣在皇帝面前永远留三分余地，哪怕心里骂娘，嘴上也是“臣愚钝，容臣再想想。”当面顶回去那是少年将军干的事，不是他。

信号三，他开始对下属发脾气摔东西。权臣的情绪永远压在笑容底下，摔东西等于告诉全府“我乱了”，他自己第一个不允许。真怒的时候他只是把人调职、把折子留中、把茶换了一种。

信号四，他的台词变长。一个习惯了三句话说完事的人，突然开始跟女主解释自己小时候多苦、读书多累、在朝中多难，那就崩了。这种人一辈子不会跟人解释，他只做，不辩。
