# 3.2 职业行当设定：金融、律所、医院、建筑、娱乐圈

> 素材来源：novel-material-skill ·《现言题材创作手册》3.2 职业行当设定：金融、律所、医院、建筑、娱乐圈

现言里写行业，最忌讳的是只写头衔不写日常。写一个投行副总裁，不能只写他在会议室里说一不二，要写他一天怎么过、他的时间表是什么样、他的同事怎么叫他、他的加班是什么节奏。下面五个行业，逐个拆。

### 3.2.1 金融行业：一天被会议切碎

职级序列：分析师、高级分析师、经理、高级经理、副总裁、高级副总裁、董事总经理。一个投行副总裁通常工作八到十年，手里管两到三个人。他们的一天是这样的：早上七点到公司看隔夜市场，八点半开晨会，九点开始路演或者写报告，中午边吃边开电话会，下午见客户或者做模型，晚上六点还要开一次全球电话会，九点以后才能走。

常用术语：路演、尽调、估值模型、carry、赛道、退出、IPO、并表、对赌。他们的晋升考核看项目数量和项目质量，每年一次评级，评级直接影响奖金。他们的加班是常态，出差是家常便饭，手机24小时开机，周末随时被叫回去。

该行业特有的体面与狼狈：体面是出入写字楼顶层、和客户吃饭喝红酒；狼狈是出差拎着两个行李箱在机场狂奔、凌晨三点还在改PPT、年终奖发了但第二天还要上班。写错会被读者抓的细节：投行不是一个电话就能调动几个亿，做决策要走流程；副总裁不是一把手，上面还有董事总经理。

金融行业还有一个写法要点：他们的时间是按分钟算的。他约你吃饭，要提前一周约；他见你一面，要看他的日程表；他回你消息，可能要等三个小时。这种时间上的不对等，本身就是一种张力。写金融男的时候，不要让他秒回消息，他的时间比女主的时间贵得多。

金融男的时间：他的时间按分钟算，约饭要提前一周，回消息要等三小时。这种时间不对等本身就是张力。

金融行业的项目节奏比人设更值得写。晨会是每天早上八点半，全组围坐一圈，每个人报一个项目进展，谁卡住了当场讨论；路演是跑去见投资人，十五分钟讲完一个项目，投资人随时打断提问；尽调是派两个人去被投公司蹲一周，翻合同、查流水、跟高管聊天，回来写一份几十页的尽调报告；模型迭代是投资逻辑变了，财务模型就要重搭，一个公式改完，后面三十页全要跟着调；投标是最紧张的，标书改到最后一刻，半夜两点还在跟法务确认条款。写金融男的时候，不要只写他在会议室里说一不二，要写他在这些流程里的高强度和紧绷。

早上七点到公司，先看隔夜美股和亚洲市场。

八点半开晨会，每个人报一个项目进展。

上午做模型、写报告，下午见客户、开路演。

中午边吃边开电话会，饭经常凉了才吃。

晚上六点开全球电话会，和纽约、伦敦对时间。

周末随时被叫回去改材料，手机不能静音。

年终奖在年初发，发完第二天照常上班。

出差住四星酒店，打车报销但要攒票。

### 3.2.2 律师行业：把一切当案子谈

职级序列：实习律师、律师、资深律师、合伙人、高级合伙人。一个争议解决方向的律师，工作五到八年可以做到资深律师，手里有两三个案子在跑。他们的一天是这样的：早上九点到律所，先看昨天的邮件和案情摘要，十点开庭或者见客户，中午在律所吃外卖，下午写法律文书或者跟客户电话沟通，晚上六点还要开团队例会。

常用术语：质证、举证、上诉、反诉、保全、执行、仲裁、和解、胜诉率。他们的晋升考核看办案数量和客户满意度，合伙人要看能不能拉来案源。他们的加班是阶段性的：案子开庭前一周天天加班到凌晨，开完庭可以喘两天。

该行业特有的体面与狼狈：体面是穿西装在法庭上发言、和客户在商务酒店谈事；狼狈是开庭前一天还在改证据目录、出差住的酒店旁边就是法院、手机里存着十几个当事人的电话。写错会被读者抓的细节：律师不能随便承诺胜诉率、出庭要穿律师袍、诉讼费不是律师费。

律师行业的案卷流程比人设更值得写。接案是先听当事人讲事实，再判断这个案子值不值得接、能不能赢；阅卷是到法院档案室调对方的证据材料，一页一页翻，找漏洞；写证据目录是把己方证据按逻辑排好，每一条都要标清楚证明目的；开庭前准备是模拟对方会问什么、己方怎么答，连着装和站位都要过一遍；客户沟通是最磨人的，当事人不懂法律，你要用大白话解释，但又不能把话说死。写律师的时候，不要只写他在法庭上滔滔不绝，要写他在这些流程里的细致和紧绷。

律师行业还有一个写法要点：他的工作是替别人说话，但他自己的话很少。他在法庭上滔滔不绝，在生活里沉默寡言。他习惯了替别人辩护，不习惯替自己辩护。写他的时候，不要让他变成一个话多的人，他的甜在他替你做的那些事里，不在他说的话里。

律师的日常：律师的一天不是在法庭上就是在写文书。写他的时候，不要让他每天都在开庭，他大部分时间在改合同、打电话、见客户。

### 3.2.3 医疗行业：见惯了生死

职级序列：住院医、主治医、副主任医、主任医。一个三甲医院的心外科主治医生，工作五到八年，每周要做两到三台手术，还要出门诊、写病历、带学生。他们的一天是这样的：早上七点半到病房查房，八点进手术室，中午在手术室里吃盒饭，下午继续做手术或者看门诊，晚上六点还要写病历、值夜班。

常用术语：查房、手术、术后、并发症、值班、交班、门诊、会诊、抢救。他们的晋升考核看论文和手术量，副主任医师要发核心期刊，主任医师要带团队。他们的加班是24小时制的：值班的时候不能走，随叫随到，手机不能关机。

该行业特有的体面与狼狈：体面是病人家属送锦旗、在行业会议上发言；狼狈是连续站了八个小时手术腿都肿了、值班的时候在值班室的折叠床上睡、刚下手术台就被主任叫去改病历。写错会被读者抓的细节：医生不能随便给病人承诺“一定没事”、值班是24小时连班、手术不是想做就能做。

医疗行业的一天比人设更值得写。查房是早上七点半，主任带队挨个儿病房走，每床停两分钟，下级医生汇报病情，主任下判断；手术排班是前一天下午排好的，第二天临时加急诊是家常便饭，排好的计划全打乱；交接班是夜班和白班在护士站面对面交接，哪个病人今晚发烧了、哪个家属要沟通、哪个药要调整，一条一条念；写病历是最耗时的，一台两小时的手术，术后病历要写三个小时，主任还要在旁边挑格式问题。写医生的时候，不要只写他在救人，要写他在跑这些流程时的机械和疲惫。

值班室的细节也值得写。一张折叠床、一条薄被、一个枕头，上面永远有压不下去的褶皱。桌上放着没喝完的矿泉水、半盒冷掉的外卖、一本翻到一半的病历。值班的时候手机不能静音，凌晨三点被呼叫铃叫起来，迷迷糊糊走到病房，处理完再回去躺着，天就亮了。

医疗行业还有一个写法要点：他的手是最贵的。他的手要做手术，不能受伤，不能留疤，不能抖。他平时连瓶盖都不让她拧，因为他怕她弄伤手。这种对她的保护，不是因为她弱，是因为他知道一双手有多重要。

医疗行业还有一个写法要点：他的作息是被手术排期决定的。他不是想加班就加班，是手术排到什么时候就什么时候下班。他的生活不是他自己的，是病人的。他答应你的约会，可能因为一个急诊手术就取消了。这种不可控的作息，本身就是一种张力。

急诊室的走廊永远亮着白光，推床的轮子碾过地砖发出短促的声响。护士站的电脑屏幕亮了一排，呼叫铃时不时响一声，有人在压低声音打电话。走廊尽头的自动门开了又关，带着外面十一月的冷风。

### 3.2.4 建筑行业：画得出所有人的家

职级序列：助理建筑师、建筑师、主创建筑师、设计总监、合伙人。一个主创建筑师，工作五到八年，手里有两三个项目在跟，从概念方案到施工图全程参与。他们的一天是这样的：早上九点到设计院，先看昨天的方案修改意见，十点开会讨论，中午边吃边画草图，下午和甲方对接或者跑工地，晚上六点还要改方案，经常加班到凌晨。
