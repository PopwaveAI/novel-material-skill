# 10.2 合格样段与拆解批注

> 素材来源：novel-material-skill ·《现言题材创作手册》10.2 合格样段与拆解批注

| 样段组 | 常见抄错 | 正确手感 |
|---|---|---|
| 职场初遇 | 让男主直接夸奖她 | 他只对自己写一句记号 |
| 雨天共处 | 男主直接把伞送她 | 伞要还，制造下次见面 |
| 酒后真言 | 第二天重复那句话 | 话只说一次，不重复 |
| 吃醋 | 和第三方开战 | 无视第三方，只接管动作 |
| 旧账对峙 | 把旧账讲成小作文 | 只答关键一句，让她拼图 |
| 日常护短 | 替她把事情解决完 | 挡一下，然后让她自己走 |
