# 9.2 职业与家庭背景设定表

> 素材来源：novel-material-skill ·《现言题材创作手册》9.2 职业与家庭背景设定表

职业和家庭是现言的压力源。职业决定人物每天在为什么事忙，家庭决定人物在为什么事烦。两张子表，各填 10 个字段。

### 9.2.1 职业背景设定表

表9-2 职业背景字段设计

| 字段 | 填什么 | 怎么判断填对了 |
|---|---|---|
| 岗位 | 具体职位名称 | 说出去别人能听懂是干嘛的 |
| 公司类型 | 在什么规模什么行业的公司 | 和角色的段位匹配 |
| 入职年限 | 做了几年 | 年限和职位匹配 |
| 上级是谁 | 直属领导的职位和性格 | 上级是后面冲突的来源之一 |
| 日常工作内容 | 一天在做什么事 | 具体到动作，不是岗位名称 |
| KPI 是什么 | 怎么衡量他/她做得好不好 | 有数字或者具体标准 |
| 收入范围 | 月薪或年薪大概什么量级 | 能支撑他/她的生活方式 |
| 工作地点 | 在城市的哪个区域上班 | 和住所有距离感 |
| 同事关系 | 和同事是合作还是竞争 | 有一两个可以对话的同事 |
| 职业野心 | 想做到什么位置 | 有明确目标，不是走一步看一步 |

职业背景的填写示例：男主沈砚，建筑事务所合伙人，32 岁，入职 8 年，上级是事务所创始人，日常工作是画方案、和客户开会、盯施工，KPI 是项目中标率和利润率，年收入 50 万到 80 万，在 CBD 上班，同事里有一个同期进来的合伙人，关系是亦敌亦友，职业野心是做一个自己署名的地标项目。

职业压力源：职业不只是背景，是压力源。KPI、上级、同事关系，都是后面冲突的来源。

### 9.2.2 家庭背景设定表

表9-3 家庭背景字段设计

| 字段 | 填什么 | 怎么判断填对了 |
|---|---|---|
| 原生家庭 | 父母做什么的，关系怎么样 | 和人物性格有关系 |
| 父母婚姻 | 父母是离婚、丧偶还是在一起 | 婚姻模式影响人物对感情的态度 |
| 主要抚养人 | 小时候谁带大的 | 抚养人决定人物的亲密模式 |
| 兄弟姐妹 | 有几个，关系怎么样 | 兄弟姐妹是后面的配角来源 |
| 经济条件 | 家里是富裕、普通还是紧张 | 经济条件决定人物的安全感 |
| 家庭期待 | 父母希望他/她做什么 | 期待和人物的选择有冲突 |
| 童年记忆 | 一件印象最深的家庭事件 | 这件事能解释人物的某个行为 |
| 和父母的关系 | 现在联系多不多，亲不亲 | 关系状态影响人物现在的感情 |
| 老家在哪 | 在哪个城市，多久回去一次 | 老家是后面的场景来源 |
| 家庭秘密 | 家里有没有没说开的事 | 秘密是后面的伏笔来源 |

家庭背景的填写示例：女主苏念，母亲在她 5 岁时离婚，跟着外婆在县城长大，父亲是货车司机，再没见过。外婆是小学老师，对她严格但疼爱。家里经济普通，外婆退休金够生活。母亲在外地再婚，有一个同母异父的弟弟。苏念和母亲关系冷淡，每年春节打个电话。她最深刻的记忆是小学三年级，外婆带她去报名，说你要靠自己。家里没有秘密，只有距离。

家庭压力源：家庭不只是背景，是压力源。父母期待、经济条件、家庭关系，都是后面冲突的来源。

家庭秘密：家里没说开的事，是后面的伏笔来源。有秘密的家庭，人物更有层次。

### 9.2.3 职业与家庭的咬合

职业和家庭不是两张孤立的表，它们要咬合。职业决定人物每天在为什么事忙，家庭决定人物在为什么事烦。两张表咬合的地方，就是人物最累的地方。

咬合的判断方法：看人物的职业野心和家庭期待有没有冲突。比如女主想有一间自己的工作室，但家里希望她考公务员、回老家。这个冲突就是她每天在烦的事。如果职业和家庭没有冲突，人物的生活就太平，没有压力源。

咬合的另一个维度：职业压力会不会影响家庭关系。比如男主是建筑师，经常加班，和母亲的关系越来越淡。这个咬合就是后面的伏笔来源。

职业家庭咬合：职业野心和家庭期待有冲突，职业压力影响家庭关系。咬合的地方就是人物最累的地方。

填写示例：苏念想有一间自己的工作室，但外婆希望她考公务员，稳定。这个冲突是她每天在烦的事。沈砚是建筑事务所合伙人，经常加班，和母亲的关系越来越淡，因为母亲觉得他应该接父亲的班，做一个“正经”的建筑师。

常见填错：职业和家庭两张表各填各的，没有咬合。比如女主的职业是室内设计师，家庭是温馨和睦，没有任何冲突。这样的人物太顺，写出来的故事没有压力。

### 9.2.5 背景表的填写示例

下面给一张完整的职业家庭背景表示例，以沈砚和苏念为例。

表9-3a 职业家庭背景填写示例

| 字段 | 沈砚 | 苏念 |
|---|---|---|
| 岗位 | 建筑事务所合伙人 | 室内设计师 |
| 公司类型 | 中型事务所，20 人左右 | 小型工作室，8 人 |
| 入职年限 | 8 年 | 5 年 |
| 上级 | 创始人，60 岁，严但公正 | 女老板，35 岁，强势 |
| 日常工作 | 画方案、开会、盯施工 | 量房、出图、改方案 |
| KPI | 项目中标率、利润率 | 客户满意度、出图量 |
| 收入范围 | 年薪 50 万到 80 万 | 月薪 1.5 万到 2 万 |
| 工作地点 | CBD | 老城区创意园 |
| 同事关系 | 有一个同期合伙人，亦敌亦友 | 有一个闺蜜同事，互相吐槽 |
| 职业野心 | 做一个自己署名的地标项目 | 开一间自己的工作室 |
| 原生家庭 | 父亲是建筑师，已故；母亲退休 | 母亲再婚，外婆带大 |
| 父母婚姻 | 父亲病逝后母亲独居 | 父母 5 岁离婚，母亲再婚 |
| 主要抚养人 | 母亲 | 外婆 |
| 兄弟姐妹 | 无 | 同母异父弟弟，10 岁 |
| 经济条件 | 中产，有房贷 | 普通，租房 |
| 家庭期待 | 母亲希望他结婚稳定 | 外婆希望她考公务员回老家 |
| 童年记忆 | 父亲深夜画图，他在旁边写作业 | 外婆带她去报名，说你要靠自己 |
| 和父母关系 | 和母亲冷淡，每周打一次电话 | 和母亲冷淡，春节打个电话 |
| 老家在哪 | 杭州本地 | 绍兴县城 |
| 家庭秘密 | 父亲其实是抑郁自杀，对外说是病逝 | 母亲再婚后没再见过她 |

背景表示例：职业家庭两张表填在一起，能看到人物的压力源和冲突源。咬合的地方就是故事的起点。

### 9.2.4 背景表的更新

职业和家庭表开书前填完，中途不改。但有一种情况要更新：写到某个阶段，你发现人物的职业或家庭和你一开始想的不一样了。这时候不要硬拉回来，要回头改表。

比如你一开始写女主是室内设计师，写着写着发现她更适合做文案。这时候要回头改职业表，把后面所有涉及职业的情节都改过来。不能前面写室内设计师，后面突然变成文案，读者会出戏。

背景表更新：开书前填完不改。但写着写着发现不对，要回头改表，不要硬拉人物回来。
