# 2.1 男主模板库总览：四轴定位法

> 素材来源：novel-material-skill ·《强制爱创作手册》2.1 男主模板库总览：四轴定位法

这一部分给你四套模板：男主十二型、女主十二型、配角四类、冲突矩阵。模板不是让你照抄，是让你在三十秒内把一个人的骨架搭出来，再用细节把他填成活人。选型选错，后面所有的桥段都会别扭；选型选对，情节自己会长出来。

不要问“他是什么型”，要问“他的权力从哪来、他的情绪多热、他的脑子多冷、他的执念长什么样”。四轴一填，型号自然浮现，而且不会串味。

### 2.1.1 四轴：权力来源、情绪温度、理性程度、执念形态

权力来源决定他能做什么：来自资本、来自暴力、来自制度、来自信息、来自血缘。情绪温度决定他怎么发作：滚烫、温热、冰凉。理性程度决定他会不会算：精算、半算、不算。执念形态决定他为什么不肯放手：占有、证明、补偿、习惯。

| 轴 | 取值 | 对写法的影响 |
|---|---|---|
| 权力来源 | 资本 / 暴力 / 制度 / 信息 / 血缘 | 决定压迫手段，也决定女主的反抗通道 |
| 情绪温度 | 滚烫 / 温热 / 冰凉 | 决定台词的密度与动作的幅度 |
| 理性程度 | 精算 / 半算 / 不算 | 决定他会不会自己踩坑，也决定反转的可信度 |
| 执念形态 | 占有 / 证明 / 补偿 / 习惯 | 决定他最后为什么松手，或者为什么松不了手 |

四轴的好处是可以量化。同样是疯批，权力来源写资本、情绪冰凉、理性精算，他就是一个冷血的投资人；权力来源写暴力、情绪滚烫、理性不算，他就是一个会自毁的亡命徒。两种疯批，写法完全不同。

「轴的组合禁忌」：情绪冰凉加理性不算，人物会变成随机发疯的工具人，读者无法预测。要疯就给他一条自己的逻辑，哪怕是歪的。

「轴的微调」：同一本书里男主的轴可以移动一次，通常在中段。理性的他为一件事失去理性，这就是人设的转折点，详见 4.5 节。

### 2.1.2 十二型速览

十二型不是十二个标签，是十二种压迫方式。每种给一句定位和一个标志动作，方便你快速对号。

| 型号 | 一句话定位 | 标志动作 | 适配分支 |
|---|---|---|---|
| 疯批型 | 把偏执写在脸上，情绪即是武器 | 笑着说出最狠的话 | 囚禁、黑道 |
| 黑恶型 | 秩序之外的王，讲自己的规矩 | 一句话决定别人的去留 | 黑道、罪案 |
| 掌权型 | 制度里的赢家，用规则压人 | 把文件推到她面前 | 权贵、宫廷、职场 |
| 阴郁偏执型 | 不吵不闹，安静地织网 | 在她不知道的时候把路堵死 | 掌控、悬疑 |
| 克制型 | 所有情绪都收在西装里 | 替她做一件她没开口的事 | 现言、职场 |
| 温润型 | 外表是无害的，手段是锋利的 | 先递茶，再断她的退路 | 古言、宅斗 |
| 暴烈型 | 用破坏表达在乎 | 砸掉一样她珍视的东西 | 黑道、末世 |
| 矜贵型 | 血统与教养构成的天然优越 | 不必开口，别人替他说 | 宫廷、权贵 |
| 病弱型 | 以脆弱为筹码索取 | 咳着血谈条件 | 古言、宫廷 |
| 枭雄型 | 目标高于一切，包括她 | 在利益和她之间选利益 | 权谋、末世 |
| 守序型 | 守规矩守到偏执，规矩比她重要 | 按条款办她 | 职场、现言 |
| 伪善型 | 所有人都说他好，只有她知道不好 | 在人前握住她的手 | 现言、悬疑 |

十二型里，前四型是本赛道的骨干，中间四型负责调温，后四型负责反差。一本书选一个骨干型做主轴，再选一个调温型做副轴，人物就有层次。

### 2.1.3 选型的三条规矩

▪ 规矩一：主型决定压迫方式，必须和分支咬合。写宫廷却选黑恶型，男主一句话就能调兵，故事立刻失真。

▪ 规矩二：副型只提供反差，不提供第二套权力。他的副型应该体现在生活细节里，比如掌权型的人在深夜会因为一碗粥失态。

▪ 规矩三：不要选两个高压迫型做主轴。疯批加黑恶，男主强到没有对手，女主的反抗变成笑话。

还有一条隐含规矩：男主的型号要和女主的型号形成互补或对撞。互补产生甜，对撞产生张力。写强制爱，优先选对撞，比如掌权型配清醒对抗型，两个人都在算，谁也不肯先认。

「选型的检验方法」：把男主的型号说给一个没看过你书的人听，问他“这个人最可能干出什么事”。他答得出来，说明型号清晰；答不出来，说明你选的是标签，不是人。
