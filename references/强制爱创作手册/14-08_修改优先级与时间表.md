# 14.8 修改优先级与时间表

> 素材来源：novel-material-skill ·《强制爱创作手册》14.8 修改优先级与时间表

发现问题之后，先改哪个。顺序错了，会在小问题上耗光时间。

### 14.8.1 优先级四档

第一档是致命问题：结构塌、结局错、合规红线。必须在三天内改完，不改不能交。

第二档是重要问题：人物动机不清、节奏失衡、钩子失效。一周内改完。

第三档是观感问题：语言不顺、细节不真、对话生硬。两周内改完。

第四档是锦上添花：比喻、意象、段落重排。有时间就改，没时间就放着。

### 14.8.2 时间表模板

| 时间 | 任务 | 产出 |
|---|---|---|
| 第一天 | 通读一遍，只记页码不记细节 | 问题清单 |
| 第二天到第三天 | 改致命问题 | 结构修订稿 |
| 第四天到第六天 | 改重要问题 | 人物与节奏修订稿 |
| 第七天到第十天 | 改观感问题 | 语言修订稿 |
| 第十一天 | 合规全查 | 合规清单 |
| 第十二天 | 终检与格式统一 | 定稿 |
| 第十三天 | 交稿 | 成品 |

十三天是标准周期。赶时间可以压到七天，但致命问题那一档不能省。

### 14.8.3 全册收尾

到这十四部分写完，这本书的骨架、血肉、皮肤、衣服都齐了。剩下的事只有一件：坐下来，一章一章地写。

手册能给你的是判断力，不是文字。判断力让你知道哪里不对，文字还得你自己一句一句地磨。
