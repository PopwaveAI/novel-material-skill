# 13.10 标签组合案例

> 素材来源：novel-material-skill ·《强制爱创作手册》13.10 标签组合案例

标签不是越多越好，是越准越好。下面十组组合，覆盖了常见的几种定位。

### 13.10.1 十组组合示例

| 定位 | 标签组合 | 适配内容 |
|---|---|---|
| 权贵虐恋 | 现言、权贵、强制爱、拉扯、HE | 掌权型男主加清醒女主 |
| 古言宅斗 | 古言、宅斗、强制爱、先婚后爱 | 伪君子型加隐忍女主 |
| 悬疑融合 | 现言、悬疑、强制爱、双向救赎 | 旧案与共同调查 |
| 末世生存 | 末世、强制爱、女主成长、开放结局 | 资源稀缺与夺权 |
| 病娇偏执 | 现言、病娇、强制爱、意难平 | 病娇型加柔顺女主 |
| 军阀年代 | 年代、军阀、强制爱、BE | 军阀型加弱而不屈女主 |
| 宫廷权谋 | 古言、宫廷、强制爱、夺权 | 掌权型加算计者女主 |
| 治愈救赎 | 现言、双向救赎、慢热、HE | 两个有伤的人 |
| 爽文翻盘 | 现言、强制爱、打脸、爽文 | 夺权加清算 |
| 文艺向 | 现言、强制爱、群像、开放结局 | 氛围与余味为主 |

每组标签都要能回答一个问题：读者点进来会期待什么。期待与内容不符，前二十章就会流失大半。

### 13.10.2 标签的三个常见错误

错误一：把雷点写成卖点。写着“慢热”又写着“爽文”，读者会困惑。

错误二：标签互相矛盾。“甜宠”与“虐恋”同时出现，算法无法判断受众。

错误三：标签太泛。“言情”“爱情”这类大词，等于没有标签。
