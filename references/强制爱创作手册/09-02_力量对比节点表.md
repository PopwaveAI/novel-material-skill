# 9.2 力量对比节点表

> 素材来源：novel-material-skill ·《强制爱创作手册》9.2 力量对比节点表

这张表记录全书主导权的移动。它是一条曲线，不是一个状态。填完你就能看出，你的故事有没有一直在变化。

### 9.2.1 模板表

| 节点 | 章节 | 谁占优 | 优势来源 | 女主可选项数量 | 读者情绪 |
|---|---|---|---|---|---|
| 开局 |  | 男方绝对 |  | 1 到 2 | 窒息 |
| 第一次试探 |  | 男方 |  | 2 到 3 | 紧张 |
| 第一次失败 |  | 男方 |  | 1 | 憋闷 |
| 第一张小牌 |  | 男方略优 |  | 3 | 期待 |
| 第一次小胜 |  | 接近对等 |  | 3 到 4 | 解气 |
| 当众对峙 |  | 对等 |  | 4 | 爽 |
| 第一次清算 |  | 女方略优 |  | 5 | 紧张 |
| 全面反转 |  | 女方 |  | 6 以上 | 痛快 |
| 关系重置 |  | 双方对等 |  | 不限 | 复杂 |

第五列是全表的核心。她的可选项数量从一到二开始，一路涨到六以上，这个过程就是她的成长。如果这条线一直是二，说明你的女主从头到尾没有变化。

第六列记录读者的情绪。填完之后看这一列，如果连着三个节点都是“憋闷”，节奏一定出了问题。

### 9.2.2 填写方法

先把九个节点按你的篇幅分配章节。九节点分八十章，大约每九章一个。分完之后，看每两个节点之间有没有至少一次拉扯回合，没有就补。

再填第五列。填不出来，说明这个节点没有实际变化，删掉或者合并。九个节点里，真正有变化的通常只有五到六个。

最后填第六列。这一列要靠感觉，但感觉也要有依据：这个节点读者应该想看到什么。想不出来，说明这个节点没有情绪价值。

### 9.2.3 曲线的读法

一条健康的曲线应该呈锯齿上升：每次上升之后有一次回落，但整体向上。一路向上的曲线太顺，读者不信；一路向下的曲线太苦，读者会跑。

如果曲线在中间某一段完全平坦，说明你写了十章但局势没变。这一段必须加事件，否则读者会觉得原地踏步。
