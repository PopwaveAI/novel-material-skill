# 2.11 女主十二型速览与选型

> 素材来源：novel-material-skill ·《强制爱创作手册》2.11 女主十二型速览与选型

三种底子会长出十二种活法。速览给定位，选型讲匹配，看完这一节你应该能定下自己的女主。

### 2.11.1 十二型速览

| 型号 | 底子 | 一句话定位 | 标志动作 |
|---|---|---|---|
| 护弟型 | 弱而不屈 | 所有的忍都为了一个人 | 把药费单据折好收进内袋 |
| 守秘型 | 弱而不屈 | 知道得太多，所以不能走 | 别人问起往事就低头喝水 |
| 等时型 | 弱而不屈 | 低着头，等一个能一次翻盘的节点 | 数日子，用指甲在墙上划 |
| 棋手型 | 清醒对抗 | 把关系当棋局，落子不留情 | 说话前先看对方的袖口 |
| 职业型 | 清醒对抗 | 专业能力是她的第二条命 | 随身带着工具或笔记本 |
| 掌账型 | 清醒对抗 | 她记得每一笔人情与亏欠 | 吃饭时先算账再动筷 |
| 示弱型 | 柔顺藏反骨 | 哭是她的战术，不是她的情绪 | 眼泪掉下来之前先看四周 |
| 侍奉型 | 柔顺藏反骨 | 周到到让人害怕 | 记得所有人不吃什么 |
| 记账型 | 柔顺藏反骨 | 一本看不见的账，记了三年 | 把字写在别人看不到的地方 |
| 野草型 | 弱而不屈 | 打不死，也不需要人浇水 | 受伤自己包扎，不问人 |
| 锋利型 | 清醒对抗 | 不藏，直接顶回去 | 打断对方的话，一句顶三句 |
| 旧伤型 | 弱而不屈 | 被伤过一次，这次不肯再退 | 听到某个词会突然沉默 |

十二型里，前九型是主力，后三型是变奏。变奏型不适合做女主角，适合做女二或者前期的女主状态，因为它们太单一，撑不住四十万字。

### 2.11.2 与男主的匹配逻辑

匹配讲三条：压迫方式要对撞，反抗方式要互补，底线要能互相踩到。

▪ 对撞的压迫：掌权型男主配棋手型女主，两个人都在算，谁先露出破绽谁输，读者看得过瘾。

▪ 互补的反抗：疯批型男主配示弱型女主，一个明着来，一个暗着来，节奏有张有弛。

▪ 可踩的底线：男主的底线是“不许她走”，女主的底线是“不许动她弟弟”。两条底线在中段正面撞一次，全书最高潮就在那里。

不匹配的组合也有，但要有意识地用。比如黑恶型配锋利型，两个人都硬，冲突很足，但缺少柔的一环，容易写成一路对吼。要补一个软性配角来调和。

「匹配的检验」：写三场对手戏，如果三场都是同一个套路（他压、她顶），说明匹配太同质，需要换型或者加一层。

### 2.11.3 选型决策流程

第一步，定分支。分支决定压迫形态，也排除掉一半型号。

第二步，定女主的底子。你想写心疼、写爽、还是写悬念，三种诉求对应三种底子。

第三步，定匹配。在速览表里找压迫方式能对撞的那一型，找不到就说明分支选错了。

第四步，定副型。给女主加一层和她底子相反的特质，作为她的裂缝，比如棋手型加一层“其实很怕黑”。

四步走完不超过半小时。超过半小时说明你在纠结，而不是在选型，这时候应该先去写第一章。
