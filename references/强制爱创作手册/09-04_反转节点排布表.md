# 9.4 反转节点排布表

> 素材来源：novel-material-skill ·《强制爱创作手册》9.4 反转节点排布表

反转不是越多越好，是越准越好。这张表管的是“每个反转放在哪、埋在哪、收在哪”。

### 9.4.1 模板表

| 旧案翻出 | 四成处 |  | 一份旧文件 |  |  |
| 真实动机 | 五成处 |  | 他自己说漏 |  |  |
| 谁是内鬼 | 六成处 |  | 一次排查 |  |  |
| 底牌现身 | 七成处 |  | 她第一次拿出来 |  |  |
| 全面夺权 | 八成处 |  | 公开场合 |  |  |
| 清算落地 | 九成处 |  | 程序或舆论 |  |  |

第三列埋线和第五列影响范围是这张表的灵魂。埋线章节必须早于位置至少十章，否则反转会显得突然；影响范围决定这个反转要惊动多少人，只惊动两个人的反转不够分量。

### 9.4.2 八种反转的用法

身份反转：她的真实身份不是表面那样。放在两成处，用来解释前面所有的反常。这个反转要用一次，不能反复。

隐藏条款：契约里有一条她没看见的内容。放在两成五处，用来把局势再压一层，也给她一个反击的切口。

旧案翻出：一桩旧事被重新提起。放在四成处，用来连接两个人的过去，也用来引入新的敌人。

真实动机：他为什么非要她的真正原因。放在五成处，是全书的情感转折点。

谁是内鬼：身边有人背叛。放在六成处，用来制造信任危机，也用来清理配角线。

底牌现身：她手里的牌第一次亮出来。放在七成处，是全书的爽点起点。

全面夺权：主导权彻底易手。放在八成处，是全书的结构中心。

清算落地：结果真正发生。放在九成处，用来收束所有线索。

### 9.4.3 排布的三个纪律

纪律一：反转之间至少隔八章。太密，读者来不及消化；太疏，读者会忘。

纪律二：同类型的反转只用一次。用了两次身份反转，读者会怀疑你在注水。

纪律三：每个反转都要改变局势。只改变认知、不改变局势的反转，是伪反转，删。
