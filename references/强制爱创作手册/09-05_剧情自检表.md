# 9.5 剧情自检表

> 素材来源：novel-material-skill ·《强制爱创作手册》9.5 剧情自检表

这张表是定稿前用的。四十个检查点，全过一遍，能挡掉八成的常见问题。

### 9.5.1 自检表（前二十项）

| 序号 | 检查项 | 通过标准 |
|---|---|---|
| 1 | 绑定是否可验证 | 能说出凭证、持有人、期限 |
| 2 | 女主为何不跑 | 一句话答得出，且具体 |
| 3 | 男主动机是否两层 | 表层与深层都能说清 |
| 4 | 女主是否有主体性 | 每五章有一次自主行动 |
| 5 | 压迫是否可见 | 至少三处日常细节 |
| 6 | 是否有期限 | 有具体天数或事件节点 |
| 7 | 第一次反抗是否在前三章 | 第三章内出现 |
| 8 | 第三章是否有爽点 | 有一次女主小胜 |
| 9 | 配角是否各司其职 | 一人一功能，不重复 |
| 10 | 设定是否前后一致 | 能能力与不能能力列清 |
| 11 | 情感转折是否有过渡 | 每次变化前有自我说服 |
| 12 | 清算是否分三步 | 证据、程序、结果 |
| 13 | 是否有喘息章节 | 每三章一次 |
| 14 | 章末钩子是否重复 | 十二式轮换使用 |
| 15 | 反转是否埋过线 | 每个反转前有至少两处铺垫 |
| 16 | 重要场景是否有物件 | 一场戏一个锚点 |
| 17 | 台词是否过长 | 支配方不超过十五字 |
| 18 | 视角是否混乱 | 切换处有明确标记 |
| 19 | 结尾是否三章内收完 | 不超过三章 |
| 20 | 全书是否有立场 | 明确指出强制是错的 |

二十项里，最容易出问题的是第五、第十、第二十。第五项决定压迫感真不真，第十项决定读者信不信，第二十项决定这本书能不能发。

### 9.5.2 自检表（后二十项）

| 序号 | 检查项 | 通过标准 |
|---|---|---|
| 21 | 男主的软肋是否存在 | 能让他失去一切的东西 |
| 22 | 女主是否有独特技能 | 具体到能解决问题 |
| 23 | 是否有第三方制衡 | 监管、舆论或另一势力 |
| 24 | 情敌是否照镜子 | 她照见女主的缺口 |
| 25 | 辅助方是否付代价 | 帮忙的人失去过什么 |
| 26 | 施压方是否有私心 | 他的动机不是纯工具 |
| 27 | 是否有沉默的旁观者 | 舆论压力被写过 |
| 28 | 男主的破例是否有代价 | 每次破例都失去东西 |
| 29 | 女主的胜利是否靠自己 | 不是靠天降贵人 |
| 30 | 是否有工业虐感 | 误会与巧合不超过三次 |
| 31 | 是否有重复桥段 | 同一桥段不超过两次 |
| 32 | 是否有人物 OOC | 行为都能对应规矩卡 |
| 33 | 是否有注水章节 | 每章都有变化 |
| 34 | 是否有高危写法 | 对照 7.5 节逐条过 |
| 35 | 清算是否被豁免 | 没有任何豁免 |
| 36 | 结局是否与反转强度匹配 | 强度对得上形态 |
| 37 | 是否有余味 | 结尾留一件未完成的事 |
| 38 | 标题是否与内容相符 | 不夸大、不误导 |
| 39 | 简介是否准确 | 承诺的东西书里都有 |
| 40 | 标签是否合规 | 不碰敏感词 |

后二十项里，最容易漏的是第二十九与第三十五。前者决定爽感真不真，后者决定这本书的立场站不站得住。

### 9.5.3 自检的执行方式

不要一次全查。分三次：第一次查前二十项，重点在结构；第二次查后二十项，重点在细节；第三次只查第三十四与第三十五，重点在合规。

每次查完，把不通过的项写在一张纸上，按严重程度排序。先改致命的，再改观感。全改一遍通常要三天，改完再通读一次。
