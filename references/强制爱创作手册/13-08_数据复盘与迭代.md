# 13.8 数据复盘与迭代

> 素材来源：novel-material-skill ·《强制爱创作手册》13.8 数据复盘与迭代

运营不是凭感觉，是看数据。但数据只能告诉你哪里有问题，不能告诉你该怎么改。

### 13.8.1 四个观测指标

指标一：点击转化率。看到封面与书名的人里，有多少点进来。这个数字低，问题在书名与封面。

指标二：首章完读率。点进来的人里，有多少读完第一章。这个数字低，问题在开篇。

指标三：追读率。读完一章的人里，有多少打开下一章。这个数字低，问题在钩子。

指标四：评论率。读完的人里，有多少留下评论。这个数字低，问题在话题埋点。

四个指标对应四个环节。按顺序看，不要跳着看，因为前面的问题会掩盖后面的问题。

### 13.8.2 复盘的方法

每周一次，用半小时，看四个指标的变化。变化超过两成，就值得追查原因。

每月一次，用两小时，做一次完整复盘：这个月做了什么动作、哪些动作有效、哪些无效。写成三行字，存档。

每卷一次，用半天，做一次内容复盘：这一卷的节奏、人物、钩子，哪些地方读者反应最好。这些反应就是下一卷的方向。

### 13.8.3 迭代的三个原则

原则一：小步改。一次只改一个变量，改完看数据。一次改三个，你永远不知道是哪个起了作用。

原则二：不改核心。书名可以改、标签可以改、简介可以改，但故事的核心不能为了数据改。改了核心，书就散了。

原则三：不听骂声改人物。读者的骂往往是因为入戏。看到骂男主，先判断是“他太坏了”还是“他坏得没道理”。前者是成功，后者是问题。

### 13.8.4 连载期的运营日历

| 时间 | 动作 | 目标 |
|---|---|---|
| 开更前一周 | 定书名、标签、简介，做三条短视频素材 | 解决点击转化 |
| 开更第一周 | 每天固定时间更新，回复所有评论 | 解决首章完读 |
| 第二到第四周 | 每三章一个钩子，每周一次账号内容 | 解决追读率 |
| 第一个月 | 第一次数据复盘，调整标签与简介 | 修正方向 |
| 第二到第三个月 | 埋入第一第二个争议点，开始做长评引导 | 做讨论度 |
| 完结前两周 | 发布完结预告，准备创作手记 | 做完结期热度 |
| 完结后一个月 | 集中发布回顾内容，整理长评 | 做口碑沉淀 |
| 完结后三个月 | 每月一到两条，做旧文重发与读者提问 | 做长尾 |

这张日历不必严格照做，但顺序不要乱。开更前不准备好书名与简介，后面补的每一分力气都要打折。

### 13.8.5 三种常见的运营误区

误区一：把宣传当运营。宣传是让别人知道你，运营是让别人留下来。前者一次性的，后者是持续的。

误区二：追热点追到忘了书。热点能带来一波流量，但来的人不是你的读者，留不住。

误区三：数据好看就改方向。数据涨了，说明这个方向对；数据掉了，说明这个动作错。不要把两件事混起来。
