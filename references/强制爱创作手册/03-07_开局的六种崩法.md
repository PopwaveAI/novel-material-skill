# 3.7 开局的六种崩法

> 素材来源：novel-material-skill ·《强制爱创作手册》3.7 开局的六种崩法

开局崩掉的书，九成不是因为写得不好，是因为作者急着往后写。这一节把六种最常见的崩法列出来，对照自查。

### 3.7.1 崩法一：绑定来得太容易

症状：女主一句"我答应"就进了局，读者不明白她为什么不拒绝。根因是作者把绑定写成了选择，而不是没有选择。

修法：在她说"我答应"之前，先给她一个走不通的路。她求过三个人，三个都拒绝了；她算过账，钱差得太远。走过一遍绝路，她的答应才有重量。

「检验」：把第一章的"她答应"删掉，看她还能不能活。还能活，说明绑定不成立。

### 3.7.2 崩法二：男主出场太晚

症状：前三章都在写女主的处境，男主第三章末尾才出现。读者在没有压迫的时候不会紧张，只会觉得闷。

修法：男主不必露面，但他的权力必须露面。第一章让他的司机来、第二章让他的律师来、第三章让他本人来。权力先到，人后到。

### 3.7.3 崩法三：压迫全靠台词

症状：男主每一章都在放狠话，但读者不觉得可怕。根因是压迫没有落到具体的事上。

修法：把三句狠话换成三件小事。门禁改了、药停了、她的名字从名单上被划掉了。事情比语言狠。

### 3.7.4 崩法四：女主开局就太强

症状：第一章她就把男主怼得说不出话，读者觉得这两个人势均力敌，后面没得看。

修法：把她的强留在心里，不留在嘴上。她可以看穿一切，但只能沉默。沉默的强者比开口的强者更有张力，也更能撑住后面的爆发。

### 3.7.5 崩法五：信息给得太满

症状：第一章就把男主的过去、女主的秘密、两个人的渊源全部交代完。读者没有疑问，也就没有追读动力。

修法：第一章只给三成信息，留七成。留下的部分要留得有心机：不是"以后再讲"，而是"这里有个不对劲的地方"。

### 3.7.6 崩法六：开局没有期限

症状：读者不知道这个局要持续多久，也不知道什么时候能结束，于是失去耐心。

修法：第一章末尾给一个数字。"三个月""到明年春天""到那笔账还清"。一个数字，读者就有了等待的理由。

| 崩法 | 一句话症状 | 最快修法 |
|---|---|---|
| 绑定太易 | 她为什么答应，读者不服 | 先写一条走不通的路 |
| 男主太晚 | 前三章没有压迫 | 让权力先出场 |
| 压迫靠台词 | 狠话多，事少 | 换成三件具体的小事 |
| 女主太强 | 开局就势均力敌 | 强在心里，不在嘴上 |
| 信息太满 | 第一章全交代完 | 只给三成，留七成 |
| 没有期限 | 读者不知道等多久 | 给一个具体数字 |
