# 1.8 本册怎么用

> 素材来源：novel-material-skill ·《强制爱创作手册》1.8 本册怎么用

这本册子不是读完就完的教材，是写到卡住时回来翻的工具。三种读法，对应三个写作阶段。

### 1.8.1 三种读法

开书前读一遍第一部分、第二部分、第三部分，把赛道、人设、开局定下来。这一步花两小时，能省后面二十小时。

写到卡住时读第四部分、第五部分、第六部分，找节奏、找桥段、找话术。这三部分是工具箱，按需取用。

定稿前读第七部分、第十四部分，做合规与质量两道检查。这一步不能跳，跳了就是给自己埋雷。

### 1.8.2 编号与跳转规则

全书编号规则固定：部分用“第X部分”，节用“X.X”，条目用“X.X.X”。所有跳转只写编号，例如“详见 4.3 节”，不写“见前文”“见后文”，避免你自己回头找不到。

本册所有案例、样段、模板均为本册内部素材，不引自任何外部作品。你要仿写，直接照着样段的结构改，不必去别处找范本。

### 1.8.3 开书前的准备清单

| 准备项 | 要定下来的内容 | 对应章节 |
|---|---|---|
| 赛道分支 | 九个分支里选一个主分支，最多加一个错层分支 | 1.5、1.6 |
| 合规基线 | 列出本书可能触碰的黄区内容，写好处理方案 | 1.7、7.4 |
| 男主型号 | 从十二型里选一个主型，加一个反差副型 | 2.2 至 2.7 |
| 女主型号 | 从十二型里选一个主型，明确她的四级反抗路径 | 2.8 至 2.11 |
| 绑定方式 | 五种绑定选一到两个，写清凭证与期限 | 3.1 |
| 开局三章 | 三章各干什么，章末钩子是什么 | 3.7 |
| 阶段刻度 | 七阶段各占多少章，峰值在第几章 | 4.1 |
| 结局形态 | 四类结局选一个，主清算定一种 | 11.1 |

这张清单填完，你手上就有了一份可以开写的地基。填不完不要动笔，动笔之后返工的成本是现在的五倍。
