# 3.10 压迫环境的九个细节

> 素材来源：novel-material-skill ·《强制爱创作手册》3.10 压迫环境的九个细节

环境不是布景，是压力的一部分。九个细节，每一个都能单独撑起一场戏。

### 3.10.1 门的三种状态

第一种是能锁的门。锁在外面，钥匙只有他有。这种门写的是绝对控制，适合开局。

第二种是不能锁的门。门一直是虚掩的，谁都可以进来。这种门写的是失去隐私，比锁更难受。

第三种是没有门的房间。她住的地方没有门，只有一道帘子。这种写法最狠，也最需要谨慎处理。

三种门可以递进：从能锁，到不能锁，到最后没有门。递进的过程就是她失去边界的过程。

### 3.10.2 光的三层

第一层是屋里的灯。灯的位置、亮度、开关的人，都在说明谁有权力。她不能关灯，就是被看着。

第二层是窗外的光。她能看见外面，但出不去。这种可视而不可达，是最折磨人的。

第三层是白天与黑夜的区分。她的作息被他安排，白天黑夜对她失去意义。这一层最容易被忽略，也最有力量。

### 3.10.3 声音的四类

第一类是他的脚步。她能分辨出哪一种是他，这说明她已经被训练得熟悉。

第二类是楼下的车声。车来了意味着他要回来，车走了意味着他不在。她的时间被车声切割。

第三类是别人的说话声。隔着一堵墙，她听得见但听不清。这种半知半解最让人焦躁。

第四类是完全没有声音。安静本身也是一种压迫，尤其是当她知道有人就在门外。

### 3.10.4 物件的三重功能

第一重是实用：杯子能喝水，钥匙能开门。这一重负责让场景可信。

第二重是象征：杯子摆在谁的面前，钥匙在谁的口袋。这一重负责传递权力关系。

第三重是伏笔：那个被磨掉字的戒指、那张被撕掉一页的账本。这一重负责后文的回收。

一件好物件，三重功能都能承担。写场景时先选物件，再安排动作，戏就有骨头了。

### 3.10.5 九个细节的组合

| 细节 | 指向 | 适合阶段 |
|---|---|---|
| 锁在外面的门 | 绝对控制 | 强制绑定 |
| 虚掩的门 | 失去隐私 | 抗拒挣扎 |
| 没有门的房间 | 抹除边界 | 失控越界 |
| 她关不了的灯 | 被监视 | 暗中博弈 |
| 看得见出不去的窗 | 可视不可达 | 全阶段 |
| 被安排的昼夜 | 时间被夺 | 动摇裂隙 |
| 她能认出的脚步 | 被训练 | 抗拒挣扎 |
| 车声 | 他的在與不在 | 全阶段 |
| 听不清的说话声 | 半知半解 | 暗中博弈 |

九个细节不必全用。挑三到四个贯穿全书，读者会形成条件反射，一看见就紧张。
