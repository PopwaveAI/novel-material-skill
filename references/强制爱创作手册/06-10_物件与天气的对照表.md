# 6.10 物件与天气的对照表

> 素材来源：novel-material-skill ·《强制爱创作手册》6.10 物件与天气的对照表

氛围不是形容词堆出来的，是具体的物与具体的天气。这一节给两张某册内部的对照表，用的时候按场景查。

### 6.10.1 物件对照表

| 物件 | 暗示 | 适用场景 |
|---|---|---|
| 钥匙 | 谁掌握进出 | 绑定、夺权、放手的节点 |
| 茶杯 | 谁在服务谁 | 对峙、日常、示弱 |
| 文件 | 规则与证据 | 压制、清算、谈判 |
| 外套 | 她能不能出门 | 限制、天气、离开 |
| 药瓶 | 她的牵挂 | 软肋、交换、威胁 |
| 日历 | 时间与期限 | 倒计时、等待、到期 |
| 相框 | 过去与身份 | 揭示、替身、旧案 |
| 账本 | 记账与清算 | 隐忍、博弈、反杀 |
| 灯 | 有人等或没人等 | 归来、静场、结尾 |
| 伞 | 靠近与遮蔽 | 暧昧、照顾、送别 |

表的用法是反查。写一场戏前，先定这场戏的核心物件，再让所有的动作围着它转。一场戏一个物，多了就散。

### 6.10.2 天气对照表

| 天气 | 情绪指向 | 常见用法 |
|---|---|---|
| 雨 | 压抑与共处 | 同一把伞，同一间屋檐 |
| 雪 | 干净与冷却 | 关系降温或彻底结束 |
| 风 | 外部的力量 | 她被迫留在原地的理由 |
| 阴天 | 不确定 | 信息不全的场面 |
| 大晴 | 表面的平静 | 用亮光反衬人物内心的阴影 |
| 雾 | 看不清 | 误判与错认 |

天气不要用来替代情绪。下雨不等于她难过，应该写“下雨，她还是出了门”。天气与动作连在一起，才有意义。

### 6.10.3 组合示例

样段：雨从下午开始下。她站在门口，手里拿着那把旧伞，没有撑开。他把车停在台阶下，没有下来，也没有走。两个人都听见雨打在地上的声音。

批注一：伞没有撑开，说明她还在犹豫。车没有走，说明他在等。两个“没有”，把僵持写完了。

批注二：雨在这里不是情绪，是计时器。雨声说明了时间在过去。

批注三：全段没有一句写“他们都不想先动”，但读者完全明白。

### 6.10.4 用错的两个例子

错法一：天阴沉沉的，就像她的心情。这是把天气当形容词用，读者不会被打动。

错法二：大雨滂沱，她的眼泪也流了下来。这是天气与情绪重复，浪费了一个好意象。

正确的做法是让天气与人物做对。她越难过，天越晴；她越想留，风越大。反差比顺应更有力。
