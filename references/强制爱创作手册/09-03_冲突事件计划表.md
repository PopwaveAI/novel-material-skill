# 9.3 冲突事件计划表

> 素材来源：novel-material-skill ·《强制爱创作手册》9.3 冲突事件计划表

这张表管的是“每一章到底发生了什么”。它把抽象的冲突变成具体的事件，也把节奏变成可以看见的排布。

| 第 2 章 | 处境具体化 | 男方 |  |  |  |
| 第 3 章 | 第一次反抗 | 女方 |  |  |  |
| 第 4 章 | 加码 | 男方 |  |  |  |
| 第 5 章 | 外部求援 | 女方 |  |  |  |
| 第 6 章 | 求援失败 | 外力 |  |  |  |
| 第 7 章 | 缓冲日常 | 无 |  |  |  |
| 第 8 章 | 第二次加码 | 男方 |  |  |  |

六列里，最后一列最重要。它逼你在写这一章的时候就想到下一章。写完一章想不出钩子，说明这一章没有推动力。

第三列记录谁发起。如果连续五章都是男方发起，说明女主在被动挨打，需要给她一次主动出手。

### 9.3.2 事件类型的六种

类型一：绑定类。建立或强化关系的事件。开局用，中段偶尔用来收紧。

类型二：加码类。男方主动施压，收紧限制或者提高代价。全书十五到二十次。

类型三：反抗类。女方主动出手，试探、求助、布局、摊牌。全书十到十五次。

类型四：外部类。第三方介入，改变局势。全书八到十二次。

类型五：缓冲类。日常、温情、幽默，用来给读者喘气。全书十次左右。

类型六：转折类。改变故事走向的大事件。全书三到五次。

六种类型的配比建议：加码三成、反抗两成五、外部两成、缓冲一成五、绑定与转折各占一成。配比失衡，节奏就会偏。

### 9.3.3 表格的使用节奏

不要一次填八十章。填前十章，写完再填下一个十章。填得太远，写的时候会被表绑住，反而僵硬。

每填完十章，回头看两类东西：事件类型有没有偏、钩子有没有重复。这两样是最容易走形的地方。
