# 7.5 安全写法与高危写法对照

> 素材来源：novel-material-skill ·《强制爱创作手册》7.5 安全写法与高危写法对照

这一节把常见的二十个场景并排放。左边是安全写法，右边是高危写法，中间是替代方案。写完之后对照一遍，能省掉大半麻烦。

### 7.5.1 对照表

| 场景 | 安全写法 | 高危写法 | 替代方案 |
|---|---|---|---|
| 限制人身 | 写门禁、日程、随行三重锁定 | 写具体拘禁工具与空间细节 | 写她连出门都要算日子 |
| 言语羞辱 | 写旁观者的沉默与她的事后反应 | 写具体的辱骂内容与过程 | 写她回房后先做的事 |
| 肢体冲突 | 事发前切镜头，事后写结果 | 写打斗过程与伤害细节 | 写第二天谁来了、谁走了 |
| 心理操控 | 写她如何识破并反制 | 写完整的话术与步骤 | 写她一句反问让局失效 |
| 以把柄要挟 | 写把柄指向她最在意的人 | 写具体的违法手段 | 写她把柄被反用的那一刻 |
| 权力胁迫 | 写流程、审批、拖延 | 写权力如何碾压的细节 | 写她卡在一个没有名字的环节 |
| 囚禁 | 写空间与时间的封闭感 | 写锁具、路线、看守安排 | 写窗外的路被封了 |
| 药物相关 | 不写，改写她的身体状态 | 写药名、剂量、来源 | 写她醒来时天已经黑了 |
| 情感绑架 | 写绑架背后的空虚 | 写操控的成功案例 | 写她主动摊牌的那一夜 |
| 强制婚姻 | 写名分与家族利益结构 | 写强迫的过程细节 | 写她签字时笔尖停了几秒 |
| 暴力审美 | 写后果与代价 | 写暴力的美感与仪式 | 写他毁自己的东西，手在抖 |
| 自伤 | 写她坐在楼梯上一整夜 | 写具体方式与工具 | 写她第二天的手在抖 |
| 跟踪监视 | 写信息差带来的窒息 | 写具体跟踪方法与设备 | 写他准确说出她昨天几点到家 |
| 身份伪造 | 写她被换了名字之后的不适 | 写伪造流程与材料 | 写她听见别人叫那个名字时愣住 |
| 经济控制 | 写卡刷不出来、房租被截断 | 写具体的洗钱与转移手段 | 写她在柜台前站了很久 |
| 家族压迫 | 写规矩与执行者的冷漠 | 写具体的体罚与家法 | 写她被请出祠堂那天下着雨 |
| 舆论羞辱 | 写闲话与眼神 | 写有组织的污名化操作 | 写一条朋友圈让她三天没出门 |
| 以命相逼 | 写她站在门口没有动 | 写具体的威胁方式 | 写他把钥匙放在桌上说“你走吧” |
| 失控占有 | 写他毁掉自己最在意的东西 | 写他对她的伤害过程 | 写他背过身去，指节发白 |
| 结局清算 | 写程序、舆论、权力的反噬 | 写私刑与报复的快感 | 写他签下那份文件时手很稳 |

这张表可以直接当改稿清单用。写完一卷，把涉及场景的行对一遍，落在第三列的就改。改的时候优先用第四列，因为第四列通常比第一列更有戏。

### 7.5.2 对照表的使用方法

第一步，标出全书涉及强张力的场景，通常二十到三十处。第二步，逐条对照，把落在高危列的圈出来。第三步，用替代方案改写，改完再读一遍，看张力有没有掉。

张力掉了，说明替代方案选得太保守。换一个更靠前的方案，或者把镜头调得更近一点。安全不等于平淡，好的替代方案往往比原写法更有余味。
