# 3.6 开局三章的设计

> 素材来源：novel-material-skill ·《强制爱创作手册》3.6 开局三章的设计

前三章决定读者去留。三章各有任务，任务不能混：第一章立局，第二章立人，第三章立志。

### 3.6.1 第一章：绑定落地

第一章只做一件事：让读者相信这个关系成立。写法上要快，前三百字必须出现强制信号。

第一章的四个必备信息：她是谁（职业或身份，一句话）、她缺什么（具体的困境）、他凭什么（一句台词或一个动作）、她为什么答应（一个无法拒绝的理由）。

第一章不要写男主的深情，也不要写女主的心理长句。写事，写动作，写一句让人后背发凉的台词。

示例结构：她在医院走廊拿到一张缴费单，数字后面有四个零；她转身，看见他站在走廊尽头，手里拿着同一张单子；他说“我可以付。你跟我走。”她问“多久”，他说“我说了算。”

「第一章的禁忌」：不要开场写景，不要开场写回忆，不要开场写女主的容貌。这三样都在消耗读者的耐心。

### 3.6.2 第二章：处境具体化

第二章要让读者看见牢笼的形状。住哪、几点起、谁能见、什么不能碰，四件事说清楚，读者就有了空间感。

第二章要出现第一个配角，最好是一个执行规则的人：管家、司机、助理、门卫。配角的冷漠比男主的强硬更能制造压迫。

第二章要给女主一次微小的反抗，且必须失败。失败要具体：她想打电话，手机没电；她想出门，门锁着；她想问清楚，对方不回答。

「第二章的节奏」：一章之内完成"看清处境、见到执行者、尝试反抗、反抗失败"四步。四步紧凑，读者不会觉得慢。

### 3.6.3 第三章：第一次反制

第三章必须给读者一个爽点，哪怕很小。女主用他的规则卡他一次、用一个细节让他改口、用一句话让他沉默三秒。

这次反制要让男主第一次正眼看她。不是爱上，是"这个人有点意思"。这个转变要写得极轻，只是一秒钟的停顿。

反制之后要立刻加码。他因为她这一次反制，收紧了一条规矩。读者刚爽一下就被压回去，这种落差最能勾人。

示例：她说“合同第七条写的是每周一次外出，今天是本周第三次申请，您已经拒了两次。”他看了她三秒，说“那就今天。”转身却让人把门禁改成了双人确认。

### 3.6.4 三章的钩子配置

| 章节 | 钩子类型 | 示例 |
|---|---|---|
| 第一章末 | 悬念钩 | 她签完字，看见第七条被人用铅笔圈过 |
| 第二章末 | 危机钩 | 她藏起来的手机在第二天出现在餐桌上 |
| 第三章末 | 反转钩 | 她反制成功，却发现门外多了一把新锁 |

三个钩子要层层升级：第一个是信息缺口，第二个是安全威胁，第三个是希望破灭。三种情绪一轮，读者就被拴住了。

### 3.6.5 开局自检表

| 检查项 | 通过标准 |
|---|---|
| 绑定是否可验证 | 能说出凭证是什么、在谁手里 |
| 女主为何不跑 | 能一句话答出，且理由具体 |
| 男主凭什么 | 有一个具体动作或台词，不是旁白 |
| 压迫是否可见 | 至少三处日常细节 |
| 是否有期限 | 有明确的天数、月数或事件节点 |
| 第三章是否有爽点 | 有一次女主的小胜 |
| 三个章末钩子 | 类型不重复，强度递增 |

七项全过，开局就立住了。有任意一项没过，不要往下写，返工成本会越滚越高。
