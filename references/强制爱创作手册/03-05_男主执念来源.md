# 3.5 男主执念来源

> 素材来源：novel-material-skill ·《强制爱创作手册》3.5 男主执念来源

执念不能是天生的，必须有出处。出处越具体，人物越可信；出处越含糊，读者越觉得作者在硬凑。

### 3.5.1 八种执念来源

| 来源 | 核心逻辑 | 写法要点 | 适配分支 |
|---|---|---|---|
| 替代 | 她像某个失去的人 | 给一个相同的细节，反复出现 | 悬疑、古言 |
| 证明 | 留住她等于证明自己不是废物 | 写他输过的那一次 | 权贵、职场 |
| 补偿 | 他欠过一个人，想在她身上还 | 让他的补偿方式伤人 | 古言、宫廷 |
| 习惯 | 看了太久，看成了必须 | 写他多年前第一次见她 | 现言、校园 |
| 恐惧 | 怕再被抛弃，所以先抓住 | 写他被丢下的那个晚上 | 阴郁、囚禁 |
| 占有 | 他的东西不许别人碰 | 写他对物件的态度 | 黑道、疯批 |
| 征服 | 越难得到越想要 | 写他第一次被拒绝 | 掌控、权贵 |
| 责任 | 他答应过某人要护着她 | 写那个承诺的场合 | 守序、案件 |

八种里，最耐写的是"习惯"和"恐惧"，因为它们没有戏剧性，只有时间。最难写的是"征服"，因为它最容易滑向"她不爱我我就要毁了她"这种廉价逻辑。

### 3.5.2 执念的合理化

执念必须能被读者理解，哪怕不认同。理解和不认同之间的落差，就是这个角色的魅力。

合理化的三个步骤：给一个具体的过去、给一个具体的当下、给一个具体的代价。过去解释他为什么这样，当下解释他为什么还在这样，代价解释他为此失去了什么。

三步写完，读者会想"原来他是这样变成这样的"，而不是"作者为什么让他这样"。这一句差别，就是人物成立与不成立的分界。

「合理化的边界」：合理化不是洗白。理解他的成因，不等于原谅他的行为。代价必须照付，这是底线。

### 3.5.3 执念的可视化

执念要变成看得见的东西：一间保存了十年的屋子、一本翻烂的相册、一条从不换的领带、一个每年同一天必去的地方。

可视化的好处是省字。不用写"他很执着"，写"他每年那天都会去码头站一个小时"，读者自己就懂了。

这些物件最好在前期出现三次：第一次不提原因，第二次给一点暗示，第三次揭开。三次之后，这个物件就成了这本书的符号。

「物件的选择」：选便宜的东西。一枚旧纽扣比一块名表更有说服力，因为便宜的东西留下来，一定是舍不得。

### 3.5.4 执念的裂缝

执念必须有裂缝，否则人物无法转变。裂缝通常出现在三个地方：他发现她不是他以为的那个人、他发现自己的手段伤害了他想护的东西、他发现没有她他也能活。

第三个裂缝最动人，因为它意味着放手。全书把这条裂缝留到最后，让他自己承认"我不是非你不可"，这一句比任何告白都有分量。
