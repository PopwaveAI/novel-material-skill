# 9.5 单章结构卡

> 素材来源：novel-material-skill ·《网文写作技巧·结构篇》9.5 单章结构卡

### 9.5.1 表格结构

单章卡有八项：章号、任务、主视角、起点处境、终点处境、核心选择、小高潮、收尾钩子。八项填完，这一章就可以动笔。填不完，说明这一章还没想清。

“核心选择”这一栏最容易被空着。很多人写章节只写“她做了什么”，不写“她选了什么”。没有选择的章节，人物不会成长，读者也不会更认识她。

表 9-4 单章结构卡模板

| 项目 | 填写内容 | 自检 |
|---|---|---|
| 章号 | 第 X 章 | 与卷规划表对得上 |
| 任务 | （动词开头的一句话） | 能否判断完成 |
| 主视角 | （这一章跟谁走） | 是否只换一次 |
| 起点处境 | （章首位置） | 接上章结尾 |
| 终点处境 | （章末位置） | 是否有不可逆变化 |
| 核心选择 | （两难，选一个） | 是否暴露性格 |
| 小高潮 | （兑现什么） | 是否有外部反应 |
| 收尾钩子 | （具体未完成） | 下章能否接住 |

### 9.5.2 填写要点

任务要写成“动词加对象”，比如“拿到账册”“赶走收房的人”“说服族老会三房”。不要写“推进剧情”“展现人物”，那不是任务，是效果。

终点处境要写成“她从此不能再……”。写不出来，说明这一章没有位移。有位移的章节，读者读完会觉得“事情变了”；没有位移的章节，读者只会觉得“又看了一段”。

### 9.5.3 卡片的使用

卡片可以写在纸上，也可以放在文档里。关键是要“写前填、写后回填”。写前填计划，写后填实际，两者不一致时，要么改下一章，要么回头改这一章。

卡片不必长期保存。一卷写完，把这一卷的卡打包归档，下一卷重新开始。归档的价值是复盘：回头看看哪些卡填得准，哪些卡经常失效，就知道自己的结构感在哪里薄弱。
