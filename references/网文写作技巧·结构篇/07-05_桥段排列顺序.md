# 7.5 桥段排列顺序

> 素材来源：novel-material-skill ·《网文写作技巧·结构篇》7.5 桥段排列顺序

### 7.5.1 顺序决定情绪

同样的三个桥段，排列顺序不同，读者的感受完全不同。先打脸再救援，读者觉得主角强；先救援再打脸，读者觉得主角有情有义。桥段本身不带情绪方向，顺序带。

排列的基本原则是“先抑后扬”与“先扬后抑”交替。连续三个扬，读者会麻；连续三个抑，读者会跑。一抑一扬，或者两抑一扬，是最稳的节奏。

### 7.5.2 三种经典排列

第一种是阶梯式：小打脸、中打脸、大打脸，强度递增。适合卷末高潮。第二种是回环式：打脸、被反打、再打回去。适合中期，读者会觉得局势在反复。第三种是嵌套式：一个桥段里套另一个桥段，比如在宴席上打脸，打脸的过程中揭晓身份。

三种排列里，嵌套式最省篇幅，也最容易写乱。用嵌套式要先画清主壳与内壳的边界：主壳是宴席，内壳是身份揭晓。内壳结束，要回到主壳，不能一直沉在里层。

### 7.5.3 排列的禁忌

第一，不要连着用同一个桥段。第二，不要在同一个场景里塞三个以上的桥段。第三，不要把最强的桥段放在开头。第四，不要让桥段的顺序与服务对象冲突：卷末要收束，不能再用“身份揭晓”开新局。

第四条最容易被忽略。很多作者在卷末安排一个身份揭晓，读者刚被震到，卷就结束了，情绪没有落地。卷末的桥段应该服务“结账”，而不是“开新账”。
