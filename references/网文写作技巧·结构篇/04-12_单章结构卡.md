# 4.12 单章结构卡

> 素材来源：novel-material-skill ·《网文写作技巧·结构篇》4.12 单章结构卡

### 4.12.1 一张卡写一章

写每一章之前，先填一张卡：这一章的任务、主视角、起点处境、终点处境、核心选择、小高潮、收尾钩子、下一章接什么。八项填完，动笔就不会跑偏。

表 4-4 单章结构卡模板

| 项目 | 填写要求 | 示例 |
|---|---|---|
| 章节任务 | 一句话，动词开头 | 拿到西街铺子的账册 |
| 主视角 | 这一章跟谁走 | 女主 |
| 起点处境 | 章首她处在什么位置 | 被二叔的人挡在门外 |
| 终点处境 | 章末她的位置变化 | 进了门，拿到半本账册 |
| 核心选择 | 两难，选一个 | 当场翻脸还是先忍下 |
| 小高潮 | 兑现什么 | 用一句话点破账册缺页 |
| 收尾钩子 | 具体未完成 | 缺的那几页，墨迹是新的 |
| 下章接口 | 下一章第一段接什么 | 她连夜去找抄账的老先生 |

### 4.12.2 卡的使用节奏

短章可以两张卡合成一张，长章可以一张卡拆成两张。关键不是卡的数量，而是每一项都要填实。填不出来的项，就是这一章会卡住的地方。

写完一章，回填一次“实际终点处境”。如果实际与计划差太多，要么改下一章的卡，要么回头改这一章。不回填的卡，写三十章之后就会完全失效。
