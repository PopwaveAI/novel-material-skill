# 1.12 结构设计前的八项输入

> 素材来源：novel-material-skill ·《网文写作技巧·结构篇》1.12 结构设计前的八项输入

### 1.12.1 没有输入就没有结构

结构不是凭空想出来的。动笔之前，至少有八项信息必须先确定，否则设计出来的骨架一定是空的。这八项输入不需要一次想全，但必须在写前五章之前有草稿，否则会在三十章左右开始返工。

表 1-6 结构设计的八项输入

| 输入项 | 要回答的问题 | 不确定的后果 |
|---|---|---|
| 主角欲望 | 他最想要什么，愿意付出什么 | 主角变成推动剧情的工具 |
| 终局画面 | 最后一场戏是什么样子 | 后期无处可去，只能加地图 |
| 对手量级 | 最大的敌人强到什么程度 | 中后期威胁失效，爽感疲软 |
| 赛道兑现 | 读者等的那个东西是什么 | 写了很多，读者没拿到想要的 |
| 篇幅体量 | 计划写多少字，分几卷 | 节奏与卷长错配，越写越散 |
| 更新产能 | 每天能写多少，多久休一次 | 高潮颗粒度与更新节奏打架 |
| 分发平台 | 免费流量还是付费订阅 | 钩子密度与兑现节奏选错 |
| 读者画像 | 谁在看，他们在意什么 | 情绪设计对不上目标读者 |

### 1.12.2 输入之间会互相约束

八项输入不是八张独立的表，它们互相牵制。篇幅决定卷数，卷数决定每卷的承重章数量，承重章数量决定高潮之间的间距，间距又决定更新节奏能不能兜住。只改其中一项，其他项必须跟着调。

最常见的错配是篇幅与对手量级不匹配。计划写一百万字，却只设计了三层对手，写到四十万字就没得打了，只能临时加设定。正确做法是先算清需要多少次升级：一百万字的书，通常需要五到七个明确的对手层级，每层支撑十五到二十万字。

第二常见的错配是更新产能与高潮设计不匹配。一个需要连续铺垫五章的高潮，在日更两千的节奏里要写五天半，读者会有明显的等待疲劳。这种情况下要么压缩铺垫章数，要么在铺垫章里塞入独立的小兑现，不能硬熬。

### 1.12.3 输入的确认顺序

建议按这个顺序确认：先定终局画面，再定主角欲望，再定对手量级，再定赛道兑现，最后才是篇幅、产能、平台、读者。原因是前三项决定故事能不能立住，后四项决定它能不能被写出来。很多人反过来，先算字数、先看平台，再想故事，结果写出来的东西是合规的，但不好看。

八项输入确认之后，写成一页纸放在手边。每次卡文，先看这一页，通常能发现是某一项输入本身含糊，而不是当天状态不好。结构问题几乎从不表现为“写不出来”，而是表现为“写出来之后不知道往哪去”。
