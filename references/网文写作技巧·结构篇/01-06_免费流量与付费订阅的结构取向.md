# 1.6 免费流量与付费订阅的结构取向

> 素材来源：novel-material-skill ·《网文写作技巧·结构篇》1.6 免费流量与付费订阅的结构取向

### 1.6.1 两种分发逻辑下的结构差异

免费流量模式靠广告分成，核心指标是阅读时长与持续打开，结构取向是“留住”：钩子要密，章节要短，情绪要连续，尽量不让读者有空档离开。付费订阅模式靠章节订阅，核心指标是付费转化与追订，结构取向是“值得”：每一段都要让读者觉得付的钱没白花，兑现要实，不能只吊不给。

这个差异会直接影响开篇：免费模式可以在前三章疯狂给爽点，把情绪拉满；付费模式前三章要给爽点，但更要给“这本书的独特价值”，让读者相信后面的内容值得付费，而不是把最好的东西全放在免费部分。

表 1-5 免费模式与付费模式的结构取向

| 维度 | 免费流量 | 付费订阅 |
|---|---|---|
| 章节长度 | 偏短，断点密 | 中等，允许一个完整小高潮 |
| 钩子密度 | 每章至少一个 | 两到三章一个强钩子 |
| 兑现节奏 | 小兑现频繁 | 大兑现稳定，按卷结账 |
| 开篇策略 | 情绪拉满，快速立信 | 立信加立价值，展示独特性 |
| 中期策略 | 防流失，缩短空档 | 防跳订，保证单章含金量 |
| 风险 | 爽点通胀，读者麻木 | 铺垫过长，读者觉得亏 |

### 1.6.2 平台规则对结构的外部约束

不同平台对章节字数、更新频率、免费章节比例有不同要求，这些规则会反过来塑造结构。日更两千字的节奏，不适合安排需要连续三章铺垫的大场面；日更六千字的节奏，则可以把一个高潮拆成三段慢慢推。结构设计要先确认自己的更新产能，再决定高潮的颗粒度。

一个实用的换算：如果你每天能写四千字，那么一个需要六章铺垫的卷末高潮，实际跨度为一天半；读者的等待感很轻，可以放心铺。如果你每天只能写一千五，同样的六章要写四天，就必须在铺垫章里塞入独立的看点，否则读者会在第二天就走。
