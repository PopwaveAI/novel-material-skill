# 13.25 排版交付前的格式核对

> 素材来源：novel-material-skill ·《网文设定素材手册》13.25 排版交付前的格式核对

稿件最终要交付时，格式问题往往比内容问题更影响第一印象。下表的六项，逐项看一遍。

表 13-25　格式交付核对

| 项 | 标准 | 常见问题 |
|---|---|---|
| 标题层级 | 三级以内，字号递降 | 层级跳跃 |
| 正文缩进 | 统一，不用空格代替 | 手工敲空格 |
| 表格 | 表头重复，列宽一致 | 跨页无表头 |
| 页码 | 连续，页脚居中 | 分节后重排 |
| 目录 | 与正文标题一致 | 手工目录未更新 |
| 标点 | 全角，统一 | 中英混用 |

提示：所有工具最终都指向同一个目的：让作者把注意力放回故事本身。表填得再漂亮，故事不动人也没用。
