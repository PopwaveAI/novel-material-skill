# 9.14 设定与章节结构：一章装多少东西

> 素材来源：novel-material-skill ·《网文设定素材手册》9.14 设定与章节结构：一章装多少东西

一章的容量是有限的。大致可以这样估算：一章三千字，能装一个主要事件、一个次要事件、一到两条设定。

表 9-12　单章容量分配

| 内容 | 字数占比 | 说明 |
|---|---|---|
| 主事件 | 五成 | 推动主线，必有得失 |
| 次事件 | 两成 | 补充人物或关系 |
| 设定投放 | 一成 | 一到两条，不超过 |
| 场景与感官 | 一成半 | 让读者站住 |
| 过渡与钩子 | 半成 | 进下一章 |

超出容量的常见表现是：一章里塞了三件事，每件都只写了一半。读者的感觉是“乱”，其实是缺分配。

多线并行时的取舍：一章最多切两次视角。切三次以上，读者会丢失当前位置。

高潮章的配额：高潮章可以牺牲设定投放（压到零），把额度全给主事件。
