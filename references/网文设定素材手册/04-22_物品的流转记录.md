# 4.22 物品的流转记录

> 素材来源：novel-material-skill ·《网文设定素材手册》4.22 物品的流转记录

重要物品要有一条清楚的流转线：谁造的、谁用过、怎么到主角手上。这条线越清楚，物品越有分量。

表 4-14　流转记录五栏

| 环节 | 记录 | 作用 |
|---|---|---|
| 来历 |  | 建立可信度 |
| 初主 |  | 建立前任与恩怨 |
| 失主 |  | 建立悬念 |
| 到手 |  | 交代代价 |
| 去处 |  | 给出结局 |

流转的代价：到手时付了什么，决定读者对这件东西的感情。白捡的东西没人珍惜。

流转的误传：流言版本与真实版本的差异，是最省力的悬念。

提示：写物品不是写清单。每一件留下来的东西，都应该替人物说过一句话。
