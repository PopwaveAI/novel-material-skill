# 7.5 鸟兽意象：动作即象征

> 素材来源：novel-material-skill ·《网文设定素材手册》7.5 鸟兽意象：动作即象征

动物意象比植物更动，因此更适合写关系与命运。它们的价值在于行为可复现：读者看到同样的动作，就想起前面那个人。

鹰：高、独、俯冲。适合写权力与冷眼，也适合写“看得见却救不了”。

雁：成行、南飞、失群则鸣。最适合写离散与消息，鸿雁传书不是随便用的。

雀：群聚、争食、易惊。适合写市井、写谣言的传播者。

蛇：静、缠、蜕皮。适合写隐忍的复仇者，蜕皮可写“他换了一个身份”。

犬：守、认主、咬住不放。适合写忠仆，也适合写“被主人抛弃后的野化”。

鹤：清、长寿、离群。适合写方外之人与不涉世事的长者。

鸦：聚于死处、叫声不祥。最好的凶兆意象，也是最省字的氛围工具。

鱼：水中、无声、被网。适合写被困者与看不见的监视。

蚁：多、微、能搬动大物。最适合写“看不见的力量在改变局势”。

笼中鸟：会唱、不能飞。写被豢养的人，一句就够。
