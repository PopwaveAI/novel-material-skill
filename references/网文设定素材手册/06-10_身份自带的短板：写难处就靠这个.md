# 6.10 身份自带的短板：写难处就靠这个

> 素材来源：novel-material-skill ·《网文设定素材手册》6.10 身份自带的短板：写难处就靠这个

短板比特权更能塑造人物。因为人是在受限时才是他自己。

表 6-5　身份短板与可用困境

| 身份 | 短板 | 可用困境 |
|---|---|---|
| 女子 | 不得入祠堂、不得应试 | 必须借他人之名行事 |
| 庶出 | 不得继承、不得主事 | 被要求让位 |
| 降将 | 不被信任、随时被削 | 必须上交投名状 |
| 商籍 | 子弟不得科举 | 孩子的前程成为筹码 |
| 医者 | 不得拒诊、须报疫 | 被逼救一个该死的人 |
| 公差 | 一言一行皆有记录 | 想做私事只能托人 |
