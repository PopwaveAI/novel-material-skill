# 5.7 秘境副本：把规则关进一片地

> 素材来源：novel-material-skill ·《网文设定素材手册》5.7 秘境副本：把规则关进一片地

秘境是“有规则的小世界”。它必须有三样：入口条件、内部规则、退出方式。三样缺一，秘境就变成普通的山。

表 5-4　秘境设计四件套

| 要素 | 作用 | 写法 |
|---|---|---|
| 入口 | 为什么只有此时此地能进 | 特定时辰、特定血、特定信物 |
| 内部规则 | 与外界不同的物理或道德法则 | 不可说谎、不可杀生、不可回头 |
| 资源 | 里面能得到什么 | 一味药、一件器、一条消息 |
| 退出 | 怎么出去，代价是什么 | 原路返回须留一物、三日之内必出 |

镜界：一切左右颠倒。左手变右手，字是反的，人的善恶也反。

回声谷：说出口的话会在三息后原样返回。因此不能喊，也不能说谎。

无月之夜：每月只有一夜开启，进入者须在天亮前离开，否则永远留下。

试炼场：分七关，每关淘汰一半。它最适合写团队内部的信任崩塌。

旧战场：兵煞不散，入夜则有兵戈之声。适合写“死人的执念还没结束”。
