# 2.24 一城之内的时间表

> 素材来源：novel-material-skill ·《网文设定素材手册》2.24 一城之内的时间表

城市是有作息的。把一天的时间表写出来，所有的戏都能找到合适的时辰。

表 2-17　古代城市一日

| 时辰 | 城中状态 | 可用事件 |
|---|---|---|
| 五更 | 鼓绝开门，市未起 | 夜逃、密捕、出殡 |
| 辰时 | 市开，人渐多 | 跟踪、采买、传话 |
| 午时 | 最热最挤 | 当街冲突、失窃 |
| 申时 | 市将散，价最低 | 甩卖、清仓、急售 |
| 戌时 | 闭门，灯火起 | 私会、递物、夜宴 |
| 子时 | 全城静 | 翻墙、杀人、密信 |

时间压力：“散市前必须凑够钱”这类句子，比任何形容都更让人急。

错时：让人物在错误的时辰做错误的事，冲突自动产生。

现代对照：通勤高峰、午休、加班时段，用途与古代时辰完全对应。

提示：世界观的最后一步不是画地图，而是排一张时间表。人什么时候在哪儿，故事就发生在哪儿。
