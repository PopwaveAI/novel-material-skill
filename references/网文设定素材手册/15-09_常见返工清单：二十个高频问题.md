# 15.9 常见返工清单：二十个高频问题

> 素材来源：novel-material-skill ·《网文设定素材手册》15.9 常见返工清单：二十个高频问题

返工是常态。下表把最常见的问题与最小改动方案放在一起，能用最少的时间把稿子救回来。

表 15-9　二十个高频问题与最小改动

| 问题 | 最小改动方案 |
|---|---|
| 开头三百字没有麻烦 | 把第一个冲突提前，删掉环境描写 |
| 主角动机不清 | 补一句他“不得不”的理由 |
| 配角像工具人 | 给他一个与主线无关的目标 |
| 设定解释成段 | 拆成三句台词，分给三个人说 |
| 战斗没有画面 | 补位置、状态、一个具体伤口 |
| 反派太单薄 | 补一条他不能退的理由 |
| 情绪靠形容词 | 换成身体反应与动作 |
| 中段掉读者 | 回收一笔旧账，不要开新地图 |
| 升级太顺 | 给升级加一次失败与一次代价 |
| 结尾太满 | 删掉最后一段总结 |
| 节奏全紧 | 插一个松章，写关系变化 |
| 称谓混乱 | 统一三组核心称谓，其余略过 |
| 时间线乱 | 画时间轴，只改前后不一致的两处 |
| 钱不合逻辑 | 补一张收支简表 |
| 力量通胀 | 横向扩张，同级不同流派 |
| 伏笔没回收 | 挑两条在本卷收掉，其余降级为背景 |
| 重复句式 | 每章挑三处改掉，其余不动 |
| 对话像说明 | 让每句对话都在索取或拒绝 |
| 场景没记忆点 | 每场戏加一个感官细节 |
| 标题平庸 | 换成带动作或带物件的短语 |

返工的原则是改小不改大。能靠一句话解决的，不要重写一章；能靠删解决的，不要加。
