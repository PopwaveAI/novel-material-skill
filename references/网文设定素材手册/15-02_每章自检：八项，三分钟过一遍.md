# 15.2 每章自检：八项，三分钟过一遍

> 素材来源：novel-material-skill ·《网文设定素材手册》15.2 每章自检：八项，三分钟过一遍

每章写完立刻过一遍。这时改成本最低，隔天就会忘。

表 15-2　单章自检表

| 检查项 | 合格标准 | 不合格表现 |
|---|---|---|
| 推进 | 这一章有具体得失 | 读完没有变化 |
| 设定 | 最多一个新概念 | 一段塞三个名词 |
| 感官 | 至少一处具体感官 | 全靠形容词 |
| 人物 | 至少一个人做了选择 | 全是被推动 |
| 节奏 | 有起伏，不是平铺 | 通篇同一情绪 |
| 对话 | 每句都在做事 | 互相解释设定 |
| 钩子 | 章末留一个未完动作 | 干净收尾 |
| 字数 | 与连载节奏匹配 | 忽长忽短 |
