# 3.5 科技能力：把黑科技写成有说明书的科技

> 素材来源：novel-material-skill ·《网文设定素材手册》3.5 科技能力：把黑科技写成有说明书的科技

科幻与末世题材的力量来自装备，而装备必须有参数、能耗、维护三样。缺一样，装备就成了魔法。

表 3-3　装备设定必填四项

| 项目 | 作用 | 写错的后果 |
|---|---|---|
| 参数 | 射程、威力、精度、载重 | 读者不知道它能不能打赢 |
| 能耗 | 燃料、电量、充能时间 | 永远不用充电，紧张感消失 |
| 维护 | 零件、保养周期、故障率 | 装备永不坏，危机无从制造 |
| 操作门槛 | 训练时长、后坐力、副作用 | 谁都能用，专业感消失 |

改装与拼装：把两台废装备拼成一台能用的。这是末世与科幻最抓人的技术爽点，前提是所有零件都提前出现过。

技术黑箱：一件来源不明、原理不明的核心设备。它可以推动主线，但不能解决主线，否则故事就结束了。

能量上限：给所有高科技手段一个总能量池。池见底时，人就退回肉身，戏立刻变真。

EMP 与反制：一次电磁脉冲可以让全场装备失效。它是最好用的“重置局面”手段，每个长篇都该有一次。

生物改造：植入、强化、基因编辑。代价要落在身体上：排异、寿命、失控、失去某种感受能力。
