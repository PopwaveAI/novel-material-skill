# 6.4 现代职业：越具体越可信

> 素材来源：novel-material-skill ·《网文设定素材手册》6.4 现代职业：越具体越可信

现代职业写作的诀窍是写流程而不是写名词。读者不关心你是什么 title，关心你一天要打几个电话、几点交报表、被谁卡着。

表 6-2　现代职业的“一天流程”模板

| 职业 | 一天的关键节点 | 天然冲突 |
|---|---|---|
| 急诊医生 | 交班、查房、抢救、写病历、家属谈话 | 资源不够时的取舍 |
| 诉讼律师 | 阅卷、会见、开庭、调解、催费 | 真相与委托利益的冲突 |
| 审计 | 盘点、抽凭、访谈、出报告 | 发现问题却要签字 |
| 项目经理 | 晨会、对接、救火、汇报 | 三方需求互斥 |
| 基层公务员 | 接访、报表、迎检、值班 | 政策与民情的夹缝 |
| 媒体记者 | 选题、采访、写稿、审稿 | 报道与关系的冲突 |
| 教师 | 早读、上课、家访、批改 | 一个学生与全班的取舍 |
| 销售 | 拜访、报价、陪酒、回款 | 业绩与底线的冲突 |

职级与年限：同一岗位不同年限，说话方式完全不同。新人请示，老人拍板，这是最便宜的真实感。

工牌与门禁：现代世界的“路引”。一张卡能进哪层楼，就是他的权限。

汇报线：谁向谁汇报，决定谁能压谁。写职场戏，先画这张图。

流程卡点：盖章、审批、预算、法务。流程本身就是阻力，不必再编反派。
