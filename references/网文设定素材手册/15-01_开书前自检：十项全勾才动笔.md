# 15.1 开书前自检：十项全勾才动笔

> 素材来源：novel-material-skill ·《网文设定素材手册》15.1 开书前自检：十项全勾才动笔

这一部分是全书的验收环节。四个阶段各自一张表：开书前、每章、每卷、完稿。另有专章处理三类红线与设定一致性终检。

用法：把表拿出来，逐条打钩。不勾的项不是“以后再说”，而是“现在就改”。凡是能拖到完稿的问题，完稿时一定改不完。

开书前的自检决定这本书能不能活过三十章。十项里任一条空着，都是后面返工的伏笔。

表 15-1　开书前自检表

| 序号 | 检查项 | 合格标准 |
|---|---|---|
| 一 | 世界一句话 | 二十字内说清，且不是“一个修士的成长” |
| 二 | 主角处境 | 第一章就处在麻烦里，不是准备出发 |
| 三 | 核心规则 | 一条读者能复述的规矩 |
| 四 | 代价体系 | 至少三条能让主角犹豫的代价 |
| 五 | 主要势力 | 三到五方，各有不能退的理由 |
| 六 | 常驻场景 | 三个以上会反复出现的场地 |
| 七 | 核心道具 | 一到两件贯穿全书的物件 |
| 八 | 赛道尺度 | 标签与内容一致，不虚标 |
| 九 | 三十章大纲 | 至少写到第一个大转折 |
| 十 | 存稿 | 五到十章，且质量过关 |
