# 11.9 适配矩阵：先定位，再取素材

> 素材来源：novel-material-skill ·《网文设定素材手册》11.9 适配矩阵：先定位，再取素材

写新书前先填这张矩阵，能避免“写了一堆用不上的设定”。

表 11-6　素材适配矩阵（按需勾选）

| 素材类别 | 本书是否需要 | 使用强度 | 备注 |
|---|---|---|---|
| 地理与据点 | 必填 | 高 | 至少三个常驻场景 |
| 势力与制度 | 必填 | 中 | 三到五方，各有诉求 |
| 力量体系 | 按题材 | 高（幻想类） | 现实类可只保留能力边界 |
| 道具 | 必填 | 中 | 三到五件核心道具 |
| 场景感官 | 必填 | 高 | 每章至少一处具体感官 |
| 身份职业 | 必填 | 中 | 主要角色各一张卡 |
| 符号意象 | 建议 | 中 | 两到三个核心意象 |
| 冲突事件 | 必填 | 高 | 每卷至少三轮升级 |
