# 3.16 体系通胀治理：写到后期怎么不飘

> 素材来源：novel-material-skill ·《网文设定素材手册》3.16 体系通胀治理：写到后期怎么不飘

所有长篇幻想都会遇到同一个问题：前期的高手，到后期不如一条狗。治理办法有四，越早用越好。

抬高天花板：前期不要把最高层写死。留两级没出场的境界，后期才有地方去。

横向扩张：不往上加层，往横向加类型。同样是第五级，有人擅长攻，有人擅长守，强不再单一。

稀缺化高手：越到后期，高手越少而不是越多。稀缺比数量更能维持威慑。

转移战场：后期不靠战力决胜负，靠资源、人心、规则。战场一换，通胀就不重要了。

代价同步升级：能力越强，代价越贵。让后期的高手活得更艰难，读者才不会觉得爽得廉价。

四条里最有效的是横向扩张。它不需要否定前文，只需要让“同级之间也有巨大差异”。

表 3-11　通胀症状与处方

| 症状 | 处方 |
|---|---|
| 前期高手后期成炮灰 | 横向扩张，给同级不同流派 |
| 境界名字越造越多 | 合并层级，把相似的两级归一 |
| 主角越级无代价 | 补代价，且要在下一章发作 |
| 战斗没有悬念 | 抬高对手的手段，不给数值 |
| 读者开始跳读战斗 | 减少战斗频次，增加战斗后果 |
