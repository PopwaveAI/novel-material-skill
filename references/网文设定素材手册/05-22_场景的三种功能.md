# 5.22 场景的三种功能

> 素材来源：novel-material-skill ·《网文设定素材手册》5.22 场景的三种功能

每一场戏都发生在某个地方，但地方的作用不只有“背景”一种。写之前先问：这个场景是干什么的。

表 5-12　场景的三功能

| 功能 | 特征 | 写法 |
|---|---|---|
| 容器 | 只提供空间，不参与冲突 | 尽量少写，一两句交代 |
| 推手 | 环境本身制造麻烦 | 把环境的限制写进动作 |
| 证人 | 有人或有事在场，能改变走向 | 安排一个不该在场的旁观者 |

容器的处理：容器类场景不要多写，写多了就是风景散文。

推手的做法：让天气、地形、时间为难主角，而不是让人为难主角。

证人的价值：旁观者一句话，能改变一场戏的结局。这是最省力的一种转折。

三种功能可以叠加。最理想的一场戏是：既是推手，又有证人。
