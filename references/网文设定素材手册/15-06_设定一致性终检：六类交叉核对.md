# 15.6 设定一致性终检：六类交叉核对

> 素材来源：novel-material-skill ·《网文设定素材手册》15.6 设定一致性终检：六类交叉核对

一致性问题的特点是“单看都对，放一起就错”。六类交叉核对最有效。

表 15-8　六类一致性核对

| 类型 | 核对方法 | 典型错处 |
|---|---|---|
| 物理 | 地点－天数－交通方式三点对照 | 千里之路半日到 |
| 时间 | 事件日期与季节、节日对照 | 国丧期办喜事 |
| 经济 | 收入－支出－物价三点对照 | 月俸十两却随手赏百两 |
| 权限 | 身份－能做的事－后果对照 | 县丞调边军 |
| 称谓 | 关系－场合－称呼三点对照 | 私下仍称官称 |
| 力量 | 层级－标尺－代价对照 | 重伤后连战三场 |

核对的具体做法是做一张事件轴：横轴写章号，纵轴写时间、地点、钱、伤、关系五项。五项对齐之后，矛盾会自己浮出来。
