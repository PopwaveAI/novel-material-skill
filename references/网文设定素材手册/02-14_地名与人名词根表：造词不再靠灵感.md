# 2.14 地名与人名词根表：造词不再靠灵感

> 素材来源：novel-material-skill ·《网文设定素材手册》2.14 地名与人名词根表：造词不再靠灵感

造名词最忌临时拍脑袋，容易前后风格不一致。做法是先定词根表，之后所有地名、人名、门派名都从表里组合。

表 2-10　常用词根组合表

| 方向 | 词根 | 组合示例 |
|---|---|---|
| 地形 | 崖、岭、隘、津、泽、陂 | 黑石崖、双流津、盐皮泽 |
| 城镇 | 关、镇、堡、驿、埠、坊 | 雁回关、铁门堡、青石埠 |
| 水文 | 渡、湾、汀、渠、堰、渚 | 落雁渡、白茅堰、芦花渚 |
| 宗门 | 观、院、堂、阁、斋、宗 | 清微观、枕流院、悬剑阁 |
| 器物 | 令、符、印、牌、鉴、圭 | 盐引令、照夜符、断水鉴 |
| 称号 | 君、侯、使、郎、娘、客 | 盐铁使、走山人、渡口娘 |

组合有三条规矩：同部首尽量同地域、同后缀尽量同性质、重要地名不超过三字。三字以上难记，读者会自己给你改名。

提示：写完一份词根表，先把全书要用的二十个专名一次定完，再动笔。中途改名，是长篇最常见的自伤。
