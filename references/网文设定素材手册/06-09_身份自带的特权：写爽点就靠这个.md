# 6.9 身份自带的特权：写爽点就靠这个

> 素材来源：novel-material-skill ·《网文设定素材手册》6.9 身份自带的特权：写爽点就靠这个

特权是身份的兑现方式。写特权要写它解决了一个具体的麻烦，而不是宣称“他很有地位”。

表 6-4　身份特权与对应麻烦

| 身份 | 特权 | 可解决的麻烦 |
|---|---|---|
| 钦差 | 可调地方兵、可先斩后奏 | 被地方官软禁 |
| 太医 | 可入内廷、可阅脉案 | 有人装病 |
| 宗室 | 不受地方刑名管辖 | 被县衙扣押 |
| 盐商 | 可调用船帮与仓 | 急需连夜运走一批货 |
| 镖头 | 过境不问，各寨给面 | 带人穿山越岭 |
| 掌印太监 | 能改诏、能传口谕 | 一道假旨 |
| 主家嫡女 | 可开祠堂、可动族产 | 族中有人私卖田 |
