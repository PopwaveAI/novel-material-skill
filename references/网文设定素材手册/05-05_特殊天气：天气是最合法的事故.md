# 5.5 特殊天气：天气是最合法的事故

> 素材来源：novel-material-skill ·《网文设定素材手册》5.5 特殊天气：天气是最合法的事故

天气是作者最方便的“外部变量”。它不改人物动机，却能改一切条件，而且读者不会觉得刻意。

暴雨：路断、河涨、火灭、脚印消失。暴雨是所有追踪戏的橡皮擦。

大雪：掩盖尸体、冻住伤口、留下唯一一串脚印。雪天同时提供隐藏与暴露。

大雾：十步之外不辨人形。雾让“认错人”成为可能，也让“当面错过”成立。

闷雷无雨：云压得低，雷声滚但不下。它制造的是等待的焦躁，而不是行动的阻碍。

干旱：井枯、粮贵、牲畜死。旱灾是慢性的，适合写“日子一天天坏下去”。

倒春寒：回暖后又冻，冻死新芽与希望。最文艺的一种灾。

沙尘：能见度低、呼吸难、器物磨损快。适合写边地、写长途行军的苦。

潮汐与风暴潮：水位暴涨、栈桥垮塌。它给“时间不够”提供物理证据。
