# 9.5 设定轻量化写法：一句话顶三页

> 素材来源：novel-material-skill ·《网文设定素材手册》9.5 设定轻量化写法：一句话顶三页

长篇读者对“设定讲座”的容忍度极低。同样的信息，用一句台词交代，比用一段说明有效十倍。

轻量化对照  原写法：本朝自太祖以来，凡五品以上官员，家眷不得经商，违者削籍，故此城中大户虽富，却无人敢挂官身。改写：她看了那张匾一眼，“你家挂着五品的衔，怎么还敢开铺子？”

改写之后，信息一点没少，但读者是在冲突里被告知的，因此不会烦。

表 9-5　五种轻量化手法

| 手法 | 做法 | 适用 |
|---|---|---|
| 降为定语 | 把一段说明压成一个修饰语 | 地理、身份、时代 |
| 降为动作 | 让人物按规则行事，不解释规则 | 礼法、制度 |
| 降为对比 | 让两个人做法不同，差异自明 | 风俗、阶层 |
| 降为否定 | 只写“不许”，不写为什么 | 禁忌、秘密 |
| 降为残留 | 只写留下的痕迹，不写过程 | 历史、灾祸 |
