# 5.21 关卡与边界：必须过一次的地方

> 素材来源：novel-material-skill ·《网文设定素材手册》5.21 关卡与边界：必须过一次的地方

所有故事都需要“门”。关卡、城门、山门、检票口，作用都一样：筛人。

城门：验籍、收税、禁兵器。进城的那一刻，人物就被分类了。

关隘：军管，过者需引。引的真伪，是最好用的悬念。

山门：宗门之地，外人不入。想进就得有理由，理由是戏。

渡口检查：查货不查人，或查人不查货。漏洞就是通路。

城门官：小吏，权力极大。他放不放人，全看那一句话怎么说。

夜禁与通行牌：牌子决定一切。丢牌比丢钱严重。

边检与海关：现代场景里的同类。排队、申报、抽检，全是时间成本。

禁区：不许进的地方。它存在于任何世界，只是名字不同。

表 5-11　关卡四问

| 问 | 用途 |
|---|---|
| 查什么 | 决定主角要藏什么 |
| 谁在查 | 决定能不能买通 |
| 多严 | 决定风险成本 |
| 有无漏洞 | 决定故事走法 |

提示：写关卡时，先让主角失败一次。第一次过不去，读者才会认真看第二次他是怎么过的。
