# 15.5 三类红线专查

> 素材来源：novel-material-skill ·《网文设定素材手册》15.5 三类红线专查

三类红线是硬性要求，不达标就要返工，不能靠“差不多”过关。

### 红线一：跨文档引用

表 15-5　跨文档引用排查清单

| 排查项 | 合格标准 |
|---|---|
| 是否提到别的册子 | 全书不得出现“见另一本”“参阅某手册”类表述 |
| 是否引用外部资料 | 案例与素材均为本册内部示范，不作来源指向 |
| 跳转是否自洽 | 所有跳转只指向本册内部章节，且编号真实存在 |
| 是否存在未定义术语 | 每个专有概念在本册内有首次定义 |

### 红线二：标点与符号

表 15-6　标点排查清单

| 排查项 | 合格标准 |
|---|---|
| 长破折号 | 全文不出现连续两个长横，改用冒号、逗号或直接删除 |
| 省略号 | 单章不超过三处，且只用在被打断处 |
| 感叹号 | 单章不超过五处，避免情绪通胀 |
| 书名号 | 只用于真实作品名，虚构作品名同样加书名号但不指向现实 |
| 引号层级 | 双引号在外，单引号在内，不混用 |
| 数字用法 | 同一册内中文数字与阿拉伯数字分工统一 |
| 表情符号 | 全文不得出现任何表情符号 |
| 空格与缩进 | 段首统一缩进两字，不用空格代替 |

### 红线三：商业化视角

表 15-7　商业化视角排查清单

| 排查项 | 合格标准 |
|---|---|
| 立场 | 始终是作者宣传自己的作品，不出现卖资料、卖课、带货 |
| 承诺 | 不承诺收益、不承诺效果、不使用夸张诱导 |
| 导流 | 不出现任何站外联系方式、二维码、群号 |
| 比较 | 不贬低同类作品，不做拉踩式宣传 |
| 数据 | 引用数据须有可核查口径，不虚构涨幅 |
