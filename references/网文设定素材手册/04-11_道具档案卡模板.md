# 4.11 道具档案卡模板

> 素材来源：novel-material-skill ·《网文设定素材手册》4.11 道具档案卡模板

重要道具建卡。一张卡填完，这件东西在全书里的位置就稳了。

表 4-6　道具档案卡

| 字段 | 填写内容 |
|---|---|
| 名称与俗称 | 官方叫什么，民间怎么叫 |
| 外观 | 材质、尺寸、磨损痕迹、随身方式 |
| 功能 | 一句话说清，不超过两项 |
| 限制 | 次数、条件、对象 |
| 代价 | 用得越多的后果 |
| 来历 | 谁做的、为什么做、经过谁的手 |
| 现任持有者 | 现在在谁手里，怎么得到的 |
| 关键场景 | 它在哪三场戏里起过作用 |
| 最终归宿 | 被毁、被交出、被埋、被传下去 |
