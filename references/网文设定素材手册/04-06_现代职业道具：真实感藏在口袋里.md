# 4.6 现代职业道具：真实感藏在口袋里

> 素材来源：novel-material-skill ·《网文设定素材手册》4.6 现代职业道具：真实感藏在口袋里

现代题材的道具不追求奇，追求准确。一个人口袋里装什么，比他自我介绍更能说明他是谁。

表 4-3　职业道具速查

| 职业 | 核心道具 | 细节价值 |
|---|---|---|
| 医生 | 听诊器、工牌、值班表 | 值班表能证明谁在凌晨三点不在岗 |
| 律师 | 卷宗袋、录音笔、便签 | 卷宗编号可追出案件调阅记录 |
| 程序员 | 工卡、双屏、耳机 | 工卡刷卡记录即出入证明 |
| 记者 | 录音笔、相机、名片 | 名片上的旧头衔暴露职业变动 |
| 厨师 | 厨刀、围裙、点菜单 | 刀的磨损方式说明使用习惯 |
| 警察 | 执法记录仪、手铐、对讲机 | 记录仪的开关时间线最关键 |
| 教师 | 教案、红笔、点名册 | 点名册的涂改痕迹是线索 |
| 销售 | 名片夹、合同、车钥匙 | 车钥匙对应消费层级 |

写现代道具的窍门是让它出故障。手机没电、录音笔没开、门禁卡消磁，一次故障就能把顺风局变成绝境，而且完全合理。
