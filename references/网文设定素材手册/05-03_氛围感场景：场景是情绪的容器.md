# 5.3 氛围感场景：场景是情绪的容器

> 素材来源：novel-material-skill ·《网文设定素材手册》5.3 氛围感场景：场景是情绪的容器

氛围场景不承担剧情功能，只承担感受功能。它的写法是用三个具体细节替换一句形容词。

氛围样段  灯芯结了花，她伸手去剪，指尖被烫了一下，才发觉自己坐了整整一个时辰。窗外更鼓敲过三响，声音很远，像是从别人家的院子里传来的。

这段没有一个“寂寞”，但读者知道她寂寞。做法是：一个动作（剪灯芯）、一个身体感觉（烫）、一个时间证据（三响更鼓）、一个空间距离（别人家的院子）。

表 5-2　氛围场景的四种常规配置

| 氛围 | 可用细节 | 避免写法 |
|---|---|---|
| 清冷 | 薄霜、冷茶、未添的炭、单衣 | 直接写“清冷”“孤寂” |
| 压迫 | 低檐、窄门、满屋人却不说话 | 写“气氛压抑” |
| 将变 | 风向变了、狗突然不叫、烛火歪 | 写“预感到有事发生” |
| 余温 | 碗还热、椅子还温、门未关严 | 写“人刚走” |
