# 3.12 力量体系自检表

> 素材来源：novel-material-skill ·《网文设定素材手册》3.12 力量体系自检表

写完体系后，用下面这张表逐条打钩。任何一条打不上，都建议先补再写。

表 3-8　力量体系自检清单

| 检查项 | 合格标准 |
|---|---|
| 层级数量 | 五至七级，每级有质变而非只差数值 |
| 升级条件 | 每一级都有具体门槛，且不能单纯靠时间 |
| 代价体系 | 至少三条代价，且在日常场景里会发作 |
| 能力边界 | 写清“不能做什么”，且全书未曾破例 |
| 战力标尺 | 三个可测量的刻度，全书统一 |
| 反派强度 | 同境界反派有独特手段，不靠堆数值 |
| 社会映射 | 力量强弱能兑换成地位差异 |
| 通胀控制 | 中后期不出现满地高阶 |
| 弱者生存 | 无力量者也有可用的手段与价值 |
| 读者可算 | 读者能自行推断一场战斗的大致结果 |

十条全过，体系就立住了。剩下要做的，是让它在剧情里被反复兑现，而不是躺在设定集里。
