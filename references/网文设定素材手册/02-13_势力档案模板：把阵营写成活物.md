# 2.13 势力档案模板：把阵营写成活物

> 素材来源：novel-material-skill ·《网文设定素材手册》2.13 势力档案模板：把阵营写成活物

每个重要势力建一张档案卡。卡不必长，但要能回答“它此刻在做什么”。

表 2-9　势力档案卡

| 字段 | 填写内容 |
|---|---|
| 名称与自称 | 对外怎么称，对内怎么称 |
| 性质 | 官、商、军、宗族、江湖、宗教 |
| 头面人物 | 一人为主，一至两人为副 |
| 真实诉求 | 一句话，不能是“争霸天下” |
| 恐惧 | 最怕失去什么 |
| 资源 | 人、钱、地、消息，各写一样 |
| 软肋 | 一处可被击穿的地方 |
| 内部裂缝 | 新旧、嫡庶、主战主和 |
| 对外关系 | 与各方是交易、敌对还是暧昧 |
| 可见标识 | 服色、口号、信物、行事风格 |
| 近期动作 | 这三章它在干什么 |
