# 10.1 男主人设卡模板：一张表填完一个男主

> 素材来源：novel-material-skill ·《男主人设手册》10.1 男主人设卡模板：一张表填完一个男主

本部分承接第一部分（男主人设底层框架），把前面九部分讲的"是什么、为什么、怎么写"，收拢成一套可以立刻上手的操作工具：一张填了就能用的人设卡、一条五步走的设计流程、一张打钩就能过的一致性检查表、一套改人设时的校验方法，以及多男主和男二的写法。前九部分是"教你认识一个男主"，本部分是"给你一台机器，你自己造出一个男主"。本部分与第一部分、第十二部分衔接，人设卡的字段全部来自第一部分的五要素与三层结构，一致性检查表的每一条都能在第十二部分的总自检清单里找到对应的完整版；男女主双卡对照的做法见 10.1.5，男主与女主、男二的关系定位见 10.5。

为什么强调"填"而不是"想"？因为想的时候，你脑子里全是"感觉"，他要苏、要冷、要虐，这些感觉没法落到纸上，也没法检验。填的时候，你被逼着把"感觉"翻译成"字段"：他苏，苏在哪一格？他冷，冷在对外标签还是对内真实？他虐，虐在缺陷还是创伤？一格一格填，感觉就变成了图纸，图纸就能施工、就能验收、就能改。新手和老手的区别，往往不在天赋，就在这张表上，老手开书前填完了，新手开书时还在想。

用本部分之前，先立一个观念：人设不是想出来的，是填出来的。坐在那里空想"我要一个又冷又苏的男主"，填出来的一定是纸片；对着一张字段表，一格一格填，填不出来的格子就是你还没想清楚的地方。下面先给模板，再给三张填好的样例卡，照着填。

人设卡是全书的工程图纸。开书之前填完，开书之后放在手边，每写一章对照一次。字段分十一组：基础信息、外貌锚点、性格底色、过往经历、致命缺陷、台词习惯、关系网、五要素、三层结构、冲突清单、触发器清单、名场面计划。下面先给空白模板字段说明，再给三张填好的样例卡。

### 10.1.1 完整字段模板

| 字段组 | 具体字段 | 填写要求 |
|---|---|---|
| 基础信息 | 姓名、年龄、身份、职业、所处题材/时代、一句话定位 | 一句话定位要能贴在书架上当简介 |
| 外貌锚点 | 眉形、眼型、标志性细节（泪痣/旧疤/手）、固定气味、固定单品 | 5–7 个锚点，全书只准在这些锚点上写外貌 |
| 性格底色 | 对外标签、对内真实、行事逻辑（一定会/绝不会）、说话节奏 | 对外标签是表层，对内真实是三层 |
| 过往经历 | 出身、人生转折点、造就他现在性格的那件事 | 过往要落到"一件具体的事"，不是一段经历 |
| 致命缺陷 | 缺陷是什么、它让他怎么吃亏、代价是什么 | 缺陷必须真的让他吃亏，且亏得读者看得见 |
| 台词习惯 | 口头禅（≥5）、禁忌用语（绝不会说）、说话节奏 | 对照第七部分 7.1 七类人设台词库 |
| 关系网 | 与女主关系、与男二关系、与对手/反派关系、与下属/兄弟关系 | 每段关系写清"他对对方"和"对方对他" |
| 五要素 | 核心欲望、核心恐惧、致命缺陷、行事逻辑、反差点 | 与第一部分 1.1 严格对应 |
| 三层结构 | 表层标签、中层行为、底层创伤 | 表层第一章交付，中层前十章，底层中后期 |
| 冲突清单 | 他与世界的冲突、他与女主的冲突、他与自己的冲突 | 三类冲突各列≥2 条 |
| 触发器清单 | 什么事会让他破功/失控/心软 | 触发事件要具体到"一句话、一个动作、一个物件" |
| 名场面计划 | 初见、救场、失控、告白、诀别各一个 | 对照第七部分 7.3 桥段库 |

这张表不是走形式，每一格都有它的用处。基础信息那一栏决定他在哪个赛道、面对什么读者；外貌锚点那一栏是给你自己下的死命令，全书只能在这五到七个点上写他的脸，禁止第一章写"剑眉星目"、第五章又写"剑眉斜飞"；性格底色那一栏是他对外和对她的两张脸，写对手戏时随时对照；过往经历那一栏必须落到"一件事"，写"他小时候很惨"是懒，写"七岁那年他躲在柴堆里看了一夜"才是设定；致命缺陷那一栏，空着这一格，整本书就没有虐点；台词习惯那一栏直接对照第七部分；五要素那一栏是地基，不能动；冲突清单那一栏是剧情发动机，三类冲突各列两条，全书的矛盾就从这里长出来；触发器清单那一栏是你写"他破功"时的开关；名场面计划那一栏是全书骨架，先有场面，再填中间的章节。

填这张表有个技巧：哪一格你填了半天填不出来，那就是你这个男主还没想清楚的地方。一个合格的作者，开书前能把这张表填满到每一格都有具体内容；填不满的格子，就是你开写之后要补的窟窿。别在没想清楚的时候硬开书，那是拿三万字试错。

### 10.1.2 样例卡一：疯批权臣（顾衍）

| 字段组 | 填写内容 |
|---|---|
| 基础信息 | 顾衍，28 岁，大曜王朝太傅、摄政王，古言权谋。一句话定位：全京城都怕他，他却把唯一的温柔留给了那个替他挡过一箭的罪臣之女。 |
| 外貌锚点 | 眉峰斜飞入鬓、眼尾上挑带笑、左手虎口一道旧箭疤、常年着玄色常服、身上有淡淡的龙涎香、笑起来左眼底下有一个极浅的梨涡。 |
| 性格底色 | 对外标签：心狠手辣、笑里藏刀、说一不二。对内真实：极度缺乏安全感、一旦认定就死不放手。行事逻辑：一定会当面把话说满、背后把事做绝；绝不会当众解释、绝不向任何人示弱。 |
| 过往经历 | 七岁满门抄斩，他躲在柴堆里看了一夜，被忠仆偷运出宫。十五年后回京，从一个小御史做到权倾朝野，每一步都踩着仇人上去。 |
| 致命缺陷 | 不信人。他谁都不信，连女主也不信，总要反复试探、反复确认她不会走，试探到她崩溃。代价：差点把她推走。 |
| 台词习惯 | 口头禅：急什么、你猜、我说过的对吧、乖、有意思。禁忌用语：我错了、我害怕、求你别走。说话节奏：慢、轻、带笑，越狠越温柔。 |
| 关系网 | 对女主：嘴上拿捏、暗地里护她所有软肋。男二（忠臣之子）：视为情敌，面上不动声色，暗地里处处设防。对手（太后一党）：笑着下棋，一局一局收掉。下属：赏罚分明，从不多说一句。 |
| 五要素 | 核心欲望：查清母亲死因、把灭门仇人一个个拉下马。核心恐惧：再次被自己最信任的人背叛。致命缺陷：不信人。行事逻辑：先下手为强，后发制人。反差点：对外冷血如修罗，对内会偷偷给她养的那只猫留鱼。 |
| 三层结构 | 表层标签：活阎王、权臣。中层行为：做任何决定都先算三步后手、说话从不留把柄。底层创伤：七岁那夜柴堆里的尖叫与血。 |
| 冲突清单 | 与世界：他要复仇，整个朝堂都是他的仇人。与女主：他想留她在身边，她却想逃。与自己：他想信她，又不敢信。 |
| 触发器清单 | 她受伤（瞳孔骤缩、笑意消失）、她提到那个男二（语气变冷、但仍笑）、她说"我走了"（第一次失控）、有人动他送给她的东西（当场掀桌）。 |
| 名场面计划 | 初见：夜宴上她撞见他杀人，他留下她。救场：宫宴上有人辱她，他当众披大氅。失控：她瞒着他去见男二，他锁门逼问。告白：以江山为聘。诀别：中毒将死，亲手写放她自由的文书。 |
