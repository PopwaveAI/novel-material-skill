# 4.8 外貌描写避雷：模板词、堆砌、千人一面

> 素材来源：novel-material-skill ·《男主人设手册》4.8 外貌描写避雷：模板词、堆砌、千人一面

这一节是写外貌最容易翻车的三个地方：模板化形容词、辞藻堆砌、千人一面。前面给了那么多库，最后一节负责把你从旧习惯里拽出来。

### 4.8.1 模板词清单与替换方案

下面十个词，是古言现言外貌描写里出现频率最高、也最偷懒的十个词。左边是模板词，右边是替换方案。

| 模板词 | 为什么不能用 | 替换思路与例句 |
|---|---|---|
| 剑眉星目 | 用了二十年，读者已经免疫，且谁都能用 | 换成具体眉形+具体眼神："眉斜飞入鬓，眼尾在笑，那笑没到眼底。" |
| 俊美无俦 | 空泛到等于没写 | 落到一处具体部位："他下颌线干净得像刀裁，侧脸对着窗光，那一道线没有一点多余。" |
| 面如冠玉 | 古言陈词 | 写皮相+骨相分开："他皮相白得发冷，骨相却清瘦，整个人像一盏随时会灭的灯。" |
| 玉树临风 | 站姿成语，无画面 | 写动作："他站在廊下没动，袖口被风掀起一角，那截手腕骨就那么露着。" |
| 风神俊朗 | 四个字总结一张脸 | 写气质+一个破绽："他眉眼是干净的，唯独眼下那颗泪痣，让整张脸忽然有了故事。" |
| 英俊潇洒 | 现代文偷懒万能句 | 写穿衣+细节："他一件旧皮夹克，肩线都磨软了，可他就是不换。" |
| 冷若冰霜 | 性格词不是外貌词 | 写眼神+距离："他抬眼看人时目光是平的，不迎不送，像一杯放凉的白水。" |
| 气势逼人 | 形容词不是描写 | 写周围人的反应："他一进门，满屋子说话声就低了下去。" |
| 薄唇微抿 | 网文标配动作，烂大街 | 换成别的唇部动作："他咬了一下下唇，那一下让她心跳漏了一拍。" |
| 眸色深邃 | 所有男主都深邃 | 写瞳孔具体动作："她那句话入耳，他瞳孔猛地收了一下，像被针扎了。" |

### 4.8.2 堆砌辞藻的改法

堆砌的典型症状是：一段三百字的外貌，写了眉毛眼睛鼻子嘴下巴脖子肩膀手，像在报菜名。读者看完记不住他是谁，只记住作者很努力。改法有三条：
- 第一，一段外貌只写一个重点。这一段写眼，下一段写手，再下一段写声音。一段里塞十处，等于一处都没写。
- 第二，用动作带外貌，不要静态陈列。不写"他有一双修长的手"，写"他伸手替她把碎发别到耳后，指腹擦过她耳廓"，手的长、骨节、温度，全在动作里出来了。
- 第三，用旁人反应写外貌。不直接写他多好看，写"满屋子人同时抬头，又同时静了一下"。读者会自己补出那张脸，比你写出来的好看十倍。

【堆砌改法对照】原句（堆砌）："他剑眉星目，面如冠玉，鼻梁高挺，薄唇微抿，一双深邃眼眸精光内敛，下颌线分明，身材高挑，气质清冷，站在那里犹如玉树临风。"，一百字塞了九个成语，等于零。改后："他今天穿了一件白衬衫，袖子挽到小臂。她抬头看他的时候，他正低头翻文件，长睫毛在眼下投出一小片影。听见她进来，他抬眼，那目光是平的，不迎也不送。"，同样写了他，但是活的。

### 4.8.3 千人一面的三个根因与解法

为什么十个作者写出来的男主都像同一个人？三个根因。

「根因一：只写五官，不写动作」：五官是通用的，动作才是个人的。疯批和清冷都可以有高鼻梁、薄唇，区分他们的是"那双手在做什么""那双眼在看谁"。解法：每写一处五官，紧跟着写一个只有这个男主会做的动作。

「根因二：没有差别待遇」：他看女主和看下属是同一张脸、同一个眼神、同一个笑法。解法：至少设计两组对照，他看别人 vs 他看她；他在人前 vs 他独处时。本章 4.1.3 给了三组样本，直接套。

「根因三：外貌不随剧情变化」：男主出场什么样，到结局还是什么样，伤了不留疤，老了不留纹，瘦了不陷颊。解法：给外貌加"剧情刻度"，他受过的伤要在身上留记号，他熬过的夜要在眼下留青影，他动过的心要在某个瞬间让她发现他耳尖红了。这些"变化点"是人物活过的证据。

写外貌的最后一条纪律：少即是多。一个让读者记三年的细节（眼下那颗泪痣、袖口那道旧痕、指腹那层薄茧），胜过一段三百字的五官清单。外貌描写的进阶写法，详见第十三部分 13.5 多层人设。

### 4.8.4 外貌一致性自查三条

「自查一：他的外貌标签在三十章里是否漂移」：第一章写他"眉峰极淡"，第五章忽然变成"剑眉斜飞"，这是漂移。解法：写之前在人设卡上把五到七个外貌锚点写死（眉形、眼型、泪痣位置、手的特征、固定气味、固定单品），全书只准在这几个锚点上做文章，不准新增。

「自查二：他的外貌是否只在第一次出场出现」：很多作者第一章写了三百字外貌，后面两百章再也不提他长什么样。解法：外貌是高频载体，每三到五章必须有一次"外貌复发"，不必写全脸，一个眼神、一只手、一种气味即可，让读者一直记得他长什么样。

「自查三：他的外貌是否服务了剧情」：如果一段外貌删掉，剧情和人设都不受影响，这段就是装饰。解法：每写一段外貌，问自己，这段外貌有没有透露他此刻的情绪？有没有写出他和女主的关系？有没有推进剧情？三个问题都答不上，删掉。

至此，第四部分的外貌词库、对照表、登场路径、避雷方案全部交付。写的时候不要从头到尾把所有库都翻一遍，那是工具书，不是小说。动笔前先查 4.6 对照表定位人设，写的时候从对应分库里挑两三条最贴切的，用动作把它带出来，写完用 4.8 的清单自查一遍。外貌写到这个份上，男主就活了。
