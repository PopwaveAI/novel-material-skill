# 11.3 新增十个案例（2.0 版增补项）

> 素材来源：novel-material-skill ·《男主人设手册》11.3 新增十个案例（2.0 版增补项）

- 他没有缺陷：他完美、稳、温柔，读者觉得寡淡。救法：给他一个真的会搞砸的瞬间（比如他安排了她的人生让她窒息）。
- 他全程都稳，没有破功：读者等不到他失控。救法：每二十章给一次他声音抖、手抖、或者一夜没睡的瞬间。
- 他对谁都稳，没有差别：读者看不出偏爱。救法：他对别人是公事公办的稳，对她是稳底下藏着紧张，他在她面前笔会放歪、话会说慢半拍。

【仿写练习】写一段八百字的她加班到深夜、他来接她的对手戏。自检：他有没有说一句废话？他有没有直接说我心疼你？他有没有做一件事让她（和读者）心里一动？他的手有没有一次想碰她又收回去？四条都做到，轻熟男的质感就出来了。

### 案例四：轻熟医生｜情绪稳定的治愈（主类型：轻熟男；副类型：治愈型）

一句话定位：他是急诊科最年轻的主任医师，见过太多生死，唯一一次手抖是在她进抢救室的那天。

【人设卡·五要素】
- 核心欲望：让她平安，从第一次见她捂着肚子走进急诊开始。
- 核心恐惧：在他手里失去人。他三年前没救活一个十四岁的病人，从此再没在值班室睡过整觉。
- 致命缺陷：他把所有情绪都包在专业外壳里，她生病他能治，她难过他却不知道怎么接。
- 行事逻辑：先诊断、再安抚；她哭他递纸巾但不抱；医嘱写得比情话细。
- 反差点：手术室里他稳到护士都说温主任像块石头，下了手术台他会蹲下来给她系松开的鞋带。

【底层创伤】三年前的冬夜，一个十四岁的女孩被送进来，急性阑尾炎穿孔，他主刀，女孩在台上大出血。他抢救了四个小时，女孩没下手术台。家属在走廊哭到站不住，他站在手术室门口，手套还没摘，墙上的钟显示凌晨四点。从那以后他值夜班再也不睡值班室，他坐在医生办公室写病历，写到天亮。这个创伤写出来时，要写手套上的血、走廊里那声妈妈、他在洗手池前洗到皮肤发红的那双手。

【行为与习惯清单】
- 白大褂口袋里永远有一支笔、一个小手电、一包纸巾。
- 她来看病，他问的第一句不是哪里痛，是吃饭了没有。
- 她加班不吃晚饭，他会把粥放在她工位上，不敲门，放下就走。
- 她生病他开药，但他会在医嘱上多加一句：这个药饭后吃，我五点下班，五点半陪你。
- 他从不在她面前提那个没救活的病人，但她某次问他为什么这么在意她吃饭，他沉默了三秒说有人没等到她长大。
- 她半夜急诊，他从家里赶来，白大褂下面穿着睡衣，头发没梳。
- 她情绪崩溃，他不会说别哭，他会说你现在坐在这，我听着。
- 他记得她对头孢过敏，记得她生理期不准，记得她小时候得过肺炎，这些是他在病历之外偷偷记的。
- 她出院那天，他替她办手续，把所有发票按时间叠好装在文件袋里，上面写着复查日期。

【台词样本】

（她捂着肚子走进急诊）哪里痛？什么时候开始的？吃饭了没有？

（她复查，他说恢复得很好）恢复得好。但下次不准再拖到半夜。

（她问他为什么对自己这么上心）我是医生。你是我的病人。

（她哭着说我是不是很麻烦）你不麻烦。你要是麻烦，我就不在这了。

（她问他手抖过没有）在你进抢救室那天。

【名场面一】

她急性肠胃炎半夜进急诊，他从家里赶过来，白大褂下面是睡衣。他蹲在她面前问哪里痛，她疼得说不出话，他伸手按她的肚子，按到右下腹时她嘶了一声。他抬头看护士：血常规、便常规、补液。然后他回头，声音放轻：不是大病。我在。输液的时候她靠在椅子上睡着，他从值班室拿了一件自己的外套盖在她身上。护士小周悄悄问他：温主任，你对病人都这样？他看了一眼沉睡的她，说：不是。对别的病人，我没有这样过。

【名场面二】

她康复出院，他替她办手续，把发票按时间叠好装在文件袋里。她接过来，忽然说：温医生，你为什么对我这么好。他站在窗口，阳光落在他白大褂上。他沉默了很久，说：三年前我手上有个病人，十四岁，没救回来。她要是活着，应该跟你差不多大。他转过身看她：我不是对你好。我是不想再看着一个人，因为没人好好管她，就这么没了。她眼泪掉下来。他从口袋里掏出纸巾，递过去，没说别哭。过了一会他又说：你以后吃饭要按时。这是医嘱。

【拆解仿写要点】
- 医生男主的魅力在专业感，不在温柔。他所有的温柔都要包装成医嘱和安排，这样才不腻。
- 创伤要具体到那个没救活的病人，不要泛泛写他有心理阴影。一个名字、一个年龄、一个冬夜的走廊，就够了。
- 他的手抖要极少，全书一次，就是她进抢救室那天。这一下比他说一百句我爱你都重。
- 他与女主的关系要从医患开始，慢慢越界。越界的那一步要写得克制，他多问一句吃饭了没有，就是越界。
- 治愈不是治愈她的病，是治愈她被人忽略的那部分。详见第五部分 5.3 偏爱。

【崩人设预警】
- 他变成了唠叨的老妈子：每天问吃饭睡觉，读者腻。救法：他只在关键节点出现，平时不黏人。
- 他全程专业，没有越界：读者等不到他动心。救法：每十章给一次他越界的小动作（盖外套、记医嘱之外的事）。
- 他的治愈写成了情话：他开口就是你要照顾自己。救法：他的关心全部通过动作和安排体现，不说教。
- 他太完美：医术高、人稳、还温柔。救法：给他一个真的失误（比如他误诊过一次），让读者看见他也是人。

【仿写练习】写一段八百字的她半夜发烧、他从家里赶来的对手戏。自检：他有没有先问病情再问人？他有没有说一句多余的情话？他离开时有没有留一样东西？他的手有没有一次想碰她额头又收回去？四条都做到，医生男主的质感就出来了。

### 案例五：神性仙尊｜为她破戒（主类型：神性；副类型：仙尊型）

一句话定位：他是昆仑山上三百年没有下过凡的玄清仙尊，为一个小弟子破了三百年的戒。

【人设卡·五要素】
- 核心欲望：守天道，直到遇见她。
- 核心恐惧：动情。他修炼三百年，最怕的不是死，是动凡心。
- 致命缺陷：他知道动情会毁道行，但他控制不住，他每看她一眼，道心就裂一道缝。
- 行事逻辑：凡事先讲规矩；她做错事他先罚她；但罚完他会偷偷去看她有没有事。
- 反差点：全宗门都以为他无欲无求，他的枕下却压着一根她落下的发带，压了两百年。

【底层创伤】他还没成仙的时候，师父把他从乱葬岗捡回来，告诉他：你这辈子只能修道，不能动情，动情就是死。他十七岁那年动过一次心，是隔壁村子的一个姑娘，给他送过一双布鞋。师父发现后，当着他的面把那双布鞋烧了，告诉他：她已经嫁人了，你再想她，她就会死。他从此再没见过那个姑娘。这个创伤写出来时，要写布鞋在火里卷起来的样子、师父的脸、他跪在地上没哭但指甲掐进掌心的样子。

【行为与习惯清单】
- 他的话很少，每句不超过十个字。
- 她犯错，他罚她面壁，但面壁的地方他选在能晒到太阳的角落。
- 她练功摔了，他嘴上说基本功不扎实，手却已经扶了上去。
- 他从不吃荤，但她偷带给他凡间的糕点，他会当着她的面吃，吃完说下次不许。
- 她在门派里被人欺负，他不帮她出头，但第二天那个人的功课会突然变多。
- 他的剑从不离手，但她靠在他剑旁边睡觉，他会把剑收起来，怕硌着她。
- 她下山历练，他表面上不送，她走后他会站在昆仑山顶看她的方向看很久。
- 她生病，他给她渡气，渡完他自己要打坐三天，渡气要耗他百年道行。
- 他的枕下压着她的发带，两百年没换过。

【台词样本】

（她被罚面壁，他路过）错了没有。她说错了。他说：还敢不敢。她说不敢了。他说：回去吧。

（她偷带糕点给他）下次不许。但他吃了。

（她问他为什么对自己特殊）没有特殊。你是我的弟子。

（她表白，他背过身）人仙殊途。你回去。

（她要被天雷劈，他挡在她身前）这一劫，我替你受。
