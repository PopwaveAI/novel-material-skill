# 11.3 新增十个案例（2.0 版增补项）

> 素材来源：novel-material-skill ·《男主人设手册》11.3 新增十个案例（2.0 版增补项）

她要嫁别人了。他在酒吧听见这个消息，手里的酒瓶砸在地上。全场安静。他起身走了。她追出来：你干什么。他转身，眼睛红的：你不能嫁。她说：你又不认真。他走过来，第一次抓住她的手：我以前不认真。但你要嫁别人，我慌了。她哭。他说：我奶奶走那年，我十二岁。她留下一只杯子，我收在柜子里。我浪，是因为我怕认真了人会走。但你不一样。你退的时候，我慌了。

【拆解仿写要点】
- 烂人浪子的魅力在迟到的真心。他越浪，真心的那一下越重。
- 他的浪要具体到场景，酒吧、撩女人、换女人。
- 他的创伤要回扣奶奶去世，他不是天生烂，他是怕人走。
- 他的真心要在最后一刻才露，她要嫁别人，他才失态。
- 他的结局要有成长：他学会不浪、学会认真。详见第三部分 3.2 烂人真心。

【崩人设预警】
- 他变成了纯渣男：他全程浪，读者不站他。救法：让她要嫁别人时他慌了，这个慌是真心的开始。
- 他浪得太廉价：他见谁撩谁。救法：他只对她认真。
- 他全程浪，没有出口：读者等不到他认真。救法：每二十章给一次他破功的瞬间。
- 他的创伤太浅：他只是说怕人走。救法：给一个奶奶去世的场景。

【仿写练习】写一段八百字的她拒绝他的对手戏。自检：他有没有当场被拒？他有没有解释他为什么浪？她走了之后他有没有一个人慌？他第二天有没有做一件让她心软的事？四条都做到，烂人浪子的质感就出来了。

### 案例十八：烂人反派｜自毁式的爱（主类型：烂人；副类型：反派型）

一句话定位：他是全书最大的反派，杀人不眨眼，唯独对她下不去手，最后为她毁了自己。

【人设卡·五要素】
- 核心欲望：毁掉所有对不起他的人，包括他自己。
- 核心恐惧：她知道他是反派后会怕他。
- 致命缺陷：他把爱做成自毁，他越爱她，越把自己往绝路上推。
- 行事逻辑：先杀人，再谈爱；她的安全第一，但她不能知道他在做什么。
- 反差点：他在所有人面前是杀人不眨眼的反派，回到她面前却连大声说话都舍不得。

【底层创伤】他小时候被所有人欺负，没有人帮他。他十四岁那年第一次杀人，是为了自卫。他从此知道：这个世界对他不好，他也要对这个世界不好。这个创伤写出来时，要写他被打的那个巷子、他第一次杀人后在河边洗到天亮的手、他抬头看天的样子。

【行为与习惯清单】
- 他杀人前先笑，笑的时候眼角不动。
- 她给他的东西，他都收着，但他从不带在身上，怕被她看见。
- 她问他的过去，他说：我是个坏人。
- 他手上有血，但他在她面前从不伸手。
- 她遇到危险，他先护她，但护完他自己要躲起来，怕她看见他杀人的样子。
- 他从不在她面前喝酒，因为喝酒会吐真言。
- 他的计划是毁了所有人，但他给她留了一条退路。
- 她发现他是反派，他说：你当我死了。
- 最后他为她挡了一刀，死在她怀里。

【台词样本】

（她问他的过去）我是个坏人。

（她问他手上的血）干活弄的。

（她发现他是反派）你当我死了。

（她哭着说你为什么不解释）我解释了，你就走不了了。

（最后他挡刀）这次……我不躲了。

【名场面一】

她偶然看见他杀人。她吓得发抖，转身要跑。他挡在她面前：你看见了。她哭：你是坏人。他说：是。她后退：你杀了人。他说：是。她转身跑了。他没追。他一个人站在原地，站了很久。后来她听说，那天他杀的那个人，是当年欺负他的人。她站在雨里，不知道该恨他还是该心疼他。

【名场面二】

她被仇人抓住，用来威胁他。他一个人闯进仇人的老巢，杀了所有人。他走到她面前，身上全是血。她哭：你为什么要来。他说：我不杀他们，他们就杀你。仇人最后一刀刺过来，他挡在她前面，刀插在他胸口。他倒在她怀里。她哭：你干什么。他伸手摸她的脸：这次……我不躲了。他笑了一下：我是个坏人。但对你，我不坏。他闭上眼睛。

【拆解仿写要点】
- 反派男主的魅力在自毁。他越坏，为她死的那一下越重。
- 他的坏要具体到场景，杀人、血、巷子。
- 他的创伤要回扣被欺负，他不是天生坏，他是被逼的。
- 他的爱要做成自毁，他越爱，越把自己往绝路上推。
- 他的结局必须是死或者被抓，反派不能洗白成好人。详见第八部分 8.4。

【崩人设预警】
- 他变成了纯反派：他杀人不眨眼，读者不站他。救法：他只杀欺负过他的人，不杀无辜。
- 他洗白成好人：最后他变好了。救法：他必须为他的恶付出代价，死或者被抓。
- 他全程坏，没有出口：读者等不到他爱她。救法：每二十章给一次他对她好的瞬间。
- 他的创伤太浅：他只是说被欺负。救法：给一个具体的巷子场景。

【仿写练习】写一段八百字的她发现他杀人的对手戏。自检：他有没有解释？他有没有让她走？她走了之后他有没有一个人站在雨里？他最后有没有为她挡刀？四条都做到，反派男主的质感就出来了。

### 案例十九：罕见性格｜冷幽默的疯子（主类型：罕见性格；副类型：冷幽默型）

一句话定位：他是全城最不能惹的疯子，杀人时还在讲冷笑话，唯独对她讲的笑话她不笑。

【人设卡·五要素】
- 核心欲望：活得有趣，他的人生太苦，他要用冷笑话把苦盖过去。
- 核心恐惧：被人看穿他的冷幽默底下是痛。
- 致命缺陷：他用冷幽默挡所有人，包括她；她走了他才知道，他失去的是唯一不笑他笑话的人。
- 行事逻辑：先讲笑话，再杀人；她怕他，他就讲个笑话让她不那么怕。
- 反差点：他在杀人现场是讲冷笑话的疯子，回到她面前却因为她不笑他的笑话而失眠一夜。

【底层创伤】他小时候全家被杀，他躲在柜子里，听着外面的声音。他从此用冷笑话盖过那个晚上。他杀人时讲冷笑话，是因为他不讲就会想起那个晚上。这个创伤写出来时，要写柜子的缝、外面的声音、他在柜子里数到天亮的样子。

【行为与习惯清单】
- 他杀人前先讲个冷笑话。
- 她给他做饭，他讲个笑话，她不笑，他回去把笑话练了十遍。
- 她怕他，他就讲个笑话让她不那么怕。
- 她跟别的男人说话，他在旁边讲个冷笑话，讲完把那人吓跑。
- 他送她东西，附一张纸条，写个冷笑话。
- 她不理他，他在她窗外讲笑话，讲到她开窗。
- 她要走，他第一次没讲笑话，站在原地。
- 他从不在公开场合承认他在意她。
- 她走了，他把所有讲过的笑话都写在本子里。

【台词样本】

（杀人前）你知道为什么死人不说话吗？因为他们……死了。

（她怕他）别怕。我杀人不杀熟人。

（她不笑他的笑话）……你怎么不笑。

（她要走）你别走。我再讲个笑话。

（她哭着说你能不能别讲笑话）好。我不讲了。

【名场面一】

他抓住一个仇人，仇人吓得发抖。他蹲下来：你知道为什么死人不说话吗？仇人不答。他自己说：因为他们死了。然后他笑了。仇人吓得尿了。他起身，对旁边的手下说：把他处理了。他转身回去，她在门口等他。她问：你又讲笑话了？他说：嗯。她说：你能不能别讲了。他愣住：为什么。她说：因为你讲笑话的时候，比杀人还可怕。

【名场面二】

她要走了。他站在门口，手里拿着那个写满笑话的本子。她说：你能不能别讲笑话了。他说：好。他第一次没讲笑话。他说：我小时候全家被杀，我躲在柜子里。我不讲笑话，就会想起那个晚上。她哭。他说：你是第一个不笑我笑话的人。我以为你笑了，就不怕我了。但你不笑，你才看见我。

【拆解仿写要点】
- 冷幽默疯子的魅力在反差。他越讲笑话，底下的痛越重。
- 他的笑话要冷，不要搞笑，要冷。
- 他的创伤要回扣柜子，他不是天生冷幽默，他是怕想起那个晚上。
- 他的真心要在最后一刻才露，她要走，他才不讲笑话。
- 他的结局要有出口：她不笑他的笑话，但她看见他。

【崩人设预警】
- 他的笑话太搞笑：读者笑了，不觉得痛。救法：他的笑话要冷，冷到让人起鸡皮疙瘩。
- 他全程讲笑话，没有出口：读者等不到他不讲。救法：每二十章给一次他不笑的瞬间。
