# 6.1 人设弧光三段式：初始状态 → 触发事件 → 改变与代价

> 素材来源：novel-material-skill ·《男主人设手册》6.1 人设弧光三段式：初始状态 → 触发事件 → 改变与代价

「他说了半句又咽回去」：写中间态的摇摆。例句：他张了张嘴，说到一半，自己停了，转而说：没事。

「他把刀递出去」：写他把命交给她。例句：他把那把刀搁在她面前，刀柄朝她，刀身没动。

「他第一次跪下」：写他对事不对人。他从前跪天跪地跪君父，这一次他为一个人跪。例句：他在午门外跪下，背挺得很直，一句话没说。

「他把袖子抚平」：写他恢复伪装。例句：他起身，把被风吹皱的袖口一寸一寸抚平，脸上又挂上那副笑。

「他站到她身边，不是她身后」：写他从保护者改成并肩者。例句：他从前总把她护在身后，这一次他退到她旁边，和她背靠背站着。

「他把钥匙扔在井里」：写他封死退路。例句：他把那把锁院子的钥匙扔到井里，听了一声响，转身走了。

「他没追那阵风」：写他接受失去。例句：帕子被风卷走，他抬眼看了看，没追。

「他笑了一下，没说话」：写他终于学会沉默里有内容。例句：她问他后悔吗，他笑了一下，没答，端起茶喝了一口。

「他写了又揉」：写他第一次想说却说不出口。例句：信纸写了七张，揉了七张，第八张他没写完，锁进抽屉。

「他回头，她也回头」：写开放式的余味。例句：走出去十步，他回头，她也回头，隔着一条街，都没动。

「他让她等」：写他从前从不让人等他。例句：他对她说：你等我把这课上完。

「他把奏折烧了」：写他放弃野心。例句：他把那道写了三天的奏折凑到烛火上，看它烧尽。

「他问她怎么回」：写他把她放进自己的决断里。例句：他把参他的折子念给她听，问：你觉得该怎么回。

「他摸了摸袖扣」：写他紧张时的老动作。例句：他紧张时会摸袖扣，这个动作到结局他也没改。

「他把那盏灯留到天亮」：写他为她守夜。例句：她屋里的灯他不让灭，自己在隔壁坐了一夜，灯芯烧短了三次，他都起来添过。
