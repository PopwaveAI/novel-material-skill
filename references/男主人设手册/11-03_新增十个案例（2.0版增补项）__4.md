# 11.3 新增十个案例（2.0 版增补项）

> 素材来源：novel-material-skill ·《男主人设手册》11.3 新增十个案例（2.0 版增补项）

她练功走火入魔，剑气伤了自己。他冲进她的洞府时，她倒在地上，嘴唇发青。他蹲下来，把她抱到榻上，指尖搭在她腕上。她睁开眼，看见他，伸手摸他的脸：师尊，你的手在抖。他没说话，把手收回去。他给她渡了一口真气，那一口真气耗了他五十年道行。她睡过去之后，他坐在她床边，第一次在自己的洞府里叹气。他的徒弟清风端药进来，看见他枕下露出一根发带，是她十五岁那年掉的。清风没敢说话。他起身，把发带塞回枕下，说：照顾好她。然后他走出洞府，在昆仑山顶站了一夜。

【名场面二】

她爱上他的事被宗门发现，长老们要废她的修为逐出师门。他站在大殿上，长老问他：玄清，你动过心没有。他沉默了很久，说：动过。大殿哗然。长老说：那就废她。他拔出剑，剑尖指向长老：你们要动她，先过我这一关。三百年，他第一次在宗门大殿上拔剑。他的道心那一刻碎了，他听见自己体内有什么东西裂开的声音。他回头看她，眼睛红的，但声音还是平的：你走。我留下来处理。她哭着说不走。他说：这是命令。她走后，他一个人在大殿上站到天亮，他的道行从九重天掉到了七重天。但他不后悔。

【拆解仿写要点】
- 神性男主的魅力在克制。他越克制，破戒的那一下越重。不要让他一上来就动情，要让他压了三百章才动。
- 他的破戒要一件一件来：从吃她带的糕点、到扶她、到渡气、到拔剑。每一步都是一次破戒，每一步都有代价。
- 创伤要回扣那个烧布鞋的意象，他不是天生无情，他是被教成无情的。他动情不是天性，是反抗。
- 他对她的好不能说，只能做。渡气、挡剑、站一夜，这些动作比台词重。
- 神性男主与女主的关系要有伦理张力，师徒、人仙、规矩。张力越大，破戒越爽。详见第五部分 5.5。

【崩人设预警】
- 他变成了面瘫：全程没表情，读者觉得木。救法：每二十章给一次他眼神动、手停、或者背过身叹气的瞬间。
- 他破戒太快：前几章就表白，神性碎了。救法：把破戒分成十次小破戒、一次大破戒，慢慢放。
- 他的神性没有落点：他高高在上但不知道他守的是什么。救法：给他一个具体的信念（守天道、护宗门），让他的破戒真的有代价。
- 他对她太宠：他全程护着，没有克制。救法：他要先罚她、推开她、说人仙殊途，然后再破戒。

【仿写练习】写一段八百字的她被罚面壁、他偷偷去看她的对手戏。自检：他有没有说超过十个字的话？他有没有动手碰她？他离开时有没有留下一样东西？他回去之后有没有一个人消化这件事？四条都做到，神性仙尊的克制感就出来了。

### 案例六：神性掌权者｜悲悯与疏离（主类型：神性；副类型：掌权者型）

一句话定位：他是君临天下的少年帝王，悲悯苍生却不靠近任何人，唯独在她身上看见了自己。

【人设卡·五要素】
- 核心欲望：做一个好皇帝，让天下不再有人像他小时候那样挨饿。
- 核心恐惧：靠近人。他见过太多人为了权力靠近他，他不信任何人是真心的。
- 致命缺陷：他把所有人都当成子民来怜悯，却没有人把他当成一个人来疼。
- 行事逻辑：先天下后自己；她求他什么他都答应，但他从不求她。
- 反差点：他在朝堂上是铁血帝王，回到寝宫却一个人对着窗外的雪坐到天亮。

【底层创伤】他九岁那年宫变，他被藏在枯井里三天，外面是他父亲的尸体。第三天夜里，一个小太监偷偷给他塞了一块干饼，小太监第二天就被人打死了。他从枯井里出来时，手里还攥着那块饼的碎渣。他登基那年十四岁，朝堂上的老臣都觉得他是个孩子。这个创伤写出来时，要写枯井里的冷、那块干饼的硬、小太监塞饼时手在抖。

【行为与习惯清单】
- 他吃饭从不浪费一粒米，枯井里那三天的后遗症。
- 他批奏折到深夜，太监劝他休息，他说天下还有人没睡，朕不敢睡。
- 她求他免某地赋税，他二话不说就准，但他准完会问她：你怎么知道那个地方的事。
- 他从不让人伺候穿衣，但她来了，他会让她替他系朝服上的带子。
- 他记仇，当年参与宫变的人，他一个一个慢慢收拾，不急，但一个不漏。
- 他对她好的方式是给她自由：她想走，他不拦；她想留，他给她最好的。
- 他从不当众牵她的手，但她走过他身边时，他的袖子会悄悄碰一下她的袖子。
- 他夜里失眠，会一个人在御花园走，她撞见一次，陪他走了半圈，他没说话，但第二天她宫里多了一盏跟御花园一样的灯。
- 他的玉玺盖下去从不犹豫，但她的事，他要盖三次才盖得下去。

【台词样本】

（她求他免赋税）准。你下次想求什么，直接来。

（她问他为什么对自己这么好）你让朕想起一个人。他给过朕一块饼。

（她说你是皇帝，你不用对谁都这样）朕是皇帝。但朕也是人。

（她要离开皇宫）你要走，朕不拦。但你要记得，宫门永远为你开着。

（她在雪夜陪他走）朕这辈子，没人陪朕走过夜路。

【名场面一】

南方大旱，她跪在养心殿外求他开仓放粮。他不见她，跪了三个时辰。太监来报，他在里面批奏折，批到第三本，忽然停了笔。他走到门口，没开门，隔着门说：你起来。朕准了。她在门外哭。他在门里站了很久。然后他开门，把她扶起来，她膝盖都麻了。他没说话，把她打横抱起来，放进殿内的软榻上。太监都看傻了，皇帝从不碰人。他蹲下来，替她揉膝盖，声音很轻：下次不要跪。你要什么，朕给。

【名场面二】

她要离开皇宫。他站在宫墙上看她的马车走远。他身边的大太监问他：陛下不留她？他说：她要的是自由，朕给不了。朕能给的是天下，不是一个人。大太监低头。他又站了一会，忽然说：去，把朕的令牌给她。她走到城门，守城的拦住她，递过来一块令牌。她回头看皇宫的方向，宫墙上那个身影还在。她攥着令牌，眼泪掉下来。后来她才知道，那块令牌是他能给的最高特权，持此令牌，随时可入宫，随时可走。他给了她自由，也给了她退路。

【拆解仿写要点】
- 神性掌权者的魅力在高位感加孤独感。他越高，越孤独；她是唯一看见他孤独的人。
- 他的悲悯要通过具体事件体现（免赋税、开仓），不能空写他爱民如子。
- 他与女主的关系要克制：他不靠近，但他给她所有的特权。这种克制比宠更动人。
- 创伤要回扣那块干饼，他对她的好，本质上是对当年那个小太监的报答。这条暗线要埋到结局。
- 他的结局要有取舍：是选择天下，还是选择她。这个取舍是全书的立意。

【崩人设预警】
- 他变成了圣父：他对所有人都好，读者觉得假。救法：他只对她例外，对别人他是皇帝，不是好人。
- 他全程疏离，没有靠近：读者等不到他动心。救法：每二十章给一次他越界的动作（抱她、替她揉膝盖、给令牌）。
- 他的高位感没有代价：他是皇帝但他不累。救法：写他批奏折到深夜、写他失眠、写他一个人坐天亮。
- 他对她太宠：他什么都给，读者觉得腻。救法：他要克制，他给特权但不表白，他靠近但不牵手。

【仿写练习】写一段八百字的她跪在殿外求他开仓的对手戏。自检：他有没有立刻开门？他有没有说一句心疼她的话？他开门之后做了什么动作？他离开之后有没有一个人消化这件事？四条都做到，神性掌权者的质感就出来了。

### 案例七：清冷师尊｜冷面下的在意（主类型：清冷感；副类型：师尊型）

一句话定位：他是修仙界最冷的孤月师尊，收了她这个徒弟，从此冷面上多了一道裂缝。

【人设卡·五要素】
- 核心欲望：修成大道，直到她出现。
- 核心恐惧：被人看穿他的冷底下是热。
- 致命缺陷：他把所有在意都藏在冷冰冰的规矩里，她以为他不在乎。
- 行事逻辑：先讲规矩；她做错他先罚；罚完他偷偷补她。
- 反差点：全宗门都以为他六亲不认，他的剑穗却是她十五岁编的，他挂了二十年。
