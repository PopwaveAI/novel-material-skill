# 11.3 新增十个案例（2.0 版增补项）

> 素材来源：novel-material-skill ·《男主人设手册》11.3 新增十个案例（2.0 版增补项）

【底层创伤】他小时候是个孤儿，被前任师尊捡回去。前任师尊对他极严，从不对他笑。他出师那天，前任师尊只说了一句：修道之人，不能有情。他站在山门口，等了一天，等师尊出来送他，师尊没出来。他从此以为，好的师尊就是不靠近弟子。这个创伤写出来时，要写山门的风、他等了一天的石头、他最后转身走时没有回头。

【行为与习惯清单】
- 他说话不超过十个字，但他会把她的名字在心里念三遍。
- 她练功受伤，他给她上药，手很稳，但上完药他会自己在外面站一会。
- 她的功课他批得最严，但每次批完他会在末尾写一个继续。
- 她被人欺负，他不帮她出头，但第二天那个人的剑会断。
- 她过生日，他送她一本功法，书里夹着一颗她小时候爱吃的糖。
- 她下山，他不送，但她走后他会站在山门口看她的背影。
- 她发烧，他给她渡气，渡完他自己要打坐，但他不说耗了多少道行。
- 他的剑穗是她编的，二十年没换过。
- 她跟别的师兄走得近，他会在她路过时故意把剑拔出来擦，擦完看她一眼。

【台词样本】

（她犯错，他罚她）去面壁。

（她问他为什么对自己严）你是我弟子。

（她生日，他送书）这本你用得上。

（她下山，他说）小心。就两个字。

（她表白，他背过身）修道之人，不能有情。

【名场面一】

她练功走火，剑气伤了自己。他冲进她的洞府，她倒在地上。他蹲下来，把她的手搭在自己腕上，渡了一口真气。她睁开眼，看见他，伸手摸他的脸：师尊，你的手在抖。他把手收回去，没说话。他给她上完药，起身要走。她拉住他的袖子：师尊，你是不是在乎我。他背对着她，站了很久，说：你是我弟子。然后他走了。但他没回自己洞府，他在她洞府外的石头上坐了一夜。第二天她开门，看见石头上有霜，他的剑穗挂在石头上，她编的那个。

【名场面二】

她要下山历练，他不送。她走到山门口，回头看，他不在。她走了。他其实在山门外的树上坐着，看她的背影走远。他的大弟子清风问他：师尊，你不去送送小师妹？他说：修道之人，不能有情。清风说：那你的剑穗为什么是她编的？他沉默了。过了一会他说：收拾东西。清风问去哪。他说：下山。清风愣了：师尊你不是不下山吗？他已经走了。

【拆解仿写要点】
- 清冷男主的魅力在冷面下的热。他越冷，热的那一下越重。
- 他的在意要通过具体物件体现，剑穗、糖、功法书。这些物件是他的情话。
- 他不能表白。他所有的在意都要藏在动作里。他下山找她，比说我爱你重十倍。
- 创伤要回扣他的前任师尊，他不是天生冷，他是被教成冷的。他对她的好，本质上是对当年自己的补偿。
- 清冷与神性的区别：神性是高位者为她破戒，清冷是冷面人对她例外。详见第二部分 2.3 与 2.4。

【崩人设预警】
- 他变成了真的冷：全程没表情，读者觉得木。救法：每十章给一次他眼神动、手停、或者背过身的瞬间。
- 他对她太宠：他全程护着，没有冷。救法：他要先罚她、推开她、说修道不能有情，然后再偷偷补她。
- 他的冷没有理由：他天生冷，读者不心疼。救法：给他一个被教成冷的创伤。
- 他太快动心：前几章就破戒，清冷碎了。救法：把破戒分成十次小破戒，慢慢放。

【仿写练习】写一段八百字的她练功受伤、他上药的对手戏。自检：他有没有说超过十个字的话？他有没有动手碰她超过三秒？他离开时有没有留下一样东西？他回去之后有没有一个人消化？四条都做到，清冷师尊的质感就出来了。

### 案例八：清冷学者｜克制的心动（主类型：清冷感；副类型：学者型）

一句话定位：他是大学里最年轻的博导，三年没正眼看过人，唯独在她的论文草稿上停了笔。

【人设卡·五要素】
- 核心欲望：做完那本写了十年的书。
- 核心恐惧：分心。他的时间每一分钟都算好了。
- 致命缺陷：他把感情当变量，想控制它，但控制不住。
- 行事逻辑：先理性能后感性；她表白他先分析；分析完他自己也乱了。
- 反差点：讲课从不看学生的他，在她的论文草稿上写了满满三页批注。

【底层创伤】他读博那年喜欢过一个师妹，师妹毕业跟别人走了。他从此把所有精力投入学术，不再跟人有任何私人往来。他的导师说他：你不是不喜欢人，你是怕再被人丢下。这个创伤写出来时，要写图书馆那个他常坐的位置、师妹借走没还的那本书、他在办公室坐到凌晨三点的灯。

【行为与习惯清单】
- 他的书桌永远整洁，笔按颜色排。
- 她来问问题，他讲得比给博士生还细，但他不说他故意讲细。
- 她的论文他改三遍，改完他发现自己在批注里写了一句这个观点很好，划掉了。
- 她加班到实验室关灯，他会假装也在加班，等她走了他才走。
- 她病了，他把药放在她实验室门口，不留名。
- 他从不吃别人带的饭，但她带的三明治他会吃，吃完说下次别带了。
- 她跟男同学讨论问题，他会在办公室里把书翻得很响。
- 她的名字他从不在公开场合提，但他的邮箱里存着她所有的邮件。
- 她毕业那天，他站在人群后面，没上前。

【台词样本】

（她来问问题）这个地方，你再看三遍。

（她感谢他改论文）我是你导师。这是我的工作。

（她问他为什么对自己特殊）没有特殊。你的论文有可改之处。

（她表白，他沉默了很久）我需要想一想。

（她毕业，他说）以后有问题，可以回来问。

【名场面一】

她的论文初稿被外审毙了，她在实验室哭到凌晨。他路过，看见灯还亮着。他推开门，她抬头，眼睛红的。他没说话，走过去把她的论文拿起来，坐在旁边的椅子上，一页一页看。看到天蒙蒙亮，他放下论文，说：外审毙的不是你，是那个审稿人没看懂。他把论文递回去：我陪你改。她抬头看他：林老师，你为什么对我这么好。他把眼镜摘下来擦了擦：你的论文，是我带过最好的。他没说的是：你的论文，他改了三遍，每一遍都在凌晨。

【名场面二】

她毕业那天，他站在人群后面。她穿学士服，跟同学合影。他想上前，脚没动。她跟同学告别，转身看见他。她跑过来：林老师，我毕业了。他点头：嗯。她伸出手：谢谢你。他犹豫了一下，握了握她的手，很快松开。她转身要走，他忽然说：以后有问题，可以回来问。她回头笑：林老师，你这是想我了吗。他没说话，转身走了。她站在原地，看见他走得比平时快。

【拆解仿写要点】
- 学者男主的魅力在智性恋，他通过改论文、讲题靠近她，而不是通过约饭。
- 他的心动要通过学术细节体现：改三遍论文、写批注、熬夜陪她。这些是他的情话。
- 他不能主动。他所有的靠近都要包装成工作。读者要的是"他明明在乎但他不说"。
- 创伤要回扣那个师妹，他不是不喜欢人，他是怕再被丢下。
- 他的结局要给一个出口：要么他终于开口，要么她主动一步。不能让他一直克制到死。

【崩人设预警】
- 他变成了油腻教授：开口就是你很特别。救法：他的所有表达都要包装成学术指导。
- 他全程克制，没有出口：读者等不到他动心。救法：每十章给一次他破功的瞬间（改三遍、陪她熬夜、握她手）。
- 他的智性恋写成了说教：他全程在讲学术，读者腻。救法：他讲学术的时候，要夹一个只有他和她懂的细节。
- 他太完美：学术高、人稳、还帅。救法：给他一个真的笨拙，他不会约人、不会表白、连握手都犹豫。

【仿写练习】写一段八百字的她论文被毙、他陪她改的对手戏。自检：他有没有说一句私人的话？他有没有把她的论文拿起来看？他离开时有没有留一样东西？他回去之后有没有一个人想她？四条都做到，清冷学者的质感就出来了。

### 案例九：隐忍暗卫｜无声守护（主类型：隐忍型；副类型：守护型）

一句话定位：他是她的暗卫，从小被训练不能说话、不能抬头、不能有感情，为她挡了十三次刀。

【人设卡·五要素】
- 核心欲望：护她安全，这是他唯一被允许的欲望。
