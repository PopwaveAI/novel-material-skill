# 11.3 新增十个案例（2.0 版增补项）

> 素材来源：novel-material-skill ·《男主人设手册》11.3 新增十个案例（2.0 版增补项）

- 致命缺陷：他把爱做成温柔的囚禁，她以为他是好老师，直到她发现他删了她所有男同学的联系方式。
- 行事逻辑：先温柔，再控制；她的每一步他都安排，但他安排得让她觉得是为她好。
- 反差点：他在课堂上是最温柔的教授，回到办公室却对着她的手机屏幕看了一夜。

【底层创伤】他小时候母亲离开家，他被父亲管教极严。他从此知道：爱就是控制，控制就是为她好。这个创伤写出来时，要写父亲把他锁在书房的那个下午、母亲走时没回头的样子、他把自己锁在房里一夜的样子。

【行为与习惯清单】
- 他在课堂上说话温文尔雅，但他的眼睛在看她。
- 她的手机他看过，但他不说。
- 她跟男同学讨论问题，他在课后把那个男同学的成绩压低。
- 她的作业他改三遍，改完他在末尾写一句这个观点很好。
- 她加班到实验室关灯，他会假装也在加班，等她走了他才走。
- 她病了，他把药放在她实验室门口，不留名。
- 他从不吃别人带的饭，但她带的三明治他会吃。
- 她跟别的男人说话，他会在办公室里把书翻得很响。
- 她的名字他从不在公开场合提，但他的邮箱里存着她所有的邮件。

【台词样本】

（课堂上，他看着她）这位同学，你来说说。

（她问他为什么对自己好）你是我学生。

（她发现他删了男同学的联系方式）我是为你好。

（她要走，他说）你别走。我……我改。

（她哭着说你这不是爱）我知道。但我不知道怎么爱。

【名场面一】

她偶然发现手机里所有男同学的联系方式都被删了。她愣住，转身看见他站在实验室门口。他走进来，把门关上。她说：是你删的。他说：是。她后退：你为什么。他说：我是为你好。那些男生，他们跟你说话不是为了学习。她哭：你凭什么管我。他走过来，第一次伸手握住她的手：因为……我控制不住。

【名场面二】

她要离开他。他站在实验室门口，手里拿着她的手机。她说：你把手机还我。他把手机递给她：你走了，别回来。她转身要走，他忽然说：等等。她回头。他摘下眼镜，第一次让她看见他眼睛红的样子：我小时候，我妈走了。我爸把我锁在书房，说这是为我好。我以为爱就是这样。但你走了，我才知道，我做错了。她站在原地，眼泪掉下来。

【拆解仿写要点】
- 斯文败类的魅力在温柔的危险。他越温柔，控制的那一下越重。
- 他的控制要具体到删联系方式、压成绩、看手机，不要空写他控制。
- 他的创伤要回扣父亲把他锁在书房，他不是天生败类，他是被教成这样的。
- 他的真心要在最后一刻才露，她要走，他才摘眼镜。
- 他的结局要有成长：他学会放手、学会不控制。

【崩人设预警】
- 他变成了纯变态：他全程控制，读者害怕。救法：他只控制跟她说话的男生，不控制她本人。
- 他的控制太温柔：读者不觉得可怕。救法：让她真的发现、真的反抗、真的要走。
- 他全程温柔，没有出口：读者等不到他露危险。救法：每二十章给一次他破功的瞬间。
- 他的创伤太浅：他只是说父亲严。救法：给一个被锁在书房的场景。

【仿写练习】写一段八百字的她发现手机被删的对手戏。自检：他有没有承认？他有没有说为你好？她走了之后他有没有一个人摘眼镜？他第二天有没有做一件让她心软的事？四条都做到，斯文败类的质感就出来了。

### 案例二十三：忠犬将军｜战死也要护她（主类型：忠犬；副类型：将军型）

一句话定位：他是镇守边关的将军，她是他从小护着的姑娘，他的命是她的。

【人设卡·五要素】
- 核心欲望：护她安全，这是他从十五岁那年就立下的誓。
- 核心恐惧：她不需要他了。
- 致命缺陷：他把所有的爱都做成守护，她不知道他爱她，只知道他护着她。
- 行事逻辑：她的安全第一；她的命令第二；他的命最末。
- 反差点：他在战场上是杀人不眨眼的将军，回到她面前却连说话都不敢大声。

【底层创伤】他十五岁那年，她被人欺负，他替她挡了一棍子，背上留了一道疤。他从那天起立誓：这辈子护她。这个创伤写出来时，要写那根棍子、他背上的疤、他跪在她面前说我护你的样子。

【行为与习惯清单】
- 他在战场上杀人不眨眼，但在她面前说话声音放轻。
- 她走在前面，他永远在她身后三步。
- 她睡觉，他在她窗外守一夜。
- 她受伤，他比她还慌，但他不说，他只是手会抖。
- 她的名字他在心里念，但从不说出口。
- 她遇到危险，他第一个挡在她前面。
- 她给他的东西，他都收着，一块帕子、一块糖。
- 她问他叫什么，他说：我是你的将军。
- 他从不在她面前提他背上的疤。

【台词样本】

（她问他疼不疼）不疼。

（她问他为什么护她）职责。

（她问他叫什么）我是你的将军。

（她说你能不能不挡刀）不行。

（她哭着说你为什么不说你也疼）……不敢说。

【名场面一】

她遇刺，他挡在她前面，刀插在他肩上。她吓得哭出来，转身看他。他第一次让她看他的背，那道疤。她愣住：你背上怎么了。他把衣服拉好：旧伤。她伸手去摸那道疤，他身体僵住。她眼泪掉下来：你替我挡了多少次刀。他没说话。她把他的手抓住：以后不准再挡。他摇头：职责。她哭：那不是职责，那是你。

【名场面二】

她要嫁人了，嫁给一个世家公子。他站在她身后三步，看她试嫁衣。她转身：将军，你过来。他走过去。她说：你替我看看，这嫁衣好看吗。他抬头看她，她穿着大红的嫁衣，他眼睛红了。他说：好看。然后他跪下，从怀里掏出一块帕子，是她十年前给他的那块。他说：姑娘，以后有人护你了。我……可以走了。她蹲下来：你去哪。他说：我是个将军。她抓住他的手：你不准走。你走了，谁替我挡刀。

【拆解仿写要点】
- 忠犬将军的魅力在无声的守护。他所有的爱都通过挡刀、守夜、收帕子体现。
- 他的创伤要回扣那根棍子和那道疤，他不是天生忠，他是被她需要过。
- 他第一次让她看背，是全书的高光。
- 他与女主的关系要有身份差：将军与主子。
- 他的结局要有取舍：是继续做将军，还是被她看见。

【崩人设预警】
- 他全程忠，没有高光：读者等不到他开口。救法：每二十章给一次他说超过三个字的瞬间。
- 他变成了工具人：他只会挡刀。救法：给他一个私人空间，收帕子、守夜。
- 他的忠没有代价：他挡刀但不疼。救法：让他真的受伤、真的差点死。
- 他对她太服从：全程服从。救法：给他一次他违抗她命令的瞬间，为了她好。

【仿写练习】写一段八百字的她遇刺、他挡刀的对手戏。自检：他有没有说超过三个字的话？他有没有让她看他的背？他离开时有没有留下一样东西？他回去之后有没有一个人包扎？四条都做到，忠犬将军的质感就出来了。

### 案例二十四：反派转化·追妻火葬场（主类型：反派转化；副类型：追妻型）

一句话定位：他是她曾经爱错的人，等她心死离开，他才发现他想要的是她。

【人设卡·五要素】
- 核心欲望：把她追回来，哪怕她已经不爱了。
- 核心恐惧：她真的不爱了。
- 致命缺陷：他在她爱他的时候不珍惜，等她走了才追，已经晚了。
- 行事逻辑：先冷，再追；她不理他，他堵在门口；她恨他，他跪着不走。
- 反差点：他在所有人面前是高冷的大佬，在她门口却跪了一夜。

【底层创伤】他以前是那种被人捧着的人，不知道怎么珍惜。她爱他的时候，他觉得她不会走。等她走了，他才发现他的世界空了。这个创伤写出来时，要写她走的那个雨夜、他在她空房间里站了一夜的样子、他把她留下的东西一件件收好的动作。

【行为与习惯清单】
- 她在的时候，他从不主动找她。
- 她走了，他每天去她楼下站着。
- 她给他发消息，他回得很冷淡；她不发了，他又主动发。
- 她跟别的男人说话，他在旁边不动，回去把那个男人的底细查三遍。
- 她生日，他送她很多东西，但她不收。
- 她不理他，他在她楼下等一夜。
- 她要搬家，他第一次失态，把她的箱子抢过来。
- 他从不在公开场合承认他在追她。
- 她恨他，他跪着不走。
