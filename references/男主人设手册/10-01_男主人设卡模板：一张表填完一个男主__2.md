# 10.1 男主人设卡模板：一张表填完一个男主

> 素材来源：novel-material-skill ·《男主人设手册》10.1 男主人设卡模板：一张表填完一个男主

| 字段组 | 填写内容 |
|---|---|
| 基础信息 | 沈清辞，外表 25 岁、实际修行千年，蜀山掌门，仙侠。一句话定位：他守了山门一千年没为谁破过例，直到那个磕破额头的小弟子。 |
| 外貌锚点 | 眉峰极淡、一双不怎么起波澜的眼、眉心一颗极淡的朱砂痣、一身月白道袍、常年一柄拂尘、身上有雪后松柏的清气、垂眼时睫毛投一小片影。 |
| 性格底色 | 对外标签：冷淡、疏离、不食人间烟火。对内真实：把在意藏在最深处，自己都不肯承认。行事逻辑：一定会先替她把事做了、再装作没发生；绝不会当众表露、绝不会主动开口。 |
| 过往经历 | 他是上一任掌门从昆仑墟捡回的一块灵石，修成人形那天，全山只为他一人开过藏经阁。他生来就被教育"神不应有情"。 |
| 致命缺陷 | 不会表达。他做了所有能做的，却一句软话都说不出口，让她以为他从不在意。代价：她下山那次，差点再也不回来。 |
| 台词习惯 | 口头禅：嗯、随你、不必、知道了、我在。禁忌用语：长篇大论的解释、当众的偏爱、肉麻的情话。说话节奏：短、淡、留白。 |
| 关系网 | 对女主：嘴上冷淡，行动上替她挡雷劫、替她受罚。男二（同门前辈师兄）：视为人，不设防，唯独在她的事上会不动声色地横一刀。对手（魔族）：剑下从不留情。弟子们：一视同仁，唯独她的功课他亲自批。 |
| 五要素 | 核心欲望：守山门、护她平安。核心恐惧：自己动了情，会连累她堕入劫数。致命缺陷：不会表达。行事逻辑：做了不说，说了就一定做到。反差点：对外是不沾尘的仙尊，独处时会偷偷看她写给自己的信。 |
| 三层结构 | 表层标签：清冷、高冷、不近人情。中层行为：对谁都一样的淡，唯独在她出事时第一个到。底层创伤：灵石化人，从未尝过"被人需要"的滋味。 |
| 冲突清单 | 与世界：天道要她死，他要逆天。与女主：他想护她，又怕自己护的方式伤了她。与自己：他知道自己动了心，却不肯认。 |
| 触发器清单 | 她受伤（眉心朱砂痣都在动）、她要下山（第一次失态）、她跪谢他（侧身避开，不受凡人跪）、她哭（垂眼，把情绪收进阴影里）。 |
| 名场面计划 | 初见：云台上她磕破额头，他第一次皱眉。救场：她被诬陷，他一剑震退行刑人。失控：她发烧瞒他三天，他第一次发火。告白：山门口"你是第一个"。诀别：自散神格，换她一世平安。 |

### 10.1.4 样例卡三：钓系影帝（陆时衍）

| 字段组 | 填写内容 |
|---|---|
| 基础信息 | 陆时衍，29 岁，三金影帝，娱乐圈文。一句话定位：镜头前他是全少女的梦，镜头后他把所有的偏爱，都藏在那个小助理看不见的地方。 |
| 外貌锚点 | 眼尾天生带笑、抬眼时睫毛半垂、笑起来右脸一个梨涡、常年剪裁合体的西装、身上有淡淡的雪松与烟草味、无名指上一枚从不摘的素圈。 |
| 性格底色 | 对外标签：风流倜傥、八面玲珑、谁都能聊。对内真实：极长情、极克制、把真心藏在玩笑里。行事逻辑：一定会先逗她、看她脸红、再在她看不见处兜底；绝不会把话说死、绝不会当众卑微。 |
| 过往经历 | 十八线跑了五年，被经纪人骗光积蓄，最穷时一天只吃一顿饭。是她在他最落魄时递过一碗热面，他记了八年。 |
| 致命缺陷 | 不敢认真。他玩世不恭是壳，壳下面是怕一旦认真就会被再次抛弃。他用玩笑试探了她八年，直到她要被别人娶走。 |
| 台词习惯 | 口头禅：是吗、逗你的、想我了、你猜、慢慢来。禁忌用语：我是真心的、我从没这么认真过、逼对方表态。说话节奏：短、上扬、带笑。 |
| 关系网 | 对女主：嘴上逗她，桌角永远备着她爱喝的牛奶。男二（资本方新贵）：面上客气，暗地里推掉了他给她安排的所有资源。对手（对家流量）：镜头前客气，镜头后绝不手软。粉丝：周全得体，唯独她的私信他每条都回。 |
| 五要素 | 核心欲望：和她光明正大地在一起，不用再藏。核心恐惧：配不上她、被她看穿自己其实没那么洒脱。致命缺陷：不敢认真。行事逻辑：先逗后收，把真心藏在玩笑里。反差点：对外是八面玲珑的影帝，私下里会把她随口说的一句话记在备忘录里。 |
| 三层结构 | 表层标签：风流、油、雅痞。中层行为：逢场作戏滴水不漏，唯独在她的事上慌。底层创伤：穷到吃不起饭那年，被全世界看轻。 |
| 冲突清单 | 与世界：他是顶流，公开恋情等于自毁前程。与女主：他逗了她八年，她以为他不爱。与自己：他怕认真了就输了。 |
| 触发器清单 | 她被人围堵（当场下车护她）、她提到那个资本男二（笑容收半秒）、她哭着说"我以为你只是玩玩"（第一次不笑）、她要辞职（第一次失态挽留）。 |
| 名场面计划 | 初见：片场她递水，他故意让指尖擦过她掌心。救场：地下车库私生饭堵她，他停车报警。失控：她发烧瞒他，他第一次摔了杯。告白：推掉三亿代言，只为回来陪她吃一碗面。诀别：公开演唱会，他当着千万人，单膝走向镜头外的她。 |

### 10.1.5 双卡对照：男主要和女主放在一起看

单填男主卡，容易写成"自嗨型男主"，他很厉害、很苏、很有深度，但和女主没有化学反应。正确做法是：填完男主卡，再用同一张模板给女主填一张卡，把两张卡并排放在一起，做三件事。

「第一看伤口」：他的伤口，她能不能懂？她的伤口，他能不能接？两个伤口对不上，就是各写各的。疯批权臣的伤口是"被信任的人背叛"，女主的伤口就得是"被至亲抛弃"，两个被抛弃过的人，才懂得彼此的怕。

「第二看互补」：他缺的，她有没有？他不会表达，她就得是那个主动把话挑明的人；他太狠，她就得是那个让他收手的人。互补不是"性格相反"，是"他缺的那一块，正好长在她身上"。

「第三看拉扯」：他们之间，有没有一个"谁都不肯先低头"的死结？没有死结的两个人，谈恋爱像喝白开水，没有拉扯。死结越解不开，读者越上头。死结的设计详见第五部分。
