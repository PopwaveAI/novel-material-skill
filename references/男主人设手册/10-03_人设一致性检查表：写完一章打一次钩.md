# 10.3 人设一致性检查表：写完一章打一次钩

> 素材来源：novel-material-skill ·《男主人设手册》10.3 人设一致性检查表：写完一章打一次钩

人设崩坏，九成不是大错，是小漂移，第三章他说"随你"，第二十章他开始长篇大论解释。这张表给二十条，每写完一章对照一次，哪条不过，当场改。完整的全书级自检见第十二部分。

| 检查项 | 判定方法 | 不通过怎么办 |
|---|---|---|
| 1. 他的口头禅出现了吗 | 本章他说的话里，有没有至少一句他的口头禅 | 没有就把一句普通台词换成他的口头禅 |
| 2. 他有没有说禁忌用语 | 扫一遍本章他的台词，有没有碰他绝不会说的话 | 删掉，换成他会说的那句 |
| 3. 他对外和对她是不是两张脸 | 本章他对下属/外人 vs 对她，态度有没有差 | 没差就加一场差别待遇的戏 |
| 4. 他的行事逻辑有没有破 | 本章他做的决定，是不是"他一定会做/绝不会做" | 破了就改动作，别让他OOC |
| 5. 他的外貌锚点有没有复发 | 本章有没有提到他的眉/眼/疤/手/气味/单品一个 | 完全没提就加一个小动作带出来 |
| 6. 他的缺陷有没有让他吃亏 | 本章他的缺陷有没有给他惹麻烦 | 没惹麻烦就设计一个小代价 |
| 7. 他的核心恐惧有没有被碰 | 本章有没有触到他怕的那件事 | 连续三章没碰，就安排一个触发点 |
| 8. 他的核心欲望有没有推进 | 本章他离自己想要的东西近了还是远了 | 原地踏步就加一场推进戏 |
| 9. 他对女主的偏爱有没有递进 | 本章他对她，和上一章比，有没有多破例一点 | 没递进就加一个专属特权 |
| 10. 他的反差点有没有曝光 | 三到五章内，有没有给读者看一次他的内里 | 太久没曝光，安排一次反差 |
| 11. 他独处时和人前是不是不一样 | 本章他有没有一个人时的镜头 | 没有就加一段独处，暴露真实情绪 |
| 12. 他的台词是不是太长 | 本章他有没有说超过三行的话 | 长台词砍短，拆成动作+短句 |
| 13. 他有没有对女主过度卑微 | 本章他是不是把姿态放得太低 | 男主不能卑微，卑微是男二的活 |
| 14. 他的情绪有没有外溢 | 本章他是不是情绪写在脸上 | 该收的收住，用动作和细节带情绪 |
| 15. 他有没有解释太多 | 本章他是不是一直在跟女主解释 | 解释是崩人设，换成沉默或行动 |
| 16. 他的名字遮住后还认得出吗 | 把他名字遮了，这场戏能安到别的男主身上吗 | 能就重写，让这场戏只有他能演 |
| 17. 他和男二的区分度够吗 | 本章男二和他，说话方式、动作有没有混 | 混了就把男二的台词按他的类型调 |
| 18. 他的成长有没有刻度 | 本章和开局比，他有没有变一点点 | 没变就加一个小转变的信号 |
| 19. 他有没有一个"固定动作" | 本章他思考时/紧张时，有没有那个招牌动作 | 没有就设计一个，全书复用 |
| 20. 他让读者心疼了吗 | 读完本章，有没有一个瞬间让读者想摸他头 | 没有就加一处他"没人看见的苦" |
| 21. 他让读者心动了吗 | 本章有没有一个瞬间让读者想尖叫 | 没有就加一处克制的失控 |
| 22. 他的身体有没有随剧情变化 | 他受过的伤、熬过的夜，有没有留在身上 | 没留痕就加一个身体记忆点 |

这张表用的时候别贪多。每写完一章，挑三五条最相关的过一遍就行，比如这章是对手戏，就重点过第 1、2、3、6、13 条；这章是独处，就重点过第 11、14、20 条。全表二十二条每次都过一遍，半小时就过去了，不现实。真正的用法是：把这张表打印出来贴在桌边，写到哪条想起哪条。

检查表还有个隐藏用法：它是"改稿顺序"。当你回头改一本写了二十万字的稿子，不要从头到尾改，按这张表的顺序查：先查他的口头禅和禁忌用语（改起来最快），再查他的外貌锚点（几处替换），再查他的行事逻辑（局部重写），最后才动他的核心欲望和创伤（那是地基，动了全书重排）。从易到难，从轻到重。
