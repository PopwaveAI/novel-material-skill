# 6.3 副线不抢戏的五条边界

> 素材来源：novel-material-skill ·《CP设定手册》6.3 副线不抢戏的五条边界

副线抢戏不是因为它写得好，是因为它越过了边界。五条边界守住，副线再动人也不会伤主线。

边界一，不给副线独立悬念：副线可以有未解的事，但不能有需要读者追更才知道答案的悬念。悬念是主线的特权。

边界二，不让副线解决主线的问题：副线可以帮忙，但不能替主角完成关键一步。关键一步必须主角自己走。

边界三，副线的高潮不能高于主线：副线的情绪峰值要低于主线同阶段的峰值。副线哭得比主角惨，读者的注意力就跑了。

边界四，副线不占用主角的成长节点：主角的每一次转变，必须由主线事件触发，不能由副线的某句话点醒。

边界五，副线的结局要比主线早收：副线先落地，主线再收，读者才有“看完一个世界”的完整感。副线拖到最后，会显得主线没收干净。

| 越界症状 | 读者反应 | 修正办法 |
|---|---|---|
| 副线比主线好看 | 评论区只讨论配角 | 削减副线篇幅，把副线的高光挪给主线 |
| 副线悬念未解 | 读者问“那对怎么样了呢” | 在主线收束前给副线一个明确交代 |
| 副线替主角做决定 | 读者觉得主角被动 | 把决定权还给主角，让副线只提供信息 |
| 副线情绪更重 | 读者跳读主线找副线 | 把副线最重的一场戏改成轻处理 |
| 副线拖到最后 | 结局显得散 | 副线提前两章收，留出主线收束空间 |
