# 11.3 一张填好的设定卡

> 素材来源：novel-material-skill ·《CP设定手册》11.3 一张填好的设定卡

下面是一张完整的示例，题材是民国，型号是破镜重圆。填的时候不必照抄内容，照抄的是“具体”这个标准。

| 字段 | 填写内容 |
|---|---|
| 关系一句话 | 他是她十年前的未婚夫，也是把她父亲送进牢里的人 |
| 关系起点 | 她带着一封旧信来找他，求他翻案；他知道那封信是他当年写的 |
| 关系的名字 | 外人眼里是旧情复燃，实际是债主与债户 |
| 关系的期限 | 案子下个月开庭，翻不了案她就得走 |
| 公开度 | 不能公开，他的位置不允许他与旧人有牵扯 |
| 关系的代价 | 他失去位置，她失去刚站稳的生活 |
| 他要什么 | 要她把当年那封信烧了，永远别提 |
| 她要什么 | 要他出庭作证，承认当年的证词是假的 |
| 交叉点 | 同一桩旧案，一个要掩，一个要翻 |
| 冲突点 | 翻案会毁掉他现在的一切，掩案会毁掉她父亲的名声 |
| 底线 | 他不做伪证，她不拿父亲的名声换钱 |
| 欲望变化 | 他从“掩”变成“认”，她从“翻案”变成“要一个道歉” |
| 主墙 | 十年前那桩案子的真相，以及他当年为什么作伪证 |
| 主墙类型 | 内部加外部：他的愧疚与他的位置 |
| 拆墙条件 | 必须有新的证据，且他愿意自毁 |
| 拆墙代价 | 他失去位置与名声，她失去刚建立的信任 |
| 副墙 | 她现在的未婚夫、他上面的那位 |
| 墙的变化 | 前段硬，中段裂缝，后段他主动把墙推倒 |
| 他的缺口 | 他怕被当成叛徒，所以每一步都在证明自己忠于某种东西 |
| 她的缺口 | 她怕自己记错，所以她一直在找证据证明自己没有疯 |
| 缺口来处 | 十年前她一个人在法庭上，没有人信她 |
| 认知错位 | 他以为她恨他，她以为他早就忘了 |
| 错位证据 | 一封没寄出的信、一张旁听席的旧照片 |
| 错位解除 | 她在旧档案里看见他的亲笔供词，解除在他出庭那天 |
| 互动模式 | 互相审问：每句话都在试探对方知道多少 |
| 模式升级 | 从审问到共谋，触发是两人一起被人盯上 |
| 他的语言 | 句子短，不用疑问句，紧张时开始说方言 |
| 她的语言 | 句子长，爱用反问，说谎时会重复对方的话 |
| 身体距离 | 一开始隔一张桌，中段同乘一车，结局并肩站 |
| 亲密禁区 | 他不让人碰他的右手，那只手当年按过假证词 |
| 关系中点 | 两人承认当年都怕，但谁都不肯先说对不起 |
| 最大危机 | 她发现他保留了那份能救她父亲也能毁掉他的证据 |
| 危机代价 | 她不再信他，他被上面的人停职 |
| 回头方式 | 他带着原始卷宗出庭，当众承认伪证 |
| 最终选择 | 她选择不作报复性报道，他选择放弃位置 |
| 落定动作 | 庭后两个人坐在台阶上，他把那只右手伸出来，她握了 |

这张卡填完，全书的结构基本就出来了。真正写作时会有变化，但变化应该是“在这一格上加细节”，而不是“把这一格推翻”。推翻超过三格，说明设定卡填得太早，回去重填。
