# 5.5 反差配：强与弱、善与恶、秩序与混乱

> 素材来源：novel-material-skill ·《CP设定手册》5.5 反差配：强与弱、善与恶、秩序与混乱

反差配是最好用的配法，因为反差天然产生戏剧。但反差必须建立在“反差之下有共通”，否则就是猎奇。

结构：两个人在地表上完全相反：一个守序，一个破坏；一个干净，一个脏；一个信人，一个不信。地表反差越大，底层的共通就越要写得扎实。

化学反应：反差的爽来自“他居然会为她例外”。守序的人为她破一次规矩，脏的人为她洗一次手，这种例外是全书的糖。

操作要点：第一，反差要落到具体行为，不是标签；第二，例外要有次数限制，破例三次以上就不叫例外；第三，底层共通要早埋，比如两个人都怕黑。

雷点：反差变成猎奇：一个完美，一个有病。修正办法：让完美的人有一处脏，让有病的人有一处清醒。

【反差样本】他是那种连发票都要按日期排好的人，她是那种冰箱里能长出东西的人。他第一次去她家，站了半分钟，然后去厨房把碗洗了。她说“你别动我东西”，他说“我没动，我只是洗了”。

反差的甜不在“他包容她”，在“他用自己的方式介入她的生活”，并且被允许。
