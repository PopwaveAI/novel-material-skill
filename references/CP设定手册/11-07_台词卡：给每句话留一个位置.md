# 11.7 台词卡：给每句话留一个位置

> 素材来源：novel-material-skill ·《CP设定手册》11.7 台词卡：给每句话留一个位置

台词卡不是台词本，它记录的是“哪句话该在哪一章说”。写作时经常出现“这句好台词不知道放哪儿”，原因是没提前安排位置。

| 台词 | 归属 | 放置章位 | 功能 |
|---|---|---|---|
| “这张票，明天别拿来。” | 男主 | 第 2 章 | 初遇留钩 |
| “你父亲的名字，别写在票上。” | 男主 | 第 2 章 | 暴露他知道底细 |
| “你对谁都这样吗？” | 女主 | 第 22 章 | 第一次试探 |
| “姑母方才那句话，是在说我母亲吗。” | 男主 | 第 43 章 | 公开护短 |
| “你别去了。” | 男主 | 第 71 章 | 确认 |
| “是我对不起她。” | 男主 | 第 110 章 | 当众认错 |
| “我原谅你，但我们回不去了。” | 女主 | 第 118 章 | 拒绝复合 |
| “我知道晚了。” | 男主 | 第 120 章 | 承认迟到 |
| “牛奶快没了。” | 女主（便利贴） | 第 80 章 | 日常亲密 |
| “你终于明白了。” | 女主 | 第 126 章 | 收束火葬场 |

填台词卡有两个纪律。第一，一句台词只写一次，不要重复使用；第二，台词必须挂在具体的场景上，不能单独存在。脱离了场景的金句，放进正文会像贴上去的。
