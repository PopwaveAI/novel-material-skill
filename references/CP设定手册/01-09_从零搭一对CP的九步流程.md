# 1.9 从零搭一对 CP 的九步流程

> 素材来源：novel-material-skill ·《CP设定手册》1.9 从零搭一对 CP 的九步流程

这一节把前面的框架收成一个可执行流程。九步走完，你手里会有一份能直接开写的CP设定，而不是一堆形容词。

| 步骤 | 要产出的东西 | 判断通过的标准 |
|---|---|---|
| 第一步 | 一句话故事：他们各自要什么，什么挡在中间 | 陌生人听完想知道后续 |
| 第二步 | 两个欲望的交叉点 | 两个欲望指向同一件事 |
| 第三步 | 墙的类型与代价 | 拆墙必须流血，不能靠沟通解决 |
| 第四步 | 各自的缺口 | 缺口能被对方的行为证明，而不是填补 |
| 第五步 | 认知错位 | 错位有明确解除时点，解除时付代价 |
| 第六步 | 共同秘密 | 排他、有倒计时 |
| 第七步 | 互动模式与升级路径 | 三次升级各有触发事件 |
| 第八步 | 四变量配比 | 选两个变量，写出三种场景样本 |
| 第九步 | 名场面清单 | 至少十二个，分布在全书四个阶段 |

九步里最容易被跳过的是第六步。共同秘密看起来是可选项，其实它决定了读者有没有“偷看”的快感。没有秘密的关系是公开的，公开的关系没有私密感，读者代入不进去。

第九步的名场面清单要现在就列，不要等写到那里再想。清单的作用是给写作设锚：你知道第二十章必须发生“她替他撒谎”，第三十章必须发生“他当着所有人选了她”，写到那里就不会拖。

流程走完，再做一次“反推测试”：从结局往回推，这对人最后为什么会在一起？如果答案是“因为他们相爱”，这个答案不及格。合格的答案是具体的：因为他终于承认自己怕被丢下，因为她终于不再用离开来证明自己被爱。
