# 7.5 护短台词：二十五句

> 素材来源：novel-material-skill ·《CP设定手册》7.5 护短台词：二十五句

“姑母方才那句话，是在说我母亲吗。”：把火引到自己身上，比直接骂人高级。

“她的合同还有两年，违约金我付。”：用钱解决，但解决得漂亮。

“她说的没错。”：六个字，公开站队。

“要问就问，别围着。”：把人群挡开。

“她酒精过敏，你们不知道。”：替她撒谎，她没法拆穿。

“这话我只说一次。”：警告，不解释。

“他是我的人。”：古言式的宣示，最有分量。

“再动她一下试试。”：短句，威胁到位。

“她的事，我来谈。”：把谈判权接过来。

“你们继续，我听着。”：不吵不闹，坐着施压。

“这个规矩今天改了。”：改制度，比骂人狠。

“她的位置，谁也别想动。”：职场式护短。

“有事冲我来。”：老套，但永远有效。

“她不懂事，我懂。”：替她认错，把责任揽过来。

“她要是少一根头发，我拆了这儿。”：狠话要有具体的对象。

“别叫她名字。”：连称呼都要管，是最细的护。

“她哭过，你们谁看见了。”：追责式护短。

“钱我出，人我带走。”：交易式解决，干脆。

“她不是你们想的那种人。”：一句话定调。

“我担保。”：三个字，押上自己。

“谁敢传，就试试。”：封口式护短。

“她要是倒了，这桌人就都别坐了。”：掀桌式，适合古言。

“她的东西，放回去。”：从细节上维护。

“我送你回去。”：当众带走，是最明确的立场。

“以后她来，不用通报。”：给一个特权，等于给一个身份。
