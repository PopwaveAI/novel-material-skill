# 9.7 三张自查表

> 素材来源：novel-material-skill ·《CP设定手册》9.7 三张自查表

定稿前把三张表过一遍。每张表里有一项打勾不过，就回到对应章节改。

| 人物自查 | 通过标准 | 不过怎么办 |
|---|---|---|
| 主角有缺点吗 | 至少一个会让他付出代价的缺点 | 回到人物小传补缺点，并在正文里让它发作一次 |
| 配角有独立欲望吗 | 每个有名字的配角都有一件与主角无关的事 | 给配角加一场自己的戏 |
| 标签有行为证据吗 | 每个标签三个证据，分布在不同场景 | 补行为，删标签 |
| 女主有独立线吗 | 一条不依赖男主的成长或事业线 | 加线，或把现有线写实 |
| 反派有逻辑吗 | 他的选择能被理解，哪怕不被认同 | 补动机，不要补悲惨童年 |

| 关系自查 | 通过标准 | 不过怎么办 |
|---|---|---|
| 有边界吗 | 双方都说过“不”，且被尊重 | 加一场边界对话 |
| 控制被批判了吗 | 第三方指出，或她明确反抗 | 补一场反抗戏 |
| 付出有回应吗 | 至少三次双向付出 | 把单向付出改成双向 |
| 三角恋体面吗 | 第三个人有尊严地退出或有自己的选择 | 删掉污名化描写 |
| 替身有主体性吗 | 她有自己的目的和离开 | 补她的线，补正名 |

| 结构自查 | 通过标准 | 不过怎么办 |
|---|---|---|
| 每章有关系变化吗 | 至少一个可指认的变化 | 删章或并章 |
| 三级虐点数量 | 不超过三个 | 降级或合并 |
| 缓冲够吗 | 两个三级虐点之间至少三章 | 插入日常章 |
| 线索都回收了吗 | 每条线有明确回收章 | 补收或删线 |
| 结局配得上虐点吗 | 符合 8.6 的匹配表 | 改结局或改虐点 |
