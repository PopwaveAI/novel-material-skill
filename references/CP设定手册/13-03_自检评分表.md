# 13.3 自检评分表

> 素材来源：novel-material-skill ·《CP设定手册》13.3 自检评分表

六十问太细，日常用一张十分制的粗表就够。每一项一到十分，总分低于六十，就别急着发。

| 维度 | 评分要点 | 满分标准 |
|---|---|---|
| 关系地基 | 一句话、欲望交叉、墙、代价 | 四项都能说清，且互相咬合 |
| 人物可信 | 行为有来处、女主有主体性 | 每个主要人物都能被三件事解释 |
| 结构节奏 | 节点齐全、曲线有起伏 | 没有超过八章的平段 |
| 场面记忆 | 道具、反转、余味 | 至少五个场面能被复述 |
| 语言质感 | 少形容词、多动作、有潜台词 | 随便抽一章，没有解释型台词 |
| 风险控制 | 五条红线全过 | 没有需要修改的敏感内容 |
| 结局匹配 | 虐点与结局对应 | 结局之后读者能说出为什么 |
| 余味 | 最后一段是日常 | 合上书能记住一个动作 |

评分表的作用不是打分，是找短板。八项里最低的那一项，就是你下一本书要重点补的。很多人反复写同一类问题，就是因为从来没做过这种横向比较。
