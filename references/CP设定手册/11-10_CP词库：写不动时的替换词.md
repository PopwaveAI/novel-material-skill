# 11.10 CP 词库：写不动时的替换词

> 素材来源：novel-material-skill ·《CP设定手册》11.10 CP 词库：写不动时的替换词

词库不是为了堆砌，是为了在你写出第五个“他看着她说”的时候，给你别的选择。下面分三组：人物属性、关系动作、情绪状态。用时按需替换，不要整段照搬。

### 11.10.1 人物属性词（四十条）

| 维度 | 可用词 | 对应的行为证据 |
|---|---|---|
| 克制 | 自持、寡言、留白、慢半拍、礼数周全 | 说话前停顿，递东西隔着距离 |
| 锋利 | 直、冷、准、不留余地、刀口向內 | 一句话结束对话，不解释 |
| 散漫 | 松、不经心、敷衍、慢条斯理 | 答应的事总晚一天，但一定做到 |
| 偏执 | 认死理、反复确认、盯住不放 | 同一个问题问三次，答案必须一致 |
| 温和 | 软、缓、好说话、不争 | 先让对方说完，再提自己的 |
| 骄矜 | 抬着、不屑、懒得解释 | 被冒犯时不动怒，只降低对方的存在感 |
| 野 | 不管不顾、横、敢、没规矩 | 在正式场合做不合规矩的事 |
| 疲惫 | 撑、熬、忍着、钝 | 说话变短，反应慢半拍，坐着就睡着 |

属性词要和行为证据一起用。只写“他克制”，读者没感觉；写“他说话前总要停半秒”，读者立刻看见。上面每一条都配了行为方向，填卡时照这个思路补。

### 11.10.2 关系动作词（四十条）

| 动作类别 | 可用词 | 适合的节点 |
|---|---|---|
| 靠近 | 递、扶、挡、让、替、守、等、跟 | 越界、护短、回头 |
| 退开 | 避、收手、转身、落后半步、让开位置 | 危机、分离、试探 |
| 试探 | 问、看、停、绕、提、借、试 | 记住、二见、交底前 |
| 确认 | 叫名字、介绍、牵手、并肩、留灯 | 确认、亲密、选择 |
| 拒绝 | 关门、退票、还钥匙、删号、不接 | 决裂、危机 |
| 照顾 | 留饭、盖衣、买药、修东西、记住忌口 | 示弱、亲密、日常 |
| 交锋 | 抢、驳、压、拆、逼、让一步 | 对抗、宿敌、博弈 |
| 交付 | 给、签、押、托付、交出底牌 | 交底、选择、结局 |

动作词最好成对使用：靠近之后要退开，试探之后要确认，交付之后要拒绝一次。成对的动作才有节奏，单向的动作写多了会腻。

### 11.10.3 情绪状态词（四十条）

| 情绪 | 可用词 | 身体表现 |
|---|---|---|
| 心动 | 发紧、发慌、耳朵热、呼吸乱 | 不敢对视，说话变快或变慢 |
| 委屈 | 堵、酸、咽下去、说不清 | 反复做一件小事，不肯抬头 |
| 愤怒 | 冷、硬、发沉、压着 | 动作变轻，声音变低，句子变短 |
| 恐惧 | 空、凉、僵、失重 | 抓住一个固定的东西，反复确认 |
| 羞耻 | 烧、躲、想消失 | 遮脸、低头、找借口离开 |
| 安心 | 松、暖、落地 | 长出一口气，靠过去，闭眼 |
| 失望 | 塌、白、懒得 | 不再追问，转身做别的事 |
| 决绝 | 清、静、断 | 把东西放下，把话说完整，然后走 |

情绪词不要直接写“她很委屈”，写她“把一张缴费单折了四次”。身体表现是情绪的唯一可信证据，形容词只是作者的转述。
