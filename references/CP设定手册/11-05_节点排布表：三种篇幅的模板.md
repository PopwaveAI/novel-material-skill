# 11.5 节点排布表：三种篇幅的模板

> 素材来源：novel-material-skill ·《CP设定手册》11.5 节点排布表：三种篇幅的模板

不同字数，节点的位置不同。下面给二十万、三十万、五十万三种模板，按章节数排，不按字数排，因为连载作者是按章更新的。

### 11.5.1 二十万字模板（约八十章）

| 节点 | 章位 | 必须发生的事 |
|---|---|---|
| 初遇 | 1–2 | 留下一个未解的问题 |
| 记住 | 3–6 | 一个无用的细节 |
| 二见 | 7–11 | 建立共同场 |
| 并肩 | 12–18 | 一起做成一件小事 |
| 越界 | 19–24 | 一个不该有的靠近 |
| 示弱 | 25–30 | 一次真实的狼狈 |
| 护短 | 31–36 | 公开站队 |
| 对抗 | 37–44 | 一次输掉的仗 |
| 交底 | 45–50 | 一个秘密 |
| 确认 | 51–56 | 关系被命名 |
| 亲密 | 57–62 | 日常的侵入 |
| 危机 | 63–70 | 信任被击穿 |
| 分离 | 71–74 | 短分离 |
| 回头 | 75–77 | 带着答案回来 |
| 选择 | 78–79 | 公开选择 |
| 落定 | 80 | 一个日常动作 |

### 11.5.2 三十万字模板（约一百二十章）

| 节点 | 章位 | 必须发生的事 |
|---|---|---|
| 初遇 | 1–3 | 一个问题 |
| 记住 | 4–8 | 一个细节 |
| 二见 | 9–14 | 一个共同场 |
| 并肩 | 15–22 | 一件小事 |
| 越界 | 23–30 | 一次失控 |
| 示弱 | 31–38 | 一次崩溃 |
| 护短 | 39–46 | 一次站队 |
| 对抗 | 47–56 | 一次失败 |
| 交底 | 57–66 | 一个秘密 |
| 确认 | 67–76 | 一次命名 |
| 亲密 | 77–86 | 一段日子 |
| 危机 | 87–100 | 一次击穿 |
| 分离 | 101–108 | 一段距离 |
| 回头 | 109–114 | 一次跨回 |
| 选择 | 115–118 | 一次公开选择 |
| 落定 | 119–120 | 一个动作 |

### 11.5.3 五十万字模板（约二百章）

| 节点 | 章位 | 必须发生的事 |
|---|---|---|
| 初遇 | 1–5 | 一个问题 |
| 记住 | 6–12 | 一个细节 |
| 二见 | 13–22 | 一个共同场 |
| 并肩 | 23–36 | 一件难事 |
| 越界 | 37–48 | 一次失控 |
| 示弱 | 49–62 | 一次崩溃 |
| 护短 | 63–78 | 一次站队 |
| 对抗 | 79–96 | 一场长仗 |
| 交底 | 97–112 | 一个秘密 |
| 确认 | 113–126 | 一次命名 |
| 亲密 | 127–144 | 一段日子 |
| 危机 | 145–164 | 一次击穿 |
| 分离 | 165–176 | 一段长距离 |
| 回头 | 177–186 | 一次跨回 |
| 选择 | 187–194 | 一次公开选择 |
| 落定 | 195–200 | 一个动作 |

三张表的结构一样，只是密度不同。五十万字的模板里，对抗和危机各占了十六到二十章，因为长篇需要更大的舞台。二十万字的模板里，对抗只有八章，因为读者没有耐心看太长的博弈。
