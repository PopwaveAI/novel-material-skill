# 11.13 一页纸速查表合集

> 素材来源：novel-material-skill ·《CP设定手册》11.13 一页纸速查表合集

这一节把全书最常用的判断压缩成四张表。打印出来贴在桌前，写作时随手一扫，比翻书快。

四张表分别是：开书自检、章节自检、关系温度判断、风险扫描。每张不超过二十行，能在一分钟内看完。

### 11.13.1 开书自检表

| 项目 | 合格标准 | 不合格怎么办 |
|---|---|---|
| 一句话定位 | 能说出类型与关系 | 回第一部分重做框架 |
| 欲望交叉 | 两人要的东西在同一件事上撞车 | 改欲望，不改性格 |
| 主墙 | 只有一堵，且拆解有条件 | 删掉多余的墙 |
| 代价 | 由主角承担，不可逆 | 把代价从配角挪回主角 |
| 女主主体性 | 有一条与男主无关的线 | 补一条，三章即可 |
| 期限 | 有倒计时 | 加一个硬期限 |
| 缺口 | 两人互为镜像 | 重写缺口的来处 |
| 结局形制 | 与虐点匹配 | 对照结局匹配表 |

### 11.13.2 章节自检表

| 问题 | 合格标准 |
|---|---|
| 这一章改变了什么 | 关系状态有变化 |
| 这场戏属于谁 | 删掉他不成立 |
| 墙在哪里 | 本章能指出具体的阻力 |
| 代价是什么 | 有人付了具体的东西 |
| 她做了什么选择 | 至少一次主动决定 |
| 有没有重复 | 冲突性质与前面不同 |
| 章末钩子 | 能说出一个具体疑问 |
| 能否截图 | 每五章至少一次 |

### 11.13.3 温度曲线判断表

| 曲线形状 | 判断 | 动作 |
|---|---|---|
| 连续八章平 | 失速 | 提前一次冲突 |
| 相邻两章差三级 | 陡坡 | 补事件支撑 |
| 两次以上断崖 | 过载 | 删掉一次，改缓冲 |
| 结尾满十 | 无余味 | 降到九，留一格 |
| 全书中段最高 | 结构失衡 | 把峰值后移或前置一次小峰 |

### 11.13.4 风险扫描表

| 扫描对象 | 高危信号 | 动作 |
|---|---|---|
| 未成年角色 | 身体描写、成人关系模拟 | 改为情绪与距离 |
| 自伤情节 | 方法、工具、次数 | 删方法，留前因后果 |
| 控制行为 | 无批判、被写成甜 | 加第三方与代价 |
| 群体表述 | 都、从来、天生 | 改为个体 |
| 真实影射 | 机构名、案件名 | 架空 |
| 入口文案 | 极限词、暗示词 | 换意象 |

### 11.13.5 四张表的使用节奏

开书前用第一张，写每一章用第二张，每二十章用第三张，交稿前用第四张。四张表不需要同时用，同时用会把人压垮。

表格的作用是减少犹豫，不是增加流程。如果一张表让你更慢，就把它简化成三个问题，写在便利贴上。
