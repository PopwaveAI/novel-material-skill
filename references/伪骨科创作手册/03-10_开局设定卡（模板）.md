# 3.10 开局设定卡（模板）

> 素材来源：novel-material-skill ·《伪骨科创作手册》3.10 开局设定卡（模板）

「开局设定卡」把关系起源、空间、称呼、惯性、秘密压进一张表，开书前填完，写到哪一章翻到哪一页。

前面九节讲的所有东西，最后要落到一张纸上。这张纸就是开局设定卡。开书之前把它填完，写到卡壳的时候翻出来看，比你翻灵感笔记管用。下面是模板，十四个字段，填完就等于把开局那层壳搭完了。

| 字段 | 填什么 | 示例（林知夏与沈砚） |
|---|---|---|
| 关系类型 | 重组继兄妹/寄养/托孤/师门/古言养兄妹 | 重组继兄妹，母亲改嫁带女入住 |
| 成立时间 | 两个人住进同一屋檐的具体时间点 | 苏文茵与沈立川领证后一个月，林知夏十七岁生日那天搬进来 |
| 同住时长 | 到故事开始时已经住了多久 | 两年零三个月 |
| 屋内空间 | 谁住哪，房间怎么分，走廊和浴室怎么安排 | 沈砚二楼朝南主卧加书房，林知夏二楼朝北客房，中间走廊共用，浴室两间但早上热水只够一个人 |
| 对外称呼 | 对邻居/同学/亲戚怎么介绍 | 邻居叫“沈家两个孩子”，同学叫“你哥”，亲戚叫“砚礼和知夏” |
| 对内称呼 | 私下怎么叫 | 她叫他“哥”，四种念法轮换；他叫她“知夏”，从不叫“妹妹” |
| 三条惯性 | 吃/作息/物件各一条 | 他替她留汤；她等客厅那盏落地灯；他顺手收她桌上的乱 |

设定卡的前半段是关系与日常，后半段是秘密与节奏。

| 字段 | 填什么 | 示例（林知夏与沈砚） |
|---|---|---|
| 初始秘密 | 两个人共享的不能说的事 | 她知道他书房抽屉里有一张她不知道是什么的纸；他知道她日记本换了锁 |
| 男主初始心态 | 责任/别的心思/警惕 | 表面当责任，实际从她进门第二天就存了别的心思 |
| 女主初始心态 | 认命/警惕/心动 | 清醒识趣，先观察再说话，不敢接 |
| 天然矛盾 | 起源自带的冲突 | 她是外人住进他家，他是原主守着地盘，苏文茵夹在中间 |
| 第三方阻力 | 谁会第一个反对 | 苏文茵最先察觉，沈立川最后知道，二姨是嘴快的那个 |
| 第一次越界计划位置 | 在哪一章、什么场景、谁先越的 | 第十二章，浴室门口，她忘拿毛巾，他敲门递进来，手指碰到 |
| 适合赛道 | 校园/豪门/古言/悬疑 | 现代校园加豪门，主场景在沈家别墅和林知夏的高中 |

这张卡填完之后，再做一件事：把“第一次越界计划位置”那一行单独抄出来，贴在你写稿的电脑边上。从第一章到第十二章，每一章都要往那个位置走一步。前面所有的日常、所有的惯性、所有的称呼念法，都是在给那一次手指碰到做铺垫。铺垫够了，那一下才响；铺垫不够，那一下就是白开水。

最后再强调一次：这张卡是开局用的，不是全书用的。写到八阶段推进的时候，你会发现这张卡上的东西一条条被打破，被打破的时候就是故事走起来的时候。开局卡的使命，是让你开书的时候心里有底，知道这层壳从哪来、有多厚、什么时候该裂第一道缝。

「第一次越界位置」开局卡上最重要的一格。它不是亲密戏，是两个人之间第一次有一个动作超出了“兄妹”的边界。这个位置定在哪一章，前面所有章节都在往那里走。

填完这张卡，再做一件事：把卡上的“初始秘密”那一行拿出来，想想这个秘密是谁先知道的。如果是她先知道，那她开局就是秘密持有者，她的每一个动作都带着“我知道但我不说”的潜台词。如果是他先知道，那他开局就是那个“看她不知道自己被看着”的人。如果两个人都不知道，那这个秘密就是读者知道但角色不知道，读者全程替他们着急。三种写法出来的戏完全不一样，开局的时候就要选好。

还有最后一个提醒：这张卡填完，不要锁起来。写到第五章的时候翻出来看看，哪一格上的东西已经被你写丢了。写着写着把“她日记本换了锁”这个秘密写丢了，后面他站在她门口看见行李箱上锁那一段就没有着落。开局卡不是写完就扔的设定集，是你写到中间的锚，隔三差五拿出来对一遍，才不会跑题。

最后给一个自检问题：把这张卡拿给一个没看过你书的人看，他能不能在三分钟内明白这两个人是谁、为什么住在一起、哪里不对头、读者在等什么。如果他看了还问“那他们到底是什么关系”，说明你的卡填得不够清楚，回去重填。开局卡是给自己用的，但它必须清楚到能给别人讲明白。讲不明白的设定，写出来读者也看不明白。
