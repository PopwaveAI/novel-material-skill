# 3.2 同居共处的空间设计：房子怎么摆，戏就怎么走

> 素材来源：novel-material-skill ·《伪骨科创作手册》3.2 同居共处的空间设计：房子怎么摆，戏就怎么走

「房子地图」把空间摆成戏，哪个角落能发生什么、不能发生什么，先画好再写。空间不是背景板，是第三个人。

房子不是背景板，房子是第三个人。两个人住在同一栋楼里，墙多厚、门有没有锁、浴室什么时候只有热水够一个人用，这些东西决定了他们能在什么时候碰见、碰见了能说什么、说了会不会被别人听见。开书前先把房子画出来，画完再写。

拿沈家那栋三层独栋举例。一楼是公共区，客厅、餐厅、厨房、周姨的小房间，楼梯在客厅侧边，木质，踩上去第三级会响。二楼是居住区，沈砚的主卧和书房在朝南那侧，林知夏的客房在朝北那侧，中间隔着一段走廊和一间共用浴室。三楼是空着的客房和一个朝南的阳台，平时没人上去。厨房是周姨的地盘，但沈砚早上六点半会自己进去煮咖啡，林知夏下晚自习回来十点半会进去热牛奶。浴室两间，一间带浴缸归沈砚用，一间淋浴归林知夏用，但早上七点半只有热水够一个人用，另一个人得等。沈砚的书房门通常不关，但林知夏从不进去。林知夏的房间锁是她自己换的，沈砚没问过。

这栋房子的好处是，它给两个人留了足够多的“半独处”空间：走廊能撞见，厨房能并肩，浴室门口能递毛巾，但每个角落都有第三双眼睛的风险。写戏的时候，先想这个空间里此刻还有谁，再决定这两个人能走到哪一步。

再把沈家的房子往细里描一笔。玄关的鞋柜有三层，最上层是沈立川和苏文茵的鞋，中间是沈砚的，最下层是林知夏的，鞋尖朝外，摆得整整齐齐，是周姨每天早上摆的。林知夏进门换鞋的时候，要弯腰，她的头刚好到沈砚膝盖的位置。有一次她换鞋换得慢，他站在她旁边等，她抬头，他低头，两个人的距离近到她能闻见他衬衫上洗衣液的味道。那是他们搬进来两年，第一次离得这么近。她先站起来，上楼了。他在玄关又站了两秒。

二楼走廊的地毯是灰色的，踩上去没声音。两个人在走廊里走路，全靠听脚步声判断对方在不在。沈砚的脚步重，林知夏的脚步轻。她写作业写累了出来倒水，听见走廊里他的脚步声，会先停一下，等他走过去再开门。他也一样，他路过她房间的时候，如果听见里面有翻书声，脚步会放轻。这些细节不用写很多，一两个就够，够读者知道这两个人在一个屋檐下互相听了两年的脚步声。

| 空间 | 谁在用 | 能发生什么 | 不能发生什么 |
|---|---|---|---|
| 二楼走廊 | 两个人共用 | 深夜偶遇、递东西、一句没头没尾的话、走廊里站着说半句话 | 不能在走廊吵架，墙薄，周姨房间在楼梯口 |
| 厨房 | 周姨白天，沈砚早起，林知夏夜宵 | 留饭、偷煮东西被撞见、并肩站着等水开、他背对着她说话 | 不能在厨房接吻，周姨随时回来 |
| 浴室门口 | 轮流用 | 忘拿毛巾敲门、湿着头发出来撞见、递浴巾时手指碰到 | 不能同时进去，淋浴间的门锁是坏的 |
| 沈砚书房 | 沈砚专用 | 她进去问作业、他叫她进来谈事、她站在门口他没抬头 | 不能在书房翻他抽屉，里面有他不想让她看的 |
| 林知夏房间 | 林知夏专用 | 他敲门送东西、她躲在里面哭、她反锁门假装不在 | 他不能不敲门就进，她不能反锁太久，苏文茵会担心 |
| 一楼客厅 | 全家共用 | 吃饭时的沉默、看电视时的距离、沙发上的并排 | 不能在客厅拉手，周姨和沈立川随时在 |
| 三楼阳台 | 偶尔用 | 深夜一个人发呆、他抽烟她递火、风把两个人的声音吹散 | 不能在阳台说心事，风大会被楼下客厅听见 |

空间设计有一个铁律：两个人能独处的地方，必须同时存在“随时可能被打断”的风险。纯独处的角落不写，写了就不是伪骨科，是普通恋爱。

再补三条空间设计的实操原则。第一条，门要有区别。他的书房门常开，她的房间门常关，这个开合本身就是权力关系。他不锁门是因为他是这个家的男主人，她锁门是因为她是这个家的客人。写到越界的时候，那扇门从“关着”变成“虚掩着”，比写一百句他紧张都管用。第二条，声音要分层。一楼是白天的声音，周姨切菜、沈立川看新闻、苏文茵打电话；二楼是晚上的声音，她翻书、他走动、水管响。两个人在不同楼层的时候，读者能通过声音知道对方在不在。写“她听见楼上椅子响了一声”，比写“她知道他还没睡”高级。第三条，物件要有归属。他的杯子是灰的，她的碗是白的，周姨的围裙是蓝格子的。这些颜色不是装饰，是地盘标识。写到她用错他杯子那一段，读者立刻知道这是越界，不用你解释。

### 3.2.1 房子的三个关键位置

同居的空间不是背景，是剧本。三个位置定下来，戏就自动长出来。

第一个位置，共用的走道。走道是全书最重要的一条线，因为所有的擦身都发生在这里。把它写窄一点，窄到两个人要让半身；写长一点，长到走过去要三秒。三秒里可以发生一次对视，也可以发生一次装作没看见。

第二个位置，各自的房门。门的关与开是全书最省力的情绪刻度。她第一次关门是防备，第二次关门是生气，第三次关门之后又把门留了一条缝，这一条缝比任何告白都贵。

第三个位置，家里的公共桌面。饭桌、茶几、书桌，这三个地方负责摆放证据：一只杯子、一张单子、一盒没吃完的药。所有会被家人看见的东西，都要放在桌面。

三个位置的分配很讲究：走道负责身体，房门负责心理，桌面负责外部风险。写卡住的时候，问自己这三个位置这一章用了哪一个，通常会发现有一个已经十页没用过了。
