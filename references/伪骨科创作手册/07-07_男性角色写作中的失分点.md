# 7.7 男性角色写作中的失分点

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.7 男性角色写作中的失分点

沈砚是长兄型，说话少做事快，习惯用安排代替表达。这个类型最容易写崩的地方不是“太冷”，是“太苏”。作者写到后面忍不住给他加戏，让他说情话、让他吃醋、让他当众宣示主权，写着写着就从长兄型滑向了霸道总裁。下面八条同样给对照句。

| 常见失分 | 写成这样的句子 | 改成这样的句子 |
|---|---|---|
| 他说情话 | 他看着她眼睛说“知夏，我这辈子只对你这样” | 他把牛奶放在她门口，发消息“趁热喝”，不回头 |
| 他当众宣示主权 | 他在同学聚会上把她拉到身边说“这是我妹妹，你们别欺负她” | 他在停车场等她出来，替她拉开车门，一句话没说 |
| 他吃醋写在脸上 | 她跟顾明舟说话，他摔门进房间，冷她三天 | 他从停车场柱子后面看了一眼，转身上车，给她发消息“到家了吗” |
| 他解释太多 | 他跟她解释“那个女同事只是客户，我跟她真的没什么” | 他第二天中午把那个女同事朋友圈截图发到家庭群，配文“王总部门同事”，一个字不多说 |
| 他情绪外放 | 他在雨里把她按在墙上说“我再也忍不住了” | 他在阳台站了很久，把烟摁灭，说“知夏，今晚的事当我没做过” |
| 他替她做所有决定 | 他说“我替你选了学校，你明天去报到” | 他把两份招生简章放在桌上，说“你自己看，想好了告诉我” |
| 他对别人冷对她特殊 | 他对全公司员工板着脸，唯独对她笑 | 他对谁都板着脸，对她也板着脸，只是把她的碗换了新的 |
| 他把脆弱亮出来 | 他坐在她床边说“知夏，我其实很累，只有在你面前我才敢卸下面具” | 他一个人在书房坐到凌晨三点，第二天出门前跟她说“今晚有应酬，别等我” |

沈砚这个角色的魅力全在“不说”两个字。他替她换碗不说，替她挡酒不说，替她调岗不说。他所有的在意都藏在动作和物件里，藏在他安排好但不解释的那些事情里。一旦他开口说“我对你怎么样”，这个角色就塌了一半。长兄型的男主不是没有情绪，是他觉得情绪不该说出来，做了就是做了，说出来就轻了。

「长兄型男主」用安排代替表达的男主。他不说“我在意你”，他把你摔裂的碗换了；他不说“我担心你”，他在玄关留一盏灯；他不说“我想你”，他出差回来顺手给你带了一条围巾。
