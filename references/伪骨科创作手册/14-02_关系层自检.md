# 14.2 关系层自检

> 素材来源：novel-material-skill ·《伪骨科创作手册》14.2 关系层自检

关系层查的是两个人怎么从兄妹走到那一步。亲情惯性有没有重量，第一次心动是不是只有一个触发点，越界之后两个人是更近了还是更远了，这些决定了读者信不信。

「亲情惯性」故事开始前已经运转多年的相处模式。它不是温馨日常，是给后面越界留落差用的。前面惯性写得越稳，后面那一下偏移越疼。

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.2.1 | 亲情惯性是否在正文里有三处以上具体日常？ | 数一下：他替她热牛奶、她帮他叠衬衫、饭桌上固定坐对面。不足三处的，在前十章补。 |
| 14.2.2 | 这些日常是否全是单方面付出？ | 补一场她反过来给他做一件小事，哪怕只是把他的药盒摆好。 |
| 14.2.3 | 第一次异样悸动是否只有一个触发点？ | 如果同时有三个触发点，砍到一个，让那一下来得又准又狠。 |
| 14.2.4 | 那个触发点是动作还是一句话？ | 如果只是一句话，补一个身体反应：她手里的杯子停了半秒。 |
| 14.2.5 | 越界是否是意外而不是预谋？ | 如果越界前他已经计划了三天，改成他本来要躲开、没躲开。 |
| 14.2.6 | 越界之后两人的距离是否反而拉开了？ | 越界后还天天坐一起吃饭的，补三场他刻意避开她的戏。 |
| 14.2.7 | 拉开距离这件事，对方是否察觉了？ | 补一场她发现他把车停到了离门口更远的位置。 |
| 14.2.8 | 秘密是几个人知道？ | 数一下：两人自己、江晚、周姨、顾明舟。超过五个知情者的，砍掉一个。 |
| 14.2.9 | 谁知道得最多？ | 如果江晚全知道，给她一场“知道得太多反而不敢说话”的戏。 |
| 14.2.10 | 谁知道得最晚？ | 那个最晚知道的人，他的反应戏要给足，这是高潮燃料。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.2.11 | 配角是否各有各的目的，不是只为了推两人在一起？ | 江晚的目的是看热闹，周姨的目的是家宅平安，沈立川的目的是面子。各写一场。 |
| 14.2.12 | 家里是否有人真的反对到底？ | 如果所有人都暗中助攻，给沈立川加一场他真摔杯子的戏。 |
| 14.2.13 | 反对者反对的理由是否站得住？ | 他反对的理由是“这个家怎么办”，不是“你不要脸”。写成后者就崩了。 |
| 14.2.14 | 情敌顾明舟是否是个正常人？ | 如果他只会使坏，补一场他真心对她好、她反而不自在的戏。 |
| 14.2.15 | 男主对情敌的反应是否克制而不是咆哮？ | 咆哮的改成：他只是把她的书包接过来拎在自己手上，什么都没说。 |
| 14.2.16 | 两人之间是否有一件只有他们懂的暗号？ | 补一个，比如敲两下门代表“我在”。后面用三次。 |
| 14.2.17 | 这个暗号是否在后期被打破过一次？ | 打破那场就是危机戏，比如他敲了两下，她没应。 |
| 14.2.18 | 女主是否对男主动过一次手？ | 如果全是他在碰她，补一场她急了推他一把的戏。 |
| 14.2.19 | 男主是否对女主说过一次重话？ | 全是温柔的，补一场他说完就后悔、站在走廊抽烟的戏。 |
| 14.2.20 | 两人是否有过一次真正的吵架，不是撒娇？ | 吵完不能当天和好，隔一章，让那点冷意挂着。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.2.21 | 和好是怎么发生的，是谁先递的台阶？ | 如果每次都是他递台阶，改一次她先递，递的方式是把他的碗也盛了饭。 |
| 14.2.22 | 两人共享的那个秘密，是否在第三阶段后才成型？ | 太早共享的，把秘密挪到压抑期之后，秘密拉扯期才有东西可拉。 |
| 14.2.23 | 配角江晚是否真的帮过倒忙？ | 如果她只会说漂亮话，补一场她好心办坏事差点曝光的戏。 |
| 14.2.24 | 母亲苏文茵是否察觉到过什么？ | 如果她全程没感觉，补一场她看着两人背影欲言又止的戏。 |
| 14.2.25 | 这个欲言又止最后有没有落地？ | 如果只是悬着，在抉择期让她说出那句“我其实早看出来了”。 |
