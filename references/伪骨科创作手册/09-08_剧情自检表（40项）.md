# 9.8 剧情自检表（40 项）

> 素材来源：novel-material-skill ·《伪骨科创作手册》9.8 剧情自检表（40 项）

这张表是卡文或写完一段之后用来对的。不是每一项都要满分，但不合格的项必须知道改哪里。40 项分成四层：设定层、关系层、节奏层、桥段与台词层。每层 10 项，逐项打勾。

「剧情自检表」开书前对设定，写中段对节奏，完稿前对全文的 40 项检查清单。不是考试，是体检，哪项红了就查哪项。

设定层 10 项：

| 检查项 | 能不能用一句话回答 | 不合格时改哪 |
|---|---|---|
| 关系起源能不能用一句话说清 | 她怎么进的这个家，谁带谁来的，具体到事件 | 改设定卡的第一行，把模糊的形容词换成具体事件 |
| 两个人的称呼有没有内外区分 | 对外一套，对内一套，饭桌上和私下里不一样 | 改称呼系统，让他在外面叫她名字，在家里叫“知夏” |
| 女主有没有一个具体的习惯性动作 | 不是性格形容词，是能在饭桌上演出来的动作 | 把“她很清醒”改成“她吃饭时先看一圈谁动了筷子” |
| 男主有没有一个具体的习惯性动作 | 不是“他很沉稳”，是他处理事情的固定顺序 | 把“他话少”改成“他家里有事先打电话安排好人手再坐下来” |
| 至少有一个秘密是两个人共享的 | 这件事如果被第三个人知道，家会乱 | 在第 8–15 章之间埋一个，不要放在开局 |
| 反对者的理由听起来有没有道理 | 他反对不是因为坏人，是因为他有他的逻辑 | 给反对者加一句“你走了这个家怎么办”这种有道理的话 |
| 女主的退路是不是具体的 | 不是“回外婆家”，是有学校、有宿舍、有奖学金 | 改退路设定，让她走的时候有地方去 |
| 男主的代价是不是具体的 | 不是“失去亲情”，是两个以上能说清的损失 | 加一个具体代价，比如出国名额作废、父亲信用受损 |
| 开局三千字里有没有亲情感的证据 | 读者能不能在三千字内感觉到“他们已经在一起很久了” | 在开局加一个日常细节，比如他替她留灯、她用他的杯子 |
| 有没有把“名义亲属”这层壳在前三章立住 | 读者知不知道他们不是亲的，但所有人都以为是 | 在开局加一句对外介绍，让读者先知道这层关系的边界 |

关系层 10 项：

| 检查项 | 能不能用一句话回答 | 不合格时改哪 |
|---|---|---|
| 第一次心跳是谁先意识到的 | 只有一个人先意识到，不是两个人同时 | 改成一个人先发现，另一个人后知后觉 |
| 第一次越界是不是意外的 | 不是计划好的，是身体状态或环境造成的 | 改成发烧、醉酒、下雨这种失控条件 |
| 越界之后有没有拉开距离 | 两个人不是越界完就顺理成章，是越完之后更别扭 | 在越界章之后加三到五章的克制期 |
| 有没有至少一次“想靠近又退开”的回合 | 不是一次，是多次，每一次退开的理由不一样 | 在压抑期加两次，一次因为家里有人，一次因为自己心里过意不去 |
| 两个人有没有共享一个不能说的秘密 | 这个秘密把他们绑在一起，也让他们不敢面对彼此 | 在秘密拉扯期让两个人同时知道这件事 |
| 家人有没有从“察觉不对”到“正式反对”的递进 | 不是一上来就摊牌，是先觉得怪，再正式谈 | 把家庭冲突按烈度排成三级，察觉、谈话、摊牌 |
| 配角有没有自己的立场，不是工具人 | 江晚有她的性格，顾明舟有他的判断，不是只为了推主线 | 给每个配角加一个他自己的诉求 |
| 男主有没有“为她做了但不说”的时刻 | 他做的事读者知道，但她不一定知道 | 加一个他替她挡了一次催婚的话，但没告诉她 |
| 女主有没有“为他犹豫了但最后没说”的时刻 | 她想说什么，到了嘴边咽回去了 | 在某个场景里加一句她本来想开口，又放下了 |
| 两个人的关系有没有在某一章出现不可逆的变化 | 过了那个点，就回不到兄妹了 | 在第 30 章左右设一个不可逆节点，比如接吻或共享秘密 |

节奏层 10 项：

| 检查项 | 能不能用一句话回答 | 不合格时改哪 |
|---|---|---|
| 前 5 章的情绪值有没有逐步上升 | 不是第一章就 8，是从 3 慢慢爬到 6 | 把开局的暧昧往后压，前 5 章只写亲情感 |
| 有没有连续三章情绪值都在 5 以下 | 连续平淡读者会跑 | 在平淡章节里加一个越界或秘密暴露的小节点 |
| 有没有连续三章情绪值都在 8 以上 | 连续紧绷读者会麻 | 插一章泄压，让两个人松一口气，但心还悬着 |
| 每 10 章有没有一个大的转折点 | 读者每隔 10 章要觉得“事情变了” | 在第 10、20、30、40、50 章各设一个转折 |
| 章节末尾有没有悬念或落点 | 每章最后一句不是“她睡觉了”，是一个让读者想翻下一章的钩子 | 给每章末尾加一个动作或一句台词，留半句话 |
| 有没有水章（既没推关系也没推冲突） | 删掉这章不影响主线 | 合并水章，把有用的细节挤进别的章 |
| 越界节点有没有按顺序排好 | 不是先接吻再碰手，是从碰手到靠近到接吻逐级升级 | 把越界节点重新排序，从低烈度到高烈度 |
| 秘密暴露的间隔是不是合理 | 不是一次性爆完，是一个一个来 | 把秘密暴露拉开间隔，每 8–10 章爆一个 |
| 家庭对抗的篇幅够不够充分 | 不是吵一架就完了，是有几个回合 | 在家庭对抗阶段加两到三个回合，让冲突持续发酵 |
| 结局前有没有把所有秘密回收 | 读者之前埋的东西，到结局要给交代 | 在最后 5 章里把每个秘密都回收一次 |

桥段与台词层 10 项：

| 检查项 | 能不能用一句话回答 | 不合格时改哪 |
|---|---|---|
| 有没有至少三个“日常越界”的桥段 | 比如递东西碰手、留灯、换碗 | 在开局到压抑期之间埋三个，间隔不要太近 |
| 有没有至少两个“被家人撞破”的桥段 | 不是直接撞破，是差点被看见 | 在危机曝光阶段用两个，一个小一个大 |
| 台词里有没有克制感 | 人物不是把心里话说出来，是说半句留半句 | 把“我喜欢你”改成“你最近是不是没睡好” |
| 有没有用动作代替告白 | 他替她做了一件事，比说“我喜欢你”有力 | 加一个动作细节，比如他把她的碗往她那边推了半寸 |
| 有没有避免“工业糖精”式的虐 | 不是每章都哭，是该哭的时候才哭 | 检查连续两章都有哭戏的地方，删掉一章 |
| 男主的台词是不是够少 | 他说的话比女主少，但每句都有分量 | 把他的台词删掉一半，留下最关键的那几句 |
| 女主的台词是不是有她的性格 | 不是标准言情女主的话，是她这种“先观察再开口”的人会说的 | 把她的台词改成更短、更克制的版本 |
| 有没有环境在帮着施压 | 饭桌上的灯光、走廊的距离、下雨天，环境不是背景板 | 在每个关键场景里加一个环境细节，让环境本身有压力 |
| 有没有把“哥”这个称呼用出层次 | 同一个字，不同场景不同语气 | 在不同章节里让她叫“哥”的语气不一样，有时候是撒娇，有时候是求救，有时候是推开 |
| 结尾的最后一句有没有回收开局 | 第一章里的某个细节，在最后一章重新出现 | 在结局加一个呼应开局的动作，比如他又替她换了一只碗 |

这 40 项不是考完就扔的。开书前对一遍设定层，写到第 15 章对一遍关系层，写到第 35 章对一遍节奏层，完稿前对一遍桥段与台词层。每对一遍，把不合格的项标出来，写下你打算怎么改。不要一口气把 40 项全做完，那样你会累，而且很多项在那个阶段还没发生，对了也白对。

自检表最有价值的用法是：当你卡文的时候，翻到节奏层那 10 项，看看是哪一项不合格。卡文的原因百分之八十是节奏出了问题，要么太平了，要么太满了。不是你不会写了，是你的曲线歪了，把曲线调正，笔自然就顺了。
