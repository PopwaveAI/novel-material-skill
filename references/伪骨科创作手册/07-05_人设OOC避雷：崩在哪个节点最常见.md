# 7.5 人设 OOC 避雷：崩在哪个节点最常见

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.5 人设 OOC 避雷：崩在哪个节点最常见

OOC不是“人物写错了一句话”，是“在那个节点他做出了一个他不会做的选择”。伪骨科的人物有个特点：前面越克制，后面越容易崩，因为读者对他的期待已经被拉得很高。这一节列六个最容易崩的节点，每个节点讲清楚两件事：他为什么会在这里崩，守住人设的一句台词是什么。

「OOC节点」人物在这个位置最容易做出不符合他前史的选择。不是作者写得不好，是这个节点本身压力最大、最容易偷懒。

第一个节点：第一次越界之后。沈砚是长兄型，说话少做事快，他的越界应该是身体先于脑子、事后自己都没预料到。很多作者在这里让他立刻变霸道，把她按在墙上说“我忍很久了”。崩就崩在这，他前面二十章都在克制，越界之后不可能立刻变身。守住人设的台词：他退开半步，说“知夏，刚才那一下，当我没做过”。这句话才是长兄型会说的，他先把责任揽过来，再把距离拉开。

第二个节点：被家长发现之后。沈立川把他叫进书房，问他到底有没有那个心思。这里最容易崩成两种：一种是他立刻全招，把所有责任揽过来，说“爸是我不好”；另一种是他死不承认，说“您想多了”。两种都不对。长兄型的沈砚不会全招也不会死不认，他会半承认：“爸，我没做过任何对不起这个家的事。”这句话既没承认越界，也没否认心思，把父亲噎在那里，这才是他。

第三个节点：情敌出现时。顾明舟约林知夏去书店，被沈砚撞见。这里最容易崩成霸总桥段：他走过去把林知夏拉走，当着顾明舟的面说“我妹跟我回家”。崩就崩在他前面从来没这么宣示过主权。守住人设的写法：他靠在车边等她，她出来之后他替她把围巾绕好，一句话没对顾明舟说，上车之后才冷着脸问“他跟你说了什么”。他的占有欲用在车里，不用在情敌面前。

第四个节点：抉择前。沈立川让他搬出去，或者让他调去外地分公司。这里最容易崩成他义正辞严说“我不搬，我跟她是真心的”。长兄型的沈砚不会这么喊，他会把那份调岗申请放在桌上，说“爸，我去外地，一年回来一次，这事到此为止”。他的抉择不是喊出来的，是用行动替两个人把代价扛了。

第五个节点：结局前。家庭终于松口，两个人可以在一起了。这里最容易崩成两个人抱头痛哭说“我们终于可以在一起了”。伪骨科的结局不能这么甜，因为前面压了八十万字的内疚不可能一顿饭就消。守住人设的台词：他在阳台站了很久，说“知夏，我调岗两年，两年后我们再谈”。他不是不要她，是他还没准备好面对这个家。

第六个节点：番外里。番外最容易写崩，因为作者觉得主书写完了可以放松了。很多人在番外直接写床戏、写婚后日常全是糖。崩就崩在你前面八十万字攒的克制感，番外一场戏就泄光。守住人设的写法：番外只写三年后的一个普通早上，他还是把她的碗换了新的，她在饭桌上替他挡了半杯酒，两个人谁都没提当年那些事。亲密停在物件上，不停在身体上。

「一句台词救场」OOC出现的时候，不要整段重写，先找人物在这个节点最该说的那句话。台词对了，整段戏的人就立住了；台词错了，写再多细节都是白搭。

六个节点看完，教你一个自检办法。每写完一个关键节点，把这一章里人物说的所有台词单独抽出来，贴在一个文档里，从头到尾读一遍。如果你在读某一句的时候觉得“这话不像他说的”，那就是OOC的苗头，当场改。不要等读者帮你找。人物的声音是练出来的，你抽出来读十次，自然就知道哪句不对了。

还有一个常见的崩法要单独说：人物在压力下会做出他平时不会做的事，这本身是对的，但你要给这个转变一个理由。沈砚在被父亲质问的时候半承认，是因为他前四十章攒下来的克制在那一刻被压到了极限。如果你前面没写他克制，到了这一章他突然半承认，读者就会觉得突兀。OOC不是他说错了一句话，是他的转变没有铺垫。

### 7.5.1 人设崩掉的四个节点

人设不是慢慢崩的，是在四个节点上一次崩掉。写的时候盯住这四个地方，比通读十遍有用。

第一个节点，第一次越界之后。很多男主在这一夜之后突然变得游刃有余，前一章还在为一声“哥”失眠，后一章就熟练地堵人。修法是给他一段退行期：越界之后的头三天，他比之前更客气，见面先敲门，说话多用“您”，用这种过度的礼貌掩盖心虚。读者信这个，因为人真是这样。

第二个节点，第一次被家人质问之后。此前的克制是自愿的，此后的克制是被迫的，两者的表现必须不一样。自愿的克制是少说话，被迫的克制是话变多，多到把每件事都解释一遍，越解释越假。写他对着母亲把那天的时间线讲了三次，第三次讲错了顺序，人设就立住了。

第三个节点，第一次为对方牺牲之后。牺牲最容易把人物写成圣人。修法是让牺牲带一点私心：他挡下那件事，一半是为了她，一半是怕她走了之后自己没法活。私心一露，人物就从神位回到人间。

第四个节点，真相揭开之后。秘密持有者在这一刻最容易变成另一个人。她知道了全部，然后呢？如果她立刻原谅，前面的隐忍全废；如果她立刻翻脸，前面的深情全废。写法是让她先做一件极小的日常事，洗碗、叠衣服、给他倒水，然后在做这件事的中途停下，手还湿着，说一句“你早就知道了吧”。

四个节点，四处埋雷。宁可在这四章各多写两千字，也别在别处省。
