# 9.1 伪骨科 CP 设定卡模板（含填写示例）

> 素材来源：novel-material-skill ·《伪骨科创作手册》9.1 伪骨科 CP 设定卡模板（含填写示例）

前面八个部分讲的是判断和手感，这一部分全是能直接填、直接对、直接用的表格和模板。开书前填一遍，卡文时翻一遍，写完再对一遍。

设定卡是开书前必须填完的第一张表。不是给别人看的，是给自己把模糊的直觉钉成能写的东西。一张卡填完，你才知道这两个人在一起的时候，哪一步会先碎。

填写顺序有讲究：先填关系起源和称呼系统，再填双方的初始心态，最后填越界触发点和秘密内容。关系是地基，心态是柱子，越界点是屋顶。地基没打稳就写屋顶，写到中段一定塌。

「CP 设定卡」开书前必须填完的核心档案，把两个人的关系起源、性格底色、初始心态、越界触发点和秘密内容一次性锁死，中途改动必须在卡上留痕。

| 字段名 | 填什么 | 判断标准 | 填错会怎样 |
|---|---|---|---|
| 关系起源 | 两个人怎么进的同一个屋檐下，具体到事件和时间 | 一句话能说清“谁带谁来的” | 写成“他们就住一起”，后面所有戏都没有根 |
| 名义亲属称呼 | 对外怎么介绍，对内怎么叫 | 对外一个叫法，对内一个叫法 | 内外不分，禁忌感直接消失 |
| 女主性格底色 | 她在这个家里最常做的动作是什么 | 写得出一个具体动作，不是形容词 | 写成“清醒独立”，读者看不到人 |
| 男主性格底色 | 他处理家庭事务的习惯是什么 | 写得出一个具体动作，不是形容词 | 写成“沉稳寡言”，和模板没区别 |
| 双方初始心态 | 故事开始时，她对他是什么感觉，他对她是什么感觉 | 各用一句话说清“靠近还是躲开” | 都写“有点在意”，节奏从第一章就垮 |
| 日常惯性三条 | 已经长在身上的三个相处细节 | 每条都能在饭桌上或走廊里发生 | 写得太浪漫，不是惯性是约会 |
| 越界触发点 | 让两个人跨过那条线的具体事件 | 能说清“在什么场景下、因为什么意外” | 写“日久生情”，越界就成了预谋 |
| 秘密内容 | 至少一个只有两个人知道的事 | 这件事如果被家人知道，家会乱 | 秘密太小，拉扯期没有重量 |
| 反对力量 | 谁最不接受这件事，他的理由是什么 | 他的理由听起来有道理 | 反对者写成疯子，家庭对抗就假了 |
| 女主退路 | 如果离开这个家，她能去哪 | 有具体的去处，不是“回外婆家”这种空话 | 退路太虚，抉择时读者不觉得她在赌 |
| 男主代价 | 如果选择她，他失去什么 | 至少两个具体代价，不是“亲情”一个词 | 代价太轻，HE 没有重量 |
| 第一次心跳 | 谁先意识到不对，在什么场景下 | 能写清“谁看见对方哪个动作” | 两个人同时意识到，张力立刻减半 |

下面是一张填好的完整示例，用林知夏和沈砚。照着这个粒度填，不要填得比这个粗。

| 字段 | 填写内容 | 这样填的理由 |
|---|---|---|
| 关系起源 | 林知夏十八岁，母亲苏文茵改嫁沈立川，搬进沈家三个月。沈砚二十四岁，沈立川独子，比她早住这个家六年。 | 把年龄差和入住时长写死，后面所有动作都按这个时间线倒推 |
| 名义亲属称呼 | 对外叫“沈家哥哥”或“沈砚哥”，对内她直接叫“哥”，他叫她“知夏”。全家饭桌上保持这个叫法，从来没换过。 | 称呼是壳，开局定死，后面每一次改口都是戏 |
| 女主性格底色 | 习惯先观察再开口。吃饭时谁夹哪盘菜、谁先放碗，她都记着，但不表现出来。 | 用动作写性格，不用形容词，后面饭桌戏直接套用 |
| 男主性格底色 | 话少，做事快。家里有事他先安排好人手，再坐下来吃饭，不等别人开口。 | 男主越界全靠“做事”落地，性格底色定了动作才不飘 |
| 双方初始心态 | 她：这个哥哥客气但疏远，保持距离就好。他：家里多了个妹妹，照顾是应该的，没想过别的。 | 开局两个人都没动心，后面那一下心动才有重量 |
| 日常惯性三条 | 一、他晚归时玄关留一盏灯，她写作业时客厅电视开小声。二、她摔裂过一只碗，第二天柜里多了一只新的，谁也没提。三、下雨那天他会把车停在学校门口，她上车就系安全带，不问他怎么知道今天下雨。 | 惯性是代入感的地基，三条不够就再加，写到越界的时候这些细节全要回收 |
| 越界触发点 | 她发烧三十九度，他背她去社区医院，路上她脸贴在他颈窝，他第一次觉得这个妹妹的呼吸和别人不一样。不是故意的，是烧出来的。 | 第一次越界必须是意外，写清楚“谁都没打算”，读者才不会骂男主 |
| 秘密内容 | 她偷偷知道他在准备出国读研的材料，他偷偷知道她在申请外地的大学。两个人都没说，都以为对方不知道。 | 双向秘密比单向秘密多一层张力，两个人都在等对方先开口 |
| 反对力量 | 沈立川。他的理由不是骂人，是“你走了这个家怎么办，你妈怎么想，外面的人怎么说”。 | 反对者必须有道理，反对才压得住，不能写成脸谱家长 |
| 女主退路 | 申请到邻省的大学，有宿舍，有奖学金，寒暑假可以不回来。 | 女主有退路，她留下才是选择，不是被困住 |
| 男主代价 | 一、出国名额作废，导师那边没法交代。二、父亲在生意上的信用会受牵连，因为他是沈家长子。 | 男主选她必须付真代价，代价越实，读者越认这个选择 |
| 第一次心跳 | 是他。背她去医院那天，她在他颈边迷迷糊糊说了一句“哥你慢点”，他脚步顿了半秒。他知道不对，但那天没停。 | 心跳落在一个动作上（脚步顿半秒），比写十段心理活动都管用 |

填这张卡的时候，最容易犯的错是把“性格底色”写成形容词。形容词不产生戏。“她习惯先观察再开口”能写出来，“她很清醒”写不出来。每一格都问自己一句：这个东西能不能在饭桌上演出来。演不出来，重填。

设定卡不是填完就锁死的。写到中段如果发现某一格填的东西写不出来，比如“男主的代价”那一栏你现在写的是“出国名额作废”，但写到那里发现这个代价不够疼，那就回来改卡，改完在卡上用铅笔标一个日期。改卡是正常的，不改卡硬写才是硬伤。很多人卡文不是因为不会写，是因为设定卡上的东西和他现在想写的东西对不上了，他还在硬撑旧设定。

用卡的时机也有讲究。开书前填一遍，写到第 10 章翻一遍，写到第 30 章翻一遍，完稿前翻一遍。三次翻卡的重点不一样：第 10 章看关系起源有没有走样，第 30 章看越界触发点是不是按计划发生的，完稿前看秘密内容有没有全部回收。每翻一次卡，你都应该能发现至少一处需要回头改的地方。如果三次翻卡都发现不了问题，说明你写得太顺了，顺到假了，那反而要警惕。
