# 13.2 书名策划：六种命名公式与自测

> 素材来源：novel-material-skill ·《伪骨科创作手册》13.2 书名策划：六种命名公式与自测

书名是这本书最贵的一行字。读者在列表里停在你这本书上的时间，平均不到两秒。两秒里他要判断三件事：这是什么题材，有没有越界的味道，我想不想点进去。书名能不能一次把这三件事说清，决定了漏斗第一层的开口有多大。

下面六种命名公式，是伪骨科这个题材里被反复验证过的六种有效结构。每种给公式、给三个自拟示例、给适合的分支、给容易踩的坑。示例都是为了讲结构现编的，你拿去改字用，不要直接照搬。

「身份反差式命名」用两个本该对立的身份词挤在一个名字里，让读者一眼看出关系的错位感。

### 13.2.1 身份反差式

公式结构：身份 A + 身份 B，中间用“与”“和”“的”连接，两个身份本来不该出现在同一个屋檐下。
- 示例一：《我哥他不是我哥》。适合校园分支，一句话把伪骨科的壳掀了一半。
- 示例二：《养父在上》。适合豪门分支，身份差拉到最大，禁忌感一眼能闻出来。
- 示例三：《师门有个小师妹》。适合古言师门分支，“师门”两个字自带规矩。

适合分支：校园、豪门、师门古言。

容易踩的坑：身份词太常见，读者分不清是哪种伪骨科。“哥哥”两个字一挂上去，平台里挂这个名字的书一抓一把，搜出来你排不进去。要么在前面加一个限定（“我哥”“养父”“师门”），要么在后面加一个反转（“不是我哥”）。

「关系越界式命名」把越界那半步直接写进书名，让读者在列表里就闻到禁忌味。

### 13.2.2 关系越界式

公式结构：一个正常称呼 + 一个不该有的动作或状态。
- 示例一：《叫了十年的哥忽然吻我》。适合校园分支，时间长度加瞬间动作，反差立起来。
- 示例二：《这声哥哥叫到第三年就变了味》。适合豪门分支，用“变了味”这种留白，比直接写动作高级。
- 示例三：《兄长他越界了》。适合古言分支，古言味靠“兄长”两个字撑。

适合分支：全分支通用，校园和豪门尤其好用。

容易踩的坑：暗示过强。“忽然吻我”这种写法在有些平台会被判擦边，过不了审。换成“变了味”“越界了”“不像从前”这种留白式表达，既保留暗示，又不至于触线。

「时间地点式命名」把故事最关键的那一天或那栋房子写进名字，用具体感换记忆点。

### 13.2.3 时间地点式

公式结构：一个具体时间或地点 + 关系后缀。
- 示例一：《搬进沈家的第一个夏天》。适合校园重组家庭分支，时间点很具体。
- 示例二：《西院那个他》。适合古言侯府分支，“西院”两个字自带空间距离。
- 示例三：《十七岁那天他背我去医院》。适合校园分支，一个具体事件就是一个钩子。

适合分支：校园、古言宅斗、重组家庭。

容易踩的坑：太文艺，读者不知道你在写什么。“西院那个他”如果放在校园频道，根本搜不到。这种名字要配在它该在的频道里，别跨区硬套。

「动作悬念式命名」用一个未完成的动作吊住读者，让他想知道后来怎么了。

### 13.2.4 动作悬念式

公式结构：一个戛然而止的动作 + 一个问句或省略号味道的尾。
- 示例一：《他把门反锁了》。适合豪门分支，反锁这个动作自带紧张。
- 示例二：《那年他没送我上车》。适合分离线分支，留白很大。
- 示例三：《我喊了一声哥，他没回头》。适合压抑期分支，一句话把两个人的距离拉开。

适合分支：豪门、悬疑向、远走相守结局。

容易踩的坑：悬念太玄，读者不知道是言情还是悬疑。“他把门反锁了”如果后面接的是普通甜宠，读者会觉得被骗。动作式命名一定要匹配你书里真的有这一下，不能挂羊头卖狗肉。

「称谓双关式命名」用同一个称谓的两种念法做文章，把“哥”这一个字的重量打出来。

### 13.2.5 称谓双关式

公式结构：核心称谓 + 一个词性转换（动词、形容词、时态变化）。
- 示例一：《这声哥我叫不出口了》。适合摊牌前后的转折分支，“叫不出口”是个动作。
- 示例二：《哥他变了》。适合豪门分支，两个字“变了”留白很大。
- 示例三：《叫哥这件事我干了八年》。适合校园重组家庭分支，时间长度换分量。

适合分支：全分支通用，尤其适合压抑期和摊牌期情绪重的书。

容易踩的坑：太像文案，不像书名。“这声哥我叫不出口了”读着像简介，不像名字。要么缩成短的（《哥他变了》），要么在副标题里补一个类型词。

「氛围意象式命名」用一个具体物件或场景做书名，靠氛围换辨识度。

### 13.2.6 氛围意象式

公式结构：一个有情绪重量的物件或场景 + 一个关系暗线。
- 示例一：《柜里那只新碗》。适合校园重组家庭分支，用前面讲过的“碗”这个细节。
- 示例二：《西廊下的灯》。适合古言分支，灯这个意象自带等待。
- 示例三：《他房里那杯凉掉的茶》。适合豪门分支，凉掉的茶是一个情绪刻度。

适合分支：古言、年代、文艺向校园。

容易踩的坑：意象太小众，搜不到。“柜里那只新碗”这种名字，读者没法通过关键词搜到你。必须配副标题或标签把题材补上，名字负责氛围，标签负责被搜到。

### 13.2.7 书名自测表

写完六个候选书名，自己打分。每项一分，五分里过四分才拿出去用。

| 自测项 | 怎么算一分 | 怎么算零分 |
|---|---|---|
| 一眼看懂关系 | 不点开简介，光看名字能知道是“名义亲属”题材 | 名字是个文艺意象，要靠猜 |
| 有越界暗示 | 能闻出一点不对劲，但不至于被判擦边 | 要么太露骨过不了审，要么太干净看不出禁忌 |
| 不低俗 | 读完不会觉得油腻或刻意卖肉 | 靠身体部位、床、锁这种硬钩子撑 |
| 记得住 | 念两遍能复述下来 | 名字长到十个字以上、修辞绕弯 |
| 能搜到 | 里面有读者会真的去搜的词（哥、养、师门、家） | 全是自造词或太偏的意象 |

打分有一个反直觉的判断：五个项都要凑齐，但“能搜到”这一项的权重要比“文艺”高。一本没有人搜到的好书，等于没写。你的书名里至少要留一个读者真的会去搜的词，哪怕这个词很常见。常见词排不上去的问题，靠标签和简介第一句补，不要靠把名字改成生造词去解决。
