# 14.3 节奏层自检

> 素材来源：novel-material-skill ·《伪骨科创作手册》14.3 节奏层自检

节奏层查的是八阶段有没有按顺序走，压抑期是不是拖成了死水，每三章有没有一次泄压。读者弃书多半不是因为写得差，是因为连着五章都在憋着。

「泄压」连续紧绷三章后必须给一次情绪出口。泄压不是发糖，是让读者喘口气，喘完再勒紧。没有泄压的紧绷叫疲劳，不叫张力。

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.3.1 | 前三章是否有一次明确的钩子？ | 如果前三章全是日常，在第三章末尾补一个让她心跳漏一拍的瞬间。 |
| 14.3.2 | 八阶段的顺序有没有错乱？ | 翻大纲：异样悸动必须在边界失守之前，秘密拉扯必须在压抑克制之后。反了就调。 |
| 14.3.3 | 亲情惯性期是否超过了五章还没出异样？ | 超过五章的，把第一次悸动提前到第三章末。 |
| 14.3.4 | 压抑克制期是否短于五章？ | 短于五章的，在里面补两场他想靠近又退开的戏。 |
| 14.3.5 | 压抑克制期是否长于十五章？ | 超过十五章的，砍掉中间重复的克制戏，直接推到秘密拉扯。 |
| 14.3.6 | 危机曝光是否早于全文三分之一？ | 太早曝光的，把曝光挪到中点附近，前面用小撞破代替。 |
| 14.3.7 | 每三章是否有一次泄压？ | 数一下：连续三章都在绷的，在中间插一场轻松的日常拌嘴。 |
| 14.3.8 | 抉择前是否给足了代价？ | 如果抉择像去楼下买瓶水，补一场他放弃了什么（工作、房子、父亲）。 |
| 14.3.9 | 结局前是否回收了主要伏笔？ | 列一张伏笔清单，对着结局一章一章勾，没勾上的回去补一句交代。 |
| 14.3.10 | 家庭对抗期是否写成了单方面吵架？ | 如果全程是父亲在骂，补一场两人统一战线对外的戏。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.3.11 | 每章末尾是否有一个让读者想点下一章的落点？ | 太平的章末，把最后一句改成一个没说完的动作：他站在她房门口，手抬起来又放下。 |
| 14.3.12 | 落点是钩子还是信息？ | 连续三章都在交代信息的，换一章用钩子收尾。 |
| 14.3.13 | 中点是否有一次大转折？ | 中点还在原地踏步的，把危机曝光提前到中点。 |
| 14.3.14 | 两人第一次独处超过半小时是在哪一章？ | 太晚的，把一次独处提前到前五章，让读者先尝到味道。 |
| 14.3.15 | 独处那场戏有没有一个外部打扰打断？ | 没被打断的，加一通电话或周姨敲门，把气氛掐在最痒的地方。 |
| 14.3.16 | 越界那场戏占了几章？ | 占了三章还没写完的，压到一章半，余味放在后面。 |
| 14.3.17 | 曝光那场戏是否给了围观者反应？ | 如果只有两人在场，改成江晚端着水果站在门口。 |
| 14.3.18 | 摊牌是在哪一方先说出口的？ | 如果两人同时说，改成一个人忍到极限开口，另一个人愣了三秒。 |
| 14.3.19 | 摊牌之后是否立刻进入下一场冲突？ | 摊完就甜三章的，接一场家庭对抗，别让张力泄光。 |
| 14.3.20 | 最后五章是否每章都在推进抉择？ | 如果最后五章还在绕，砍掉两章，把抉择提前。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.3.21 | 有没有连续两章都在写同一种情绪？ | 连着两章都在压抑的，中间插一场泄压或外部事件。 |
| 14.3.22 | 泄压那场戏是真的轻松还是假轻松？ | 假轻松超过两场的，换一场真的轻松，比如两人一起去超市。 |
| 14.3.23 | 男主的戏份是否在后半段掉了？ | 后半段全是女主独角戏的，补两场他的视角或他在外奔波的戏。 |
| 14.3.24 | 女主在后半段是否还在主动做决定？ | 如果她后半段全在等他安排，补一场她自己搬出去住的戏。 |
| 14.3.25 | 全文最后一章是否还留了一个小钩子？ | 如果彻底闭合，留一个十年后的瞬间：她叫他哥，他顿了一下。 |
