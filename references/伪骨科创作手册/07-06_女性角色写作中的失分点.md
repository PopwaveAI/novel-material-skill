# 7.6 女性角色写作中的失分点

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.6 女性角色写作中的失分点

林知夏是清醒识趣型，习惯先观察再说话。这个类型最容易写崩的地方不是“太弱”，是“太乖”。乖到她所有反应都是读者预期之内的：脸红、低头、小声说“哥”。读者要看的是一个18岁会自己做判断的人，不是一个等被安排的妹妹。下面八条每条给“写成这样的句子”和“改成这样的句子”，你对着自己的稿子一句句比。

| 常见失分 | 写成这样的句子 | 改成这样的句子 |
|---|---|---|
| 她只会脸红 | 她被他碰了一下手，脸红到耳朵根，低下头不敢看他 | 她把手抽回来，说“哥，你手凉”，转身去拿杯子 |
| 她没有判断 | 沈砚说什么她都“好”“嗯”“知道了”，从不反驳 | 沈砚说周末带她去拔牙，她说“我上周刚拔过，你忘了” |
| 她把心事全写在脸上 | 她看他的眼神充满爱慕，读者隔着屏幕都能闻到 | 她看了他一眼，低头继续吃饭，筷子夹的菜掉在桌上 |
| 她只会哭 | 被母亲质问之后她哭着说“妈我再也不跟他说话了” | 她沉默了很久，说“妈，我搬去住校半年”，第二天自己打包 |
| 她没有自己的生活 | 她所有场景都在家里或在沈砚车上，她不上课不跟同学来往 | 她在学校跟顾明舟讨论考研方向，放学跟江晚去喝奶茶，沈砚只是她生活里的一部分 |
| 她被动接受所有安排 | 沈砚说“我替你安排好了”，她乖乖照做 | 她把他安排好的报名表退回去，说“哥，我想报另一个城市” |
| 她只会问“哥你怎么了” | 他心情不好，她就端水过去问“哥你怎么了，是不是工作不顺” | 她把一杯水放在他桌上，自己坐在沙发上看书，不说话，等他自己开口 |
| 她把顺从当温柔 | 他说“你别管”，她就真的不管了，坐在旁边等他忙完 | 她说“哥，你忙你的，我去厨房把汤热一下”，真的去了 |

这八条的核心就一句话：林知夏不是沈砚的附属品，她是一个有自己判断、自己选择、自己代价的人。她可以克制，可以懂事，但她不能没有自己。一个18岁的女孩在重组家庭里活了两年，她早就学会了怎么看人脸色、怎么替自己打算，这个底子不能丢。

「清醒识趣型女主」表面安静、心里有数的女主。她不抢话不闹事，但她每一次开口都有目的，每一次让步都有底线。写崩的标志是她从“心里有数”变成了“什么都没有”。
