# 7.9 黑名单速查表

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.9 黑名单速查表

这张表把前面八节的内容压成一张能放在电脑旁边的速查表。按章节位置分五段：开篇、前十章、中期、后期、结局。每段给三个东西：这个位置最容易踩的雷是什么，自检问句是什么，立刻能做的修改是什么。写每一章之前扫一眼这张表，比你读十遍大道理管用。

「速查表用法」不是让你照着表写，是让你写完一章之后对着表查。查完发现中了哪条，当场改，不要等写完十章再回头返工。

| 章节位置 | 最容易踩的雷 | 自检问句 | 立刻能做的修改 |
|---|---|---|---|
| 开篇（前3000字） | 开篇即暧昧，第一句就在写他看她 | 前三千字里有没有任何一句心跳、脸红、发呆？ | 有就删掉，把所有暧昧描写推迟到第8章以后 |
| 前十章（3000–30000字） | 亲情惯性没建立就越界，称呼乱掉 | 这十章里有没有一场兄妹日常戏，是“本来就该一起做的事”？ | 没有就加一场：洗碗、接送、换碗、留灯，先把壳搭好 |
| 中期（3万–10万字） | 越界写成预谋，男主全能，女主被动 | 沈砚有没有一场失败戏？林知夏有没有一场主动戏？ | 没有就补：他替她出头搞砸了，她在饭桌上替他挡酒 |
| 中期（3万–10万字） | 误会反复，配角全在助攻，秘密没有代价 | 误会有没有拖过五章？有没有一个配角真心反对？ | 误会拖过五章就戳破，让周姨第五十章开始起疑 |
| 后期（10万–15万字） | 一亲就软，全家降智，摊牌太轻 | 接吻之后两个人是更近了还是更远了？父母有没有真的察觉？ | 亲完必须更冷，让周姨或沈立川先察觉，摊牌拆三场写 |
| 后期（10万–15万字） | 情敌工具化，男主情绪外放，女主只会哭 | 顾明舟有没有他自己的生活？沈砚有没有把情绪藏进动作里？ | 给顾明舟加一场他自己的戏，把沈砚的情话改成动作 |
| 结局（15万字前后） | 和解太易，道德自洽，两个人不愧疚 | 结局前有没有人付出代价：调岗、搬家、冷战？ | 没有就加：沈砚调岗两年、林知夏在外租房一年、苏文茵半年不说话 |
| 结局（15万字前后） | 节奏失衡，三十万字还在暧昧，或三万字就亲完 | 阶段三边界失守在40%前发生了吗？阶段六危机曝光在70%前发生了吗？ | 没发生就提前，已经发生但后面灌水就合并章节 |
| 番外 | 番外肉写，番外全是糖，番外崩人设 | 番外里两个人的亲密停在哪个刻度？ | 停在“他替她把围巾绕好”这个刻度，不写床戏不写婚后甜 |
| 全程随时 | 称呼错位，身体接触升级当剧情，道德不自洽 | 人前她叫他“哥”了吗？接触是靠物件还是靠身体？两个人有没有内疚过？ | 称呼按规则改，把身体接触换成物件，给沈砚加一场独白 |
| 全程随时 | 家长工具人，男主对别人冷对她特殊，配角纸片化 | 沈立川反对的理由是他自己的还是作者塞的？配角有没有自己的生活？ | 让沈立川说出“这个家怎么办”，给江晚加一条考研线 |

这张表不要背。写每一章之前花三十秒扫一眼，问自己这章落在哪个位置、中了哪条雷。中了就当场改，不要攒到后面。改稿最贵的成本不是写字，是你写完十章才发现第一章就要重写。
