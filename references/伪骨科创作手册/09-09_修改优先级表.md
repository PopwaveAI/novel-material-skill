# 9.9 修改优先级表

> 素材来源：novel-material-skill ·《伪骨科创作手册》9.9 修改优先级表

写完之后一定会有问题。但问题分轻重，有的不改读者也能忍，有的不改读者直接弃书。这张表帮你判断先改什么后改什么。原则很简单：前 3 章的问题优先级最高，因为读者还没决定追不追。后面章节的问题可以慢慢改，前 3 章的问题必须立刻改。

「修改优先级」读者感知强度和修改成本的交叉判断。读者一眼能看出来的问题先改，藏在深处的问题后改。

| 问题类型 | 读者感知强度 | 修改成本 | 建议顺序 |
|---|---|---|---|
| 前 3 章没有亲情感的证据 | 极高，读者前三章决定追不追 | 低，加 1–2 个日常细节就行 | 第一个改，动笔前就改好 |
| 越界写成了预谋 | 极高，读者会觉得人物虚伪 | 中，需要重写越界那一段的前因后果 | 第二个改，在写到越界之前先改 |
| 反对者写成了疯子 | 高，读者会觉得冲突很假 | 中，给反对者加两句有道理的话 | 第三个改，在家庭对抗阶段开始前改 |
| 连续三章情绪值都在 5 以下 | 高，读者会觉得水 | 中，需要在平淡章节里加一个小转折 | 第四个改，写完一整段之后回头调 |
| 台词太像独白，人物不会说话 | 中高，读着别扭但不一定弃书 | 高，需要逐句改 | 第五个改，全稿写完之后统一过 |
| 秘密太多，读者记混 | 中，读到后面才发现对不上 | 低，删掉一个秘密或延后暴露 | 第六个改，中期发现中期改 |
| 配角是工具人，没有自己的诉求 | 中，读者不会立刻说，但会觉得假 | 中，给配角加一句他自己的事 | 第七个改，写完主线之后补 |
| 结尾没有回收伏笔 | 低，读者看完才觉得少了点什么 | 低，在最后几章加两句呼应 | 第八个改，定稿前最后一遍过 |

先改什么后改什么，判断标准就一条：这个问题会不会让读者在弃书之前就看到。前 3 章的问题，读者翻开第一页就看到，必须第一个改。越界写成预谋，读者看到那一段就觉得不对，要在写之前就想好怎么改。反对者写成疯子，到家庭对抗阶段读者才发现，所以可以放到那个阶段开始之前再改。台词和配角这种问题，读者要读到后面才慢慢感觉到，可以全稿写完之后统一过一遍。不要边写边改，先写完再改，否则你永远在改前半本，后半本一直写不完。

“先改前 3 章”不是说改文笔，是改结构。前 3 章要检查的不是句子好不好，是三件事：读者知不知道这两个人是什么关系，读者相不相信他们已经在一起生活了很久，读者有没有一点点好奇“这两个人会不会有问题”。这三件事有一件没做到，前 3 章就要重写，不是润色，是重写。很多人前 3 章文笔很好，细节很多，但读者看完不知道这两个人是谁，这就是结构问题，不是文笔问题。

改前 3 章最有效的方法是：把第 1 章的开头三百字拿掉，从第三个场景开始写。很多人开局写了太多背景介绍，读者还没见到人就已经跑了。从一个具体的动作开始，比如她推门进来，他在厨房，锅在响。读者先看见人，再慢慢知道他们是谁。
