# 13.3 标签与关键词：平台内检索的写法

> 素材来源：novel-material-skill ·《伪骨科创作手册》13.3 标签与关键词：平台内检索的写法

标签这件事，很多作者随手填，填完就不管了。标签是平台给你这本书分类的依据，也是读者在搜索框里输入一个词时能不能把你捞出来的关键。你在列表里被刷到的机会有多大，一半靠书名，一半靠标签对不对。

「四层标签组合」把标签分成类型词、关系词、情绪词、人设词四层，每层至少填一个，组合起来才能让对的人搜得到。

四层各管一件事。类型词告诉平台这是个什么题材，关系词告诉读者这是什么样的禁忌，情绪词勾出他想要的那种感觉，人设词让喜欢某一种男主或女主的人一眼锁定你。只填类型词，你会被淹没在几百本同类书里；只填情绪词，平台不知道把你分进哪个栏目。

| 层级 | 作用 | 伪骨科题材下常用词 | 填错会怎样 |
|---|---|---|---|
| 类型词 | 告诉平台这是哪个频道 | 言情、都市言情、古代言情、校园青春、豪门世家 | 不填或填错，平台把你推给不对的人 |
| 关系词 | 告诉读者这是什么名义亲属 | 伪骨科、继兄妹、养兄妹、师门兄妹、重组家庭 | 这一层不填，读者不知道你写的是哪种关系 |
| 情绪词 | 勾出读者想要的感觉 | 禁忌拉扯、克制暗恋、双向奔赴、破镜重圆、久别重逢 | 没有这一层，书名再好也少了情绪钩子 |
| 人设词 | 让偏好某一种人设的人锁定你 | 高冷哥哥、清醒女主、闷骚男主、外冷内热、年上 | 这一层决定了哪一类读者会留下来 |
| 场景词 | 给已经入坑的读者一个具体画面 | 饭桌、玄关、走廊、雨夜、加班、接送 | 这一层不填，读者收藏了也不知道拿什么截图发评论区 |

下面六组可以直接抄结构的组合示例，照着改你的分支词就行。
- 校园重组家庭组：都市言情 + 伪骨科 + 继兄妹 + 克制暗恋 + 高冷哥哥 + 清醒女主。
- 豪门联姻组：豪门世家 + 伪骨科 + 养兄妹 + 双向奔赴 + 闷骚男主 + 外冷内热。
- 古言侯府组：古代言情 + 伪骨科 + 养兄妹 + 破镜重圆 + 年上男主 + 温柔女主。
- 师门传承组：古代言情 + 师徒 / 伪师徒 + 师门兄妹 + 久别重逢 + 高冷师尊 + 钝感徒弟。
- 年代乡土组：年代文 + 重组家庭 + 异姓兄妹 + 慢热拉扯 + 务实男主 + 坚韧女主。
- 悬疑向伪骨科组：悬疑言情 + 名义亲属 + 秘密持有 + 双向救赎 + 黑化男主 + 聪明女主。

「读者搜索词」读者在搜索框里真的会输入的那些词，不是作者自嗨的词。判断方法有三种：看同类书的标签、看评论区高频词、看搜索联想。

再讲怎么把读者会搜的词写进书名副标题和简介第一句。平台内检索的本质是：读者输入什么词，你的书里得有什么词。 不是让你堆砌关键词，是让你在三个位置上自然地把这些词放进去：书名副标题、简介第一句、第一章第一段。

三种判断读者会搜什么词的方法。

第一种，打开同频道里最近三个月热度靠前的十本伪骨科书，把它们书名里、标签里、简介第一句里反复出现的词抄下来。出现三次以上的词，就是读者在用的词。你自己的书名里至少要留一个这样的词。

第二种，翻你自己书的评论区（开书前翻同类书的评论区也行），看读者在短评和章评里最常说哪几个词。“克制”“拉扯”“哥哥”“暧昧”“敢不敢”“心疼”这些就是他们心里的词。把这些词原封不动写进简介第一句，比你写“一段隐忍多年的情感”有效十倍。

第三种，在搜索框里输入“伪骨科”三个字，看平台自动联想出来的下拉词是什么。那些下拉词是平台数据告诉它，读者真的在搜的词。你不需要把所有下拉词都用上，但你书里至少要有其中两个。

举个落地的例子。你写的是豪门养兄妹分支。读者真的会搜的词可能是“豪门”“养兄妹”“伪骨科”“克制”“年上”。你的书名就可以是《养兄在上》（书名里有“养兄”），标签里把“豪门”“伪骨科”“克制”“年上”都填上，简介第一句写“她叫了他五年的哥，他叫了她五年的名字，谁都没敢越那半步”。三个位置都有真词，搜“养兄妹”能搜到你，搜“豪门伪骨科”也能搜到你。

### 13.3.1 标签的三种写法与排序

标签不是堆词，是给检索和推荐各留一条路。三种写法分开放，别混在一行。

「品类词：告诉系统这是什么。」如“伪骨科”“名义亲属”“豪门”“校园”。这一类决定你被放进哪个池子，必须放在最前面，不要用生造词，系统不认识。

「情绪词：告诉读者这是什么感觉。」如“克制”“拉扯”“追妻”“双向暗恋”。这一类决定点开率，放在第二段。

「反差点：告诉读者你和同类不一样。」如“他先动的心”“她早就知道”“全家只有我一个外人”。这一类最多两个，多了就是自夸。

排序有个原则：系统词在前，情绪词在中，反差点在后。反过来写，读者看得懂，推荐系统读不懂，你的书就进不了该进的池子。

还有一条纪律：不要在标签里写你不打算兑现的东西。“追妻火葬场”写了就要真的追，“双向救赎”写了就要真的有救赎。标签是承诺，兑现不了，差评会自己来。
