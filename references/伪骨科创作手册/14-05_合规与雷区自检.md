# 14.5 合规与雷区自检

> 素材来源：novel-material-skill ·《伪骨科创作手册》14.5 合规与雷区自检

这一层不是写给编辑看的，是写给你自己保命的。伪骨科和真血缘骨科之间就一层纸，纸上写着“无血缘”三个字。这一层二十项，每一项都是一次下架风险。

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.5.1 | 女主年龄是否在正文里明确写出过十八岁？ | 如果只有“刚上大学”这种模糊说法，补一句她生日那天许了愿。 |
| 14.5.2 | 所有亲密描写是否都发生在成年之后？ | 翻一遍时间线，把任何可能发生在未成年阶段的暗示删掉或挪后。 |
| 14.5.3 | 正文里是否说清楚了两人无血缘？ | 这一条前面查过，这里再查一次：不能只在设定里写，要在正文里让角色说出来。 |
| 14.5.4 | 是否出现过任何“其实有血缘”的反转可能？ | 有就删掉，这个反转一出现整本书就崩。 |
| 14.5.5 | 亲密描写是否停留在动作与氛围，没有器官级描写？ | 越界那场戏停在一个动作上，停在呼吸上，不要往下写。 |
| 14.5.6 | 是否有把强迫写成情趣的段落？ | 任何“他不让她走”写成暧昧的，改成他站在门口，手放在门把上，最终还是让开了。 |
| 14.5.7 | 是否出现过违法情节被美化？ | 跟踪、偷拍、私闯房间，这些如果写了，后面必须有角色自己意识到这是错的。 |
| 14.5.8 | 男主有没有利用身份压制女主？ | 他用哥哥身份命令她做事的段落，补一场她反抗成功的戏。 |
| 14.5.9 | 两人的关系是否建立在自愿之上？ | 任何一方被道德绑架留下来的，补一场她主动选择回来的戏。 |
| 14.5.10 | 家里反对时，有没有人用经济控制威胁？ | 如果有，让女主有一次自己赚钱独立的场景兜底。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.5.11 | 配角是否有人真的把两人当情侣看，而不是当病人看？ | 补一个江晚的反应，她不是祝福，是先吓了一跳，再慢慢接受。 |
| 14.5.12 | 女主的母亲是否有一次明确表示过不接受？ | 如果母亲全程无所谓，补一场她哭着说“你让我怎么做人”。 |
| 14.5.13 | 父亲反对的理由是否是家庭层面而非个人羞辱？ | 他说“这个家以后怎么抬头”，可以。他说“你真不要脸”，不行。 |
| 14.5.14 | 结局是否给两人留了社会层面的交代？ | 远走还是留下，都要写清楚他们以后怎么生活，不能私奔之后就完了。 |
| 14.5.15 | 是否有未成年读者可能模仿的危险行为描写？ | 比如喝酒开车、自残。这些要么不写，要么写后果。 |
| 14.5.16 | 亲密戏里是否有一方失去意识的场景？ | 酒后、晕倒后发生的一切都要删掉，这是高压线。 |
| 14.5.17 | 年龄差是否超过十岁且一方仍在高中？ | 超过的，把女主时间线往后推到大学。 |
| 14.5.18 | 两人是否在对方明确说“不”之后停手了？ | 补那场戏：她往后退一步，他就真的停了。这一笔值千金。 |
| 14.5.19 | 是否出现过把这段关系包装成“命中注定”的文案腔？ | 删掉所有“这是命”“逃不掉的”这类句子，改成两个普通人的选择。 |
| 14.5.20 | 全文有没有任何一处让读者觉得“这其实是真骨科”的错觉？ | 有，就在最近的章节里补一句非血缘的确认，由一个旁观者嘴里说出来。 |
