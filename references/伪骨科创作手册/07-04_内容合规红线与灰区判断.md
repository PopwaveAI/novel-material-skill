# 7.4 内容合规红线与灰区判断

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.4 内容合规红线与灰区判断

这一节只讲创作自保，不教怎么绕审核。红线是不管你怎么改都不能碰的东西，碰了就是下架风险。灰区是“这样写安全、那样写危险”的对照，笔力收住就没事，收不住就踩线。

「合规红线」不管平台口径怎么调都不能写的内容。踩红线不是数据掉的问题，是整本书被处理的问题。

先列红线。下面这五条，一条都别碰。
- 红线一：任何形式的真血缘骨科。兄妹、姐弟、父女、母子，哪怕旁系三代以内，都不要写。伪骨科的前提是名义亲属无血缘，这个前提一旦破了，题材就不成立。
- 红线二：未成年人之间的亲密描写。女主设定18岁，写到她高中阶段就停在牵手和对视，不要写身体接触升级。
- 红线三：把违法犯罪行为浪漫化。跟踪、偷拍、强行带走、限制人身自由，这些行为在现实里是犯罪，在文里写得再苏也是踩线。
- 红线四：把虐待或家暴写成爱的表达。男主掐女主下巴、把她按在墙上、扇耳光，这些动作不管后面怎么解释都不行。
- 红线五：详细的性描写。床戏、器官、性过程，一个字都不要落。伪骨科的张力全在“不能”，写了就没了。

「灰区」不是不能写，是笔力必须收住的内容。同一句话，换个写法就从灰区跳进红线。

下面是灰区对照表，每条给“这样写安全”和“这样写危险”两句话，你对着自己的稿子比。

| 灰区主题 | 这样写安全 | 这样写危险 |
|---|---|---|
| 名义关系的暧昧称呼 | 人前她叫“哥”，他叫她“知夏”，语气跟普通兄妹一样 | 两人独处她突然改叫“砚”或“阿砚”，当成情趣 |
| 同住一个屋檐下的独处 | 他在客厅改合同她在沙发写作业，中间隔一张茶几 | 他把她叫到自己房间关门谈事，一谈谈三小时 |
| 生病照顾 | 他把药和温水放在她床头，自己退到门外等 | 他坐在她床边把手放在她额头上，一放不放 |
| 接送上下学 | 他把车停在斑马线外，摇下车窗让她上车 | 他下车替她开车门、替她绕围巾，被同学看见 |
| 醉酒照顾 | 她喝醉了他把她扶到客房，给她盖好被子就走 | 他把她抱回自己房间，在她床边坐到天亮 |
| 吵架之后的靠近 | 她哭着跑出门，他跟在后面保持十米距离 | 他在雨里把她按在墙上吻，说“我再也忍不住了” |
| 家族聚餐的座位 | 他坐在她对面，中间隔着沈立川和苏文茵 | 他坐在她旁边，腿贴着腿，桌子底下手碰手 |
| 手机和聊天记录 | 他把女同事消息删了，什么都没说 | 他当着她面翻她手机，把顾明舟的聊天记录截图发给她 |

灰区判断有个笨办法：写完一场戏，把它念给一个不知道你们在写伪骨科的人听。对方说“这俩人有点不对劲”，安全；对方说“这俩人在搞吧”，危险。读者的敏感度比你高，你觉得没什么的地方，人家一眼就看出来了。

还有一个尺度要记住：合规是底线，不是目标。你不能因为“没踩红线”就放心大胆写，红线和读者的接受度是两回事。有些东西平台不管，但读者看了会不舒服，比如在饭桌上写两个人桌子底下碰脚。这种不违规，但读着硌，你也要自己收住。

「念稿测试」写完一段暧昧戏之后，念给一个完全不了解这本书的人听。对方的第一反应就是读者的第一反应。对方觉得正常，你就过了；对方觉得“这俩有事”，你就要收笔。

### 7.4.1 三档灰区判断法

合规这件事，最实用的不是背条款，是随身带一把尺子。落笔前问一句：这一段如果被截图单独发出去，我能不能用一句话解释清楚？能解释的往下写，解释不了的换写法。

「绿档：写关系，不写身体。」所有能公开讲的张力都在这一档：称呼、站位、谁先松手、谁在饭桌上多看了一眼。这一档不是保守，是主战场。读者要的紧绷感，八成来自这里，身体接触只是偶尔兑现。

「黄档：写身体，但停在界线前。」擦到手腕、衣服、头发、体温，写到呼吸变化就收。黄档的关键是不写结果，只写反应：他碰到她的手，写她手指缩了一下，不写他握了多久。反应归人物，时长归作者，时长一写清，味道就变。

「红档：不能写。」任何明确的身体关系、任何把未成年角色放进性语境里的描写、任何用亲属身份做性暗示的台词。红档不是“写得含蓄一点就行”，是整段换掉，换成第二天早上的一件小事，让读者自己明白发生过什么。

三档之间有一条灰色地带，处理原则只有一条：能用后果代替过程，就永远用后果代替过程。写第二天她洗了两遍手，比写前一晚的任何细节都有分量，而且安全。
