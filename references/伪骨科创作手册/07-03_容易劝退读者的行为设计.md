# 7.3 容易劝退读者的行为设计

> 素材来源：novel-material-skill ·《伪骨科创作手册》7.3 容易劝退读者的行为设计

这一节讲的不是“写得不好”，是“写了读者立刻烦”。劝退型行为设计有个特点：作者自己觉得很苏，读者看了很尬。下面十条每条给三个东西：行为是什么，读者为什么烦，替换写法是什么。十条之间要有区分度，不是所有条都在说“男主太霸道”。

| 劝退行为 | 读者为什么会烦 | 替换写法 |
|---|---|---|
| 男主每次出场必换西装，头发一丝不乱 | 男主不像活人像海报，24岁管公司也要吃饭熬夜 | 写他出差回来衬衫皱了、胡茬没刮、在玄关坐了五分钟才上楼 |
| 女主一哭男主就慌，一慌就抱，一抱就软 | 情绪解决全靠肢体，作者懒得写对话 | 让她哭完自己擦干，他递一杯水放在桌上，不抱 |
| 配角说话全是捧哏，“你哥对你真好”“你俩真配” | 江晚和周姨变成作者的嘴，不是活人 | 让江晚说半句留半句：“姐，我那天在楼下看见……算了不说了” |
| 情敌出场必下绊子，必使坏，必被男主打脸 | 顾明舟像个工具反派，读者不信有这种人 | 让顾明舟帮林知夏讲完题，自己走了，什么都没求 |
| 每次暧昧必配夜景配月光配雨声 | 环境描写堆得像MV，读者翻页跳过 | 把夜景删掉，写他在等红灯时手指在方向盘敲了两下 |
| 男主心理活动全是“我不能”“我不该”“我控制不住” | 同一句话说十遍，读者觉得男主精神分裂 | 把心理活动换成动作：他把烟摁灭三次没点，把手机屏幕按亮又按黑 |
| 女主每次被越界都僵住两秒然后脸红 | 她像个反应模板，不像18岁有主见的人 | 让她有一次直接退开半步说“哥，你坐那边去” |
| 家长一出场就是哭和拍桌子 | 沈立川和苏文茵除了反对没有别的情绪 | 写沈立川一个人在书房把那张合照压在笔筒底下，半天没说话 |
| 误会每次都靠第三方传，当事人从不直接问 | 两个人像是没长嘴，读者急 | 让林知夏直接问“哥，那天楼下那个姐姐是谁”，他直接答“客户” |
| 高潮必打雷下雨闪电交加 | 情绪全靠老天爷配合，作者自己没招 | 把雷雨删掉，写两个人在客厅坐了一整夜，谁都没开电视 |

这十条有个共同点：作者在用“模板情绪”代替“具体动作”。读者不是不爱看暧昧，是不爱看你把她已经看过一百遍的东西又抄一遍。改的方向只有一个：把形容词换成动作，把心理活动换成物件，把第三方传话换成当面说话。

最后提醒一句：劝退型行为设计跟“不够甜”是两回事。你把上面十条全改了，读者还是可能嫌不够甜，但不会烦。嫌不够甜可以加戏，烦了就直接弃书。所以这一节的优先级比“怎么写得更苏”高得多，先把劝退的删掉，再考虑加不加分。

「模板情绪」作者从其他言情文里抄来的标准化反应：脸红、心跳、僵住、深呼吸。单个看都对，叠在一起就假，因为活人不会每次都一模一样地反应。

### 7.3.1 劝退行为的三个信号

读者弃书往往不是因为情节不好，是因为某一种行为让他们开始讨厌主角。三个信号一出现，要立刻改。

第一个信号，主角开始骗自己人。她为了见他，对母亲撒谎，而且撒得毫不费力。第一次可以理解，第二次开始掉分，第三次读者就会觉得这人不值得同情。修法是让她每次撒谎都付一点代价：手抖、话说不完整、事后一个人坐在楼梯上。

第二个信号，主角开始占便宜。他借着哥哥的身份，替她做决定、替她推掉别人的追求、替她安排生活。这类行为在书里常被写成深情，读者看到的却是控制。修法是让她的反抗明确出现一次，并且成功一次。

第三个信号，主角开始降智。明显该问的话不问，明显该看出的破绽看不出。降智不是剧情需要，是作者不想让秘密早点破。修法是把“不问”写成主动的选择：她其实看出来了，她选择不问，因为她怕答案。

三个信号里，降智最致命。前两个还能靠后面的补偿救回来，降智一旦发生，人物就再也立不起来。
