# 14.4 桥段与台词层自检

> 素材来源：novel-material-skill ·《伪骨科创作手册》14.4 桥段与台词层自检

桥段库用得多了会有个毛病：同一个动作写三遍，读者就麻了。台词写多了也会有个毛病：每个人都像作者自己在说话。这一层查的是桥段有没有落点、台词有没有人味。

「桥段落点」每个桥段结束后人物关系或信息必须发生一次不可逆变化。没有落点的桥段等于白写，读者看完什么都没记住。

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.4.1 | 同一个桥段是否在全书连用了两次以上？ | 比如“他替她擦头发”用了三次的，第三次换成她替他擦。 |
| 14.4.2 | 每个桥段结束后是否有一个落点？ | 桥段演完就切场的，补一个余味动作：他把她的毛巾叠好放回原处。 |
| 14.4.3 | 落点是关系变了还是信息变了？ | 连续三章落点都是信息的，换一章落点落在两人距离上。 |
| 14.4.4 | 男主的台词是否超过三行？ | 超过三行的砍到两行，把剩下的改成动作，他本来就不是话多的人。 |
| 14.4.5 | 女主的台词是否全是反应句？ | 全在“哦”“嗯”“好的”的，补一场她主动发问、主动顶回去的戏。 |
| 14.4.6 | 是否有一句台词只交代情绪不交代信息？ | 翻一遍全是信息句的，加一句：她看着窗外说“今天风真大”。 |
| 14.4.7 | 是否出现过“我爱你但我不能”这种直白句？ | 出现了就删，改成他把她的手从自己胳膊上拿开，握了一下，才松开。 |
| 14.4.8 | 旁观者是否说过一句关键的话？ | 周姨那句“汤要凉了”是不是真的在最关键的场出现了？不是就挪过去。 |
| 14.4.9 | 旁观者说完关键话之后有没有被接话？ | 如果说完就冷场，让另一个人假装没听见去做别的事。 |
| 14.4.10 | 两人吵架时是否有一句话戳中了对方真正的痛处？ | 没有就补一句，男主被戳中的那句应该和“这个家”有关。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.4.11 | 台词里是否出现过解释性独白？ | 他心里想了三段来解释自己为什么克制的，砍成一段，剩下用动作演。 |
| 14.4.12 | 两个人是否说过同一句口头禅？ | 如果连口头禅都一样，改掉一个，习惯雷同会让两个人像一个人。 |
| 14.4.13 | 男主有没有一句口头禅是只对她用的？ | 补一句，比如他叫她“小孩”，只在两个人私下时用。 |
| 14.4.14 | 女主有没有一句话是只有读者能听懂、男主当时没懂的？ | 补一句双关，后期再翻出来让他愣住。 |
| 14.4.15 | 戏里是否出现过第三次还在用的同一个道具？ | 比如每次暧昧都用倒热水。第三次换成递外套。 |
| 14.4.16 | 道具用完之后有没有被收走或换掉？ | 一直摆在桌上的，在某个节点让它消失：杯子碎了。 |
| 14.4.17 | 动作描写是否有重复句式？ | 翻一下“他抬起眼”“她低下头”出现了几次。超过五次的，换写法。 |
| 14.4.18 | 是否有一场戏两人全程没说一句话？ | 没有就补一场，停电那晚两个人坐在楼梯上，谁都没开口。 |
| 14.4.19 | 那场没说话的戏，读者能不能读懂发生了什么？ | 如果读者会懵，加一个外部细节：她的手碰到了他的手背，两个人都没缩。 |
| 14.4.20 | 配角的台词是否和主角一个腔调？ | 江晚说话应该比沈砚快、比沈砚碎。腔调一样的，给江晚加语气词。 |

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.4.21 | 是否有一句台词被两个人分别在不同章节说过？ | 如果有一次呼应，是好的。如果重复了三次，删掉后两次。 |
| 14.4.22 | 男主是否在女主面前失态过一次？ | 全程稳如泰山的，补一场他听到她要搬走时捏碎了一个杯子。 |
| 14.4.23 | 失态之后他有没有立刻掩饰？ | 失态完不掩饰就不是长兄型了。补一句他转身去厨房洗了手。 |
| 14.4.24 | 女主是否说过一次反话，而男主听懂了？ | 补一场她说“你走吧”，他没走，坐下来给她倒了杯水。 |
| 14.4.25 | 最后一章两人之间有没有一句和开头呼应的台词？ | 开头她叫他“哥，碗换了”，结尾他叫她“知夏，饭好了”。对上就稳。 |
