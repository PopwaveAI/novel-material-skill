# 14.6 读者体验自检

> 素材来源：novel-material-skill ·《伪骨科创作手册》14.6 读者体验自检

这一层站在读者那一头翻稿子。开篇三百字有没有把人按住，每章有没有一句话值得截图，有没有让读者替主角着急的时刻。读者的感受骗不了人，数据会告诉你。

「截图句」每章至少一句可以被读者截下来发评论区的话。它不是金句，是一句具体的、有动作的、有潜台词的台词。

| 编号 | 检查项 | 不合格时改哪 |
|---|---|---|
| 14.6.1 | 开篇三百字是否有具体场景和动作？ | 如果开篇是心理独白，重写第一章开头，从一个动作切进去。 |
| 14.6.2 | 是否有连续两段都在解释设定？ | 连续两段解释的，砍成一段，剩下的拆到后面章节里用对话带出。 |
| 14.6.3 | 每章是否有一句可以截图的话？ | 翻一遍目录，给太平的章节补一句有潜台词的台词。 |
| 14.6.4 | 有没有让读者替主角着急的时刻？ | 补一场她差点叫错称呼、在门口差点被撞见的戏。 |
| 14.6.5 | 配角是否有人被读者记住名字？ | 如果除了主角没人被记住，给周姨或江晚一个标志性动作。 |
| 14.6.6 | 是否有一次意料之外但合理的转折？ | 如果全程在预期内，把一个助攻换成倒忙，读者会愣一下再拍腿。 |
| 14.6.7 | 读者有没有机会比角色先知道一点什么？ | 补一场读者看见男主口袋里的药、女主还不知道的戏。 |
| 14.6.8 | 有没有一个瞬间让读者想冲进屏幕摇醒主角？ | 补一场她在最该跑的时候留下来道歉的戏。 |
| 14.6.9 | 每三章是否有一次情绪高点？ | 连续三章平的，把后面的一个小高潮提前。 |
| 14.6.10 | 读者读完一章之后是满足还是悬着？ | 连续三章都满足的，在其中一章末尾改成悬着。 |

| 14.6.11 | 是否有一段描写让读者也觉得喘不过气？ | 压抑期那段，用短句子写，句子不要超过十个字。 |

### 14.6.1 拿给外人读的三问

自己读十遍，不如给一个没看过的人读一章。只问三句，别问“好不好看”。

第一问，“这两个人是什么关系？”答不出来，说明身份壳没立住，前三章要补。

第二问，“你觉得他们该不该在一起？”答“该”或者“不该”都算成功，答“无所谓”说明张力没建立，感情线要重写。

第三问，“你想不想看下一章？”追问一句“想看什么”，如果对方说的是具体的事，你的钩子成了；如果对方说“想知道他们会不会在一起”，你的钩子还是概念级的，末章要改。

三问的答案要写下来，不要凭印象。三章之后再看一遍，你会发现自己当时以为的问题，和读者真正卡住的地方，往往不是一个。
