# 14.7 定稿自查简报模板

> 素材来源：novel-material-skill ·《悬疑题材创作手册》14.7 定稿自查简报模板

### 14.7.1 简报的六项内容

表 14-9 定稿自查简报模板

| 项目 | 填写内容 | 用途 |
|---|---|---|
| 总字数 | 正文实际字数 | 判断体量与平台匹配 |
| 章节数 | 总章数与卷数 | 判断节奏分布 |
| 案件数 | 单元案与主线案 | 判断结构清晰度 |
| 人物数 | 有名有姓的角色 | 判断群像负担 |
| 伏笔数 | 埋设与回收数量 | 判断逻辑完整性 |
| 未回收项 | 故意不回收的条目 | 判断余味是否成立 |

### 14.7.2 三项红线
- 红线一：跨文档引用。全文不出现任何指向外部资料或其他作者的表述。所有跳转只能在本册内部，写成“详见第几部分第几节”。
- 红线二：标点规范。全文不使用长破折号。需要停顿用逗号，需要解释用冒号，需要转折用句号。数字区间统一用短连接号。
- 红线三：商业化视角。运营部分只写作者给自己作品做热度的动作，不写卖课、卖资料、卖工具、导流他人。

三条红线是全册的出版底线。任何一条不过，都要回头改，不能带着交稿。

### 14.7.3 自查结论的三种
- 通过：五十项里四十五项以上合格，三条红线全过。可以交。
- 有条件通过：四十到四十四项合格，问题集中在语言与场景层。改两周再交。
- 不通过：四十项以下，或者任一条红线不过。回炉。
