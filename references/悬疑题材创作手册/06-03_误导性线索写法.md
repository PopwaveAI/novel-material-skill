# 6.3 误导性线索写法

> 素材来源：novel-material-skill ·《悬疑题材创作手册》6.3 误导性线索写法

### 6.3.1 误导的合法性

误导不是撒谎。合法误导只做两件事：转移注意力和限制视角。非法误导做第三件事：伪造事实。前两者读者复盘时会服气，第三者会骂人。

### 6.3.2 五种合法误导

红鲱鱼：放一个明显可疑的人，让他有动机、有行为、有物证，最后证明他只是“恰好符合”。

时间误导：让读者以为两件事同时发生，其实是先后。用“与此同时”这类连接词制造错觉。

视角误导：只让读者看到主角看到的部分。主角没看见的，读者也看不见。这不叫骗，叫限制。

因果误导：让读者以为 A 导致 B，其实是 C 导致 B。前面给的两个事实都是真的，只是顺序被读者自己排错了。

身份误导：让读者把两个人当成一个人。同样的外套、相似的背影、共同的称呼。

五种误导里，因果误导最高级，因为它不靠隐藏信息，靠读者的思维惯性。读者自己把因果接错了，复盘时会拍大腿。

### 6.3.3 误导的配比

一本三十万字的悬疑，误导性线索不宜超过八条，其中三条要指向同一个无辜者。三条指向同一个人，读者才会真的怀疑他；分散到三个人身上，谁都不够可疑。

被误导的那个人，最后必须有一个“清白但代价惨重”的结局。他可能被拘留、被网暴、被单位开除。读者会为他难受，这份难受会让真相更有重量。

### 6.3.4 误导失败的样子
- 让无辜者做出完全不合逻辑的可疑行为，只为让他可疑。
- 在最后一章才说“其实他一直有不在场证明”。
- 把读者的怀疑归因于“他想多了”。

这三条一旦出现，读者会认定作者在耍手段。悬疑可以骗人，但不能骗得难看。
