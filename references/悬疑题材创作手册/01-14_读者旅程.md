# 1.14 读者旅程

> 素材来源：novel-material-skill ·《悬疑题材创作手册》1.14 读者旅程

读者从看到你的书到追更，要经过六步。每一步都有对应的写作任务。

### 1.14.1 六步

表 1-8 读者旅程六步

| 步骤 | 读者在做什么 | 你要做什么 |
|---|---|---|
| 看见 | 扫过书名与封面 | 三秒内说清类型 |
| 点进 | 读简介 | 四段内建立疑问 |
| 试读 | 读前三章 | 第一段就有异常 |
| 决定 | 决定是否收藏 | 第三章末给出承诺 |
| 追更 | 第二天回来 | 章末钩稳定 |
| 推荐 | 向别人提起 | 给一个可复述的画面 |

### 1.14.2 每一步的失败
- 看见失败：书名看不懂类型。
- 点进失败：简介全是形容词。
- 试读失败：第一段在写景。
- 决定失败：第三章还没有案件。
- 追更失败：章末没有钩。
- 推荐失败：没有一个能被复述的画面。

六个失败里，前三个最致命。前三步流失超过一半，后面写得再好也没人看到。

### 1.14.3 复述画面的重要性

读者推荐一本书时，通常不会讲剧情，只会讲一个画面：“她把饭倒进垃圾桶，饭还是热的。”一个画面，胜过三千字简介。

所以写作时要主动设计“可复述画面”。每卷至少一个，全书三到五个。画面越具体，传播越远。

### 1.14.4 平台差异

表 1-9 平台差异

| 平台类型 | 读者习惯 | 写法建议 |
|---|---|---|
| 长篇连载平台 | 追更、看章末 | 章末钩必须稳 |
| 短内容平台 | 看开头、看截图 | 开头三行定生死 |
| 音频平台 | 听、不能回看 | 少用复杂人名 |
| 出版向平台 | 整本阅读 | 结构与余味优先 |

平台差异决定“钩子放在哪”。连载平台放在章末，短内容平台放在第一行，音频平台放在每一段的开头。
