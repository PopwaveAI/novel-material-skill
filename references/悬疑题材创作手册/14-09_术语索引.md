# 14.10 术语索引

> 素材来源：novel-material-skill ·《悬疑题材创作手册》14.10 术语索引

全册出现的核心概念，按首字归类。写作时遇到“这词在本册里是什么意思”的问题，翻这里最快。

### 14.10.1 B 与 C

本格：以公平解谜为核心的类型。三个硬条件：谜面封闭、信息公平、解答唯一。

变格：以氛围与动机为核心的类型。解答可以多解、可以无解。

暴风雪山庄：封闭空间内的连续案件结构。特点是人数有限、无法离开、必须内部解决。

不可能犯罪：表面上违反物理或常识的犯罪。它需要“合理解释”，不能靠超自然收尾。

场景调度：通过远景、中景、特写的顺序组织场景，让读者先知道空间，再知道动作，最后看见关键细节。

沉默道具：用动作与停顿替代台词，制造压力。常用于审讯、认尸、家属见面。

### 14.10.2 D 与 F

动机三层：表层（他自己承认的）、中层（他真正的处境）、深层（他说不出口的）。

毒点：让读者弃书的写法。五种常见：凶手空降、线索矛盾、推理靠直觉、超自然收尾、篇幅注水。

断点：读者可能离开的位置。通常是解释段之后、切换视角处、连续三章无推进处。

反转：用旧事实重排出新结论。判断标准是：读者回头看，能找到三处支撑。

伏笔三段：埋、碰、收。三次出现的语气要依次加重，但不能明说。

复述画面：一个能被读者用一句话讲出来的场景。全书三到五个，是传播的抓手。

### 14.10.3 G 与 H

公平性：破案所需的关键线索，在揭晓前全部出现过。本格的底线。

关系图谱：把与案件有关的人按内圈、中圈、外圈分层，标出关系与可疑点。

钩子：让读者想知道下一句、下一章的那一句或那一个动作。

悬疑密度：单位章节内的悬念数量。过低会闷，过高会疲。

黑名单：第七部分列出的六类致命写法，写作前先对照。

呼吸章：每三到四章安排一次的缓和段落，防止读者疲劳。

### 14.10.4 J 与 K

阶段八段：案件引入、迷雾铺设、线索递进、嫌疑人引子、反转再反转、高潮对峙、真相揭晓、余味收束。

节拍：每一卷的四个节点：卷首钩、卷中压、卷中放、卷末翻。

嫌疑人轮换：让读者的怀疑对象按设计依次移动，制造“每个人都有问题”的感觉。

开场异常：第一章第一段里那个“不该这样”的细节。没有它，开篇留不住人。

可检验性：读者能否用文中信息验证推理。不可检验的推理，等于作者的独断。

### 14.10.5 L 与 M

逻辑闭环：动机、手法、证据、时间四者互相支撑，没有缺口。

冷启动：新书前七天的分发阶段。动作越少越好，重点在前三章质量与更新稳定。

谜面：一句话说清的核心疑问。四种句式：矛盾式、缺失式、多出一件式、重复式。

误导：把注意力引向错误方向，同时留下公平点。没有公平点就不是误导，是欺骗。

名场面：可被复述、可被截图的关键场景。判断标准是“有没有一个物件”。

### 14.10.6 Q 与 S

情绪结账：读者跟着人物走了一路，结局要给出对应的情绪回应。

社会派：以社会结构与人性处境为核心的悬疑。解答可以无解，观点必须落地。

三重动机：见“动机三层”。

视角控制：通过限制读者能看到的信息制造悬念。限制的理由必须是物理性的，不能是作者需要。

时间线表：以案发日为轴，前后各推三天，每条标注来源与可信度。

叙事契约：开篇给读者的类型承诺。承诺要兑现，兑现点不晚于第三章。

### 14.10.7 T 与 W

题材融合：悬疑与言情、古言、无限流等结合。纪律是一条主线一条副线，共享一个核心问题。

套路：被反复验证的结构。反套路不是抛弃结构，是改变其中一环。

伪结局：卷末看起来解决了问题，实际留了缺口。它的作用是让读者放松，再被推翻。

物证链：实物证据之间的互相印证关系。断一环，就要找替代证据。

无差别案：受害者与施害者之间没有特定关系。写作重点是“为什么是我”，不是“为什么是他”。

### 14.10.8 X 与 Y

现场重建：根据痕迹、血迹形态、物品位置还原案发过程。

悬念三件套：一个未回答的问题、一个未完成的动作、一个不该出现的东西。

信息差：读者知道而人物不知道，或人物知道而读者不知道。两种都可用，但要有理由。

线索类型：硬线索（推逻辑）、软线索（推情绪）、假线索（推误导）。比例约二比二比一。

嫌疑度打分：用动机、机会、能力、异常四项打分排序。排名第一的通常不是凶手。

叙述性诡计：通过叙述方式而非事实制造误导。公平的前提是不隐瞒关键事实。

悬疑言情：案件线与感情线并行，两条线互相影响。

余味：结局之后残留的一点不安或未解。通常用一个未解释的细节实现。

### 14.10.9 Z

真凶三登场：真凶在前三分之二至少露面三次，其中一次是单独场景。

证据体系：现场证据、法医证据、言词证据三层互相支撑。

章末钩：每章结尾的悬念。类型有五种：未完成动作、视点转移、突然沉默、时间跳切、第三人称插入。

追读曲线：每章强度分连成的线。健康形态是波浪向上。

自检清单：第十四部分的三轮清单，共五十项。

最后一小时：交稿前的六件事与三件不要做的事。

### 14.10.10 索引的使用

索引不是用来背的。写作卡住时，凭记忆找到那一节，翻回去看。翻三次以上，你就记住了。

如果某一节你反复翻，说明那一块是你的弱项。把它抄在纸上，贴在桌边。
