# 5.14 情绪与桥段的对应

> 素材来源：novel-material-skill ·《悬疑题材创作手册》5.14 情绪与桥段的对应

桥段的作用是“生产情绪”。不同的情绪，要用不同的桥段。用错了，场面再大也不动人。

### 5.14.1 八种情绪与对应桥段

表 5-6 八种情绪与桥段对应

| 情绪 | 最合适的桥段 | 要避免的写法 |
|---|---|---|
| 恐惧 | 空屋、夜路、电梯 | 靠突然的巨响吓人 |
| 焦虑 | 等待、跟踪、倒计时 | 让主角无所事事 |
| 愤怒 | 对峙、揭穿、家属质问 | 让主角冷静说理 |
| 悲伤 | 认尸、遗物、空房 | 让主角放声大哭 |
| 怀疑 | 审讯、试探、双人对话 | 让旁白替读者判断 |
| 震撼 | 真相揭晓、照片对照 | 一次给太多信息 |
| 释然 | 旧物归还、告别 | 让所有人握手言和 |
| 不安 | 结尾、余味、最后一句话 | 解释清楚 |

### 5.14.2 恐惧怎么写

恐惧来自“预期”，不来自“出现”。写恐惧时，先把一个可能性摆出来，然后让它迟迟不发生。读者的想象力比你写得更可怕。

具体技巧是“三次延迟”：第一次声音、第二次影子、第三次仍旧什么都没有。三次之后，读者已经绷紧，第四次才给一点点东西。

要避免的是“突然的巨响”。这种手法用一次有效，用两次就成了廉价。真正高级的恐惧，是安静的。

### 5.14.3 悲伤怎么写

悲伤的写法是“写日常，不写悲伤”。一个人失去亲人后，不会立刻哭，会先做一件很平常的事：洗碗、叠衣服、给手机充电。读者看到这个动作，会自己难过。

具体技巧是“一个未完成的动作”：她端了两碗饭，然后想起只剩一个人。

要避免的是“大段抒情”。抒情会把读者的情绪挤出去，因为读者被作者的眼泪挡住了。

### 5.14.4 愤怒怎么写

愤怒需要“对象”。对着空气发火没有戏，对着一个具体的人、一句具体的话发火才有戏。

写法上，先给一句轻飘飘的话（“这事就这样吧”），再给一个沉默，最后给一个动作（把杯子放回桌上，很轻）。越克制，越有力量。

要避免的是“主角长篇质问”。质问一旦超过五句，读者会站到被质问者那一边。

### 5.14.5 震撼怎么写

震撼来自“重排”。不是给新信息，是让旧信息换一个位置。读者会突然明白“原来那件事是这个意思”。

具体技巧是“两张纸的对照”：一份旧笔录与一份新证词，摆在同一个画面里。不需要解释，读者自己会算。

要避免的是“一次给太多”。一次只重排一件事，读者才吸收得了。

### 5.14.6 不安怎么写

不安是悬疑的底色。它不需要事件，只需要“一处不对”。椅子多了一把、鞋少了一只、时钟慢了三分钟。

写法上，把这个“不对”放在段落的最后一个短句里。短句会让读者停下来，回头想。

要避免的是“解释这个不对”。一解释，不安就变成了信息。

### 5.14.7 情绪的排列

一章里不要给三种以上情绪。三种以上，读者会不知道该感受什么。好的排列是“一种主情绪加一次短暂的反转情绪”。

比如：主线是焦虑，中间插一次短暂的释然（找到了一个线索），然后立刻回到焦虑（线索是假的）。一次起伏，胜过全程紧绷。
