# 3.1 案件设计的五个参数

> 素材来源：novel-material-skill ·《悬疑题材创作手册》3.1 案件设计的五个参数

案件是悬疑的发动机。发动机不好，人物再动人，车也跑不起来。本部分给出可直接取用的案件设定：六类案件、五族动机、四组手法、一套技术与证据体系、一条时间线方法、一批氛围词库。

使用顺序建议：先定案件类型，再定动机，再定手法，最后用技术细节和证据体系把逻辑补齐。顺序反了，容易写出“为了炫技而设计的案子”。

### 3.1.1 参数一：案发地点

地点决定一切。同一个死亡，发生在出租屋、写字楼、高档小区、城乡结合部，社会含义完全不同。地点选对了，动机自然长出来；地点选错，动机只能硬编。
- 私密空间（出租屋、宿舍、老家）：适合写人际纠葛、控制、亲密暴力。
- 半公开空间（写字楼、商场、学校）：适合写身份伪装、职场压迫、目击者众但无人看清。
- 公共空间（地铁、车站、广场）：适合写无差别、恐慌、监控与人群。
- 封闭空间（山庄、孤岛、地下车库、电梯）：适合写密室、内鬼、时间压力。
- 边缘空间（拆迁区、废弃厂、河滩、烂尾楼）：适合写被遗忘的人、陈年旧案、无人在意的死亡。

一个实用技巧：让地点本身有“前史”。这个厂房以前死过人，这栋楼以前是招待所，这条河每年都捞上东西。前史不需要在第一章讲完，它会在后面变成伏笔。

### 3.1.2 参数二：死亡方式

死亡方式决定案件的“可读性”。有的死法一眼看出是他杀，有的死法必须靠法医才能分辨。前者适合快节奏，后者适合本格。
- 明显他杀：刀伤、钝器伤、勒痕、明显搏斗痕迹。优势是开局就有冲击，劣势是嫌疑人范围立刻收窄。
- 疑似意外：坠楼、溺水、煤气、药物过量。优势是悬念足，劣势是需要大量技术解释。
- 疑似自然：猝死、心梗、过敏。优势是最容易被忽略，最适合写“藏在医院里的谋杀”。
- 疑似自杀：优势是能写“遗书是假的”，劣势是这类桥段已被写滥，必须有新切口。

进阶写法是“双重死法”：表面上死于 A，实际上是 B 导致的，而 A 是凶手故意制造的假象。读者以为自己看懂了，其实看的是凶手想让他看的东西。

### 3.1.3 参数三：发现者

谁先发现尸体，决定了故事的视角和第一现场的可信度。发现者有三种典型功能。
- 无辜发现者：保安、外卖员、邻居、保洁。他的证词有偏差，但他的生活细节最真实。
- 关联发现者：家属、同事、房东。他既可能是凶手，也可能是被凶手选中的人。
- 刻意发现者：报警的人就是凶手，或者凶手安排别人发现。这类开局最适合写“自导自演”。

发现者的选择还会影响“报案时间”。凌晨三点报案、第二天中午才报案、尸体放了三天才被发现，三种时间差背后是三种人性。

### 3.1.4 参数四：案件数量
- 单案：一个案子贯穿全书，靠深度撑篇幅。适合心理悬疑、社会派。
- 单元案加主线：每三到五章一个案子，主线缓慢推进。适合刑侦、都市悬疑。
- 连环案：案子一个接一个，凶手在暗处。适合节奏型悬疑。
- 并案：两起看似无关的案子被并到一起，制造“原来一直是一个人”的震撼。

新手最稳的结构是“单元案加主线”。单元案给读者即时满足，主线给读者长期期待。两条线要共用同一批人物，才不散。

### 3.1.5 参数五：真相层级

好的悬疑不止一层真相。建议设计三层。
- 第一层（表层）：谁动的手。读者追了十章，最想知道这个。
- 第二层（动机层）：为什么动手。这一层负责让读者心疼或心寒。
- 第三层（结构层）：为什么这件事能发生，谁让它发生的。这一层负责让读者合上书之后还在想。

三层真相的节奏是：第一层在中后段揭，第二层在接近结尾揭，第三层在结尾之后留一个暗示。三层全在小节一次揭完，读者会累；只揭一层，读者会觉得浅。
