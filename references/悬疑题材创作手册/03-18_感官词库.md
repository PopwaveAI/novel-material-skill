# 3.18 感官词库

> 素材来源：novel-material-skill ·《悬疑题材创作手册》3.18 感官词库

悬疑靠细节撑。细节不是形容词，是具体的感官信息。以下五类感官词条，按场景取用。

### 3.18.1 气味

表 3-11 气味词库

| 气味 | 常见于 | 能暗示什么 |
|---|---|---|
| 铁锈味 | 旧楼道、水管、血 | 陈旧与不祥 |
| 消毒水 | 医院、出租屋、清理过的现场 | 有人在收拾 |
| 霉味 | 老房、地下室、长期无人 | 被搁置的时间 |
| 香灰 | 寺庙、老人房间 | 旧习惯与祈愿 |
| 汽油 | 车库、仓库 | 准备与销毁 |
| 饭菜糊味 | 厨房、独居 | 突然的中断 |

### 3.18.2 声音

表 3-12 声音词库

| 声音 | 写法 | 作用 |
|---|---|---|
| 滴水 | 一秒一滴，节奏不稳 | 计时与焦虑 |
| 电流嗡鸣 | 灯管、冰箱 | 空间的空 |
| 远处犬吠 | 夜里、村落 | 有人经过 |
| 楼上拖椅子 | 老楼 | 人还在 |
| 钥匙串 | 楼道 | 身份与归来 |
| 纸张翻动 | 办公室、档案室 | 秘密被翻 |

### 3.18.3 光线
- 楼道声控灯：亮三秒，灭，再亮。
- 手机屏幕的光：从上往下照，人的脸会变形。
- 车灯扫过墙面：一瞬间的影，之后更黑。
- 冰箱门打开的光：冷白，只照到一小块。
- 傍晚的斜光：把房间切成两半，一半亮，一半暗。

### 3.18.4 材质与触感
- 铁门：凉，接缝处有毛刺。
- 旧沙发：坐下去陷一块，起来弹不回去。
- 湿衣服：贴在身上，越走越冷。
- 纸箱：软，压一压会塌。
- 瓷砖：冬天凉，走上去脚底发紧。

### 3.18.6 感官的使用原则

一章里，气味不超过两处、声音不超过三处、光线不超过两处。超过这个量，读者会疲。

更重要的一条是：每个感官细节都要“有用”。气味暗示状态、声音暗示位置、光线暗示时间。没有功能的细节，是装饰，装饰会拖慢节奏。

第三部分收束。你现在应当有一个能自洽的案件、一个可信的动机、一套能自证的技术与证据，以及一批随时可用的氛围词。第四部分，讲这些材料怎么排成节奏。
