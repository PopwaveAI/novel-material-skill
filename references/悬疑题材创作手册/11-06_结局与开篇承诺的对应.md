# 11.6 结局与开篇承诺的对应

> 素材来源：novel-material-skill ·《悬疑题材创作手册》11.6 结局与开篇承诺的对应

### 11.6.1 承诺对照表

表 11-2 开篇承诺与结局对应

| 开篇承诺 | 适合的结局 | 不适合的结局 |
|---|---|---|
| 我要找到凶手 | 真相大白 | 开放留白 |
| 我要证明我哥是清白的 | 真相大白加遗憾 | 纯反转 |
| 我想知道那晚发生了什么 | 遗憾或留白 | 强行大团圆 |
| 我要活下去 | 反转或留白 | 庆功式结局 |
| 我要让他们付出代价 | 遗憾式 | 轻飘飘的和解 |

错配是烂尾的主要原因。开篇说“我要找凶手”，结局却留白，读者会觉得你没写完。开篇说“我要活下去”，结局却是法庭戏，读者会觉得跑题。

### 11.6.2 结局调整的三个信号
- 读者在中期就开始问“到底谁是凶手”：说明你的谜面太单一，结局必须给明确答案。
- 读者在中期开始讨论配角的命运：说明人物比案子有吸引力，结局可以留白，把重量放在人身上。
- 读者在中期开始骂主角：说明主角的道德立场有问题，结局必须给他一次明确的选择与代价。

三个信号来自评论区，也可以来自自己的判断。写到大纲中段，回看一遍开篇三章，就知道自己该走哪条结局线。
