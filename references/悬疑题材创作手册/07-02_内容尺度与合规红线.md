# 7.2 内容尺度与合规红线

> 素材来源：novel-material-skill ·《悬疑题材创作手册》7.2 内容尺度与合规红线

### 7.2.1 刑侦与犯罪细节的处理

写犯罪，目的是写人，不是写教程。所有涉及具体操作的部分，都要做“三不写”。
- 不写可复现的操作步骤。不写配方、剂量、工具改装、规避手段的具体流程。
- 不写规避侦查的方法。反侦察技巧、伪造证据的手法，一律虚写。
- 不写对执法人员的具体攻击方式。冲突可以写，方法不写。

可以写的是：动机、心理、后果、侦破逻辑、证据链。这些东西既安全，又比操作细节更有戏剧价值。读者要的是“怎么破的”，不是“怎么做的”。

### 7.2.2 敏感情节的边界

悬疑常涉及死亡、暴力、创伤。写这些内容时，遵循四条边界。
- 不美化犯罪。可以写凶手的逻辑，不能写他的“酷”。
- 不详细描写施暴过程。重点是受害者的处境与后果，不是伤害的细节。
- 不消费苦难。弱势群体的痛苦要写得有尊严，不能当猎奇素材。
- 不指向现实中的具体个人与群体。虚构要明确虚构，避免影射。

还有一条实践建议：涉及未成年人、性暴力、自杀等题材时，把笔力放在“恢复”与“追责”上，而不是“现场”。这既是合规要求，也是写作水平的分界线。

### 7.2.3 平台审核的三个高频触点
- 标题与封面：不要用血腥、猎奇、暗示性的表述。标题党的短期收益，抵不过限流的长期损失。
- 开篇三章：审核最看开头。开头就出现极端暴力或敏感情节，容易被判定风险。
- 章节内的具体描写：涉及尸体、伤害、审讯暴力的段落，用“结果”代替“过程”。

被限流时，先自查这三处，再考虑申诉。多数问题是描写过细，不是题材本身。

### 7.2.4 合规自检表

表 7-2 合规自检表

| 检查项 | 合格标准 | 整改方式 |
|---|---|---|
| 犯罪操作 | 无可复现步骤 | 改为结果描写 |
| 暴力过程 | 不过度细节化 | 聚焦后果与情绪 |
| 弱势群体 | 有尊严、非猎奇 | 增加主体视角 |
| 现实影射 | 明确虚构 | 改地名、改身份 |
| 标题封面 | 无猎奇暗示 | 改为悬念型表达 |
