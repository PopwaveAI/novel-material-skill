# 3.14 法医与刑侦技术细则

> 素材来源：novel-material-skill ·《悬疑题材创作手册》3.14 法医与刑侦技术细则

这一节给写作真正用得上的技术点。原则是“写得准，不写细到能照做”。读者要的是判断逻辑，不是操作手册。

### 3.14.1 死亡时间的五个参照

尸温：人死亡后体温逐步下降。常规估算以每小时下降一定幅度为基础，再受环境温度、衣着、体型影响。写作时用“比正常体温低了几度”就够。

尸僵：先在下颌与颈部出现，逐渐向下扩展，之后逐步缓解。它给出的是一段区间，不是精确时刻。

尸斑：血液因重力沉积，形成紫色斑块。斑块是否随体位改变而转移，能提示死亡后是否被搬动。

胃内容物：根据食物消化程度推断最后一餐的时间，再与已知的用餐记录比对。这是最好用的“时间误差”工具。

角膜与指甲：角膜透明度、指甲生长等辅助判断，只能作为参考。

写法提示：法医永远给“区间”，不给“几点几分”。给区间的法医是专业的，给精确时刻的法医是外行。这个区别，懂行的读者一眼能看出来。

### 3.14.2 损伤类型与叙述价值

表 3-9 损伤类型与叙事价值

| 类型 | 典型特征 | 叙事价值 |
|---|---|---|
| 钝器伤 | 广泛挫伤、骨折线、皮下出血 | 说明力量与反复 |
| 锐器伤 | 创口整齐、创角锐利、深浅不一 | 说明工具与试探 |
| 窒息 | 索沟、面部点状出血、舌骨骨折 | 说明过程漫长 |
| 溺死 | 口鼻泡沫、手中抓握异物 | 说明生前入水 |
| 高坠 | 损伤集中于着力侧、内脏破裂 | 说明起跳点与姿势 |
| 烧死 | 呼吸道烟尘、碳氧血红蛋白 | 说明生前还是死后 |

上表最有用的是第三列。同样的伤，写法不同，戏也不同。钝器伤适合写“愤怒”，锐器伤适合写“冷静”，窒息适合写“犹豫”。

### 3.14.3 毒物与药物的写作边界
- 写类别，不写配方。写“镇静类药物”“工业溶剂”“农药类”，不写具体名称与剂量。
- 写检测，不写提取。写“血样检出”，不写“如何获得”。
- 写来源，不写制作。悬疑的关键是“谁能拿到”，这一点足够了。

三条边界既是合规要求，也是写作要求。读者的兴趣在“谁下的”，不在“怎么配的”。

### 3.14.4 现场痕迹的六种

指纹：最常见，也最容易被破坏。它的价值在“位置”：出现在不该出现的地方，比出现本身更有意义。

足迹：能给出身高、体重、步态与来去方向。泥地、湿地、灰尘上的足迹最有用。

血迹形态：滴落、喷溅、擦拭、流淌，各自对应不同的动作。这是现场重建的核心。

微量物证：纤维、玻璃碎屑、土壤、花粉。它能回答“这个人去过哪里”。

工具痕迹：撬压、剪切、切割。它能回答“用了什么”。

生物检材：用于身份确认与亲属关系判断。它是最后一道保险。

六种痕迹里，写作最好用的是血迹形态与微量物证。前者能重建动作，后者能重建行程。两者一结合，嫌疑人范围就出来了。

### 3.14.5 数字取证的四条线
- 通讯线：通话记录、短信、聊天记录、删除痕迹。
- 位置线：定位记录、基站切换、门禁与停车记录。
- 资金线：转账、消费、代付、红包。钱比嘴诚实。
- 影像线：监控、行车记录仪、手机拍摄、社交平台发布。

四条线的用法是“互相验证”。通讯说他在外地，位置说他在本地，资金说他在本地消费，三条对不上，谎就露了。

写法上，数字取证不要写成技术报告。选一条最能打的线，用一个具体的动作呈现：点开一条转账记录，备注栏写着三个字。
