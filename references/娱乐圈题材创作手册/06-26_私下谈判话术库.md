# 6.26 私下谈判话术库

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》6.26 私下谈判话术库

私下谈判与公开谈判不同，它更像试探。下面按阶段给句子。

### 6.26.1 开场
- “这件事我们私下说，别让第三个人知道。”
- “我不绕弯子，我要那个角色。”
- “我手上有一个消息，你可能会感兴趣。”
- “先说好，今天不谈感情。”
- “我们各说各的底线。”
- “你开个价。”

### 6.26.2 试探
- “如果我答应，你能给我什么。”
- “这件事你说了算吗。”
- “你上面的人知道吗。”
- “我们之间，还有谈的余地吗。”
- “你怕什么。”
- “你最不能失去的是什么。”

### 6.26.3 交换
- “我帮你这一次，你欠我一次。”
- “这件事我可以压，但我要一个位置。”
- “我给你消息，你给我时间。”
- “我不需要钱，我需要署名。”
- “这次我退，下次你别挡我。”
- “我们交换，谁也不吃亏。”

### 6.26.4 收尾
- “就这么说定了。”
- “今天的话，出了这个门就没了。”
- “我会记住你今天说的。”
- “希望我们不用再见。”
- “祝你好运。”
- “后会有期。”

私下谈判的台词要短，因为真正的谈判大部分时间是沉默。写的时候，让对话之间留出空档，让读者感到两个人在互相衡量。
