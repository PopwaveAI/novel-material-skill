# 1.8 选题成立性自检

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》1.8 选题成立性自检

在动笔之前，用下面这张表把选题过一遍。任何一项答不上来，都不要急着写第一章，因为这些问题会在第二十万字时集中爆发。

表 1-5 选题成立性八问

| 检查项 | 要回答的问题 | 不合格的信号 |
|---|---|---|
| 场域 | 故事主要发生在剧组、综艺、公司还是平台？ | 什么都写一点，没有主场景 |
| 视角 | 谁在讲故事，他掌握多少信息？ | 视角飘移，读者不知道跟谁 |
| 主爽点 | 读者最想看的那个瞬间是什么？ | 说不出一个具体画面 |
| 资源链 | 主角要争的东西由谁分配？ | 资源凭空出现 |
| 对手 | 谁最不希望主角成功？ | 对手只是坏人，没有利益 |
| 代价 | 主角每上升一步失去什么？ | 升级没有成本 |
| 秘密 | 全书最大的信息差是什么？ | 没有秘密，只有误会 |
| 终点 | 故事结束时主角站在哪里？ | 结局靠感情收尾，事业没有落点 |

这张表的用法不是打勾，而是逼自己写出具体答案。能写出具体答案的选题，通常已经具备写四十万字的基本结构；写不出来的，多半要靠后期硬撑，而硬撑出来的长篇，读者一眼就能看出来。
