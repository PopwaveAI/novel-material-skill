# 9.17 资源与代价对照表

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》9.17 资源与代价对照表

娱乐圈的每一次上升都有代价。把资源和代价放在一张表里，故事就有了重量。

表 9-10 资源与代价对照

| 得到的资源 | 付出的代价 | 可写的外显 |
|---|---|---|
| 女主角 | 和原来的朋友疏远 | 杀青宴上没有人陪她坐 |
| 一线代言 | 被要求保持单身形象 | 把戒指摘下来放进抽屉 |
| 平台自制剧 | 签了三部戏的优先权 | 合同上有一个她没细看的附加条款 |
| 奖项提名 | 必须参加所有宣传活动 | 一个月飞了十一个城市 |
| 自立工作室 | 失去公司的法务与公关支持 | 第一次自己写声明 |
| 顶级综艺常驻 | 被剪辑定型 | 观众只记得她的一个表情 |
