# 5.9 优质桥段与高危雷区对照

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》5.9 优质桥段与高危雷区对照

表 5-1 八类桥段的优质与雷区对照

| 桥段类型 | 优质版本的共同点 | 高危版本的共同点 |
|---|---|---|
| 初见 | 靠专业性建立第一印象 | 靠外貌与意外制造心动 |
| 对戏 | 情绪发生在角色的缝隙里 | 借角色之名行越界之实 |
| 红毯 | 克制，只留一个痕迹 | 当众亲密，靠旁人起哄 |
| 直播 | 救场有代价、有后续 | 一句话封神，全场膜拜 |
| 黑料 | 危机真实，反应分层 | 黑料是假，澄清即解决 |
| 官宣 | 动作小，余震长 | 场面大，情感空 |
| 颁奖 | 话说一半，克制 | 长篇告白，当众求婚 |
| 对峙 | 落在条款与数字上 | 靠气场与金句取胜 |

这张表的用法是反向检查。写完一个桥段，逐条对照右边一列，只要有两条命中，就说明这个场面还停留在“看起来很热闹”的阶段。真正让人记住的场面，往往只有一个动作，一句没说完的话，一个别人看不懂的细节。
