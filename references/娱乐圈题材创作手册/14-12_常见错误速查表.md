# 14.12 常见错误速查表

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》14.12 常见错误速查表

表 14-2 十种常见错误速查

| 错误 | 识别方式 | 快速修法 |
|---|---|---|
| 开篇是概述 | 前三章没有具体场景 | 把第一段改成人物正在做一件事 |
| 人物太多 | 前五章超过六个有名字的人 | 合并或删掉次要角色 |
| 主角被动 | 连续三章由别人推动情节 | 给她一个主动的决定 |
| 反派单薄 | 反派只会使坏，没有利益 | 补一段他的处境 |
| 危机太易解 | 一次声明解决全部问题 | 留一个未爆的引线 |
| 感情跳级 | 从陌生直接到告白 | 中间补两次有效互动 |
| 台词同质 | 遮住名字认不出谁在说 | 给每人一个句式习惯 |
| 行业词过量 | 一段出现五个以上术语 | 删到两个，其余用动作替代 |
| 结局仓促 | 最后一章解决所有问题 | 拆成三章收束 |
| 主题靠旁白 | 结尾出现“她终于明白” | 删掉，换成动作 |
