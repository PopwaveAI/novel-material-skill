# 3.18 商务与谈判词库

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》3.18 商务与谈判词库

商务场景的语言特点是“留余地”。每一句话都不说死，但每一句话都在传递立场。这一节给常用词与常用句式。

### 3.18.1 商务词条
- 商务：艺人的商业活动统称。
- 代言：品牌请艺人作为形象代表。
- 品牌大使：比代言人低一档的合作身份。
- 品牌挚友：更轻度的合作。
- 站台：出席品牌活动，露个面。
- 出席费：参加活动的报酬。
- 坑位费：直播中某个商品位置的费用。
- 佣金：按销售额提取的报酬。
- 税后价：扣除税费后的报价。
- 打包价：多项合作一起报的价格。
- 排他条款：合约期内不能接同类品牌。
- 肖像权：使用艺人形象的权利。
- 授权期：可以使用形象的时间。
- 结算周期：多久结一次款。
- 账期：从开票到付款的时间。
- 违约金：违约要赔的钱。
- 保底：承诺最低收益。
- 分成：按比例分配收益。
- 买断：一次性买下版权或合约。
- 续约：合约到期后继续合作。
- 优先权：同等条件下的优先合作权。

### 3.18.2 谈判常用句式
- “这个价格我们做不了，但可以换一种合作方式。”
- “我们尊重你的判断，不过市场这边有市场的算法。”
- “如果这一条能松一点，其他都可以谈。”
- “我不需要你现在答复，你可以回去商量。”
- “这件事我可以让，但我要一个说法。”
- “你说的我记下了，我们内部过一下。”
