# 5.21 桥段与章末钩子的配合

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》5.21 桥段与章末钩子的配合

桥段负责“发生”，钩子负责“留下”。两者配合得好，一章就有了完整的呼吸。

表 5-3 桥段与钩子的搭配

| 桥段类型 | 适合搭配的钩子 | 效果 |
|---|---|---|
| 相遇类 | 一个未解的身份或一句话 | 读者想知道他们还会不会再见 |
| 合作类 | 一个突然的外部干扰 | 关系刚建立就被打断 |
| 危机类 | 一个更大的威胁 | 压力层层加码 |
| 情感类 | 一句没说完的话 | 情绪悬在半空 |
| 事业类 | 一个意外的机会或拒绝 | 下一步走势不明 |
| 收束类 | 一个未拆的东西 | 余韵 |

一个常见的失误是：桥段很热闹，钩子很弱。比如一场精彩的试镜戏，章末写“她回家睡着了”，读者没有理由点下一章。正确做法是把钩子放在桥段的余波上，比如“她刚躺下，手机亮了，是一个陌生号码”。
