# 6.7 潜台词的五种写法

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》6.7 潜台词的五种写法

娱乐圈的人说话，很少直说。他们要顾虑镜头、顾虑合约、顾虑对方的团队。这种“不能直说”的语言习惯，正好给了写作者大量潜台词空间。

### 6.7.1 话题转移

问 A，答 B，但 B 与 A 有隐秘的关联。比如记者问“你们是不是在一起了”，她答“我最近在学做菜”。学做菜和在一起没有直接关系，但如果前文写过他爱吃某道菜，这句话就是回答。

### 6.7.2 程度偏移

用“还行”“不错”“挺好的”这类模糊词，但语气决定含义。同样一句“挺好的”，重音在前是认可，重音在后是敷衍，拖着说是心不在焉。写作者要写出这个语气，而不是写出这个词。

### 6.7.3 视角置换

不说自己，说“有的人”“有些人”。比如“有些人就是不适合这一行”，说的其实是自己或者对方。这种句式最适合写不敢承认的情绪。

### 6.7.4 反向表达

嘴上说不在乎，行为上很在乎。写这种反差要写两个东西：一句淡漠的话，一个相反的动作。比如她说“他爱跟谁合作跟谁合作”，说完把手机屏幕扣在桌上。

### 6.7.5 未完成句

话说到一半停住，或者被外部打断。未完成句的力量在于读者的补全。补全的内容因人而异，但方向是确定的。写这种句子要注意：停的位置必须在关键信息之前，不能停在不重要的地方。
