# 9.23 一张填好的 CP 设定卡

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》9.23 一张填好的 CP 设定卡

下面是一张填好的样例，用来感受表该怎么填。填表的关键不是写满，是写具体。

表 9-15 填好的 CP 设定卡

| 字段 | 内容 |
|---|---|
| 姓名 | 沈知夏、陆迟 |
| 身份 | 她：被换过三次角的演员；他：只拍电影不拍剧的导演 |
| 关系起始 | 同一部戏，她是替补，他是原定导演 |
| 核心矛盾 | 他要一部完整的作品，她要一次被看见的机会 |
| 相互需要 | 她能演他想要的那种“不解释的痛”，他能给她别人不给的镜头 |
| 最大阻碍 | 他签了平台的合约，必须按期交片；她的旧事会影响项目 |
| 节奏节点 | 第 3 章初见、第 12 章第一次争执、第 28 章公开危机、第 55 章决裂、第 80 章和解 |
| 标志性物件 | 一支用旧的分镜笔 |
| 结局方向 | 双成，错峰 |

### 9.23.1 说明

这张卡里最有用的是“相互需要”与“最大阻碍”两栏。前者决定他们为什么会在一起，后者决定他们为什么不能轻易在一起。两栏写不清，关系就立不起来。
