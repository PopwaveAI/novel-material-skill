# 9.24 一张填好的危机事件表

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》9.24 一张填好的危机事件表

表 9-16 填好的危机事件表

| 项 | 内容 |
|---|---|
| 事件 | 她三年前的一段采访被翻出，其中一句话被断章取义 |
| 时点 | 开机第十二天，第二天有重要外景 |
| 第一反应 | 她决定不解释，只发一张工作照 |
| 各方 | 平台要稳、制片要按期、品牌观望、粉丝分裂 |
| 代价 | 一个代言暂缓，两个通稿被撤 |
| 转折 | 原采访的完整音频被人放出来 |
| 结果 | 舆情反转，但她的公众印象已经变了 |
| 后遗症 | 此后她每次采访都要先审提纲 |

### 9.24.1 说明

危机表的价值在“代价”与“后遗症”两栏。没有代价的危机是假危机，没有后遗症的危机是假解决。两栏都填上，危机才有重量。
