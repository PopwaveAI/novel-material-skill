# 9.1 娱乐圈 CP 设定卡

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》9.1 娱乐圈 CP 设定卡

这一部分是整本册子的工作台。前面八个部分讲的是判断，这一部分给的是可以直接填写的表单。六张表分别对应六个最常出问题的地方：人物关系、圈层站位、事业节奏、危机管理、伏笔回收、整体自检。

使用方式建议打印出来或者存成一份文档，边写边填。表格不是装饰，填不满的地方就是你的故事还缺的地方。

CP 设定卡解决的是“这两个人为什么非彼此不可”。填卡的时候不要写形容词，只写行为。写不出行为，说明关系还停留在概念层。

### 9.1.1 填写说明

圈内位置：写具体层级，比如“一线电影演员，三年无爆款”，不要写“很红”。

最想要的东西：必须是可被看见的目标，比如“拿到一个能证明自己的角色”。

关系里最不公平的地方：这是张力的来源。一方付出更多，一方掌握更多，关系才有摩擦。

公开关系的代价：填不出来，说明这段关系还没有真正的风险，读者不会紧张。

表 9-2 CP 设定卡示例

| 栏目 | 男主 | 女主 |
|---|---|---|
| 公开身份 | 三届视帝，票房保证 | 全网黑的小花，被叫营销咖 |
| 圈内位置 | 顶流，被资本与粉丝双重绑定 | 二线边缘，随时可能被替换 |
| 最想要的东西 | 演一个自己认可的角色 | 让骂她的人承认她会演 |
| 最怕失去的东西 | 对表演的判断力 | 最后一点体面 |
| 不能让步的底线 | 不接自己看不上的本子 | 不接受被安排的人生 |
| 最容易被说动的地方 | 有人真的懂他的表演 | 有人在她被骂时不移开眼 |
| 最怕对方知道的事 | 他已经三年没接到想接的戏 | 她把所有恶评都截图存了下来 |
| 只有对方懂的习惯 | 开机前自己走一遍机位 | 被夸时会短暂失神 |
