> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》9.6 剧情自检表

这张表用于每写完一卷做一次整体检查。二十个问题，答不上来的就是下一卷要补的洞。

表 9-7 剧情自检表

| 检查项 | 问题 | 是或否 | 处理动作 |
|---|---|---|---|
| 主动性 | 这一卷里，主角有没有做过一个真正影响结局的决定 |  |  |
| 代价 | 主角这一卷失去了什么具体的东西 |  |  |
| 对手 | 对手的动机能不能用一句话说清，且与利益有关 |  |  |
| 关系 | 这一卷的感情有没有推进一个明确的层次 |  |  |
| 信息 | 这一卷有没有揭开或埋下一个信息差 |  |  |
| 节奏 | 有没有连续三章以上没有任何推进 |  |  |
| 新鲜感 | 有没有出现一个此前没见过的场景或人物 |  |  |
| 台词 | 有没有一句能被读者截图的话 |  |  |
| 行业 | 行业细节有没有出错或过度解释 |  |  |
| 雷区 | 有没有影射、失真、幼稚化的问题 |  |  |

### 9.6.1 使用建议

不要一次填二十项，容易走形式。每次只挑三项最容易出问题的填，填完立刻改。下一卷换另外三项。三轮下来，整本书的骨架就被检查过一遍了。
