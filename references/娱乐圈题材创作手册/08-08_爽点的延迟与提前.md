# 8.8 爽点的延迟与提前

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》8.8 爽点的延迟与提前

### 8.8.1 延迟的价值

爽点不是越早越好。一个被延迟了三章的爽点，兑现时会更有力量，因为读者已经积攒了情绪。延迟的关键是“不能空等”，等待期间必须有新的信息或新的压力，否则读者会觉得作者在拖。

### 8.8.2 提前的价值

有些爽点必须提前，尤其是开篇。第一章如果没有一个明确的爽点，读者不会等到第三章。开篇的爽点不需要大，一次漂亮的回击、一句让对手说不出话的台词，就够。

### 8.8.3 延迟与提前的配比

表 8-3 爽点投放时点

| 位置 | 爽点类型 | 建议时点 |
|---|---|---|
| 第一章 | 小回击或小胜 | 三千字内 |
| 第三到五章 | 专业高光 | 第一次被看见 |
| 第十到十五章 | 身份小跃迁 | 第一次资源升级 |
| 中段 | 正面打脸 | 延迟两到三章后兑现 |
| 后段 | 格局反转 | 一次摊牌 |
| 结局 | 最终确认 | 最后一到三章 |
