# 5.18 桥段的组合与复用

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》5.18 桥段的组合与复用

单独一个桥段只能撑一场戏，桥段组合起来才能撑一卷。一个可用的组合是：试镜落选、开机站位靠后、探班被拍、庆功宴孤独、解约、雪藏、复出。七个桥段串起来，就是一条完整的低谷到反弹的弧线。

表 5-2 五种桥段组合方案

| 组合目标 | 桥段顺序 | 情绪走向 |
|---|---|---|
| 建立处境 | 试镜、开机、探班 | 被挑选、被排序、被观看 |
| 关系升温 | 深夜对戏、机场、红毯 | 靠近、同行、公开同框 |
| 危机爆发 | 黑料、危机会议、粉丝见面会 | 失控、应对、面对爱 |
| 夺回主动 | 资本对峙、解约、复出 | 谈判、切割、重建 |
| 收束 | 颁奖、官宣、庆功宴 | 确认、公开、余韵 |

复用桥段要小心。同一个桥段在书里出现两次，第二次必须有不同的意义。比如第一次开机仪式她是第三排，第二次开机仪式她站在第一排，但身边的人都换了。场景一样，人事已非，这样复用才有价值。
