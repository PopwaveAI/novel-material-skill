# 3.5 平台与资源链

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》3.5 平台与资源链

资源链是这个题材的血液循环系统。写不清资源怎么流动，事业线就只能靠空喊。下面这张表把常见的资源类型、分配方、获取难度和替代品列清楚，写作时可以直接查。

表 3-2 文娱资源链速查

| 资源类型 | 分配方 | 获取难度 | 典型代价 |
|---|---|---|---|
| 剧集主角 | 平台 + 制片方 | 高 | 降片酬、让番位、接受捆绑宣传 |
| 电影角色 | 导演 + 出品方 | 很高 | 长期试戏、接受低酬、赌口碑 |
| 常驻综艺 | 平台 + 制作公司 | 中 | 配合话题、接受剪辑安排 |
| 品牌代言 | 品牌方 + 经纪公司 | 中高 | 形象绑定、排他条款、活动出场 |
| 杂志封面 | 杂志 + 品牌 | 中 | 配合拍摄、接受造型 |
| 晚会资源 | 卫视 + 平台 | 中 | 档期配合、接受合唱或拼盘 |
| 音乐舞台 | 平台 + 音乐公司 | 中低 | 接受改编、配合宣传 |
| 直播带货 | 平台 + 品牌 | 低 | 消耗形象、承担翻车风险 |

### 3.5.1 片酬的三种结构

固定片酬：一口价，最稳妥，适合新人或有现金流压力的艺人。

片酬加分账：降低前期成本，赌作品爆。适合有信心的项目，也适合想绑定长期收益的艺人。

资源置换：不收钱，换平台资源或后续项目。这类交易最隐蔽，也最容易出事。

### 3.5.2 平台话术

平台的人说话有一套固定语法，写作者掌握这套语法，谈判戏立刻就有真实感。

“这个项目我们内部评级不高”：意思是不想给好排播，或者想压价。

“我们可以考虑联合出品”：意思是要分你的版权，或者要塞人。

“先看看市场反馈”：意思是暂不定档，可能要压着。

“这个阵容还差一点”：意思是让你去请更大牌的演员，或者换掉某个人。

“我们尊重创作”：通常出现在他们要干预创作之前。

“这次宣发资源会倾斜”：意思是他们会拿你的项目去换别的项目。
