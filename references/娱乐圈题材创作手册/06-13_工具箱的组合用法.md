# 6.13 工具箱的组合用法

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》6.13 工具箱的组合用法

六件工具不要单独使用。一个有效的组合是：用信息差设计一场戏，用潜台词写对话，用沉默控制节奏，用手机戏推进关系，用剪辑装置制造危机，用同款细节收尾。六件工具串起来，一场戏就有了六个层次。

表 6-2 场景需求与工具搭配

| 场景需求 | 首选工具 | 辅助工具 |
|---|---|---|
| 想让读者心动 | 克制式暗恋、闪光灯下的私密感 | 潜台词、手机戏 |
| 想让读者紧张 | 信息差、剪辑装置 | 沉默、同款 |
| 想让读者愤怒 | 粉圈压力、偷拍 | 剪辑、舆论三段 |
| 想让读者佩服 | 资本博弈、谈判话术 | 行业词、数字 |
| 想让读者回味 | 未完成句、场景复用 | 沉默、留白 |

最后一个纪律：工具是给人物用的，不是给作者炫的。如果一场戏里三个工具同时出现，读者会感到刻意。一场戏一个主工具，一个辅工具，足够了。
