# 8.12 追读曲线异常诊断表

> 素材来源：novel-material-skill ·《娱乐圈题材创作手册》8.12 追读曲线异常诊断表

表 8-4 追读异常诊断

| 异常 | 可能的病根 | 先改哪里 |
|---|---|---|
| 首章跳出率高 | 开场没有冲突，或信息太密 | 改前三百字，删掉所有背景 |
| 第三章流失 | 主角还没有专业高光 | 把高光提前到第二章末 |
| 第十章流失 | 第一个小目标没有兑现 | 在第九章给一次明确的小胜 |
| 中段评论骤减 | 关系推进停滞 | 加一次越界或一次误读 |
| 后段追读下滑 | 敌人消失，目标模糊 | 换敌人或抬高目标 |
| 完结后差评集中 | 结局没有兑现许诺 | 补一个承诺的画面 |

诊断的顺序是先看数据掉在哪里，再看那一章的结尾写了什么，最后看那一章之前埋了什么。多数问题不在掉点的那一章，而在它前面两三章。
