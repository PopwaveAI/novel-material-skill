# 2.1 人设总原则：欲望决定行为，底线决定选择

> 素材来源：novel-material-skill ·《人性欲望创作手册》2.1 人设总原则：欲望决定行为，底线决定选择

人设不是性格标签的集合，是一套配置：他的欲望有多硬，他的底线有多低，这两条线之间的距离，决定了他能演多少戏。同样的情节，放在一个底线很高的人身上是折磨，放在一个底线很低的人身上是过场。所以这一部分不给性格词，只给配置。

阅读顺序建议：先读 2.1 的总原则，再按自己的主角类型挑一节精读，最后一定要读完 2.9 的冲突矩阵。矩阵是这一部分的核心，它把人物关系变成了可计算的戏剧张力，很多“人物不够立体”的问题，在矩阵里一摆就露馅了。

一个人物在故事里只会做两种动作：一是朝着欲望走，二是在底线前停下或跨过去。前者给读者看“他是什么样的人”，后者给读者看“他到底是谁”。缺了前者，人物没有动力；缺了后者，人物没有重量。

很多作者写人物时习惯先写性格：他很冷、他很暖、他表面玩世不恭。这些形容词在故事里几乎不起作用。把它们换成配置语言，立刻就有了戏：他要什么（欲望），他绝不做什么（硬底线），他做过之后会后悔什么（软底线）。三条一写，人物的行为就有了可预测性，而可预测性正是读者愿意追下去的原因之一。

### 硬底线、软底线、无底线

硬底线是这个人物宁死不做的事，比如不害孩子、不出卖朋友、不动手打女人。硬底线必须在故事里被正面撞击至少一次，否则读者不知道它真的硬。

软底线是他做了会难受、但必要时会做的事，比如撒谎、拿回扣、让无辜的人背锅。软底线是人物性格的刻度尺，他越过软底线的次数和代价，就是他堕落的速度。

无底线区是他自己都没意识到可以跨的地方。高明的写法是在故事后段把他推进这个区，让他自己也吓一跳。人被自己吓到的那一下，比被对手打败有价值得多。

表 2-1　人物欲望配置的五层

| 配置层 | 回答的问题 | 在故事里的功能 | 写错的表现 |
|---|---|---|---|
| 欲望底色 | 他非要不可的是什么 | 发动机，决定他主动做什么 | 只写在设定里，不落在行动上 |
| 硬底线 | 他宁死不做的是什么 | 刹车，制造两难 | 从不被正面撞击，等于不存在 |
| 软底线 | 他做了会后悔的是什么 | 刻度，标记堕落程度 | 越过之后毫无反应 |
| 无底线区 | 他不知道自己会做的是什么 | 后段爆点，制造自我震惊 | 从头到尾没有触碰 |
| 羞耻点 | 他最不愿被人看见的是什么 | 要挟的把柄，关系反转的钥匙 | 设定有，剧情不用 |

### 配置要写进动作，不能写进设定

所有配置都必须有对应的外化动作，否则等于没写。下面这张对照是硬要求：设定写完，动作必须跟上。

表 2-2　配置与外化动作对照

| 配置 | 可用的外化动作 |
|---|---|
| 欲望底色 | 他会为一个机会推掉什么；他把什么放在手机第一屏；他记得谁的电话号码 |
| 硬底线 | 他拒绝时的第一反应（不是说的话，是手上的动作）；他转身走开的时机 |
| 软底线 | 他答应之前的那一秒停顿；事后洗手、抽烟、开窗这些小动作 |
| 无底线区 | 被逼到墙角时他自己都没料到的那一句；说完之后的沉默 |
| 羞耻点 | 他抢在别人开口之前先自嘲；他特别在意某个词的用法 |

还有一个原则必须强调：人设不能一次交代完。读者对人物的认识应该是递增的，每十到十五章翻一层。第一章让读者看见他的欲望，第三章看见他的软底线，第八章看见他的羞耻点，第二十章才让他撞上硬底线。一次交代完，人物就成了说明书。
