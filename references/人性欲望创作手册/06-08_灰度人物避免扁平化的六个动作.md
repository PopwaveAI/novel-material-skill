# 6.8 灰度人物避免扁平化的六个动作

> 素材来源：novel-material-skill ·《人性欲望创作手册》6.8 灰度人物避免扁平化的六个动作

扁平化的本质是“可预测”。读者看两章就知道这个人会怎么反应，剩下的戏就成了等待。破解办法不是加设定，是加矛盾动作。

表 6-4　反扁平化的六个动作

| 动作 | 具体做法 | 为什么有效 |
|---|---|---|
| 给一个反向习惯 | 刻薄的人喂流浪猫，节俭的人给自己买贵东西 | 习惯不解释动机，读者自己会想 |
| 给一个无用的技能 | 会修老式收音机、会认星、会包粽子 | 无用之物最能显出人的来处 |
| 给一次说不出口的示弱 | 他偷偷去看了对方的演出，没进场 | 示弱但不说，比说出来更有重量 |
| 给一个错误的坚持 | 明知没用还要守着一条旧规矩 | 错误的坚持最像真人 |
| 给一个不肯提的旧事 | 所有人都知道，只有他不提 | 沉默的位置就是伤口的位置 |
| 给一次不体面的成功 | 他赢的方式有点难看，他自己知道 | 体面的失败常见，不体面的成功才真实 |

这六个动作里，第三个和第六个最有效。偷偷去看演出那一下，把“喜欢但不配”这个复杂心态写完了。赢得难看那一下，把“成功也要付账”写完了。

还有一个通用纪律：每个人物至少有一个他自己解释不了的举动。这个举动不要给理由，读者会替他找，找出来的理由一定比作者写的更贴合他自己的经验。
