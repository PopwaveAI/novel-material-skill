# 5.22 桥段失败的五种原因

> 素材来源：novel-material-skill ·《人性欲望创作手册》5.22 桥段失败的五种原因

写完一个桥段，读者没反应。五种常见原因，逐条排查。

### 原因一，压力不足

两难的两个选项，一个明显更好。读者会觉得人物在演。修正：让两个选项的代价对等，或者让较好的那个选项附带一个隐性损失。

### 原因二，读者不关心

桥段发生在一个人物身上，而这个人物前面没有铺垫。读者不知道他是谁，自然不会紧张。修正：桥段之前给这个人物两到三笔，让他有名字、有家人、有一个具体的难处。

### 原因三，反应错位

人物做了过大的反应，或者过小的反应。过大显得浮夸，过小显得冷漠。修正：反应要匹配他的性格与前史，而不是匹配场面的强度。

### 原因四，解释过多

桥段之后作者出来解释：他之所以这样，是因为……读者被打断，情绪断了。修正：把所有解释移到前面的铺垫里，桥段之后只留动作。

### 原因五，没有余波

桥段结束，下一章直接进新事件，没有余波。读者会觉得这一下白挨了。修正：给一到两段余波，写他事后怎么处理这件事的后遗症。

表 5-7　桥段失败的五种原因

| 原因 | 表现 | 修正动作 |
|---|---|---|
| 压力不足 | 选项不对等 | 让代价对等或加隐性损失 |
| 读者不关心 | 受害者无铺垫 | 桥段前给两三笔 |
| 反应错位 | 过大或过小 | 按性格与前史定反应 |
| 解释过多 | 作者出面说明 | 解释前移，后留动作 |
| 没有余波 | 下一章直接新事件 | 补一到两段后遗症 |

五种原因里，第二种最普遍，也最容易被忽略。作者以为读者会自动关心受害者，其实不会。一个没有名字的人在桥段里受损，读者的感受约等于零。给他一个名字、一个年纪、一件正在操心的事，桥段立刻成立。

还有一个技术细节：受害者的名字最好在桥段之前出现一次，在桥段里再出现一次。两次出现，读者就记住了。一次都不出现，他只是个符号。
