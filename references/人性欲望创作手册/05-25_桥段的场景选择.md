# 5.25 桥段的场景选择

> 素材来源：novel-material-skill ·《人性欲望创作手册》5.25 桥段的场景选择

同一场戏，放在不同的场景，效果完全不同。场景选择有三个依据。

### 依据一，公开还是私密

需要羞辱感的戏，放公开场合；需要坦白感的戏，放私密空间。判断方法：这场戏里的人物，希望被别人看见还是害怕被别人看见。

### 依据二，熟悉还是陌生

需要安全感的戏，放熟悉的地方（家里、办公室）；需要失衡感的戏，放陌生的地方（外地、医院、酒店大堂）。陌生环境会让人的防御降低。

### 依据三，能不能走

能走的地方，冲突容易中断；不能走的地方（车里、电梯、飞机上），冲突必须持续。前者适合写回避，后者适合写逼迫。

表 5-9　场景选择的三个依据

| 依据 | 选择 | 效果 |
|---|---|---|
| 公开私密 | 公开 | 羞辱感 |
| 公开私密 | 私密 | 坦白感 |
| 熟悉陌生 | 熟悉 | 安全感，防御低 |
| 熟悉陌生 | 陌生 | 失衡感，防御更低 |
| 能不能走 | 能走 | 回避 |
| 能不能走 | 不能走 | 逼迫 |

三个依据可以叠加。最有力的组合是“公开加不能走”：在众人面前，他无处可退。这种场面几乎必然产生重大转折。

场景选好之后，还有一个细节要处理：给场景一个声音。电梯的提示音、走廊的拖把声、小区的狗叫。声音一出现，场面就有了实地感。
