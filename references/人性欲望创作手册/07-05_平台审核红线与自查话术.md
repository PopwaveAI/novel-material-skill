# 7.5 平台审核红线与自查话术

> 素材来源：novel-material-skill ·《人性欲望创作手册》7.5 平台审核红线与自查话术

平台的审核逻辑通常分三层：关键词层、情节层、价值导向层。关键词层是机器扫，情节层是人工看，价值导向层是在被举报或推荐位审核时才重点看。三层都过，书才稳。

### 三层各自的应对

关键词层。不要用那些明确会被扫到的词，也不要用拼音、符号、谐音去绕。绕词在机器层可能通过,在人工层一定被记一笔。正确做法是换叙述角度，根本不出现那些词。

情节层。审核员看的是这一段整体在讲什么。如果一段情节的净效果是“展示越界”,就会被打回；净效果是“展示代价”,就安全。所以每段情节点都要能一句话说清它的净效果。

价值导向层。这一层看的是全书。主角最终的走向、有没有反方、有没有代价、有没有美化。这一层最容易被忽视，也最容易在推荐位审核时出事。

### 六个自查话术

写完一卷，用这六个句子过一遍。每一句都能答“是”，就基本安全。
- 这一段里，读者看见的是人的难受，还是事的刺激？
- 这一段如果被单独截图传播,会不会让人误会作品在鼓励什么？
- 这一段有没有给行为设置代价，哪怕只是暗示？
- 这一段里有没有一个角色，明确表达了不认同？
- 这一段有没有可模仿的操作细节？
- 这一段删掉之后，情节会不会垮？不会垮的部分，往往是风险最高的部分。

最后一句最有用。很多风险段落其实是“作者舍不得删的精彩段落”,删掉不影响情节，只影响作者的成就感。这类段落在审核端最容易出事，因为它们的存在理由就是展示。

### 被判定之后的处理顺序

如果某一章被驳回，不要整章重写。按这个顺序处理：先定位被驳的具体句段；再判断是关键词、情节还是导向问题；然后只改那一处，保留上下文；改完自己通读一遍，确认前后语气不断；最后记进自己的“雷点档案”,后面同类的写法直接绕开。

雷点档案是一个非常值得建的东西。每本书踩过的坑都记下来，写到第五本的时候，你已经知道哪些写法一定不能碰，创作效率会明显提高。
