# 9.19 空白模板：可直接抄用的四张表

> 素材来源：novel-material-skill ·《人性欲望创作手册》9.19 空白模板：可直接抄用的四张表

这一节给四张空白模板。写自己的书时，把表复印下来或者照抄一遍，填上自己的内容。模板的价值在于“结构已经对了，只剩填”。

### 模板一，人物欲望设定卡

模板 9-1　人物欲望设定卡

| 字段 | 填写要求 | 示例方向 |
|---|---|---|
| 姓名与身份 | 一句话说清他是谁 | 县医院护工，四十二岁 |
| 欲望标的 | 要什么，具体到数目或位置 | 凑够母亲手术的四万二 |
| 欲望强度 | 一到五 | 四 |
| 三条底线 | 每条标软硬 | 不害人（硬）、不牵连家人（硬）、不撒谎（软） |
| 羞耻点 | 他最怕被人知道什么 | 他曾在同事面前借过钱 |
| 外化动作 | 一个只属于他的小动作 | 把工牌反着戴 |
| 可变细节 | 这个细节后面会怎么变 | 从反着戴到不戴 |
| 结局位置 | 他最后站在哪里 | 新的科室门口 |

### 模板二，诱惑事件排布表

模板 9-2　诱惑事件排布表

| 章位 | 谁递的 | 递的是什么 | 他的反应 | 代价落在谁身上 |
|---|---|---|---|---|
|  |  |  | 拒绝 / 接受 / 半推半就 |  |

填写要点：五到七行为宜，太少不够推，太多读者疲劳。每一行的“代价落在谁身上”必须有具体人名，不能写“他自己”。

### 模板三，抉择节点计划表

模板 9-3　抉择节点计划表

| 节点 | 两个选项 | 各自的代价 | 伤的是谁 | 他的选择 | 事后的动作 |
|---|---|---|---|---|---|
| 第一次 |  |  |  |  |  |
| 第二次 |  |  |  |  |  |
| 最终 |  |  |  |  |  |

填写要点：三次抉择要一次比一次重，且最后一次的两个选项都要伤到同一个人。事后的动作一栏决定读者对他的最终判断，务必填。

### 模板四，伏笔追踪表

模板 9-4　伏笔追踪表

| 伏笔 | 埋设章位 | 读者以为的含义 | 真实含义 | 回收章位 | 回收后的效果 |
|---|---|---|---|---|---|

填写要点：“读者以为的含义”这一栏最重要，它是伏笔成立的前提。如果这一栏填不出来，说明这个伏笔没有悬念，只是一个信息。

四张模板填完，一本书的骨架就齐了。剩下的工作是写，而写之前你已经知道自己要写什么。这就是工具的意义：把不确定的东西固定在纸上，然后专心处理语言。
