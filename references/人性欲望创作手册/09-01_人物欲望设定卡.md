# 9.1 人物欲望设定卡

> 素材来源：novel-material-skill ·《人性欲望创作手册》9.1 人物欲望设定卡

这一部分没有理论，全是表。六张表分别管六件事：人物欲望怎么定、诱惑怎么排、底线怎么波动、抉择怎么排期、伏笔怎么追踪、成稿怎么自检。填完六张表，一本书的骨架就搭好了。

使用建议：把六张表打印出来，手填。手填比在电脑上填慢，但慢下来的过程就是在想。写完一本之后把这些表存档，下一本可以直接对照，会越来越快。

每张表后面都附了填写说明与常见错误。填写说明里的每一条都是被实际稿子验证过的，不是假设。

这是六张表里最重要的张。一个主要人物填一张，配角可以两三个人合用一张简化版。

表 9-1　人物欲望设定卡

| 字段 | 填写内容 | 示例（可直接替换） |
|---|---|---|
| 姓名与身份 | 一个具体的职业和一个具体的社会位置 | 县医院急诊科护士，编外，合同一年一签 |
| 核心欲望 | 他要的那个东西，带数量或名字 | 一份能转正的编制，以及一个能挂自己名字的房子 |
| 欲望的具体形状 | 他会在什么场景下想起这件事 | 每次发工资看见工资条上“临时”两个字的时候 |
| 原生诱因 | 少年时的一件事，能解释他现在的一个习惯 | 十八岁那年他母亲住院，他签不了字 |
| 硬底线 | 宁死不做的事 | 不动病人的救命药 |
| 软底线 | 会做但会难受的事 | 替主任写论文、替同事顶班、收家属的土特产 |
| 无底线区 | 他自己都没想到会做的事 | 为了编制，把一份对己方不利的检查报告压下来 |
| 羞耻点 | 最不愿被人看见的事 | 他其实是专科毕业，一直说是本科 |
| 外化动作 | 每个配置对应一个动作 | 被问学历时先笑一下，然后说“差不多” |
| 说话方式 | 句长、口头禅、回避什么 | 句子短，爱说“行”，被追问就重复对方的话 |
| 最怕的人 | 谁一句话能让他塌 | 他母亲 |
| 最想要的一句评价 | 他最希望谁说他什么 | 护士长说一句“你办事我放心” |

### 填写说明

第一，“核心欲望”必须写成可验证的事实。写“想要更好的生活”就是没填。要写“三年内转正、五年内买房”，这样后面才有具体的进度可以写。

第二，“欲望的具体形状”这一栏最容易被跳过，但它决定了这个欲望能不能写进正文。一个只有名字没有场景的欲望，读者感受不到。

第三，“无底线区”要写一件你作为作者都觉得有点过分的事。写得太客气，这一栏就没有用，因为真正的高潮就在这个区里。

第四，“最怕的人”和“最想要的一句评价”要互相配合。往往是同一个人既能让他塌，也能让他立。这种“一个人同时是软肋和奖赏”的结构，最好写。

### 常见错误

表 9-2　设定卡常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 欲望写成形容词 | 想要成功、渴望被爱 | 换成数量、名字、地点 |
| 底线没被撞过 | 填了但全书没有一次正面撞击 | 在第二卷安排一次撞线 |
| 所有字段都填了但互相不搭 | 欲望和羞耻点没有关系 | 让羞耻点成为欲望的反面 |
| 配角也填满十二栏 | 浪费时间 | 配角只填欲望、底线、外化动作三项 |
