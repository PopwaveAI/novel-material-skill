# 14.17 十四部分方法速览

> 素材来源：novel-material-skill ·《人性欲望创作手册》14.17 十四部分方法速览

这一张表把十四个部分的核心方法各压成一句。写作卡住的时候，先查这张表，再回原文。

表 14-9　十四部分方法速览

| 部分 | 一句方法 | 最容易犯的错 |
|---|---|---|
| 一 认知 | 先定欲望标的与底线，再谈性格 | 从形容词开始设计人物 |
| 二 人设 | 欲望有账，底线有硬度 | 人物只有标签没有账 |
| 三 开局 | 第一章给处境，不给冲突 | 简历式开场 |
| 四 节奏 | 八阶段按比例走，沉溺要写台阶 | 没有台阶，直接坠落 |
| 五 桥段 | 桥段靠动作，不靠情绪 | 选项不对等 |
| 六 工具箱 | 状态换成动作与时间 | 心理总结代替证据 |
| 七 合规 | 抽掉过程，留下前因与后果 | 用绕词代替换角度 |
| 八 追读 | 章末留一个未结算的问题 | 章末写总结 |
| 九 工具 | 表格不要一次填满 | 开书就填三百章 |
| 十 案例 | 给证据，不给结论 | 作者出来点评 |
| 十一 结局 | 给动作，不给道理 | 用宣言代替转变 |
| 十二 高阶 | 打碎预期，但要先埋够证据 | 为了反转而反转 |
| 十三 运营 | 内容做入口，作品做留存 | 宣传强度超过作品 |
| 十四 自检 | 分阶段只查该查的 | 用完结清单查开书稿 |

这张表的用法有两个。一是写前查，找到对应的一句话，照着做；二是写后查，看自己犯的是哪一行里的错。前者省时间，后者省返工。

十四个部分的顺序是有逻辑的：先想明白（一），再定人（二），再定开局（三），再排节奏（四），再备桥段（五），再练手艺（六），再守边界（七），再抓追读（八），再上工具（九），再看案例（十），再定结局（十一），再到高阶（十二），最后才是运营（十三）与自检（十四）。运营在最后，不是因为它不重要，是因为它不能替代前面的任何一步。
