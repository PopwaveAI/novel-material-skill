# 5.26 桥段的开头与结尾

> 素材来源：novel-material-skill ·《人性欲望创作手册》5.26 桥段的开头与结尾

桥段写得好不好，一半看中间，一半看两头。开头决定读者会不会投入，结尾决定这一下会不会留在他心里。

### 三种开头

开头一，直接进入动作。不铺垫，第一句就是一件正在发生的事。他推门、他坐下、他把东西放下。这种开头最有力，适合章首。

开头二，给一个反常的平静。先写日常，写得特别正常，正常到读者感到不安。“那天下午他给自己泡了一杯茶”，读者会立刻想：为什么这天要泡茶。

开头三，从别人的眼睛开始。先写旁观者看到的东西，再转入当事人。这种开头天然带着评判，也天然带着距离，适合写羞辱与背叛。

### 三种结尾

结尾一，停在一个动作上。他把杯子放下、他转身走了、他把灯关了。动作一停，读者的想象开始。

结尾二，停在一句没说完的话上。他说“其实我”，然后没有下文。这种结尾有风险，用多了会显得刻意，但用得准，效果极强。

结尾三，停在别人的反应上。写旁观者的一句话、一个眼神、一次沉默。这种结尾把判断交给了世界，比作者出面更有分量。

表 5-10　桥段的开头与结尾

| 位置 | 写法 | 适用 |
|---|---|---|
| 开头 | 直接进入动作 | 章首、紧张场面 |
| 开头 | 反常的平静 | 铺垫转折 |
| 开头 | 从别人眼里开始 | 羞辱、背叛 |
| 结尾 | 停在动作上 | 通用 |
| 结尾 | 停在半句话上 | 关键揭示 |
| 结尾 | 停在别人反应上 | 公开场合 |

两头都做对，中间怎么写都不会太差。两头做错，中间写得再用力，读者也记不住。这就是桥段的真正结构。
