# 11.7 结局回收清单

> 素材来源：novel-material-skill ·《人性欲望创作手册》11.7 结局回收清单

写到最后一章之前，拿这张清单逐条核对。漏一条，读者就会觉得有一件事没交代。

表 11-3　结局回收清单

| 回收项 | 检查内容 | 常见遗漏 |
|---|---|---|
| 欲望 | 他最初想要的那个东西，有没有明确交代结果 | 只交代了替代品，忘了原标的 |
| 代价 | 每一次越界的代价，有没有出现 | 中间某次越界没有结算 |
| 关系 | 重要关系的最终状态 | 配角线断了，没有交代 |
| 伏笔 | 所有标记为“待回收”的伏笔 | 小伏笔忘得最多 |
| 人物 | 每个主要人物的最后位置 | 配角集体消失 |
| 物件 | 反复出现的道具的最后归宿 | 信封、本子、钥匙没有交代 |
| 时间 | 故事结束在什么时间点 | 时间线模糊，读者算不清过了几年 |
| 空间 | 最后一个场景在哪 | 场景跳跃，读者没有落点 |

八项里最容易漏的是“物件”和“时间”。物件是读者的记忆锚，不交代会让人觉得少了什么；时间是读者的坐标，不交代会让人觉得故事没落地。这两项补起来很快，但漏了很显眼。
