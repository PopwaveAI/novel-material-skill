# 2.9 欲望底色与性格底线的冲突矩阵

> 素材来源：novel-material-skill ·《人性欲望创作手册》2.9 欲望底色与性格底线的冲突矩阵

把欲望和底线摆成一张表，人物关系立刻可以计算。横轴是欲望强度，纵轴是底线高度，四个象限对应四种完全不同的人物，也对应四种完全不同的故事走向。

表 2-3　人物四象限

| 象限 | 欲望强度 | 底线高度 | 人物形态 | 故事走向 | 读者感受 |
|---|---|---|---|---|---|
| A 强欲高线 | 极强 | 很高 | 悲壮型：想要，但绝不越界 | 求而不得，以代价换体面 | 敬重、心疼 |
| B 强欲低线 | 极强 | 很低 | 掠夺型：想要，且不在乎手段 | 一路向上，代价后置 | 紧张、刺激、隐隐不安 |
| C 弱欲高线 | 不强 | 很高 | 守护型：不争，但不让 | 被动卷入，被迫站队 | 安心、替他着急 |
| D 弱欲低线 | 不强 | 很低 | 随波型：谁给就跟谁走 | 被环境推着走，结局由他人决定 | 无奈、可怜、有时厌恶 |

这张表最实用的地方是配对。两个人放在一起，只看象限就知道他们会不会有戏。

表 2-4　六种人物配对及其张力

| 配对 | 关系本质 | 戏剧张力来源 | 适合的桥段 |
|---|---|---|---|
| A 与 B | 同一目标，两种手段 | A 的痛苦在于他也可以像 B 那样做 | 秘密交换、背叛博弈 |
| A 与 D | 拯救与被拖累 | A 一次次替 D 收拾，最后发现自己也在往下走 | 良知拉扯、抉择两难 |
| B 与 C | 掠夺与守护 | C 挡在 B 的路上，B 开始恨 C 的干净 | 诱惑试探、守底线 |
| B 与 B | 同类相食 | 谁先心软谁先死 | 背叛博弈、欲望兑现后空虚 |
| C 与 D | 强者与依附者 | C 想拉 D 一把，D 只想躺着 | 良知拉扯 |
| A 与 A | 同路不同心 | 互相欣赏又互相不能让步 | 抉择两难、忏悔与自审 |

矩阵还能用来诊断“人物不够立体”。如果一个角色在四个象限里来回跳，说明你没有给他定坐标；如果两个角色在同一象限且强度相同，说明你写重了，需要拉开差距。

进阶用法是让人物在故事里跨象限移动。A 型人物在巨大压力下短暂滑向 B，然后爬回来；D 型人物在某个时刻突然变成 C。跨象限的移动必须有一次明确的触发事件和一次不可逆的代价，否则读者会觉得人物性格不稳定。移动的具体刻度，详见 4.10 的心理密度控制。

### 把矩阵落到具体台词上

矩阵是抽象的，台词是具体的。同一句“这件事我不能做”，四个人说出来是四种意思：

A 型说：“这件事我不能做。”（他心里已经在算，如果做了会失去什么。）

B 型说：“这件事我不能做。”（他在试探你能给到什么价。）

C 型说：“这件事我不能做。”（他真的没想过要做。）

D 型说：“这件事我不能做。”（他在等你替他做。）

同一句话，四种潜台词。写人物时如果能这样设计台词，读者不用看设定就能分辨谁是谁。这种“同句不同心”的练法，比写人物小传有用得多。
