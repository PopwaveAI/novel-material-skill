# 13.2 定位：一句话说清这本书

> 素材来源：novel-material-skill ·《人性欲望创作手册》13.2 定位：一句话说清这本书

定位不是给作品分类，是给读者一个“我要不要点”的理由。一句话说不清，读者就不会点。

### 定位句的三段结构

结构：一个人 + 一个处境 + 一个两难。

例：一个县医院的编外护士，为了一个转正名额，替主任压下一份对病人不利的报告。

这句话里有身份、有具体的欲望、有道德代价。读者一看就知道这本书大概是什么味道，也知道自己会不会喜欢。

把这句话缩到十五个字以内，就是你的核心卖点。缩短的过程会逼你删掉所有不重要的东西，剩下的那个就是这本书的骨头。

### 定位的三种常见错误

错误一，用题材定位。“一本都市人性小说”。这不是定位，这是分类。读者不会因为分类点开一本书。

错误二，用情绪定位。“一本看完让你久久不能平静的书”。这是评价，不是内容。读者不信评价，只信具体。

错误三，用设定定位。“一个关于欲望与救赎的故事”。太抽象，读者脑子里没有画面。

正确做法永远是具体的：一个职业、一个数字、一件事。具体的定位句，读者能立刻判断“这本合不合我”。
