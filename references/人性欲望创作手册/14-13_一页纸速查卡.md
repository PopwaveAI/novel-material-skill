# 14.13 一页纸速查卡

> 素材来源：novel-material-skill ·《人性欲望创作手册》14.13 一页纸速查卡

这张卡可以打印出来贴在桌前。写作时不用读整本书，看这张卡就够。

表 14-8　一页纸速查卡

| 环节 | 一句话要点 | 反例 |
|---|---|---|
| 人物 | 欲望有账，底线有硬度 | 他很矛盾 |
| 开局 | 第一章给处境，不给冲突 | 那天下着雨 |
| 诱惑 | 留东西，不说话 | 我可以帮你 |
| 越界 | 第一次要小到可以否认 | 一上来就挪用巨款 |
| 代价 | 要给有名有姓的人 | 很多人都在议论 |
| 两难 | 两个选项伤害同一个人 | 一个明显更好 |
| 心理 | 状态换成动作与时间 | 他痛苦极了 |
| 对话 | 遮住说话人也能分辨 | 你好吗，我很好 |
| 章末 | 一个未结算的问题 | 他终于明白了 |
| 结局 | 给动作，不给总结 | 从此他学会了做人 |

十行对应十个最容易出错的环节。每写完一章，对着这十行看一眼，能挡住大部分基础问题。

这张卡的作用不是提高上限，是守住下限。上限靠天赋与积累，下限靠纪律。这本书里所有的方法，最终都是为了把下限抬高。
