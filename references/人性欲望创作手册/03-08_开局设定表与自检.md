# 3.8 开局设定表与自检

> 素材来源：novel-material-skill ·《人性欲望创作手册》3.8 开局设定表与自检

下面这张表建议每个新书都填一遍，填不出来的格子就是你要补的地方。

表 3-5　开局设定表

| 项目 | 填写内容 | 合格标准 |
|---|---|---|
| 核心缺口 | 他缺的那一样东西，具体到一个场景 | 能用一句话说清，且读者能想象 |
| 欲望标的 | 他要的具体物，带数量或名字 | 可量化、可失去 |
| 硬底线 | 他宁死不做的事 | 在一卷内会被正面撞击 |
| 软底线 | 他会做但会难受的事 | 第一次越线在第三章前 |
| 触发事件 | 让他忍不了的那件事 | 发生在场面上，有见证者 |
| 诱饵 | 谁递的、递了什么、为什么刚好 | 由人递出，后面要还 |
| 代价预告 | 越线之后会失去什么 | 在第一章就有暗示 |
| 读者钩子 | 第一章最后一句留下什么疑问 | 不解释，只呈现 |

### 五个自检问题

填完表，用五个问题过一遍。有一个答不上来，开局就需要改。
- 如果把他换成一个没有这个缺口的人，故事还成立吗？成立说明缺口是假的。
- 第一章里有没有一个具体的数字、日期或名字？没有说明还不够实。
- 触发事件有没有第三个人在场？没有说明还停在内心戏。
- 他第一次越界，读者能不能替他想出两个不越界的办法？想不出说明两难不成立。
- 第一章最后一句，读者会不会想知道下一句？不会说明钩子没挂上。
