# 7.6 灰度人物的安全写法对照

> 素材来源：novel-material-skill ·《人性欲望创作手册》7.6 灰度人物的安全写法对照

很多人以为写灰度人物风险高。实际上，写一个扁平的坏人才风险高，因为他没有复杂性，作品容易被判定为“宣扬恶”。灰度人物只要处理得当，反而是最安全的写法，因为他自带批判性。

### 六组安全对照

表 7-3　灰度人物的六组安全对照

| 危险写法 | 安全写法 |
|---|---|
| 他有苦衷，所以他的恶可以理解 | 他有苦衷，但他的恶仍然造成了伤害 |
| 他坏，但他很迷人 | 他坏，他的迷人正是他伤害别人的方式 |
| 所有人都不理解他，只有读者懂他 | 有人理解他，但那个人最后也离开了他 |
| 他的选择是环境逼的 | 环境逼他，他仍然有另一个选择，只是他没选 |
| 他最后悔了，所以一切被原谅 | 他悔了，但有些事已经无法弥补 |
| 他的对手更坏，所以他算好人 | 他的对手也复杂，两个人的错不在一个层面上 |

六组对照的共同逻辑是：保留复杂性，但保留责任。复杂性让作品有深度，责任让作品站得住。只保留复杂性，作品会变成替恶辩护；只保留责任，作品会变成道德说教。两者都要，才叫成熟的人性写作。

### 三个具体的安全技巧

技巧一，让伤害落到具体的日常里。不要写“很多人受到了影响”，要写“隔壁那家的孩子今年没能上学”。具体的伤害最能抵消抽象的辩护。

技巧二，让人物自己也说不出理由。他在辩解，辩到一半自己停了。这种“辩不下去”的瞬间，比任何批判都有力。

技巧三，给一个不原谅的人。全书保留一个拒绝原谅的角色，哪怕他很小的戏份。他的存在就是作品的道德锚点。
