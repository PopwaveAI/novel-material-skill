# 12.10 反套路的十个具体做法

> 素材来源：novel-material-skill ·《人性欲望创作手册》12.10 反套路的十个具体做法

反套路不是把结局反过来，是把读者的预期拆成两半：一半兑现，一半打碎。兑現让读者有安全感，打碎让读者有惊喜。下面十个做法，每一个都可以直接用在稿子里。

### 做法一，让主角第一次反抗成功

常规套路是主角第一次反抗失败。反过来：他成功了，但成功带来了更大的麻烦。成功之后的麻烦，比失败更让人心慌，因为他没有理由再退缩。

### 做法二，让反派说真话

常规套路是反派说谎、主角揭穿。反过来：反派说的全是真的，主角无法反驳，只能沉默。这一手能让读者重新审视整场冲突。

### 做法三，让受害者拒绝被拯救

常规套路是主角弥补，受害者感恩。反过来：受害者不需要他的弥补，甚至厌恶他的出现。这一笔会让救赎变得艰难，也更有分量。

### 做法四，让配角的判断是对的

常规套路是配角误会主角。反过来：配角早就看穿了他，而且判断准确。主角在读者面前被一个次要人物看透，这是最有效的羞耻。

### 做法五，让选择的结果不如预期

常规套路是选择之后立刻见分晓。反过来：他选了，然后过了很久什么都没发生。悬着的状态比结果更折磨人。

### 做法六，让最亲近的人先离开

常规套路是众叛亲离，最后家人还在。反过来：外人还在，家人先走了。因为家人看得最清楚，也最不能忍受。

### 做法七，让秘密不再是秘密

常规套路是秘密被揭露，主角崩塌。反过来：秘密早就被人知道了，只是没人说。他自以为藏得很好，其实所有人都在配合他演。这种荒诞感比揭露更狠。

### 做法八，让欲望实现之后变得更具体

常规套路是欲望实现之后空虚。反过来：欲望实现之后，他发现还需要更多，且更具体。空虚是文学，具体的贪婪是现实。

### 做法九，让结局早一点到

常规套路是最后一章才抉择。反过来：倒数第五章他就选了，剩下五章写选择之后怎么过。这种结构非常少见，也很有力量，因为读者会看到“选择之后”的真实。

### 做法十，让叙述者不可靠

常规套路是全知全能的叙述。反过来：让他的自述与事实有偏差，读者慢慢发现他在美化自己。这一手最适合第一人称的人性题材，但要求作者极其克制，不能提前提醒读者。

表 12-6　十种反套路的预期拆解

| 做法 | 打碎了什么预期 | 风险 |
|---|---|---|
| 第一次反抗成功 | 失败即挫折 | 成功来得太容易 |
| 反派说真话 | 反派必说谎 | 主角显得无力 |
| 受害者拒绝被救 | 弥补会被接受 | 读者觉得太苦 |
| 配角判断正确 | 配角必误会 | 主角显得可笑 |
| 结果延迟 | 选择立刻见效 | 读者等得不耐烦 |
| 家人先离开 | 家人永远在 | 需要足够铺垫 |
| 秘密早被知道 | 秘密被揭露 | 前面要留线索 |
| 欲望变得更具体 | 实现即空虚 | 容易写成贪得无厌 |
| 结局提前到 | 最后一章抉择 | 后半段必须有料 |
| 叙述者不可靠 | 叙述是真实的 | 读者可能反感 |

十个做法里，最稳妥的是第五个与第七个。前者只需要调整节奏，后者只需要在前文留两处线索。最冒险的是第十个，因为读者一旦觉得自己被骗，会直接弃书。
