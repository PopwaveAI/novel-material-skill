# 掉马创作手册 1.0 版

### 目录

### 第一部分：掉马底层框架（全书锚点）

1.1 掉马的核心魅力：信息差、反转感、被看穿的紧张与被认出的释放

第一，信息差：读者先知道，角色后知道，制造期待

第二，反转感：身份一翻，之前所有的细节被重新解读

第三，紧张感：马甲随时可能掉，每一次险些暴露都是看点

第四，释放感：掉马瞬间的震惊、尴尬与爽感

1.2 掉马五要素：马甲身份、保密理由、暴露风险、掉马契机、掉马后果

第一，马甲身份：他（她）隐藏的是什么身份

第二，保密理由：为什么必须瞒，瞒不住会怎样

第三，暴露风险：谁最可能发现，线索埋在哪里

第四，掉马契机：什么事件让马甲掉落

第五，掉马后果：关系、剧情、人设发生什么变化

1.3 掉马三阶段：藏马 → 险掉 → 全掉

藏马：铺设马甲，留下可回收的细节

险掉：一次次差点暴露，拉高期待

全掉：掉马名场面与余波

1.4 掉马与信息差的三种模式：读者知情角色不知、读者与角色同步揭晓、读者先被骗后反转

1.5 东亚读者最吃的掉马诉求：身份反差、被偏爱的真相、打脸与反转、掉马后的修罗场

1.6 题材适配：古言、现言、仙侠、悬疑、娱乐圈、末世的掉马差异

1.7 与其他手册的互挂：男主人设手册、女主人设手册、CP 设定手册、先婚后爱创作手册、悬疑题材创作手册

### 第二部分：马甲身份设定库（核心卖点）

每个马甲统一模板：马甲名称 → 适配题材 → 保密理由 → 可埋的线索 → 经典桥段 → 避雷

2.1 身份反差型

低调背后的大佬：普通人背后是首富、权臣、宗主

保密理由：避免麻烦、保护家人、考验人心

可埋线索：一闪而过的特殊习惯、不合身份的见识

避雷：反差只靠标签，没有铺垫

2.2 职业马甲型

神秘职业：神医、杀手、情报官、顶流、黑客、仵作

保密理由：职业本身需要隐藏

可埋线索：专业技能的无意流露

2.3 性别与外貌伪装型

女扮男装、男扮女装、易容、改名换姓

经典张力：被发现的瞬间、被识破的细节

避雷：伪装漏洞太大，周围人集体迟钝

2.4 阵营卧底型

卧底、间谍、线人、双面身份

保密理由：任务、复仇、保护

经典张力：身份对立下的感情撕扯

2.5 隐藏血脉与出身型

真千金、流落皇子、隐世后人、被换走的孩子

可埋线索：信物、胎记、旧事

2.6 双重人格与双面人设型

白天与夜晚、人前与人后、表人格与里人格

2.7 网络与现实身份型

网友即同事、神秘大神即身边人、匿名身份

2.8 拓展类型：重生者、穿越者、系统宿主、前世记忆持有者

2.9 马甲组合与融合：身份反差+职业、卧底+血脉、女扮男装+权谋……

### 第三部分：掉马契机与方式库

3.1 主动掉马：自己选择坦白的五种场景

为救人而暴露、为表真心而摊牌、为反击而亮身份、被逼到绝路、时机成熟的主动揭晓

3.2 被动掉马：被意外发现的五种方式

撞见现场、被信物认出、被他人揭穿、被技能暴露、被熟人认出

3.3 被对手揭穿：反派拿马甲做文章

3.4 被第三方偶然拆穿：路人、配角、系统提示

3.5 渐进式掉马：线索一点点拼凑，对方早已知情

3.6 反向掉马：对方早知道，只是一直陪着演

3.7 集体掉马：全员在同一场景下发现真相

3.8 掉马的时机选择：开篇、中段、高潮、结局四个位置的利弊

### 第四部分：线索铺设与险掉设计

4.1 线索的类型：外貌细节、习惯动作、专业技能、随身物件、说话习惯

4.2 线索的隐藏方式：混入日常、借他人之口解释、反复出现但不被注意

4.3 险掉梗清单（每条含场景、写法、化解方式）

被人追问、差点被撞见、物件掉落、被熟人叫住、被试探

4.4 圆谎技巧：怎么让谎言看起来合理又留下破绽

4.5 他人的怀疑线：谁在怀疑、怀疑到哪一步、为什么不戳穿

4.6 读者先知的铺垫：给读者看一眼，又不让角色看见

4.7 线索回收：掉马时回扣前文所有伏笔
