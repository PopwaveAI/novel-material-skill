# 网文细节描写词库 1.0 版

> 素材来源：novel-material-skill ·《网文细节描写词库（雏形）》网文细节描写词库 1.0 版

### 目录

### 第一部分：细节描写底层框架（全书锚点）

1.1 细节描写的三个作用：塑造人物、传递情绪、推动剧情

第一，塑造人物：同一个情绪，不同的人用不同的动作表达

第二，传递情绪：不直接说情绪，让读者从细节里读出来

第三，推动剧情：细节里藏伏笔、藏信息、藏潜台词

1.2 “写结果”与“写过程”：为什么“哽咽”是结果，不是过程

结果词：愣住、哽咽、愤怒、紧张，只告诉读者发生了什么

过程拆解：生理反应、动作变化、视线变化、语言变化、环境反应

从结果词到过程的改写方法（附改写样例）

1.3 细节描写五感框架：视觉、听觉、触觉、嗅觉、味觉

1.4 细节密度控制：哪里该细、哪里该略、一场戏放几个细节

1.5 细节与人设绑定：同一动作，换一个人写法就不同（挂男主、女主人设手册）

1.6 词库使用方法：怎么查、怎么改、怎么避免用成模板

### 第二部分：微表情词库（核心卖点）

每个条目统一模板：表情名称 → 对应情绪 → 具体写法（3~5 种）→ 适用人设 → 适用场景 → 避雷

2.1 眼部微表情

视线：躲闪、回避、直视、停留、扫过、下移、上抬

眼睑与睫毛：眨眼频率、垂眸、睫毛颤动、眼睑发红

瞳孔与眼神：骤缩、放空、聚焦、失焦、眼底的光

眼眶与眼泪：泛红、含泪、泪不落、泪滑落的不同写法

2.2 眉部微表情：蹙眉、挑眉、眉心跳动、眉梢变化、眉头松开

2.3 嘴部微表情

嘴角：上扬、下压、抽动、僵住、勉强

嘴唇：抿唇、咬唇、唇色发白、舔唇、微张

笑的细分：冷笑、苦笑、讥笑、轻笑、失笑、假笑、笑意不达眼底

2.4 面部整体微表情：脸色变化、肌肉紧绷、面无表情的细分

2.5 喉结、下颌与颈部：吞咽、绷紧、青筋、喉间滚动

2.6 口是心非的微表情：嘴上说不、身体说是的写法

2.7 微表情与谎言：说谎时的破绽、伪装的破绽、被识破的瞬间

2.8 微表情避雷：表情堆砌、千篇一律、情绪与表情不匹配

### 第三部分：情绪动作词库

3.1 愤怒怎么写

第一，爆发型愤怒：摔、砸、吼、拍桌、失控

第二，压抑型愤怒：沉默、指节发白、声音压低、笑

第三，冷静型愤怒：语速变慢、措辞变客气、眼神变冷

第四，愤怒的生理反应：呼吸、脸色、青筋、颤抖

第五，愤怒的收尾：爆发后的空白、后悔、僵持

3.2 傲慢怎么写

视线与姿态：下巴、眼尾、俯视、不看人

语气与措辞：轻描淡写、居高临下、不屑解释

对他人的忽视方式：不抬头、打断、替别人做决定

傲慢被打破的瞬间（挂男主人设手册 3.1）

3.3 愣怎么个愣法：愣住的十种写法

大脑空白型、不敢相信型、反应迟钝型、被戳中型、受惊型、意外型、失神型、装愣型、愣后回神型、愣到失态型

愣的持续时间与回神的方式

3.4 哽咽与哭泣

哽咽的过程写法：喉咙、声音、呼吸、停顿、说不完的话

哭的细分：无声流泪、崩溃大哭、忍着不哭、笑着哭、哭到失语

哭之后：眼睛、声音、动作、环境

3.5 紧张与不安：手、呼吸、出汗、小动作、坐立难安

3.6 羞涩与心动：脸红、耳尖、躲闪、手足无措、心跳

3.7 悲伤与绝望：麻木、失语、动作变慢、世界变安静

3.8 恐惧与惊吓：僵住、后退、发抖、屏息、冷汗

3.9 嫉妒与吃醋：不同人设的吃醋反应（挂 CP 设定手册 5.3）

3.10 窒息感与压迫感：呼吸、空间、沉默、时间变慢（挂情绪与悲剧叙事手册）

3.11 隐忍与克制：忍的方式、忍到极限的破绽

3.12 情绪转折：从一种情绪切到另一种情绪的过渡写法

### 第四部分：疼痛与身体感受词库

4.1 写疼痛要具体：疼痛的五个维度

第一，位置：哪里疼，从哪里蔓延到哪里

第二，性质：刺痛、钝痛、灼痛、绞痛、闷痛、撕裂痛

第三，强度：从“忍得住”到“失去意识”的梯度

第四，时间：一阵一阵、持续、突然、后劲

第五，伴随反应：冷汗、发抖、视线模糊、耳鸣、呼吸变化

4.2 外伤疼痛：刀伤、箭伤、鞭伤、烧伤、骨折、擦伤

4.3 内伤与病痛：胸闷、胃痛、头痛、发热、咳血、中毒

4.4 心痛的身体化写法：心口、胸腔、喉咙、四肢、麻木感

4.5 疲惫、饥饿、寒冷、炎热等身体感受

4.6 受伤后的处理细节：包扎、止血、忍耐、强撑、示弱

4.7 疼痛避雷：写得太夸张、不符合伤情、主角受伤后无后遗

### 第五部分：动作与小动作词库

5.1 日常小动作写性格：不靠台词写活角色

习惯性动作：转笔、摩挲指节、敲桌、整理袖口、捻佛珠

下意识动作：说谎时、紧张时、思考时、被戳中时

动作与性格对照表：不同人设对应的典型小动作

5.2 漫不经心怎么写

姿态：懒散、倚靠、半垂眼、随手

语气：轻描淡写、拖长、随意

动作：漫不经心地做重要的事、重要的事做得像随手

漫不经心里的认真：反差的设计

5.3 走、坐、站、躺的姿态词库：不同身份、性格的姿态区别

5.4 手部动作词库：握、攥、抚、按、拢、叩、颤

5.5 眼神动作词库：看、瞥、扫、盯、望、睨、觑、窥的区别

5.6 说话方式词库：语气、停顿、语速、音量、口头禅

5.7 亲密动作词库：靠近、触碰、牵手、拥抱、停留（挂 CP 设定手册 5.2）

5.8 打斗与对抗动作：出手前、交手中、收手后的细节

5.9 群戏动作调度：多人同场时，每个人的动作与站位

### 第六部分：替代词库（告别“然后”“突然”）

6.1 为什么要替换：高频词让文字变平

6.2 “然后”的替代

顺承：随即、旋即、接着、转而、紧接着、片刻后、不多时

转折与停顿：顿了顿、沉默片刻、隔了半晌

省略法：直接用动作衔接，不写连接词

6.3 “突然”的替代

骤然、倏地、猛地、陡然、忽而、乍然、冷不防

用动作写突然：不写“突然”，写出突然发生的事

6.4 “看”“说”“走”“笑”“哭”的替代词库

6.5 “好看”“漂亮”“帅”的替代（挂男主、女主人设手册：外貌盘点）

6.6 “很”“非常”“特别”等程度词的替代

6.7 “眉眼”不要只会写“好看”

按人设分类的眉眼表达库（挂男主、女主人设手册 4.1）

6.8 替代词避雷：生僻词堆砌、风格不统一、替换后意思变了
