# 5.19 桥段的替换表

> 素材来源：novel-material-skill ·《先婚后爱创作手册》5.19 桥段的替换表

同一个功能，可以换不同的桥段。这张表给出二十种功能对应的替代选择，避免全书重复。

表：功能与替代桥段

| 功能 | 首选桥段 | 替代一 | 替代二 |
|---|---|---|---|
| 表现照顾 | 煮汤 | 修好旧物 | 把伞放进包里 |
| 表现在意 | 问一句「吃了吗」 | 记住偏好 | 多买一份 |
| 表现吃醋 | 问「他为什么送你回来」 | 把对方的东西放回原处 | 沉默一整晚 |
| 表现试探 | 问「你为什么嫁给我」 | 故意提起旧人 | 碰一下对方的手 |
| 表现退让 | 把位子让出来 | 先道歉 | 改口叫名字 |
| 表现失控 | 提高声音 | 摔了东西 | 说了不该说的话 |
| 表现温柔 | 替对方盖上被子 | 关掉刺眼的灯 | 把水温调好 |
| 表现距离 | 分桌吃饭 | 错开作息 | 不接电话 |
| 表现靠近 | 共伞 | 同坐一排 | 递一杯水 |
| 表现秘密 | 藏起一份文件 | 换掉一张照片 | 半夜接电话 |
| 表现危机 | 有人受伤 | 钱断了 | 身份被揭穿 |
| 表现和解 | 一起做饭 | 一起收拾 | 把旧账翻篇 |
| 表现承诺 | 说「下次我来」 | 把钥匙给出 | 留出一格衣柜 |
| 表现背叛 | 隐瞒一次 | 替别人做决定 | 在关键时刻缺席 |
| 表现守护 | 挡在前面 | 替对方承担 | 连夜赶回来 |
| 表现疏远 | 改称呼 | 换房间 | 不再等 |
| 表现羞耻 | 被当众纠正 | 穿错衣服 | 说错话被笑 |
| 表现依赖 | 生病 | 受伤 | 喝醉 |
| 表现释然 | 笑出来 | 叹一口气 | 把话说开 |
| 表现余味 | 留一盏灯 | 留下旧物 | 一句未说完的话 |

实务提醒：全书同一功能最多用三次。第四次一定要换替代项，否则读者会先于人物察觉重复。
