# 14.6 合规与价值观层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.6 合规与价值观层自检

表：合规与价值观层（十五项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| C01 | 是否涉政敏感 | 无政治议题、无现实影射 | 必删 |
| C02 | 是否涉黄低俗 | 无具体性描写、无低俗词 | 必删 |
| C03 | 是否涉暴细节 | 无可操作手法、无详细伤害 | 虚化 |
| C04 | 是否涉未成年 | 未成年人无情感线 | 必删 |
| C05 | 是否影射真实人物 | 无真实可识别信息 | 改名改设定 |
| C06 | 是否宣扬迷信 | 无可操作方式 | 改为文化背景 |
| C07 | 是否涉诈骗赌博 | 无流程细节 | 必删 |
| C08 | 是否有婚内越界 | 主角无实质出轨 | 改为误会并澄清 |
| C09 | 是否有性别刻板 | 无绝对化性别判断 | 改为个人选择 |
| C10 | 是否有地域群体标签 | 行为归因于个人 | 改写归因 |
| C11 | 是否美化控制 | 控制行为有代价 | 补代价 |
| C12 | 是否道德绑架式和解 | 受害者有表达权 | 重写和解 |
| C13 | 是否美化违法 | 违法行为有后果 | 补后果 |
| C14 | 是否专业细节失实 | 医疗法律金融已虚化 | 虚化处理 |
| C15 | 是否符合目标平台规则 | 按平台标准自查过 | 按平台调整 |
