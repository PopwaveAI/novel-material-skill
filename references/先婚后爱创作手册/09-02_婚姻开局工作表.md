# 9.2 婚姻开局工作表

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.2 婚姻开局工作表

开局工作表用来把前三章拆到可执行的颗粒度。填完之后，前三章基本可以直接写。

表：开局工作表

| 项目 | 填写内容 | 检查点 |
|---|---|---|
| 契机的类型 | 期限、交换、意外、责任、制度中的哪一种 | 是否够急够硬够私人 |
| 契机的具体理由 | 写清日期、金额、后果 | 能否一句话说清 |
| 阻力来自谁 | 具体的人或机构 | 阻力是否有自洽立场 |
| 婚礼或领证的形式 | 民政局、拜堂、宴席、签字、代嫁 | 是否有四个有效镜头 |
| 仪式中的不配合细节 | 一个具体的小失误 | 是否被注意到但没被揭穿 |
| 同居空间格局 | 一墙之隔、一屋两制、主客倒置等 | 是否有明确的规则归属 |
| 特殊物件 | 灯、杯子、钥匙、旧衣 | 是否有三种状态变化 |
| 协议条款 | 五到八条，含一条模糊条款 | 模糊条款是否留了缝隙 |
| 初始立场 | 两人各占哪一档 | 是否一冷一热一进一退 |
| 初始误判 | 两人各自的错误判断 | 是否有文本依据 |
| 第三章钩子 | 一个不对劲的细节 | 读者是否能记住 |
| 前三角色出场 | 谁在第几章出现 | 是否有角色迟到或缺席 |

填这张表最容易漏的是「阻力来自谁」。很多开局只有一个抽象的「家族压力」，没有具体的人。压力一旦没有面孔，读者就感觉不到它的重量。
