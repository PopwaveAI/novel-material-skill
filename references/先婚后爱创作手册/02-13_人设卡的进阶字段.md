# 2.13 人设卡的进阶字段

> 素材来源：novel-material-skill ·《先婚后爱创作手册》2.13 人设卡的进阶字段

基础人设卡之外，还有五个进阶字段。填了这五个，人物的行为会更难预测，也更有说服力。

表：五个进阶字段

| 字段 | 填写问题 | 用途 |
|---|---|---|
| 道德弹性 | 他在什么情况下会破例 | 决定关键选择 |
| 金钱观 | 他如何花钱，为什么 | 制造日常冲突 |
| 权力观 | 他如何看待支配与被支配 | 决定关系边界 |
| 羞耻点 | 什么事会让他难堪 | 制造失控瞬间 |
| 补偿心理 | 他会为什么过度补偿 | 解释反常行为 |

道德弹性　写明人物在什么条件下会破例，决定关键时刻的选择。

要点：要具体到条件，比如「涉及家人时可以撒谎」

落笔：破例后要有代价

分寸：不要写成没有底线。

示例：「对外人我可以不算话。对她，我说过的都算。」

避坑：道德弹性写成随时可以背信，人物没有可信度。

羞耻点　写明让人物难堪的事，制造合理的失控瞬间。

要点：羞耻点要小而具体，比如被当众纠正发音

落笔：失控要短

分寸：事后要有一段时间的回避。

示例：有人笑他念错了一个字。他笑了笑，那顿饭之后再没说过话。

避坑：羞耻点过于沉重，比如童年创伤被当众揭开，冲突升级过快。

实务提醒：进阶字段不必全填，填两三个就够。填太多，人物会变得复杂到无法行动，写起来反而束手束脚。
