# 9.1 CP 设定卡

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.1 CP 设定卡

前面八章讲的是判断，这一章给的是表格。所有表格都设计成可以直接打印填写的格式，字段不多，但每一个字段都必须填。填不满的格子，就是故事还没想清楚的地方。

建议的使用顺序是：先填 CP 设定卡，再填婚姻开局工作表，然后排感情节点，接着排冲突事件，动笔之后每十章过一遍剧情自检表。五张表走完，一本书的骨架就立住了。

CP 设定卡分四张：男主卡、女主卡、关系卡、配角卡。前三张是必填，第四张可以简填。每张卡都控制在一页以内，超过一页说明设定过载。

### ◆ 9.1.1 男主设定卡

表：男主设定卡（可打印填写）

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 姓名与称呼 | 全名、常用称呼、她对他的称呼变化 | 沈砚；沈先生；砚哥（后期） |
| 年龄与职业 | 具体职业，不写「总裁」这类笼统词 | 三十二岁，家族企业并购负责人 |
| 模板归属 | 对应第二章的哪一款，最多两款 | 冷面掌权者为主，隐忍旧伤为辅 |
| 核心诉求 | 这段婚姻里他最想守住什么 | 守住父亲留下的公司控制权 |
| 核心恐惧 | 最怕被看见什么 | 怕被看见自己撑不住 |
| 动心开关 | 什么事会让他动摇 | 她在他定的规矩之外活得好 |
| 生活短板 | 一个具体的、反复出现的弱点 | 不会做饭，闻不得油烟 |
| 标志动作 | 三次以上可重复的动作 | 思考时用指节敲桌面两下 |
| 台词腔调 | 句长、用词、口癖 | 短句，少用形容词，习惯用反问 |
| 秘密 | 关于过去、身份或动机 | 三年前那场并购，他做过一次不干净的决定 |
| 崩坏预警 | 最容易被写坏的地方 | 把掌控写成剥夺 |
| 成长终点 | 结尾时他变成什么样 | 从管理一切到允许失控 |

填写这张卡有三个纪律。第一，职业要具体，写到能想出他一天在做什么的程度。第二，生活短板必须小，小到可以反复出现，比如怕烫、挑食、认床。第三，成长终点要能一句话说完，说不完就是没有弧光。

### ◆ 9.1.2 女主设定卡

表：女主设定卡（可打印填写）

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 姓名与称呼 | 全名、常用称呼、她对他的称呼变化 | 温迟；温小姐；迟迟（后期） |
| 年龄与职业 | 具体职业与工作内容 | 二十九岁，独立记账与税务顾问 |
| 模板归属 | 对应第二章的哪一款 | 清醒务实型为主，温软有骨为辅 |
| 核心诉求 | 她自己要什么，与婚姻无关 | 把母亲留下的那间小店盘回来 |
| 核心恐惧 | 最怕失去什么 | 怕再一次被人替她做决定 |
| 独立线 | 一条不依赖男主的收入或事业 | 接单、跑客户、处理税务申报 |
| 底线 | 绝不能让步的三件事 | 不辞职、不搬离小店所在城区、不隐瞒债务 |
| 动心开关 | 什么事会让她动摇 | 有人认真听完她算的账 |
| 生活细节 | 一个反复出现的小习惯 | 记账用铅笔，写完再描一遍 |
| 台词腔调 | 句长、用词、口癖 | 直给，习惯先给结论再解释 |
| 秘密 | 她隐瞒的事 | 替嫁过，或者替人签过一份担保 |
| 崩坏预警 | 最容易被写坏的地方 | 写成只会算账的冷机器 |
| 成长终点 | 结尾时她变成什么样 | 从守住自己到愿意共享 |

女主的卡里，「独立线」和「底线」是最重要的两栏。独立线保证她不依附，底线保证她有冲突的资格。两栏都填不出来，说明这个女主还没有站起来。

### ◆ 9.1.3 关系设定卡

表：关系设定卡（可打印填写）

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 锁 | 这段婚姻为什么非结不可 | 她替人签的担保爆了，只有结婚能保住店 |
| 钥匙 | 他们最后靠什么走近 | 共同把一笔烂账查清楚 |
| 初始立场 | 两人各占抗拒、将就、利用、期待中的哪一档 | 他利用，她将就 |
| 初始误判 | 两人对彼此的错误判断 | 他以为她贪钱，她以为他冷血 |
| 冲突主轴 | 贯穿全书的一条矛盾 | 信任与控制的拉扯 |
| 次要冲突 | 两条支线矛盾 | 家族压力、旧账追查 |
| 配型强度 | 低、中、中高、高、极高 | 高 |
| 推进节奏 | 六阶段的章节分配 | 12、24、24、18、24、18 |
| 名场面清单 | 计划中的五个高光点 | 领证、雨夜、挡酒、摊牌、重签协议 |
| 结局类型 | 圆满、轻现实、开放 | 轻现实向圆满 |

关系卡的核心是「锁」与「钥匙」两栏。锁决定开局的可信度，钥匙决定结局的合理性。两栏必须能互相呼应：钥匙要正好能打开那把锁，而不是另一把。

### ◆ 9.1.4 配角设定卡

表：配角设定卡（每个配角一张，可简填）

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 姓名与身份 | 与主角的关系 | 沈家二叔，家族董事会成员 |
| 功能 | 施压、助攻、对照、反衬中的哪一种 | 施压，兼信息源 |
| 立场 | 他自己认为正当的理由 | 公司不能交给一个外人 |
| 与主角的接口 | 在哪个场景与主角产生交集 | 董事会、家宴、医院 |
| 退场方式 | 如何离开故事 | 失去董事席位，转为中立 |
| 记忆点 | 一个动作或一句话 | 说话前先敲两下桌子 |
