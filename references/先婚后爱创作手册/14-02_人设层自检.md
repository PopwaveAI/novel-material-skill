# 14.2 人设层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.2 人设层自检

表：人设层（二十项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| P01 | 男主是否有不肯交出的东西 | 有具体往事、忌讳、习惯 | 补一项具体秘密 |
| P02 | 男主是否有维持婚姻的理由 | 理由能自我说服 | 重写动机 |
| P03 | 男主是否有生活短板 | 短板具体且反复出现 | 补一个笨拙细节 |
| P04 | 女主是否有独立线 | 婚姻之外有收入或事业 | 补独立线 |
| P05 | 女主是否有底线 | 三件绝不让步的事 | 补底线 |
| P06 | 女主是否有主动行为 | 每卷至少一次改变局势 | 补主动选择 |
| P07 | 两人是否一冷一热 | 初始立场分属不同档 | 调整档位 |
| P08 | 两人是否各有误判 | 各有一处对彼此的错误判断 | 补误判 |
| P09 | 人设是否前后一致 | 无突然黑化或突变 | 补铺垫 |
| P10 | 人设是否与行为匹配 | 每个关键行为符合人设卡 | 改行为或改卡 |
| P11 | 配角是否各有功能 | 每个配角能说出一种功能 | 删或合并 |
| P12 | 配角是否越位 | 未替主角完成关键决定 | 把决定还给主角 |
| P13 | 反派是否有逻辑 | 目标自洽且成功过一次 | 重写反派动机 |
| P14 | 情敌是否够强 | 至少在一件事上强过主角 | 加强情敌 |
| P15 | 长辈是否有面孔 | 压力来自具体的人 | 具名化 |
| P16 | 人物称呼是否随关系变化 | 至少三次变化 | 补称呼线 |
| P17 | 人物是否有标志动作 | 主要人物各有一个 | 补动作 |
| P18 | 人物是否有台词腔调差异 | 遮住名字能分辨说话人 | 重写台词 |
| P19 | 人物是否只有标签 | 每个标签都有行为证据 | 补行为 |
| P20 | 人物成长是否有痕迹 | 结尾与开篇有具体不同 | 补成长节点 |
