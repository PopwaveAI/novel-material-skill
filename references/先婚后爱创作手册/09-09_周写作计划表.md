# 9.9 周写作计划表

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.9 周写作计划表

写作需要计划，但不是每天定字数目标那种计划。周计划的作用是「在动笔前排好这一周的戏」，避免写到周三才发现没有事件。

表：周写作计划表

| 日期 | 章节 | 事件 | 需要查的资料 | 预计字数 | 完成情况 |
|---|---|---|---|---|---|
| 周一 | 01 至 02 | 领证 | 民政局流程 | 5000 | 已写 |
| 周二 | 03 至 04 | 搬家，分房 | 户型常识 | 5000 | 已写 |
| 周三 | 05 | 第一次早餐 | 无 | 2500 | 已写 |
| 周四 | 06 | 家族宴席 | 宴席座次 | 2500 | 待写 |
| 周五 | 07 | 宴席上的失误 | 称谓习惯 | 2500 | 待写 |
| 周六 | 08 | 独处，各怀心事 | 无 | 2500 | 待写 |
| 周日 | 复盘与调整 | 无 | 无 | 无 | 待复盘 |

这张表的用法是「周日晚复盘」。复盘只回答三个问题：这一周有没有推进？有没有一章是水章？下周的事件够不够？三个问题答完，下周的计划就出来了。
