# 7.12 配角与冲突的雷区

> 素材来源：novel-material-skill ·《先婚后爱创作手册》7.12 配角与冲突的雷区

主角的雷区前面列过了，配角与冲突也有自己的雷。这一类雷不太引人注意，但会拉低整本书的质感。

表：配角与冲突的十二个雷区

| 编号 | 雷区 | 表现 | 修法 |
|---|---|---|---|
| G01 | 配角工具化 | 只负责传话与尖叫 | 给一件自己的事 |
| G02 | 长辈脸谱化 | 只会摔杯骂人 | 给一个自洽立场 |
| G03 | 情敌降智 | 手段下作且无效 | 让她真赢一次 |
| G04 | 反派乱开挂 | 资源凭空出现 | 给资源来源 |
| G05 | 冲突靠巧合 | 每次都恰好被听见 | 提前埋伏笔 |
| G06 | 冲突靠天气 | 每次下雨就出事 | 换成人物的选择 |
| G07 | 冲突无代价 | 吵完就好了 | 补一个真实损失 |
| G08 | 冲突重复 | 同类冲突三次以上 | 合并为一次递进 |
| G09 | 全员误会 | 所有人同时误解 | 只让一个人误解 |
| G10 | 配角抢主线 | 配角篇幅超过三成 | 削减支线 |
| G11 | 群像无差异 | 所有人说话一样 | 给每人一个腔调 |
| G12 | 反派临阵倒戈 | 最后一刻良心发现 | 提前埋动机 |

情敌要真赢一次　让情敌在一件事上真正胜出，提升威胁的可信度。

要点：胜出要在具体事务上，比如一次谈判

落笔：主角要因此真实受损

分寸：胜出后情敌不能立即作恶。

示例：那一单她拿走了。他在会议室里坐了很久，才把笔放下。

避坑：情敌永远输，主角的胜利变得廉价。

冲突要有代价　每一次冲突都要留下真实的损失。

要点：损失要具体，比如一笔钱、一次机会、一段关系

落笔：损失要有人承认

分寸：不要用「后来都解决了」抹平。

示例：那间店最后还是没保住。她把牌子摘下来，抱回家。

避坑：冲突结束得像没发生过，读者不会紧张。
