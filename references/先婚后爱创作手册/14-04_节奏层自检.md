# 14.4 节奏层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.4 节奏层自检

表：节奏层（二十项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| R01 | 阶段进度与章数是否匹配 | 无长期停滞 | 合并事件 |
| R02 | 刻度是否单调上升 | 无连续五章不升 | 补推进 |
| R03 | 是否有抢跑 | 前三章无心动直写 | 后移心动 |
| R04 | 是否有拖沓 | 连续五章无阶段推进即为拖 | 砍重复桥段 |
| R05 | 是否有反复 | 同一矛盾不重复三次以上 | 合并为一次 |
| R06 | 是否有断裂 | 相邻两章情绪不跳档 | 补过渡 |
| R07 | 双线是否咬合 | 删掉支线主线会受影响 | 重接支线 |
| R08 | 是否有喘息章 | 每次大冲突后有一章缓冲 | 补缓冲 |
| R09 | 虐段是否过密 | 连续虐不超过三章 | 插日常 |
| R10 | 甜段是否过密 | 每五章至少一段纯日常 | 减糖 |
| R11 | 每章是否有事件 | 每章有一件发生的事 | 补事件 |
| R12 | 每章是否有变化 | 章首与章末关系状态不同 | 补变化 |
| R13 | 是否有原地打转 | 无三章内容可合并 | 合并 |
| R14 | 高潮是否分布均匀 | 每二十章至少一个中型高潮 | 补高潮 |
| R15 | 是否有强钩子 | 每三章至少一个强钩子 | 重写章末 |
| R16 | 钩子类型是否轮换 | 未连续三章同类型 | 换类型 |
| R17 | 日常是否具体 | 每场日常有具体物件 | 补物件 |
| R18 | 冲突是否有代价 | 每次冲突有可见损失 | 补代价 |
| R19 | 解决是否靠巧合 | 全书巧合不超过两次 | 改写解法 |
| R20 | 结尾是否落地 | 最后一幕在日常空间 | 重写结尾 |
