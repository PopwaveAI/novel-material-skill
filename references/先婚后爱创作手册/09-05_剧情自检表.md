# 9.5 剧情自检表

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.5 剧情自检表

这张表每十到十五章过一遍，全部打勾再往下写。勾不满的项，就是下一卷要修的地方。

表：剧情自检表（四十项）

| 编号 | 检查项 | 判定标准 |
|---|---|---|
| 01 | 主角是否有主动选择 | 本卷至少一次改变局势的主动行为 |
| 02 | 关系是否有推进 | 卷首与卷末的关系状态不同 |
| 03 | 阶段是否匹配 | 当前桥段与第四章刻度一致 |
| 04 | 冲突是否重复 | 同类冲突未在十期内出现两次 |
| 05 | 冲突是否有代价 | 每次冲突都有可见损失 |
| 06 | 误会是否可信 | 信息缺失的原因合理 |
| 07 | 误会是否及时澄清 | 五章内给过部分真相 |
| 08 | 配角是否越位 | 配角未替主角完成关键决定 |
| 09 | 反派是否有逻辑 | 反派目标自洽，且成功过一次 |
| 10 | 巧合是否过量 | 本卷巧合不超过一次 |
| 11 | 女主是否全程被动 | 女主有自己的行动线 |
| 12 | 男主是否只会施压 | 三次施压至少换一次协商 |
| 13 | 是否有单方面牺牲 | 付出方获得明确回馈 |
| 14 | 是否触碰合规红线 | 无涉黄涉暴涉政涉未成年 |
| 15 | 是否有降智情节 | 人物行为符合已有信息量 |
| 16 | 台词是否有潜台词 | 无连续直白表白 |
| 17 | 钩子是否有效 | 每章末尾留有一个问题 |
| 18 | 钩子类型是否有变化 | 未连续三章用同一类型 |
| 19 | 开头是否直接入戏 | 前一百字进入场景 |
| 20 | 结尾是否过长 | 章末钩子控制在五行内 |
| 21 | 日常是否具体 | 每场日常有一个具体物件 |
| 22 | 甜段是否过密 | 每五章至少一段纯日常 |
| 23 | 虐段是否过密 | 连续虐不超过三章 |
| 24 | 是否有喘息章 | 每次大冲突后有一章缓冲 |
| 25 | 伏笔是否埋够 | 每个秘密至少三次埋设 |
| 26 | 伏笔是否回收 | 本卷回收至少一个旧伏笔 |
| 27 | 物件是否贯穿 | 核心物件出现三次以上 |
| 28 | 称呼是否变化 | 称呼随关系阶段变化 |
| 29 | 人设是否前后一致 | 无突然黑化或突变 |
| 30 | 成长是否有痕迹 | 主角与卷首相比有具体改变 |
| 31 | 配型是否成立 | 冲突主轴贯穿本卷 |
| 32 | 是否有信息差 | 本卷存在至少一处信息不对等 |
| 33 | 信息差是否过长 | 未超过五章不揭露 |
| 34 | 评论话题是否可讨论 | 存在双解空间的争议点 |
| 35 | 是否有巧合解法 | 危机不靠天降资源 |
| 36 | 结局是否陡转 | 收束提前至少八章 |
| 37 | 是否有多余角色 | 每个角色都有功能 |
| 38 | 是否有无关支线 | 支线与主线有交集 |
| 39 | 字数是否失衡 | 单章偏差不超过三成 |
| 40 | 读者是否能复述 | 能用三句话讲清本卷发生了什么 |
