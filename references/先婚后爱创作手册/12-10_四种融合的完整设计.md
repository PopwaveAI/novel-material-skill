# 12.10 四种融合的完整设计

> 素材来源：novel-material-skill ·《先婚后爱创作手册》12.10 四种融合的完整设计

这一节把四种融合题材各给一个完整设计，从锁到钥匙到比例，可以直接照结构改造。

### ◆ 12.10.1 加权谋：双面婚约

设定：两国交战前夕，一方以和亲为名送来婚约，另一方以联姻为名接下。两人都带着任务进入婚姻。

锁是国事，钥匙是「一次共同的背叛」。两个人各自接到命令要窃取对方的东西，最后都选择了不执行。这个「不执行」就是钥匙。

比例建议权势博弈四成，日常相处六成。博弈要有具体的事：一份布防图、一封密信、一次宴席上的试探。

表：权谋融合的设计要点

| 要素 | 设计 | 注意 |
|---|---|---|
| 锁 | 和亲婚约，抗命即开战 | 国事要具体到一家人 |
| 钥匙 | 两人同时抗命 | 不能只有一方牺牲 |
| 比例 | 权谋四成，感情六成 | 博弈事件必须改变关系 |
| 节奏 | 每十章程一次博弈 | 不要连续两章博弈 |
| 结局 | 两国和解，两人留下 | 避免一方殉国 |

### ◆ 12.10.2 加悬疑：同一间屋子

设定：她嫁进一栋老宅，宅子里三年前死过一个人，警方定性为意外。她发现丈夫的证词有漏洞。

锁是婚约，钥匙是「共同查清一件事」。悬疑的谜面要一句话说完：三年前那晚，谁最后一个离开这间屋子。

线索要公平：一张被换掉的照片、一段对不上的时间、一个不肯开口的老仆。解答要干脆，最后揭开的必须是人的动机，不是超自然。

表：悬疑融合的设计要点

| 要素 | 设计 | 注意 |
|---|---|---|
| 谜面 | 三年前那晚谁最后离开 | 一句话能说完 |
| 线索 | 照片、时间、老仆 | 至少三条，读者能猜到 |
| 误导 | 丈夫的证词有漏洞 | 误导要有依据 |
| 解答 | 人为动机，非灵异 | 必须给完整解释 |
| 感情作用 | 查案过程产生信任 | 每次线索推进关系 |

### ◆ 12.10.3 加娱乐圈：镜头前后

设定：一桩为了公关而缔结的婚姻，两人都是公众人物。婚前协议写明：对外恩爱，对内互不干涉。

锁是舆论，钥匙是「一次镜头前的失控」。两个人在直播或红毯上，同时忘了演。

这一型要写清「人设成本」：维持形象要付出什么。谁的代言受影响、谁的粉丝脱粉、谁的通告被撤。成本越具体，行业感越真。

表：娱乐圈融合的设计要点

| 要素 | 设计 | 注意 |
|---|---|---|
| 锁 | 公关婚姻，危机公关需要 | 要有具体危机 |
| 钥匙 | 镜头前同时失控 | 失控要小，一句话就够 |
| 人设成本 | 代言、粉丝、通告 | 每一项都要有代价 |
| 舆论反噬 | 一次偷拍、一条爆料 | 要有实际后果 |
| 结局 | 公开关系，承担代价 | 不要轻松洗白 |

### ◆ 12.10.4 加种田：一院四季

设定：她带着一个孩子嫁给一个守着几亩薄田的男人，两个人从春耕开始，把一院子的荒草变成菜园。

锁是生计，钥匙是「一起把日子过起来」。种田的节奏靠四季，每一季完成一件具体的事：翻地、育苗、抗涝、卖菜。

这一型最忌「只有丰收」。虫害、旱情、市价下跌、邻里纠纷，这些苦是感情的试金石。苦要真实，解决要具体，不能靠贵人。

表：种田融合的设计要点

| 要素 | 设计 | 注意 |
|---|---|---|
| 锁 | 生计与名分 | 要有具体的经济压力 |
| 钥匙 | 共同经营一院一地 | 每季一件事 |
| 节奏 | 四季推进，每季十到十五章 | 不要跳季 |
| 苦 | 虫害、旱情、市价 | 解决要靠自己 |
| 甜 | 收成、新家具、一顿好饭 | 甜要来自劳动 |
