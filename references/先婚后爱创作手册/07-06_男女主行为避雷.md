# 7.6 男女主行为避雷

> 素材来源：novel-material-skill ·《先婚后爱创作手册》7.6 男女主行为避雷

人物的行为是价值观的直接体现。下面男女各十条，是这个赛道里最容易踩的行为雷。

表：男主行为避雷清单

| 行为 | 为什么危险 | 替代写法 |
|---|---|---|
| 限制对方人身自由 | 触碰控制与合规红线 | 写他忍住了没说出口的那句话 |
| 查手机、翻私物 | 侵犯隐私，读者反感 | 写他看见亮屏但把手收回来 |
| 以爱为名替对方辞职 | 剥夺主体性 | 写他提出建议后尊重对方的决定 |
| 当众羞辱对方 | 伤害尊严 | 写私下争执，且事后补偿 |
| 用金钱解决所有问题 | 关系物化 | 写他做一件不花钱但费心的事 |
| 对所有人都好，只对她特殊又不说 | 暧昧不清 | 写他明确拒绝他人的示好 |
| 把吃醋写成审问 | 控制欲外显 | 写他多问一句然后自己收回 |
| 承诺后不兑现且无解释 | 人物失信 | 写他兑现了但方式笨拙 |
| 把对方的牺牲当理所当然 | 价值否定 | 写他明确说出「我记着」 |
| 用过度的保护替代沟通 | 窒息感 | 写他先问「你需要我做什么」 |

表：女主行为避雷清单

| 行为 | 为什么危险 | 替代写法 |
|---|---|---|
| 无底线原谅 | 主体性缺失 | 写她原谅但有条件 |
| 用伤害自己换取关注 | 情绪勒索 | 写她直接说出需求 |
| 对同性刻薄 | 价值观反感 | 写她与同性竞争但守底线 |
| 靠装可怜获得资源 | 人物掉价 | 写她用能力交换 |
| 反复试探不作回答 | 消耗对方 | 写她给一次明确回应 |
| 把婚姻当跳板且毫无愧疚 | 价值否定 | 写她有挣扎与代价 |
| 遇事只会哭等救 | 人物失真 | 写她先自救再求助 |
| 用秘密要挟对方 | 关系毒化 | 写她把秘密还回去 |
| 为爱放弃全部事业 | 单薄且过时 | 写她调整节奏但不放弃 |
| 把对方的付出当理所当然 | 关系失衡 | 写她主动回馈一次 |
