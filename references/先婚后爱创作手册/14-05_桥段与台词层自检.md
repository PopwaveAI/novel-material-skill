# 14.5 桥段与台词层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.5 桥段与台词层自检

表：桥段与台词层（二十项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| B01 | 桥段是否三参数齐备 | 场景、动作、潜台词都有 | 补参数 |
| B02 | 桥段是否与阶段匹配 | 无越阶段使用 | 换低强度版本 |
| B03 | 桥段是否与人物匹配 | 符合人设卡 | 改执行方式 |
| B04 | 桥段是否留后果 | 至少后文回收一次 | 补回收 |
| B05 | 同类桥段是否重复 | 十章内不超过两次 | 换类别 |
| B06 | 高危桥段是否受控 | 每类只出现一次且加约束 | 删或改 |
| B07 | 是否有强制亲密 | 零容忍 | 必删 |
| B08 | 是否有偷看私物 | 零容忍 | 改写为看见但不碰 |
| B09 | 是否有当众羞辱 | 主角不可用 | 改为私下争执 |
| B10 | 台词是否有潜台词 | 无连续直白表白 | 重写为半句话 |
| B11 | 台词是否过长 | 单次发言不超过四句 | 拆句 |
| B12 | 台词是否可辨人 | 遮住名字能分辨 | 补腔调 |
| B13 | 是否有模板台词 | 无旧配方句式 | 重写 |
| B14 | 是否每句台词配动作 | 关键台词都有动作 | 补动作 |
| B15 | 是否有解释性旁白 | 无「他其实早就」式旁白 | 删 |
| B16 | 是否有形容词堆砌 | 外貌描写不超过三句 | 删减 |
| B17 | 是否有心理直给 | 情绪靠动作呈现 | 改写 |
| B18 | 是否有无效对话 | 每段对话推进信息或关系 | 删或并 |
| B19 | 称呼是否随阶段变化 | 至少三次 | 补称呼 |
| B20 | 是否有可截图的金句 | 全书至少五句 | 补写 |
