# 14.16 定稿四十问

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.16 定稿四十问

四十个问题分五组，每组八问。答不上来的，就是需要改的地方。建议打印出来，逐条打勾。

表：第一组：人物八问

| 编号 | 问题 | 不合格信号 |
|---|---|---|
| Q01 | 男主的诉求能用一件物表示吗 | 只能说性格 |
| Q02 | 女主的诉求能用一件物表示吗 | 只能说心情 |
| Q03 | 男主最大的恐惧是当下的事吗 | 写成童年阴影 |
| Q04 | 女主有没有一次主动选择 | 全程被安排 |
| Q05 | 两人的短处是否在日常里出现 | 只有优点 |
| Q06 | 配角有没有自己的事 | 只负责传话 |
| Q07 | 反派动机是否自洽 | 只会放狠话 |
| Q08 | 人物说话能否不看名字分辨 | 腔调一样 |

表：第二组：关系八问

| 编号 | 问题 | 不合格信号 |
|---|---|---|
| Q09 | 婚姻的锁是否具体 | 只说「被迫」 |
| Q10 | 有没有一个反复出现的物件 | 没有意象 |
| Q11 | 六阶段是否都能指出章号 | 阶段模糊 |
| Q12 | 每次靠近是否付出代价 | 无代价的甜 |
| Q13 | 有没有一次真正的破例 | 人物全程如一 |
| Q14 | 有没有一次失败的沟通 | 沟通永远顺畅 |
| Q15 | 关系是否产生「第三种东西」 | 只有两个人 |
| Q16 | 结尾状态与开篇是否不同 | 原地不动 |

表：第三组：结构八问

|---|---|---|
| Q17 | 第一章是否在场景里 | 开头写设定 |
| Q18 | 前三章是否有一次完整冲突 | 只有铺垫 |
| Q19 | 每章是否有一个事件 | 纯对话章 |
| Q20 | 章末是否留下问题 | 话都说完了 |
| Q21 | 有没有超过三章无水章 | 中段塌陷 |

| Q23 | 伏笔是否全部回收 | 埋了没还 |

|---|---|---|

表：第五组：合规与交付八问

| 编号 | 问题 | 不合格信号 |
|---|---|---|
| Q33 | 亲密戏是否有拒绝空间 | 无拒绝 |

四十问全部答完，大约两小时。这比通读三遍有用，因为它把「感觉不对」变成了「具体要改哪一处」。

实务提醒：第一本按四十问改，第二本只需要二十问，第三本你会发现自己的错集中在三四处。错题收敛，就是进步。
