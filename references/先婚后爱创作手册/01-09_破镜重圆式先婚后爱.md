# 1.9 破镜重圆式先婚后爱

> 素材来源：novel-material-skill ·《先婚后爱创作手册》1.9 破镜重圆式先婚后爱

这一支把旧情和新婚叠在一起。两个人有过往，因误会或现实分开，多年后因为某种理由重新缔结婚姻。它的情绪底色是「带伤的克制」，比纯陌生人开局更浓，也更容易写腻。

关键在于旧伤要新鲜。所谓新鲜，是指旧伤至今仍在影响人物的行为，而不是只在回忆里出现过。他至今不肯在她面前提那个人，她至今听到某个词会僵一下，这些当下的反应才是旧伤的价值。如果旧伤只活在回忆段落里，那就是背景介绍，不是人物。

开篇重心是重逢的那一场。重逢要有一个具体的、无法回避的场合，比如签约、家族宴席、医院走廊。场合越无法逃，压抑越有效。这一场不要给太多对话，给动作和停顿，克制感是这一支的命脉。

爽点位置在「旧账清算」和「重新认识」两处。清算是把过去说清楚，重新认识是承认彼此都变了。清算给情绪，重新认识给希望。很多作品只写清算，写完就甜，读者会觉得伤口愈合得太快。

破镜重圆式先婚后爱　两人有过情感前史，因误会或现实分开，再度以婚姻形式绑定，故事主体是旧伤的清算与重新认识。

要点：旧伤必须持续影响当下的行为选择

落笔：重逢场合要无法回避，制造被迫面对

分寸：清算之后必须写「彼此都变了」，不能直接进入甜。

示例：「当年那件事，我不问，你也别解释。我们就按现在这样过。」

避坑：把前史写成纯误会，一解释就全消，情绪成本太低，读者会觉得这段感情不值钱。
