# 14.1 结构层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.1 结构层自检

这一章是一张总闸。前面十三章的所有判断，压缩成可以逐条勾选的清单。交稿之前过一遍，能挡掉九成硬伤；过两遍，能挡住那些自己看不出来的问题。

清单的使用规则有三条。第一，按顺序过，不要跳。前面的问题会掩盖后面的问题。第二，每条只判「过」或「不过」，不写「差不多」。第三，不过的项，必须落成具体的修改任务，写清改哪一章、改哪一段。

表：结构层（二十项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| S01 | 全书是否有明确的锁与钥匙 | 能用两句话说清为什么非结不可、凭什么会走近 | 回第三章重填开局表 |
| S02 | 是否只有一条冲突主轴 | 删掉其余支线，主线仍完整 | 合并次要冲突 |
| S03 | 六阶段是否齐全 | 客气、试探、动摇、确认、危机、绑定都在 | 补缺失阶段的过渡章 |
| S04 | 阶段顺序是否颠倒 | 无先确认后试探这类错位 | 重排事件顺序 |
| S05 | 阶段比例是否合理 | 任一阶段不超过全书三成 | 压缩最长阶段 |
| S06 | 每阶段是否有出口事件 | 六个出口事件都能指到具体章节 | 补出口事件 |
| S07 | 是否有阶段跳跃 | 相邻阶段之间无空档 | 补一到两章过渡 |
| S08 | 主线是否有回收 | 所有主干伏笔在结尾前回收 | 补回收章 |
| S09 | 结尾是否陡转 | 收束提前至少八章 | 提前收束 |
| S10 | 首尾是否呼应 | 结尾至少回扣开篇两处细节 | 补呼应细节 |
| S11 | 卷与卷之间是否有钩子 | 每卷末有一个跨卷悬念 | 补卷末钩子 |
| S12 | 是否有无关支线 | 每条支线都与主线有交集 | 删除或合并 |
| S13 | 篇幅是否均衡 | 三卷之间字数差不超过两成 | 调整事件密度 |
| S14 | 单章功能是否清晰 | 每章能说出一个功能 | 拆或并章节 |
| S15 | 是否有重复章节 | 无两章讲同一件事 | 合并 |
| S16 | 时间线是否自洽 | 所有日期、季节、年龄可核对 | 做时间轴表 |
| S17 | 空间线是否自洽 | 人物位置变化有交代 | 补位移交代 |
| S18 | 因果是否闭合 | 每个果都有一个可查的因 | 补动机 |
| S19 | 是否有无效悬念 | 所有悬念都被兑现 | 兑现或删除 |
| S20 | 是否能用三句话说清全书 | 说得出即为合格 | 回炉重搭骨架 |
