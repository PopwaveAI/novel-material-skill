# 9.11 素材库字段设计

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.11 素材库字段设计

写长篇需要素材库。素材库不是收藏夹，是有字段的数据库。每个素材至少要有五个字段：场景、人物、动作、台词、可用的阶段。

表：素材库字段与用法

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 素材名 | 一句话概括 | 雨夜共伞 |
| 场景 | 具体地点与时间 | 小区门口，晚上九点，中雨 |
| 人物 | 涉及谁，各是什么状态 | 男主刚开完会，女主刚被辞退 |
| 动作 | 可拍摄的具体动作 | 他把伞往她那边倾，自己半边肩膀淋湿 |
| 台词 | 一到两句 | 「伞太小了。」 |
| 潜台词 | 这场戏真正在说什么 | 他在意她，但不会说 |
| 可用阶段 | 第几阶段 | 第二阶段 |
| 来源 | 观察、听来、改编 | 地铁上看到的一对夫妻 |

素材库的价值在于「防止重复」。写到中途没素材了，翻库找一条没用过的，比凭空硬编有效。素材积到一百条，一本书的桥段就够用了。
