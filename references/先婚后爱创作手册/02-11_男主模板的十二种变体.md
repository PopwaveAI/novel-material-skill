# 2.11 男主模板的十二种变体

> 素材来源：novel-material-skill ·《先婚后爱创作手册》2.11 男主模板的十二种变体

十二个主模板之外，每个模板还有若干变体。变体不是新人物，是同一骨架的不同皮。选主模板定性格，选变体定处境。

表：主模板的常见变体

| 主模板 | 变体 | 差别 | 适合分支 |
|---|---|---|---|
| 冷面掌权者 | 寡言的执行者 | 话更少，只做事 | 末世、悬疑 |
| 冷面掌权者 | 有洁癖的规则派 | 规矩细到生活层面 | 豪门、现言 |
| 温润体面型 | 礼数周全的旧派人 | 分寸感来自家学 | 古言、家族联姻 |
| 温润体面型 | 职业性的温和 | 温和是工作需要 | 娱乐圈、职场 |
| 痞气生意人 | 草根起家的实干者 | 市井气更重 | 协议搭伙、现言 |
| 痞气生意人 | 世家出身的浪荡子 | 痞是保护色 | 豪门 |
| 隐忍旧伤型 | 战后归来的沉默者 | 伤来自具体事件 | 末世、现言 |
| 隐忍旧伤型 | 被误解多年的替罪者 | 伤来自名声 | 破镜重圆 |
| 少年气技术型 | 学者型 | 专注学术，人情生疏 | 现言、校园向 |
| 少年气技术型 | 手艺型 | 以技立身，语言笨拙 | 种田、市井 |
| 疏离清冷型 | 山水气的隐者 | 冷来自选择 | 古言、仙侠向 |
| 疏离清冷型 | 职业性的冷静 | 冷来自训练 | 医疗、刑侦向 |

变体的作用是「降低同质感」。同一个模板写了三本，第四本必须换变体，否则读者会觉得你在重复自己。
