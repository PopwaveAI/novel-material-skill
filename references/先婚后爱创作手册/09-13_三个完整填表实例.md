# 9.13 三个完整填表实例

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.13 三个完整填表实例

下面三张表是三个不同类型故事的填表示范。它们的作用是让你看见「填好的表」长什么样，不用照着写。

### ◆ 9.13.1 实例一：契约婚姻

表：实例一 CP 卡（契约婚姻）

| 字段 | 男主 | 女主 |
|---|---|---|
| 姓名与称呼 | 沈砚，三十二岁，并购负责人 | 温迟，二十九岁，税务顾问 |
| 模板归属 | 冷面掌权者加隐忍旧伤 | 清醒务实型加温软有骨 |
| 核心诉求 | 保住父亲留下的公司控制权 | 盘回母亲留下的小店 |
| 核心恐惧 | 怕被看见自己撑不住 | 怕再一次被人替她做决定 |
| 动心开关 | 她在他的规矩之外活得好 | 有人认真听完她算的账 |
| 生活短板 | 不会做饭，闻不得油烟 | 记账用铅笔，写完再描一遍 |
| 秘密 | 三年前做过一次不干净的并购 | 替人签过一份担保 |
| 崩坏预警 | 把掌控写成剥夺 | 写成只会算账的冷机器 |
| 成长终点 | 从管理一切到允许失控 | 从守住自己到愿意共享 |

表：实例一开局表（契约婚姻）

| 项目 | 填写内容 | 检查结果 |
|---|---|---|
| 契机 | 替人签的担保爆了，只有婚姻能保住店面 | 够硬，有期限 |
| 阻力 | 债主、担保人、银行三方 | 有具体面孔 |
| 仪式 | 私下签字，七页合同 | 有四个镜头 |
| 不配合细节 | 她签名时墨重了一点 | 被对方看见 |
| 空间 | 一墙之隔，主客倒置 | 规则归属清晰 |
| 物件 | 走廊的壁灯 | 三种状态可写 |
| 协议 | 九条，其中第六条模糊 | 留了缝隙 |
| 初始立场 | 他利用，她将就 | 一冷一热 |
| 误判 | 他以为她贪钱，她以为他冷血 | 有文本依据 |
| 第三章钩子 | 书房里有一份三年前的报告 | 记得住 |

### ◆ 9.13.2 实例二：古言赐婚

表：实例二 CP 卡（古言赐婚）

| 字段 | 男主 | 女主 |
|---|---|---|
| 姓名与称呼 | 裴砚之，二十六岁，世家嫡子 | 谢氏，二十岁，旁支庶女 |
| 模板归属 | 世家规矩型加表里不一 | 隐忍谋算型加反差隐藏 |
| 核心诉求 | 守住家族清誉与爵位 | 查清母亲当年的死因 |
| 核心恐惧 | 怕家族因他而败 | 怕被识破身份 |
| 动心开关 | 她守规矩守得比他更硬 | 他替她挡下一次家法 |
| 生活短板 | 不会算家用，账目一塌糊涂 | 不识几个字，怕人知道 |
| 秘密 | 他知道赐婚背后有人做局 | 她并非真正的谢氏女 |
| 崩坏预警 | 规矩形同虚设 | 写成无所不能的操盘手 |
| 成长终点 | 从守规矩到敢破规矩 | 从借身份到放下身份 |

表：实例二开局表（古言赐婚）

| 项目 | 填写内容 | 检查结果 |
|---|---|---|
| 契机 | 宫中赐婚，抗旨是死罪 | 够急够硬 |
| 阻力 | 嫡母、宫中贵人、族中长辈 | 三层面孔 |
| 仪式 | 拜堂成礼，赞礼声停 | 四个镜头 |
| 不配合细节 | 她念错了一个字，无人察觉 | 被一人听见 |
| 空间 | 一院两厢，主院与偏院 | 规则归属清晰 |
| 物件 | 一盏不许灭的长明灯 | 可写三种状态 |
| 协议 | 口头相约三条，无字据 | 模糊空间大 |
| 初始立场 | 他抗拒，她利用 | 一进一退 |
| 误判 | 他以为她攀附，她以为他薄情 | 有依据 |
| 第三章钩子 | 长明灯下压着一张旧庚帖 | 记得住 |

### ◆ 9.13.3 实例三：末世配对

表：实例三 CP 卡（末世配对）

| 字段 | 男主 | 女主 |
|---|---|---|
| 姓名与称呼 | 编号 0731，三十岁，前工程兵 | 编号 1109，二十七岁，前护士 |
| 模板归属 | 沉默执行型加落魄贵气 | 冷感专业型加落魄硬撑 |
| 核心诉求 | 活着，并守住一个人的托付 | 找到失散的弟弟 |
| 核心恐惧 | 怕再失去一个需要负责的人 | 怕自己成为别人的负担 |
| 动心开关 | 她替他记住一件他自己忘了的事 | 他把她当合作者而非累赘 |
| 生活短板 | 不会说软话，只会下指令 | 手上有旧伤，遇冷会疼 |
| 秘密 | 他多报了一个人的配额 | 她的编号是伪造的 |
| 崩坏预警 | 写成功能化的装备 | 写成不会示弱的铁人 |
| 成长终点 | 从执行任务到愿意托付 | 从独自硬撑到接受依赖 |

表：实例三开局表（末世配对）

| 项目 | 填写内容 | 检查结果 |
|---|---|---|
| 契机 | 配给制要求按户分配，单身无法获得完整配额 | 制度够冷 |
| 阻力 | 登记处、审查员、资源黑市 | 具体机构 |
| 仪式 | 登记处填表，笔拴在桌角 | 四个镜头 |
| 不配合细节 | 她把编号报错了半个数字 | 被登记员记下 |
| 空间 | 一间半地下室，上下铺 | 规则归属清晰 |
| 物件 | 一只搪瓷缸，磕了一个口 | 可写三种状态 |
| 协议 | 口头约定：物资各半，互不干涉 | 无字据 |
| 初始立场 | 他将就，她抗拒 | 错位 |
| 误判 | 他以为她是累赘，她以为他要占她便宜 | 有依据 |
| 第三章钩子 | 他箱子里有一张不属于他的照片 | 记得住 |

三张表填完，能看出一个规律：所有能写的故事，锁都很具体，钥匙都很朴素。锁是制度、债务、赐婚、配额，钥匙是一句话、一件小事、一次挡在前面。锁越具体，钥匙越朴素，故事越可信。

实务提醒：填表时如果某一栏怎么写都别扭，不要硬写。别扭说明这一栏与人物不匹配，换人物或换设定，比硬凑有效。
