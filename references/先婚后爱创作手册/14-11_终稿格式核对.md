# 14.11 终稿格式核对

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.11 终稿格式核对

内容过关之后，还有一层格式。格式不统一，读者读起来会觉得糙，编辑也会要求返工。

表：终稿格式核对表

| 项目 | 规则 | 检查方式 |
|---|---|---|
| 标题层级 | 一级章、二级节、三级小节，不跳级 | 通读目录结构 |
| 正文字号 | 四号，行距固定 | 抽查三段 |
| 段落缩进 | 首行缩进两字，条目悬挂缩进 | 抽查五段 |
| 标点 | 中文标点，引号统一为直角引号 | 全文搜索英文引号 |
| 数字 | 年份用阿拉伯数字，数量可混用 | 抽查时间与金额 |
| 省略号 | 统一为六点省略，不用三点加句号 | 全文搜索 |
| 连接号 | 范围用短横，不用长横 | 全文搜索长横 |
| 空格 | 中文之间不加空格，中英之间加半角空格 | 抽查 |
| 章节序号 | 连续，不跳号不重号 | 检查首尾 |
| 页眉页脚 | 页码连续，位置统一 | 检查前后 |
| 表格 | 表头加粗，边框统一，跨页重复表头 | 抽查三张 |
| 引用 | 册内引用写章节号，不写外部来源 | 全文搜索「详见」 |
