# 9.8 单章写作卡

> 素材来源：novel-material-skill ·《先婚后爱创作手册》9.8 单章写作卡

写每一章之前，先填一张卡。卡片只有七栏，填完不超过五分钟，但能省下大量返工。

表：单章写作卡

| 栏目 | 填写内容 | 示例 |
|---|---|---|
| 章号与标题 | 编号加一个具体标题 | 第 27 章 他第一次进厨房 |
| 本章功能 | 推进、伏笔、冲突、喘息四选一 | 推进 |
| 所在阶段与刻度 | 阶段名加刻度数字 | 试探拉扯，刻度 3 |
| 主场景 | 一个主场景 | 厨房 |
| 核心动作 | 一个能被记住的动作 | 他把锅铲拿反了 |
| 本章变化 | 章首与章末关系状态 | 从客气到尴尬 |
| 章末钩子 | 一句话 | 她看见水池里泡着两只碗 |

七栏里最重要的是「核心动作」与「本章变化」。前者决定这一章有没有画面，后者决定这一章有没有推进。两栏空着，这一章就是水章。
