# 14.7 运营层自检

> 素材来源：novel-material-skill ·《先婚后爱创作手册》14.7 运营层自检

表：运营层（十二项）

| 编号 | 检查项 | 判定标准 | 不过怎么办 |
|---|---|---|---|
| M01 | 书名是否说清类型 | 三秒内可辨 | 重拟 |
| M02 | 书名是否独特 | 换书不能用 | 重拟 |
| M03 | 书名是否承诺过头 | 书里确有其事 | 改书名或改内容 |
| M04 | 标签是否覆盖三维 | 类型、分支、调性 | 补标签 |
| M05 | 标签与内容是否一致 | 无错位 | 改标签 |
| M06 | 简介是否三段 | 处境、冲突、悬念 | 重写 |
| M07 | 简介是否超两百字 | 控制在两百字内 | 压缩 |
| M08 | 简介悬念是否兑现 | 前二十章内兑现 | 调整 |
| M09 | 章节是否有话题点 | 每卷两到三个 | 补埋点 |
| M10 | 话题点是否双解 | 双方都有理 | 补证据 |
| M11 | 引流内容是否含书名 | 每条都有落点 | 补落点 |
| M12 | 是否有违规引导 | 无刷量、无诱导、无导流成交 | 必删 |
