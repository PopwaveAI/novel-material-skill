# 6.2 群像得失设计

> 素材来源：novel-material-skill ·《群像题材创作手册》6.2 群像得失设计

单主角小说里，得失围着一个人转，他得什么读者都觉得理所当然。群像不行，一群人站在台上，必须每一章都有人拿到点什么，也有人交出点什么。得失是群像的呼吸，一章全是得，读者飘；一章全是失，读者丧。这一节讲怎么排这本账。

### 6.2.1 每一章都要有人得到什么

翻开任何一章，问自己一句：这一章结束时，谁的处境比章初多了一样东西。答不上来，这章就是水。
- 得的不一定是宝物。可以是一条情报、一句信任、一个秘密、一次被看见、一笔人情。
- 得的人不一定是主角团。葛长风这种冷角色，一章让他多知道一件事，读者就会觉得他这条线活着。
- 得要落到具体物件或具体对话上，不要写“他心里涌起一股暖流”这种虚得。

错法是整章都在吵架、赶路、吃饭，章末谁都没多拿一样东西。读者读完会觉得这章像没发生过。合格的章末检查：拿一张纸，把这一章每个人物名下写一行他多了什么。邵清晏多了城南账册，葛长风多了城门口那个卖饼老汉的一句闲话，阮青禾多了母亲留下的半块玉佩，鲁小满什么都没多，但他多知道了一个不该知道的名字。

鲁小满蹲在墙角啃饼，听见里屋两个管事说，邵家那笔账，押的是城南三亩水田。他把饼咽下去，谁也没看。

【批注】这就是一次合格的“得”：鲁小满不是主角团核心，戏份也短，但他多知道了一个名字。读者会记住他，因为他知道了别人不知道的事。可迁移写法：冷角色的章末，永远让他偷听到半句关键话。

### 6.2.2 得与失的错位配法

一章之内，得与失必须错开落在不同的人身上。同一个人同一章既得又失，等于什么都没发生。
- 甲得情报、失体面：他去拿情报时被旧识看见跪在地上。
- 乙得体面、失信任：他在堂上说得漂亮，回头发现没人再接他的话。
- 丙什么都不得，只多一个疑问：他的戏份最短，但读者会记住他。
- 丁什么都没失，只是站在旁边看：他是这一章的镜子，下一章程就用他的眼睛写别人。

[表 6-3] 单章得失分配表

| 角色 | 本章得到 | 本章失去 | 读者情绪 |
|---|---|---|---|
| 邵清晏 | 城南账册 | 被旧识看见下跪 | 心疼 |
| 阮青禾 | 堂上的话柄 | 同伴不再接话 | 起疑 |
| 鲁小满 | 半块玉佩 | 无 | 温暖 |
| 葛长风 | 半句闲话 | 无 | 好奇 |

错法是让主角一章连得三样，配角只负责陪笑，读者会觉得这章白看。另一种错法是让同一个人又得又失：邵清晏拿到账册，同时又被母亲训了一顿。这两件事互相抵消，章末他的处境和章初一样。正确做法是把得和失拆到两章，或者干脆让另一个人去承受那个失。

邵清晏把账册塞进怀里时，阶下有人喊了他的旧名。他直起腰，先笑了。

【批注】得与失在同一个动作里完成，但落在不同层面：物上得了，面上失了。可迁移写法：让角色在拿到东西的那一刻暴露一个旧身份，体面和收获打包成交。

### 6.2.3 集体得失与个人得失的换算

群像写到中段，会出现一种大事件：一场仗打完，主角团整体赢了，但每个人都在自己那条线上输了一点。这叫集体得、个人失，是群像最有劲的一种章末。
- 集体得：阵营打赢了，地盘扩大，朝廷下了嘉奖。
- 个人失：邵清晏失去了一个旧部，葛长风失去了一个能说话的朋友，阮青禾失去了母亲最后一句解释的机会。
- 换算比例：一本长篇里，集体得和个人失的章节比例大概是三比七。三章小胜，七章里有人要疼一下。

错法是大团圆式胜利：一仗打完，所有人升赏，每个人都笑。这种章读者看完就忘，因为没人付代价。另一种错法是集体失、个人也全失：一仗打完，地盘没了，朋友死了，主角团散了架。读者会弃书。正确做法是让赢的那一方每个人都付出一点小代价，代价要小到还能接着写，但要真到让读者记得疼。

捷报送进城里那天，鲁小满在城门口站了很久。他想给葛长风道一声喜，话到嘴边，想起葛长风那个没回来的表弟，又咽了回去。

【批注】集体得用捷报一句带过，个人失用鲁小满这个旁观者的犹豫写出来。可迁移写法：大事件的庆功戏，永远安排一个想道贺却开不了口的人，他不开口的那半句话就是代价。
