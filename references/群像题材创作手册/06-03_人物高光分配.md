# 6.3 人物高光分配

> 素材来源：novel-material-skill ·《群像题材创作手册》6.3 人物高光分配

群像写到十万字以后，最容易听到的读者反馈是“某某好久没出场了”“某某一直很工具人”。这不是读者偏心，是作者的高光账没记平。高光不是给谁加戏，是让读者每过三五章就能看见某个人站在光里一次。这一节讲怎么记账、怎么轮换、怎么补冷角色。

### 6.3.1 高光配额的账本记法

开一个 Excel 或一张纸，每个核心角色一列，每三章记一次他有没有拿到高光。记账不是记字数，是记“这三章里有没有一件事非他不可”。
- 高光事件：换一个人来做这件事，故事就不对。邵清晏去谈账，换葛长风去谈就谈不下来，这是邵清晏的高光。
- 高光字数：一场高光戏 800-1500 字就够，不要超过一章。太长就变成他单开一本。
- 账期：每十章一小结，每个核心角色至少一条高光记录。连续十五章没高光的，必须补。

[表 6-4] 十章高光账本示例

| 章次 | 邵清晏 | 葛长风 | 阮青禾 | 鲁小满 |
|---|---|---|---|---|
| 11-13 | 谈账 | 无 | 无 | 偷听闲话 |
| 14-16 | 无 | 守城 | 管家 | 无 |
| 17-19 | 被参 | 无 | 无 | 送药 |
| 20-22 | 无 | 搬救兵 | 认母 | 无 |

错法是只记主角，配角一栏全是空的。读者不会替你算账，但读者会用脚投票，冷角色的戏份会被划走。另一种错法是高光太密：邵清晏连着六章每章都高光，其他人全部陪衬，这就退化成单主角了。账本的意义是让你看见谁被冷落，不是让你平均分。

### 6.3.2 四种高光类型与轮换顺序

高光是有类型的，不能连续三次给同一个人同一种高光，读者会腻。
- 智谋高光：想出一招，把局势盘活。适合智囊型，两章给一次。
- 武力高光：一仗打得漂亮，护住别人。适合武力型，三章给一次。
- 情感高光：一句话把人说哭，把人劝回来。适合情感纽带型，四章给一次。
- 牺牲高光：付出代价，替别人扛事。适合悲情位，全书只给一到两次，给多了不值钱。

轮换顺序建议：智谋、武力、情感、智谋、牺牲，这样五章一轮。错法是每次高光都写同一种：邵清晏每次都是靠聪明，葛长风每次都是靠拳头，读者很快会觉得这两个人扁平。正确做法是让邵清晏也有一次靠身体硬扛的高光，让葛长风也有一次一句话点醒众人的高光，人设会一下子厚出来。

葛长风这一仗本来该输。他却把刀插在地上，冲身后那几个新兵喊：“都把腰挺直了，今天咱们退一步，明天就得给人磕头。”

【批注】这是一次武力型角色的情感高光：他不是打赢的，是用一句话把溃散的人钉在原地。可迁移写法：让打手角色在士兵面前说一句糙但硬的话，比让他多砍三个人更立得住。

### 6.3.3 冷角色的补光方法

有些角色天生戏少：崔九娘、曲阿蛮这种阵营里的长辈，或者黎照这种沉默的年轻随从。他们不能给大高光，一给就抢戏。补光要用小镜头。
- 一个动作镜头：崔九娘在没人看见的时候，把那杯冷茶换成热的。
- 一句半句台词：曲阿蛮路过厅堂，只说一句“今天风大”，别人都愣住，因为她极少开口。
- 一次被看见：黎照替邵清晏挡了一下，不喊疼，只是事后自己用布条缠手，被阮青禾撞见。

补光频率：每五章给冷角色一次小镜头，每次 50-150 字。不要写他的内心独白，不要写他的前史，只写一个动作或一句半句。读者会自己把这个人拼出来。错法是发现冷角色被冷落，就硬塞一大段他的身世回忆，读者其实不关心，只觉得打断节奏。

[表 6-5] 冷角色补光手段对照

| 手段 | 字数 | 适合阶段 | 错法 |
|---|---|---|---|
| 动作镜头 | 50-100 | 全程 | 加内心独白 |
| 半句台词 | 30-80 | 群戏间隙 | 让他长篇大论 |
| 被看见瞬间 | 100-150 | 中段 | 写成回忆杀 |
| 旁人评价一句 | 30-60 | 收尾 | 让众人吹捧 |
