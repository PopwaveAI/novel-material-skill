# 5.7 优质桥段与高危写法的对照

> 素材来源：novel-material-skill ·《群像题材创作手册》5.7 优质桥段与高危写法的对照

【病灶批注】背叛揭晓后，五个人站成一排轮流发表感想。每个人说的都是自己的情绪，但没有一个人做任何事。秦九霄拍桌子但他没有站起来，池砚舟叹气但他没有去查账，柳蝉哭但她没有去拿那封告别信。情绪全在嘴上，身体全在原地。

改法：秦九霄拍桌子之后直接站起来往外走，被薛照按住。池砚舟不说话，直接翻开账本开始查那笔钱去了。柳蝉不哭，她去把费无双以前坐过的那个座位上的茶杯收走。每个人听完背叛的反应，都是一个具体动作，不是一句具体感想。

[表 5-补 2] 动作代替台词的速查

| 情绪 | 不要写台词 | 改写动作 |
|---|---|---|
| 辛苦 | 我知道你辛苦了 | 看见他手里的茧子 |
| 愤怒 | 我早看他不对 | 站起来要被按住 |
| 难过 | 他以前对我好 | 把他的茶杯收走 |
| 震惊 | 居然是这样 | 手里的东西掉了 |
| 坚定 | 我不会放弃 | 把刀又往紧里握了握 |

最后提醒一句：桥段库不是公式大全。这一册给的所有骨架，都是起点不是终点。真正写的时候，把骨架套进你自己的人物和故事里，套完之后一定要做一件事，把你最满意的那个桥段删掉重写一遍。第一遍写出来的多半是套路，第二遍才是你自己的东西。

有一个常见的误区要单独说：很多作者以为名场面靠的是大场面，几百人在街上打架，几千人在朝堂上吵架。其实真正被读者记住的名场面，全是小场面。六个人在一间屋子里，一杯茶没喝完，一场对峙就结束了。读者记住的是那半杯茶，不是几千人的混战。

【拆解批注】名场面的大小和读者记忆深度不成正比。六个人在一间屋子里的张力，比六千人在战场上的混战更让人忘不掉。因为小场面里每个人的动作都看得清，每个人的呼吸都听得见。可迁移写法：写大场面之前，先把人缩到一间屋子里试试。一间屋子里能写好，

放大了才不会散。

把这一册的桥段骨架拿去用之前，先做一件事：翻开你自己的稿子，找到你写得最得意的一场群戏。拿这一册的对照表逐条打勾。登场有没有每人一件道具？对峙有没有分三档站位？多线有没有公共信号焊时间？牺牲有没有三层定价？背叛有没有三层铺垫？终局有没有分组对位？打完之后有没有收束小动作？打不完勾的地方就是你该回去改的地方。改完再写新的，比从头写快三倍。
