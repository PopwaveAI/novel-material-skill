# 7.7 主角团行为避雷

> 素材来源：novel-material-skill ·《群像题材创作手册》7.7 主角团行为避雷

主角团是读者代入的对象，他们做的事会被读者记住。有些行为写出来会让读者反感，不管作者后面怎么圆都圆不回来。下面这张行为红线表，写之前对着看一遍。

[表 7-2] 主角团行为红线表

| 行为 | 为什么不能写 | 替代写法 |
|---|---|---|
| 欺负无辜路人 | 读者立刻出戏 | 让他对敌人狠 |
| 背信弃义还得意 | 主角魅力尽失 | 让他背约付代价 |
| 把女性当奖品 | 女性读者大面积流失 | 女性角色有自己意志 |
| 仗势欺弱小 | 读者无法代入 | 让他保护弱小 |
| 无端杀人灭口 | 主角变成反派 | 让他放人留证据 |
| 拿别人痛苦开玩笑 | 显得刻薄 | 让他沉默或救人 |
| 抢功推过 | 团队散架 | 让他认错扛事 |
| 对下属颐指气使 | 失去人心 | 让他听下属说完 |

主角团可以不完美，可以吵架，可以犯错，但底线是他们对弱小的态度。读者可以接受一个有缺点的主角，不能接受一个欺负人的主角。写主角团对普通人、对下人、对弱者的态度，就是在写这本书的价值观。这个基调一旦歪了，后面再怎么补都救不回来。

【批注】行为红线不是道德说教，是读者代入的底线。读者看主角对店小二说话的态度，比看他对反派说话的态度更敏感。可迁移写法：每写一场主角团和普通人的互动，问自己一句“如果我是这个店小二，我希望被这样对待吗”，答案是否定的就重写。

五个毒点再各补一段深入讲解，把成因和改法再往下挖一层。

主角过多导致失焦，根子不是人多，是没有轻重。一本群像长篇写到一百万字，出场三十个人都正常，关键是这三十个人里要有三到五个读者真在乎的。前二十章只立这三到五个，其他人在背景里晃。晃到第三十章，读者熟了，再慢慢把第六个、第七个提上来。错法是开书就想把三十个人全立住，结果一个都没立住。正确的节奏是：第一章立主角，第五章立二号，第十章立三号，第十五章立四号，第二十章以后再考虑五号六号。每加一个人，前面的人已经在读者心里住稳了，新人才加得进来。

工具人化配角，根子是作者只把配角当功能，没把他当人。智囊型配角不是出主意的机器，他自己也有怕的事。他出的每一条主意背后，都有他自己的算计、他自己的局限。让他出一次错，让他犹豫一次，让他为自己的家人担心一次，他立刻就活了。武力型配角也一样，他不是只会打架的打手，他打架的时候手也会抖，他打完架回家也会给自己上药，他也会想起某个不能想的人。把这些写出来，配角就不是工具了。

线索散乱，根子是作者边写边想，没有提前排。开写之前应该画一张线头图，横轴是章节，纵轴是每条线。每条线什么时候埋、什么时候推进、什么时候收，提前标好。写到的时候照着图走，就不会丢。错法是写到哪算哪，埋一条线全凭灵感，写到后面根本不记得自己埋过什么。建议作者每开一条新线，就在笔记本上记一行：第几章埋的、埋了什么、打算第几章收。每十章翻一次这张表，到点了就收。

主线被稀释，根子是作者喜欢写配角的日常，写嗨了收不住。群像确实需要日常，但日常要围着主线转。主角团今天吃饭，饭桌上聊的应该是主线那件事的进展。主角团今天吵架，吵的应该是主线那件事怎么办。错法是让配角聊他们自己的家长里短，聊了五章，主线没人管了。判断标准很简单：把这一章里所有角色的对话抽出来，问一句“这些对话和主角要办的那件事有什么关系”。超过一半答不上来，这章就水了。

流水账，根子是作者把“写得真实”和“写得有事”搞混了。真实生活里大部分时间是吃饭睡觉，但小说不是生活，小说是生活里那些出事的瞬间。群像写日常可以，日常里必须埋着冲突的种子。今天吃饭看着平静，其实桌上两个人昨天刚闹翻，今天谁也不看谁。今天逛街看着悠闲，其实有人在后面跟着。把冲突埋在日常底下，日常就不水了。

| 毒点 | 病根 | 药方 | 检查动作 |
|---|---|---|---|
| 主角过多 | 没有轻重 | 前二十章立三四人 | 数前二十章视角章 |
| 工具人化 | 配角没人味 | 给私事和犯错 | 每个配角有私事吗 |

【批注】五个毒点表面是五种毛病，根子是同一个：作者写的时候没有账本。视角账本、戏份账本、线头账本、主线账本、事件账本，五本账记平了，五个毒点一个都犯不了。可迁移写法：开写之前先把这五本账的表头画出来，写的时候随时记。

再补五组反面样段，每组配病灶批注和改法示范，都是真实写作里最常见的翻车现场。

反面样段一（主角过多失焦）。

第一章写邵清晏出门查账，第二章写葛长风在守城，第三章写阮青禾管家，第四章写鲁小满跑腿，第五章写崔九娘喝茶，第六章写向晚卖消息，第七章写曲阿蛮说段子，第八章写黎照站岗。八章八个人，每人一章。

【病灶批注】八章没有重心，读者不知道追谁。视角平均分配，等于没有主角。

【改法示范】前八章改为五章跟邵清晏、两章跟葛长风、一章跟阮青禾。其他人在群戏里露脸，不给独立章。

反面样段二（工具人化）。

邵清晏说：“黎照，你去门口看着。”黎照说：“是。”然后黎照去门口站了一章，什么都没说，什么都没想。章末邵清晏说：“黎照，回来吧。”黎照说：“是。”

【病灶批注】黎照是个传令器，他不知道邵清晏在屋里干什么，也不关心，他只负责听话。读者记不住他。

【改法示范】让黎照在门口站岗时听见屋里的对话，他皱了一下眉，把刀握紧了半寸。他有反应，他就是个人。

反面样段三（线索散乱）。

第三章提到阮青禾母亲留下一个匣子，锁着。第十章提到匣子的钥匙丢了。第二十章提到有人在打听这个匣子。第三十章之后再也没人提过匣子。读者问匣子呢，作者说“后面写”，写到一百章也没写。

【病灶批注】埋了三条关于匣子的线，一条都没收。读者会觉得作者在挖坑不填。

【改法示范】第三十五章让阮青禾打开匣子，里面是母亲留下的一封信，信里写了一件和主线有关的事。三章收完，不用拖。

反面样段四（主线稀释）。

主角团要查城南账册。结果写了十章：葛长风和士兵比武，阮青禾和隔壁婶子吵架，鲁小满学做饭，曲阿蛮讲以前的笑话。账册一个字没提。

【病灶批注】十章日常，主线零推进。读者追日常可以，但追久了会忘主线。

【改法示范】葛长风比武时赢得的那个士兵，是从城南逃出来的，他身上带着账册的消息。日常戏挂回主线。

反面样段五（流水账）。

早上邵清晏醒了，穿衣，洗漱，喝粥。葛长风练了一套拳，擦汗，喝水。阮青禾浇花，看花，剪枝。鲁小满扫院子，喂鸡，生火。中午一起吃饭，吃完各自回屋。晚上点灯，吃饭，睡觉。

【病灶批注】一整天，四个人各干各的，没有冲突，没有事件，没有钩子。读者看完什么都没记住。

【改法示范】邵清晏喝粥时发现粥里有怪味，葛长风练拳时发现院墙上有脚印，阮青禾浇花时发现花被人掐过，鲁小满生火时从灰里扒出一张纸条。四个人，四个不对劲。

[表 7-4] 五组反面样段速查

| 样段 | 病灶 | 改法一句话 |
|---|---|---|
| 八人各一章 | 无重心 | 五章跟一人 |
| 黎照传话 | 工具人 | 让他有反应 |
| 匣子失踪 | 线头没收 | 三十五一章打开 |
| 十章日常 | 主线零推进 | 日常挂主线 |
| 一天流水账 | 无事件 | 每人遇不对劲 |

这五组样段，作者写完自己的稿子，对着查一遍。中了哪一条，就回去改哪一条。不要觉得自己不会犯，十个作者九个半都犯过。

内容尺度这一节再补两组对照，把边界讲得更具体。

暴力写法对照。错法：葛长风一刀劈下去，那人从肩膀到腰被劈成两半，肠子流了一地，血喷了葛长风一脸，他蹲下来吐了。这一段写了一百多字全是血腥细节，读者看完不是觉得葛长风厉害，是觉得恶心。改法：葛长风一刀劈下去，那人退了三步，靠在墙上，慢慢滑下去。葛长风站在原地，手在抖，他把刀插回鞘里，转身走了。四十个字，打斗结束，重点放在葛长风的手抖上。暴力的张力在出手那一下和出手后的反应，不在中间的血肉。
