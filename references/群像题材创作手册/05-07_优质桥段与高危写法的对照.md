# 5.7 优质桥段与高危写法的对照

> 素材来源：novel-material-skill ·《群像题材创作手册》5.7 优质桥段与高危写法的对照

前面六节给的是正向做法。这一节反过来，把常见的写法病灶摆出来，对照着看。优质群像桥段和线头散乱的高危写法，差别不在文笔，在调度意识。

| 终局 | 四组对位各清旧账 | 所有人围着 boss 一个人打 |
| 收束 | 小动作收尾不总结 | 大段述职报告式总结 |

### 5.7.1 第一类高危写法：群像写成流水账

下面三段是典型的流水账群像。每段 250 字左右，后面跟病灶批注。

薛照今天去了军营，秦九霄在练兵。池砚舟在书房看书，看了一上午。柳蝉在厨房做饭，做了一桌子菜。费无双在账房算账，算了一下午。韩听雪在花园浇花，浇了三盆。程知白在院子里练剑，练到太阳落山。晚上大家坐在一起吃饭，聊了聊今天的事，

说明天还要继续努力。

【病灶批注】这段是标准的流水账群像。六个人每人一句日常，没有冲突没有钩子。每个人做的事和他的性格无关，换个名字也成立。整段读完读者记不住任何一个人为什么要读下去。改法：挑其中两个人，让他们的日常撞在一起。

比如柳蝉做的那桌菜里有一盘是给薛照做的，但薛照今天没回来。一个缺席的人就能把一桌子菜写出戏。

第二天早上，薛照召集大家开会。他说最近情况不太好，大家要小心。秦九霄说他知道了。池砚舟说他会注意的。柳蝉说她明白。费无双说他没问题。韩听雪说她会配合。程知白点了点头。薛照说那就这样吧，大家散了。散会之后，大家各自回了自己的房间。

【病灶批注】全员表态式流水账。每个人说的话都是同一句“我知道了”，没有任何信息增量。开会这场戏唯一的作用是告诉读者“主角团又聚了一次”。没有一个人说出和别人不一样的话，没有一个动作暴露性格。改法：开会只让三个人说话，另外三个人做别的事。

秦九霄擦刀不抬头，池砚舟在转笔，韩听雪在本子上画圈。三个人的沉默比三句“知道了”有信息量。

薛照走到军营门口，看见秦九霄在门口站着。他跟秦九霄打了个招呼，秦九霄点了点头。他往里走，看见池砚舟在廊下站着，他跟池砚舟打了个招呼，池砚舟笑了笑。他继续走，看见柳蝉在井边打水，他跟柳蝉打了个招呼，柳蝉挥了挥手。他走到自己帐里，坐下来，

喝了一口茶。

【病灶批注】打招呼串联式流水账。主角走一路跟每个人打一次招呼，每个人的反应都是点头微笑挥手。这不是群像，这是主角的散步 vlog。每个人被看见的方式完全一样，说明作者没有给任何一个角色单独设计过动作。改法：主角走到廊下时，

池砚舟不是站着等他，而是正在跟一个幕僚低声说话，看见他来了立刻停了。这个“停了”就比笑一笑有戏。

### 5.7.2 第二类高危写法：高光只给一个人

下面三段是典型的单人高光碾压群像的写法。群像书里如果一场戏只有一个人在发光，其他人全是观众，那不叫群像，叫单主角带背景板。

薛照一个人冲进敌阵，左砍右杀，无人能挡。他一把剑挥出去，倒下一片敌人。秦九霄在旁边看得目瞪口呆，心想大哥真厉害。池砚舟在后面摇着扇子，心想薛兄果然勇猛。柳蝉攥着手绢，心想薛将军一定要赢啊。费无双摸着下巴，心想此人不可小觑。

韩听雪两眼放光，心想这就是我崇拜的人。

【病灶批注】典型的主角无敌加五人围观。五个人的反应全是崇拜，没有一个人有自己的动作和判断。秦九霄作为武力担当，在旁边“目瞪口呆”等于自废武功。池砚舟作为智囊，只会“果然勇猛”等于没有脑子。这一段把群像写成了主角的啦啦队。

改法：秦九霄不是站着看，他带着自己的一队人从另一个方向冲进去，跟薛照形成夹击。池砚舟在后面不是夸薛照，是在调整箭雨覆盖的位置。每个人都有自己的事在干，薛照才不是一个人在发光。

大殿上，费无双一个人舌战群儒，把满朝文武说得哑口无言。他引经据典，逻辑严密，大臣们一个个面面相觑，说不出话来。薛照站在旁边，心想无双真是太厉害了。秦九霄站在旁边，心想我就不会说这么多话。柳蝉站在旁边，无双说得真好。

韩听雪在旁边崇拜地看着。程知白也在旁边，一脸佩服。

【病灶批注】单人演讲加全员听众。费无双说爽了，但其他五个人的反应全是“佩服”，没有一个人提出不同意见，没有一个人在费无双说漏嘴的时候补一句，没有一个人在费无双被反驳的时候站出来帮腔。一场殿辩写成了独角戏，听众全是 npc。

改法：费无双说到一半，有个老臣站起来反驳。这时候池砚舟不用说话，只用手指轻轻敲了一下桌面，费无双就知道该从哪个角度接。两个人不说话的配合比费无双一个人说三章都好看。

秦九霄一个人守在城门口，敌人一波一波冲上来，他一个人一把刀全挡回去了。他浑身是伤，就是不退。薛照在城楼上看着，攥紧了拳头。池砚舟在旁边叹气。柳蝉哭了。费无双摇了摇头。韩听雪捂着嘴。程知白转过身不忍看。秦九霄最后大吼一声，

把最后一波敌人打退了。城楼上的人都松了一口气。

【病灶批注】孤胆英雄加城楼上围观团。秦九霄一个人打完了一整场，城楼上五个人的反应是攥拳叹气哭摇头捂嘴转身，没有一个人下去帮忙，没有一个人喊弓箭手放箭，没有一个人组织预备队补位。群像书里最惨的一场仗，写成了一个人的演唱会。

改法：秦九霄守到一半，城楼上的池砚舟突然喊“左边三十步有个缺口”，弓箭手立刻往那个位置放箭。柳蝉不是在哭，是在跑着给守城士兵递水递布条。每个人都在自己的位置上做了该做的事，秦九霄的孤胆才不是真的一个人。

| 检查项 | 不合格的样子 |
|---|---|
| 一场戏里几个人有动作 | 只有主角有动作，其他人站着看 |
| 每个人的台词能不能互换 | 能互换说明没写好 |
| 散场时有没有留钩子 | 散场就散了，什么都没发生 |
| 打完之后有没有回响 | 死了输了赢了，后面没人再提 |
| 配角有没有自己的判断 | 配角只会说“主角真厉害” |

除了上述两类，还有第三类常见的写法病灶：桥段全靠台词撑，没有动作。下面两段对照供自查。

下面两段是典型的“站着说话型”桥段。所有情绪都靠角色用嘴说出来，身体一动不动。

薛照走进来，看着大家说：“兄弟们，我知道你们最近很苦。秦九霄你练兵练得很辛苦，我都看在眼里。池砚舟你每天熬夜想计策，我也知道。柳蝉你为了大家做饭洗衣，你辛苦了。费无双你算账算到很晚，你也不容易。韩听雪你虽然小但你很勇敢。

程知白你练剑练得手上都是茧子。大家都是好样的，我们一定能成功。”大家听完都很感动，纷纷表示愿意继续跟着薛照。

【病灶批注】主角一个人站着念了一段表彰大会发言稿。六个人的“辛苦”全是主角说出来的，没有一个动作展示。秦九霄练兵辛苦在哪里？池砚舟熬夜到几点？柳蝉洗了多少衣服？全靠嘴说。读者看完的感觉是公司年会上老板在讲话。

改法：把这段表彰全部改成动作。薛照走进来，看见秦九霄的刀上又多了一个缺口，看见池砚舟案上的茶凉了三壶，看见柳蝉的手被水泡得通红。他什么都不用说，把这些东西看一遍，就够了。

费无双背叛之后，大家都很生气。秦九霄拍着桌子说：“费无双这个叛徒！我早就看他不对了！”池砚舟叹了口气说：“没想到他居然是这种人。”柳蝉红了眼眶说：“他以前对我那么好。”韩听雪攥紧拳头说：“我再也不想见到他。

”程知白沉默了很久说：“也许他有苦衷。”薛照坐在主位上，听着大家说完，然后说：“都别吵了。”
