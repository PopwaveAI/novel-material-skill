# 7.2 致命毒点二：工具人化配角

> 素材来源：novel-material-skill ·《群像题材创作手册》7.2 致命毒点二：工具人化配角

症状：配角出场就是为了给主角送情报、挨打、被骂、哭一场，戏份结束立刻消失，读者完全记不住他的名字。翻到下一章，他又出现了，还是干同样的事。

成因：作者把配角当道具用，没想过他自己也想要什么。智囊型配角每次出场就是说一句“主公，我有一计”，说完就退下。武力型配角每次出场就是“主公莫慌，我去斩了他”，斩完就回来。这种写法单主角小说里还能凑合，群像里读者会觉得这些人是纸片。

读者反应：读者会给这种配角起外号叫“工具人”，在评论区吐槽“这个人除了递话还会干嘛”。读者不会为工具人哭，他死的时候读者毫无感觉，作者安排的牺牲戏全部失效。

三档严重度。
- 轻度：配角有一两句性格台词，但没有自己的欲望。读者觉得他扁，但还能忍。
- 中度：配角连续十章只干同一件事，没有任何私事。读者开始跳过他的戏份。
- 重度：配角连台词都没有，纯动作工具，主角一喊他就跑。读者完全无视他。

两个改法。
- 改法一：给每个工具人配一个私事。智囊型除了给主角出主意，让他自己偷偷查一件和他亡妻有关的旧案。武力型除了护主角，让他自己在城外养着一个孤儿。私事不用多，每十章露一次，每次 100 字。
- 改法二：让工具人在某件事上反过来给主角制造麻烦。智囊型出的主意这次是错的，害主角吃了亏。武力型这次没拦住，他自责了一章。配角有了自己的判断，就不是工具了。

改后对照示例。错法一段：邵清晏问葛长风：“城门那边怎么样？”葛长风说：“主公放心，我已经安排好了。”说完退下。葛长风这一段除了答话，没有任何自己的东西。改法一段：邵清晏问葛长风城门那边，葛长风说：“安排好了，只是今天城门口那个卖饼的老汉问我，上次押走的那个人什么时候放，我答不上来。”说完他顿了一下，没再说话。改法多了一个卖饼老汉，葛长风立刻有了自己的心事。

【批注】工具人化的病根是配角没有自己的牵挂。改法不是给配角加戏，是给他加一个和主线无关的小牵挂。可迁移写法：每个出场五次以上的配角，给他安一个和主线无关的小人物或小事，偶尔提一句。
