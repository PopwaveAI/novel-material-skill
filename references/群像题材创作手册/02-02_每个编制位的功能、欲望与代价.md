# 2.2 每个编制位的功能、欲望与代价

> 素材来源：novel-material-skill ·《群像题材创作手册》2.2 每个编制位的功能、欲望与代价

编制位只是骨架，真正让人物立起来的是三件事：他要什么、他怕什么、他愿意付出什么。这三件事缺一不可。

功能是他在主角团里干什么。欲望是他私下想要什么。代价是他为了欲望要丢什么。三者必须错开：他想要的，不能是他正在干的；他怕的，不能是他已经面对的；他付出的，不能是他根本不在乎的东西。

举个例子。情报位的功能是报信。欲望是攒钱开店。代价是他每报一次信，就离自己的店远一步，因为他报信的对象欠了他一笔还不清的人情。这样写，人物就有了拉扯。

[表 2-7] 七个编制位的功能欲望代价表

| 编制位 | 功能 | 欲望 | 代价 |
|---|---|---|---|
| 决策位 | 拍板 | 被人理解 | 每次拍板都要孤一次 |
| 执行位 | 动手 | 退下来 | 每次动手都离退远一步 |
| 情报位 | 报信 | 攒钱开店 | 报信多了欠下人情 |
| 后勤位 | 算账 | 出一次名 | 算账算得越精越没人记得 |
| 情绪位 | 安抚 | 自己被人安抚 | 安抚别人耗光自己 |
| 变数位 | 搅局 | 不被利用 | 搅局越多越像棋子 |
| 制衡位 | 否决 | 投一次赞成 | 投反对票投成孤家寡人 |
- 决策位：叶青梧，欲望是翻案，代价是翻案之后发现自己爹也在里面。
- 执行位：苏景行，欲望是隐退，代价是每次动手都让他离隐退更远。
- 情报位：章南枝，欲望是开酒楼，代价是他欠的人情比他攒的钱多。
- 后勤位：裴知微，欲望是写药典，代价是她每次配药都救了一个不该救的人。
- 情绪位：赵不器，欲望是有人替他挡一次，代价是他替所有人挡过太多次。
- 变数位：萧令仪，欲望是封侯，代价是他越封侯越被朝廷当刀使。
- 制衡位：闻人鹤，欲望是退隐，代价是他越想退，越被推到前台。

写法纪律是：每个人物的欲望不能在第一章说出口。第一章只能给功能，第三章给一个动作露出欲望，第十章给一句台词说破，第三十章让他为了欲望付出第一次代价。欲望说早了，后面没有戏；代价付早了，人物就扁了。

正确写法：章南枝第一次在饭桌上偷偷把剩菜打包，谁也没说；第三章他和叶青梧算账，多要了两钱银子；第十章他在酒楼门口站了很久，说一句“这铺子要是我的就好了”。错误写法：第一章章南枝自我介绍“我叫章南枝，我最大的梦想是开一间酒楼”，欲望直接说出口，后面再写他攒钱就没劲了。

章南枝把桌上的剩包子用油纸包了，塞进怀里。叶青梧看在眼里，没说话。到月底算账，章南枝多报了两钱。叶青梧把那两钱拨回去，只说一句“酒楼的钱，你自己攒”。章南枝愣了一下，低头没接话。

【拆解批注】欲望用动作露出，用台词点破，中间隔十章。可迁移写法：让人物先做一件小事，再让另一个角色看穿他，看穿的人不说破，只给他一个台阶。
