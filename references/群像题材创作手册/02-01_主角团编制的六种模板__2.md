# 2.1 主角团编制的六种模板

> 素材来源：novel-material-skill ·《群像题材创作手册》2.1 主角团编制的六种模板

五人以上小队的写法纪律是：每一场戏只调动两到三个人。你不可能在一场饭桌上让八个人每人说一段话，读者会疯。把八个人分成三组，每组负责一个话题，话题之间用菜、酒、堂倌当过渡。

[表 2-4] 五人以上小队功能位满编表

| 功能位 | 职责 | 出场频率 | 不可替代的标志 |
|---|---|---|---|
| 决策位 | 拍板 | 每章 | 最后一个开口 |
| 执行位 | 动手 | 每章 | 第一个到现场 |
| 情报位 | 报信 | 每 2 章 | 手里永远有纸条 |
| 后勤位 | 算账 | 每 3 章 | 背着褡裢 |
| 情绪位 | 安抚 | 每 3 章 | 给人递水递布 |
| 变数位 | 搅局 | 每 5 章 | 临时改主意 |
| 制衡位 | 否决 | 每 8 章 | 专门投反对票 |
- 决策位角色卡：叶青梧，刑名世家出身，欲望是把二十年前那桩案子翻出来，恐惧是翻案之后发现自己爹也在里面，绝不做的事是屈打成招，与主角团的关系是默认首领，但每次拍板前要看一眼苏景行。
- 情报位角色卡：章南枝，市井跑堂出身，欲望是攒够钱开一间自己的酒楼，恐惧是被人认出他以前偷过东西，绝不做的事是出卖恩客，与主角团的关系是消息最灵但最不靠谱。
- 后勤位角色卡：裴知微，药铺学徒出身，欲望是攒一本自己的药典，恐惧是自己配的药吃死人，绝不做的事是拿药当毒，与主角团的关系是每次出队都背最大的包。

正确写法：七个人围着一张长桌，叶青梧坐主位不开口，苏景行先说话，章南枝补一句，裴知微低头算账，何砚舟擦刀，赵不器靠墙打盹，闻人鹤从门外走进来，所有人同时抬头。错误写法：七个人轮流站起来报名字，一人一句“我叫某某，我擅长什么”，像入职介绍。

长桌七副碗筷，叶青梧坐主位没动。苏景行先开口：“粮道走西线。”章南枝嗑着瓜子接：“西线有山贼。”裴知微把算盘推到中间，没说话，只拨了三下。何砚舟擦刀，赵不器打呼噜，闻人鹤推门进来时，七个人同时抬头。

【拆解批注】七人同场，靠动作和发言顺序建立功能位，不做自我介绍。可迁移写法：给每个人一个固定小动作，小动作重复三次，读者自动记住谁是谁。

### 2.1.5 双线双团：两个阵营互为镜像

双线双团是群像里最难写的一种，因为你要同时管两拨人，每拨人四到六个。写法上的关键是镜像：A 团的决策位，对面 B 团也要有一个决策位，两个人隔着一件事互相猜。

镜像不是对称。对称是两边人数一样、功能位一样、戏份一样，读者会觉得是复制粘贴。镜像的意思是：A 团的人看 B 团的某个人，像看另一个自己；B 团的人看 A 团的某个人，也像看另一个自己。这种对视本身就是张力。

双线双团的节奏纪律是：每三章必须有一次交叉点。A 团的事影响到 B 团，或者 B 团的事影响到 A 团。如果连续五章两边各干各的，读者会分裂成两拨，一拨只看 A 团，一拨只看 B 团，书的销量就腰斩。

[表 2-5] 双线双团镜像对位表

| 主角团位 | 反派团对位 | 镜像点 |
|---|---|---|
| 叶青梧 决策 | 闻人鹤 主谋 | 都查二十年前那案 |
| 苏景行 执行 | 萧令仪 执行者 | 都是刀口上的人 |
| 章南枝 情报 | 敌方密探 | 都在市井里讨消息 |
| 裴知微 后勤 | 敌方医官 | 都在救不该救的人 |
| 何砚舟 武力 | 敌方剑客 | 都使左手剑 |
- 反派团角色卡：闻人鹤，前御史出身，欲望是扳倒当年的宰相，恐惧是自己的女儿被卷进来，绝不做的事是杀无辜的孩子，与主角团的关系是明面敌对，暗地给叶青梧递过一次纸条。
- 反派团角色卡：萧令仪，边军副将出身，欲望是封侯拜将，恐惧是自己出身低微被人看不起，绝不做的事是卖队友，与主角团的关系是与何砚舟交手过三次，每次都留手。

正确写法：叶青梧在案上摆棋子，闻人鹤在对面观棋，两人都不说话，棋子落定之后，叶青梧说一句“你下一步会动左边”，闻人鹤笑一下，没接。错误写法：两边各写一章，一章全是主角团，一章全是反派团，中间没有任何呼应，读者读到反派团那章直接跳。

叶青梧把一枚黑子落在天元。对面的闻人鹤端起茶，没喝，只看着棋盘。良久，闻人鹤伸手把那枚黑子挪到了左下。叶青梧没拦，只说一句“你比我想的快三步”。闻人鹤笑：“你也比我想的慢三步。”

【拆解批注】双团镜像，一场戏两个人下棋，对话不超过四句，张力全在挪子那一下。可迁移写法：让两个阵营的核心角色隔一场棋、一场茶、一场对联，互相看穿一步。

### 2.1.6 一带多：伪群像的识别与补救

很多作者以为自己在写群像，其实写的是一带多。一带多的症状是：主角一个人在前头跑，后面跟着七八个名字，每个人都没自己的事，只负责在主角需要的时候出现一下。

识别伪群像有三个硬指标。第一，主角一章不出场，读者就想弃书。第二，配角单独拿出来一章，读者不关心。第三，所有冲突都是主角和反派的冲突，配角之间没有冲突。三条占两条，就是伪群像。

补救的办法不是加戏，是拆戏。把主角一章里做的事拆一半给配角，让配角独立解决一次。开头三章就要做这个手术，越往后越难。如果 100 章还没拆出来，这本书就别再叫群像了，老老实实当单主角写。

[表 2-6] 伪群像症状与补救表

| 症状 | 识别指标 | 补救动作 |
|---|---|---|
| 主角离场读者慌 | 主角缺席一章掉追读 | 给配角一场独立私事 |
| 配角无自己的目标 | 翻 30 章找不到他想干嘛 | 给他一条 5 章的短线 |
| 配角之间无冲突 | 配角见面只寒暄 | 让两人抢一件物资 |
| 配角只在主角需要时出现 | 配角出场必伴随主角 | 让配角在主角不在场时行动 |
| 群像人数虚高 | 封面十个人，前 50 章只写活三个 | 砍到五人，给剩下的人加戏 |

正确写法：叶青梧病了三天，章南枝自己去西街查账，裴知微自己去药铺抓药，何砚舟自己去门口拦了一次探子。主角不在，事情照样转。错误写法：叶青梧病了，所有人围在他床边，章南枝说“你一定要好起来”，裴知微说“我给你熬药”，何砚舟说“我守着你”，主角一躺下，整个团停摆。

叶青梧发烧躺在内屋，章南枝揣着账本自己去了西街，裴知微拎着药罐去了后街，何砚舟坐在门槛上擦刀。到傍晚，三个人各自回来，把账、药、刀都搁在案上，谁也没去里屋看叶青梧，只把一碗粥搁在门口。

【拆解批注】主角病倒，配角各干各的，事不停。可迁移写法：每 20 章安排一次主角缺席，看配角能不能自己撑住一场戏。
