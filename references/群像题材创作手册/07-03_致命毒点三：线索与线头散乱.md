# 7.3 致命毒点三：线索与线头散乱

> 素材来源：novel-material-skill ·《群像题材创作手册》7.3 致命毒点三：线索与线头散乱

症状：写了五十章，埋了二十条线头，没有一条收。读者翻评论区，作者自己都答不上来“某某人后来怎么样了”。每条线都开了个头，每条线都断在半路。

成因：作者开写时没列线头清单，写一条开一条，写到后头忘了前头。群像最容易犯这个，因为人多事多，每个配角身上都挂着一条他自己的线，作者写到主角那条线时，配角的线就晾在那里。

读者反应：读者会在评论区列一张“失踪人口表”，把几十章没出现的角色和没解开的谜列出来。作者答不上来，读者就觉得这书写崩了。连载到中段，弃书率会明显上升。

三档严重度。
- 轻度：有三到五条线断了五章以上，但都能圆回来。读者会问，但还能等。
- 中度：有十条以上线断了十章以上，有些线连作者自己都忘了。读者开始跳着看。
- 重度：二十条以上线没收，关键谜题解不开，主角团的目标也模糊了。读者大面积弃书。

两个改法。
- 改法一：立刻做一张线头追踪表。把所有没解开的线列出来，每条标上“埋在第几章、埋的是什么、计划第几章收”。超过三十章没安排收的线，要么立刻收，要么彻底砍掉。
- 改法二：用一次大事件把所有线头穿起来。安排一场宴、一场仗、一次审案，让所有失踪的人在这一场里露个脸，把该说的说了，该了的了了。不用每条线都写满，露个脸就算收。

改后对照示例。错法一段：第三章埋了葛长风后背那道疤，第十五章埋了他喝醉喊的那个“河”字，第三十章埋了城门口那块碑。写到第六十章，这三件事一次都没提。读者在评论区问了三次，作者说“后面会写”，写到一百章还没写。改法一段：第四十五章，葛长风路过那个城，城门口又立着那块碑。他停下来，对身边的鲁小满说了一句：“我当年就是在这条河上，把我那个兄弟丢了。”一句话，三道疤、一个字、一块碑，全收了。不用写回忆杀，一句话就够。

【批注】线头不是非得写满才能收。一个配角埋了三十章的谜，用一句话点破，读者会觉得作者一直记着。可迁移写法：每十章回头翻一次线头表，把最老的那条用一两句收掉。
