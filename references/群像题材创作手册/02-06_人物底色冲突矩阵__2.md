# 2.6 人物底色冲突矩阵

> 素材来源：novel-material-skill ·《群像题材创作手册》2.6 人物底色冲突矩阵

- 角色卡：何砚舟，边军逃兵出身，底色硬，底线信义，触发点被背叛。他平时不说话，动手前先绑袖口。他最怕的是兄弟卖他，一旦发现兄弟投敌，他拔刀，但不杀，只把刀架在对方脖子上问一句“为什么”。他与主角团的关系是苏景行的师弟，每次打完坐门槛上喝酒。
- 角色卡：闻人鹤，前御史出身，底色硬，底线尊严，触发点被羞辱。他平时隐忍，被人骂了不还嘴。他最怕的是被人当众看不起，一旦被人指着鼻子骂“你算什么东西”，他记二十年，二十年之后还回来。他与主角团的关系是明面反派，暗地给过叶青梧一次线索。

四张卡，四个底色，四个底线，四个触发点，没有一个重复。你写群像的时候，主角团和反派团加起来六到八个人，每人填一张，填完检查一遍：有没有两个人三个全一样？有就改一个。

底色矩阵的最后一个用法：给配角也填表。很多作者只给主角填表，配角是空白的。结果配角写到 50 章以后，说话和主角越来越像，读者分不清谁是谁。救法是给每个有名有姓的配角也填一张表，哪怕只有底色和底线两个空。
- 配角底色速查：沈砚，冷，尊严。章南枝，软，尊严。赵不器，硬，亲人。萧令仪，软，利益。柳明澜，冷，利益。苏景行，暖，亲人。

六个配角，六个底色，六个底线。你写他们开口之前，先想一下：这个底色的人，会怎么说这句话？想清楚再写，人物就不会混。

正确写法：写沈砚说话，你想“冷底色的人，话短，不解释”，所以他说“第一条最稳”，不说“第一条最稳，因为怎样怎样”。写章南枝说话，你想“软底色的人，嘴碎，爱抱怨”，所以他说“我这月钱还没结呢”，不说“我要求加薪”。错误写法：两个人都写“我认为这件事应该这样办”，像同一个人在说话。

沈砚把纸条推过来，只四个字“走西线”。章南枝凑过来，看了一眼，撇撇嘴：“西线？山贼那么多，我这小命还要不要了？”沈砚没接话，把纸条收回去。

【拆解批注】同样一件事，冷底色说四个字，软底色抱怨三句，差别立刻出来。可迁移写法：写配角台词之前，先想他的底色，底色决定他说几句话、用什么语气。

底色矩阵写到这里，工具就给全了。你拿回去，开书前填一遍，每 20 章对照一遍，写到 300 章，群像不会混。

底色矩阵用熟了之后，你会发现一个问题：有时候你写着写着，两个人物会忽然变得很像。比如你写着写着，发现沈砚和叶青梧说话都变短了，两个人都冷，读者分不清谁是谁。这不是你写得不好，是底色撞了。救法有三条。

第一条，改底线。两个人底色一样，但底线不同，反应就不同。沈砚的底线是尊严，叶青梧的底线是信义。沈砚被人骂会炸，叶青梧被人骗会炸。炸的点不同，人就分开了。

第二条，加缺陷。两个人底色一样，但一个有缺陷，一个没有。比如沈砚有个缺陷：他算得准但不敢说，每次都留半句。叶青梧没有这个缺陷，他想什么说什么。缺陷一加，两个人就不一样了。

第三条，换场景测试。把两个人物放进同一个场景里，让他们做同一件事，看他们的反应有没有差别。如果没差别，说明你写混了，必须改一个。

[表 2-21] 底色撞车的三种救法

| 救法 | 怎么做 | 效果 | 例子 |
|---|---|---|---|
| 改底线 | 给两个人配不同底线 | 反应点不同 | 沈砚尊严，叶青梧信义 |
| 加缺陷 | 给其中一个人加一个毛病 | 行为习惯不同 | 沈砚留半句，叶青梧直来直去 |
| 换场景测试 | 同一场景让两人做同一件事 | 看出差别 | 两人都被骂，一个炸一个忍 |

底色矩阵还有一个进阶用法：故意让两个人底色撞车，然后用撞车制造冲突。比如叶青梧和闻人鹤都是硬底色，都讲尊严，那他们见面就是硬碰硬，谁也不让谁。这种冲突不用设计，底色一撞，张力自动来。
- 硬底色对撞：叶青梧和闻人鹤。一个硬在信义，一个硬在尊严。两个人同场审案，叶青梧先问证据，闻人鹤先问动机。谁也说服不了谁，因为两个人的硬法不同。
- 软底色对撞：章南枝和萧令仪。一个软在嘴碎，一个软在投机。两个人都在打小算盘，章南枝算的是月钱，萧令仪算的是站队。小算盘不一样，人就不一样。
- 暖底色对撞：裴知微和苏景行。一个暖在照顾人，一个暖在护亲人。裴知微给所有人熬药，苏景行只给家里人写信。暖的方式不同，人就不同。

正确写法：叶青梧和闻人鹤同场，两个人都不说话，但叶青梧翻卷宗，闻人鹤喝茶，动作不同，心思不同。错误写法：两个人都翻卷宗，都不说话，读者觉得是同一个人在两幕里出现。

叶青梧翻卷宗，一页一页翻得很慢。闻人鹤端着茶，茶凉了也没喝。两个人坐在同一张案前，中间隔着一尺远，谁也没看谁。窗外的蝉叫了三声，叶青梧翻完最后一页，闻人鹤才把茶搁下。

【拆解批注】同底色对撞，动作不同，距离感就是张力。可迁移写法：让两个同底色的人同场，一个翻东西一个不动，动作差就是冲突。

最后给你一张开书前的自检表，填完这张表，群像人设库才算立住。

| 每个编制位 | 有功能、欲望、代价 | 只有名字 |
| 反派群三层 | 主谋、执行者、投机者 | 只有一个大反派 |
| 反派独立之路 | 每人有一段往事 | 为坏而坏 |
| 配角功能位 | 五类至少占三类 | 配角都是工具人 |
| 底色底线触发点 | 每人填一张表 | 凭感觉写 |
| 角色卡 | 主角团+反派团每人一张 | 只写主角 |
| 盟友节点 | 外援、中立、摇摆至少各一 | 没有盟友 |
| 群像关系边 | 主角团内部有矛盾 | 所有人一团和气 |

十条检查项，每条都有合格标准和不合格的样子。你拿这张表对着自己的稿子打勾，哪条不合格，回去补哪条。补完再开写，比写了 50 章再回头改省事十倍。

正确写法：开书前花一天时间，把这十项填完，填完再动笔。错误写法：边写边想，写到哪算哪，写到 50 章发现人物混了，回头重写，浪费一个月。

你坐在桌前，纸上列着十行。第一行主角团人数，你写五个。第二行编制模板，你写三角核心。第三行每个编制位，你开始写功能、欲望、代价。写到第十行，天已经亮了。你把纸折好，塞进怀里，打开文档，开始写第一章。

【拆解批注】人设不是写出来的，是填出来的。填完表再动笔，写得顺。可迁移写法：开书前花一天填表，填表的时间比返工少十倍。

群像人设库这一部分，从编制模板到功能位，从反派群到底色矩阵，工具给全了。你拿回去用，用熟了，群像就立住了。

编制模板选好之后，下一个问题是：第一场群戏怎么写。第一场群戏决定了读者记不记得住这些人。

第一场群戏的写法纪律是：每个人只给一个记忆点。不要在第一场就把每个人的出身、欲望、恐惧全交代了，读者记不住。第一场只给一个动作、一句话、一个物件，让读者对这个人有个印象就行。

[表 2-23] 第一场群戏的记忆点分配

| 人物 | 记忆点 | 怎么给 | 不要给 |
|---|---|---|---|
| 决策位 | 一个动作 | 拍板时看一眼某人 | 出身介绍 |
| 执行位 | 一句话 | 说一句狠话 | 欲望独白 |
| 情报位 | 一个物件 | 手里拿着纸条 | 恐惧交代 |
| 后勤位 | 一个动作 | 背着最大的包 | 身世往事 |
| 情绪位 | 一句话 | 说一句软话 | 背景故事 |
- 第一场群戏样板：叶青梧在案上拍板，拍之前看了苏景行一眼。苏景行手按刀柄，说一句“我去”。章南枝从怀里掏出纸条，展开看了一眼，又塞回去。裴知微背着最大的包，蹲下来给每个人倒水。赵不器靠墙站着，没说话，只把刀横在胸前。

五个人，五个记忆点，一场戏立住。读者看完第一章，至少能记住三个人。

正确写法：第一场群戏，每个人只做一件事，一件事里见性格。错误写法：第一场群戏，每个人轮流自我介绍，一人一段“我叫某某，我出身某某，我擅长某某”，读者看完记不住任何人。

叶青梧拍案：“走。”拍之前他看了苏景行一眼。苏景行手按刀柄：“我去。”章南枝从怀里掏出纸条，扫了一眼，又塞回去。裴知微蹲下来，给每个人碗里添了水。赵不器靠墙站着，刀横在胸前，没说话。
