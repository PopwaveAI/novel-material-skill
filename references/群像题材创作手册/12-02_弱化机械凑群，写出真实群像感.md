# 12.2 弱化机械凑群，写出真实群像感

> 素材来源：novel-material-skill ·《群像题材创作手册》12.2 弱化机械凑群，写出真实群像感

### 12.2.1 凑群的四种典型痕迹

“凑群”是群像写作最常见的毛病。作者为了凑够七个人，硬把不相干的人拉到一个队伍里，读者一看就觉得假。凑群有四种典型痕迹，你对照自己的稿子一条一条查。
- 痕迹一：每个人都完美互补。武力的负责打，智力的负责想，治疗的负责奶，搞笑的负责逗乐。七个人像 RPG 队伍一样各司其职，谁也不越界。现实里人不是这样的，一个能打的人也会动脑子，一个搞笑的人也有心事。
- 痕迹二：见面就熟。两个人第一次见面，三句话之内就称兄道弟，五天之后就可以把后背交给对方。现实里两个人从认识到信任要经过很多事，不可能一场酒就过命。
- 痕迹三：没有自己的私事。所有人每天醒来想的都是主线任务，没人回家看爹妈，没人惦记自己欠的赌债，没人半夜想自己喜欢的人。他们是为主线而活的工具人。
- 痕迹四：说话一个腔。七个人说的话听起来是同一个人写的，都是那套文绉绉的台词，没有一个人有自己的口头禅、自己的语速、自己的粗口。

下面给四组正反对照，每组看具体的动作和台词。

[表 12-2] 凑群四种痕迹的正反对照

| 痕迹 | 错误写法 | 正确写法 |
|---|---|---|
| 完美互补 | 能打的从不思考，聪明的从不打架 | 能打的也会出主意，聪明的也得自己跑一趟 |
| 见面就熟 | 第一次见面就拍肩说兄弟 | 第一次见面只说公事，私下不来往 |
| 没有私事 | 每天一睁眼就聊主线 | 有人惦记家里生病的妈，有人欠着酒钱 |
| 说话一个腔 | 七个人都说文绉绉的书面语 | 有人骂娘，有人咬文嚼字，有人半天憋一句 |

正确写法是让骆青川这个负责打的人，在打仗之前先把自己的干粮分一半给伤兵，然后才提刀上阵。他不是只会打，他心细。错误写法是骆青川每次出场就是喊“跟我冲”，打完就退到后面等下一场，他从来不关心旁边的人饿不饿。

骆青川把自己那半块干饼掰成三份，塞给旁边两个新兵。新兵愣了一下，说骆大哥你不饿。骆青川说我昨天吃多了。说完他提刀站起来，往前走了两步，又回头说，等会儿冲的时候你们别跟太近。

【拆解批注】技法名“打者心细”。打破“负责打的人就是莽夫”的套路，让他在打架之前先照顾旁边的人。可迁移写法：给功能位角色加一个和他功能相反的小动作。

### 12.2.2 用生活流替代任务流

任务流是凑群的根源。一群人每天就是接任务、做任务、交任务，跟上班打卡一样。生活流是让这群人在任务之间过日子。

任务流和生活流的区别在一个字：闲。任务流里没有闲，每一场戏都在推进主线。生活流里要有闲，闲的时候写他们吃什么、睡哪、跟谁拌嘴、为什么事脸红。
- 每三章主线戏之间，插一章生活流。
- 生活流这一章可以没有任何主线推进，但要让至少两个角色的关系发生一点变化。
- 生活流的场景固定在一两个地方：营地的厨房、城门口的粥棚、某个角色的院子。
- 生活流里不要出现反派，不要出现大事件。

正确写法是打完一场仗之后，用一整章写这帮人在营地里歇着。岑书在磨刀，闻人照在晒被子，苏阿禾在跟伙夫讨价还价，骆青川在教新兵扎马步。这一章啥大事都没有，但读者看完会觉得这群人是真的在过日子。错误写法是打完一仗直接接下一仗，中间不歇，读者会觉得他们是机器。

苏阿禾蹲在伙夫旁边，说你今天的米又掺沙子了。伙夫说今年的米都这样。苏阿禾抓了一把摊开，数出七颗沙子，说七颗，你赔我七碗粥。伙夫笑骂她小气。旁边骆青川扎马步扎得腿抖，岑书在磨刀，霍霍的声音盖过了他们的拌嘴。

【拆解批注】技法名“粥棚拌嘴”。生活流戏靠日常拌嘴推进，不靠事件。可迁移写法：在两场大事件之间，安排一场做饭吃饭的戏，让角色在饭桌上暴露性格。

### 12.2.3 群像的脏数据：谁跟谁其实不熟

真实的群像里，不是所有人都互相熟。七个人里，A 和 B 过命，A 和 C 只见过三面，B 和 D 根本没说过话。这叫脏数据，你要敢写。

干净的数据是七个人两两都认识、两两都熟、两两都互相帮忙。这种群像一看就是假的。真实的人群是分圈的，每两个人之间的亲密度都不一样。
- 画一张七人亲密度表，每两个人之间标 0 到 3 分。
- 3 分是过命的交情，2 分是合作过几次，1 分是点头之交，0 分是没说过话。
- 整本书里，大部分两两关系应该在 1 到 2 分之间，3 分的不超过三对。
- 0 分的那几对，在书里要安排一两次不得不说话的场合，让读者看见他们的生疏。

[表 12-3] 七人亲密度分配示例

| 角色对 | 亲密度 | 他们怎么相处 |
|---|---|---|
| 岑书与闻人照 | 3 | 不用说话就知道对方要什么 |
| 闻人照与赫连青 | 1 | 公事公办，私下不来往 |
| 赫连青与苏阿禾 | 2 | 合作查过案，互相敬重 |
| 苏阿禾与骆青川 | 0 | 没说过话，见面只点头 |
| 骆青川与蒋叙 | 2 | 一起守过城，话不多 |
| 蒋叙与宋九思 | 1 | 宋九思怕蒋叙，躲着走 |
| 宋九思与岑书 | 2 | 宋九思欠岑书一条命 |

正确写法是让苏阿禾和骆青川在一次会议上同桌，苏阿禾说话的时候不看骆青川，骆青川想接话也不知道说什么，两个人中间隔着别人。读者一看就知道这俩不熟。错误写法是所有人开会的时候都互相看、互相点头、互相接话，像一个团建过十次的大公司。

会议上苏阿禾在念卷宗，念到一半停下来，问骆青川你那边的粮草数对不对。骆青川愣了一下，说我回头单独报给你。苏阿禾点头，接着念。整场会他们俩就说了这一句话。

【拆解批注】技法名“会议隔席”。两个不熟的人在大会上说话，说完就完，不寒暄不寒暄之后的寒暄。可迁移写法：在群戏里安排一对不熟的人，他们的对话短到只有公事。

凑群还有一个隐蔽的痕迹，叫集体没有私生活。你翻自己的稿子，看看每个角色在不推进主线的时候在干嘛。如果答案是“他在等下一场主线戏”，那就是凑群了。

真实的人，每天醒来不是先想“今天主线怎么办”，他想的是“我昨晚那局牌输了三两银子”“我娘让人捎信说家里屋顶漏了”“我看上了杂货铺那个姑娘不知道人家愿不愿意”。这些事跟主线半毛钱关系没有，但它们是这个人活着的证据。

给每个主角团成员安排一条私人生活线，这条线和主线无关，但要占他戏份的两成。
- 岑书私下里在养一盆花，那花怎么都养不活，他养了三十章。
- 闻人照私下里有个老母亲在老家，他每个月写一封信，信里报喜不报忧。
- 赫连青私下里在偷偷学写字，他出身武人，不认字，不好意思让别人知道。
- 苏阿禾私下里在攒钱，她想以后开个自己的铺子。
- 骆青川私下里会拉一段胡琴，拉得很难听，但他每天晚上都拉。
- 蒋叙私下里在记账，他把每天花的钱都记下来，记得清清楚楚。
- 宋九思私下里在偷偷练剑，他觉得自己武功不够，怕哪天保护不了人。

这些私人线不要每章都写，隔五到十章提一笔就行。提的时候不要让角色自己说出来，要通过别人的眼睛看到。比如岑书那盆花，不要写“岑书今天又在浇花了”，写老仆端水的时候看见那盆花又黄了两片叶子，他叹了口气。

老仆端着水路过岑书房门口，看见窗台上那盆兰花又黄了两片叶。他没进去，把水放在门口，转身走了。走到廊下他跟伙夫说，那花怕是活不过这个冬天。伙夫说老爷养了它快一年了吧。老仆说快了。

【拆解批注】技法名“窗台上的花”。角色的私事通过旁观者的嘴带出来，不占用主线篇幅。可迁移写法：给每个主角安排一件他偷偷在做的小事，通过配角的视角偶尔提一笔。

生活流还有一个写法要练，叫无事生非。不是真的没事，是写他们在没事的时候互相找事做。
- 两个人闲着没事，开始拌嘴，拌着拌着暴露了一个过去的秘密。
- 三个人闲着没事，开始打赌，赌注是一件和主线有关的东西。
- 五个人闲着没事，开始分工干活，干活的时候有人偷懒有人勤快，关系变了。

无事生非的好处是，你不用引入外部事件，光靠几个闲人待在一起就能出戏。这才是群像的本事：人堆在一起，本身就有戏。
