# 14.14 常见问题的快速修法

> 素材来源：novel-material-skill ·《仙侠题材创作手册》14.14 常见问题的快速修法

下面十四个问题覆盖了中后期最常见的症状，每条给一个最省力的修法。

| 症状 | 修法 |
|---|---|
| 中段读者掉得厉害 | 在平台期插入一个旧人，让他带来新信息 |
| 主角越来越不像自己 | 回到他的“不肯做的事”，让他再做一次选择 |
| 反派变得可恨但无趣 | 给他一段三句话的陈词，让他的道理成立 |
| 感情线推进慢 | 减少对白，增加同一场景里的共同劳动 |
| 战斗都像 | 给每场战斗一个不同的目的：救人、夺物、拖时间、试探 |
| 境界写得乱 | 把境界表贴在桌前，每章更新一次 |
| 设定解释太多 | 把设定改成一次损失或一次机会 |
| 配角太多记不住 | 删到九人以内，每人给一个记住点 |
| 结局写不出 | 先把终点画成一句画面，再倒推三步 |
| 读者说“水” | 删掉所有“他在想”的段落 |
| 读者说“太赶” | 在两次强事件之间加一章余烬 |
| 读者说“看不懂” | 把关键信息提前到章首，而不是藏在段中 |
| 读者说“主角太顺” | 给他一次真正的失败，且不解释 |
| 自己写不动 | 回到最近一个未兑现的承诺，从那里开始写 |

十四个修法里，最常用的是第一条与最后一条。前者解决数据，后者解决状态。写作的很多问题不是技术问题，是“作者自己也不想读了”，那就回到最后一个未兑现的承诺，那里通常还有火。
