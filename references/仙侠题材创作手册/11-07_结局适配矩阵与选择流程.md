# 11.7 结局适配矩阵与选择流程

> 素材来源：novel-material-skill ·《仙侠题材创作手册》11.7 结局适配矩阵与选择流程

不知道自己该选哪个结局，按下面两步走。

| 作品类型 | 首选结局 | 次选 | 慎用 |
|---|---|---|---|
| 男频正统修真 | 飞升证道 | 隐于人间 | BE（读者接受度低） |
| 男频凡人流 | 隐于人间 | 飞升证道 | 舍修为（代价太大） |
| 女频仙侠 | 舍修为相守 / 隐于人间 | 开放式 | 飞升（易被骂冷） |
| 师徒恋 | 舍修为相守 | BE（一方陨落） | 飞升（情感落空） |
| 仙魔对立 | 飞升 / BE | 开放式 | 隐于人间（格局撑不住） |
| 仙侠悬疑 | 开放式 | BE | 大团圆（泄气） |
| 无 cp 修真 | 飞升证道 | 道消身死 | 相守类 |
| 群像 | 开放式 / 各自归处 | BE | 单主角飞升（其他人无交代） |

### 11.7.1 两步选择法

第一步问主题：这本书到底在讲“求”还是“守”？求，选飞升或开放式；守，选隐于人间或舍修为。第二步问读者：你的读者是来爽的还是来疼的？爽，选 HE；疼，选 BE 或开放式。两个答案交叉，结局就定了。

### 11.7.2 双结局的写法

有些作品会准备两个结局，正文给一个，番外给一个。做法是：正文走主题结局，番外走读者期待结局，两者之间隔一段时间，并在番外开头明确写“另一个可能”。这样既守住了作品，也照顾了读者。

双结局的风险是“官方打脸”：番外太甜，会让正文的悲变得像玩笑。控制方法是让番外的甜带一点“如果”的凉，比如番外最后一句是“如果那年他没有走进天门”。

最后一条提醒：结局的选择权在作者，不在评论区。读者的意见值得听，但结局必须服务于这本书在讲什么。为了讨好而改结局，往往两头不讨好。
