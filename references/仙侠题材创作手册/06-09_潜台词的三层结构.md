# 6.9 潜台词的三层结构

> 素材来源：novel-material-skill ·《仙侠题材创作手册》6.9 潜台词的三层结构

潜台词不是“话里有话”这么笼统，它有明确的三层：说出口的话、真正想说的话、不能说的原因。三层齐了，台词才有回味。

### 6.9.1 三层拆解示例

| 台词 | 真正想说的 | 不能说的原因 |
|---|---|---|
| “地上凉。” | 我在意你，别坐在地上 | 他不肯承认自己在意 |
| “随你怎么想。” | 你别误会我 | 解释会暴露他隐瞒的事 |
| “你的剑，握反了。” | 我注意到你手在抖 | 他不想让她知道自己一直在看 |
| “我不用你救。” | 我不想欠你 | 欠了就得还，还不起 |
| “这炉丹，火候差一点。” | 我等你回来再开炉 | 等一个人是最说不出口的事 |
| “山门不许外人进。” | 你进来我就护不住你了 | 规矩比他的心意更有分量 |

拆解之后就能看出规律：真正想说的话越软，说出口的话越硬。温差就是潜台词。

### 6.9.2 三种常见失误

失误一 说透：把潜台词直接说出来，读者失去参与感。失误二 说空：台词与真心毫无关系，读者读不出关联。失误三 说重复：一句潜台词用三次，第三次就成了口号。

### 6.9.3 十个练习
- 写一句“我不想让你走”，但不能出现“走”“留”。
- 写一句“我担心你”，但不能出现“担心”。
- 写一句“我后悔了”，但不能出现“悔”。
- 写一句“别信他”，但不能出现“信”。
- 写一句“我需要你”，但不能出现“需要”。
- 写一句“我恨你”，但不能出现“恨”。
- 写一句“我等了很久”，但不能出现“等”。
- 写一句“我骗了你”，但不能出现“骗”。
- 写一句“我快撑不住了”，但不能出现“撑”。
- 写一句“我爱你”，但不能出现“爱”。

十个练习做完，你会发现最难的是最后一句。因为“我爱你”这三个字太重，一旦不许说，就必须用一个具体到不能再具体的东西来代替。那个东西，就是你的人物真正的情感。
