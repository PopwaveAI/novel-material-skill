# 1.17 赛道选择的自测问卷

> 素材来源：novel-material-skill ·《仙侠题材创作手册》1.17 赛道选择的自测问卷

不确定自己该写哪个分支时，用下面十二道题自测。每题选一个答案，最后按得分对照区间。

### 1.17.1 十二道题

| 题号 | 问题 | 选项 |
|---|---|---|
| 1 | 你更想写一个人的成长，还是一群人的命运 | 单人／群像 |
| 2 | 你更擅长写打斗，还是写对话 | 打斗／对话 |
| 3 | 你更喜欢冷的主角，还是热的主角 | 冷／热 |
| 4 | 你更能接受主角犯错，还是主角必须正确 | 犯错／正确 |
| 5 | 你想让读者爽，还是让读者疼 | 爽／疼 |
| 6 | 你能写多长的铺垫而不焦虑 | 三章／十章／三十章 |
| 7 | 你熟悉的世界是宗门，还是江湖 | 宗门／江湖 |
| 8 | 你更喜欢规矩，还是更喜欢意外 | 规矩／意外 |
| 9 | 你的主角更想赢，还是更想懂 | 赢／懂 |
| 10 | 你愿意让感情线占多少 | 一成／三成／五成 |
| 11 | 你能接受结局不圆满吗 | 能／不能 |
| 12 | 你写作时最享受的是哪一刻 | 设局／揭穿／告别 |

### 1.17.2 结果对照

| 组合特征 | 推荐分支 | 理由 |
|---|---|---|
| 单人＋打斗＋爽＋三章 | 正统修真逆袭 | 节奏与爽点最匹配 |
| 单人＋对话＋疼＋十章 | 凡人流 | 慢热与写实最匹配 |
| 单人＋设局＋冷＋三十章 | 飞升流或写实修仙 | 长线布局需要耐心 |
| 双人＋对话＋五成感情 | 师徒恋或仙魔对立 | 关系张力足够 |
| 群像＋揭穿＋懂＋能接受不圆满 | 双主群像或无 CP | 格局大于个人 |
| 江湖＋意外＋犯错 | 散修江湖 | 无常与自由的底色 |

问卷不是决定论，是把你已有的偏好显影。多数作者在填完之后会发现，自己一直在写某个分支，只是没给它命名。命名之后，读者定位、节奏刻度、桥段选择都会跟着清楚。

问卷还有一个反向用法：如果你已经写了一部分，把它当成读者来填，看看读者会把你归到哪一类。归错类，说明你的开篇给出的信号不对，需要调整前三章的“味道”。

### 1.17.3 三个常见的错配

错配一 慢热的作者写了快节奏的分支：三章要求高光，他偏偏想铺陈，写得痛苦，读者也不买。错配二 喜欢对话的作者写了打斗为主的分支：每场战斗都写不动，只能靠设定堆。错配三 不能接受不圆满的作者写了写实向：写到中段开始回避代价，作品失去重量。

三个错配都能改，但要早改。写到三十万字才想换分支，前面的稿子基本作废。所以开书前填一次问卷，比写十章之后再后悔划算得多。
