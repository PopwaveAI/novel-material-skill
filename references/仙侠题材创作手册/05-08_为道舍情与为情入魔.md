# 5.8 为道舍情与为情入魔

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.8 为道舍情与为情入魔

这两个桥段是一对：一个把情放下，一个把道放下。它们是仙侠最能出圈的段落，因为它们把“选择”抬到了不可两全的高度。

### 5.8.1 为道舍情的写法

难点在于“舍”要舍得像样。主角不能是权衡利弊之后放弃她，那样他只是个现实的人。他必须是在两个都对的道理之间选了一个，并且选完不后悔，但会痛。

优质样段的写法：他在天门下站着，她已经走到了山门。他没有回头，只把剑上的穗子解下来，递给旁边的师弟，说“给她”。师弟问“师叔不去看看吗”。他说“看了就走不动了”。然后他走进天门。三十年后有人问他这一生最怕什么，他说“怕那一年她真的停下来等我”。

### 5.8.2 为情入魔的写法

入魔不是发疯，是主动选择一条更快但更脏的路。写三层：第一层他为了救她用了魔功，第二层魔功反噬，他开始忘事，第三层他忘了她是谁，但还记得要护着她。第三层是全场最狠的一刀。

入魔之后不要立刻洗白。让他真的做几件恶事，读者才会觉得“他付出了什么”。洗白过快的作品，读者的感动会变成愤怒。

### 5.8.3 两种桥段的配比

| 作品类型 | 推荐桥段 | 原因 |
|---|---|---|
| 男频正统 | 为道舍情 | 与“求道”主题一致，悲壮感强 |
| 女频仙侠 | 为情入魔 | 情绪浓度高，适合做中段高潮 |
| 双强文 | 两个都给 | 一次舍、一次入，前后对照 |
| 无 cp | 都不用 | 改用“为道舍师门”或“为道舍旧友” |
