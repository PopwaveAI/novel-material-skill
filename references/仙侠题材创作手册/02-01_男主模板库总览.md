# 2.1 男主模板库总览

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.1 男主模板库总览

仙侠的人设库与其他题材最大的不同，是人设必须和修行路径咬合。一个清冷剑尊之所以清冷，不是因为他性格孤僻，而是因为他的道要求他断掉多余的情绪；一个魔道狠戾之所以狠，不是因为他天生坏，而是因为他修的道每进一层就要吞掉一样东西。人设不是贴上去的标签，是修行方式的副产品。本部分给出可直接取用的模板，每个模板都写明外形锚点、行为锚点、破绽位置与适配剧情。

九种男主模板覆盖了仙侠男频的主要需求。先看总表定位，再进入单型细读。

| 模板 | 一句话人设 | 核心爽点 | 主适配分支 |
|---|---|---|---|
| 清冷剑尊 | 话少、剑快、心里有一座不肯塌的山 | 克制下的失控 | 正统修真、师徒恋 |
| 魔道狠戾 | 笑着杀人，杀完还记得给人收尸 | 越界的深情 | 仙魔对立、复仇流 |
| 护短师尊 | 全天下都可以死，我徒弟不行 | 当众偏护 | 师徒恋、师尊重生 |
| 废柴逆袭 | 被踩到泥里，还能把泥捏成剑 | 打脸与翻盘 | 正统修真、凡人流 |
| 少年意气 | 不知天高地厚，偏偏天高地厚都怕他 | 不知死活的燃 | 散修江湖、群像 |
| 技术流 | 一炉丹、一柄器、一张符，都是他的刀 | 以技破力 | 凡人流、仙门世家 |
| 散修浪子 | 没有山门，只有一身野路子和一张嘴 | 信息差套利 | 散修江湖、仙侠悬疑 |
| 天骄嫡子 | 生在云端，被期待压得喘不过气 | 排场与反叛 | 老子孙辈流、仙门世家 |
| 无 cp 道痴 | 除了道，什么都不认 | 纯粹到可怕的专注 | 无 cp 修真、飞升流 |

这张表可以直接用来做“差异化定位”：如果你的稿子和表里某一行的三个格子都能对上，说明你在写一个成熟类型，读者好找；如果对不上任何一行，说明人设有独创性，但要花更多笔墨让读者快速理解。

还有一条使用建议：主角只取一个主模板，最多加一个副模板的三成。主模板决定读者第一印象，副模板负责制造反差。两个模板各占一半，人物会分裂成两个人。
