# 9.13 空白模板六件

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.13 空白模板六件

下面六件是可直接抄到本子上使用的空白模板，附填法提示。

### 9.13.1 模板一：主角一页卡

| 栏目 | 填写提示 |
|---|---|
| 姓名与身份 | 身份要具体到岗位，不写“某宗弟子” |
| 一句话人设 | 用“他做了什么、不做什么”写，不用形容词 |
| 要什么 | 一个可以被挡住的目标 |
| 怕什么 | 一个具体的失去 |
| 不肯做什么 | 全书至少被诱惑三次 |
| 记住点 | 一个能被复述的习惯 |
| 说话方式 | 给三个常用短句 |
| 成长弧三段 | 每段写“被什么打破” |

### 9.13.2 模板二：单章设计卡

| 栏目 | 填写提示 |
|---|---|
| 章号与标题 | 标题用一个具体物件或动作 |
| 本章功能 | 从十种章型里选一种 |
| 起点状态 | 他与谁、在什么地方、为什么 |
| 转折 | 一个变数，必须来自外部或他自己的选择 |
| 结果 | 不可逆的一点变化 |
| 章末钩子 | 轻钩、中钩还是重钩 |
| 数据目标 | 这一章要让读者得到什么 |

### 9.13.3 模板三：伏笔登记卡

| 栏目 | 填写提示 |
|---|---|
| 编号 | F-01 起编，全书统一 |
| 内容 | 一句能被读者认出的具体描述 |
| 埋设位置 | 章号＋具体场景 |
| 计划回收 | 章号＋大致方式 |
| 是否已回收 | 已／未／放弃 |
| 状态 | 提醒一次／已提醒／待提醒 |

### 9.13.4 模板四：桥段检查卡

| 栏目 | 填写提示 |
|---|---|
| 桥段类型 | 八类之一 |
| 核心动作 | 那一个会被记住的动作 |
| 对手的判断 | 对手在这一段里做了什么决定 |
| 代价 | 主角付了什么 |
| 不该出现的小东西 | 埋线用 |
| 留白点 | 哪一句不解释 |

### 9.13.5 模板五：卷末结算卡

| 栏目 | 填写提示 |
|---|---|
| 本卷成果 | 境界、身份、名声各一句 |
| 本卷损失 | 人情、旧物、人，各一句 |
| 已收线 | 列编号 |
| 未收线 | 列编号与计划章 |
| 下一卷钩子 | 一个具体物件或一句台词 |

### 9.13.6 模板六：自查表

| 项目 | 通过标准 |
|---|---|
| 跨文档引用 | 全文零处指向本册以外的文档 |
| 破折号 | 全文零处 |
| 表情符号 | 全文零处 |
| 数值台账 | 关键节点都有依据 |
| 伏笔 | 未回收不超过三项 |
| 视角 | 无他人心理描写越界 |
| 尺度 | 暴力写结果、情感有克制 |

六个模板里，最该坚持使用的是第二件与第六件。单章卡逼你为每一章想清功能，自查表逼你在发布前过一遍底线。两件都不长，但能把很多问题挡在发布之前。

模板的价值是“减少决策成本”。写作者每天要做上百个决定，能交给模板的就交给模板，省下的精力留给真正需要判断的地方：这一场戏，到底该怎么写才像真的。
