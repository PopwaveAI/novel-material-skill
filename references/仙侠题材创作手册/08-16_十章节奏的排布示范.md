# 8.16 十章节奏的排布示范

> 素材来源：novel-material-skill ·《仙侠题材创作手册》8.16 十章节奏的排布示范

下面给一段十章的排布示范，说明“爽点、钩子、余烬”如何错开。

### 8.16.1 十章排布表

| 章 | 功能 | 爽点位置 | 章末钩子 |
|---|---|---|---|
| 1 | 受辱 | 无 | 重钩（划名） |
| 2 | 不认 | 情绪爽（他站着） | 中钩（有人看见） |
| 3 | 入门 | 小爽（被允许上山） | 轻钩（一句怪话） |
| 4 | 规矩 | 无 | 轻钩（犯了几条） |
| 5 | 同门压力 | 无 | 中钩（一个旧物） |
| 6 | 发现线索 | 信息爽 | 中钩（字还在） |
| 7 | 被否定 | 无 | 轻钩 |
| 8 | 小比失败 | 反向爽（他认输干脆） | 中钩（改步法） |
| 9 | 关系初起 | 暖点 | 轻钩 |
| 10 | 第一个任务 | 小爽（完成任务） | 重钩（药圃被动） |

十章里爽点出现六次，其中三次是小爽、一次是反向爽、一次是信息爽、一次是情绪爽。密度不高，但节奏清楚：三章一给，读者不会觉得枯燥，也不会觉得廉价。

### 8.16.2 排布的三条规律

规律一 前三章必须有两次爽：一次是情绪爽（他不认），一次是小爽（他被允许）。两次都不大，但足够让读者留下。

规律二 第五到第七章是低点：这三章压力最大、爽点最少，作用是蓄力。蓄力不能超过三章，超过读者会走。

规律三 第十章必须有重钩：卷内第一个小高潮的钩子，要够狠。药圃被动、旧物被发现、有人失踪，都行。

### 8.16.3 排布的常见错误

错误一 每章都有爽点：读者三天就麻了，后面写什么都不够。错误二 十章没有爽点：读者会怀疑作者忘了自己在写什么。错误三 钩子全在同一类型：十章十个“有人来了”，读者会疲劳。

排布的意义是“让作者有谱”。写到第五章觉得无聊时，看一眼排布表，会知道这是蓄力段，不必慌；写完第十章觉得平淡时，对照表会发现钩子力度不够，该加码。

最后一个方法：把排布表打印出来，每写完一章就打个勾。二十章之后回头看，勾的分布一眼就能看出节奏有没有偏。这比任何灵感都可靠。
