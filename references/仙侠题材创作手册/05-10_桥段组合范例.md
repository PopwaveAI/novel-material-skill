# 5.10 桥段组合范例

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.10 桥段组合范例

单个桥段好用，组合起来才有戏。下面六组组合按“冲突升级”的顺序排列，每组给出一段可用的连缀方案。

### 5.10.1 组合一：入门 → 护道 → 叛变

先用拜师桥段建立关系，让读者相信这个师门值得护；再用护道桥段让主角为同门挡一次，代价是重伤；最后用叛变桥段，让被他护过的那个人成为叛徒。三段连起来，读者的情绪是“暖、燃、凉”，落差极大。

这个组合的关键在于被护的人与叛变的人是同一个。如果换成两个人，冲击力会掉一半。

### 5.10.2 组合二：夺宝 → 分赃 → 反目

夺宝桥段给出价值倒置的旧物，出秘境后被同行者要求分赃。分赃时的争执不需要激烈，只要一句“你拿那块废料，也算一份”就够了。三个月后，反目成仇，原因不是那块石头，是那句轻蔑。

这个组合示范了一个重要原则：反目的理由要小，后果要大。小题大做的仇恨，比深仇大恨更真实。

### 5.10.3 组合三：情动 → 舍情 → 重逢

情动写三次多余动作，让读者确认他动心了；舍情写他在天门下不回头，代价是三十年的怕；重逢写三十年后她已老去，他仍是当年的样子。三段的时间跨度由长到更长，情绪由甜到苦到凉。

重逢段不要写对话。写他站在她门口，看见门上贴着一张旧符，是他当年画的。这个细节比任何对白都重。

### 5.10.4 组合四：对峙 → 让步 → 联手

对峙三回合后，让强者一方先让步，理由是“我杀不了你，但我可以等你死”。这句让步既保住面子，也埋下杀意。二十章后，两人因为一个更大的敌人被迫联手，联手时的每一次配合都带着旧怨。

这个组合适合写宿敌变战友，是男频最有味的双强结构。

### 5.10.5 组合五：渡劫 → 代价 → 道基劫难

渡劫桥段让他在雷里做一个选择，代价是不可逆的（比如听不见雨声）。这个代价在后面变成道基劫难的引子：他听不见雨声，就听不见当年那场雨夜里她的呼救。

组合的关键是让代价成为后来的漏洞。代价如果只是疼，就浪费了。

### 5.10.6 组合六：叛变 → 清算 → 留白

叛变之后不要立刻清算。先让他逃，让主角在三十章里不断遇到他留下的痕迹：一处被改的阵纹、一句被人转述的话、一个他救下的人。最后清算时，让读者发现叛徒做过的坏事远没有他想的那么多。

清算之后必须留白：主角没有原谅，也没有追问。他只是在叛徒的坟前放了一样东西，然后走了。
