# 5.18 桥段与章节的排布

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.18 桥段与章节的排布

桥段不是均匀分布的，是“疏密相间”。

### 5.18.1 一卷的疏密图

| 卷内位置 | 桥段密度 | 类型 |
|---|---|---|
| 卷一前段 | 低 | 日常与铺垫 |
| 卷一后段 | 中 | 第一次小高潮 |
| 卷二前段 | 低 | 关系推进 |
| 卷二中段 | 高 | 秘境或大比 |
| 卷二后段 | 中 | 余烬与转向 |
| 卷三 | 高 | 大战与劫难 |
| 卷末 | 极高 | 终局选择 |

疏密图的作用是让作者知道“现在该紧还是该松”。一直紧，读者疲劳；一直松，读者离开。规律是“三松一紧，紧后两松”。

### 5.18.2 两个桥段之间

两个高强度桥段之间至少要隔三章。这三章不是废章，是“消化期”：写伤亡、写关系变化、写新的小目标。没有消化期，读者会对高强度麻木。

消化期也要有钩子，只是钩子更小：一封没有落款的信、一句被听错的话、一样被放在门口的东西。小钩子维持追读，大钩子负责爆发。

### 5.18.3 卷末桥段的特殊处理

卷末桥段要比平时高一档，且必须留下三样东西：一个结果、一个失去、一个悬念。三样齐了，读者才会立刻点开下一卷。

示例：他在秘境里拿到了想要的东西（结果），守山人因为他这次行动被问责（失去），那件东西的背面刻着一个不该出现的名字（悬念）。三样东西只用三百字，卷末就立住了。
