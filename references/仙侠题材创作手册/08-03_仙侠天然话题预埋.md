# 8.3 仙侠天然话题预埋

> 素材来源：novel-material-skill ·《仙侠题材创作手册》8.3 仙侠天然话题预埋

话题是免费流量。仙侠自带大量可讨论的命题，作者要做的不是制造话题，是把话题埋进剧情里，让读者自己吵起来。

### 8.3.1 五个天然话题点

| 话题 | 埋法 | 读者会怎么吵 |
|---|---|---|
| 该不该为长生断情 | 让两个角色做出相反选择，都付出代价 | “断情才是道”对“有情才是人” |
| 魔道是不是另一种正道 | 让魔道角色说出让人无法反驳的话 | 立场之争，容易出长评 |
| 师门与苍生谁重 | 让主角在两者间做一次不可两全的选择 | “宗门养你”对“苍生更大” |
| 改命要不要付别人的命 | 让改命需要牺牲一个无辜者 | 伦理之争，传播力最强 |
| 飞升是不是逃避 | 让飞升者留下一句“我还会回来”却没回来 | “他骗了她”对“他回不来” |

五个话题里，“改命要不要付别人的命”最容易出圈，因为它把修仙设定翻译成了现实伦理。写这类段落时不要给结论，给出两个都站得住的选择，让读者自己选边。

### 8.3.2 话题的埋设节奏

话题不能一章一个，会显得刻意。正确节奏是：每三十章埋一个话题，埋的时候只用一场戏，不解释，不站队。等到读者在评论区开始吵，作者再在后面章节给一次“回应”，回应可以是剧情，不可以是议论。

还有一个技巧叫“双向代言”：让两个讨喜的配角各站一边。读者喜欢这两个人，就不得不认真对待他们的立场。这比让反派说歪理有效得多。

### 8.3.3 话题的边界

可讨论不等于可挑动。涉及现实中的群体、地域、宗教、性别对立的话题不要碰，即便在架空世界里也不要。仙侠的话题应该停留在“道与情”“个体与规则”“长生与须臾”这类普适命题上。

另外，不要用作品替自己吵架。作者在正文里对读者喊话，是最快的掉粉方式。把话留给角色说，把判断留给读者做。
