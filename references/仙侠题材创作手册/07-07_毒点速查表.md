# 7.7 毒点速查表

> 素材来源：novel-material-skill ·《仙侠题材创作手册》7.7 毒点速查表

下表是三十条高频毒点，按“读者最不能忍”的程度排序。写完一卷，逐条对照，命中三条以上就要改。

| 编号 | 毒点 | 判定标准 |
|---|---|---|
| 01 | 主角被路人压制 | 升级后仍被新出场角色轻松击败 |
| 02 | 金手指无代价 | 连续使用三次以上没有付出 |
| 03 | 恩将仇报 | 对救过他的人下手 |
| 04 | 欺凌弱者 | 对毫无还手之力者施暴 |
| 05 | 境界通胀 | 后期强者密度是前期的十倍以上 |
| 06 | 女主工具化 | 她只负责被救、被爱、被误会 |
| 07 | 配角全员垫脚 | 没有一个配角赢过主角一次 |
| 08 | 误会型拖戏 | 靠不解释制造矛盾超过十章 |
| 09 | 战力靠喊 | 胜负由谁吼得响决定 |
| 10 | 反派智商下降 | 为了输而做出明显错误决策 |
| 11 | 重复打脸 | 同一种羞辱方式连续使用 |
| 12 | 主角圣父 | 对敌人也讲仁慈，导致同伴死亡 |
| 13 | 感情线突现 | 无前置铺垫的直接表白 |
| 14 | 设定倾倒 | 连续两章以上纯设定说明 |
| 15 | 现代语穿帮 | 出现网络词、科技词、翻译腔 |
| 16 | 修为凭天赋 | 所有突破都归因于“天赋异禀” |
| 17 | 师门全恶 | 宗门上下无一个好人 |
| 18 | 死而复生滥用 | 重要角色死亡后无代价复活 |
| 19 | 资源无账 | 想用就有，从不算消耗 |
| 20 | 战斗同质 | 每场都是正面对轰 |
| 21 | 地图跳跃 | 场景频繁切换，缺少过渡 |
| 22 | 旁白剧透 | 提前宣布命运与结局 |
| 23 | 强行降智 | 为了让剧情推进，人物行为违背性格 |
| 24 | 过度说教 | 单章议论超过三百字 |
| 25 | 情绪硬煽 | 没有铺垫的死亡与离别 |
| 26 | 名字混乱 | 同姓角色过多，读者分不清 |
| 27 | 支线失控 | 支线篇幅超过主线 |
| 28 | 结局失重 | 最后一章草草收场 |
| 29 | 抄袭痕迹 | 桥段与结构高度撞车 |
| 30 | 人设漂移 | 中期性格与开篇判若两人 |

这张表可以当作“改稿清单”用：每命中一条，在稿子上标一个记号，改完再销。三十条全部清完，稿子的下限就有保障了。

最后提醒一点：雷区的本质是失信。读者不是不能接受主角犯错，是不能接受作者糊弄。所有修正方法归根到底只有一句：让每一个结果都有原因，让每一个原因都在前文出现过。
