# 9.11 道具与细节清单

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.11 道具与细节清单

细节是仙侠的质感来源。下面按类别列出可直接取用的道具，每一样都带一个用法。

| 类别 | 道具 | 用法 |
|---|---|---|
| 随身 | 缺角的旧罗盘 | 指向最近的水源，也指向灵脉 |
| 随身 | 一枚磨得发亮的铜钱 | 用来占一次吉凶，只信一半 |
| 随身 | 半截断梳 | 梳齿上缠着几根头发，是某个人的 |
| 器物 | 补过三次的丹炉 | 每次炸炉都会先从补的地方裂 |
| 器物 | 刻满记号的药匙 | 记号是失败次数，一共四十七道 |
| 器物 | 卷了边的旧地图 | 标的路线有一条已经不存在了 |
| 信物 | 一枚空心玉佩 | 里面藏着半张纸 |
| 信物 | 褪色的平安结 | 打了多少个结就是多少年 |
| 信物 | 一封没寄出的信 | 封口用蜡，蜡上有指印 |
| 消耗 | 只剩半瓶的药 | 瓶底有沉淀，摇一摇才有效 |
| 消耗 | 三张符纸 | 每张只能挡一次，挡完变灰 |
| 消耗 | 一块中品灵石 | 切了一半，另一半给了别人 |

道具使用的三条规矩：一物一用（不要一件东西什么都能干）、一物一人（尽量绑定某个人的记忆）、一物一收（用了要收，收的时候要有动作）。三条做到，道具就有了生命。

最后一条建议：全书只设三件“贯穿道具”，其余都是消耗品。贯穿道具出现在开篇、中段、结局各一次，其余时间偶尔提一下。这样读者既不会忘，也不会腻。
