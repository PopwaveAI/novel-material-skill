# 12.12 反套路清单三十条

> 素材来源：novel-material-skill ·《仙侠题材创作手册》12.12 反套路清单三十条

写反套路之前，先看清套路长什么样。下面三十条是仙侠最常见的套路动作，每一条后面给一句“可以怎么反”。

| 套路 | 反法 |
|---|---|
| 废柴被测出绝顶灵根 | 测不出，但他另有路径 |
| 退婚当场被打脸 | 婚退了，他也没翻身 |
| 神秘老者送功法 | 老者是骗子，功法有假 |
| 秘境宝物自动认主 | 认主的是别人，他被认成仆人 |
| 反派临死前求饶 | 反派从头到尾不求饶 |
| 主角越级秒杀 | 越级之后重伤三月 |
| 同门全是垫脚石 | 同门有人比他先突破 |
| 女主一见倾心 | 女主先利用他 |
| 师尊无所不能 | 师尊有一件事永远做不到 |
| 宗门大比夺魁 | 他弃权，另有目的 |
| 魔道全是坏人 | 魔道有守约者 |
| 正道全是好人 | 正道有伪君子 |
| 丹药吃了就突破 | 丹药有反噬 |
| 灵兽开口卖萌 | 灵兽只说真话，且很刺人 |
| 法宝越多越强 | 法宝互相冲突，用多了伤人 |
| 闭关必成 | 闭关失败，且丢了时间 |
| 渡劫必过 | 第一次渡劫失败，修为倒退 |
| 飞升即圆满 | 飞升之后发现更冷 |
| 前世记忆全知 | 记忆是残缺的，且有一处假 |
| 重生必定复仇成功 | 复仇成功之后更空 |
| 掌门必是好人 | 掌门是最会算的那个 |
| 长老只会护短 | 长老护的是宗门，不是人 |
| 主角天赋第一 | 天赋第二，第一是反派 |
| 打不过就突破 | 打不过就跑，跑不掉就谈 |
| 敌人送上门 | 敌人一直在暗处算他 |
| 宝物越古越强 | 古物有主，主还在 |
| 秘境必有传承 | 传承是个骗局 |
| 结局必大团圆 | 结局停在一个门口 |
| 主角永远正确 | 主角错一次，付了代价 |
| 作者替主角解释 | 一次都不解释 |

三十条里不必全反。选三到五条改造，读者就会觉得“这本不一样”；全反会让读者找不到熟悉的入口。

反套路的最后一条心法：反的是预期，不是逻辑。逻辑必须比套路更严，否则读者只会觉得你在乱来。
