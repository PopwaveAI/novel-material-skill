# 9.7 六张表的组合流程

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.7 六张表的组合流程

六张表不是并列的，它们有使用顺序。开书前填 CP 卡与境界进度表；写作中维护机缘表与伏笔表；每卷末用自检表体检；关系矩阵每五十章更新一次。

| 阶段 | 用哪张表 | 产出 |
|---|---|---|
| 开书前 | CP 卡、境界进度表 | 感情骨架、全书时间轴 |
| 写到第一卷 | 机缘表、伏笔表 | 资源节奏、线索档案 |
| 每卷末 | 自检表 | 体检报告与修改清单 |
| 每五十章 | 关系矩阵 | 人物关系更新 |
| 定稿前 | 全部六张 | 一致性核对 |

最后给一句实操建议：表要少填，不要填满。填满的表会让你产生“工作已经完成”的错觉。表的空行是留给剧情的余地，空着的格子比填满的格子更值钱。
