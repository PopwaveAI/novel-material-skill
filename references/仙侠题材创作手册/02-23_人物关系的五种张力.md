# 2.23 人物关系的五种张力

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.23 人物关系的五种张力

关系不是设定，是持续的拉力。下面五种关系各自提供一种拉法，写的时候选一种，不要五种混着来。

### 2.23.1 债务型

一方欠另一方一条命、一句话、一个承诺。债务让关系有了明确的方向：还清之前，两人绑在一起；还清之后，关系可能立刻断。写这种关系，关键是“还的方式出乎意料”，比如他用一件更重的东西去还，反而欠得更多。

### 2.23.2 隐瞒型

一方知道另一方不知道的事。隐瞒制造持续的紧张：每一次对话都有潜台词，每一个细节都可能泄露。写这种关系，关键是“泄露的时机”，太早失去张力，太晚读者会觉得作者在拖。

### 2.23.3 竞争型

两人在同一件事上争夺，且彼此尊重。竞争型关系的妙处是“赢了也不痛快”，因为对手是自己认可的人。写这种关系，要给一次“联手”的机会，让两人在共同的敌人面前短暂并肩，然后再回到竞争。

### 2.23.4 互补型

一个人有的，另一个人缺；一个人怕的，另一个人不怕。互补型关系最容易写成甜，也最容易写成腻。避免腻的方法：让互补带来麻烦，比如他替她挡下所有风雨，她就永远学不会自己撑伞，某一天他不在，她连门都出不去。

### 2.23.5 镜像型

两人起点相似，选择不同，走向相反。镜像型关系不需要太多对手戏，只需要几次关键节点的对照。读者会自己在心里比较，比较产生的情绪比对话更持久。

### 2.23.6 五种张力的配比

| 关系线 | 常用张力 | 高潮形态 |
|---|---|---|
| 男女主 | 隐瞒＋互补 | 真相揭开后的选择 |
| 师徒 | 债务＋隐瞒 | 师父的旧事被揭开 |
| 宿敌 | 竞争＋镜像 | 联手之后的再次对立 |
| 同门 | 竞争＋债务 | 大比或问罪 |
| 主仆或上下 | 债务＋互补 | 身份反转 |

五种张力的共同前提是“双方都有东西可失去”。一方无所谓的对抗，读者不会紧张。所以在设计关系时，先问：他失去什么会疼。答案就是张力所在。

最后一条经验：一条关系只推进一件事。男女主的关系就推进“她能不能信他”；师徒的关系就推进“他会不会知道真相”。一件事推到底，关系才厚；贪多，每条都浅。
