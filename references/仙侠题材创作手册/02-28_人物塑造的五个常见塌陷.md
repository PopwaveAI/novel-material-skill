# 2.28 人物塑造的五个常见塌陷

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.28 人物塑造的五个常见塌陷

人物写坏，通常不是“不够好”，是“塌了”。五种塌陷有明确症状与修法。

### 2.28.1 塌陷一：全知全能

症状：主角每次遇险都有办法，从不需要别人。修法：给他一个“永远学不会的事”，并让它在中段真的坏一次事。这个缺口，是读者喜欢他的理由。

### 2.28.2 塌陷二：性格漂移

症状：第一卷他冷，第三卷他热，中间没有理由。修法：每一次转变都配一次事件，事件要足够重。重不到，读者会觉得你在换人。

### 2.28.3 塌陷三：动机外包

症状：他做事的理由是“师父让他做”“系统让他做”。修法：给他一个自己的目的，哪怕很小、很自私。人只有为自己做过一次事，才立得住。

### 2.28.4 塌陷四：道德无成本

症状：他做了好事，没有任何代价；做了坏事，也没有任何后果。修法：给每一次选择标价。善要付代价，恶要有回响，人物才有重量。

### 2.28.5 塌陷五：语言不分

症状：师父、同门、敌人说话都一样。修法：给每个人一条“语言指纹”：一个口头词、一种句长、一个习惯动作。三个人物三条指纹，对话就分得开。

### 2.28.6 五种塌陷的修法表

| 塌陷 | 症状关键词 | 修法 |
|---|---|---|
| 全知全能 | 总有办法 | 给一个学不会的事 |
| 性格漂移 | 前后不像一个人 | 每次转变配一次事件 |
| 动机外包 | 都是别人让他做 | 给一个自私的目的 |
| 道德无成本 | 好事坏事都无后果 | 给选择标价 |
| 语言不分 | 谁说话都一样 | 一条语言指纹 |

五种塌陷里，第三种最隐蔽。作者往往觉得“他有使命”，读者却觉得“他像在完成任务”。区别在于：使命是别人给的，目的是自己要的。两样都要有，人物才完整。

最后一个检查办法：把主角的名字遮住，让朋友读两章，问他能不能认出这是同一个人。认不出，就是塌了；认得出，说明这个人物已经有自己的形状。
