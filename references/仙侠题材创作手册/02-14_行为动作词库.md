# 2.14 行为动作词库

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.14 行为动作词库

人设靠动作立，不靠形容词。下面三十条动作，每一条都能直接放进场景，也都隐含一层性格。

| 动作 | 隐含性格 | 适用人设 |
|---|---|---|
| 递东西时先擦一下再递 | 在意对方，又不肯说 | 清冷剑尊、护短师尊 |
| 说话前先看对方的手 | 习惯判断威胁 | 散修、魔道 |
| 坐下前把椅子往后挪一寸 | 本能保持距离 | 清冷、孤僻 |
| 喝茶只喝半杯 | 随时准备起身 | 剑修、将死之人 |
| 数东西时用手指点 | 精确、控制欲 | 技术流、权谋型 |
| 把袖口卷到肘上才动手 | 郑重、预兆 | 少年意气 |
| 听完话先沉默三息 | 在算，或者在忍 | 师尊、权谋 |
| 笑的时候先看别处 | 笑是给场面的，不是给心的 | 魔道、贵公子 |
| 走路时把手背在身后 | 端着，也在藏东西 | 世家嫡脉 |
| 关门时用脚背推 | 不想让人看见手在抖 | 重伤、心虚 |

| 动作 | 隐含性格 | 适用人设 |
|---|---|---|
| 把别人的话重复半句再答 | 慢，且要留余地 | 师尊、老修士 |
| 替人挡风时站在上风口 | 护，且不邀功 | 清冷、护短 |
| 吃剩下的东西自己收走 | 不浪费，出过苦日子 | 废柴、散修 |
| 刀出鞘前先掂一下重量 | 职业病式的谨慎 | 散修、器修 |
| 看天时眯眼 | 农家或猎户出身 | 凡人流、少年 |
| 说话时手指在膝上敲节拍 | 在压情绪 | 隐忍型 |
| 把人按住不让动，手掌极稳 | 关键时刻能定人 | 护短、双主 |
| 临走前把桌上的灰擦一下 | 洁癖，或者不想留痕 | 刺客型 |
| 对人笑完之后叹一口气 | 装得很累 | 贵公子、圣女 |
| 听见钟声会停半息 | 有一段旧事 | 几乎所有类型 |

| 动作 | 隐含性格 | 适用人设 |
|---|---|---|
| 剑不离手，连睡觉都握着 | 没有安全感 | 孤儿、废柴 |
| 给东西时只说“接着”，不说用途 | 不肯示好 | 清冷、魔道 |
| 走到门口会回头看一眼 | 舍不下 | 师徒、道侣 |
| 把重要东西放在最不显眼的地方 | 被偷过 | 散修、凡人流 |
| 从不坐主位 | 不想担责，或还没资格 | 少年、外门弟子 |
| 别人讲话时盯着对方衣领 | 在找破绽 | 权谋型 |
| 受伤后先整理衣服再处理伤口 | 体面比命重要 | 世家嫡脉 |
| 用袖子擦剑，不用布 | 剑比衣服重要 | 剑修 |
| 把药煎两次，第二次留给自己 | 把自己的份往后放 | 医修、护短 |
| 听人说完才开口，从不打断 | 教养，或者敬畏 | 圣女、老仆 |
