# 1.12 对标拆解：怎么看一本同类作品

> 素材来源：novel-material-skill ·《仙侠题材创作手册》1.12 对标拆解：怎么看一本同类作品

看同类作品不是为了抄，是为了量出自己的位置。拆解要有方法，否则看一百本也只是“好看”两个字。

### 1.12.1 五层拆解法

第一层 结构：它的八阶段分别落在第几章，每阶段的核心事件是什么。第二层 人设：主角的核心欲望与恐惧是什么，哪一章第一次暴露。第三层 爽点：它的爽点分布在哪，用的是哪一类爽点。第四层 语言：它的句子长度、常用句式、有没有标志性的口头禅。第五层 缺口：它哪里写得薄，那个薄的地方就是你的机会。

五层里第五层最有价值。一本爆款必然有薄处，因为作者的偏好会留下空档。别人把“打斗”写得极好，情感写得敷衍，你就在情感上加码；别人把“设定”写得极细，人物写得扁平，你就在人设上用功。

### 1.12.2 拆解笔记模板

| 项目 | 记录内容 |
|---|---|
| 八阶段落点 | 每阶段起止章、核心事件 |
| 主角三要素 | 欲望、恐惧、缺陷 |
| 爽点类型与分布 | 力量/地位/关系/智谋，各出现在哪 |
| 标志性桥段 | 三个能被记住的场面 |
| 语言特征 | 句长、句式、口头禅 |
| 明显缺口 | 哪一层写得薄 |
| 可借用结构 | 能移植到自己书里的结构 |
| 不可借用部分 | 与自己的题材不兼容的设计 |

拆解完要立刻做一件事：在自己的开篇上改一处。只看不改，笔记就是废纸。

最后提醒：对标是为了找位置，不是为了找爹。把别人的结构吃透，再写自己的东西，这叫学习；把别人的桥段换个名字搬过来，这叫抄。前者让你成长，后者让你出局。
