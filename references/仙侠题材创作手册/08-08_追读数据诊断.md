# 8.8 追读数据诊断

> 素材来源：novel-material-skill ·《仙侠题材创作手册》8.8 追读数据诊断

数据不会骗人，但需要会读。下面给出四个指标与对应的诊断路径。

| 指标 | 下降意味着 | 先查什么 |
|---|---|---|
| 第一章点击率 | 书名/简介/封面不行 | 卖点是否一句话说清 |
| 前三章完成率 | 开篇钩子不够 | 第一章前三百字有没有冲突 |
| 章均完成率 | 节奏或语言有问题 | 这一章有没有“前进” |
| 追更率 | 钩子兑现不足 | 章末钩子是否下一章给答案 |
| 评论互动量 | 话题不足 | 有没有可站队的裂缝 |

五个指标里，“章均完成率”最值得每周看一次。它掉的章节，就是你的节奏漏洞。把掉得最厉害的三章挑出来，对照第八部分的爽点刻度表，通常能立刻找到原因。

还有一个隐形指标：读者在评论区的提问类型。问设定的多，说明世界观有趣但没讲清；问人物的多，说明人物立住了；问“什么时候更新”的多，说明钩子成功。三种提问的比例，就是你的作品当前的体检报告。
