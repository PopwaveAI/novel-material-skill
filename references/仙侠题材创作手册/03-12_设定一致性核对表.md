# 3.12 设定一致性核对表

> 素材来源：novel-material-skill ·《仙侠题材创作手册》3.12 设定一致性核对表

| 核对项 | 核对方法 | 常见错误 |
|---|---|---|
| 境界与寿元 | 对照境界表逐级核 | 活了几百年还在炼气 |
| 境界与能力 | 每级的能做什么写成一句话 | 元婴修士被凡人拖住 |
| 地理与路程 | 两点之间要走几天 | 一日之内横跨三域 |
| 势力与资源 | 这个势力靠什么养人 | 小宗门养着三个化神 |
| 法宝与代价 | 每次动用写清消耗 | 用了十次毫无损耗 |
| 货币与物价 | 同一件东西在不同处价格差多少 | 价格随时变 |
| 称谓与身份 | 称呼与位置是否对应 | 外门弟子被称长老 |
| 时间线 | 关键事件之间隔多久 | 三年内发生二十年的事 |

核对表建议在写完全书后整体过一遍，逐行标注“已核”。这一遍很枯燥，但它是作品能不能被认真读者认可的分水岭。
