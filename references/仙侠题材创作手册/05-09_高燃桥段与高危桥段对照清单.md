# 5.9 高燃桥段与高危桥段对照清单

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.9 高燃桥段与高危桥段对照清单

下面这张表把二十种常见桥段写法分成两列，左边是读者会截图转发的，右边是读者会在评论区骂的。写之前对照一遍，能省下很多返工。

| 优质高燃写法 | 高危写法 |
|---|---|
| 他跪着，剑还立着 | 他站着，敌人全倒了 |
| 他挡不住，但撑到了最后一个人走完 | 他临阵突破，反手全灭 |
| 他把最好的位置让出去，自己蹲角落 | 他把所有人踩在脚下 |
| 她注意到针脚的方向 | 他当众表白，全场鼓掌 |
| 他拿到当时最不值钱的东西 | 宝物自动认主 |
| 他在雷里动摇过，才说“等我” | 他硬扛九雷，毫发无伤 |
| 魔道说出正道不敢说的话 | 正道长篇演讲，反派哑口 |
| 叛徒按了三次才按下去 | 叛徒天生就是坏的 |
| 他舍了情，三十年后还在怕 | 他舍了情，然后遇到新的人 |
| 他忘了她是谁，还记得护她 | 他入魔后立刻清醒 |
| 师父拒收一次，再改口 | 师父一见惊为天人 |
| 对手赢了主角一次，且赢得有理 | 对手永远差一口气 |
| 主角做错一次选择，付了代价 | 主角每次都对 |
| 同门做出了相反但正确的选择 | 同门全是垫脚石 |
| 战后用一章写埋人 | 打完直接庆功 |
| 秘境留下三样后遗症 | 出秘境干干净净 |
| 他把账本上她的名字划掉 | 他当众宣布她是他的人 |
| 飞升前回头看一眼，不解释 | 飞升时万人跪送 |
| 他把戒律碑按碎，只为一个徒弟 | 他从未破过规矩 |
| 他的道被砸碎，人还在 | 他的道从不动摇 |

这张表还有第二种用法：当作桥段复用节奏表。同一列里的桥段不要连着用，读者会疲劳。左列的二十种桥段，按“隔八章用一次”的频率铺开，一本九百章的书刚好铺满，且不会重复。

最后一条纪律：每个桥段都要有一个“不该出现的小东西”。不该出现的旧物、不该在场的人、不该说的一句话。这个小东西是桥段的记忆点，也是读者二创时的抓手。
