# 5.4 情丝暗动桥段

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.4 情丝暗动桥段

仙侠的感情戏不能直说，只能“漏”。漏的方式决定了作品的段位：三流写心动，二流写动作，一流写多余。

### 5.4.1 多余动作的三条法则

法则一 无必要：这个动作对当下的事毫无必要。他明明可以直接把药递过去，却先把瓶口的蜡封刮干净，因为怕她指甲划到。法则二 有重复：同一个多余动作至少出现三次，第三次要变奏。法则三 被看见：必须有一个第三人看见，或者被她自己察觉，否则只是心理活动。

### 5.4.2 优质写法：只写她注意到的那一瞬

优质样段：她把斗篷还给他，他说不必。她转身走了三步，忽然发现斗篷的系带被人重新缝过，针脚是她习惯的那种，从里往外挑。她站住，回头看他，他正在和别人说话，侧脸平静得像什么都没发生。她低下头，把系带又解开，重新系了一次，系成他缝的那个样子。

这段没有一句“喜欢”，全靠“针脚的方向”与“重新系一次”完成。读者会自己在心里补完那句话，这比自己说出来有效十倍。

### 5.4.3 高危写法

高危一是心理独白泛滥：“她不知道，其实他早已心动。”这种写法把读者的活干了，读者只剩旁观。高危二是借第三者解说：“师妹，你看师兄对你多好。”这种写法俗且廉价。高危三是过早表白，第五章就说“我心悦你”，后面四十万字只能反复拉扯同一件事。

### 5.4.4 不同人设的漏法

| 人设 | 漏的方式 | 不该做的事 |
|---|---|---|
| 清冷剑尊 | 替她挡风，站到上风口 | 说肉麻的话 |
| 魔道狠戾 | 把她的名字从账本上划掉 | 当众示爱 |
| 护短师尊 | 把自己的佩剑挂到她腰上 | 越界的身体接触 |
| 少年意气 | 把最好的位置让给她，自己蹲在角落 | 突然深沉 |
| 技术流 | 为她单独炼一样东西，不说用途 | 夸自己手艺 |
