# 14.13 定稿检查的完整流程

> 素材来源：novel-material-skill ·《仙侠题材创作手册》14.13 定稿检查的完整流程

定稿不是“写完最后一章”，是走完一遍流程。下面按顺序给十个步骤，每步都有可执行的判定。

### 14.13.1 十步流程

| 步骤 | 动作 | 判定 |
|---|---|---|
| 一 | 通读开头三章 | 读者能在三章内说出主角是谁 |
| 二 | 核对境界与章数 | 境界与进度表一致，没有跳级 |
| 三 | 核对资源账 | 每一笔大额收支都有场景 |
| 四 | 核对伏笔表 | 未回收项不超过三项，且都在末三卷 |
| 五 | 扫现代词与穿帮语 | 零残留 |
| 六 | 扫破折号与异常标点 | 零残留 |
| 七 | 扫重复桥段 | 同一桥段不超过两次 |
| 八 | 扫配角出场间隔 | 每位配角不超过二十章空窗 |
| 九 | 核对结局三笔账 | 关系、因果、主题都结清 |
| 十 | 写完结附言 | 两百字以内，不提数据 |

十步里最容易跳过的是第五步。现代词不只包括科技词，还包括现代句式：把字句泛滥、被字句滥用、“进行了一次”这类公文腔。这些词会让仙侠瞬间掉档。

第六步的破折号排查，本质是排查“AI 腔”。破折号常出现在情绪转折处，删掉或换成句号、逗号、冒号，文字会立刻像人写的。

### 14.13.2 三个必查的细节

细节一 称呼一致：同一个人被不同人怎么称呼，全书要一致。称呼混乱是最容易被读者发现的错误。细节二 时间一致：季节、月色、天气不要前后矛盾，尤其跨卷时。细节三 数字一致：第几峰、几位长老、多少人、多少里，写之前定一次，之后不再改。

三个细节看起来琐碎，却是“专业感”的来源。读者说不出为什么，但会觉得这本书“讲究”。

### 14.13.3 定稿的最后一次通读

最后一次通读不要做修改，只做记录。把觉得别扭的地方标出来，读完再统一处理。边读边改会打断节奏，也会让作者陷入无限修改。

通读的标准是“是否想继续读”。如果自己在某一章想跳过，那一章就是问题章。作者自己的疲劳感，往往就是读者的疲劳感。
