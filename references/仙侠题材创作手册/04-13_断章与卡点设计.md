# 4.13 断章与卡点设计

> 素材来源：novel-material-skill ·《仙侠题材创作手册》4.13 断章与卡点设计

断章是技术活。断得好的作者，读者会骂一句然后点下一章；断得差的作者，读者会平静地关掉应用。

### 4.13.1 五种断章位置

| 断点 | 效果 | 风险 |
|---|---|---|
| 正要出手时 | 紧张感最强 | 用多了读者会烦 |
| 话说一半时 | 好奇心最强 | 下一章必须给答案 |
| 结果刚出时 | 满足感与期待并存 | 最稳，推荐常用 |
| 视角刚切时 | 悬念感强 | 切换要自然 |
| 平静处 | 余味最好 | 新手慎用，容易掉读者 |

最稳的断法是“结果刚出”：一场比试赢了，但赢的代价刚显现；一个人救回来了，但他醒来第一句话不对。结果已出，悬念未消，读者既有满足感，也有追读动力。

### 4.13.2 卡点的三个层次

小卡点每三章一次，作用是让读者别在段落中间走。中卡点每十章一次，通常是一卷内的小高潮。大卡点每三十章一次，是卷末的大事件。三层卡点错开布置，节奏就有了骨架。

卡点还有一个隐性要求：卡点之后必须给回报。卡了十章，读者期待很高，如果回报不够，信任就会打折。所以大卡点之前要想清楚：这一场到底能给读者什么。

### 4.13.3 断章的字数控制

单章两千到三千字最稳。低于一千五，读者觉得“没内容”；高于四千，手机阅读容易中断。断章位置要落在两千字的自然收尾处，不要为了卡点硬把一个场景切成两半。
