# 11.9 三类结局的章节节奏

> 素材来源：novel-material-skill ·《仙侠题材创作手册》11.9 三类结局的章节节奏

结局不是一章，是一段。下面给出三类结局的收尾节奏，按章数分配。

### 11.9.1 飞升型的收尾节奏（八章）

| 章次 | 内容 | 作用 |
|---|---|---|
| 倒数第八章 | 旧敌清算，因果账结 | 收线 |
| 倒数第七章 | 宗门与同门的去向 | 关系账结 |
| 倒数第六章 | 他把该交代的交代完 | 准备 |
| 倒数第五章 | 与最重要的人一次对话 | 情绪顶点 |
| 倒数第四章 | 渡劫或天门开启 | 高潮 |
| 倒数第三章 | 他在天门下的选择 | 主题 |
| 倒数第二章 | 走进去，回头看 | 余味 |
| 最后一章 | 多年后的一笔 | 收尾 |

八章里最后两章最关键。“回头看”与“多年后的一笔”之间要留白，不要解释他看到了什么、那一笔是谁写的。

### 11.9.2 隐于人间型的收尾节奏（六章）

| 章次 | 内容 | 作用 |
|---|---|---|
| 倒数第六章 | 最后一战或最后一次出手 | 告别旧身份 |
| 倒数第五章 | 把剑收起来，处理旧物 | 仪式 |
| 倒数第四章 | 回到那个地方 | 落地 |
| 倒数第三章 | 重新学做一件凡人的事 | 新生 |
| 倒数第二章 | 有人敲门 | 重逢 |
| 最后一章 | 日常的一天 | 余味 |

这类结局最忌写“他其实还能打”。收尾阶段一次都不要展示他的力量，读者才会相信他真的放下了。

### 11.9.3 BE 型的收尾节奏（七章）

| 章次 | 内容 | 作用 |
|---|---|---|
| 倒数第七章 | 预兆出现，她不说 | 埋疼 |
| 倒数第六章 | 他察觉，但来不及 | 紧张 |
| 倒数第五章 | 她的选择与理由 | 人物 |
| 倒数第四章 | 最后一段时间 | 情绪 |
| 倒数第三章 | 她死，或他道消 | 高潮 |
| 倒数第二章 | 他做的那件小事 | 余味 |
| 最后一章 | 第二天 | 收尾 |

BE 的最后一章不要写葬礼，写第二天。葬礼是仪式，第二天才是生活。生活里的空缺，才是最疼的部分。
