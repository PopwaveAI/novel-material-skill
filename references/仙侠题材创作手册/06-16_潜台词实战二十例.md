# 6.16 潜台词实战二十例

> 素材来源：novel-material-skill ·《仙侠题材创作手册》6.16 潜台词实战二十例

下面二十例按场景分类，每例给“表层”与“里层”，可直接套用。

### 6.16.1 师徒场景五例

| 表层 | 里层 |
|---|---|
| “你的剑，握得太高了。” | 你心不静，我看得出来 |
| “今日不必来听课。” | 我有些事不想让你看见 |
| “这本册子，你自己看。” | 我不能再教你了 |
| “路是自己选的。” | 我拦不住你，也不打算拦 |
| “我记性不好。” | 有些事我永远不会说 |

### 6.16.2 同门场景五例

| 表层 | 里层 |
|---|---|
| “你先去，我随后。” | 这件事我不想跟你一起做 |
| “你的份例我领了。” | 我替你挡了一次罚 |
| “别问，问了也没用。” | 我知道，但不能告诉你 |
| “这次算你运气好。” | 我让了你半招 |
| “山门快关了。” | 你该走了，别再回来 |

### 6.16.3 敌对场景五例

| 表层 | 里层 |
|---|---|
| “你的手在抖。” | 我和你一样怕 |
| “你还有三天。” | 我不想杀你，但必须动手 |
| “坐吧。” | 我们谈谈条件 |
| “你师父当年也这么说过。” | 我认得你师父，且我敬他 |
| “你走吧。” | 我欠你一次，这次还了 |

### 6.16.4 情动场景五例

| 表层 | 里层 |
|---|---|
| “地上凉。” | 别坐在地上，我心疼 |
| “粥在灶上。” | 我等你回来 |
| “你的袖子破了。” | 我一直在看你 |
| “下次来，带点别的。” | 下次还要来 |
| “门别关。” | 我怕黑，也怕一个人 |

二十例的共同结构是“表层全是实务，里层全是情”。写台词时先想“这句话有什么用”，再想“这个人真正想说什么”，两句话之间的距离就是潜台词。

还有一条纪律：里层不能每一句都深。二十句台词里，最多五句有潜台词，其余直说。全是潜台词，读者会累；全无潜台词，读者会觉得白。
