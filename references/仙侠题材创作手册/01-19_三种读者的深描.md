# 1.19 三种读者的深描

> 素材来源：novel-material-skill ·《仙侠题材创作手册》1.19 三种读者的深描

写之前先想清楚“读者是谁”，比想清楚“故事是什么”更重要。三种读者最典型。

### 1.19.1 快感型读者

他读仙侠是为了“爽”。他要的是打脸、越级、扬名、收服。他不介意设定简单，介意憋屈；不介意套路，介意拖。给他三章一次小爽、十章一次大爽，他就会一直追。

写给他看的方法是“前置”：把爽点提前，把铺垫压后。不要为了“合理”先解释三章，读者会在第二章走。合理性可以在爽完之后补。

### 1.19.2 沉浸型读者

他要的是“这个世界是真的”。他愿意读三万字的铺垫，只要那铺垫里有生活。他会计较境界、物价、人情、地理，会在评论区算你的账。

写给他看的方法是“落实”：每一个设定都要有成本，每一次胜利都要有代价。他最讨厌的是“作者忘了”，最喜欢的是一句“原来三个月前那个细节是这个意思”。

### 1.19.3 情感型读者

他要的是“这两个人值不值得”。他能忍受慢节奏，不能忍受人物走形。他会为一句台词截图，会为一个人物的死写长评。

写给他看的方法是“留白”：不要解释情绪，给动作；不要总结关系，给细节。他最喜欢的是“什么都没说，但我知道”。

### 1.19.4 三类读者的配比

| 作品类型 | 主读者 | 兼顾 |
|---|---|---|
| 正统逆袭、飞升流 | 快感型 | 沉浸型 |
| 凡人流、写实修仙 | 沉浸型 | 情感型 |
| 师徒恋、仙魔对立 | 情感型 | 快感型 |
| 无 CP、群像 | 沉浸型 | 情感型 |

配比的原则是“一类为主，一类兼顾”。三类都想要，结果三类都不满意，因为三类的要求互相冲突：快感型嫌慢，沉浸型嫌飘，情感型嫌糙。

还有一个现实：读者会变。追了半年之后，快感型读者也会开始在意人物，情感型读者也会开始算设定。所以前期主打一类，后期兼顾三类，是最稳的策略。
