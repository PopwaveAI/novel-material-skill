# 5.17 桥段的长度控制

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.17 桥段的长度控制

一个桥段写多长，决定它是“名场面”还是“注水”。

| 桥段 | 建议长度 | 超过会怎样 |
|---|---|---|
| 拜师 | 600 至 900 字 | 变成说教 |
| 夺宝 | 1200 至 1800 字 | 变成寻宝流水账 |
| 护道 | 1500 至 2200 字 | 变成持续打斗 |
| 情动 | 400 至 700 字 | 变成言情 |
| 渡劫 | 1800 至 2500 字 | 变成特效秀 |
| 对峙 | 1000 至 1500 字 | 变成辩论 |
| 叛变 | 800 至 1200 字 | 变成审案 |
| 舍情 | 500 至 800 字 | 变成煽情 |

长度控制的原则是“一个桥段一个核心动作”。核心动作写透，其余全部压掉。所谓核心动作，就是读者会记住的那一下：他跪下了、他把剑插回鞘里、他没有回头。

写完一段，问自己三个问题：核心动作是什么、它出现在第几段、它后面还有没有多余的东西。三个问题答完，长度自然就对了。
