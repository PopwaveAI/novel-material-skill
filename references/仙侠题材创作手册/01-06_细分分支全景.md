# 1.6 细分分支全景

> 素材来源：novel-material-skill ·《仙侠题材创作手册》1.6 细分分支全景

仙侠的十个主要分支，各有各的读者、各有各的死法。下面逐条给出定义、代表作特征（只讲结构，不点名具体作品）、核心爽点与最容易翻车的地方。写之前选定一条主干，不要混着写。

### 1.6.1 正统修真逆袭

结构：凡人测灵根、入宗门、逐级突破，主线是境界与地位的双重攀升。核心爽点：清楚的进度条与当众立威。最容易翻车：境界升级全靠闭关，读者看不到博弈。补救：每个境界都绑一个具体的世俗利益，比如筑基才能护住一座灵田，金丹才能替师门挡下一场问罪。

### 1.6.2 师徒恋与师尊重生

结构：以师徒关系为情感主轴，师尊往往背负旧伤或旧劫，徒弟是变数。核心爽点：禁忌感、护短、师尊掉价。最容易翻车：师尊全程高冷无破绽，感情无法推进。补救：给师尊安排“三次失守”，第一次是道心裂缝，第二次是护徒越界，第三次是为徒改道，详见第五部分 5.4。

### 1.6.3 仙魔对立

结构：两套秩序的战争，正道未必正，魔道未必恶。核心爽点：立场反转与阵营壮阔。最容易翻车：把魔道写成纯粹的坏人堆。补救：给魔道一条自洽的价值主张，比如“弱者的命凭什么由天定”，让读者在骂的时候也点头。

### 1.6.4 仙门世家

结构：以家族为核心单位，讲资源、婚约、嫡庶、门第。核心爽点：族内斗争与联姻博弈，接近仙侠版宅斗。最容易翻车：家族内部戏太多，修行线失重。补救：把每一场族斗都绑一次修行资源的重新分配，让斗争直接换算成实力。

### 1.6.5 散修江湖

结构：无门无派，靠接单、走货、闯秘境活着，接近修仙版江湖。核心爽点：自由、野路子、信息差套利。最容易翻车：没有组织支撑，剧情容易散。补救：给他一个固定的落脚点，比如一间铺子、一支小队、一座破庙，用“据点”代替“宗门”。

### 1.6.6 飞升流

结构：把“飞升”当成明面上的主目标，全书围绕渡劫与天门展开。核心爽点：目标感极强，进度条最短最亮。最容易翻车：飞升之后没戏可写。补救：在飞升前就把“上界并不更好”的伏笔埋好，飞升本身成为一次幻灭与重建。

### 1.6.7 凡人流

结构：主角资质平庸，全靠算计、资源与时间熬上去。核心爽点：真实感、苟且中的智慧。最容易翻车：节奏过慢，读者中途弃书。补救：每二十章安排一次“非战斗型胜利”，比如用一张假契据换到一座药田，让读者尝到智力爽。

### 1.6.8 老子孙辈流

结构：主角出身极高，自带资源与靠山，写的是“如何配得上这份出身”而非“如何爬上去”。核心爽点：排场、传承、被期待。最容易翻车：主角没有真实困境，读者无从代入。补救：把困境从“外部打压”换成“内部期待”，比如他不愿意继承家学，或他的天赋与家族道统相冲。

### 1.6.9 无 cp 修真

结构：不设情感主线的纯修行叙事。核心爽点：纯粹的道、极致的体系、师徒同门的群像。最容易翻车：情绪缺位，读者只看到设定。补救：用“道侣以外”的关系补温度，师徒、挚友、器灵、旧敌都能承担情绪功能，详见第十二部分 12.7。

### 1.6.10 分支选择速查表

| 写作目标 | 推荐分支 | 理由 |
|---|---|---|
| 新人第一本，求稳 | 正统修真逆袭 / 凡人流 | 结构清楚，爽点明确，读者预期稳定 |
| 擅长写感情 | 师徒恋 / 师尊重生 | 情绪密度高，人物关系自带张力 |
| 擅长写权谋 | 仙门世家 / 仙魔对立 | 阵营与利益结构天然成立 |
| 擅长写悬疑 | 散修江湖 / 因果宿命 | 信息差与旧案可以做主线 |
| 想做短视频改编 | 飞升流 / 仙魔对立 | 设定一句话讲得清，画面对撞强 |
| 已有读者盘子，想突破 | 老子孙辈流 / 无 cp 修真 | 反预期，能跳出同质化 |
