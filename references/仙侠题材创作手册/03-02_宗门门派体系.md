# 3.2 宗门门派体系

> 素材来源：novel-material-skill ·《仙侠题材创作手册》3.2 宗门门派体系

宗门是仙侠的社会单位，它同时承担三个功能：给主角规矩、给主角资源、给主角敌人。设计宗门时不要只画山门图，要画利益结构图。

### 3.2.1 三层结构与职级

一个成熟宗门分三层：外门（杂役、记名弟子，负责劳作与低阶任务）、内门（正式弟子，按峰分配，负责执行与战斗）、核心（长老、峰主、宗主，掌握资源与决策）。三层之间的通道只有一个：考核。考核就是全书最好用的冲突发生器。

| 职级 | 权限 | 资源配给 | 典型冲突 |
|---|---|---|---|
| 杂役 | 无 | 每月三块下品灵石 | 被克扣、被顶罪 |
| 外门弟子 | 接低阶任务 | 每月十块下品灵石 | 任务分配不公 |
| 内门弟子 | 入藏经阁一层 | 每月一块中品灵石 | 峰与峰之间的排位 |
| 亲传弟子 | 随师修行 | 按师分配，差距极大 | 师门内部的偏爱 |
| 执事/峰主 | 调配一峰资源 | 每年定额 | 资源截留与账目 |
| 长老会 | 议定门规 | 宗门大阵、秘境名额 | 路线之争 |

路线之争是宗门戏的最高级冲突：保守派要守住山门，激进派要开疆拓土，两派都有道理，主角必须选一边。选完就要承担后果，这个后果能撑起整卷。

### 3.2.2 门规的写法

门规不是墙上的字，是随时能落下来的刀。写门规要写三条就够：一条不准弟子私斗，一条不准外传功法，一条不准擅入后山。三条规矩看起来无关，实则是三个伏笔位：私斗引出恩怨，外传功法引出背叛，后山引出秘密。

还有一条铁律：每一条门规都要被破一次，破的时候要有代价。规矩立了不用，读者会觉得这个世界是空的。

### 3.2.3 山门地理与阵法

山门地理决定战术。前山是门面，有迎客松与大阵；中峰是核心，藏经阁、丹房、器堂在此；后山是禁地，往往封印着宗门最不愿提的旧事。三块地形分别对应三种剧情：前山写脸面，中峰写资源，后山写秘密。

护山大阵要写清三件事：怎么开、耗什么、能挡谁。开会耗灵石，挡得住化神，挡不住大乘。有了这三条，读者就能自己算出“敌人打进来需要多久”，紧张感自动生成。
