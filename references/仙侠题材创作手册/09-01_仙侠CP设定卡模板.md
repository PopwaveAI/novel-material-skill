# 9.1 仙侠 CP 设定卡模板

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.1 仙侠 CP 设定卡模板

本部分的六张表是本册的工作台。它们的作用不是记录灵感，是把灵感变成可执行的进度。建议全部录入表格软件，每写完一卷回填一次，写完全书再对照一次。

CP 卡解决的是“两个人凭什么在一起、又凭什么不能在一起”。填满这张卡，感情线的骨架就成立了。

| 字段 | 填写要求 | 示范 |
|---|---|---|
| 双方身份 | 各写一句，含宗门与位置 | 她：外门药童；他：守山剑尊 |
| 力量差 | 差几级，差在什么地方 | 差两大境，他一根手指能压住她 |
| 初见场景 | 在哪里、因为什么事 | 她偷摘他院里的药，被他抓住手腕 |
| 初见误会 | 他/她当时误判了什么 | 他以为她是探子，她以为他是管事 |
| 吸引点 | 各写一条，必须具体 | 他：她不怕他；她：他记得她说的每句话 |
| 互补处 | 一个缺什么，另一个有什么 | 他缺人味，她缺靠山 |
| 对撞处 | 两人必然冲突的一件事 | 他要守山，她要下山找亲人 |
| 共同秘密 | 只有两人知道的事 | 那夜山门外的火，两人都在场 |
| 关系阻碍一 | 外部阻碍 | 门规不许弟子与守山人私交 |
| 关系阻碍二 | 内部阻碍 | 他不肯承认在意 |
| 关系阻碍三 | 宿命阻碍 | 她的命格克师门 |
| 第一次越界 | 谁先破的规矩，怎么破 | 她替他挡了一剑，他第一次下山的界 |
| 第一次冷战 | 因为什么，持续多久 | 他瞒了她的身世，冷战二十章 |
| 最大危机 | 会失去什么 | 她若知道真相，必须离开山门 |
| 关键道具 | 三样承载感情的物件 | 药锄、旧剑穗、一盏灯油 |
| 专属动作 | 只对彼此做的动作 | 他替她理药筐的绳结 |
| 专属称呼 | 怎么叫对方，何时改口 | 从“前辈”到“阿昭” |
| 确认时刻 | 在哪一章、因为什么 | 第两百章，她中毒，他剖了自己的血 |
| 公开时刻 | 在哪一章、代价是什么 | 第两百六十章，他当众认下她，被罚守山百年 |
| 结局选项 | 三种可能 | 相守、他飞升她留下、双双归隐 |

填卡的三条纪律。第一，吸引点必须具体到一件小事，不能写“她很善良”。第二，对撞处必须是两人都无法让步的事，能让步的冲突撑不起长篇。第三，共同秘密必须在正文里被读者知道，只有角色知道而读者不知道的秘密，会让读者觉得被排除在外。

填完之后做一次压力测试：把“关系阻碍”三行中的任意两行删掉，感情线还能不能撑住一百章？撑不住，说明阻碍设计得太薄。
