# 13.9 开书前后的运营日历

> 素材来源：novel-material-skill ·《仙侠题材创作手册》13.9 开书前后的运营日历

运营不是天天发帖，是在正确的时间做一件正确的事。下面按时间轴给出动作，全部是作者给自己的书做的。

### 13.9.1 开书前：十四天

| 时间 | 动作 | 目的 |
|---|---|---|
| 前十四天 | 定书名与简介，找三个人试读简介 | 确认卖点能被听懂 |
| 前十天天 | 写五条短视频脚本，不拍 | 确认能讲清 |
| 前七天 | 准备三张信息图（人物、境界、名场面） | 素材就位 |
| 前三天 | 发第一条预告，只给场景不给结论 | 预热 |
| 前一天 | 发开书时间与一句话卖点 | 告知 |

预热阶段的纪律是“不刷屏”。三条以内，每一条都给一个新东西：一个场景、一个人物、一句台词。给完就停。

### 13.9.2 开书首周：七天

| 时间 | 动作 | 目的 |
|---|---|---|
| 第 1 天 | 发开篇场景的一条短视频 | 引流到第一章 |
| 第 2 天 | 发人物关系图 | 让读者看到结构 |
| 第 3 天 | 发一条“我为什么写这个故事” | 建立作者面孔 |
| 第 4 天 | 不回评论，专心存稿 | 保证更新 |
| 第 5 天 | 发一句可截图的台词 | 制造传播点 |
| 第 6 天 | 发读者提问的回应（挑一个） | 互动 |
| 第 7 天 | 发一周小结，只写数据与感受 | 真实感 |

首周最容易犯的错是“过度运营”：一天发五条，读者会屏蔽。七天内五条内容足够。

### 13.9.3 长线运营：每月四件事
- 一件内容：一条场景型短视频或一组图文，给新读者。
- 一件互动：回答一个读者问题，或者晒一次修改过程。
- 一件透明：公布一次数据或一次卡文，让读者看到真实。
- 一件沉淀：整理一章的写作笔记，给老读者。

四件事一个月做完就够。运营的目的不是每天出现，是让读者在想起你的时候，能找到新的东西。
