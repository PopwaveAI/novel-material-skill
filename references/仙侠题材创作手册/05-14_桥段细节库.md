# 5.14 桥段细节库

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.14 桥段细节库

桥段的差距往往不在结构，在细节。下面按桥段类型给出可替换的细节模块，每个模块都能直接嵌进场景里。

### 5.14.1 拜师桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 进门那一刻 | 门槛高／门槛被踩塌一角／门槛上有一道旧痕 |
| 师父在做什么 | 磨剑／晒药／闭目／看一份旧名册／喂一只不叫的鸟 |
| 第一句话 | “你走错了。”／“站进来。”／“把手伸出来。”／不说话，只看了他一眼 |
| 考验方式 | 让他端一盆水站到日落／让他抄一遍门规／让他说一件自己做过的错事 |
| 拒的理由 | 他资质不够／他心不静／他来历不明／他太像某个人 |
| 再收的理由 | 他站到了日落／他把门规抄错了一处并指出／他说了真话 |
| 收徒的仪节 | 一杯茶／一枚旧牌／一句只有两人懂的暗语／把剑穗解下来给他 |

### 5.14.2 秘境桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 入口 | 石门／井／裂缝／一棵枯树的树洞／水面倒影 |
| 开启条件 | 特定时辰／三枚令牌／一句口诀／一个人的血 |
| 第一印象 | 极冷／极静／有风但没有来源／脚下不是土 |
| 规矩提示 | 刻在墙上／由先来者口述／用死者的姿态暗示 |
| 价值倒置的旧物 | 一块被当垫脚石的玉／一枚被磨平的棋子／一页被撕的书／一把断了的梳子 |
| 第一次危机 | 路塌了／同伴不见了／时间流速不对／有东西在模仿人声 |
| 出口 | 原路已封／需献出一物／需答一问／需等下一次灵潮 |

### 5.14.3 护道桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 他要护的人 | 师妹／师弟／凡人／一个刚认识的孩子／一个他不喜欢的人 |
| 护的理由 | 答应过别人／规矩所在／他自己也不知道为什么 |
| 他能撑多久 | 三招／半炷香／一炷香／到天亮 |
| 他撑不住时的表现 | 手抖／视线发黑／耳朵听不见／站不起来 |
| 对方的强 | 高一层境界／人多／有备而来／带着他不能杀的人 |
| 代价 | 断一臂／毁一件法器／道基留裂／让敌人记住他的脸 |
| 事后 | 他先看被护的人有没有事，才看自己的伤 |

### 5.14.4 情动桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 场景 | 药炉边／雨里／灯下／长廊／山门外／一间空屋 |
| 多余动作 | 把外袍解下来又系上／拿起一样东西又放下／伸手又收回／说了一句无关的话 |
| 观察点 | 对方的手／对方的鞋／对方说话时的停顿／对方袖口的补丁 |
| 心动信号 | 他记得她随口说过的话／他把最好的位置留给她／他没有走 |
| 克制的理由 | 身份／誓言／旧伤／她不属于他 |
| 第三方插入 | 同门来找／一声钟响／一个人从远处走来／她先开口说她要走 |

### 5.14.5 渡劫桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 劫前 | 他把该交代的交代完／他把剑擦了一遍／他坐在崖边看云 |
| 劫的形态 | 九道雷／心魔幻象／旧人重现／记忆被抽走 |
| 劫中他做的选择 | 舍一件东西／认一次错／放一个人／回头看一眼 |
| 代价 | 听不见某种声音／忘记某个人／身上多一道旧疤／少十年寿 |
| 旁观者 | 师妹站在山下／同门在远处数雷／守山人在关外 |
| 劫后 | 他第一句话问的不是自己 |

### 5.14.6 仙魔对峙桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 见面地点 | 界河／断桥／一座废城／雪原／一间无人守的祠堂 |
| 开场 | 对方先坐／他先开口／两人都不说话，先看对方的手 |
| 三回合 | 第一回合讲规矩，第二回合讲旧事，第三回合讲价 |
| 对手的道理 | 魔道讲的是“你们也一样”／他讲的是“我至少承认” |
| 让步 | “我杀不了你，但我可以等你死”／“这一次算我输”／“你走吧” |
| 破裂的信号 | 对方提了一个他不能答的条件／一个人质被带上来 |

### 5.14.7 宗门叛变桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 叛前的伏笔 | 他总在夜里出去／他换过剑穗／他记着每个人的作息／他问过一句多余的话 |
| 揭穿场合 | 议事厅／大比场／灵脉口／一场葬礼 |
| 证据形式 | 一枚令牌／一封信／一份账／一个活人 |
| 叛徒的理由 | 家人被扣／他被许诺过一次机会／他真心觉得这样更好 |
| 主角的反应 | 不出手／先问为什么／替他说一句话 |
| 之后 | 叛徒逃走／叛徒被杀／叛徒留下一样东西 |

### 5.14.8 为道舍情桥段的细节模块

| 细节位 | 可选项 |
|---|---|
| 分别地点 | 天门下／山门口／渡口／一间正在关门的药铺 |
| 她的反应 | 不哭／先说一句家常话／把手里的东西递给他／转身先走 |
| 他的反应 | 不解释／把外袍留下／说了三个字／站着不动 |
| 留下的物 | 一枚旧牌／一双鞋／半页纸／一件没补完的衣服 |
| 三年后的回响 | 他在她的坟前／她在他的旧屋前／两人在不同的地方做同一件事 |

八个细节库共五十六组模块，够支撑一部长篇的桥段写作。用法是“一次只换一个模块”：场景不变，换细节；细节不变，换反应。一次换太多，读者会觉得这是另一个桥段。
