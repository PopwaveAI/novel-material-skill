# 2.5 废柴逆袭

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.5 废柴逆袭

废柴逆袭是男频的入场券，写法已经非常成熟，但仍有空间：把“废”写得具体，把“起”写得有代价。

### 2.5.1 废的四种具体化

资质废：灵根残缺、经脉断裂、丹田有旧伤。出身废：杂役、奴籍、被逐出族。名声废：背着一口黑锅，人人都说他害死了同门。关系废：唯一护他的人死了，从此无人替他说话。四种可以叠加两种，超过三种读者会觉得作者在虐待主角。

废的证据要具体。不要写“他资质很差”，要写“测灵石上只亮了一格，执事看了一眼就把石头收了，说不用测了”。这种细节比任何形容词都有效。

### 2.5.2 起的三条铁律

第一条起于绝境：他必须先被逼到没有退路，才动手。第二条起于代价：第一次翻身必须付东西，寿元、师门、朋友、一条腿。第三条起于不可复制：他的翻盘方式必须是独一份的，别人学不来，读者才会觉得“这是他的命”。

最忌讳的写法是“捡到一本神功，从此一飞冲天”。不是不能捡，而是捡了要付账：功法有反噬、有前主人的因果、有被追杀的麻烦。有一个代价，金手指就从作弊变成了命运。

逆袭节奏：第三章第一次小胜（智取），第十二章第一次正面对抗，第二十五章第一次被真正承认。
