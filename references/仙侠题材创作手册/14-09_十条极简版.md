# 14.9 十条极简版

> 素材来源：novel-material-skill ·《仙侠题材创作手册》14.9 十条极简版

时间不够的时候，只查这十条。十条全过，稿子的下限就有了。
- 一 前三百字有没有一个具体的屈辱或麻烦。
- 二 前三章有没有一次小规模的高光。
- 三 主角有没有一个说得出口的具体目标。
- 四 他有没有真的失败过一次，且付了代价。
- 五 反派有没有一套站得住的道理。
- 六 感情线有没有三次确认，且不靠误会拖戏。
- 七 境界与社会位置有没有同步变化。
- 八 金手指有没有边界，用过是否付账。
- 九 结局的三笔账有没有结清。
- 十 全书有没有一句能被读者记住并截图的话。

十条里最容易被忽略的是第四条与第九条。前者决定作品的重量，后者决定读者的评价。两条都过，这本书至少在结构上是完整的。

最后一句：清单不是枷锁，是护栏。它不保证你写出神作，但它能保证你不犯那些一眼就能看出来的错误。把错误清干净，剩下的就是你的才华该负责的部分了。
