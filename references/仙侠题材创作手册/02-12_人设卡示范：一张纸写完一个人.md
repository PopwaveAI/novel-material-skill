# 2.12 人设卡示范：一张纸写完一个人

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.12 人设卡示范：一张纸写完一个人

下面这张卡是本册的标准格式，写人设时直接照抄填空，填不满就说明人设还没立住。

| 字段 | 填写要求 | 示范（清冷剑尊） |
|---|---|---|
| 一句话人设 | 不超过二十字，含身份与性格 | 守山三十年的剑尊，剑不出鞘则已 |
| 核心欲望 | 具体到一件事，不写抽象词 | 把当年那场屠门案的凶手找出来 |
| 核心恐惧 | 他怕失去什么，怕到会做错事 | 怕自己护不住最后一个同门 |
| 致命缺陷 | 让他吃亏的性格硬伤 | 从不解释，任人误会 |
| 行事逻辑 | 一定会做与绝不会做各一条 | 一定会赴约；绝不会先说软话 |
| 表层标签 | 三句话内让人记住 | 素衣、旧剑、慢半步 |
| 底层创伤 | 一件具体旧事，带画面 | 十七岁那年，他亲眼看着师门被烧 |
| 反差点 | 对外与对内各写一个画面 | 杀人时不眨眼；给师妹削果子时手很稳 |
| 成长弧 | 起点、转折、代价各一句 | 从守一座山，到守一个人，代价是道基 |
| 适配桥段 | 列三个最出彩的场 | 问剑、护道、渡劫 |

这张卡要在开书前填完，之后每写十章回填一次，检查有没有跑偏。跑偏的判断标准很简单：如果把卡上的“核心欲望”换成另一个，故事是否照样成立？成立就说明人设没在驱动剧情，需要重写。

最后提醒一句：人设卡不是合同，允许改。但每次改都要记录改的理由，否则三十章之后你会忘记自己为什么这么写，人物就散了。
