# 9.9 人设卡填写完整范例

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.9 人设卡填写完整范例

下面给出两张填满的卡，一张男主，一张女主，示范“每一格都要能落地”。

### 9.9.1 男主卡范例

| 字段 | 填写内容 |
|---|---|
| 姓名与身份 | 谢停云，守山剑尊，青云十二峰第七峰守山人 |
| 一句话人设 | 守山三十年，剑不出鞘，人不下山 |
| 核心欲望 | 查清三十年前那一场烧了师门的火是谁放的 |
| 核心恐惧 | 怕自己护不住最后一个同门 |
| 致命缺陷 | 从不解释，任人误会 |
| 行事逻辑 | 一定赴约；绝不说软话；答应的事绕路也做到 |
| 表层标签 | 素衣、旧剑、慢半步 |
| 中层行为 | 递东西擦一下、说话先沉默三息、喝茶只喝半杯 |
| 底层创伤 | 十七岁那年亲眼看着师门被烧，他躲在井里 |
| 反差点 | 杀人时不眨眼；给师妹削果子时手很稳 |
| 专属动作 | 把外袍解下来丢给人，一句话不说 |
| 口头禅 | 不必。让开。只此一次。 |
| 成长弧 | 从守一座山，到守一个人，代价是道基留裂 |
| 关系网 | 师父（已死）、师弟（叛）、师妹（误会他）、仇人（峰主） |
| 适配桥段 | 问剑、护道、渡劫、舍情 |

### 9.9.2 女主卡范例

| 字段 | 填写内容 |
|---|---|
| 姓名与身份 | 阿昭，外门药童，后为内门弟子 |
| 一句话人设 | 偷药被抓的那天，她第一次抬头看人 |
| 核心欲望 | 找到被逐出家的弟弟 |
| 核心恐惧 | 怕自己又变成没人要的那个 |
| 致命缺陷 | 太容易相信给过她一点好的人 |
| 行事逻辑 | 一定先道歉再辩解；绝不欠人情；答应的事宁可自己吃亏 |
| 表层标签 | 手上总有药味、说话先低头、跑得很快 |
| 中层行为 | 把药渣留着再煎一次、记别人的口味、夜里磨药 |
| 底层创伤 | 七岁那年，弟弟被人从她手里抱走，她没抓住 |
| 反差点 | 对所有人客气，唯独对他会顶嘴 |
| 专属动作 | 把别人给的东西藏在袖子里，藏很久 |
| 成长弧 | 从被人护着，到能护住别人，代价是知道真相 |
| 关系网 | 弟弟（失踪）、守山人（护她）、同门（利用她）、峰主（要她） |
| 适配桥段 | 情动、护道、被叛、重逢 |

两张卡对照看，能看出“对撞处”在哪里：他要守山，她要下山找人；他不解释，她太容易信人。这两处对撞，就是全书感情线的主要燃料。
