# 3.3 法宝、丹药与修行资源

> 素材来源：novel-material-skill ·《仙侠题材创作手册》3.3 法宝、丹药与修行资源

资源体系是仙侠的经济系统，它决定了主角为什么必须出门、为什么必须和人打交道。资源写不清，剧情就只能靠“作者安排”。

### 3.3.1 法宝品阶与代价

| 品阶 | 对应境界 | 特点 | 使用代价 |
|---|---|---|---|
| 凡器 | 炼气 | 凡铁淬灵，易折 | 无 |
| 灵器 | 筑基 | 有灵性，可温养 | 需定期以精血喂养 |
| 宝器 | 金丹 | 自带一式神通 | 每次动用耗三成法力 |
| 灵宝 | 元婴 | 可变化形态，护主 | 与主人神魂相连，主人伤则宝伤 |
| 仙器 | 化神以上 | 自带规则，可斩因果 | 每次使用折一段寿元 |
| 先天至宝 | 传说 | 开天遗留，认主极难 | 认主即背负其因果 |

代价栏是这张表的灵魂。没有代价的法宝只是道具，有代价的法宝才是角色。给主角一件每次使用都要折寿的剑，读者每次看到剑出鞘都会心疼，这就是最好的紧张感。

### 3.3.2 丹药的三档与失败率

丹药分三档：疗伤丹（回血、续命、压制旧伤）、破境丹（辅助突破，有反噬）、异丹（改命、改资质、改记忆，每一颗都是一次剧情转折）。异丹不要多给，一本长篇给两到三颗就够，每颗都要引发一场争夺。

炼丹写成工序：择材、去杂、控火、凝液、结丹、养丹。每步给失败率，读者就会相信这套手艺是真的在赌命。失败要有画面：炸炉、糊味、丹成却只有半颗、丹成却带黑纹。

### 3.3.3 灵石经济与稀缺感

灵石是仙侠的货币，也是最容易被写崩的地方。给一套可用的换算与价格锚点：下品灵石是日常，中品灵石是弟子月俸，上品灵石是宗门级交易，极品灵石只出现在秘境与拍卖会。一柄灵器值三十块中品，一枚破境丹值两块上品，一座小灵脉年产百块上品。

有了价格锚点，所有剧情都能换算成“他缺多少钱”。缺钱就是最好的动机：接任务、进秘境、替人背锅、被迫和人合作，全部自然成立。

稀缺感要持续维持。主角一旦富了，资源线就失效，所以要安排“通胀”：境界越高，消耗越大，化神修士一次闭关要烧掉一条灵脉。永远让他差一点，故事永远有推力。
