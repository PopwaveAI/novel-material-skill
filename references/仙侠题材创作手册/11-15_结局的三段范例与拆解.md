# 11.15 结局的三段范例与拆解

> 素材来源：novel-material-skill ·《仙侠题材创作手册》11.15 结局的三段范例与拆解

下面三段是同一部作品的三种结局版本，均为本册自建素材，用来说明“同一个准备，可以落成三种不同的收束”。

### 11.15.1 版本一：飞升

样段：天门开的时候，山门外的风停了。他把剑从鞘里抽出来，看了一眼，又插回去，插在石缝里，剑身入石三分。他往天门走了七步，第七步落地，他停了。停下来之后他没有转身，只把右肩往后压了一点，像是要回头，又像只是站着。然后他走了进去。天门关上时没有声音，那把剑在石缝里晃了一下。

拆解：全段四个动作：插剑、七步、压肩、走进去。压肩是唯一的“回头看”，且没有真的回头，这就是克制。

呼应：剑插在石缝，呼应开篇他蹲着捡纸屑的那一幕：那时候他什么也没有，现在他留下了一样东西。

风险：如果加一句“他知道这一去再无归期”，全段就废了。

### 11.15.2 版本二：隐于人间

样段：药铺开在镇子东头，门板是他自己上的漆，上得不匀。他每天卯时开门，先擦一遍柜台，再去看灶上那锅药。有人问他为什么不开大些，他说够吃就行。第三年冬天，一个客人站在门口看了很久，才推门进来。他抬头，说：“要什么药。”客人说：“找你。”他把手里的药杵放下，放得很慢，放到底才松手。

拆解：“漆上得不匀”写出了他的笨拙与满足；“药杵放得很慢”写出了他心里的波动，全段没有一句情绪词。

呼应：开篇他被执事划掉名字，现在他给自己上了一块门板，名字这件事被换了一种写法。

风险：如果让他一见面就红了眼眶，克制全失，归隐的分量也没了。

### 11.15.3 版本三：BE

样段：她走的那天下小雨。他把她的东西收进箱子里，收得很整齐：衣服在下，书在上，那支摔弯了又掰直的笔放在最上面。收完他坐在箱子上，坐到雨停。第二天他照常起来，煮了两碗粥，摆好，才想起只有一个人。他把另一碗端到窗台上，放凉了。第三天、第四天他都端。到第十天，窗台上那碗粥没有动过，他才不再端了。

拆解：“笔”呼应了她被羞辱时掰直笔尖的那一幕，一件旧物把两个人绑了一辈子。

呼应："两碗粥"呼应开篇她给他送粥的那一段，前后同一件事，意义完全相反。

风险：如果在第十天加一句“他终于哭了”，读者会失去自己感受的空间。

### 11.15.4 三种结局的共同技术

| 技术 | 说明 |
|---|---|
| 只写动作 | 不写情绪，让动作承担一切 |
| 物件呼应 | 用开篇的旧物收束，读者自己会想起 |
| 时间刻度 | 七天、十天、三年，把悲伤量化 |
| 一次克制 | 最想写的那句煽情话，删掉 |

四种技术里，“删掉最想写的那句”最难。作者往往舍不得，而正是那句删掉的话，让结局从“好看”变成“记得住”。

三个版本的对照也说明：结局的质量不取决于选了哪一种，而取决于准备是否充分。伏笔埋够，任何一种结局都能成立；伏笔没埋，选最圆满的也会显得仓促。
