# 5.16 名场面的镜头语言

> 素材来源：novel-material-skill ·《仙侠题材创作手册》5.16 名场面的镜头语言

同一个桥段，镜头给谁、给多远、给多久，决定读者记住什么。下面按镜头类型给出用法。

### 5.16.1 六种镜头

| 镜头 | 写法 | 效果 |
|---|---|---|
| 特写 | 只写手、眼、一个物件 | 压迫与情绪 |
| 中景 | 写两个人的动作与距离 | 关系与对峙 |
| 全景 | 写场面与人数，不写脸 | 格局与残酷 |
| 背影 | 只写他的背与走的方向 | 告别与决意 |
| 空镜 | 写一个没有人的地方 | 余味与时间 |
| 错位 | 写旁观者的眼，不写主角 | 距离与敬畏 |

六种镜头里“错位”最高级。主角出手时，不写主角，写围观者的脸和他们的后退，读者自然知道那一招有多重。

### 5.16.2 镜头的切换节奏

一场戏里镜头切换不要超过三次。三次以内，读者跟得上；超过三次，读者会晕。切换的规律是“由远及近”：先全景交代场面，再中景写对峙，最后特写落在一样东西上。

示例：山门前三百人对峙（全景）→ 他与峰主隔着七步（中景）→ 他腰间的旧牌（特写）。三个镜头写完一场对峙，不用一句“气氛凝重”。

### 5.16.3 名场面的三个停顿

真正的名场面都有停顿。停顿一 出手前：他不动，对面也不动，读者屏息。停顿二 结果后：尘埃落定，他站着，读者需要消化。停顿三 离开时：他转身走，走到第三步读者才反应。

三个停顿里第二个最重要。很多作者一打完就接下一场，读者情绪没有落地，高潮就白费了。给两百字让尘埃落下，比再打一场更有效。

### 5.16.4 名场面的声音与静默

声音能放大场面：雷、钟、水、风、剑出鞘的那一声。但更高级的是静默：一场大战之后，只剩下血滴在石头上的声音。写静默时，要把所有声音都撤掉，只留一个最细的。

示例：他收了剑，山门前没有人说话。风停了。过了很久，有人咽了一口口水。这一声比任何欢呼都响。
