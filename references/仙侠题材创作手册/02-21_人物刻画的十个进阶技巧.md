# 2.21 人物刻画的十个进阶技巧

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.21 人物刻画的十个进阶技巧

前面几节讲的是人物的骨架，这一节讲怎么让骨架长出肉。十个技巧都是可操作的，每条配一个本册自建的短例，不对应任何作品原文。

### 2.21.1 技巧一：给一个人一个不肯做的事

人物最容易立住的不是他做了什么，是他死活不做的那一件事。清冷剑尊不肯解释，护短师尊不肯承认自己护不住，魔道狠戾者不肯杀孩子。这个“不肯”要贯穿全书，被诱惑三次，被逼三次，第三次之后他才可能破例，而破例就是他的人物弧线。

示例：他从不喝别人递的茶。第一次有人递茶，他推回去；第二次他接了但没喝，放在桌上；第三次他一口气喝完，因为那天他需要一点热的东西。三次之后，读者就知道这个人变了。

### 2.21.2 技巧二：让他的优点伤到人

优点不带刺，人物就是纸片。护短的人护得太过，害了被护的人；守信的人守得太死，错过了救命的机会；冷静的人在关键时刻冷静得让人心寒。优点伤人，读者才会又爱又恨。

示例：他答应过一个人不再动杀念。这个承诺救了他的道心，也让一个恶人在他面前杀了第三个人。他站在那儿没有出手，事后一个人把尸体收了。这一笔写出来，读者会恨他，也会懂他。

### 2.21.3 技巧三：给他的判断一个私人理由

人物做判断时，理由最好与一段私事有关，而不是与公理有关。他讨厌某种香气，因为那香气来自仇人的屋子；他不肯走某条路，因为那条路上死过人；他总在雨天不出门，因为三十年前那场雨里他失去过一个人。

私人理由的好处是“不需要解释就成立”。读者不会追问“为什么”，只会觉得“这个人有过去”。而公理式的理由，读者会争论对错，争论就出戏。

### 2.21.4 技巧四：让他算错一次

聪明人算错，比笨人算错更有戏。他算准了对手的每一步，却没算到对手会为一个死人回头。这一错，让他输了一场本该赢的局，也让他第一次对对手产生敬意。

算错的理由要足够人性：不是因为蠢，是因为他高估了对方的理智，低估了对方的情。这种错，往往让两个宿敌之间生出一点说不清的东西。

### 2.21.5 技巧五：给一个只有他自己知道的小习惯

小习惯是人物的指纹。递东西前先擦一下、说话前先咳一声、坐下前先把椅子挪半寸、写名字时最后一笔要顿一下。这些动作不需要解释，出现三次，读者就记住了。

小习惯还有一个高级用法：在关键时刻破掉它。他一辈子先擦再递，最后一次他没擦，直接把东西塞到对方手里，因为他知道这是最后一面。读者看到这里，情绪会瞬间到位。

### 2.21.6 技巧六：让他的语言与身份错位

身份高的人说粗话，身份低的人说雅话，都会有味道。一个守了三十年山的老剑尊，说话像镇上的老农；一个药童出身的女主，偶尔冒出一句文绉绉的话，暗示她的来历。错位不是搞笑，是伏笔。

错位使用要节制。一个人物只设一处错位，用多了变成怪癖。错位的解释最好迟到，迟到才有悬念。

### 2.21.7 技巧七：用一件旧物写出他的时间

一件用了很久的东西，比一段回忆更能写出时间。补过三次的丹炉、磨平了纹路的剑柄、袖口洗不掉的白痕、一本翻烂的册子。这些物件自带“很多年”的信息，读者一眼就懂。

旧物的写法是“先写物，后写人”。先让读者看见那件东西的样子，再让他看见人怎么用它。顺序颠倒，就变成了说明文。

### 2.21.8 技巧八：给他一个不能说的人

每个人物心里都要有一个不能提的名字。提起来他会沉默、会转开话题、会突然发火。这个名字不必在前期揭晓，但每一次触及都要有反应，反应本身就是人物。

把这个人放在第三卷揭晓，效果最好。因为读者已经被吊了三十万字，一旦揭晓，前面所有反常行为都会重新被理解，那种“原来如此”的震动，是长篇最值钱的东西。

### 2.21.9 技巧九：让他的力量有具体的手感

写强者不要只写“气势”，要写手感。他握剑时指节的位置、出手前呼吸的变化、收招后手掌的酸麻、用力过猛之后耳朵里的嗡响。手感让力量变得可信，可信才有压迫感。

还有一个反向写法：写他用力过猛之后的狼狈。衣袖裂了、嘴角有血、站起来的时侯晃了一下。强者露出狼狈，比弱者拼命更有说服力。

### 2.21.10 技巧十：给他一个不体面的时刻

再强的人也要有一个不体面的时刻：他撒谎被当场识破、他在雨里摔了一跤、他求人时声音发抖、他为了活下去吃了一样自己都嫌弃的东西。不体面的时刻不会削弱人物，反而让他变成人。

十个技巧里，这一个最容易被作者回避，因为作者爱自己的人物，不忍心让他难看。但读者恰恰是通过难看的时刻确认“这个人是真的”。护着人物的作者，最后往往写出一个没人记得的完人。

### 2.21.11 十个技巧的组合用法

| 人物类型 | 主用技巧 | 辅用技巧 |
|---|---|---|
| 清冷剑尊 | 不肯做的事、不能说的人 | 小习惯、力量手感 |
| 护短师尊 | 优点伤人、不体面的时刻 | 旧物、语言错位 |
| 废柴逆袭 | 算错一次、不体面的时刻 | 小习惯、力量手感 |
| 仙门圣女 | 不肯做的事、私人理由 | 语言错位、旧物 |
| 复仇重生 | 不能说的人、优点伤人 | 旧物、算错一次 |

组合的原则是“一主两辅”。主技巧决定这个人物的核心记忆点，辅技巧负责在细节处加分。三个以上同时用，人物会显得用力过猛，反而失真。

最后提醒：技巧是给“已经想清楚这个人是谁”的作者用的。如果人物本身还是一团模糊，再多的技巧也只是包装。先回答“他要什么、他怕什么、他不肯做什么”，再回来用技巧上色。
