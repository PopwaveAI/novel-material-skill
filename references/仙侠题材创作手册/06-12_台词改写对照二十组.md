# 6.12 台词改写对照二十组

> 素材来源：novel-material-skill ·《仙侠题材创作手册》6.12 台词改写对照二十组

下面二十组对照，左边是第一稿（多数作者会这么写），右边是改后。每一组只改一句话，差别却能决定这一场戏成不成。

### 6.12.1 拒绝型

| 第一稿 | 改后 |
|---|---|
| “我不会帮你的。” | “你走错门了。” |
| “这件事我做不到。” | “换个人来做，比我快。” |
| “我不想见你。” | “你回去吧，今天山门关了。” |
| “我不需要你的好意。” | “我这儿不缺这个。” |
| “你别再来找我。” | “下次来，带点别的。” |

### 6.12.2 关切型

| 第一稿 | 改后 |
|---|---|
| “你没事吧，我很担心你。” | “手伸出来。” |
| “你一定很疼吧。” | “坐下，别说话。” |
| “要好好照顾自己。” | “粥在灶上，凉了自己热。” |
| “别难过，一切都会好。” | “今晚风大，把窗关上。” |
| “记住，我永远支持你。” | “打输了回来，别在外面站着。” |

### 6.12.3 告白型

| 第一稿 | 改后 |
|---|---|
| “我喜欢你，从第一眼开始。” | “你那件外袍，我洗了三遍。” |
| “我爱你，愿意为你做任何事。” | “我不走。” |
| “你是我的全部。” | “门别关，我在外头。” |
| “我想和你在一起。” | “明年这个时候，我还来。” |
| “没有你，我活不下去。” | “我把药铺开到这儿，是因为你提过一次。” |

### 6.12.4 威胁型

| 第一稿 | 改后 |
|---|---|
| “你会后悔的。” | “你记住今天。” |
| “我要杀了你。” | “你还有三天。” |
| “你逃不掉。” | “路我已经堵了。” |
| “我会让你付出代价。” | “这笔账，我记着。” |
| “你等着。” | “下一次见面，别带剑。” |

### 6.12.5 承认型

| 第一稿 | 改后 |
|---|---|
| “是我做的。” | “那件事，我认。” |
| “我错了。” | “你说得对，是我错。” |
| “我骗了你。” | “有一句话，我没说实话。” |
| “我确实恨过你。” | “有那么几年，我不想听见你的名字。” |
| “我配不上你。” | “你走的时候，我没有拦。” |

二十组的共同改法是：删掉情绪词，留下具体的事。左边每一句都在告诉读者“我是什么情绪”，右边每一句都在让读者自己算。读者算出来的东西，他才会记住。
