# 2.20 群像的分工与配比

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.20 群像的分工与配比

群像不是人多，是每个人都有自己的那一件事。

### 2.20.1 五人结构

| 位置 | 功能 | 与主角的关系 |
|---|---|---|
| 镜像 | 走了一条相似的路，结果不同 | 让主角看到另一种可能 |
| 对手 | 持续施压，且有理 | 逼主角成长 |
| 旧人 | 代表他回不去的那段过去 | 给他软肋 |
| 新人 | 代表他正在保护的东西 | 给他责任 |
| 判官 | 看戏、评说、给规矩 | 给读者一个参照视角 |

五人结构里“镜像”最重要。写一个和主角起点相似、选择不同、结局不同的人，读者会自然对比，不用作者评论。

### 2.20.2 配比刻度

主角戏六成，五人各占百分之六到八，其余留白。任何一个配角超过一成，作品就开始散。配角戏份不是按喜欢给的，是按功能给的。

还有一个隐形刻度：每个配角每二十章至少出现一次，且每次都要有自己的推进。断线太久，读者会忘；忘了的配角再出场，等于重新介绍一遍，浪费篇幅。

### 2.20.3 群像的卷末合流

群像最好在每一卷末合流一次：五个人因为同一件事聚在一处，各自的选择不同。这一次合流会让读者看清他们这十章的成长，也能制造“下一卷会怎样”的期待。

合流场景不必宏大。一间屋子、一场雨、一具尸体、一封没拆的信，都足够。重要的不是场面，是五个人在同一刻各自的表情与动作。
