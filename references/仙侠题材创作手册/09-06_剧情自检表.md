# 9.6 剧情自检表

> 素材来源：novel-material-skill ·《仙侠题材创作手册》9.6 剧情自检表

这张表是每卷写完后的体检单。二十五项，逐条打钩，命中三项以上必须重写该卷。

| 编号 | 自检项 | 判定 |
|---|---|---|
| 01 | 本卷主角的处境是否发生变化 | 不变则重写 |
| 02 | 本卷是否有一个明确的目标 | 没有则加 |
| 03 | 本卷是否有一次真实的失败 | 没有则加 |
| 04 | 本卷反派是否有自洽的动机 | 没有则改 |
| 05 | 本卷是否有一个配角赢过主角一次 | 没有则加 |
| 06 | 本卷是否至少回收一个旧伏笔 | 没有则补 |
| 07 | 本卷是否埋下至少三个新伏笔 | 没有则补 |
| 08 | 本卷战斗是否有三种以上形式 | 单一则改 |
| 09 | 本卷是否有一场纯情绪戏 | 没有则加 |
| 10 | 本卷是否有一场纯智谋戏 | 没有则加 |
| 11 | 本卷感情线是否推进一格 | 不动则改 |
| 12 | 本卷是否出现现代语穿帮 | 出现则清 |
| 13 | 本卷境界是否与锚点表一致 | 不一致则改 |
| 14 | 本卷资源消耗是否记账 | 没记则补 |
| 15 | 本卷是否有重复的桥段 | 重复则换 |
| 16 | 本卷配角是否有人物弧光 | 没有则补 |
| 17 | 本卷是否有一处世界观扩展 | 没有则加 |
| 18 | 本卷是否有明确的卷末钩子 | 没有则加 |
| 19 | 本卷主角是否做过一次错的选择 | 没有则加 |
| 20 | 本卷是否有一次“代价兑现” | 没有则加 |
| 21 | 本卷是否有读者会截图的一句台词 | 没有则改 |
| 22 | 本卷是否有一次“不该出现的小东西” | 没有则加 |
| 23 | 本卷是否有一次视角切换 | 没有则考虑 |
| 24 | 本卷是否能被一句话概括 | 不能则散 |
| 25 | 本卷删掉是否影响全书 | 不影响则水 |

第二十五项最狠，也最有用。如果一卷删掉之后全书照样成立，这一卷就是水卷。水的部分不一定要删，但一定要压缩，把三十章压成十五章，读者不会察觉，节奏却会明显变紧。

自检表的用法是“先打钩，再改稿，改完销号”。不要一边写一边自检，那样会卡死。写完一卷，集中一小时自检，效率最高。
