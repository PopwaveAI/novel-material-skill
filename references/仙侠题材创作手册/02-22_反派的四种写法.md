# 2.22 反派的四种写法

> 素材来源：novel-material-skill ·《仙侠题材创作手册》2.22 反派的四种写法

仙侠的反派往往决定作品的讨论度。四种写法各有功能，选一种做主线，其余做点缀。

### 2.22.1 写法人：讲理的反派

这类反派有一套自洽的道理，且这套道理能戳中主角的软处。他不喊口号，只陈述事实：宗门保住了大多数人，代价是牺牲少数人；他做的正是那件没人敢做的事。主角反驳不了，只能选择。

写这类反派的关键是“让他说对一半”。全错的反派没有威胁，全对的反派主角就站不住。一半对，主角的坚持才有重量。

### 2.22.2 写法人二：讲情的反派

这类反派的动机是私情：为一个人、为一段旧怨、为一句没兑现的承诺。他做的所有恶事都指向同一个源头。读者会恨他做的事，却无法完全否定他的人。

这类反派的最佳结局不是被杀，是“他终于得到了那样东西，然后发现没有意义”。这个结局比一刀两断更狠。

### 2.22.3 写法人三：讲规矩的反派

这类反派代表秩序本身。他不做恶，他只是执行规矩，而规矩本身就是恶。他从不违规，甚至比主角更守规矩。与他斗争，主角要面对的不是一个人，是一整套制度。

这类反派最难写，因为他没有私欲。写好的诀窍是给他一处裂缝：他在某个深夜也会犹豫，也会想起自己年轻时被规矩伤过的那一次。裂缝让人物可信，也给了主角一个破局的口子。

### 2.22.4 写法人四：讲疯的反派

这类反派不讲逻辑，只讲执念。他可能为了一个荒唐的理由屠一座城，也可能因为一句无心的话放过主角。他的不可预测本身就是威胁。

疯反派的风险是“变成工具”。要避免这一点，必须给他一个可以被理解的起点：他曾经很正常，是被某件事弄坏的。读者看到那个起点，就会在他发疯时感到凉，而不是只觉得吵。

### 2.22.5 四种反派的组合

| 作品气质 | 主线反派 | 副线反派 |
|---|---|---|
| 正统逆袭 | 讲规矩 | 讲理 |
| 凡人流 | 讲理 | 讲情 |
| 仙魔对立 | 讲情 | 讲疯 |
| 写实修仙 | 讲规矩 | 讲规矩（另一套） |
| 无 CP | 讲理 | 讲疯 |

组合的规律是“主线讲结构，副线讲情绪”。主线反派负责让读者思考，副线反派负责让读者生气。两者都有，故事才有层次。

最后一个建议：反派要有名字，要有脸，要有一次让读者记住的具体行为。没有这三样，他只是一个“敌人”的符号，符号不会让人记住，也不会让人讨论。
