# 6.19 去 AI 腔替换表三十组

> 素材来源：novel-material-skill ·《仙侠题材创作手册》6.19 去 AI 腔替换表三十组

下面三十组替换，左边是常见的人工痕迹，右边是人话。它们是本册最后一件工具，也是最实用的一件。

### 6.19.1 情绪类十组

| 痕迹写法 | 替换写法 |
|---|---|
| 他心中五味杂陈 | 他张了张嘴，没说出话 |
| 他感到一阵悲凉 | 他把手揣进袖子里，握了握 |
| 内心充满了震撼 | 他站在原地，忘了让开 |
| 他无比愤怒 | 他把茶盏放回桌上，放得很轻 |
| 他感到一丝欣慰 | 他看了一眼，点了点头 |
| 他不禁红了眼眶 | 他咳了一声，转过身去 |
| 他心中涌起暖流 | 他把火盆往那边推了推 |
| 他感到前所未有的恐惧 | 他没有退，也没有进 |
| 他松了一口气 | 他把绷着的肩膀放下来 |
| 他陷入了沉思 | 他一直没有动那碗粥 |

### 6.19.2 动作类十组

| 痕迹写法 | 替换写法 |
|---|---|
| 他缓缓地站起身来 | 他扶着桌子站起来 |
| 他猛地转身 | 他转过身，袖子带倒了灯 |
| 他深深地看了她一眼 | 他看了她一眼，看到她把头低下去 |
| 他快步走上前去 | 他走了三步，第三步停住 |
| 他紧紧地握住剑柄 | 他握住剑柄，指节发白 |
| 他轻轻地叹了口气 | 他呼出一口气，把灯吹得晃了一下 |
| 他缓缓闭上了眼睛 | 他闭上眼睛，眼皮还在动 |
| 他默默地转身离去 | 他转身，走了七步，没有回头 |
| 他不由自主地后退一步 | 他退了半步，脚跟抵住门槛 |
| 他终于露出了笑容 | 他笑了一下，笑完把嘴角收回去 |

### 6.19.3 描写类十组

| 痕迹写法 | 替换写法 |
|---|---|
| 空气中弥漫着肃杀之气 | 没有人说话，风也停了 |
| 一股强大的气息扑面而来 | 他的衣袖被压得贴在身上 |
| 时间仿佛静止了 | 过了很久，才有人咽了一口口水 |
| 整个世界都安静了下来 | 只剩下血滴在石头上的声音 |
| 他宛如天神下凡 | 他站在那儿，没有一个人敢往前 |
| 光芒万丈，耀眼夺目 | 他脸上那层霜化了 |
| 气氛一时间变得无比凝重 | 有人把手按在了剑柄上 |
| 众人皆是瞠目结舌 | 有人手里的碗掉了 |
| 天地为之变色 | 云往一个方向聚过去 |
| 这一切都显得那么不真实 | 他伸手摸了摸门框，还在 |

### 6.19.4 替换表的使用方法

三步：第一步 找到痕迹句；第二步 问自己“这一刻他身体在做什么”；第三步 把答案写出来，删掉原句。三步走完，文字就从“描述情绪”变成“呈现动作”。

三十组不必背。写完之后搜一遍关键词：心中、内心、感到、不禁、缓缓、深深、紧紧地、仿佛、宛如。搜到就改，改完文字立刻干净。

最后一句话：人话不是口语，是具体的、有身体的、有物件的语言。同样一句“他很难过”，写成“他一直没动那碗粥”，读者就懂了，而且会记住。
