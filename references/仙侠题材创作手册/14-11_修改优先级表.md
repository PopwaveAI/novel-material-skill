# 14.11 修改优先级表

> 素材来源：novel-material-skill ·《仙侠题材创作手册》14.11 修改优先级表

时间有限时，改稿要有优先级。下面按“影响面”排序，先改前面的。

| 优先级 | 修改项 | 影响面 |
|---|---|---|
| 第一优先 | 结局三笔账是否结清 | 决定读者最终评价 |
| 第二优先 | 主角是否做过一次错的选择并付代价 | 决定作品重量 |
| 第三优先 | 开篇三章是否七格齐全 | 决定留存 |
| 第四优先 | 境界与社会位置是否同步 | 决定追更 |
| 第五优先 | 反派是否有自洽动机 | 决定讨论度 |
| 第六优先 | 感情线是否靠多余动作推进 | 决定二创 |
| 第七优先 | 章末钩子是否兑现 | 决定追读率 |
| 第八优先 | 现代语与穿帮词 | 决定沉浸感 |
| 第九优先 | 错字与标点 | 决定专业度 |

九项里前三项最重要。它们决定读者会不会推荐这本书，其余决定读者会不会吐槽这本书。推荐与吐槽之间，差的是口碑的量级。
